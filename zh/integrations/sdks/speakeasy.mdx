由 Speakeasy SDK 自动生成的代码片段可以直接集成到 Mintlify 的 API 参考文档中。在由 Mintlify 驱动的文档站点中，这些 SDK 使用示例会显示在[交互式 playground](/zh/api-playground/overview)中。

<Frame>
  ![带有 Speakeasy 代码片段的 Mintlify API playground。](/images/speakeasy/mintlify-with-speakeasy-openapi.png)
</Frame>

<div id="prerequisites">
  ## 前置条件
</div>

要将 Mintlify 与 Speakeasy 集成，你需要准备以下内容：

* 一个 [Mintlify 文档仓库](/zh/quickstart#creating-the-repository)。
  * 一个由 Speakeasy 生成并已配置 [自动代码示例 URL](https://www.speakeasy.com/docs/code-samples/automated-code-sample-urls) 的 SDK。

<div id="setting-up-the-integration">
  ## 配置集成
</div>

要将 Speakeasy 与 Mintlify 集成，你需要从注册表中获取该 API 的组合规范公共 URL，并更新你的 `docs.json` 配置文件。

<div id="get-the-apis-combined-spec-public-url-from-the-registry">
  ### 从注册表中获取 API 合并规范的公开 URL
</div>

前往你的 [Speakeasy Dashboard](https://app.speakeasy.com)，打开 **API Registry** 选项卡。打开该 API 的 `*-with-code-samples` 条目。

<Frame>
  ![Speakeasy API Registry 页面截图。API Registry 选项卡用红色方框和数字 1 标出，API 的条目用红色方框和数字 2 标出。](/images/speakeasy/openapi-registry-and-combined-spec.png)
</Frame>

<Note>
  如果该条目未标记为 **Combined Spec**，请确保该 API 已配置 [automatic code sample URL](https://www.speakeasy.com/docs/code-samples/automated-code-sample-urls)（自动代码示例 URL）。
</Note>

在该注册表条目的页面中，复制提供的公开 URL。

<Frame>
  ![显示合并规范注册表条目截图，其中复制 URL 功能用红色方框标出。](/images/speakeasy/copy-combined-spec-url.png)
</Frame>

<div id="update-your-docsjson-configuration-file">
  ### 更新你的 `docs.json` 配置文件
</div>

在 `docs.json` 文件的 **Anchors** 或 **Tabs** 部分添加组合后的规范 URL。

通过如下方式更新 `docs.json` 文件中的 `anchor` 字段，将组合后的规范 URL 添加到某个锚点中：

```json docs.json
{
  "anchors": [
    {
      "name": "API Reference",
      // !mark
      "openapi": "SPEAKEASY_COMBINED_SPEC_URL",
      "url": "api-reference",
      "icon": "square-terminal"
    }
  ]
}
```

通过如下方式更新 `docs.json` 文件中的 `tab` 字段，将合并后的规范 URL 添加到某个选项卡中：

```json docs.json
{
  "tabs": [
    {
      "name": "API Reference",
      "url": "api-reference",
      // !mark
      "openapi": "SPEAKEASY_COMBINED_SPEC_URL"
    }
  ]
}
```

现在，你可以在 API 文档中查看由 Speakeasy 生成的代码示例，并在 playground 中直接交互试用。
