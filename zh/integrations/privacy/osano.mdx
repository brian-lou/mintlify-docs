通过仓库中的[自定义 JavaScript 文件](/zh/customize/custom-scripts#custom-javascript)，为文档添加 [Osano](https://www.osano.com/) 的 Cookie 同意管理功能。

<div id="setup">
  ## 设置
</div>

在你的文档仓库中创建一个名为 `osano.js` 的文件，内容如下：

<CodeGroup>
  ```js Format
  var script = document.createElement("script");
  script.src = "OSANO_SCRIPT_URL";
  document.head.appendChild(script);
  ```

  ```js Example
  var script = document.createElement("script");
  script.src = "https://cmp.osano.com/your-tenant-id/your-site-id/osano.js";
  document.head.appendChild(script);
  ```
</CodeGroup>

将 `OSANO_SCRIPT_URL` 替换为你的 Osano 脚本 URL。脚本 URL 是 Osano 生成的代码片段中的 `src` 值。脚本 URL 始终以 `https://cmp.osano.com/` 开头，以 `/osano.js` 结尾。

<div id="troubleshooting">
  ## 疑难解答
</div>

<Accordion title="在 Strict 合规模式下页面无法加载">
  如果在使用 Osano 的 **Strict** 合规模式时，文档页面无法正常加载，你需要将 Mintlify 的域名加入允许列表，以便加载图片和其他资源。

  <Steps>
    <Step title="导航到 Managed Rules">
      在你的 Osano 仪表板中，前往 **Scripts** → **Managed Rules**。
    </Step>

    <Step title="添加 Mintlify 域名">
      将 `.mintlify.app/` 添加为一个受管规则（managed rule）。

      <Frame>
        <img src="/images/integrations/osano-managed-rule.png" alt="Osano 受管规则" />
      </Frame>

      <Info>
        这样可以确保所有由 Mintlify 提供的资源（包括图片、样式表和其他文档资源）都被视为必需内容，即使 Osano 阻止未分类的第三方内容，它们也仍然会加载。
      </Info>
    </Step>
  </Steps>
</Accordion>
