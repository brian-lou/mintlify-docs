description: "连接 Intercom 以实现应用内客户消息传递。"
keywords: ["Intercom 集成", "Intercom 小部件", "应用 ID", "应用内消息传递"]
---

在你的 `docs.json` 文件中添加以下内容以添加一个 [Intercom](https://www.intercom.com) 小部件。

<CodeGroup>

```json docs.json 中的集成选项
"integrations": {
      "intercom": {
            "appId": "APP_ID"
      }
}
```

```json 示例
"integrations": {
      "intercom": {
            "appId": "abc123def4"
      }
}
```

</CodeGroup>
