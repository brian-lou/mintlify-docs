description: "连接 Intercom 以启用应用内客户消息功能。"
keywords: ["Intercom 集成", "Intercom 小部件", "app ID", "应用内消息"]
---

将以下内容添加到你的 `docs.json` 文件中，以接入 [Intercom](https://www.intercom.com) 小部件。

<CodeGroup>
  ```json docs.json 中的集成选项
  "integrations": {
        "intercom": {
              "appId": "APP_ID"
        }
  }
  ```

  ```json 示例
  "integrations": {
        "intercom": {
              "appId": "abc123def4"
        }
  }
  ```
</CodeGroup>
