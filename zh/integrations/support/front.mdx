将以下内容添加到你的 `docs.json` 文件中，以添加 [Front Chat](https://front.com) 聊天组件。

<CodeGroup>
  ```json docs.json 中的集成选项
  "integrations": {
      "frontchat": "CHAT_ID"
  }
  ```

  ```json 示例
  "integrations": {
      "frontchat": "1365d046d7c023e9b030ce90d02d093a"
  }
  ```
</CodeGroup>
