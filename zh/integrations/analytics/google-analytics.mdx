你需要创建一个新的 <Tooltip tip="Google Analytics 4">GA4</Tooltip> 媒体资源，以在 Mintlify 中使用。收集到的数据会归入与你其他 Google Analytics 数据相同的项目中。

即使你仍在使用旧版 Google Analytics（Universal Analytics，简称 UA），也依然可以创建 <Tooltip tip="Google Analytics 4">GA4</Tooltip> 媒体资源。<Tooltip tip="Google Analytics 4">GA4</Tooltip> 数据与 UA 数据略有不同，但仍会被收集到同一个项目中。

<div id="how-to-connect-ga4-to-mintlify">
  ## 如何将 GA4 接入 Mintlify
</div>

<div id="create-a-web-stream">
  ### 创建 Web 数据流
</div>

你需要创建一个 Web 数据流来获取 Measurement ID，并将其填入 Mintlify。

点击 Google Analytics 界面左下角的齿轮图标，然后点击 Data Streams。

<Frame>![Google Analytics 仪表盘中 Data Streams 页面截图。](/images/ga4-web-streams.png)</Frame>

创建一个 Web 数据流，并将你的 Mintlify 文档站点的 URL 填写为该数据流的 URL。

你的 Measurement ID 类似于 `G-XXXXXXX`，在你创建 Web 数据流之后，会立即显示在 Stream Details 下方。

<div id="put-measurement-id-in-docsjson">
  ### 在 docs.json 中填写 Measurement ID
</div>

将你的 Measurement ID 添加到 `docs.json` 文件中，示例如下：

```json docs.json
"integrations": {
    "ga4": {
        "measurementId": "G-XXXXXXX"
    }
}
```


<div id="wait">
  ### 等待
</div>

Google Analytics 需要两到三天时间才会显示你的数据。

你可以使用 [Google Analytics Debugger](https://chrome.google.com/webstore/detail/google-analytics-debugger/jnkmfdileelhofjcijamephohjechhna?hl=en) 来检查分析功能是否已正确启用。该扩展程序会在每次 GA4 发出请求时，将相关信息记录到你的浏览器控制台中。

<Note>

预览链接默认不启用分析功能。

</Note>
