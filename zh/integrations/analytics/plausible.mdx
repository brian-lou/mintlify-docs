将你的网站域名添加到 `docs.json` 中，用来将统计数据发送到 Plausible。

<Info>
  不要在域名或服务器前包含 `https://`。
</Info>

<CodeGroup>

```json Analytics options in docs.json
"integrations": {
    "plausible": {
        "domain": "required - your documentation domain",
        "server": "optional - your self-hosted Plausible server URL"
    }
}
```

```json Example
"integrations": {
    "plausible": {
        "domain": "docs.domain.com"
    }
}
```

</CodeGroup>
