将以下内容添加到你的 `docs.json` 文件中，以便将分析数据发送到 PostHog。

只有在自托管 PostHog 时，才需要包含 `apiHost`。默认情况下，事件会发送到 `https://app.posthog.com`。

<CodeGroup>
  ```json docs.json 中的分析配置选项
  "integrations": {
      "posthog": {
          "apiKey": "YOUR_POSTHOG_PROJECT_API_KEY",
          "apiHost": "optional",
          "sessionRecording": true
      }
  }
  ```

  ```json 示例
  "integrations": {
      "posthog": {
          "apiKey": "phc_TXdpocbYTeZVm5VJmMzHTMrCofBQu3e0kN7HGMNGTVW"
      }
  }
  ```
</CodeGroup>

<div id="configuration-options">
  ### 配置选项
</div>

<ParamField path="apiKey" type="string" required>
  你的 PostHog 项目 API 密钥。必须以 `phc_` 开头。
</ParamField>

<ParamField path="apiHost" type="string">
  你的 PostHog 实例 URL。仅当你自托管 PostHog 时才需要设置。默认为 `https://app.posthog.com`。
</ParamField>

<ParamField path="sessionRecording" type="boolean" default="true">
  启用或禁用会话录制。将其设为 `false` 可在保留分析功能的同时禁用会话录制。
</ParamField>

<div id="session-recordings">
  ## 会话录制
</div>

配置 PostHog 时，系统默认会启用会话录制。若要在保留分析功能的同时禁用会话录制，请在配置中将 `sessionRecording` 设为 `false`。

```json Disable session recordings
"integrations": {
    "posthog": {
        "apiKey": "phc_your-key",
        "sessionRecording": false
    }
}
```

您需要先将文档网站的 URL 添加到 PostHog 的“Authorized domains for recordings”中，才能接收会话录制。添加 URL 的选项位于 PostHog 的项目设置中。
