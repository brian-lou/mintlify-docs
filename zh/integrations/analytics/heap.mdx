在你的 `docs.json` 文件中添加以下内容，将分析数据发送到 Heap。

<CodeGroup>

```json docs.json 中的分析选项
"integrations": {
    "heap": {
        "appId": "required"
    }
}
```

```json 示例
"integrations": {
    "heap": {
        "appId": "1234567890"
    }
}
```

</CodeGroup>
