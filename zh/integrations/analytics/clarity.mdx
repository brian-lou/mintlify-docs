将以下内容添加到你的 `docs.json` 文件中，以将分析数据发送至 Microsoft Clarity。

<CodeGroup>
  ```json docs.json 中的分析选项
  "integrations": {
      "clarity": {
          "projectId": "required"
      }
  }
  ```

  ```json 示例
  "integrations": {
      "clarity": {
          "projectId": "abc123xyz"
      }
  }
  ```
</CodeGroup>

<div id="get-your-project-id">
  ## 获取项目 ID
</div>

1. 创建一个 [Clarity 账号](https://clarity.microsoft.com/projects)。
2. 点击 **获取跟踪代码**。
3. 从跟踪代码中复制项目 ID。
