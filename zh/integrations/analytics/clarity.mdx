在你的 `docs.json` 文件中添加以下内容，将分析数据发送到 Microsoft Clarity。

<CodeGroup>

```json docs.json 中的分析配置项
"integrations": {
    "clarity": {
        "projectId": "required"
    }
}
```

```json 示例
"integrations": {
    "clarity": {
        "projectId": "abc123xyz"
    }
}
```

</CodeGroup>

<div id="get-your-project-id">
  ## 获取项目 ID
</div>

1. 创建一个 [Clarity 账户](https://clarity.microsoft.com/projects)。
2. 点击 **Get tracking code.**
3. 从跟踪代码中复制项目 ID。
