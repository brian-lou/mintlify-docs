---
title: "Hightouch"
description: "将数据同步到 Hightouch，用于受众激活。"
keywords: ["Hightouch 集成", "数据激活", "write key", "受众同步"]
---

在你的 `docs.json` 文件中添加以下配置，将分析数据发送到 Hightouch。

<Info>

  不要在 `apiHost` 中包含 `https://`。

</Info>

<CodeGroup>

```json Analytics options in docs.json
"integrations": {
    "hightouch": {
        "writeKey": "required"
        "apiHost": "optional"
    }
}
```

```json 示例
"integrations": {
    "hightouch": {
        "writeKey": "9132c81do371p76sr11da0075469b54f77649c9a067dp0303p56q0q64n072336"
        "apiHost": "us-east-1.hightouch-events.com" # 可选，默认值为 `us-east-1.hightouch-events.com`
    }
}
```

</CodeGroup>
