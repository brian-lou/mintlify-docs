---

将你的 Segment write key 添加到 `docs.json` 文件中，即可将分析事件发送到 Segment。

<CodeGroup>

```json 在 docs.json 中的分析选项
"integrations": {
    "segment": {
        "key": "required",
    }
}
```

```json 示例
"integrations": {
    "segment": {
        "key": "nqJxiRG15Y6M594P8Sb8ESEciU3VC2"
    }
}
```

</CodeGroup>
