在你的 `docs.json` 文件中添加以下内容，以将统计数据发送到 Fathom。

你可以在脚本设置中获取 `siteId`。

<CodeGroup>

```json Analytics options in docs.json
"integrations": {
    "fathom": {
        "siteId": "required"
    }
}
```

```json Example
"integrations": {
    "fathom": {
        "siteId": "YSVMSDAY"
    }
}
```

</CodeGroup>
