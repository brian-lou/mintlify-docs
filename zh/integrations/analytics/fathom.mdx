将以下内容添加到你的 `docs.json` 文件中，即可将分析数据发送到 Fathom。

你可以在脚本设置中找到 `siteId`。

<CodeGroup>
  ```json docs.json 中的分析配置
  "integrations": {
      "fathom": {
          "siteId": "required"
      }
  }
  ```

  ```json 示例
  "integrations": {
      "fathom": {
          "siteId": "YSVMSDAY"
      }
  }
  ```
</CodeGroup>
