---
title: "Google Tag Manager"
description: "使用 Google Tag Manager 管理分析标签和事件。"
keywords: ["GTM 集成", "标签管理", "标签 ID", "Cookie 同意"]
---

将你的标签 ID 添加到 `docs.json` 文件中，我们就会在你的所有页面中注入 Google Tag Manager 脚本。

如果你需要 Cookie 同意横幅，则需要自行通过 Google Tag Manager 进行设置。

<CodeGroup>
  ```json docs.json 中的分析选项
  "integrations": {
      "gtm": {
          "tagId": "required"
      }
  }
  ```

  ```json 示例
  "integrations": {
      "gtm": {
          "tagId": "GTM-MGBL4PW"
      }
  }
  ```
</CodeGroup>
