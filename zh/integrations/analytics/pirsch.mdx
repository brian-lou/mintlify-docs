在你的 `docs.json` 文件中添加以下内容，将统计数据发送到 Pirsch。

你可以在 Settings \> Developer \> Identification Code 中获取你的站点 ID。

<CodeGroup>

```json docs.json 中的分析选项
"integrations": {
    "pirsch": {
        "id": "required"
    }
}
```

```json 示例
"integrations": {
    "pirsch": {
        "id": "8Kw7OKxBfswOjnKGZa7P9Day8JmVYwTp"
    }
}
```

</CodeGroup>
