将以下内容添加到 `docs.json` 文件中，即可将分析数据发送到 Pirsch。

你可以在设置 &gt; 开发者 &gt; 识别代码中获取站点 ID。

<CodeGroup>
  ```json docs.json 中的分析选项
  "integrations": {
      "pirsch": {
          "id": "required"
      }
  }
  ```

  ```json 示例
  "integrations": {
      "pirsch": {
          "id": "8Kw7OKxBfswOjnKGZa7P9Day8JmVYwTp"
      }
  }
  ```
</CodeGroup>
