---
title: "手动创建 API 页面"
description: "使用 MDX 文件手动编写 API 端点文档。"
keywords: ["API 文档", "端点文档"]
---

你可以在单独的 MDX 页面中手动定义 API 端点。这种方式适用于小型 API 或原型开发。

<div id="setup">
  ## 设置
</div>

<Steps>
  <Step title="配置 API 设置">
    在你的 `docs.json` 文件中定义基础 URL 和身份验证方法。

    ```json Example docs.json
    "api": {
      "mdx": {
        "server": "https://api.acme.com/",
        "auth": {
          "method": "key",
          "name": "x-api-key"
        }
      }
    }
    ```

    如果你想隐藏 API playground，只需将 `display` 字段设置为 `none`。在隐藏 playground 的情况下，就不需要配置任何身份验证方式。

    ```json
    "api": {
      "playground": {
        "display": "none"
      }
    }
    ```

    API 所有配置项的完整列表请参见 [Settings](/zh/organize/settings#api-configurations)。
  </Step>

  <Step title="创建端点页面">
    为每个端点创建一个 MDX 文件。在文件头（frontmatter）中定义 `title` 和 `api`：

    ```mdx
    ---
    title: 'Create new user'
    api: 'POST /v1/users'
    ---
    ```

    frontmatter 中的 `api` 字段可以接受完整 URL 或相对路径：

    * **完整 URL**，例如 `POST https://api.acme.com/v1/users`。对于该 endpoint，`docs.json` 中的 `server` 字段会被忽略。
    * **相对路径**，例如 `POST /v1/users`。此时需要在 `docs.json` 中提供 `server` 字段。服务器 URL 会被添加到该路径前面。

    通过将路径参数包裹在 `{}` 中来指定它们：

    ```bash
    https://api.example.com/v1/endpoint/{userId}
    ```

    要在特定页面上覆盖全局的 playground 显示模式，请在 frontmatter 中添加 `playground`：

    ```mdx
    ---
    title: 'Create new user'
    api: 'POST https://api.mintlify.com/user'
    playground: 'none'
    ---
    ```

    选项：

    * `playground: 'interactive'` - 显示交互式 playground（默认）
    * `playground: 'simple'` - 显示可复制的端点，不显示 playground
    * `playground: 'none'` - 完全隐藏 playground
  </Step>

  <Step title="添加参数和响应">
    使用[参数和响应字段](/zh/components/fields)来描述端点的参数和返回值。

    ```mdx
    <ParamField path="userId" type="string" required>
      用户的唯一标识符
    </ParamField>

    <ParamField body="email" type="string" required>
      用户的电子邮箱地址
    </ParamField>

    <ResponseField name="id" type="string" required>
      新建用户的唯一标识符
    </ResponseField>

    <ResponseField name="email" type="string" required>
      用户的电子邮箱地址
    </ResponseField>
    ```
  </Step>

  <Step title="在文档中添加你的端点">
    通过更新 `docs.json` 文件中的 `pages` 字段，将你的端点页面添加到导航中：

    ```json docs.json
    "navigation": {
      "tabs": [
        {
          "tab": "API Reference",
          "groups": [
            {
              "group": "Users",
              "pages": [
                "api-reference/users/create-user",
                "api-reference/users/get-user",
                "api-reference/users/update-user"
              ]
            },
            {
              "group": "Orders",
              "pages": [
                "api-reference/orders/create-order",
                "api-reference/orders/list-orders"
              ]
            }
          ]
        }
      ]
    }
    ```

    每个页面路径都对应你文档仓库中的一个 MDX 文件。例如：`api-reference/users/create-user.mdx`。在[导航](/zh/organize/navigation)中了解更多文档结构的相关内容。

    ### 在导航中使用 OpenAPI 端点

    如果你有 OpenAPI 规范，可以在导航中直接引用端点，而无需为每个端点创建单独的 MDX 文件。通过包含 OpenAPI 文件路径和端点来引用特定端点：

    ```json docs.json
    "navigation": {
      "pages": [
        "introduction",
        "/path/to/users-openapi.json POST /users",
        "/path/to/orders-openapi.json GET /orders"
      ]
    }
    ```

    你也可以为导航组设置一个默认的 OpenAPI 规范，并通过方法和路径引用各个端点：

    ```json docs.json
    {
      "group": "API reference",
      "openapi": "/path/to/openapi-v1.json",
      "pages": [
        "overview",
        "authentication",
        "GET /users",
        "POST /users",
        {
          "group": "Orders",
          "openapi": "/path/to/openapi-v2.json",
          "pages": [
            "GET /orders",
            "POST /orders"
          ]
        }
      ]
    }
    ```

    有关 OpenAPI 集成的更多详情，请参阅 [OpenAPI 设置](/zh/api-playground/openapi-setup)。
  </Step>
</Steps>

<div id="enable-authentication">
  ## 启用身份验证
</div>

你可以在 `docs.json` 中设置全局身份验证，也可以在单个页面的 frontmatter 中通过 `authMethod` 字段进行覆盖。页面级的设置会覆盖全局设置。

<div id="bearer-token">
  ### Bearer 令牌
</div>

<CodeGroup>
  ```json docs.json
  "api": {
    "mdx": {
      "auth": {
        "method": "bearer"
      }
    }
  }
  ```

  ```mdx Page Metadata
  ---
  title: "你的页面标题"
  authMethod: "bearer"
  ---
  ```
</CodeGroup>

<div id="basic-authentication">
  ### 基本身份验证
</div>

<CodeGroup>
  ```json docs.json
  "api": {
    "mdx": {
      "auth": {
        "method": "basic"
      }
    }
  }
  ```

  ```mdx Page Metadata
  ---
  title: "您的页面标题"
  authMethod: "basic"
  ---
  ```
</CodeGroup>

<div id="api-key">
  ### API 密钥
</div>

<CodeGroup>
  ```json docs.json
  "api": {
    "mdx": {
      "auth": {
        "method": "key",
        "name": "x-api-key"
      }
    }
  }
  ```

  ```mdx Page Metadata
  ---
  title: "页面标题"
  authMethod: "key"
  ---
  ```
</CodeGroup>

<div id="none">
  ### 无
</div>

要在特定页面上关闭身份验证，将 `authMethod` 设置为 `none`：

```mdx Page Metadata
---
title: "Your page title"
authMethod: "none"
---
```
