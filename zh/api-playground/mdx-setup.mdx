---
title: "手动创建 API 页面"
description: "使用 MDX 文件手动编写 API 端点文档。"
keywords: ["API 文档", "端点文档"]
---

你可以在各个 MDX 页面中手动定义 API 端点。这种方法适合小型 API 或原型开发。

<div id="setup">
  ## 设置
</div>

<Steps>
  <Step title="配置 API 设置">
    在 `docs.json` 文件中，定义基础 URL 和身份验证方式。

    ```json Example docs.json
    "api": {
      "mdx": {
        "server": "https://api.acme.com/",
        "auth": {
          "method": "key",
          "name": "x-api-key"
        }
      }
    }
    ```

    如果你想隐藏 API 操作台，请将 `display` 字段设为 `none`。隐藏 API 操作台后，无需包含身份验证方式。

    ```json
    "api": {
      "playground": {
        "display": "none"
      }
    }
    ```

    可在 [Settings](/zh/organize/settings#api-configurations) 中查看完整的 API 配置列表。
  </Step>

  <Step title="创建端点页面">
    为每个接口创建一个 MDX 文件。在前置元数据中定义 `title` 和 `api`：

    ```mdx
    ---
    title: 'Create new user'
    api: 'POST /v1/users'
    ---
    ```

    `api` 前置元数据字段接受完整 URL 或相对路径：

    * **完整 URL**，例如 `POST https://api.acme.com/v1/users`。对于该端点，会忽略 `docs.json` 中的 `server` 字段。
    * **相对路径**，例如 `POST /v1/users`。需要在 `docs.json` 中提供 `server` 字段。系统会将服务器 URL 添加到路径前。

    将路径参数用 `{}` 包裹起来即可指定：

    ```bash
    https://api.example.com/v1/endpoint/{userId}
    ```

    如需为特定页面覆盖全局 API 操作台显示模式，请在前置元数据中添加 `playground`：

    ```mdx
    ---
    title: 'Create new user'
    api: 'POST https://api.mintlify.com/user'
    playground: 'none'
    ---
    ```

    选项：

    * `playground: 'interactive'` - 显示交互式 API 操作台 (默认)
    * `playground: 'simple'` - 显示可复制的 API 端点，不显示 API 操作台
    * `playground: 'none'` - 完全隐藏 API 操作台
  </Step>

  <Step title="添加参数和响应">
    使用[参数和响应字段](/zh/components/fields)记录端点的参数和返回值。

    ```mdx
    <ParamField path="userId" type="string" required>
      Unique identifier for the user
    </ParamField>

    <ParamField body="email" type="string" required>
      User's email address
    </ParamField>

    <ResponseField name="id" type="string" required>
      Unique identifier for the newly created user
    </ResponseField>

    <ResponseField name="email" type="string" required>
      User's email address
    </ResponseField>
    ```
  </Step>

  <Step title="将 API 端点添加到文档中">
    更新 `docs.json` 中的 `pages` 字段，将你的 API 端点页面添加到导航中：

    ```json docs.json
    "navigation": {
      "tabs": [
        {
          "tab": "API Reference",
          "groups": [
            {
              "group": "Users",
              "pages": [
                "api-reference/users/create-user",
                "api-reference/users/get-user",
                "api-reference/users/update-user"
              ]
            },
            {
              "group": "Orders",
              "pages": [
                "api-reference/orders/create-order",
                "api-reference/orders/list-orders"
              ]
            }
          ]
        }
      ]
    }
    ```

    每个页面路径都对应文档仓库中的一个 MDX 文件。例如，`api-reference/users/create-user.mdx`。如需进一步了解如何组织文档，请参阅[导航](/zh/organize/navigation)。

    ### 在导航中使用 OpenAPI 端点

    如果你有 OpenAPI 规范，无需创建单独的 MDX 文件，也可以在导航中直接引用端点。要引用特定端点，请包含 OpenAPI 文件路径和端点：

    ```json docs.json
    "navigation": {
      "pages": [
        "introduction",
        "/path/to/users-openapi.json POST /users",
        "/path/to/orders-openapi.json GET /orders"
      ]
    }
    ```

    你也可以为某个导航组设置默认的 OpenAPI 规范，并通过方法和路径引用端点：

    ```json docs.json
    {
      "group": "API reference",
      "openapi": "/path/to/openapi-v1.json",
      "pages": [
        "overview",
        "authentication",
        "GET /users",
        "POST /users",
        {
          "group": "Orders",
          "openapi": "/path/to/openapi-v2.json",
          "pages": [
            "GET /orders",
            "POST /orders"
          ]
        }
      ]
    }
    ```

    有关 OpenAPI 集成的更多信息，请参阅 [OpenAPI 设置](/zh/api-playground/openapi-setup)。
  </Step>
</Steps>

<div id="enable-authentication">
  ## 启用身份验证
</div>

你可以在 `docs.json` 中全局设置身份验证，也可以通过前置元数据中的 `authMethod` 字段为单个页面单独覆盖。页面级设置会覆盖全局设置。

<div id="bearer-token">
  ### Bearer 令牌
</div>

<CodeGroup>
  ```json docs.json
  "api": {
    "mdx": {
      "auth": {
        "method": "bearer"
      }
    }
  }
  ```

  ```mdx Page Metadata
  ---
  title: "你的页面标题"
  authMethod: "bearer"
  ---
  ```
</CodeGroup>

<div id="basic-authentication">
  ### 基本认证
</div>

<CodeGroup>
  ```json docs.json
  "api": {
    "mdx": {
      "auth": {
        "method": "basic"
      }
    }
  }
  ```

  ```mdx Page Metadata
  ---
  title: "你的页面标题"
  authMethod: "basic"
  ---
  ```
</CodeGroup>

<div id="api-key">
  ### API 密钥
</div>

<CodeGroup>
  ```json docs.json
  "api": {
    "mdx": {
      "auth": {
        "method": "key",
        "name": "x-api-key"
      }
    }
  }
  ```

  ```mdx Page Metadata
  ---
  title: "Your page title"
  authMethod: "key"
  ---
  ```
</CodeGroup>

<div id="none">
  ### 不启用
</div>

如需在特定页面上禁用身份验证，请将 `authMethod` 设置为 `none`：

```mdx Page Metadata
---
title: "Your page title"
authMethod: "none"
---
```
