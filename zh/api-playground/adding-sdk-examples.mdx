---
title: "添加 SDK 示例"
description: "在 API 文档中显示 SDK 代码示例。"
keywords: ["x-codeSamples", "SDK 示例"]
---

如果您的用户是通过 SDK 与 API 交互，而不是直接发起网络请求，您可以使用 `x-codeSamples` 扩展，在 OpenAPI 文档中添加代码示例，并将其显示在 OpenAPI 页面中。

此属性可添加到任何请求方法，并采用以下结构。

<ParamField body="lang" type="string" required>
  代码示例所使用的语言。
</ParamField>

<ParamField body="label" type="string">
  示例的标签。在为单个端点提供多个示例时，这个字段很有用。
</ParamField>

<ParamField body="source" type="string" required>
  示例的源代码。
</ParamField>

以下是一个植物追踪应用的代码示例，该应用同时提供 Bash CLI 工具和 JavaScript SDK。

```yaml
paths:
  /plants:
    get:
      # ...
      x-codeSamples:
        - lang: bash
          label: List all unwatered plants
          source: |
            planter list -u
        - lang: javascript
          label: List all unwatered plants
          source: |
            const planter = require('planter');
            planter.list({ unwatered: true });
        - lang: bash
          label: List all potted plants
          source: |
            planter list -p
        - lang: javascript
          label: List all potted plants
          source: |
            const planter = require('planter');
            planter.list({ potted: true });
```
