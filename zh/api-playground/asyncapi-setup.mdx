<div id="add-an-asyncapi-specification-file">
  ## 添加 AsyncAPI 规范文件
</div>

要为你的 WebSocket 创建页面，必须有一个有效的 AsyncAPI 规范文档，使用 JSON 或 YAML 格式，并遵循 [AsyncAPI 3.0 规范](https://www.asyncapi.com/docs/reference/specification/v3.0.0)。

<Tip>
  使用 [AsyncAPI Studio](https://studio.asyncapi.com/) 来验证你的 AsyncAPI 规范。
</Tip>

```json {3}
/your-project
  |- docs.json
  |- asyncapi.json
```

<div id="auto-populate-websockets-pages">
  ## 自动生成 websockets 页面
</div>

要为 AsyncAPI 规范中的所有 channel 自动生成页面，请在任意导航项中添加一个 `asyncapi` 属性。`asyncapi` 属性可以接受文档仓库中 AsyncAPI 规范文档的路径、托管的 AsyncAPI 文档的 URL，或指向多个 AsyncAPI 规范文档的链接数组。

<div id="examples-with-tabs">
  ### 使用选项卡的示例
</div>

<CodeGroup>
  ```json 本地文件
  "navigation": {
    "tabs": [
      {
          "tab": "API Reference",
          "asyncapi": "/path/to/asyncapi.json"
      }
    ]
  }

  ```

  ```json 远程 URL
  "navigation": {
    "tabs": [
      {
          "tab": "API Reference",
          "asyncapi": "https://github.com/asyncapi/spec/blob/master/examples/simple-asyncapi.yml"
      }
    ]
  }
  ```

  ```json 多个文件
  "navigation": {
    "tabs": [
      {
        "tab": "API Reference",
        "asyncapi": [
          "/path/to/events.json",
          "/path/to/webhooks.json"
        ]
      }
    ]
  }
  ```
</CodeGroup>

<Note>
  当你指定多个 AsyncAPI 文件时，每个文件都会生成自己的一组通道页面。
</Note>

<div id="examples-with-groups">
  ### 包含分组的示例
</div>

```json
"navigation": {
  "tabs": [
    {
      "tab": "AsyncAPI",
      "groups": [
        {
          "group": "Websockets",
          "asyncapi": {
            "source": "/path/to/asyncapi.json",
            "directory": "websockets"
          }
        }
      ]
    }
  ]
}
```

<Note>
  `directory` 字段为可选项。如果未指定，文件将被放在文档仓库的 **api-reference** 文件夹中。
</Note>

<div id="channel-page">
  ## Channel 页面
</div>

如果你想更灵活地控制频道的排序方式，或者只想引用特定频道，请创建一个在 frontmatter 中带有 `asyncapi` 属性的 MDX 文件。

```mdx
---
title: "Websocket Channel"
asyncapi: "/path/to/asyncapi.json channelName"
---
```
