<Note>
  反向代理配置仅支持 [Enterprise plans](https://mintlify.com/pricing?ref=reverse-proxy)。
</Note>

要通过自定义反向代理提供文档服务，你必须配置路由规则、缓存策略和请求头转发。

实施反向代理时，请留意域名验证、SSL 证书签发、身份验证流程、性能和分析跟踪方面的潜在问题。

<div id="choose-your-deployment-approach">
  ## 选择部署方式
</div>

Mintlify 会根据你的子路径需求，支持两种反向代理配置。

* **Host at `/docs`**：使用 `mintlify.dev` 作为代理目标。在 dashboard 的 [自定义域名设置](https://dashboard.mintlify.com/settings/deployment/custom-domain) 页面中，启用 **Host at `/docs`** 开关。这种配置更简单，需要设置的路由也更少。
* **自定义子路径**：使用 `mintlify.app` 作为代理目标。这种方式支持任意子路径，但需要额外的路由规则。

<div id="host-at-docs-subpath">
  ## Host at `/docs` 子路径
</div>

如果你想在自己的域名下通过 `/docs` 路径提供文档，请使用此配置。

在配置反向代理之前：

1. 在你的 dashboard 中，前往 [自定义域名设置](https://dashboard.mintlify.com/settings/deployment/custom-domain)。
2. 打开 **Host at `/docs`** 开关。
3. 输入你的域名，然后选择 **Add domain**。

<Warning>
  启用 **Host at `/docs`** 后，你的文档规范 URL 会变为 `<your-subdomain>.mintlify.dev`。`mintlify.app` 上将不再进行缓存失效，因此你必须反向代理到 `mintlify.dev`，更新才会生效。
</Warning>

<div id="routing-configuration">
  ### 路由配置
</div>

将以下路径代理到你的 Mintlify 子域名：

| 路径                           | 目标地址                                 | 缓存  |
| ---------------------------- | ------------------------------------ | --- |
| `/docs`                      | `<your-subdomain>.mintlify.dev/docs` | 不缓存 |
| `/docs/*`                    | `<your-subdomain>.mintlify.dev/docs` | 不缓存 |
| `/.well-known/vercel/*`      | `<your-subdomain>.mintlify.dev`      | 不缓存 |
| `/.well-known/skills/*` (可选) | `<your-subdomain>.mintlify.dev/docs` | 不缓存 |
| `/skill.md` (可选)             | `<your-subdomain>.mintlify.dev/docs` | 不缓存 |

`/.well-known/skills/*` 和 `/skill.md` 路由是可选的。只有当你想在根路径 (如 `your-domain.com/skills.md`) 提供 AI skills 文件，而不是放在文档子路径下 (如 `your-domain.com/docs/skills.md`) 时，才需要包含它们。

<div id="required-header-configuration">
  ### 必需的请求头配置
</div>

请按以下请求头要求配置反向代理：

* **Origin**：包含目标子域 `<your-subdomain>.mintlify.dev`
* **X-Forwarded-For**：保留客户端 IP 信息
* **X-Forwarded-Proto**：保留原始协议 (http/https) 
* **X-Real-IP**：转发客户端的真实 IP 地址
* **User-Agent**：转发用户代理

<Warning>
  确保不要转发 `Host` 请求头。
</Warning>

<div id="example-nginx-configuration">
  ### nginx 配置示例
</div>

```nginx
server {
    listen 80;
    server_name <your-domain>.com;

    # Vercel 验证路径
    location ~ ^/\.well-known/vercel/ {
        proxy_pass https://<your-subdomain>.mintlify.dev;
        proxy_set_header Origin <your-subdomain>.mintlify.dev;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }

    # AI 技能路径
    location ^~ /.well-known/skills/ {
        proxy_pass https://<your-subdomain>.mintlify.dev/docs;
        proxy_set_header Origin <your-subdomain>.mintlify.dev;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }

    # 技能清单（可选）
    location = /skill.md {
        proxy_pass https://<your-subdomain>.mintlify.dev/docs;
        proxy_set_header Origin <your-subdomain>.mintlify.dev;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }

    # 文档根路径
    location = /docs {
        proxy_pass https://<your-subdomain>.mintlify.dev/docs;
        proxy_set_header Origin <your-subdomain>.mintlify.dev;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }

    # 所有文档路径
    location /docs/ {
        proxy_pass https://<your-subdomain>.mintlify.dev/docs/;
        proxy_set_header Origin <your-subdomain>.mintlify.dev;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }
}
```


<div id="custom-subpath">
  ## 自定义子路径
</div>

如果你需要使用 `/docs` 以外的子路径 (例如 `/help` 或 `/resources`) ，请使用以下路由配置。

按照指定的缓存策略，将这些路径代理到你的 Mintlify 子域名：

| 路径                                | 目标地址                            | 缓存   |
| --------------------------------- | ------------------------------- | ---- |
| `/.well-known/vercel/*`           | `<your-subdomain>.mintlify.app` | 不缓存  |
| `/.well-known/skills/*`           | `<your-subdomain>.mintlify.app` | 不缓存  |
| `/skill.md`                       | `<your-subdomain>.mintlify.app` | 不缓存  |
| `/mintlify-assets/_next/static/*` | `<your-subdomain>.mintlify.app` | 启用缓存 |
| `/_mintlify/*`                    | `<your-subdomain>.mintlify.app` | 不缓存  |
| `/*`                              | `<your-subdomain>.mintlify.app` | 不缓存  |
| `/`                               | `<your-subdomain>.mintlify.app` | 不缓存  |

<div id="required-header-configuration">
  ### 必需的请求头配置
</div>

按以下要求配置你的反向代理请求头：

* **Origin**：包含目标子域 `<your-subdomain>.mintlify.app`
* **X-Forwarded-For**：保留客户端 IP 信息
* **X-Forwarded-Proto**：保留原始协议 (HTTP/HTTPS) 
* **X-Real-IP**：转发客户端的真实 IP 地址
* **User-Agent**：转发用户代理

<Warning>
  确保不要转发 `Host` 请求头
</Warning>

<div id="example-nginx-configuration">
  ### nginx 配置示例
</div>

```nginx
server {
    listen 80;
    server_name <your-domain>.com;

    # Vercel 验证路径
    location ~ ^/\.well-known/vercel/ {
        proxy_pass https://<your-subdomain>.mintlify.app;
        proxy_set_header Origin <your-subdomain>.mintlify.app;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        # 禁用验证路径的缓存
        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }

    # AI 技能路径
    location ^~ /.well-known/skills/ {
        proxy_pass https://<your-subdomain>.mintlify.app;
        proxy_set_header Origin <your-subdomain>.mintlify.app;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        # 禁用验证路径的缓存
        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }

    # 技能清单
    location = /skill.md {
        proxy_pass https://<your-subdomain>.mintlify.app;
        proxy_set_header Origin <your-subdomain>.mintlify.app;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        # 禁用技能清单的缓存
        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }

    # 启用缓存的静态资源
    location ~ ^/mintlify-assets/_next/static/ {
        proxy_pass https://<your-subdomain>.mintlify.app;
        proxy_set_header Origin <your-subdomain>.mintlify.app;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        # 为静态资源启用缓存
        add_header Cache-Control "public, max-age=86400";
    }

    # Mintlify 专属路径
    location ~ ^/_mintlify/ {
        proxy_pass https://<your-subdomain>.mintlify.app;
        proxy_set_header Origin <your-subdomain>.mintlify.app;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        # 禁用 Mintlify 路径的缓存
        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }

    # 根路径
    location = / {
        proxy_pass https://<your-subdomain>.mintlify.app;
        proxy_set_header Origin <your-subdomain>.mintlify.app;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        # 禁用动态内容的缓存
        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }

    # 其他所有文档路径
    location / {
        proxy_pass https://<your-subdomain>.mintlify.app;
        proxy_set_header Origin <your-subdomain>.mintlify.app;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        # 禁用动态内容的缓存
        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }
}
```


<div id="troubleshooting">
  ## 故障排查
</div>

<div id="changes-not-appearing">
  ### 更改未生效
</div>

**症状**：你发布了文档更新，但这些更改没有显示在你的网站上。

**原因**：你在 dashboard 中启用了 **Host at `/docs`**，但你的反向代理指向了 `mintlify.app`，而不是 `mintlify.dev`。

**解决方案**：更新反向代理配置，将其指向 `<your-subdomain>.mintlify.dev`，而不是 `<your-subdomain>.mintlify.app`。

<div id="404-error">
  ### 404 错误
</div>

**症状**：文档可以正常加载，但相关功能无法使用。API 调用失败。

**原因**：反向代理转发了 `Host` 请求头，或者未包含 `Origin` 请求头。

**解决方案**：

* 取消转发 `Host` 请求头
* 将 `Origin` 请求头设置为你的 Mintlify 子域名 (如果使用 `/docs` 子路径，则设为 `mintlify.dev`；如果使用其他子路径，则设为 `mintlify.app`)

<div id="performance-issues">
  ### 性能问题
</div>

**症状**：页面加载缓慢和布局偏移。

**原因**：缓存配置不当。

**解决方案**：如果使用自定义子路径配置，只对 `/mintlify-assets/_next/static/*` 路径启用缓存。`/docs` 子路径配置会自动处理缓存。
