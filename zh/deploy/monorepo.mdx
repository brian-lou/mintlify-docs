---
title: "Monorepo 设置"
description: "为 Monorepo 项目配置文档路径和内容目录。"
keywords: ["Monorepo", "内容目录", "多项目仓库"]
---

配置 Mintlify，使其从 Monorepo 中的特定目录部署文档。通过这种设置，你可以在包含多个项目或服务的代码仓库中，将文档与代码一并维护。

<div id="prerequisites">
  ## 先决条件
</div>

* 拥有你的 Mintlify 项目的管理员权限。
* 在 monorepo 中使用专用目录来组织文档文件。
* 文档目录中有一个有效的 `docs.json`。

<div id="configure-monorepo-deployment">
  ## 配置 monorepo 部署
</div>

<Steps>
  <Step title="访问 Git 设置">
    在 dashboard 中前往 [Git Settings](https://dashboard.mintlify.com/settings/deployment/git-settings)。

    <Frame>
      <img className="block dark:hidden my-0 pointer-events-none" src="/images/monorepo-light.png" alt="Git Settings 菜单中的项目设置面板。“Set up as monorepo”开关已启用，并已指定指向 /docs 目录的路径。" />

      <img className="hidden dark:block my-0 pointer-events-none" src="/images/monorepo-dark.png" alt="Git Settings 菜单中的项目设置面板。“Set up as monorepo”开关已启用，并已指定指向 /docs 目录的路径。" />
    </Frame>
  </Step>

  <Step title="设置文档路径">
    1. 打开 **Set up as monorepo** 开关。
    2. 输入 docs 目录的相对路径。例如，如果你的文档位于 `docs` 目录，请输入 `/docs`。

    <Note>
      路径末尾不要加斜杠。
    </Note>

    3. 选择 **Save changes**。
  </Step>
</Steps>
