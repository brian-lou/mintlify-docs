如果你的文档站点在加载几秒后出现 500 错误，或导航变得缓慢，可能是 Cloudflare 的防火墙阻止了对 Mintlify 静态资源的请求。

<div id="symptoms">
  ## 症状
</div>

- 文档页面起初可以加载，但在 30–60 秒后失败并返回 500 错误
- 页面之间的前端导航缓慢或失效
- 针对 `/mintlify-assets/*` 路径的请求在浏览器控制台中出现 403 错误
- Cloudflare 安全质询提示“数据格式错误”或“可疑的 URL 模式”

<div id="root-cause">
  ## 根本原因
</div>

Cloudflare 的 Web 应用防火墙（WAF）和 Bot Fight Mode 可能会因以下原因将 Mintlify 资源请求标记为可疑：

- URL 编码参数中包含多个 `%` 符号
- 查询字符串较长且包含特殊字符
- 来自空闲标签页的自动请求

<div id="solution">
  ## 解决方案
</div>

创建一个 Cloudflare 防火墙规则，将 Mintlify 资源排除在安全检查之外。

<div id="create-the-firewall-exception">
  ### 创建防火墙例外规则
</div>

1. 登录你的 [Cloudflare 仪表板](https://dash.cloudflare.com/)
2. 选择你的域名
3. 导航到 **Security > WAF**
4. 选择 **Create rule**
5. 按以下设置配置规则：

**Rule name：** Allow Mintlify assets

**When incoming requests match：**

- Field：`Hostname`
- Operator：`equals`
- Value：`docs.yourdomain.com`（替换为你实际的文档域名）

**And：**

- Field：`URI Path`
- Operator：`starts with`
- Value：`/mintlify-assets/`

**Then：**

- Action：`Skip`
- Select：`All remaining custom rules`、`Managed rules` 和 `Super Bot Fight Mode`

6. 启用 **Log** 以跟踪匹配的请求
7. 选择 **Deploy**

<div id="verify-the-rule">
  ### 验证规则
</div>

部署完成后：

1. 在浏览器中打开你的文档站点
2. 让页面保持空闲 2-3 分钟
3. 在页面之间来回切换
4. 检查浏览器控制台中是否出现任何 403 错误

如果问题仍然存在，请核实你的规则配置：

- 确保主机名与文档站点的域名完全匹配
- 确认 URI 路径使用 `starts with`（而不是 `contains`）
- 不要在路径值中包含通配符（`*`）
- 确认规则已启用并已部署

<div id="common-mistakes">
  ## 常见错误
</div>

- 将 `contains` 运算符用于 `/mintlify-assets/*` - 其中的 `*` 会被视为普通字符，而不是通配符
- 对 URI Path 使用 `equals` - 这只会匹配精确路径 `/mintlify-assets/`，而不会匹配其子路径
- 忘记跳过 Bot Fight Mode - 必须在跳过操作中显式将其包含在内
- 主机名错误 - 必须与你实际的文档站点域名完全一致

<div id="additional-troubleshooting">
  ## 其他故障排查
</div>

如果防火墙例外规则仍未解决问题：

1. 在 Cloudflare 的 **Security > Events** 日志中检查被拦截的请求
2. 确认你的 Cloudflare Worker（如果使用自定义子路径）正确转发了 `Host` 请求头
3. 暂时将 Security Level 设置为 "Essentially Off"，以确认问题是否确实由 Cloudflare 引起
4. 检查是否有自定义 Page Rules 覆盖了该防火墙例外规则

<div id="example-working-configuration">
  ## 工作配置示例
</div>

```
Rule: Allow Mintlify assets
Status: Enabled

When incoming requests match:
  (http.host eq "docs.flashnet.xyz" and starts_with(http.request.uri.path, "/mintlify-assets/"))

Then:
  Skip: All remaining custom rules, Managed rules, Super Bot Fight Mode
  Log: Enabled
```
