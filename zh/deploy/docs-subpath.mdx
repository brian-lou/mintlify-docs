将文档托管在类似 `your-domain.com/docs` 的子路径下，即可将文档保留在主域名上，让用户更容易找到，同时保持统一的品牌体验。

<div id="set-up-by-hosting-provider">
  ## 按托管服务提供商设置
</div>

设置 `/docs` 子路径的方式因托管服务提供商而异。请选择你的托管服务提供商，并按照相应的设置说明操作。

* [Cloudflare](/zh/deploy/cloudflare)：为你的域名配置 Cloudflare Workers，在 `/docs` 子路径提供文档服务。
* [AWS Route 53 and CloudFront](/zh/deploy/route53-cloudfront)：使用 AWS、Route 53 DNS 和 CloudFront CDN，在 `/docs` 子路径部署文档。
* [Vercel](/zh/deploy/vercel#host-from-docs) - 使用 rewrites 将文档部署到 `/docs` 子路径。
* [Custom reverse proxy](/zh/deploy/reverse-proxy) - 对于其他托管平台，请配置反向代理，将文档部署到 `/docs` 子路径。

<div id="additional-configuration-for-strict-security-policies">
  ### 严格安全策略的额外配置
</div>

如果你通过自定义域名代理所有流量，可能需要配置代理或防火墙规则，添加正确的[标头](/zh/deploy/csp-configuration)，以确保文档能够正常显示。
