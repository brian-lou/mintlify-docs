当你将更改推送到已连接的代码仓库时，文档站点会自动部署。这需要正确安装并连接 Mintlify GitHub 应用。

如果你的最新更改没有出现在线上站点上，首先检查拥有文档仓库的 GitHub 账号或组织是否已安装 GitHub 应用。更多信息请参见 [GitHub 故障排除](/zh/deploy/github#troubleshooting)。

如果已经安装了 GitHub 应用，但更改仍然没有被部署，可以在控制台中手动触发一次部署。

<div id="manually-trigger-a-deployment">
  ## 手动触发一次部署
</div>

<Steps>
  <Step title="确认你最近一次提交已成功。">
    检查你最近一次提交是否已出现在文档仓库中，并确认没有出现任何错误。
  </Step>

  <Step title="手动触发一次部署。">
    前往你的 [dashboard](https://dashboard.mintlify.com)，然后点击部署按钮。

      <img src="/images/deployments/manual-update-light.png" alt="用橙色矩形框突出显示的手动更新按钮。" className="block dark:hidden" />

    </Frame>
  </Step>
</Steps>

<div id="delete-a-deployment">
  ## 删除部署
</div>

你可以在仪表盘设置中的 [Danger zone](https://dashboard.mintlify.com/settings/organization/danger-zone) 永久删除某个部署。此操作不可撤销，并会删除所有部署数据，包括任何关联的预览部署。

<Steps>
  <Step title="导航到 Danger zone。">
    前往仪表盘设置页面中的 [Danger zone](https://dashboard.mintlify.com/settings/organization/danger-zone)。
  </Step>

  <Step title="删除部署。">
    1. 在 **Delete my deployment** 部分中，填写删除原因。
    2. 点击删除按钮，并确认要删除该部署。
  </Step>
</Steps>

<Warning>
  删除部署是永久性的，且无法撤销。如果你有有效的订阅，你将会获得当前计费周期内未用时间的按比例抵扣。
</Warning>

如果你有多个部署，删除之后你会被重定向到另一个部署。如果你删除的是唯一的部署，你会被重定向到 Mintlify 首页。当你删除部署时，组织管理员会收到一封确认删除的电子邮件通知。
