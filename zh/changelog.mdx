<Update label="2026年2月6日" tags={["新版本发布", "改进"]} rss={{ title: "自助配置 SSO、查看者角色、真人/AI 流量切换，以及斜杠命令菜单改版" }}>
  ## 自助配置 SSO

  企业客户现在可以直接在控制台中配置 SAML SSO (Okta 或 Microsoft Entra) ，包括即时 (JIT) 预配、身份提供商切换和移除连接。

  ## 查看者角色

  新增查看者角色，对你的控制台拥有只读访问权限。查看者可以查看编辑器中的内容，但无法编辑内容、邀请成员或修改配置。

  ## 真人/AI 流量切换

  分析页面现在会分别显示真人流量和 AI 流量的标签页。

  ## 斜杠命令菜单改版

  编辑器中的斜杠命令菜单现已支持输入搜索、改进的键盘导航以及其他 UX 优化。

  ## 问题修复

  * 修复了控制台表格中单元格内容溢出的问题。
  * 现在通过编辑器中的配置面板重命名文件时，可以正确保存更改。
  * MDX 解析错误 (例如未闭合的 `<Card>` 标签) 现在会随着你修复而动态更新，而不会在重新加载后仍错误保留。
  * 编辑器中的拖放手柄现在可针对标题或段落等不同内容类型正确对齐，并具有一致的尺寸和更好的点击区域。
</Update>

  ## 问题修复

  * 修复了可能导致 Tabs 组件出现性能问题的渲染循环。

  * 打印页面时不再显示 AI 助手。
  * 修复了深色模式下光标不可见的问题。
  * 修复了一个可能移除 MDX 中 style 属性的 bug。
  * 修复了一个在全局配置更改期间页面“上次修改”日期更新不正确的问题。
  * 修复了影响索引页面正确渲染的身份验证问题。
  * 现在在入门流程中，如果 GitHub 宕机，会正确显示 GitHub 状态。

<Update label="2026年1月23日" tags={["新发布", "改进"]} rss={{ title: "skill.md、审计日志和 Markdown 导出" }}>
  ## `skill.md` 自动生成

  文档站点现在会根据你的 API 参考文档、指南和功能自动生成一个 `skill.md` 文件，为 AI 代理提供一份包含完整上下文的技能文件，帮助它们协助用户使用你的产品。相比 `install.md` 方案，`skill.md` 采用了更结构化的能力定义，适用范围也更广。如果你在文档仓库根目录中有自定义的 `skills.md` 文件，则会覆盖自动生成的版本。更多信息，请参阅 [skill.md](/zh/ai/skillmd)。

  ## 身份验证事件的审计日志

  这些事件现已记录到 [审计日志](/zh/dashboard/audit-logs) 中，以提高可见性并满足合规要求。

  ## 面向代理的 Markdown 导出

  现在，当发送 `Accept: text/markdown` 请求头时，文档页面会返回原始 Markdown，便于 AI 代理更好地读取和使用内容。

  ## 改进

  * 将完整身份验证、部分身份验证和个性化整合为统一的身份验证体验。更多信息，请参阅 [身份验证设置](/zh/deploy/authentication-setup)。
  * 隐藏页面现在会自动添加 `noindex` meta 标签，以便更好地控制 SEO。
  * 新增对图片说明的 Markdown 支持。
</Update>

  新增 CLI 命令，可在部署前于本地验证文档构建。运行 `mint validate` 可尽早发现配置和构建错误。

  ## 助手消息层级

  用户现在可以在仪表板中选择每月助手消息额度的层级。

  ## 问题修复

  * 修复了 API 参考文档基础路径的问题。
  * 使用新的配色方案更新了 callout 颜色。
  * 修复了在编辑器中上传图片后首次加载时不显示的问题。
  * 修复了卡片链接中的代码样式问题。
  * 修复了 `.md` 文件错误覆盖 `.mdx` 文件的问题。

<Update label="2026年1月9日" tags={["新发布", "改进"]} rss={{ title: "面向所有用户的隐式片段和助手对话洞察" }}>
  ## 隐式片段

  片段现在无需显式配置即可使用。此前，你需要在特定的 `/snippets` 目录中定义片段。现在，你可以将文档中任意位置的任何文件作为片段导入，从而更灵活地复用内容。更多信息，请参阅 [可复用片段](/zh/create/reusable-snippets)。

  ## 面向所有用户的助手建议

  对于同时启用了代理和助手的所有文档站点，[对话洞察](/zh/agent/suggestions#conversation-insights) 现已可用。代理会分析助手对话中的模式，以识别文档缺口并提出改进建议，帮助你主动解决用户的常见问题。

  ## 标签页和代码组同步

  标签页和代码组现在会在整个页面中同步所选内容。当你在一个组件中选择某个标签页时，所有其他标签相同的标签页组件都会同步更新为相同的选择。这能让整页中的语言或框架选择保持一致。

  ## 改进

  * **标签页底部边框**：为标签页新增可选的底部边框样式。
  * **Mermaid 控件**：为 [Mermaid 图表](/zh/components/mermaid-diagrams) 新增交互式控件，以便浏览大型图表。
  * **用于搜索和助手的 URL 参数**：可使用 `?search=` 预填充搜索模态框后打开页面，或使用 `?assistant=` 打开助手。支持用户 query 参数，便于直接链接和分享知识。
  * **个人资料姓名编辑**：用户现在可以在个人资料设置中编辑名字和姓氏。
</Update>

  * **配置选项**：无需手动编辑 `docs.json`，即可在编辑器中调整所有站点配置选项。
  * **拖放资源**：将图片和文件直接从电脑拖入文件树即可上传。

  ## 移动端导航改进

  * 在移动端导航中添加了主题切换器，便于切换浅色/深色模式。

  ## 问题修复

  * 修复了 API 操作台中某些端点缺少请求示例的问题。
  * 修复了在 API 操作台中使用预填充示例时，MDX 示例无法正确显示的问题。
  * 修复了助手中的链接会在新窗口而不是当前窗口中打开的问题。
  * 修复了助手响应中的 Markdown 链接渲染问题。
  * 修复了标题 slug 对特殊字符的处理问题。

<Update label="2025年12月12日" tags={["新发布", "改进"]} rss={{  title: "代理建议和问答机器人" }}>
  ## 代理建议

  代理现在可以监控 Git 仓库，并[建议](/zh/agent/suggestions)更新文档。检测到面向用户的代码变更时，建议会显示在代理面板中。建议内容包括相关的拉取请求，以及建议更新的文档列表。你可以将这些建议添加为上下文，让代理创建拉取请求，也可以将其忽略。

  ## Slack 和 Discord 中的问答机器人

  将由助手驱动的机器人添加到你的 [Slack 工作区](/zh/ai/slack-bot) 和 [Discord 服务器](/zh/ai/discord) 中。这些机器人会基于你的文档实时回答问题，因此能为你的社区提供准确且最新的答案。

  这些机器人会响应 `@` 提及，以及名称为 `#ask-ai` 的频道中的所有消息。

  ## 片段现已支持相对导入

  你现在可以在 MDX 文件中导入片段时使用相对路径。此前，导入必须使用以 `/snippets/` 开头的绝对路径。现在你可以使用如 `../snippets/example.mdx` 这样的相对路径，从而更灵活地组织文件。

  ## 改进

  * 仪表板中的 **Insights** 已更名为 **Analytics**。
  * 新增了从仪表板删除部署的功能。
  * `Tooltip` 组件已重新设计，样式得到改进，现在还支持可选的 `headline` prop，用于为工具提示添加标题。
  * `mint a11y` 命令现在支持 `--skip-contrast` 和 `--skip-alt-text` 标志，让你可以在 CI/CD 流水线中运行特定的无障碍检查。使用 `--skip-contrast` 可仅检查缺失的 alt 文本，使用 `--skip-alt-text` 可仅检查颜色对比度比率。

  ## 问题修复

  * 修复了标签页内的链接无法正常工作的问题。
  * 修复了 web editor 中 5 级和 6 级标题的渲染问题。
  * 修复了 API 参考页面中 schema 页面示例的显示问题。
  * 修复了 monorepo 设置中的图片上传路径问题。
  * 修复了 API 操作台中默认优先选中了错误请求负载值的问题。
  * 上传时，默认图片标题不再包含文件扩展名。
  * 修复了横幅链接上的双下划线样式问题。
  * 修复了 analytics 页面的加载状态和日期范围值问题。
  * web editor 中的文件夹现在会在打开或关闭其他文件夹时，正确保持其展开/折叠状态。
  * 修复了较长的 API 页面标题溢出而不换行的问题。
</Update>

  ## 最后修改日期

  你现在可以在文档中的所有页面上显示“最后修改”时间戳。通过在 `docs.json` 设置中启用 [`timestamp`](/zh/organize/settings#param-timestamp) 标志即可开启此功能。

  启用后，每个页面都会自动显示其最后更新时间，帮助读者了解内容是否为最新。
</Update>
