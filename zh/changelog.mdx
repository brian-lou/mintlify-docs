<Update label="2026 年 2 月 6 日" tags={["新版本", "改进"]} rss={{ title: "自助式 SSO、查看者角色、人类/AI 流量切换，以及斜杠命令重设计" }}>
  ## 自助式 SSO 配置

  企业客户现在可以直接在仪表盘中配置 SAML SSO（Okta 或 Microsoft Entra），包括即时（JIT）开通、身份提供商切换以及移除连接。

  ## 查看者角色

  新增仅具只读访问权限的查看者角色。查看者可以在编辑器中查看内容，但无法编辑内容、邀请成员或修改配置。

  ## 人类/AI 流量切换

  分析页面现在分别展示人类与 AI 流量的独立标签页。

  ## 斜杠命令菜单重设计

  编辑器斜杠菜单现在支持输入即搜、改进的键盘导航以及其他用户体验优化。

  ## Bug 修复

  * 修复了仪表盘表格中单元格内容溢出的问题。
  * 通过编辑器中的配置表单重命名文件现在可以正确保存更改。
  * MDX 解析错误（例如未关闭的 `<Card>` 标签）现在会在你修复时动态更新，而不会在重新加载后错误地持续存在。
  * 编辑器中的拖放手柄现在可以与不同内容类型（如标题或段落）正确对齐，尺寸更一致，点击区域也更易于操作。
</Update>

<Update label="2026 年 1 月 30 日" tags={["新版本", "改进"]} rss={{ title: "简化的技能安装、焕新的分析页面、编辑器改进等" }}>
  ## 技能安装更简单

  现在只需使用一个文档 URL 即可安装 [skill.md 文件](/zh/ai/skillmd)，无需再提供 `skill.md` 文件路径。

  ```bash
  npx skills add mintlify.com/docs
  ```

  ## 焕新的分析页面

  改进了在各个 [分析](optimize/analytics) 标签页之间的导航，提供更具可操作性的洞察和更好的数据可视化。

  ## 编辑器改进

  * 图标支持编辑
  * 为 Cards、Accordions 和 Steps 组件提供所见即所得的标题和描述编辑
  * 可在导航中隐藏或重新显示页面
  * 实时预览中支持本地图片
  * 使用 <code>```</code> 触发代码块
  * 更精准的拖拽手柄选取
  * 稳定性改进

  ## 更新后的助手页面

  在单一页面中管理所有 [助手功能](/zh/ai/assistant)，布局更简洁、体验更佳。

  ## MCP 过滤

  AI 代理现在可以通过参数来 [过滤](ai/model-context-protocol#search-filtering-parameters) MCP 搜索结果。

  ## 其他

  * 在[上下文菜单](/zh/ai/contextual-menu)中支持 &quot;Open in Grok&quot;
  * 在[上手流程](deploy/github#alternative%3A-download-and-create-your-own-repository)中支持 Zip 文件上传

  ## Bug 修复

  * 修复了缓存问题，该问题会导致在页面间导航时侧边栏显示错误的展开/折叠状态。
  * 解决了自定义页面上的滚动位置问题，使内容可以正确显示。
  * 修复了在同一页面上出现多个 Mermaid 图表时的冲突。
  * 修复了可能导致 Tabs 组件出现性能问题的渲染循环。
  * 修复了密码重置按钮无法工作的问题。
  * 现在打印页面时不会再显示 AI 助手。
  * 修复了光标在深色模式下不可见的问题。
  * 修复了可能会移除 MDX 中样式属性的 Bug。
  * 修复了在进行全局配置更改时页面“最后修改”日期错误更新的问题。
  * 修复了影响索引页面正确渲染的身份验证问题。
  * 如果 GitHub 宕机，在上手流程中现在可以正确显示 GitHub 状态。
</Update>

<Update label="2026 年 1 月 23 日" tags={["新版本发布", "功能改进"]} rss={{ title: "skills.md、审计日志和 markdown 导出" }}>
  ## `skill.md` 自动生成

  文档站点现在会基于你的 API 参考文档、指南和功能说明自动生成一个 `skill.md` 文件，为 AI 代理提供一份完整的技能文件，其中包含帮助用户使用你产品所需的上下文信息。`skill.md` 以更结构化的能力和更广泛的适用场景取代了原先的 `install.md` 方案。如果你在文档仓库根目录自定义了 `skills.md` 文件，它会覆盖自动生成的版本。更多信息参见 [skill.md](/zh/ai/skillmd)。

  ## 身份验证事件的审计日志

  身份验证相关事件现在会记录在 [审计日志](/zh/dashboard/audit-logs) 中，以便提升可见性并满足合规要求。

  ## 为代理提供 Markdown 导出

  当发送 `Accept: text/markdown` 请求头时，文档页面现在会返回原始 markdown，从而让 AI 代理能够更好地读取和处理这些内容。

  ## 改进

  * 将完整身份验证、部分身份验证和个性化合并为统一的身份验证体验。更多信息参见 [Authentication setup](/zh/deploy/authentication-setup)。
  * 隐藏页面现在会自动添加 `noindex` meta 标签，以便更好地控制 SEO。
  * 为图片说明添加了 markdown 支持。
</Update>

  ## 助手消息额度分级

  用户现在可以在控制台中选择每月不同档位的助手消息配额。

  ## Bug 修复

  * 使用全新的配色方案更新了提示组件颜色。

  * 修复了卡片链接中的代码样式问题。
  * 修复了 `.md` 文件错误覆盖 `.mdx` 文件的问题。

<Update label="2026 年 1 月 9 日" tags={["新版本发布", "功能改进"]} rss={{ title: "隐式代码片段和面向所有人的助手对话洞察" }}>
  ## 隐式代码片段

  代码片段现在无需显式配置即可使用。之前，你需要在特定的 `/snippets` 目录中定义代码片段。现在，你可以在文档中的任意位置将任意文件导入为代码片段，从而更灵活地复用内容。更多信息参见 [Reusable snippets](/zh/create/reusable-snippets)。

  ## 面向所有用户的助手建议

  现在，所有同时启用代理和助手的文档站点都可以使用 [对话洞察](/zh/agent/suggestions#conversation-insights)。代理会分析助手对话中的模式，识别文档中的缺口并提出改进建议，帮助你主动解决常见用户问题。

  ## 选项卡与代码分组同步

  选项卡和代码分组现在会在整页范围内同步选中状态。当你在一个组件中选择某个选项卡时，所有具有相同标签的其他选项卡组件都会更新为相同的选择。这可以在整页中保持语言或框架选择的一致性。

  ## 改进

  * **选项卡底部边框**：为选项卡新增可选的底部边框样式。
  * **Mermaid 控件**：为 [Mermaid diagrams](/zh/components/mermaid-diagrams) 提供交互式控件，以便导航大型图表。
  * **搜索和助手的 URL 参数**：通过 `?search=` 打开并预填搜索弹窗，或通过 `?assistant=` 打开助手。支持使用用户查询参数进行直接链接和知识分享。
  * **个人资料姓名编辑**：用户现在可以在个人资料设置中编辑自己的名和姓。
</Update>

<Update label="2025 年 12 月 12 日" tags={["新版本发布", "改进"]} rss={{  title: "Agent 建议和问答机器人" }}>
  ## Agent 建议

  Agent 现在可以监控 Git 仓库并[建议](/zh/agent/suggestions)文档更新。当检测到面向用户的代码更改时，建议会显示在 agent 面板中。建议包括相关的 pull request，以及一份建议的文档更新列表。你可以将这些建议添加为上下文，让 agent 创建 pull request，或将其忽略。

  ## Slack 和 Discord 中的问答机器人

  将由助手驱动的机器人添加到你的 [Slack 工作区](/zh/ai/slack-bot)和 [Discord 服务器](/zh/ai/discord)。机器人会基于你的文档实时回答问题，因此能为你的社区提供准确、最新的答案。

  机器人会响应 `@` 提及，以及所有在名为 `#ask-ai` 的频道中发送的消息。

  ## 代码片段现在支持相对导入

  你现在可以在 MDX 文件中导入代码片段时使用相对路径。之前，导入要求使用以 `/snippets/` 开头的绝对路径。现在你可以使用 `../snippets/example.mdx` 这样的相对路径，以实现更灵活的文件组织。

  ## 改进

  * 在仪表盘中将 **Insights** 重命名为 **Analytics**。
  * 在仪表盘中新增删除部署的功能。
  * 重新设计了 `Tooltip` 组件的样式，并新增了可选的 `headline` prop，用于为 tooltip 添加标题。
  * `mint a11y` 命令现在支持 `--skip-contrast` 和 `--skip-alt-text` 标志，允许你在 CI/CD 流水线中运行特定的无障碍检查。使用 `--skip-contrast` 仅检查是否缺少 alt 文本，或使用 `--skip-alt-text` 仅检查颜色对比度。

  ## Bug 修复

  * 修复了选项卡内链接无法正常工作的问题。
  * 修复了在 Web 编辑器中 5、6 级标题的渲染问题。
  * 修复了 API 参考页面中 schema 页示例的展示问题。
  * 修复了 monorepo 设置中图片上传路径的问题。
  * 修复了在 API playground 中错误的请求负载值会被优先选中的问题。
  * 上传图片时，从默认图片标题中移除了文件扩展名。
  * 修复了横幅链接出现双下划线样式的问题。
  * 修复了 Analytics 页面加载状态和日期范围数值的问题。
  * Web 编辑器中的文件夹现在能在其他文件夹打开或关闭时，正确保持它们的展开/收起状态。
  * 修复了较长 API 页面标题溢出而不是换行的问题。
</Update>

<Update label="2025 年 12 月 8 日" tags={["新版本发布"]} rss={{ title: "最后修改日期", description: "通过自动时间戳显示页面的最后更新时间" }}>
  ## 最后修改日期

  你现在可以在文档中的所有页面显示“最后修改”时间戳。通过在 `docs.json` 设置中启用 [`timestamp`](/zh/organize/settings#param-timestamp) 标志即可开启此功能。

  启用后，每个页面都会自动显示其最近一次的更新时间，帮助读者判断内容的时效性。
</Update>
