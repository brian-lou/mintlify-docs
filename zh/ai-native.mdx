当你在 Mintlify 上托管文档时，内置的 AI 功能可以帮助用户更快找到答案，也能让团队更高效地维护内容。你的内容为这些 AI 原生功能提供上下文，使其能够优化文档的阅读、创作和查找体验。

<div id="what-makes-your-documentation-ai-native">
  ## 如何让你的文档具备 AI 原生特性
</div>

<div id="reading">
  ### 阅读
</div>

除了逐页阅读文档之外，用户还可以在你的文档中与 [assistant](/zh/ai/assistant) 聊天，即时获得问题的解答和相关内容的链接。assistant 会基于你的文档中的准确信息，帮助引导用户了解你的产品。通过 [API](/zh/api/assistant/create-assistant-message) 将 assistant 嵌入到自定义应用中，让用户在更多场景中也能访问你的文档。

<div id="writing">
  ### 撰写
</div>

[agent](/zh/agent) 帮助你撰写和维护文档。它会根据你的提示、pull request 和 Slack 讨论串，创建包含建议更改的新 pull request。将 agent 添加到你的 Slack 工作区，这样你团队中的任何人都可以通过与 agent 对话来协助维护文档。也可以通过 [API](/zh/api/agent/create-agent-job) 将 agent 嵌入自定义应用中。

你可以配置 agent 监控已连接的代码仓库，在检测到面向用户的变更时主动[建议](/zh/agent/suggestions)更新文档。

配置 [Cursor](/zh/guides/cursor)、[Claude Code](/zh/guides/claude-code) 和 [Windsurf](/zh/guides/windsurf) 等常用工具，使其参考 Mintlify schema、你的文档风格指南和最佳实践。

<div id="discovering">
  ### 发现
</div>

你的网站会自动为 AI 工具和搜索引擎进行优化，帮助用户发现你的文档。所有页面都会将其内容以 Markdown 的形式发送给 AI 代理，而不是 HTML，这有助于这些工具更快速地处理你的内容并占用更少的 tokens。每个页面也都可以通过在 URL 末尾添加 `.md` 以 Markdown 形式查看。

Mintlify 为你的文档托管 `llms.txt` 和 `skill.md` 文件。这些行业标准文件帮助 LLMs 在响应用户查询时高效返回相关信息，并提供一个供代理调用的功能列表，从而让用户在使用你的产品时更顺利、更高效。

你的文档站点还托管了一个 MCP 服务器，使用户能够将你的文档直接连接到他们的 AI 工具中，在他们需要的地方直接获取有关你产品的最新信息。

全文搜索和语义理解帮助用户和 AI 工具快速找到相关信息。搜索能够理解用户意图，而不仅仅是匹配关键词。如果用户遇到 404 错误，你的网站会自动推荐相关页面，帮助他们找到自己想要的内容。无需任何配置。
