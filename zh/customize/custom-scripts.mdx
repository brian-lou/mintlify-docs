<div id="styling-with-tailwind-css">
  ## 使用 Tailwind CSS 设置样式
</div>

使用 Tailwind CSS v3 为 HTML 元素设置样式。你可以控制布局、间距、颜色及其他视觉属性。常用类包括：

* `w-full` - 全宽
* `aspect-video` - 16:9 宽高比
* `rounded-xl` - 大圆角
* `block`, `hidden` - 显示控制
* `dark:hidden`, `dark:block` - 深色模式下的显示状态

不支持 Tailwind CSS 的任意值。需要自定义值时，请改用 `style` prop。

```html
<img style={{ width: '350px', margin: '12px auto' }} src="/path/image.jpg" />
```

<Warning>
  使用 `style` prop 可能会导致页面在加载时出现布局偏移，尤其是在自定义模式页面中。请改用 Tailwind CSS 类或自定义 CSS 文件，以避免布局偏移或闪烁。
</Warning>


<div id="custom-css">
  ## 自定义 CSS
</div>

将 CSS 文件添加到你的代码仓库后，其中定义的类名就会自动生效，并可在所有 MDX 文件中使用。

<div id="adding-stylecss">
  ### 添加 `style.css`
</div>

例如，你可以添加以下 `style.css` 文件，自定义导航栏和页脚的样式。

```css
#navbar {
  background: #fffff2;
  padding: 1rem;
}

footer {
  margin-top: 2rem;
}
```

<div id="custom-javascript">
  ## 自定义 JavaScript
</div>

自定义 JS 可让你在全站范围内添加自定义的可执行代码。这相当于在每个页面中加入一个包含 JS 代码的 `<script>` 标签。

<div id="adding-custom-javascript">
  ### 添加自定义 JavaScript
</div>

文档内容目录中的任何 `.js` 文件都会包含在每个文档页面中。例如，你可以添加下面的 `ga.js` 文件，在整个文档站点中启用 [Google Analytics](https://marketingplatform.google.com/about/analytics)。

```js
window.dataLayer = window.dataLayer || [];
function gtag() {
  dataLayer.push(arguments);
}
gtag('js', new Date());

gtag('config', 'TAG_ID');
```

<Warning>
  请务必谨慎使用，以免引入安全漏洞。
</Warning>
