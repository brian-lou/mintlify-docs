所有 404 页面都会根据请求的 URL 自动推荐相关页面。如果用户访问了 404 页面，代理会分析该路径，并从你的文档中检索语义相关的页面，帮助他们找到所需内容。

你可以自定义 404 错误页面的标题和描述。你还可以在描述中添加实用链接或引导说明。

<div id="configuration">
  ## 配置
</div>

可在 `docs.json` 文件的 `errors.404` 部分配置 404 页面：

```json
"errors": {
  "404": {
    "redirect": false,
    "title": "I can't be found",
    "description": "What ever **happened** to this _page_?"
  }
}
```


<div id="parameters">
  ## 参数
</div>

<ResponseField name="redirect" type="boolean">
  页面未找到时，是否自动重定向到首页。

  设为 `true` 时，将重定向到首页。

  设为 `false` 时，将显示自定义 404 页面。
</ResponseField>

<ResponseField name="title" type="string">
  404 错误页面的自定义标题。这会替换默认的“Page not found”标题。
</ResponseField>

<ResponseField name="description" type="string">
  404 错误页面的自定义描述。支持 Markdown 格式。
</ResponseField>
