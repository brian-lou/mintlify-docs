要在自定义域名上托管文档，请按以下步骤操作：

1. 在控制面板中添加你的域名。
2. 在域名服务商处配置 DNS 设置。
3. 等待 DNS 传播，系统会自动签发 TLS 证书。

<Info>
  想设置类似 `example.com/docs` 的子路径？请参阅 [/docs 子路径](/zh/deploy/docs-subpath)。
</Info>

<div id="add-your-custom-domain">
  ## 添加自定义域名
</div>

1. 在控制面板中，前往[自定义域名设置](https://dashboard.mintlify.com/settings/deployment/custom-domain)页面。
2. 输入你的域名。例如：`docs.example.com` 或 `www.example.com`。
3. 点击 **Add domain**。

<div id="configure-your-dns">
  ## 配置 DNS
</div>

1. 在域名服务商的网站上，进入域名的 DNS 设置。
2. 使用以下值创建一条新的 DNS 记录：

```text
CNAME | docs | cname.mintlify-dns.com.
```

<Tip>
  不同的域名服务商添加 DNS 记录的方式各不相同。具体操作说明请参阅你的域名服务商文档。
</Tip>

<div id="dns-propagation">
  ### DNS 传播
</div>

DNS 更改通常需要 1–24 小时才能在全球范围内传播，但在某些情况下最多可能需要 48 小时。你可以使用 [DNSChecker](https://dnschecker.org) 验证 DNS 是否已正确配置。

DNS 记录生效后，你的文档最初可通过 HTTP 访问。Vercel 完成 TLS 证书签发后，即可使用 HTTPS。

<div id="automatic-tls-provisioning">
  ### 自动签发 TLS 证书
</div>

当你的 DNS 记录传播完成并正确解析后，Vercel 会通过 Let&#39;s Encrypt 自动为你的域名签发免费的 SSL/TLS 证书。

这通常会在 DNS 传播后的几小时内完成，但少数情况下可能需要长达 24 小时。证书会在到期前自动续期。

<div id="caa-records">
  ### CAA 记录
</div>

如果你的域名使用 CAA (证书颁发机构授权) 记录，则必须授权 Let&#39;s Encrypt 为该域名签发证书。请在 DNS 设置中添加以下 CAA 记录：

```text
0 issue "letsencrypt.org"
```

<div id="reserved-paths">
  ### 保留路径
</div>

`/.well-known/acme-challenge` 路径专用于证书验证，不能被重定向或重写。如果你已为此路径配置了重定向或重写，证书签发将失败。

<div id="provider-specific-settings">
  ### 特定提供商设置
</div>

<AccordionGroup>
  <Accordion title="Vercel 验证">
    如果 Vercel 是你的域名提供商，则必须添加一条用于验证的 `TXT` 记录。提交自定义域名后，这项信息会显示在你的控制面板中，并通过电子邮件发送给你。
  </Accordion>

  <Accordion title="Cloudflare 加密模式">
    如果 Cloudflare 是你的 DNS 提供商，则必须将 SSL/TLS 加密设置为“Full (strict)”模式。此外，请在 Edge Certificates 设置中禁用“Always Use HTTPS”。否则，在证书签发过程中，Cloudflare 的 HTTPS 重定向会阻止 Let&#39;s Encrypt 验证你的域名。
  </Accordion>
</AccordionGroup>

<div id="set-a-canonical-url">
  ## 设置规范 URL
</div>

配置 DNS 后，请设置规范 URL，以确保搜索引擎将你首选的域名编入索引。规范 URL 用于告知搜索引擎，哪个版本的文档是主要版本。当你的文档可通过多个 URL 访问时，这有助于提升 SEO 效果，并避免重复内容问题。

将 `canonical` 元标签添加到你的 `docs.json` 中：

```json
"seo": {
    "metatags": {
        "canonical": "https://www.your-custom-domain-here.com"
    }
}
```

将 `https://www.your-custom-domain-here.com` 替换为你实际使用的自定义域名。例如，如果你的自定义域名是 `docs.mintlify.com`，则应使用：

```json
"seo": {
    "metatags": {
        "canonical": "https://docs.mintlify.com"
    }
}
```
