要在自定义域名上托管你的文档：

1. 在控制台中添加你的域名。
2. 在域名服务商处配置 DNS 设置。
3. 等待 DNS 生效，并自动配置 TLS 证书。

<Info>
  想要设置类似 `example.com/docs` 的子路径？请参阅 [/docs 子路径](/zh/deploy/docs-subpath)。
</Info>

<div id="add-your-custom-domain">
  ## 添加自定义域名
</div>

1. 在仪表板中前往 [Custom domain setup](https://dashboard.mintlify.com/settings/deployment/custom-domain) 页面。
2. 输入你的域名，例如 `docs.example.com` 或 `www.example.com`。
3. 点击 **Add domain**。

<div id="configure-your-dns">
  ## 配置你的 DNS
</div>

1. 在你的域名服务商网站上，进入你的域名的 DNS 设置。
2. 使用以下值创建一条新的 DNS 记录：

```text
CNAME | docs | cname.mintlify-dns.com.
```

<Tip>
  各个域名服务商添加 DNS 记录的方式各不相同。请参阅你的域名服务商文档以了解具体操作说明。
</Tip>

<div id="dns-propagation">
  ### DNS 传播
</div>

DNS 更改通常会在 1–24 小时内于全球范围内生效，在某些情况下可能需要长达 48 小时。你可以使用 [DNSChecker](https://dnschecker.org) 检查你的 DNS 是否配置正确。

一旦你的 DNS 记录生效，你的文档将首先通过 HTTP 提供访问。在 Vercel 为你配置好 TLS 证书后，就可以通过 HTTPS 访问。

<div id="automatic-tls-provisioning">
  ### 自动 TLS 证书签发
</div>

一旦你的 DNS 记录完成传播并能被正确解析，Vercel 会通过 Let&#39;s Encrypt 为你的域名自动签发一个免费的 SSL/TLS 证书。

这一过程通常会在 DNS 记录生效后的数小时内完成，但在极少数情况下可能需要长达 24 小时。证书会在到期前自动续期。

<div id="caa-records">
  ### CAA 记录
</div>

如果你的域名使用了 CAA（Certification Authority Authorization，证书颁发机构授权）记录，则必须授权 Let&#39;s Encrypt 为你的域名签发证书。请在 DNS 设置中添加如下 CAA 记录：

```text
0 issue "letsencrypt.org"
```

<div id="reserved-paths">
  ### 保留路径
</div>

用于证书验证的 `/.well-known/acme-challenge` 路径是保留路径，不能进行重定向或重写。如果你为此路径配置了重定向或重写，证书签发将会失败。

<div id="provider-specific-settings">
  ### 特定服务商设置
</div>

<AccordionGroup>
  <Accordion title="Vercel 验证">
    如果 Vercel 是你的域名服务商，你必须添加一个用于验证的 `TXT` 记录。提交自定义域名后，相关信息会显示在你的控制面板上，并通过电子邮件发送给你。
  </Accordion>

  <Accordion title="Cloudflare 加密模式">
    如果 Cloudflare 是你的 DNS 服务商，你必须在 SSL/TLS 加密设置中启用“Full (strict)”模式。此外，在 Edge Certificates 设置中禁用“Always Use HTTPS”。Cloudflare 的 HTTPS 重定向会阻止 Let&#39;s Encrypt 在证书签发过程中验证你的域名。
  </Accordion>
</AccordionGroup>

<div id="set-a-canonical-url">
  ## 设置规范 URL
</div>

在配置 DNS 之后，设置一个规范 URL，以确保搜索引擎索引你首选的域名。规范 URL 会告诉搜索引擎你的文档哪个版本是主版本。当你的文档可以通过多个 URL 访问时，这有助于提升 SEO，并避免出现重复内容的问题。

将 `canonical` meta 标签添加到你的 `docs.json` 中：

```json
"seo": {
    "metatags": {
        "canonical": "https://www.your-custom-domain-here.com"
    }
}
```

将 `https://www.your-custom-domain-here.com` 替换为你的实际自定义域名。比如，如果你的自定义域名是 `docs.mintlify.com`，则应使用：

```json
"seo": {
    "metatags": {
        "canonical": "https://docs.mintlify.com"
    }
}
```
