完成本指南后，你将拥有一个已上线、可供自定义和更新的文档站点。

<div id="before-you-begin">
  ## 开始之前
</div>

Mintlify 使用 “docs-as-code” 的方式来管理你的文档。你的网站上的每个页面都有一个对应的文件，存储在你的文档<Tooltip tip="你的文档源代码，存储了所有文件及其历史记录。网页编辑器会连接到你的文档仓库以访问和修改内容，或者你也可以在本地使用偏好的 IDE 编辑文件。">repository</Tooltip> 中。

当你将文档仓库连接到你的项目时，你可以在本地或网页编辑器中编写文档，并将所有更改同步到远程仓库。

<div id="deploy-your-documentation-site">
  ## 部署文档站点
</div>

前往 [mintlify.com/start](https://mintlify.com/start) 并完成新手引导流程。在引导过程中，你会连接 GitHub 账号，为文档创建或选择一个代码仓库，并安装 GitHub App 以启用自动部署。

完成引导后，你的文档站点就会部署完毕，并可以通过 `.mintlify.app` URL 访问。

<AccordionGroup>
  <Accordion title="可选：在引导流程中跳过连接 GitHub">
    如果你希望在不连接自己代码仓库的情况下快速开始使用，可以在引导过程中跳过 GitHub 连接。Mintlify 会在一个私有组织中为你创建一个私有仓库，并自动为你配置 GitHub App。

    这样你就可以立即使用在线编辑器，并在之后迁移到你自己的代码仓库。
  </Accordion>
</AccordionGroup>

<div id="view-your-deployed-site">
  ## 查看你已部署的网站
</div>

你的文档站点现在已部署在 `https://<your-project-name>.mintlify.app`。

在[控制面板](https://dashboard.mintlify.com/)的 **Overview** 页面中找到具体的 URL。

  你的网站已可立即访问。使用此 URL 进行测试并与团队成员分享。在向用户正式公开之前，你可能希望先添加一个[自定义域名](/zh/customize/custom-domain)。
</Tip>

<div id="make-your-first-change">
  ## 完成你的首次修改
</div>

<Tabs>
  <Tab title="CLI">
    <Steps>
      <Step title="安装 CLI">
        CLI 需要 [Node.js](https://nodejs.org/en) v20.17.0 或更高版本。为保证稳定性，请使用 LTS 版本。

        <CodeGroup>
          ```bash npm
          npm i -g mint
          ```

          ```bash pnpm
          pnpm add -g mint
          ```
        </CodeGroup>

        有关完整安装步骤和故障排查，请参见 [安装 CLI](/zh/installation)。
      </Step>

      <Step title="克隆代码仓库">
        如果你还没有在本地克隆代码仓库，请按照 [克隆代码仓库](/zh/installation#clone-your-repository) 中的说明操作。
      </Step>

      <Step title="编辑页面">
        在你常用的编辑器中打开 `index.mdx`，并更新 frontmatter 中的描述：

        ```mdx
        ---
        title: "Introduction"
        description: "Your custom description here"
        ---
        ```
      </Step>

      <Step title="本地预览">
        在文档目录中运行以下命令：

        ```bash
        mint dev
        ```

        然后在浏览器中访问 `http://localhost:3000` 查看本地预览。
      </Step>

      <Step title="推送更改">
        提交并推送你的更改以触发部署：

        ```bash
        git add .
        git commit -m "Update description"
        git push
        ```

        Mintlify 会自动部署你的更改。你可以在控制台的 [Overview](https://dashboard.mintlify.com/) 页面查看部署状态。
      </Step>
    </Steps>
  </Tab>

  <Tab title="网页编辑器">
    <Steps>
      <Step title="打开网页编辑器">
        在控制台中前往 [网页编辑器](https://dashboard.mintlify.com/editor)。
      </Step>

      <Step title="编辑页面">
        打开 **Introduction** 页面并更新描述。

        <Frame>
          <img src="/images/quickstart/hello-world-light.png" alt="Introduction 页面在网页编辑器中打开，并且描述已编辑为 Hello world!。" className="block dark:hidden" />

          <img src="/images/quickstart/hello-world-dark.png" alt="Introduction 页面在网页编辑器中打开，并且描述已编辑为 Hello world!。" className="hidden dark:block" />
        </Frame>
      </Step>

      <Step title="发布">
        点击网页编辑器工具栏右上角的 **Publish** 按钮。
      </Step>

      <Step title="查看线上效果">
        在控制台的 [Overview](https://dashboard.mintlify.com/) 页面，你可以看到站点的部署状态。部署完成后，刷新你的文档站点即可看到最新更改。
      </Step>
    </Steps>
  </Tab>
</Tabs>
