<Info>
  任何有权访问你的控制面板的用户，都可以在 [Pro 和 Enterprise 方案](https://mintlify.com/pricing?ref=agent) 中使用代理。
</Info>

代理会根据你的提示，为你的文档生成包含建议修改的拉取请求。当你向代理发送请求时，它会结合你的文档、已连接的代码仓库和 Slack 消息，生成遵循技术写作最佳实践且符合 Mintlify schema 的内容。

<div id="what-you-can-do-with-the-agent">
  ## 你可以用代理做什么
</div>

使用代理可以：

* 根据你的提示、拉取请求链接或 Slack 线程撰写新内容。
* 修订过时的代码示例和 API 参考资料。
* 搜索并更新现有内容。
* 回答有关你的文档和技术写作的问题。
* 在知识流失之前，从 Slack 对话和拉取请求中整理并留存知识。

<div id="where-you-can-use-the-agent">
  ## 你可以在何处使用代理
</div>

* **Dashboard**：在 控制面板 的任意页面，使用键盘快捷键 <kbd>⌘</kbd>+<kbd>I</kbd> (macOS) 或 <kbd>Ctrl</kbd>+<kbd>I</kbd> (Windows/Linux) 打开代理面板。或者点击 [Overview](https://dashboard.mintlify.com/) 页面上的 **Ask agent**。

  <Frame>
    <img src="/images/agent/dashboard-light.png" alt="在 控制面板 中打开的代理面板。" className="block dark:hidden" />

    <img src="/images/agent/dashboard-dark.png" alt="在 控制面板 中打开的代理面板。" className="hidden dark:block" />
  </Frame>
* **Slack**：将代理添加到你的 Slack 工作区，并通过提及 `@mintlify` 向其发出提示。
* **API**：使用[代理端点](/zh/api/agent/create-agent-job)将代理嵌入自定义应用中。
