<Info>
  任何拥有你仪表盘访问权限的用户，都可以在 [Pro 和 Enterprise 方案](https://mintlify.com/pricing?ref=agent) 中使用 Agent。
</Info>

Agent 会根据你的提示，为文档提出修改建议并创建 pull request。你向 Agent 发送请求时，它会参考你的文档、已连接的代码仓库以及 Slack 消息，生成符合技术写作最佳实践并遵循 Mintlify schema 的内容。

<div id="what-you-can-do-with-the-agent">
  ## 这个 agent 能帮你做什么
</div>

使用该 agent 可以：

* 根据你的提示、Pull Request 链接或 Slack 线程撰写新内容。
* 更新过时的代码示例和 API 文档。
* 搜索并更新现有内容。
* 解答关于你的文档和技术写作相关主题的问题。
* 在 Slack 对话和 Pull Request 中的知识流失之前，将其沉淀并记录下来。

<div id="where-you-can-use-the-agent">
  ## 可以在哪里使用 Agent
</div>

* **Dashboard**：在 Dashboard 的任意页面，使用键盘快捷键 <kbd>⌘</kbd>+<kbd>I</kbd>（macOS）或 <kbd>Ctrl</kbd>+<kbd>I</kbd>（Windows/Linux）来打开 Agent 面板。或者在 [Overview](https://dashboard.mintlify.com/) 页面点击 **Ask agent**。
  <Frame>
    <img src="/images/agent/dashboard-light.png" alt="在 Dashboard 中打开的 Agent 面板。" className="block dark:hidden" />

    <img src="/images/agent/dashboard-dark.png" alt="在 Dashboard 中打开的 Agent 面板。" className="hidden dark:block" />
  </Frame>
* **Slack**：将 Agent 添加到你的 Slack 工作区，并提及 `@mintlify` 来触发它。
* **API**：使用 [agent endpoints](/zh/api/agent/create-agent-job) 将 Agent 集成到自定义应用程序中。
