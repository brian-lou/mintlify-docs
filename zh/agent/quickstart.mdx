<div id="open-the-agent-panel">
  ## 打开代理面板
</div>

在桌面端，代理面板可调整大小。在移动设备上，代理会以全屏模式打开。

要打开代理面板：

* 在控制台的任意页面上，使用键盘快捷键 <kbd>⌘</kbd>+<kbd>I</kbd> (macOS) 或 <kbd>Ctrl</kbd>+<kbd>I</kbd> (Windows/Linux) 。
* 在 [Overview](https://dashboard.mintlify.com/) 页面上，点击 **Ask agent**。

* **聊天**：点击加号图标 <Icon icon="plus" />，开始新聊天。在聊天视图中，向代理发送提示词，以更新文档或询问与文档相关的问题。代理会根据你的指示创建拉取请求，并显示可用于查看拉取请求或在网页编辑器中打开更改的链接。
* **建议**：如果已启用，建议面板会根据拉取请求中的更改以及用户与助手的对话，显示建议的文档更新。
* **历史记录**：点击历史记录图标 <Icon icon="clock" />，浏览之前的对话，并继续处理先前的请求。点击任意对话即可在聊天视图中将其加载出来。
* **设置**：点击设置图标 <Icon icon="settings" />，配置代理的集成和仓库访问权限。

<Tip>
  每项任务都与代理开启一段新对话。这样可以让代理的上下文更聚焦，也有助于你将对话与特定项目对应起来。
</Tip>

<div id="connect-your-github-account">
  ## 连接你的 GitHub 账户
</div>

默认情况下，代理会以 Mintlify bot 的名义发起拉取请求。若要将拉取请求关联到你的账户，请在控制台的 [My profile](https://dashboard.mintlify.com/settings/account) 页面连接你的 GitHub 账户。

<div id="connect-repositories-as-context">
  ## 连接仓库作为上下文
</div>

代理只能访问你通过 Mintlify GitHub App 连接的仓库。你可以在代理面板的 **设置** 中，或在 [GitHub App settings](https://github.com/apps/mintlify/installations/new) 中配置代理可访问的仓库。
