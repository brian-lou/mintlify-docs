<div id="open-the-agent-panel">
  ## 打开 Agent 面板
</div>

在桌面端，Agent 面板可以调整大小。在移动设备上，Agent 会以全屏方式打开。

要打开 Agent 面板：

- 在仪表板中的任意页面，使用快捷键 <kbd>⌘</kbd>+<kbd>I</kbd>（macOS）或 <kbd>Ctrl</kbd>+<kbd>I</kbd>（Windows/Linux）。
- 在 [Overview](https://dashboard.mintlify.com/) 页面，点击 **Ask agent**。

- **Chat**：点击加号图标 <Icon icon="plus" /> 开始新的对话。在 Chat 视图中，向 agent 发送提示，让它更新文档或回答与你的文档相关的问题。Agent 会根据你的指令创建 pull request，并显示链接，方便你查看这些 pull request，或在 Web 编辑器中打开更改。
- **Suggestions**：如果已启用，Suggestions 面板会根据 pull request 中的更改以及用户与助手的对话，提供对文档的更新建议。
- **History**：点击历史记录图标 <Icon icon="clock" />，浏览过去的对话，并继续处理之前的请求。点击任意对话即可在 Chat 视图中加载它。
- **Settings**：点击设置图标 <Icon icon="settings" />，配置 agent 的集成和代码仓库访问权限。

<Tip>
  为每个任务单独与 agent 开启一段新的对话。这样可以让 agent 的上下文更加聚焦，并帮助你将对话与特定项目关联起来。
</Tip>

<div id="connect-your-github-account">
  ## 连接你的 GitHub 账户
</div>

默认情况下，代理会以 Mintlify 机器人的身份创建 pull request。若要将 pull request 归属到你的账号名下，请在仪表盘的 [My profile](https://dashboard.mintlify.com/settings/account) 页面连接你的 GitHub 账户。

<div id="connect-repositories-as-context">
  ## 将代码仓库连接为上下文
</div>

代理只能访问你通过 Mintlify GitHub App 连接的代码仓库。你可以在代理面板的 **Settings** 或 [GitHub App settings](https://github.com/apps/mintlify/installations/new) 中配置代理可访问的代码仓库。
