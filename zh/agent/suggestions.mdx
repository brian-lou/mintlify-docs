<Note>
  代理建议仅适用于 [Enterprise plans](https://mintlify.com/pricing?ref=autopilot)。如需为你的组织启用此功能，请[联系我们的销售团队](mailto:gtm@mintlify.com)。
</Note>

你可以让代理根据以下两个来源建议文档更新。

* **拉取请求变更**：监控选定 Git 仓库中的代码变更，找出需要同步更新文档的内容。
* **助手对话**：分析用户在你的文档站点中向助手提出的问题，以识别内容空白。

当代理识别出可能需要更新的文档时，它会在你的仪表板中创建一条建议，并附带用于创建拉取请求的相关上下文。

你可以利用这些建议，在新功能发布时主动保持文档最新，或回应用户的常见问题。

<div id="prerequisites">
  ## 先决条件
</div>

在使用建议功能之前，你必须在你的组织中安装 [Mintlify GitHub App](/zh/deploy/github)。该应用必须有权访问你的文档仓库，以及至少一个代码变更需要同步更新文档的其他仓库。

<div id="configure-suggestions">
  ## 配置建议
</div>

在代理设置中，你可以配置代理监控哪些仓库，以及如何接收通知。设置页面会显示代理当前监控的所有 GitHub 组织和仓库。

要访问代理设置：

1. 点击仪表板中的 **Ask agent** 按钮，打开代理面板。
2. 点击 **Settings** 按钮。

<div id="monitor-repositories">
  ### 监控仓库
</div>

对于你启用监控的每个仓库，代理都会监控所有已合并的拉取请求，无论它们合并到了哪个分支。在受监控的仓库中，拉取请求上会运行一个名为 **Mintlify Autopilot** 的 GitHub 检查，用于分析是否可能需要更新文档。当你合并了一个需要更新文档的拉取请求时，代理会在你的仪表板中创建一条建议。

<Note>
  当你首次为某个仓库启用监控时，代理会为过去七天内已合并的拉取请求创建建议。只有在该仓库尚无任何建议时，才会执行此回填。启用监控后，你可能会立即看到多条建议出现。
</Note>

如果你禁用监控，代理会立即停止对该仓库的监控。该仓库的现有建议会保留在你的仪表板中，直到你将其忽略。

<div id="conversation-insights">
  ### 对话洞察
</div>

如果你可以访问代理和助手，代理会根据用户与助手之间的对话生成建议。

代理会定期分析助手对话，并在识别出表明文档缺失或说明不清的问题模式时生成建议。

<div id="notifications">
  ### 通知
</div>

代理提出的建议始终会显示在你的仪表板中。你可以配置通知，以便在代理创建新建议时通过电子邮件或 Slack 私信收到提醒。

<Tip>
  如果你没有收到建议的电子邮件通知，请检查垃圾邮件文件夹，并将电子邮件地址 `notifications@mintlify.com` 添加到安全发件人列表中。
</Tip>

<div id="review-suggestions">
  ## 审核建议
</div>

代理会在你的仪表板中生成建议。每条建议都会显示触发该建议的拉取请求或助手对话主题、创建日期，以及提议的文档更新。

仪表板中的 **Ask agent** 按钮会显示等待你审核的建议数量。

<div id="create-pull-requests">
  ### 创建拉取请求
</div>

将建议作为上下文添加，让代理创建拉取请求。

1. 点击仪表板中的 **Ask agent** 按钮，打开代理面板。
2. 点击 **Add to chat**。
3. 向代理提交提示，请其创建拉取请求。

<div id="dismiss-suggestions">
  ### 忽略建议
</div>

如果某条建议无需更新文档，或者你已经处理了相关更改，可以将其忽略，使其从仪表板中移除。

1. 点击仪表板中的 **Ask agent** 按钮，打开代理面板。
2. 点击任意你想忽略的建议旁边的 **Dismiss** 按钮。

该建议会立即从你的仪表板中移除。已忽略的建议无法找回。
