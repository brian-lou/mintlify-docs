代理可协助处理多种文档任务。这些工作流展示了将代理融入文档流程的几种方式。你可以先选择一种符合团队当前工作方式的方法，再根据具体需求进行调整。

<div id="iterate-on-a-prompt-in-a-slack-thread">
  ## 在 Slack 线程中迭代完善提示
</div>

向代理发送提示，然后继续在同一线程中使用 `@mintlify` 提及它，以完善并迭代它创建的拉取请求。

例如：`@mintlify Our quickstart page needs a new section on inviting collaborators`。然后再输入 `@mintlify The new section should be called "Inviting collaborators"`。之后可继续进行其他迭代。

<div id="start-with-the-agent-finish-manually">
  ## 先让代理开始，再手动完成
</div>

提示代理先开始一个项目，然后检出它创建的分支，并在本地环境或网页编辑器中完成任务。代理可以帮你快速起步，之后再由你接手完成剩余工作。

例如：`@mintlify Update the quickstart page to include information about inviting collaborators`，然后检出该分支，并用你偏好的方式进行其他修改。

<div id="update-docs-when-merging-feature-changes">
  ## 合并功能改动时更新文档
</div>

合并功能拉取请求后，将 PR 链接发给代理，以更新相关文档。

例如：`@mintlify This PR adds a new authentication method. Update the docs to include the new auth flow: [PR link]`。

<div id="generate-release-notes-from-a-pull-request">
  ## 根据拉取请求生成发布说明
</div>

提示代理指定一个具体的拉取请求，让它根据提交历史生成发布说明或更新变更日志。

例如：`@mintlify Generate release notes for this PR: [PR link]`。

<div id="generate-code-examples">
  ## 生成代码示例
</div>

提示代理为整个文档中的功能或特定页面生成代码示例。

例如：`@mintlify Generate a code example to make the authentication method easier to understand`。

<div id="review-existing-content">
  ## 审核现有内容
</div>

提示代理审核现有内容的技术准确性、风格、语法或其他问题。

例如：`@mintlify Review the API rate limiting section. We changed limits last month`。

<div id="respond-to-user-feedback">
  ## 根据用户反馈进行回应
</div>

将用户反馈提示给代理，以便有针对性地更新你的文档。

例如：`@mintlify Users are getting confused by step 3 in the setup guide. What might be making it unclear?`。

<div id="automate-with-the-api">
  ## 使用 API 实现自动化
</div>

将代理集成到现有的自动化工具中，以便在代码发生变更时自动更新文档、触发内容审核，或在多个代码库之间同步文档更新。

使用代理端点来[创建作业](/zh/api-reference/agent/create-agent-job)、[获取特定作业](/zh/api-reference/agent/get-agent-job)和[获取所有作业](/zh/api-reference/agent/get-all-jobs)。

通过 API 创建作业时，你可以使用 `asDraft` 参数控制拉取请求是否以草稿模式创建 (默认为 `true`) 。将 `asDraft` 设为 `false`，即可创建非草稿拉取请求，以便在自动化工作流中立即审核和合并。

请参阅[代码合并时自动更新文档](/zh/guides/automate-agent)教程，了解如何设置 API 自动化。
