<div id="images">
  ## 图片
</div>

在文档中添加图片，为内容提供直观的上下文、示例或装饰。

<div id="basic-image-syntax">
  ### 基本图片语法
</div>

使用 [Markdown 语法](https://www.markdownguide.org/basic-syntax/#images) 将图片添加到文档中：

```mdx
![Alt text describing the image](/path/to/image.png)
```

<Tip>
  始终为图片添加描述性的 alt 文本，以提升无障碍访问体验和 SEO 效果。alt 文本应清晰地描述图片所展示的内容。
</Tip>

图片文件必须小于 20 MB。对于更大的文件，请将它们托管在 [Amazon S3](https://aws.amazon.com/s3) 或 [Cloudinary](https://cloudinary.com) 等 CDN 服务上。

<div id="html-image-embeds">
  ### HTML 图片嵌入
</div>

如果想更精细地控制图片的显示效果，请使用 HTML `<img>` 标签：

```jsx
<img 
  src="/images/dashboard.png" 
  alt="Main dashboard interface"
  style={{height: "300px", width: "400px"}}
  className="rounded-lg"
/>
```

<div id="resize-images-with-inline-styles">
  #### 使用内联样式调整图片大小
</div>

使用 JSX 的内联样式（`style` 属性）来调整图片大小：

```jsx
<img
  src="/images/architecture.png"
  style={{width: "450px", height: "auto"}}
  alt="Diagram showing the architecture of the system"
/>
```

<div id="disable-image-zoom">
  #### 禁用图片缩放
</div>

要禁用图片在点击时的默认缩放效果，请添加 `noZoom` 属性：

```html highlight="4"
<img 
  src="/images/screenshot.png" 
  alt="Descriptive alt text"
  noZoom
/>
```

<div id="link-images">
  #### 链接图片
</div>

要使图片变为可点击的链接，用一个 a（锚点）标签包裹图片，并添加 `noZoom` 属性：

```html
<a href="https://mintlify.com" target="_blank">
  <img 
    src="/images/logo.png" 
    alt="Mintlify logo"
    noZoom
  />
</a>
```

<Note>
  位于锚点（a）标签内的图片会自动显示指针光标，表示它们是可点击的。
</Note>

<div id="light-and-dark-mode-images">
  #### 亮色和深色模式图片
</div>

要在亮色和深色主题下显示不同的图片，请使用 Tailwind CSS 类：

```html
<!-- 浅色模式图片 -->
<img 
  className="block dark:hidden" 
  src="/images/light-mode.png" 
  alt="浅色模式界面"
/>

<!-- 深色模式图片 -->
<img 
  className="hidden dark:block" 
  src="/images/dark-mode.png" 
  alt="深色模式界面"
/>
```

<div id="svg-images">
  ### SVG 图像
</div>

在生产环境中，使用 `foreignObject` 元素的 SVG 文件与在本地开发环境中的渲染效果会有所不同。作为一项安全措施，Mintlify 的图像 CDN 会从 SVG 中移除 `foreignObject`，这可能会截断或隐藏文本和其他嵌入的 HTML 内容。

这通常会影响从 [draw.io](https://www.drawio.com) 等工具导出的 SVG，尤其是在启用了 HTML 文本格式化或自动换行功能时。要解决这个问题，请在将图表导出为 SVG 之前，关闭所有标签上的 **Formatted Text** 和 **Word Wrap** 选项。更多关于 SVG 导出的信息，请参阅 [draw.io 文档](https://www.drawio.com/doc/faq/svg-export-text-problems)。

<div id="videos">
  ## 视频
</div>

Mintlify 支持在 Markdown 中使用 [HTML 标签](https://www.markdownguide.org/basic-syntax/#html)，让你能够更灵活地创建丰富内容。

<Tip>
  始终在视频元素中包含后备文本内容，以便在浏览器不支持视频播放时进行展示。
</Tip>

<div id="youtube-embeds">
  ### 嵌入 YouTube 视频
</div>

通过 iframe 元素嵌入 YouTube 视频：

```html
<iframe
  className="w-full aspect-video rounded-xl"
  src="https://www.youtube.com/embed/4KzFe50RQkQ"
  title="YouTube video player"
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
  allowFullScreen
></iframe>
```

<Frame>
  <iframe className="w-full aspect-video rounded-xl" src="https://www.youtube.com/embed/4KzFe50RQkQ" title="YouTube 视频播放器" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowFullScreen />
</Frame>

<div id="self-hosted-videos">
  ### 自托管视频
</div>

对于自托管的视频内容，请使用 HTML 的 `<video>` 元素：

```html
<video
  controls
  className="w-full aspect-video rounded-xl"
  src="link-to-your-video.com"
></video>
```

<div id="autoplay-videos">
  ### 自动播放视频
</div>

若要自动播放视频，请使用：

```html
<video
  autoPlay
  muted
  loop
  playsInline
  className="w-full aspect-video rounded-xl"
  src="/videos/demo.mp4"
></video>
```

<Note>
  使用 JSX 语法时，将由两个单词组成的属性名写成驼峰命名形式（camelCase）：`autoPlay`、`playsInline`、`allowFullScreen`。
</Note>

<div id="iframes">
  ## iframe
</div>

使用 iframe 元素嵌入外部内容：

```html
<iframe 
  src="https://example.com/embed" 
  title="Embedded content"
  className="w-full h-96 rounded-xl"
></iframe>
```
