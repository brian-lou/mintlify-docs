软件开发的核心原则之一是 DRY（Don&#39;t Repeat Yourself，不要重复自己），这一原则同样适用于文档。如果你发现自己在多个地方重复相同的内容，可以为这部分内容创建一个自定义片段。片段中包含的内容可以被导入到其他文件中复用，你可以自行控制片段在页面上的展示位置。如果之后需要更新这段内容，只需编辑片段本身，而不必修改所有使用了该片段的文件。

<div id="how-snippets-work">
  ## 片段的工作原理
</div>

片段是被导入到其他文件中的任意 `.mdx`、`.md` 或 `.jsx` 文件。你可以在项目中的任意位置存放片段文件。

当你将片段导入到另一个文件时，它只会出现在被导入的位置，而不会单独渲染为一个页面。`/snippets/` 文件夹中的任何文件都会始终被视为片段，即使它没有被导入到其他文件中。

<div id="create-snippets">
  ## 创建片段
</div>

创建一个文件，其中包含你想要复用的内容。片段可以包含 Mintlify 支持的所有内容类型，也可以导入其他片段。

<div id="import-snippets-into-pages">
  ## 将片段导入页面
</div>

可以使用绝对路径或相对路径将片段导入页面。

* **绝对导入**：从项目根目录导入时，以 `/` 开头。
* **相对导入**：使用 `./` 或 `../` 按照当前文件的位置导入片段。

<Tip>
  相对导入支持 IDE 导航。在编辑器中按下 <kbd>CMD</kbd> 并单击片段名称即可直接跳转到该片段的定义。
</Tip>

<div id="import-text">
  ### 导入文本
</div>

1. 在要复用的 snippet 文件中添加内容。

   ```mdx shared/my-snippet.mdx wrap
   Hello world! This is my content I want to reuse across pages.
   ```

2. 使用绝对路径或相对路径，将该 snippet 导入到目标文件中。

   <CodeGroup>
     ```mdx Absolute import
     ---
     title: "An example page"
     description: "This is an example page that imports a snippet."
     ---

     import MySnippet from "/shared/my-snippet.mdx";

     The snippet content displays beneath this sentence.

     <MySnippet />
     ```

     ```mdx Relative import
     ---
     title: "An example page"
     description: "This is an example page that imports a snippet."
     ---

     import MySnippet from "../shared/my-snippet.mdx";

     The snippet content displays beneath this sentence.

     <MySnippet />
     ```
   </CodeGroup>

<div id="import-variables">
  ### 导入变量
</div>

在页面中引用代码片段中的变量。

1. 从代码片段文件中导出变量。

   ```mdx shared/custom-variables.mdx
   export const myName = "Ronan";

   export const myObject = { fruit: "strawberries" };

   ;
   ```

2. 在目标文件中导入该代码片段并使用变量。

   ```mdx destination-file.mdx
   ---
   title: "An example page"
   description: "This is an example page that imports a snippet with variables."
   ---

   import { myName, myObject } from "/shared/custom-variables.mdx";

   Hello, my name is {myName} and I like {myObject.fruit}.
   ```

<div id="import-snippets-with-variables">
  ### 使用带变量的代码片段
</div>

在导入代码片段时，使用变量向其传递数据。

1. 向代码片段添加变量，并在导入时传入对应的属性值。在此示例中，变量为 `{word}`。

   ```mdx shared/my-snippet.mdx
   My keyword of the day is {word}.
   ```

2. 在目标文件中导入带变量的代码片段。传入的属性值会替换代码片段定义中的变量。

   ```mdx destination-file.mdx
   ---
   title: "An example page"
   description: "This is an example page that imports a snippet with a variable."
   ---

   import MySnippet from "/shared/my-snippet.mdx";

   <MySnippet word="bananas" />
   ```

<div id="import-react-components">
  ### 导入 React 组件
</div>

1. 创建一个包含 JSX 组件的代码片段。更多信息请参阅 [React 组件](/zh/customize/react-components)。

   ```js components/my-jsx-snippet.jsx
   export const MyJSXSnippet = () => {
     return (
       <div>
         <h1>Hello, world!</h1>
       </div>
     );
   };
   ```

<Note>
  创建 JSX 代码片段时，请使用箭头函数语法（`=>`），而不要使用函数声明。代码片段中不支持 `function` 关键字。
</Note>

2. 导入该代码片段。

   ```mdx destination-file.mdx
   ---
   title: "示例页面"
   description: "这是一个示例页面，它导入了包含 React 组件的代码片段。"
   ---

   import { MyJSXSnippet } from "/components/my-jsx-snippet.jsx";

   <MyJSXSnippet />
   ```
