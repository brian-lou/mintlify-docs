title: "更新日志"

---

在页面中添加 [Update 组件](/zh/components/update)，即可为你的文档创建更新日志。

你可以参考 [Mintlify 更新日志](/zh/changelog) 作为示例：在每次更新中加入链接、图片、文本以及新功能的演示。

<div id="setting-up-your-changelog">
  ## 配置你的更新日志
</div>

<Steps>
  <Step title="为你的更新日志创建页面">
    1. 在文档中创建一个新页面，例如 `changelog.mdx` 或 `updates.mdx`。
    2. 在你的 `docs.json` 中将更新日志页面添加到导航中。
  </Step>

  <Step title="向更新日志中添加 Update 组件">
    为每条更新记录添加一个 `Update` 组件。

    包含相关信息，例如新功能发布、错误修复或其他公告。
  </Step>
</Steps>

```mdx Example changelog.mdx
---
title: "Changelog"
description: "Product updates and announcements"
---
<Update label="March 2025" description="v0.0.10">
  Added a new Wintergreen flavor.

  Released a new version of the Spearmint flavor, now with 10% more mint.
</Update>

<Update label="February 2025" description="v0.0.09">
  Released a new version of the Spearmint flavor.
</Update>
```

<div id="customizing-your-changelog">
  ## 自定义更新日志
</div>

掌控用户浏览更新日志的方式，让他们随时掌握你的产品最新动态。

<div id="table-of-contents">
  ### 目录
</div>

每个 `Update` 的 `label` 属性都会在右侧边栏的目录中自动生成一个条目。这是更新日志的默认导航方式。

<div id="tag-filters">
  ### 标签筛选器
</div>

在你的 `Update` 组件中添加 `tags`，即可将目录替换为标签筛选器。用户可以通过选择一个或多个标签来筛选更新日志：

```mdx Tag filters example wrap
<Update label="March 2025" description="v0.0.10" tags={["Wintergreen", "Spearmint"]}>
  Added a new Wintergreen flavor.

  Released a new version of the Spearmint flavor, now with 10% more mint.
</Update>

<Update label="February 2025" description="v0.0.09" tags={["Spearmint"]}>
  Released a new version of the Spearmint flavor.
</Update>

<Update label="January 2025" description="v0.0.08" tags={["Peppermint", "Spearmint"]}>
  Deprecated the Peppermint flavor.

  Released a new version of the Spearmint flavor.
</Update>
```

<Tip>
  当使用 `custom`、`center` 或 `wide` 页面模式时，目录和更新日志筛选器会被隐藏。在[页面模式](/zh/organize/pages#page-mode)中了解更多信息。
</Tip>

<div id="subscribable-changelogs">
  ### 可订阅的更新日志
</div>

<Note>RSS 订阅源仅适用于公开的文档。</Note>

使用 `Update` 组件，并在页面 URL 后追加 `/rss.xml`，即可创建可订阅的 RSS 订阅源。例如：`mintlify.com/docs/changelog/rss.xml`。

当你添加新的 `Update` 组件，或修改现有 `Update` 组件中的标题时，RSS 订阅源会发布新的条目。

RSS 订阅源中的条目只包含纯 Markdown。组件、代码和 HTML 元素都会被排除。当你的更新中包含这些被排除的内容时，可以使用 `rss` 属性为 RSS 订阅者提供替代的文字说明。

```xml Example RSS feed
<?xml version="1.0" encoding="UTF-8"?>
<rss xmlns:dc="http://purl.org/dc/elements/1.1/" xmlns:content="http://purl.org/rss/1.0/modules/content/" xmlns:atom="http://www.w3.org/2005/Atom" version="2.0">
  <channel>
    <title><![CDATA[产品更新]]></title>
    <description><![CDATA[新功能与改进]]></description>
    <link>https://mintlify.com/docs</link>
    <generator>RSS for Node</generator>
    <lastBuildDate>Mon, 21 Jul 2025 21:21:47 GMT</lastBuildDate>
    <atom:link href="https://mintlify.com/docs/changelog/rss.xml" rel="self" type="application/rss+xml"/>
    <copyright><![CDATA[Mintlify]]></copyright>
    <docs>https://mintlify.com/docs</docs>
    <item>
      <title><![CDATA[2025年6月]]></title>
      <link>https://mintlify.com/docs/changelog#june-2025</link>
      <guid isPermaLink="true">https://mintlify.com/docs/changelog#june-2025</guid>
      <pubDate>Mon, 23 Jun 2025 16:54:22 GMT</pubDate>
    </item>
  </channel>
</rss>
```

RSS 源可以与 Slack、电子邮件或其他订阅工具集成，用于通知用户产品变更。可选方式包括：

* [Slack](https://slack.com/help/articles/218688467-Add-RSS-feeds-to-Slack)
* 通过 Zapier 的 [Email](https://zapier.com/apps/email/integrations/rss/1441/send-new-rss-feed-entries-via-email)
* 类似 [Readybot](https://readybot.io) 或 [RSS Feeds to Discord Bot](https://rss.app/en/bots/rssfeeds-discord-bot) 的 Discord 机器人

为了让 RSS 源更容易被发现，你可以在页面顶部显示一个 RSS 图标按钮，链接到该源。将 `rss: true` 添加到页面的 frontmatter 中：

```mdx
---
rss: true
---
```
