<Note>
  个性化功能要求已配置使用 OAuth 或 JWT 的[身份验证](/zh/deploy/authentication-setup)。
</Note>

用户登录到你的文档站点后，你可以为其自定义内容。你可以预填 API 密钥，显示与用户套餐或角色对应的内容，并根据分组成员身份筛选 API 参考内容。

<div id="api-key-prefilling">
  ## API 密钥预填
</div>

通过在用户数据中返回匹配的字段名，系统会自动使用用户特定的值填充 API 操作台字段。请在[用户数据](/zh/deploy/authentication-setup#user-data-format)的 `apiPlaygroundInputs` 字段中包含这些值。

```json
{
  "apiPlaygroundInputs": {
    "header": { "X-API-Key": "user_api_key_123" },
    "server": { "subdomain": "acme" }
  }
}
```

字段名称必须与 OpenAPI 规范中定义的名称一致。只有与当前接口安全方案匹配的值才会生效。

<div id="dynamic-mdx-content">
  ## 动态 MDX 内容
</div>

在 MDX 页面中使用 `user` 变量，根据姓名、套餐或组织等用户信息动态显示内容。在[用户数据](/zh/deploy/authentication-setup#user-data-format)的 `content` 字段中加入自定义数据。

```json
{
  "content": {
    "firstName": "Jane",
    "company": "Acme Corp",
    "plan": "Enterprise"
  }
}
```

在 MDX 中引用这些值。

```mdx
Welcome back, {user.firstName}! Your {user.plan} plan includes 100 seats for members in your {user.company} organization.
```

若要基于用户数据进行条件渲染，请在 JSX 组件中使用 `user` 变量。

```jsx
{
  user.plan === 'enterprise'
    ? <>Contact your admin to enable this feature.</>
    : <>See <a href="https://yoursite.com/pricing">pricing</a> for information about upgrading.</>
}
```

<Note>
  对于未登录的用户，`user` 变量是一个空对象。请对所有 `user` 字段使用可选链，以避免报错。例如，使用 `{user.org?.plan}`，而不是 `{user.org.plan}`。
</Note>

<div id="page-visibility">
  ## 页面可见性
</div>

通过在页面前置元数据中添加 `groups`，可将页面访问限制为特定分组。用户必须至少属于所列出的一个分组，才能访问该页面。

```mdx
---
title: "Admin settings"
groups: ["admin"]
---
```

如需详细了解分组如何与公开页面配合使用，请参阅[使用分组控制访问](/zh/deploy/authentication-setup#control-access-with-groups)。

<div id="openapi-content-filtering">
  ## OpenAPI 内容过滤
</div>

使用 OpenAPI 规范中的 `x-mint` 扩展，根据用户分组过滤 API 参考内容。你可以过滤整个端点、单个 schema 属性、`oneOf` 变体以及枚举值。

<div id="filter-endpoints">
  ### 过滤端点
</div>

在操作或路径中添加 `x-mint.groups`，即可将端点页面限制为仅特定分组可见。不在所列分组中的用户既不会在导航中看到该端点，也无法访问其页面。

<CodeGroup>
  ```json {6-8} 受限操作
  {
    "paths": {
      "/billing": {
        "get": {
          "summary": "Get billing details",
          "x-mint": {
            "groups": ["admin", "billing"]
          },
          "responses": {
            "200": {
              "description": "Billing details"
            }
          }
        }
      }
    }
  }
  ```

  ```json {3-5} 受限路径
  {
    "paths": {
      "x-mint": {
        "groups": ["admin", "billing"]
      },
      "/billing": {
        "get": {
          "summary": "Get billing details",
        }
      },
      "/users": {
        "get": {
          "summary": "Get user details",
        }
      }
    }
  }
  ```
</CodeGroup>

<div id="filter-schema-properties">
  ### 筛选 schema 属性
</div>

将 `x-mint.groups` 添加到请求体、参数或响应中的各个属性上。未添加 `x-mint.groups` 的属性仍会对所有用户可见。

```json {11-13} Restricted property
{
  "components": {
    "schemas": {
      "User": {
        "type": "object",
        "properties": {
          "name": {
            "type": "string"
          },
          "internal_id": {
            "type": "string",
            "x-mint": {
              "groups": ["admin"]
            }
          }
        }
      }
    }
  }
}
```

在此示例中，所有用户都能看到 `name` 属性。只有属于 `admin` 分组的用户才能看到 `internal_id` 属性。

<div id="filter-oneof-variants">
  ### 筛选 oneOf 变体
</div>

将 `x-mint.groups` 添加到各个 `oneOf` 选项中，以限制用户可见的模式变体。

```json {7-9} Restricted oneOf variant
{
  "schema": {
    "oneOf": [
      {
        "title": "Enterprise config",
        "type": "object",
        "x-mint": {
          "groups": ["enterprise"]
        },
        "properties": {
          "sso_enabled": { "type": "boolean" }
        }
      },
      {
        "title": "Standard config",
        "type": "object",
        "properties": {
          "notifications": { "type": "boolean" }
        }
      }
    ]
  }
}
```

<div id="filter-enum-values">
  ### 筛选枚举值
</div>

使用 `x-mint-enum` 扩展按分组限制单个枚举值。将每个受限值列为一个键，将其允许的分组作为对应的值。未在 `x-mint-enum` 中列出的枚举值对所有用户可见。

```json {4-7} Restricted enum values
{
  "type": "string",
  "enum": ["free", "pro", "enterprise"],
  "x-mint-enum": {
    "pro": ["pro", "enterprise"],
    "enterprise": ["enterprise"]
  }
}
```

在此示例中，所有用户都会看到 `free`。`pro` 或 `enterprise` 分组中的用户会看到 `pro`。只有 `enterprise` 分组中的用户会看到 `enterprise`。

<Note>
  `x-mint-enum` 是 schema 对象上独立的顶层扩展，而不是嵌套在 `x-mint` 下。
</Note>

<div id="user-data-format">
  ## 用户数据格式
</div>

你的身份验证系统会返回用于控制个性化体验的用户数据。本页介绍的 `groups`、`content` 和 `apiPlaygroundInputs` 字段都属于用户数据对象的一部分。

有关完整的用户数据格式和字段参考，请参阅 [用户数据格式](/zh/deploy/authentication-setup#user-data-format)。

<div id="logout-behavior">
  ## 登出行为
</div>

登出在客户端完成。用户点击登出按钮时，Mintlify 会清除浏览器中存储的会话数据。

如需限制个性化数据的保留时间，请在用户数据中设置 `expiresAt` 字段。
