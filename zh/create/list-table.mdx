<div id="lists">
  ## 列表
</div>

列表遵循官方的 [Markdown 语法](https://www.markdownguide.org/basic-syntax/#lists-1)。

<div id="ordered-list">
  ### 有序列表
</div>

要创建有序列表，请在列表项前添加数字，并在数字后加上句点。

1. 第一项
2. 第二项
3. 第三项
4. 第四项

```mdx
1. First item
2. Second item
3. Third item
4. Fourth item
```


<div id="unordered-list">
  ### 无序列表
</div>

要创建无序列表，请在列表项前添加短横线 (`-`)、星号 (`*`) 或加号 (`+`)。

* 第一项
* 第二项
* 第三项
* 第四项

```mdx
- First item
- Second item
- Third item
- Fourth item
```


<div id="nested-list">
  ### 嵌套列表
</div>

通过缩进列表项来创建嵌套列表。

* 第一项
* 第二项
  * 子项
  * 子项
* 第三项

```mdx
- First item
- Second item
  - Additional item
  - Additional item
- Third item
```


<div id="tables">
  ## 表格
</div>

表格遵循官方的 [Markdown 语法](https://www.markdownguide.org/extended-syntax/#tables)。

要添加表格，请使用三个或更多连字符 (`---`) 来创建每一列的表头，并用竖线 (`|`) 分隔各列。为保证兼容性，还应在每行的两端都加上竖线。

| 属性     | 描述        |
| ------ | --------- |
| Name   | 用户的全名     |
| Age    | 填报的年龄     |
| Joined | 用户是否加入了社区 |

```mdx
| Property | Description                           |
| -------- | ------------------------------------- |
| Name     | Full name of user                     |
| Age      | Reported age                          |
| Joined   | Whether the user joined the community |
```


<div id="column-alignment">
  ### 列对齐
</div>

在分隔行中使用冒号即可对齐各列内容：

| 左对齐 | 居中对齐 | 右对齐 |
| :-- | :--: | --: |
| 左对齐 |  居中  | 右对齐 |
| 文本  |  文本  |  文本 |

```mdx
| Left aligned | Center aligned | Right aligned |
| :----------- | :------------: | ------------: |
| Left         | Center         | Right         |
| Text         | Text           | Text          |
```
