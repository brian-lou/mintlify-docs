<div id="lists">
  ## 列表
</div>

列表使用官方的 [Markdown 语法](https://www.markdownguide.org/basic-syntax/#lists-1)。

<div id="ordered-list">
  ### 有序列表
</div>

要创建有序列表，在每个列表项前添加数字和句点。

1. 第一项
2. 第二项
3. 第三项
4. 第四项

```mdx
1. First item
2. Second item
3. Third item
4. Fourth item
```


<div id="unordered-list">
  ### 无序列表
</div>

要创建无序列表，请在列表项前添加减号 (`-`)、星号 (`*`) 或加号 (`+`)。

* 第一项
* 第二项
* 第三项
* 第四项

```mdx
- First item
- Second item
- Third item
- Fourth item
```


<div id="nested-list">
  ### 嵌套列表
</div>

通过缩进列表项来实现嵌套。

* 第一项
* 第二项
  * 额外项
  * 额外项
* 第三项

```mdx
- First item
- Second item
  - Additional item
  - Additional item
- Third item
```


<div id="tables">
  ## 表格
</div>

表格遵循官方的 [Markdown 语法](https://www.markdownguide.org/extended-syntax/#tables)。

要添加表格，请使用三个或更多连字符（`---`）来创建每一列的表头，并使用竖线（`|`）分隔各列。为了兼容性，你还应在每一行的两端各添加一个竖线。

| Property | Description |
| -------- | ----------- |
| Name     | 用户的完整姓名     |
| Age      | 填写的年龄       |
| Joined   | 用户是否已加入社区   |

```mdx
| Property | Description                           |
| -------- | ------------------------------------- |
| Name     | Full name of user                     |
| Age      | Reported age                          |
| Joined   | Whether the user joined the community |
```


<div id="column-alignment">
  ### 列对齐
</div>

在分隔行中使用冒号来控制列内容的对齐方式：

| 左对齐  |  居中对齐  |   右对齐 |
| :--- | :----: | ----: |
| Left | Center | Right |
| 文本   |   文本   |    文本 |

```mdx
| Left aligned | Center aligned | Right aligned |
| :----------- | :------------: | ------------: |
| Left         | Center         | Right         |
| Text         | Text           | Text          |
```
