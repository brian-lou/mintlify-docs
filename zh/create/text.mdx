<div id="headers">
  ## 标题
</div>

标题用来组织内容并创建导航锚点。它们会显示在目录中，帮助用户快速浏览文档。

<div id="creating-headers">
  ### 创建标题
</div>

使用 `#` 符号来创建不同层级的标题：

```mdx
## Main section header
### Subsection header
#### Sub-subsection header
```

<Tip>
  使用描述性且富含关键词的标题，清晰指明后续内容的主题。这既有助于用户导航，也有助于搜索引擎优化。
</Tip>

<div id="disabling-anchor-links">
  ### 禁用锚点链接
</div>

默认情况下，标题会包含可点击的锚点链接，用户可以直接跳转到文中的特定部分。你可以在 HTML 或 React 标题中使用 `noAnchor` 属性来禁用这些锚点链接。

<CodeGroup>
  ```mdx HTML 标题示例
  <h2 noAnchor>
  Header without anchor link
  </h2>
  ```

  ```mdx React 标题示例
  <Heading level={2} noAnchor>
  Header without anchor link
  </Heading>
  ```
</CodeGroup>

使用 `noAnchor` 时，标题将不会显示锚点图标，点击标题文本也不会再将锚点链接复制到剪贴板。

## 文本格式

我们支持大部分用于强调和设置文本样式的 Markdown 语法。

<div id="basic-formatting">
  ### 基本格式
</div>

将以下格式样式应用于你的文本：

| 样式 | 语法 | 示例 | 结果 |
|-------|--------|---------|--------|
| **粗体** | `**text**` | `**important note**` | **important note** |
| *斜体* | `_text_` | `_emphasis_` | *emphasis* |
| ~~删除线~~ | `~text~` | `~deprecated feature~` | ~~deprecated feature~~ |

<div id="combining-formats">
  ### 组合格式
</div>

你可以组合使用多种格式：

```mdx
**_bold and italic_**
**~~bold and strikethrough~~**
*~~italic and strikethrough~~*
```

***粗体和斜体***<br />
**~~粗体和删除线~~**<br />
*~~斜体和删除线~~*

<div id="superscript-and-subscript">
  ### 上标和下标
</div>

对于数学表达式或脚注，使用 HTML 标签来实现：

| 类型 | 语法 | 示例 | 结果 |
|------|--------|---------|--------|
| 上标 | `<sup>text</sup>` | `example<sup>2</sup>` | example<sup>2</sup> |
| 下标 | `<sub>text</sub>` | `example<sub>n</sub>` | example<sub>n</sub> |

## 链接

链接可以帮助用户在页面之间跳转并访问外部资源。使用具有描述性的链接文本，有助于提升可访问性和用户体验。

<div id="internal-links">
  ### 内部链接
</div>

使用以站点根目录为起点的路径链接到文档中的其他页面：

```mdx
[Quickstart](/quickstart)
[Steps](/components/steps)
```

[快速入门](/zh/quickstart)<br />
[步骤](/zh/components/steps)

<div id="external-links">
  ### 外部链接
</div>

对于外部资源，请填写完整的 URL：

```mdx
[Markdown Guide](https://www.markdownguide.org/)
```

[Markdown 指南](https://www.markdownguide.org/)

<div id="broken-links">
  ### 失效链接
</div>

你可以使用 [CLI](/zh/installation) 检查文档中的失效链接：

```bash
mint broken-links
```

<div id="blockquotes">
  ## 引用块
</div>

引用块用于在内容中突出显示重要信息、引文或示例。

<div id="single-line-blockquotes">
  ### 单行引用
</div>

在文本前添加 `>` 即可创建引用：

```mdx
> This is a quote that stands out from the main content.
```

> 这是一段在正文中格外醒目的引用。

<div id="multi-line-blockquotes">
  ### 多行块引用
</div>

对于较长的引用或包含多段内容的情况：

```mdx
> 这是多行块引用的第一段。
>
> 这是第二段，用带有 `>` 的空行分隔。
```

> 这是多行引用的第一段。
>
> 这是第二段，中间用一行只包含 `>` 的空行分隔。

<Tip>
  请适度使用引用块，以保持其视觉效果和含义。对于备注、警告和其他信息，可以考虑使用 [callouts](/zh/components/callouts)。
</Tip>

<div id="mathematical-expressions">
  ## 数学表达式
</div>

我们支持使用 LaTeX 来渲染数学表达式和方程。你可以在 `docs.json` 的 [settings](/zh/organize/settings#param-latex) 中配置 `styles.latex`，以覆盖自动检测行为。

<div id="inline-math">
  ### 行内公式
</div>

行内数学表达式使用单个美元符号 `$`：

```mdx
The Pythagorean theorem states that $(a^2 + b^2 = c^2)$ in a right triangle.
```

勾股定理指出，在直角三角形中，两直角边的平方和等于斜边的平方，即 $(a^2 + b^2 = c^2)$。

<div id="block-equations">
  ### 块级公式
</div>

对块级公式使用双美元符号 `$$`：

```mdx
$$
E = mc^2
$$
```

$$
E = mc^2
$$

<Info>
  要正确使用 LaTeX，需遵循规范的数学语法。请参阅 [LaTeX 文档](https://www.latex-project.org/help/documentation/) 以获取完整的语法指南。
</Info>

<div id="line-breaks-and-spacing">
  ## 换行与间距
</div>

通过控制间距和换行来提高内容的可读性。

<div id="paragraph-breaks">
  ### 段落分隔
</div>

使用空白行分隔段落：

```mdx
This is the first paragraph.

This is the second paragraph, separated by a blank line.
```

这是第一段。

这是第二段，与第一段之间用空行分隔。

<div id="manual-line-breaks">
  ### 手动换行
</div>

如需在段落内强制换行，请使用 HTML `<br />` 标签：

```mdx
This line ends here.<br />
This line starts on a new line.
```

这一行在此结束。<br />
下一行从新的一行开始。

<Tip>
  在大多数情况下，使用空行分隔段落比手动换行更有利于提高可读性。
</Tip>

<div id="best-practices">
  ## 最佳实践
</div>

<div id="content-organization">
  ### 内容结构
</div>

* 使用标题来构建清晰的内容层级
* 遵循正确的标题层级结构（不要从 H2 直接跳到 H4）
* 编写具有描述性且富含关键词的标题文本

<div id="text-formatting">
  ### 文本格式
</div>

* 使用粗体来突出重点，不要整段文字都用粗体
* 将斜体保留用于术语、标题或轻度强调
* 避免过度使用格式，以免干扰对内容本身的关注

<div id="links">
  ### 链接
</div>

* 使用具有描述性的链接文本，而不是使用“click here”或“read more”
* 对内部链接使用根相对路径
* 定期测试链接，避免出现失效链接
