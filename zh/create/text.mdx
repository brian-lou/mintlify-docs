<div id="headers">
  ## 标题
</div>

标题可用于组织内容并创建导航锚点。它们会显示在目录中，帮助用户快速浏览文档。

<div id="creating-headers">
  ### 创建标题
</div>

使用 `#` 符号创建不同层级的标题：

```mdx
## Main section header
### Subsection header
#### Sub-subsection header
```

<Tip>
  使用描述明确、包含丰富关键词的标题，清晰说明后续内容。这既有助于用户导航，也有利于搜索引擎优化。
</Tip>

<div id="disabling-anchor-links">
  ### 禁用锚点链接
</div>

默认情况下，标题会包含可点击的锚点链接，用户可直接链接到特定部分。你可以在 HTML 或 React 标题中使用 `noAnchor` 属性来禁用这些锚点链接。

<CodeGroup>
  ```mdx HTML 标题示例
  <h2 noAnchor>
  Header without anchor link
  </h2>
  ```

  ```mdx React 标题示例
  <Heading level={2} noAnchor>
  Header without anchor link
  </Heading>
  ```
</CodeGroup>

使用 `noAnchor` 后，标题将不再显示锚点标签，点击标题文本时也不会将锚点链接复制到剪贴板。

## 文本格式

我们支持大多数 Markdown 文本格式，可用于强调和设置文本样式。

<div id="basic-formatting">
  ### 基本格式
</div>

在文本中应用以下格式样式：

| 样式      | 语法         | 示例                     | 效果                     |
| ------- | ---------- | ---------------------- | ---------------------- |
| **粗体**  | `**text**` | `**important note**`   | **important note**     |
| *斜体*    | `_text_`   | `_emphasis_`           | *emphasis*             |
| ~~删除线~~ | `~text~`   | `~deprecated feature~` | ~~deprecated feature~~ |

<div id="combining-formats">
  ### 混合使用格式
</div>

你可以混合使用不同的格式样式：

```mdx
**_bold and italic_**
**~~bold and strikethrough~~**
*~~italic and strikethrough~~*
```

***粗体和斜体***<br />
**~~粗体和删除线~~**<br />
*~~斜体和删除线~~*

<div id="superscript-and-subscript">
  ### 上标和下标
</div>

对于数学公式或脚注，请使用 HTML 标签：

| 类型 | 语法                | 示例                    | 结果                  |
| -- | ----------------- | --------------------- | ------------------- |
| 上标 | `<sup>text</sup>` | `example<sup>2</sup>` | example<sup>2</sup> |
| 下标 | `<sub>text</sub>` | `example<sub>n</sub>` | example<sub>n</sub> |

## 链接

链接可帮助用户在页面之间跳转并访问外部资源。请使用描述明确的链接文本，以提升无障碍性和用户体验。

<div id="internal-links">
  ### 内部链接
</div>

使用根相对路径链接到文档中的其他页面：

```mdx
[Quickstart](/quickstart)
[Steps](/components/steps)
```

[快速入门](/zh/quickstart)<br />
[步骤](/zh/components/steps)

<div id="external-links">
  ### 外部链接
</div>

对于外部资源，请使用完整的 URL：

```mdx
[Markdown Guide](https://www.markdownguide.org/)
```

[Markdown 指南](https://www.markdownguide.org/)

<div id="broken-links">
  ### 失效链接
</div>

你可以使用 [CLI](/zh/installation) 检查文档中的失效链接：

```bash
mint broken-links
```

<div id="blockquotes">
  ## 块引用
</div>

块引用可用于在内容中突出显示重要信息、引文或示例。

<div id="single-line-blockquotes">
  ### 单行块引用
</div>

在文本前加上 `>` 即可创建块引用：

```mdx
> This is a quote that stands out from the main content.
```

> 这是一段区别于正文的引用内容。

<div id="multi-line-blockquotes">
  ### 多行块引用
</div>

对于较长的引用或包含多个段落的情况：

```mdx
> 这是多行块引用的第一段。
>
> 这是第二段，通过带有 `>` 的空行与上一段分隔。
```

> 这是多行块引用中的第一段。
>
> 这是第二段，两段之间用带有 `>` 的空行分隔。

<Tip>
  请谨慎使用块引用，以保持其视觉表现和语义。对于说明、警告及其他信息，建议使用[提示框](/zh/components/callouts)。
</Tip>

<div id="mathematical-expressions">
  ## 数学表达式
</div>

我们支持使用 LaTeX 渲染数学表达式和公式。你可以在 `docs.json` 的[设置](/zh/organize/settings#param-latex)中配置 `styles.latex`，以手动覆盖自动检测。

<div id="inline-math">
  ### 行内公式
</div>

行内数学表达式请使用单个美元符号 `$`：

```mdx
The Pythagorean theorem states that $(a^2 + b^2 = c^2)$ in a right triangle.
```

勾股定理指出，在直角三角形中，$(a^2 + b^2 = c^2)$。

<div id="block-equations">
  ### 块级公式
</div>

对于独立显示的公式，使用两个美元符号 `$$`：

```mdx
$$
E = mc^2
$$
```

$$
E = mc^2
$$

<Info>
  LaTeX 支持需要使用正确的数学语法。有关完整的语法指南，请参阅 [LaTeX 文档](https://www.latex-project.org/help/documentation/)。
</Info>

<div id="line-breaks-and-spacing">
  ## 换行和间距
</div>

通过控制间距和换行，提升内容可读性。

<div id="paragraph-breaks">
  ### 段落分隔
</div>

段落之间用空行分隔：

```mdx
This is the first paragraph.

This is the second paragraph, separated by a blank line.
```

这是第一段。

这是第二段，中间用一个空行分隔。

<div id="manual-line-breaks">
  ### 手动换行
</div>

如需在段落内强制换行，请使用 HTML `<br />` 标签：

```mdx
This line ends here.<br />
This line starts on a new line.
```

这一行在这里结束。<br />
这一行另起一行。

<Tip>
  大多数情况下，段落之间留空行比手动换行更易于阅读。
</Tip>

<div id="best-practices">
  ## 最佳实践
</div>

<div id="content-organization">
  ### 内容组织
</div>

* 使用标题建立清晰的内容层级
* 遵循正确的标题层级 (不要从 H2 跳到 H4)
* 标题应明确具体，并包含相关关键词

<div id="text-formatting">
  ### 文本格式
</div>

* 使用粗体突出重点，不要整段都加粗
* 斜体仅用于术语、标题或轻微强调
* 避免过度格式化，以免喧宾夺主

<div id="links">
  ### 链接
</div>

* 使用有明确含义的链接文本，不要使用“点击这里”或“阅读更多”之类的表述
* 内部链接使用根相对路径
* 定期检查链接，避免出现失效引用
