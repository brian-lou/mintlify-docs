优化你的文档，使其同时适用于传统搜索引擎和由 AI 驱动的答案引擎，例如 ChatGPT、Perplexity 和 Google AI Overviews。

生成式引擎优化 (GEO) 侧重于通过全面的内容和结构化信息，让 AI 系统更容易引用你的内容；而传统 SEO 则以提升搜索结果排名为目标。

<div id="geo-quickstart">
  ## GEO 快速入门
</div>

<div id="initial-setup">
  ### 初始设置
</div>

1. **确保你的文档已在 `docs.json` 设置中开启索引**
2. **检查当前页面**，查看是否缺少描述和标题

<div id="content-improvements">
  ### 内容优化
</div>

1. **添加对比表格** 到合适的页面
2. **检查标题**，确保能够回答常见问题
3. **改进相关主题之间的内部链接**
4. **使用 AI 工具进行测试**，验证准确性

<div id="geo-best-practices">
  ## GEO 最佳实践
</div>

总的来说，写得好、结构清晰的文档通常会有很强的 GEO 效果。你仍然应该优先为用户而写；如果你的内容能满足他们的需求，那你就已经在朝着适配 AI 工具的方向迈进了。提供真正有帮助的内容，而不是为优化而优化，这样的做法会同时受到传统搜索引擎和 AI 搜索引擎的青睐。

重点关注：

* 内容应贴合用户需求，而不是一味匹配关键词
* 结构清晰、便于快速浏览的信息
* 直接回答问题

<div id="format-for-clarity">
  ### 为清晰起见设置格式
</div>

这些格式做法有助于 AI 工具解析并理解你的内容：

* 不要跳过标题层级 (H1 → H2 → H3) 
* 使用具体的对象名称，不要用“它”或“这个”之类的指代
* 为代码块标明所用的编程语言
* 为图片提供有描述性的替代文本
* 链接到相关概念，帮助 AI 理解它们之间的关系

<div id="answer-questions-directly">
  ### 直接回答问题
</div>

编写内容时要直接回应用户的具体问题：

* 在章节开头先说明核心要点
* 使用与常见问题相对应的描述性标题
* 将复杂主题拆解为编号步骤

<div id="mintlify-configuration">
  ## Mintlify 配置
</div>

使用以下功能提升 GEO 效果。

<div id="add-descriptive-page-metadata">
  ### 添加描述性页面元数据
</div>

在前置元数据中添加清晰的标题和描述：

```mdx
---
title: "API authentication guide"
description: "Complete guide to implementing API authentication with code examples"
---
```


<div id="configure-global-indexing-settings">
  ### 配置全局索引设置
</div>

将以下内容添加到 `docs.json`：

```json
{
  "seo": {
    "indexing": "all",
    "metatags": {
      "og:type": "website",
      "og:site_name": "Your docs"
    }
  }
}
```


<div id="llmstxt">
  ### LLMs.txt
</div>

LLMs.txt 文件可帮助 AI 系统理解你的文档结构，类似于站点地图帮助搜索引擎理解网站结构。Mintlify 会自动为你的文档生成 LLMs.txt 文件，无需任何配置。

<div id="testing-your-documentation">
  ## 测试你的文档
</div>

使用各种 AI 工具就你的产品和文档提问，看看它们引用你的文档的效果如何。

**向 AI 助手询问与你的文档相关的具体问题：**

* “如何使用这个 API 设置身份验证？”
* “一步一步带我完成安装流程”

**检查这些工具是否能提供：**

* 正确的代码示例
* 准确的分步说明
