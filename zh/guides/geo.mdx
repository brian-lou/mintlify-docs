让文档同时适配传统搜索引擎，以及 ChatGPT、Perplexity 和 Google AI Overviews 等 AI 驱动的问答引擎。

生成式引擎优化（GEO）通过内容完备和信息结构化，专注于提升被 AI 系统引用的机会，而传统 SEO 则侧重于搜索结果排名。

<div id="geo-quickstart">
  ## GEO 快速入门
</div>

<div id="initial-setup">
  ### 初始设置
</div>

1. 在 `docs.json` 配置中**确保已启用文档索引**
2. **审核当前页面**，检查是否缺少描述和标题

<div id="content-improvements">
  ### 内容优化
</div>

1. 在合适的页面**添加对比表**
2. **审查标题**，确保它们能回答常见问题
3. **优化相关主题之间的内部链接**
4. **使用 AI 工具进行测试**以核实准确性

<div id="geo-best-practices">
  ## GEO 最佳实践
</div>

总体来说，撰写良好且结构清晰的文档会有很好的 GEO 表现。你仍然应当优先为用户而写；只要内容满足了用户的需求，你就在为 AI 工具优化的正确方向上。创作真正有帮助的内容，而不是为了“优化”而优化，这一点会同时受到传统搜索引擎和 AI 搜索引擎的青睐。

重点关注：

- 内容与用户需求保持一致，而不是简单进行关键词匹配
- 结构清晰、便于快速浏览的信息
- 对问题给出直接的回答

<div id="format-for-clarity">
  ### 提高清晰度的格式规范
</div>

这些格式写法有助于 AI 工具解析并理解你的内容：

- 不要跳过标题层级（H1 → H2 → H3）
- 使用具体的对象名称，而不是“it”或“this”
- 为代码块标明其所用的编程语言
- 为图片提供具有描述性的 alt 文本
- 链接到相关概念，帮助 AI 理解它们之间的关系

<div id="answer-questions-directly">
  ### 直接回答问题
</div>

撰写能解决特定用户问题的内容：

- 在每一节开头先给出核心结论
- 使用符合常见搜索或提问的描述性标题
- 将复杂主题拆解为按顺序编号的步骤

<div id="mintlify-configuration">
  ## Mintlify 配置
</div>

使用以下功能优化 GEO。

<div id="add-descriptive-page-metadata">
  ### 添加描述性页面元数据
</div>

在 frontmatter 中添加清晰的标题和描述：

```mdx
---
title: "API authentication guide"
description: "Complete guide to implementing API authentication with code examples"
---
```


<div id="configure-global-indexing-settings">
  ### 配置全局索引配置
</div>

将以下内容添加到你的 `docs.json` 中：

```json
{
  "seo": {
    "indexing": "all",
    "metatags": {
      "og:type": "website",
      "og:site_name": "Your docs"
    }
  }
}
```


<div id="llmstxt">
  ### LLMs.txt
</div>

LLMs.txt 文件可以帮助 AI 系统理解你的文档结构，就像网站地图帮助搜索引擎一样。Mintlify 会自动为你的文档生成 LLMs.txt 文件，无需任何配置。

<div id="testing-your-documentation">
  ## 测试你的文档
</div>

使用各种 AI 工具就你的产品和文档提出问题，查看这些工具在回答中对你的文档引用得是否准确、充分。

**让 AI 助手就你的文档回答具体问题：**

- “如何使用此 API 配置身份验证？”
- “请按步骤引导我完成安装过程”

**检查这些工具是否提供：**

- 正确的代码示例
- 准确的分步操作说明
