---
title: "指南"
description: "了解如何运用最佳实践和工作流程创建高质量的文档。"
---

本节中的指南提供了一些建议，帮助你创建真正能帮助用户取得成功的文档。无论你是从零开始，还是在改进现有文档，这些指南都能帮助你规划、编写和维护文档。

最重要的是，要始终考虑用户的需求和目标。记录那些能帮助他们使用你的产品，并顺利回到手头任务的内容。

<div id="topics">
  ## 主题
</div>

<div id="ai-tools">
  ### AI 工具
</div>

使用 AI 工具加速你的文档工作流程。

* [自动化文档更新](/zh/guides/automate-agent)：介绍如何使用智能体设置自动化文档更新的教程。
* [构建应用内助手](/zh/guides/assistant-embed)：介绍如何在 React 应用中添加 AI 聊天机器人，帮助用户从文档中查找答案的教程。
* [Claude Code](/zh/guides/claude-code)、[Cursor](/zh/guides/cursor)、[Windsurf](/zh/guides/windsurf)：介绍如何使用 AI 编码助手维护文档的指南。
* [GEO](/zh/guides/geo)：针对 AI 搜索和答案引擎优化文档的最佳实践。

<div id="api-documentation">
  ### API 文档
</div>

创建便于用户测试并了解如何使用你的 API，且易于维护的 API 文档。

* [从 MDX 迁移到 OAS](/zh/guides/migrating-from-mdx)：将你的 API 文档从单独的 MDX 页面迁移为基于 OpenAPI 规范自动生成的页面。

<div id="best-practices">
  ### 最佳实践
</div>

打造一流的文档体验。

* [无障碍访问](/zh/guides/accessibility)：尽可能让更多用户都能无障碍地使用你的文档。
* [内容类型](/zh/guides/content-types)：为教程、操作指南、参考资料和解释性内容选择合适的格式。
* [内容模板](/zh/guides/content-templates)：复制并修改各类内容的模板。
* [改进你的文档](/zh/guides/improving-docs)：利用数据和反馈持续改进文档。
* [国际化](/zh/guides/internationalization)：设置多语言文档，触达全球用户。
* [链接](/zh/guides/linking)：创建内部链接、引用 API 端点，并维护整个文档中的链接完整性。
* [维护](/zh/guides/maintenance)：让文档始终保持准确和最新。
* [媒体](/zh/guides/media)：高效添加图片、视频和其他媒体，同时降低维护负担。
* [组织导航](/zh/guides/navigation)：设计适合用户的信息架构。
* [SEO](/zh/guides/seo)：针对搜索引擎优化你的文档。
* [风格与语气](/zh/guides/style-and-tone)：以一致的风格和语气进行写作。
* [了解你的受众](/zh/guides/understand-your-audience)：研究并满足用户的需求与目标。

<div id="git-workflows">
  ### Git 工作流
</div>

了解 Git，才能充分发挥 Mintlify 和文档即代码这种文档方式的优势。

* [Git concepts](/zh/guides/git-concepts): 了解文档工作所需的 Git 基础概念。
* [Branches](/zh/guides/branches): 使用分支管理文档变更。

<div id="use-cases">
  ### 使用场景
</div>

了解 Mintlify 如何支持不同的使用场景，并找到适合你的解决方案。

* [创建开发者文档](/zh/guides/developer-documentation)：通过能够解答疑问并帮助用户快速回到主要任务的开发者文档，帮助用户充分发挥你的产品或 API 的价值。
* [创建知识库](/zh/guides/knowledge-base)：搭建内部知识库，集中整理团队信息、优化搜索体验，并减轻维护负担。
* [创建支持中心](/zh/guides/support-center)：构建自助式支持中心，帮助客户自行找到答案、减少工单数量，并提升客户满意度。
