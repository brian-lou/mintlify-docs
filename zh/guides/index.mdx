title: "指南"
description: "了解如何通过最佳实践和工作流程创建高效文档。"
---

本节中的指南提供了创建文档的建议，帮助你的用户取得成功。无论你是从零开始，还是在改进现有文档，这些指南都可以帮助你规划、撰写和维护文档。

最重要的是，要始终考虑用户的需求和目标。撰写能够帮助他们使用你的产品，并尽快回到其任务中的文档内容。

<div id="topics">
  ## 主题
</div>

<div id="ai-tools">
  ### AI 工具
</div>

使用 AI 驱动的工具加速你的文档工作流程。

* [自动化文档更新](/zh/guides/automate-agent)：教程介绍如何使用 agent 设置文档的自动更新。
* [构建应用内助手](/zh/guides/assistant-embed)：教程介绍如何在 React 应用中添加 AI 聊天机器人，帮助用户在你的文档中查找答案。
* [Claude Code](/zh/guides/claude-code)、[Cursor](/zh/guides/cursor)、[Windsurf](/zh/guides/windsurf)：使用 AI 编程助手维护文档的指南。
* [GEO](/zh/guides/geo)：为 AI 搜索和问答引擎优化文档的最佳实践。

<div id="api-documentation">
  ### API 文档
</div>

创建既便于用户测试和学习如何使用 API，又易于维护的 API 文档。

* [从 MDX 迁移到 OAS](/zh/guides/migrating-from-mdx)：将你的 API 文档从单独的 MDX 页面迁移为基于 OpenAPI 规范自动生成的页面。

<div id="best-practices">
  ### 最佳实践
</div>

让你的文档达到一流水准。

* [Accessibility](/zh/guides/accessibility)：确保尽可能多的用户都能无障碍地使用你的文档。
* [Content types](/zh/guides/content-types)：为教程、操作指南、参考文档和说明性文档选择合适的格式。
* [Content templates](/zh/guides/content-templates)：复制并修改每种内容类型对应的模板。
* [Improve your docs](/zh/guides/improving-docs)：利用数据和反馈持续改进你的文档。
* [Internationalization](/zh/guides/internationalization)：设置多语言文档，以覆盖全球用户。
* [Linking](/zh/guides/linking)：创建内部链接、引用 API 端点，并在整套文档中维护链接的完整性。
* [Maintenance](/zh/guides/maintenance)：保持你的文档准确、及时更新。
* [Media](/zh/guides/media)：在控制维护成本的前提下，高效添加图片、视频和其他媒体。
* [Organize navigation](/zh/guides/navigation)：设计符合用户使用习惯的信息架构。
* [SEO](/zh/guides/seo)：为搜索引擎优化你的文档。
* [Style and tone](/zh/guides/style-and-tone)：保持一致的文风和语气。
* [Understand your audience](/zh/guides/understand-your-audience)：了解并满足用户的需求和目标。

<div id="git-workflows">
  ### Git 工作流
</div>

了解 Git，充分发挥 Mintlify 和“文档即代码”（docs-as-code）方法的优势。

* [Git 概念](/zh/guides/git-concepts)：学习文档相关的 Git 基础知识。
* [分支](/zh/guides/branches)：使用分支来管理文档变更。

<div id="use-cases">
  ### 使用场景
</div>

了解 Mintlify 如何支持不同的使用场景，并找到适合你的解决方案。

* [创建开发者文档](/zh/guides/developer-documentation)：通过能解答问题、帮助用户专注于核心工作的开发者文档，帮助用户充分利用你的产品或 API。
* [创建知识库](/zh/guides/knowledge-base)：建立内部知识库，为团队整合信息、提升搜索效率，并减轻维护负担。
* [创建支持中心](/zh/guides/support-center)：搭建自助式支持中心，帮助客户快速找到答案，减少工单数量，并提升客户满意度。
