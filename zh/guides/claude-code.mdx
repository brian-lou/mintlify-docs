Claude Code 是一款具备代理能力的命令行工具，可帮助你维护文档。它可以编写新内容、审阅现有页面，并让文档始终保持最新。

你可以在项目中添加 `CLAUDE.md` 文件，并随着时间推移不断完善它，以训练 Claude Code 理解你的文档标准和工作流程。

<div id="getting-started">
  ## 开始使用
</div>

**先决条件：**

* 已开通 Claude 订阅 (Pro、Max 或 API 访问权限) 

**设置：**

1. 安装 Claude Code：

```bash
  npm install -g @anthropic-ai/claude-code
```

2. 进入你的文档目录。
3.  (可选) 将下面的 `CLAUDE.md` 文件添加到项目中。
4. 运行 `claude` 启动。


<div id="claudemd-template">
  ## CLAUDE.md 模板
</div>

将 `CLAUDE.md` 文件保存在文档目录的根目录下，帮助 Claude Code 理解你的项目。此文件可让 Claude Code 了解你的文档标准、偏好和工作流程。更多信息，请参阅 Anthropic 文档中的 [管理 Claude 的记忆](https://docs.anthropic.com/en/docs/claude-code/memory)。

复制此示例模板，或按你的文档规范进行修改：

```mdx
# Mintlify documentation

## 协作关系
- 你可以对想法提出异议——这有助于产出更好的文档。提出异议时请引用来源并说明理由
- 务必寻求澄清，而非自行假设
- 切勿撒谎、猜测或捏造任何内容

## 项目背景
- 格式：带有 YAML 前置元数据的 MDX 文件
- 配置：docs.json，用于导航、主题和设置
- 组件：Mintlify 组件

## 内容策略
- 文档内容以满足用户需求为准——不多不少
- 优先保证准确性和可用性
- 尽量使内容保持长期有效
- 添加新内容前先检索现有内容，除非出于策略考量，否则避免重复
- 参照现有规范保持一致性
- 从最小可行的改动开始

## docs.json

- 构建 docs.json 文件和站点导航时，请参考 [docs.json schema](https://mintlify.com/docs.json)

## 页面前置元数据要求
- title：清晰、具描述性的页面标题
- description：用于 SEO/导航的简洁摘要

## 写作规范
- 使用第二人称（"你"）
- 在操作性内容开头列出前提条件
- 发布前测试所有代码示例
- 与现有页面的风格和格式保持一致
- 同时涵盖基础和高级用例
- 所有代码块添加语言标签
- 所有图片添加替代文本
- 内部链接使用相对路径

## Git 工作流
- 提交时切勿使用 --no-verify
- 开始前询问如何处理未提交的更改
- 若没有明确的分支用于变更，则创建新分支
- 开发过程中频繁提交
- 切勿跳过或禁用 pre-commit 钩子

## 禁止事项
- 在任何 MDX 文件中省略前置元数据
- 对内部链接使用绝对 URL
- 包含未经测试的代码示例
- 自行假设——务必寻求澄清
```

<div id="extending-claude-code">
  ## 扩展 Claude Code
</div>

除了手动向 Claude Code 输入提示外，你还可以将其集成到现有工作流程中。

<div id="automation-with-github-actions">
  ### 使用 GitHub Actions 实现自动化
</div>

在代码发生变更时自动运行 Claude Code，确保文档保持最新。你可以在拉取请求中触发文档审查，或在检测到 API 变更时更新示例。

<div id="multi-instance-workflows">
  ### 多会话工作流程
</div>

针对不同任务使用独立的 Claude Code 会话——一个用于编写新内容，另一个用于审查和质量保证。这样有助于保持一致性，并发现单个会话可能遗漏的问题。

<div id="team-collaboration">
  ### 团队协作
</div>

与团队共享你完善后的 `CLAUDE.md` 文件，确保所有贡献者遵循一致的文档标准。团队通常会逐步形成项目专属的提示词和工作流程，并将其纳入文档编写流程。

<div id="custom-commands">
  ### 自定义命令
</div>

在 `.claude/commands/` 中创建可复用的斜杠命令，用于处理项目或团队中常用的文档任务。
