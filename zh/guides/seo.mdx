<div id="content-basics">
  ## 内容基础
</div>

让你的内容和结构便于搜索引擎快速扫描和理解。

* **标题和副标题：** 使用有层级且有意义的标题来组织内容。每个页面都会根据 frontmatter 中的 `title:` 属性生成一个 H1。
* **短段落和列表：** 将大段文字拆分成易于阅读的部分。在合适的地方使用项目符号和编号列表。
* **内部链接：** 使用具有描述性的链接文本指向相关内容。例如，将 “Learn more about rate limiting” 用作链接文本，而不是 “Click here.”。

<div id="technical-seo-basics">
  ## 技术 SEO 基础
</div>

在优化完内容之后，还要确保你的文档在技术层面也有良好表现。

这些基础的技术 SEO 做法有助于让你的文档更易被发现：

* **Meta 标签和描述：** 为每个页面撰写符合 SEO 要求的标题（50–60 个字符）和描述（150–160 个字符）。大多数 [meta 标签](/zh/optimize/seo) 都会自动生成。
* **图片的 alt 文本：** 为图片提供包含相关关键词的描述性 alt 文本。例如，用「OAuth 2.0 API authentication flow」而不是只写「diagram」。这可以提升 SEO 和可访问性。
* **站点地图（Sitemaps）：** 确保你的站点地图是最新的。Mintlify 会自动生成站点地图。不过，如果你需要自定义格式，也可以手动创建站点地图。创建后，搜索引擎会随着时间对站点地图进行索引，但你也可以将站点地图直接提交到 Google Search Console 来加快这一过程。

<div id="page-performance">
  ## 页面性能
</div>

使用 [Google PageSpeed Insights](https://pagespeed.web.dev) 等工具来识别可改进的技术 SEO 环节。

更高级优化示例：

* **为提升加载速度优化媒体：** 使用 WebP 或 AVIF 等格式压缩图片，并确保页面加载迅速（理想情况下在 3 秒以内）。
* **结构化数据（Schema 标记）：** 在页面中添加 Schema 标记（如 HowTo、FAQ），帮助搜索引擎更好地理解你的内容并对其进行排名。

<div id="keyword-research">
  ## 关键词研究
</div>

要提升自然搜索流量，需要投入时间去了解哪些关键词能帮助用户访问你的文档。

* **关键词研究：** 使用免费的工具，例如 [Google Keyword Planner](https://ads.google.com/intl/en_us/home/tools/keyword-planner/) 或 [Keywords Everywhere](https://keywordseverywhere.com) 来发掘常见短语或长尾关键词。
* **自然地融入关键词：** 将关键词自然地加入到标题、副标题以及正文内容中，不要刻意堆砌。你的文档应该是为用户而写，而不是为搜索引擎而写。
