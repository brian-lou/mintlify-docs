<div id="content-basics">
  ## 内容基础
</div>

让你的写作和内容结构便于搜索引擎快速浏览。

* **标题和副标题：** 使用有意义且层级清晰的标题来组织内容。每个页面都有一个根据前置元数据中的 `title:` 属性生成的 H1。
* **短段落和项目符号：** 将大段文字拆分为便于阅读的部分。适当使用项目符号列表和编号列表。
* **内部链接：** 使用具有描述性的锚文本链接到相关内容。例如，使用“详细了解速率限制”而不是“点击这里”。

<div id="technical-seo-basics">
  ## 技术 SEO 基础
</div>

内容优化完成后，还要确保你的文档在技术层面同样表现良好。

以下这些基础的技术 SEO 做法有助于提升文档的可发现性：

* **Meta 标签和描述：** 为每个页面编写利于 SEO 的标题 (50-60 个字符) 和描述 (150-160 个字符) 。大多数 [meta 标签](/zh/optimize/seo) 都会自动生成。
* **图片的 alt 文本：** 为图片提供包含相关关键词的描述性 alt 文本。例如，使用“OAuth 2.0 API authentication flow”，而不只是“diagram”。这有助于提升 SEO 效果和无障碍访问体验。
* **站点地图：** 确保你的站点地图保持最新。Mintlify 会自动生成站点地图。不过，如果你想使用自定义格式，也可以手动创建站点地图。创建后，搜索引擎会逐步索引站点地图；你也可以直接将站点地图提交到 Google Search Console，以加快这一过程。

<div id="page-performance">
  ## 页面性能
</div>

使用 [Google PageSpeed Insights](https://pagespeed.web.dev) 等工具，找出技术 SEO 方面可优化的地方。

更高级的优化示例：

* **优化媒体资源以提升速度：** 使用 WebP 或 AVIF 等格式压缩图片，并确保页面加载足够快 (最好控制在 3 秒以内) 。
* **结构化数据 (schema markup) ：** 在页面中添加 schema 标记 (如 HowTo、FAQ) ，帮助搜索引擎更好地理解你的内容并提升排名。

<div id="keyword-research">
  ## 关键词研究
</div>

为了提升自然流量，花些时间了解哪些关键词能帮助用户找到你的文档。

* **关键词研究：**使用 [Google Keyword Planner](https://ads.google.com/intl/en_us/home/tools/keyword-planner/) 或 [Keywords Everywhere](https://keywordseverywhere.com) 等免费工具，找出常见短语和长尾关键词。
* **自然融入关键词：**将关键词自然地加入标题、小标题和正文中。不要过度堆砌关键词。文档应当写给用户看，而不是写给搜索引擎看。
