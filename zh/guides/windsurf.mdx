通过工作区规则和记忆功能，将 Windsurf 打造成一名熟悉你的风格指南、组件和项目上下文的文档专家。

<div id="use-windsurf-with-mintlify">
  ## 将 Windsurf 与 Mintlify 结合使用
</div>

Windsurf 的 Cascade AI 助手可进行调校，借助 Mintlify 组件按照你的标准编写文档。工作区规则和记忆可为你的项目提供持续性的上下文，从而让 Cascade 给出更一致的建议。

* **工作区规则** 存储在你的文档仓库中，并与你的团队共享。
* **记忆** 提供会随着时间逐渐积累的个人上下文。

我们建议为团队共用的文档标准设置工作区规则。你可以在工作过程中逐步积累记忆，但由于这些记忆不会共享，因此团队成员之间的结果不会保持一致。

请在文档仓库的 `.windsurf/rules` 目录中创建工作区规则。更多信息，请参阅 Windsurf 文档中的 [Memories &amp; Rules](https://docs.windsurf.com/windsurf/cascade/memories)。

<div id="example-workspace-rule">
  ## 示例工作区规则
</div>

此规则为 Cascade 提供有关 Mintlify 组件和通用技术写作最佳实践的上下文信息。

你可以直接使用此示例规则，也可以根据你的文档进行自定义：

* **写作标准**：更新语言指南，使其符合你的风格指南。
* **组件模式**：添加项目专用组件，或修改现有示例。
* **代码示例**：将通用示例替换为与你产品相关的真实 API 调用和响应。
* **风格和语气偏好**：调整术语、格式和其他规则。

将规则保存为文档仓库 `.windsurf/rules` 目录中的 `.md` 文件。

````mdx
# Mintlify 技术写作规范

## 项目背景

- 这是一个基于 Mintlify 平台的文档项目
- 我们使用带有 YAML 前置元数据的 MDX 文件
- 导航结构在 `docs.json` 中配置
- 我们遵循技术写作最佳实践

## 写作规范

- 使用第二人称（"你"）撰写操作说明
- 使用主动语态和现在时
- 在步骤说明前列出前提条件
- 为主要步骤说明预期结果
- 使用描述性强、富含关键词的标题
- 保持句子简洁且信息充分

## 页面必要结构

每个页面必须以前置元数据开头：

```yaml
---
title: "Clear, specific title"
description: "Concise description for SEO and navigation"
---
```

## Mintlify 组件

### docs.json

- 构建 docs.json 文件和站点导航时，请参阅 [docs.json schema](https://mintlify.com/docs.json)

### 提示框

- `<Note>` 用于有用的补充信息
- `<Warning>` 用于重要警告和破坏性变更
- `<Tip>` 用于最佳实践和专家建议
- `<Info>` 用于中性的背景信息
- `<Check>` 用于成功确认

### 代码示例

- 在适当情况下，提供完整且可运行的示例
- 使用 `<CodeGroup>` 展示多语言示例
- 为所有代码块指定语言标签
- 使用真实数据，而非占位符
- 在 API 文档中使用 `<RequestExample>` 和 `<ResponseExample>`

### 操作步骤

- 使用 `<Steps>` 组件呈现顺序操作说明
- 在适当时使用 `<Check>` 组件添加验证步骤
- 将复杂流程拆分为更小的步骤

### 内容组织

- 使用 `<Tabs>` 呈现特定平台的内容
- 使用 `<Accordion>` 实现渐进式展开
- 使用 `<Card>` 和 `<CardGroup>` 突出显示内容
- 将图片包裹在 `<Frame>` 组件中，并添加描述性替代文本

## API 文档要求

- 使用 `<ParamField>` 记录所有参数
- 使用 `<ResponseField>` 展示响应结构
- 同时提供成功和错误示例
- 使用 `<Expandable>` 展示嵌套对象属性
- 始终包含身份验证示例

## 质量标准

- 发布前测试所有代码示例
- 内部链接使用相对路径
- 为所有图片添加替代文本
- 确保标题层级正确（从 h2 开始）
- 参照现有模式保持一致性
````

<div id="working-with-cascade">
  ## 使用 Cascade
</div>

规则设置完成后，你可以使用 Cascade 协助处理各种文档任务。更多信息，请参阅 Windsurf 文档中的 [Cascade](https://docs.windsurf.com/windsurf/cascade)。

<div id="example-prompts">
  ### 示例提示词
</div>

**撰写新内容**：

```text wrap
创建一个新页面，说明如何通过我们的 API 进行身份验证。包含 JavaScript、Python 和 cURL 的代码示例。
```

**优化现有内容**：

```text wrap
审阅此页面并提出关于清晰度和组件使用的改进建议。重点让步骤更易于理解。
```

**创建代码示例**：

```text wrap
Generate a complete code example showing error handling for this API endpoint. Use realistic data and include expected responses.
```

**保持一致**：

```text wrap
Check if this new page follows our documentation standards and suggest any needed changes.
```

<div id="enhance-with-mcp-server">
  ## 通过 MCP 服务器增强功能
</div>

将 Mintlify MCP 服务器连接到 Windsurf，让 Cascade 在协助你编写内容时可以搜索 Mintlify 文档。连接 MCP 服务器后，Cascade 会搜索最新的 Mintlify 文档来获取上下文，因此你无需离开 IDE 即可查阅文档。

完整的设置说明请参阅 [Model Context Protocol](/zh/ai/model-context-protocol#example%3A-connect-to-the-mintlify-mcp-server)。
