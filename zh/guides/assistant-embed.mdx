<div id="what-you-will-build">
  ## 你将构建的内容
</div>

一个可复用的小部件，可将[助手](/zh/ai/assistant)直接嵌入你的应用中。该小部件提供：

* 一个悬浮按钮，点击后可打开聊天面板
* 基于你的文档内容进行实时流式响应
* 支持 Markdown 的消息渲染

用户无需离开你的应用，即可通过该小部件获取产品相关帮助。

</Frame>

<div id="prerequisites">
  ## 前置条件
</div>

* [Mintlify Pro 或 Enterprise 计划](https://mintlify.com/pricing)
* 您的域名，即显示在仪表板 URL 末尾的名称。例如，如果您的仪表板 URL 是 `https://dashboard.mintlify.com/org-name/domain-name`，则您的域名是 `domain-name`
* 一个[助手 API 密钥](https://dashboard.mintlify.com/settings/organization/api-keys)
* 已安装 Node.js v18 或更高版本及 npm
* 具备基本的 React 知识

<div id="get-your-assistant-api-key">
  ### 获取助手 API 密钥
</div>

1. 前往控制台中的 [API keys](https://dashboard.mintlify.com/settings/organization/api-keys) 页面。
2. 点击 **Create Assistant API Key**。
3. 复制助手 API 密钥 (以 `mint_dsc_` 开头) 并妥善保管。

<Note>
  助手 API 密钥是可在前端代码中使用的公开令牌。使用此令牌发起的调用会计入你的套餐消息额度，并且可能产生超额费用。
</Note>

<div id="set-up-the-example">
  ## 设置示例
</div>

克隆[示例仓库](https://github.com/mintlify/assistant-embed-example)，并根据你的需求进行定制。

<Steps>
  <Step title="克隆仓库">
    ```bash
    git clone https://github.com/mintlify/assistant-embed-example.git
    cd assistant-embed-example
    ```
  </Step>

  <Step title="选择开发工具">
    该仓库包含 Next.js 和 Vite 示例。选择你想使用的工具。

    <CodeGroup>
      ```bash title="Next.js"
      cd nextjs
      npm install
      ```

      ```bash title="Vite"
      cd vite
      npm install
      ```
    </CodeGroup>
  </Step>

  <Step title="配置项目">
    打开 `src/config.js`，填入你的 Mintlify 项目信息。

    ```js src/config.js
    export const ASSISTANT_CONFIG = {
      domain: 'your-domain',
      docsURL: 'https://yourdocs.mintlify.app',
    };
    ```

    替换：

    * 将 `your-domain` 替换为你的 Mintlify 项目域名，可在控制台 URL 的末尾找到。
    * 将 `https://yourdocs.mintlify.app` 替换为你的实际文档 URL。
  </Step>

  <Step title="添加 API token">
    在项目根目录创建一个 `.env` 文件。

    ```bash .env
    VITE_MINTLIFY_TOKEN=mint_dsc_your_token_here
    ```

    将 `mint_dsc_your_token_here` 替换为你的 助手 API 密钥。
  </Step>

  <Step title="启动开发服务器">
    ```bash
    npm run dev
    ```

    在浏览器中打开你的应用，然后点击 **Ask** 按钮以打开 助手 小部件。
  </Step>
</Steps>

<div id="source-citations">
  ### 来源引用
</div>

从助手回复中提取并显示来源：

```jsx
const extractSources = (parts) => {
  return parts
    ?.filter(p => p.type === 'tool-invocation' && p.toolInvocation?.toolName === 'search')
    .flatMap(p => p.toolInvocation?.result || [])
    .map(source => ({
      url: source.url || source.path,
      title: source.metadata?.title || source.path,
    })) || [];
};

// 在消息渲染中：
{messages.map((message) => {
  const sources = message.role === 'assistant' ? extractSources(message.parts) : [];
  return (
    <div key={message.id}>
      {/* 消息内容 */}
      {sources.length > 0 && (
        <div className="mt-2 text-xs">
          <p className="font-semibold">Sources:</p>
          {sources.map((s, i) => (
            <a key={i} href={s.url} target="_blank" rel="noopener noreferrer" className="text-blue-600">
              {s.title}
            </a>
          ))}
        </div>
      )}
    </div>
  );
})}
```

<div id="track-conversation-thread-ids">
  ### 跟踪对话线程 ID
</div>

存储线程 ID，以便在不同会话之间保留对话历史：

```jsx
import { useState, useEffect } from 'react';

export function AssistantWidget({ domain, docsURL }) {
  const [threadId, setThreadId] = useState(null);

  useEffect(() => {
    // 从 localStorage 中获取已保存的线程 ID
    const saved = localStorage.getItem('assistant-thread-id');
    if (saved) {
      setThreadId(saved);
    }
  }, []);

  const { messages, input, handleInputChange, handleSubmit, isLoading } = useChat({
    api: `https://api.mintlify.com/discovery/v1/assistant/${domain}/message`,
    headers: {
      'Authorization': `Bearer ${import.meta.env.VITE_MINTLIFY_TOKEN}`,
    },
    body: {
      fp: 'anonymous',
      retrievalPageSize: 5,
      ...(threadId && { threadId }), // 如果存在线程 ID 则包含它
    },
    streamProtocol: 'data',
    sendExtraMessageFields: true,
    fetch: async (url, options) => {
      const response = await fetch(url, options);
      const newThreadId = response.headers.get('x-thread-id');
      if (newThreadId) {
        setThreadId(newThreadId);
        localStorage.setItem('assistant-thread-id', newThreadId);
      }
      return response;
    },
  });

  // ... 组件其余部分
}
```

<div id="add-keyboard-shortcuts">
  ### 添加键盘快捷键
</div>

让用户可以通过键盘快捷键打开小部件并发送消息：

```jsx
useEffect(() => {
  const handleKeyDown = (e) => {
    // Cmd/Ctrl + Shift + I 切换小部件
    if ((e.metaKey || e.ctrlKey) && e.shiftKey && e.key === 'I') {
      e.preventDefault();
      setIsOpen((prev) => !prev);
    }

    // Enter（当小部件获得焦点时）提交
    if (e.key === 'Enter' && !e.shiftKey && document.activeElement.id === 'assistant-input') {
      e.preventDefault();
      handleSubmit();
    }
  };

  window.addEventListener('keydown', handleKeyDown);
  return () => window.removeEventListener('keydown', handleKeyDown);
}, [handleSubmit]);
```
