<div id="what-you-will-build">
  ## 你将构建的内容
</div>

一个可复用的组件，将 [assistant](/zh/ai/assistant) 直接嵌入到你的应用中。该组件提供：

* 一个浮动按钮，点击后会打开聊天面板
* 基于你文档内容的实时流式回答
* 支持 Markdown 的消息渲染

用户可以通过该组件在不离开你的应用的情况下，获取使用你产品的帮助。

<div id="prerequisites">
  ## 前提条件
</div>

* [Mintlify Pro 或 Enterprise 计划](https://mintlify.com/pricing)
* 你的域名，它会出现在仪表盘 URL 的末尾。例如，如果你的仪表盘 URL 是 `https://dashboard.mintlify.com/org-name/domain-name`，你的域名就是 `domain-name`
* 一个 [助手 API 密钥](https://dashboard.mintlify.com/settings/organization/api-keys)
* 已安装 Node.js v18 或更高版本以及 npm
* 基本的 React 知识

<div id="get-your-assistant-api-key">
  ### 获取你的 Assistant API 密钥
</div>

1. 在控制台中前往 [API keys](https://dashboard.mintlify.com/settings/organization/api-keys) 页面。
2. 点击 **Create Assistant API Key**。
3. 复制 Assistant API 密钥（以 `mint_dsc_` 开头）并妥善保存。

<Note>
  Assistant API 密钥是一个可以在前端代码中使用的公开令牌。使用此令牌发起的调用将计入你套餐的消息配额，并且可能产生超额费用。
</Note>

<div id="set-up-the-example">
  ## 设置示例项目
</div>

克隆[示例仓库](https://github.com/mintlify/assistant-embed-example)，并根据你的需求进行自定义。

<Steps>
  <Step title="克隆仓库">
    ```bash
    git clone https://github.com/mintlify/assistant-embed-example.git
    cd assistant-embed-example
    ```
  </Step>

  <Step title="选择开发工具">
    该仓库提供了 Next.js 和 Vite 的示例项目，可按你的习惯选择其一。

    <CodeGroup>
      ```bash title="Next.js"
      cd nextjs
      npm install
      ```

      ```bash title="Vite"
      cd vite
      npm install
      ```
    </CodeGroup>
  </Step>

  <Step title="配置项目">
    打开 `src/config.js`，并填入你的 Mintlify 项目信息。

    ```js src/config.js
    export const ASSISTANT_CONFIG = {
      domain: 'your-domain',
      docsURL: 'https://yourdocs.mintlify.app',
    };
    ```

    将以下内容替换为：

    * `your-domain`：替换为你在控制台 URL 末尾看到的 Mintlify 项目域名。
    * `https://yourdocs.mintlify.app`：替换为你的实际文档地址。
  </Step>

  <Step title="添加 API 令牌">
    在项目根目录创建一个 `.env` 文件。

    ```bash .env
    VITE_MINTLIFY_TOKEN=mint_dsc_your_token_here
    ```

    将 `mint_dsc_your_token_here` 替换为你的 Assistant API 密钥。
  </Step>

  <Step title="启动开发服务器">
    ```bash
    npm run dev
    ```

    在浏览器中打开你的应用，并点击 **Ask** 按钮以打开助手组件。
  </Step>
</Steps>

<div id="source-citations">
  ### 引用来源
</div>

从助手的回复中提取并展示引用来源：

```jsx
const extractSources = (parts) => {
  return parts
    ?.filter(p => p.type === 'tool-invocation' && p.toolInvocation?.toolName === 'search')
    .flatMap(p => p.toolInvocation?.result || [])
    .map(source => ({
      url: source.url || source.path,
      title: source.metadata?.title || source.path,
    })) || [];
};

// 在您的消息渲染中：
{messages.map((message) => {
  const sources = message.role === 'assistant' ? extractSources(message.parts) : [];
  return (
    <div key={message.id}>
      {/* 消息内容 */}
      {sources.length > 0 && (
        <div className="mt-2 text-xs">
          <p className="font-semibold">来源：</p>
          {sources.map((s, i) => (
            <a key={i} href={s.url} target="_blank" rel="noopener noreferrer" className="text-blue-600">
              {s.title}
            </a>
          ))}
        </div>
      )}
    </div>
  );
})}
```

<div id="track-conversation-thread-ids">
  ### 跟踪对话线程 ID
</div>

保存线程 ID，以在不同会话间保留对话历史：

```jsx
import { useState, useEffect } from 'react';

export function AssistantWidget({ domain, docsURL }) {
  const [threadId, setThreadId] = useState(null);

  useEffect(() => {
    // 从 localStorage 中获取已保存的线程 ID
    const saved = localStorage.getItem('assistant-thread-id');
    if (saved) {
      setThreadId(saved);
    }
  }, []);

  const { messages, input, handleInputChange, handleSubmit, isLoading } = useChat({
    api: `https://api.mintlify.com/discovery/v1/assistant/${domain}/message`,
    headers: {
      'Authorization': `Bearer ${import.meta.env.VITE_MINTLIFY_TOKEN}`,
    },
    body: {
      fp: 'anonymous',
      retrievalPageSize: 5,
      ...(threadId && { threadId }), // 如果存在线程 ID，则将其包含在内
    },
    streamProtocol: 'data',
    sendExtraMessageFields: true,
    fetch: async (url, options) => {
      const response = await fetch(url, options);
      const newThreadId = response.headers.get('x-thread-id');
      if (newThreadId) {
        setThreadId(newThreadId);
        localStorage.setItem('assistant-thread-id', newThreadId);
      }
      return response;
    },
  });

  // ... 组件的其余部分
}
```

<div id="add-keyboard-shortcuts">
  ### 添加键盘快捷键
</div>

允许用户使用键盘快捷键打开小组件并发送消息：

```jsx
useEffect(() => {
  const handleKeyDown = (e) => {
    // Cmd/Ctrl + Shift + I 切换小组件
    if ((e.metaKey || e.ctrlKey) && e.shiftKey && e.key === 'I') {
      e.preventDefault();
      setIsOpen((prev) => !prev);
    }

    // 按 Enter 键（小组件获得焦点时）提交
    if (e.key === 'Enter' && !e.shiftKey && document.activeElement.id === 'assistant-input') {
      e.preventDefault();
      handleSubmit();
    }
  };

  window.addEventListener('keydown', handleKeyDown);
  return () => window.removeEventListener('keydown', handleKeyDown);
}, [handleSubmit]);
```
