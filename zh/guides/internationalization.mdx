国际化（i18n）是指将软件或内容设计为适配不同语言和区域的过程。本指南将介绍如何组织文件结构、配置导航以及高效维护翻译内容，从而帮助用户以其偏好的语言访问你的文档，并提升全球覆盖范围。

<div id="file-structure">
  ## 文件结构
</div>

将翻译内容按语言分别组织在对应目录中，以便文档易于维护，并按语言来构建导航结构。

为每种语言使用 [ISO 639-1 语言代码](https://en.wikipedia.org/wiki/List_of_ISO_639-1_codes)创建一个单独的目录。将翻译后的文件放入这些目录中，并保持与默认语言相同的结构。

<Expandable title="支持的语言代码">
  * `ar` - 阿拉伯语
  * `cs` - 捷克语
  * `cn` or `zh-Hans` - 中文（简体）
  * `zh-Hant` - 中文（繁体）
  * `de` - 德语
  * `en` - 英语
  * `es` - 西班牙语
  * `fr` - 法语
  * `he` - 希伯来语
  * `hi` - 印地语
  * `id` - 印度尼西亚语
  * `it` - 意大利语
  * `jp` - 日语
  * `ko` - 韩语
  * `lv` - 拉脱维亚语
  * `nl` - 荷兰语
  * `no` - 挪威语
  * `pl` - 波兰语
  * `pt` or `pt-BR` - 葡萄牙语
  * `ro` - 罗马尼亚语
  * `ru` - 俄语
  * `sv` - 瑞典语
  * `tr` - 土耳其语
  * `ua` - 乌克兰语
  * `uz` - 乌兹别克语
  * `vi` - 越南语
</Expandable>

```text Example file structure
docs/
├── index.mdx                    # 英语（默认）
├── quickstart.mdx
├── fr/
│   ├── index.mdx               # 法语
│   ├── quickstart.mdx
├── es/
│   ├── index.mdx               # 西班牙语
│   ├── quickstart.mdx
└── zh/
    ├── index.mdx               # 中文
    └── quickstart.mdx
```

<Tip>
  在所有语言中保持相同的文件名和目录结构。这样更方便维护各语言版本并发现遗漏的内容。
</Tip>


<div id="configure-the-language-switcher">
  ## 配置语言切换器
</div>

要在文档中添加语言切换器，请在 `docs.json` 的导航配置中设置 `languages` 数组。

```json docs.json
{
  "navigation": {
    "languages": [
      {
        "language": "en",
        "groups": [
          {
            "group": "Getting started",
            "pages": ["index", "quickstart"]
          }
        ]
      },
      {
        "language": "es",
        "groups": [
          {
            "group": "Comenzando",
            "pages": ["es/index", "es/quickstart"]
          }
        ]
      }
    ]
  }
}
```

`languages` 数组中的每个语言项都需要：

* `language`：ISO 639-1 语言代码
* 完整的导航结构
* 已翻译文件的路径

为了适应特定语言的内容需求，不同语言的导航结构可以有所不同。


<div id="set-default-language">
  ### 设置默认语言
</div>

`languages` 数组中的第一个语言会自动用作默认语言。若要使用其他语言作为默认语言，可以重新排列该数组，或者添加 `default` 属性：

```json docs.json
{
  "navigation": {
    "languages": [
      {
        "language": "es",
        "groups": [...]
      },
      {
        "language": "en",
        "groups": [...]
      }
    ]
  }
}
```

或者，使用 `default` 属性来调整顺序：

```json docs.json
{
  "navigation": {
    "languages": [
      {
        "language": "en",
        "groups": [...]
      },
      {
        "language": "es",
        "default": true,
        "groups": [...]
      }
    ]
  }
}
```


<div id="single-language-documentation">
  ### 单一语言文档
</div>

如果你只想提供一种语言且不需要语言切换器，请从导航配置中删除 `languages` 字段。然后，直接定义你的导航结构：

```json docs.json
{
  "navigation": {
    "tabs": [
      {
        "tab": "Documentation",
        "groups": [
          {
            "group": "Getting started",
            "pages": ["index", "quickstart"]
          }
        ]
      }
    ]
  }
}
```

这会仅以单一语言显示你的文档，并且不会显示语言切换器界面。

<Tip>
  将导航标签（例如分组名称或选项卡名称）翻译为与内容语言一致。这样可以为用户提供完全本地化的体验。
</Tip>


<div id="global-navigation">
  ### 全局导航
</div>

要添加在所有语言版本中显示的全局导航元素，请在你的 `docs.json` 导航配置中设置 `global` 对象。

```json docs.json
{
  "navigation": {
    "global": {
      "anchors": [
        {
          "anchor": "Documentation",
          "href": "https://example.com/docs"
        },
        {
          "anchor": "Blog",
          "href": "https://example.com/blog"
        }
      ]
    },
    "languages": [
      // 各语言的导航配置
    ]
  }
}
```


<div id="maintain-translations">
  ## 维护翻译
</div>

确保译文准确无误，并与源内容保持同步。

<div id="translation-workflow">
  ### 翻译工作流程
</div>

1. 更新主要语言版本的源内容。
2. 找出已更改的内容。
3. 翻译已更改的内容。
4. 审核翻译是否准确。
5. 更新翻译文件。
6. 检查导航和链接是否正常工作。

<div id="images-and-media">
  ### 图像和媒体
</div>

将已翻译的图像存放在对应语言的目录中。

```
images/
├── dashboard.png          # 英文版本
├── fr/
│   └── dashboard.png     # 法文版本
└── es/
    └── dashboard.png     # 西班牙文版本
```

在译文内容中使用相对路径来引用图片。

```mdx es/index.mdx
![Captura de pantalla del panel de control](/images/es/dashboard.png)
```

<div id="best-practices">
  ## 最佳实践
</div>

<div id="date-and-number-formats">
  ### 日期和数字格式
</div>

考虑适应不同语言环境的日期和数字格式。

- 日期格式：MM/DD/YYYY 与 DD/MM/YYYY
- 数字格式：1,000.00 与 1.000,00
- 货币符号：$100.00 与 100,00€

为每种语言使用符合其习惯的示例格式，或使用普遍易懂的通用格式。

<div id="maintain-consistency">
  ### 保持一致性
</div>

- 在所有语言中保持内容对等，确保每位用户都能获得同样高质量的信息。
- 为技术术语创建翻译术语表。
- 在不同语言中保持相同的内容结构。
- 保持与源内容一致的语气和风格。
- 使用 Git 分支将翻译工作与主内容更新分开管理。

<div id="layout-differences">
  ### 布局差异
</div>

有些语言占用的空间可能比英语多或少。请在不同屏幕尺寸下测试你的已翻译内容，以确保：

- 导航栏能正常显示。
- 代码块不会溢出。
- 表格和其他格式化文本保持良好的可读性。
- 图像能适当缩放。

<div id="character-encoding">
  ### 字符编码
</div>

请确保你的开发环境和部署流程支持 UTF-8 编码，以便正确显示包含不同字母表和特殊字符的各类语言中的所有字符。
