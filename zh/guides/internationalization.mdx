国际化 (i18n) 是指在设计软件或内容时，使其能够适配不同语言和区域设置的过程。本指南将介绍如何组织文件结构、配置导航，以及高效维护翻译内容，帮助用户使用自己偏好的语言访问文档，并扩大你的全球影响力。

<div id="file-structure">
  ## 文件结构
</div>

按语言将翻译内容分别组织到对应的目录中，这样更便于维护文档，也能按语言组织导航结构。

使用 [ISO 639-1 language codes](https://en.wikipedia.org/wiki/List_of_ISO_639-1_codes) 为每种语言创建单独的目录。将翻译后的文件按与默认语言相同的结构放入这些目录中。

<Expandable title="支持的语言代码">
  * `ar` - 阿拉伯语
  * `cs` - 捷克语
  * `cn` or `zh-Hans` - 中文 (简体) 
  * `zh-Hant` - 中文 (繁体) 
  * `de` - 德语
  * `en` - 英语
  * `es` - 西班牙语
  * `fr` - 法语
  * `he` - 希伯来语
  * `hi` - 印地语
  * `id` - 印度尼西亚语
  * `it` - 意大利语
  * `jp` - 日语
  * `ko` - 韩语
  * `lv` - 拉脱维亚语
  * `nl` - 荷兰语
  * `no` - 挪威语
  * `pl` - 波兰语
  * `pt` or `pt-BR` - 葡萄牙语
  * `ro` - 罗马尼亚语
  * `ru` - 俄语
  * `sv` - 瑞典语
  * `tr` - 土耳其语
  * `ua` - 乌克兰语
  * `uz` - 乌兹别克语
  * `vi` - 越南语
</Expandable>

```text Example file structure
docs/
├── index.mdx                    # 英语（默认）
├── quickstart.mdx
├── fr/
│   ├── index.mdx               # 法语
│   ├── quickstart.mdx
├── es/
│   ├── index.mdx               # 西班牙语
│   ├── quickstart.mdx
└── zh/
    ├── index.mdx               # 中文
    └── quickstart.mdx
```

<Tip>
  在所有语言版本中保持一致的文件名和目录结构。这样更便于维护译文并找出缺失的内容。
</Tip>


<div id="configure-the-language-switcher">
  ## 配置语言切换器
</div>

如需为文档添加语言切换器，请在 `docs.json` 的导航配置中设置 `languages` 数组。

```json docs.json
{
  "navigation": {
    "languages": [
      {
        "language": "en",
        "groups": [
          {
            "group": "Getting started",
            "pages": ["index", "quickstart"]
          }
        ]
      },
      {
        "language": "es",
        "groups": [
          {
            "group": "Comenzando",
            "pages": ["es/index", "es/quickstart"]
          }
        ]
      }
    ]
  }
}
```

`languages` 数组中的每个语言条目都需要包含：

* `language`：ISO 639-1 语言代码
* 完整的导航结构
* 已翻译文件的路径

导航结构可以因语言不同而有所差异，以适应各语言的内容需求。


<div id="set-default-language">
  ### 设置默认语言
</div>

`languages` 数组中的第一种语言会自动作为默认语言使用。若要将其他语言设为默认语言，可以调整数组顺序，或添加 `default` 属性：

```json docs.json
{
  "navigation": {
    "languages": [
      {
        "language": "es",
        "groups": [...]
      },
      {
        "language": "en",
        "groups": [...]
      }
    ]
  }
}
```

或者，使用 `default` 属性来调整顺序：

```json docs.json
{
  "navigation": {
    "languages": [
      {
        "language": "en",
        "groups": [...]
      },
      {
        "language": "es",
        "default": true,
        "groups": [...]
      }
    ]
  }
}
```


<div id="single-language-documentation">
  ### 单语言文档
</div>

如果你只想提供一种语言且不显示语言切换器，请从导航配置中移除 `languages` 字段，然后直接定义导航结构：

```json docs.json
{
  "navigation": {
    "tabs": [
      {
        "tab": "Documentation",
        "groups": [
          {
            "group": "Getting started",
            "pages": ["index", "quickstart"]
          }
        ]
      }
    ]
  }
}
```

这会以单一语言显示你的文档，不显示语言切换器界面。

<Tip>
  将分组名称、标签页名称等导航标签翻译成与内容语言一致的文本。这样可为用户提供完全本地化的体验。
</Tip>


<div id="global-navigation">
  ### 全局导航
</div>

如需添加在所有语言版本中都会显示的全局导航元素，请在 `docs.json` 的导航配置中设置 `global` 对象。

```json docs.json
{
  "navigation": {
    "global": {
      "anchors": [
        {
          "anchor": "Documentation",
          "href": "https://example.com/docs"
        },
        {
          "anchor": "Blog",
          "href": "https://example.com/blog"
        }
      ]
    },
    "languages": [
      // 各语言的导航配置
    ]
  }
}
```


<div id="maintain-translations">
  ## 维护译文
</div>

确保译文准确，并与源内容保持同步。

<div id="translation-workflow">
  ### 翻译工作流程
</div>

1. 使用主要语言更新源内容。
2. 找出已更改的内容。
3. 翻译已更改的内容。
4. 检查翻译是否准确。
5. 更新译文文件。
6. 确认导航和链接正常可用。

<div id="images-and-media">
  ### 图片和媒体
</div>

将翻译后的图片存放在对应语言的目录中。

```
images/
├── dashboard.png          # 英语版本
├── fr/
│   └── dashboard.png     # 法语版本
└── es/
    └── dashboard.png     # 西班牙语版本
```

在译文中使用相对路径引用图片。

```mdx es/index.mdx
![Captura de pantalla del panel de control](/images/es/dashboard.png)
```

<div id="best-practices">
  ## 最佳实践
</div>

<div id="date-and-number-formats">
  ### 日期和数字格式
</div>

请考虑日期和数字的区域格式差异。

* 日期格式：MM/DD/YYYY 与 DD/MM/YYYY
* 数字格式：1,000.00 与 1.000,00
* 货币符号：$100.00 与 100,00€

请为每种语言提供符合其习惯的示例，或使用普遍易懂的格式。

<div id="maintain-consistency">
  ### 保持一致性
</div>

* 确保所有语言版本的内容保持一致，让每位用户都能获得同等质量的信息。
* 为技术术语建立翻译术语表。
* 在不同语言版本中保持相同的内容结构。
* 保持与源内容一致的语气和风格。
* 使用 Git 分支将翻译工作与主要内容更新分开管理。

<div id="layout-differences">
  ### 布局差异
</div>

某些语言比英语占用更多或更少的空间。请在不同屏幕尺寸下测试译文内容，确保：

* 导航显示正常。
* 代码块不会溢出。
* 表格和其他格式化文本仍然清晰易读。
* 图片缩放合适。

<div id="character-encoding">
  ### 字符编码
</div>

确保你的开发环境和部署流水线支持 UTF-8 编码，以正确显示使用不同字母系统和特殊字符的语言中的所有字符。
