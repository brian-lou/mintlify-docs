<div id="what-you-will-build">
  ## 你将构建的内容
</div>

你将构建一个自动化工作流：当代码推送到主分支时，它会更新你的文档。该工作流可在多个平台上搭建，包括 GitHub Actions 和 n8n。它会监控你的代码仓库，然后调用代理 API，在单独的文档仓库中更新文档。

该工作流会连接两个独立的仓库：

* **代码仓库**：用于存储应用代码。你将在这个仓库中设置自动化触发器。示例包括后端 API、前端应用、SDK 或 CLI 工具。
* **文档仓库**：用于存储文档，并连接到你的 Mintlify 项目。代理会在此仓库中创建包含文档更新的拉取请求。

本教程默认你的文档与应用代码分别存放在不同的仓库中。如果你使用的是单体仓库，请修改工作流，使其指向存放文档的目录。

<div id="workflow-overview">
  ### 工作流概述
</div>

1. 有人将代码推送到你的主分支。
2. 工作流被触发。
3. 工作流调用代理 API 来更新你的文档。
4. 代理会在你的文档仓库中创建一个包含文档更新的拉取请求。

    ## 构建工作流

    ### 创建工作流文件

    1. 在代码仓库中，创建一个新文件：`.github/workflows/update-docs.yml`
    2. 添加以下工作流：

       ```yaml
       name: Update Docs

       on:
         push:
           branches:
             - main

       jobs:
         update-docs:
           runs-on: ubuntu-latest
           steps:
             - uses: actions/github-script@v8
               env:
                 MINTLIFY_API_KEY: ${{ secrets.MINTLIFY_API_KEY }}
                 PROJECT_ID: ${{ secrets.MINTLIFY_PROJECT_ID }}
               with:
                 script: |
                   const { owner, repo } = context.repo;
                   const projectId = process.env.PROJECT_ID;
                   const apiKey = process.env.MINTLIFY_API_KEY;

                   if (!projectId || !apiKey) {
                     core.setFailed('Missing MINTLIFY_PROJECT_ID or MINTLIFY_API_KEY secrets');
                     return;
                   }

                   const url = `https://api.mintlify.com/v1/agent/${projectId}/job`;
                   const payload = {
                     branch: `mintlify/docs-update-${Date.now()}`,
                     messages: [
                       {
                         role: 'system',
                         content: 'You are an action runner that updates documentation based on code changes. You should never ask questions. If you are not able to access the repository, report the error and exit.'
                       },
                       {
                         role: 'user',
                         content: `Update the documentation for our recent pushes to main:\n\nRepository: ${owner}/${repo}`
                       }
                     ],
                     asDraft: false
                   };

                   try {
                     const response = await fetch(url, {
                       method: 'POST',
                       headers: {
                         'Authorization': `Bearer ${apiKey}`,
                         'Content-Type': 'application/json'
                       },
                       body: JSON.stringify(payload)
                     });

                     if (!response.ok) {
                       throw new Error(`API request failed with status ${response.status}: ${await response.text()}`);
                     }

                     const reader = response.body.getReader();
                     const decoder = new TextDecoder();
                     let buffer = '';

                     while (true) {
                       const { done, value } = await reader.read();
                       if (done) break;
                       buffer += decoder.decode(value, { stream: true });
                       const lines = buffer.split('\n');
                       buffer = lines.pop() || '';
                       for (const line of lines) {
                         if (line.trim()) {
                           console.log(line);
                         }
                       }
                     }
                     if (buffer.trim()) {
                       console.log(buffer);
                     }

                     core.notice(`Documentation update job triggered for ${owner}/${repo}`);
                   } catch (error) {
                     core.setFailed(`Failed to create documentation update job: ${error.message}`);
                   }
       ```

    ### 添加密钥

    1. 在代码仓库中，前往 **Settings** → **Secrets and variables** → **Actions**。
    2. 点击 **New repository secret**。
    3. 添加以下密钥：
       * 名称：`MINTLIFY_API_KEY`，密钥：你的 Mintlify 管理员 API 密钥
       * 名称：`MINTLIFY_PROJECT_ID`，密钥：你的 Mintlify 项目 ID (可在控制面板的 [API keys](https://dashboard.mintlify.com/settings/organization/api-keys) 页面找到)

    更多信息，请参阅 GitHub 文档中的 [Using secrets in GitHub Actions](https://docs.github.com/en/actions/how-tos/write-workflows/choose-what-workflows-do/use-secrets)。

    1. 在代码仓库中做一处小改动，并推送到 `main`：
       ```bash
       git add .
       git commit -m "Test: trigger docs automation"
       git push origin main
       ```

    2. 查看代码仓库中的 **Actions** 选项卡，了解工作流的运行情况。

    3. 工作流运行后，请检查你的文档仓库中是否有包含文档更新的新分支和拉取请求。

    ## 故障排除

    ### 工作流未运行

    * 确认代码仓库已启用 GitHub Actions。
    * 在 **Actions** 选项卡中查看错误信息。
    * 确保工作流文件位于 `.github/workflows/` 目录中，并且扩展名为 `.yml`。

    ### 代理 API 返回 401 错误

    * 请确认你的 API 密钥以 `mint_` 开头。
    * 检查 Authorization 标头是否采用 `Bearer mint_yourkey` 格式。
    * 确认该 API 密钥属于正确的 Mintlify 组织。

    ### 文档更新未显示

    * 确认文档仓库已连接到你的 Mintlify 项目。
    * 确认代理拥有文档仓库的写入权限。
    * 检查工作流日志中代理返回的错误信息。

    ## 构建工作流

    ### 创建 Webhook 触发器

    1. 在 n8n 中，新建一个工作流。
    2. 添加 webhook 节点。
    3. 配置 Webhook：
       * HTTP 方法：`POST`
       * 路径：`auto-update-documentation` (或任意唯一路径)
       * 身份验证：无
       * 响应：立即返回
    4. 保存工作流。
    5. 复制生产环境的 webhook URL，格式如下：`https://your-n8n-instance.app.n8n.cloud/webhook/auto-update-documentation`

    ### 设置 GitHub Webhook

    1. 前往你在 GitHub 上的代码仓库。
    2. 点击 **Settings**。
    3. 点击 **Webhooks**。
    4. 点击**添加 Webhook**。
    5. 配置 webhook：
       * Payload URL：粘贴你的 n8n webhook URL
       * Content type：`application/json`
       * 你希望由哪些事件触发此 webhook？
         * 选择 **Let me select individual events.**
         * 仅选择 **Push events**。
       * 选择 **Active**
    6. 点击 **Add webhook**。

    ### 过滤主分支推送

    在 webhook 后添加一个代码节点，用于筛选推送到 main 分支的事件并提取相关信息。

    1. 添加代码节点。
    2. 将其命名为 &quot;筛选 main 分支推送。&quot;
    3. 将模式设为 **Run Once for All Items**。
    4. 添加以下 JavaScript：

    ```javascript
    const webhookData = $input.first().json.body;

    // 仅在推送到 main 分支时继续
    if (webhookData.ref !== "refs/heads/main") {
      return [];
    }

    // 提取信息
    const repository = webhookData.repository;
    const pusher = webhookData.pusher;

    // 为代理构建消息
    const agentMessage = `更新 ${repository.name} 中推送到 main 分支的变更的文档。始终编辑文件并创建拉取请求。`;

    return {
      json: {
        codeRepoName: repository.full_name,
        codeRepoShortName: repository.name,
        agentMessage: agentMessage
      }
    };
    ```

    ### 调用代理 API

    添加 HTTP 请求节点以创建文档任务。

    1. 添加 HTTP 请求节点。
    2. 将其命名为 &quot;创建代理任务&quot;。
    3. 配置请求：

       * 方法：`POST`
       * URL：`https://api.mintlify.com/v1/agent/YOUR_PROJECT_ID/job` (将 `YOUR_PROJECT_ID` 替换为你在 [API 密钥](https://dashboard.mintlify.com/settings/organization/api-keys) 页面中看到的项目 ID)
       * 身份验证：通用凭据类型 → Header Auth
         * 新建一个凭据：
           * 名称：`Authorization`
           * 值：`Bearer mint_YOUR_API_KEY` (替换为你的 API 密钥)
       * 发送 Body：开启
       * Body 内容类型：JSON
       * 指定 Body：使用 JSON
       * 添加以下 JSON：

       ```json
       {
       "branch": "docs-update-from-{{ $json.codeRepoShortName }}-{{ $now.toISOString() }}",
       "messages": [
           {
           "role": "system",
           "content": "{{ $json.agentMessage }}"
           }
       ],
       "asDraft": false
       }
       ```

    ## 常见问题排查

    ### Webhook 未触发

    * 确认 n8n 中的工作流已启用。
    * 在 GitHub 仓库的 Settings → Webhooks → Recent Deliveries 中查看响应代码。
    * 确认 webhook URL 与你的 n8n webhook URL 完全匹配。

    ### 代理 API 返回 401 错误

    * 确认 API 密钥以 `mint_` 开头。
    * 检查 Authorization 标头是否采用 `Bearer mint_yourkey` 格式。
    * 确认该 API 密钥对应正确的 Mintlify 组织。

    ### GitHub 401 错误

    * 确认你的令牌具有 `repo` 权限范围。
    * 确认令牌尚未过期。
    * 确认你已在 GitHub 请求中包含 `User-Agent` 请求头。
