<Tip>
  本页介绍了在文档中使用截图、GIF 和视频的最佳实践。
</Tip>

截图、GIF 和视频可以提升文档效果，但随着 UI 元素变化，也需要持续维护。请谨慎使用，以避免不必要的维护成本。

关键准则：

* **媒体应作为补充。** 如果仅用文字就能清楚说明某个流程，就不要添加视觉内容。
* **确保无障碍访问。** 为图片添加替代文本，为视频添加字幕，为音频内容提供文字稿。许多人依赖辅助技术，而无障碍内容也能让所有用户受益。
* **平衡清晰度与可维护性。** 频繁的 UI 变化会让截图和视频很快过时。请考虑更新它们所需的投入是否值得其带来的价值。

<div id="when-to-use-media">
  ## 何时使用媒体
</div>

* 对于难以用文字说明的任务，使用 **截图**。
* 出于宣传目的，或用于展示简短但复杂的工作流程时，使用 **GIF**。
* 对于抽象概念和较长的工作流程，使用 **视频**。

请有节制且有明确目的地使用媒体，以免带来不必要的文档维护成本。使用得当时，它能帮助读者更好地理解内容，同时不会增加维护负担或造成无障碍访问问题。
