<div id="brand-your-site">
  ## 塑造你的网站品牌形象
</div>

设置网站的品牌标识以及访客看到的呈现方式。

* **Docs title**：文档名称。会显示在浏览器标签页和搜索结果中。
* **Description**：文档的简要说明。用于 SEO 和网站元数据。
* **Favicon**：显示在浏览器标签页中的小图标。可上传 ICO、PNG、GIF 或 JPG 文件。
* **Theme**：为文档的整体外观选择一个[主题](/zh/customize/themes)。

<div id="customize-colors-and-appearance">
  ## 自定义颜色和外观
</div>

控制站点的视觉风格和配色方案。

* **Primary color**：站点中用于链接、按钮和高亮等元素的主强调色。
* **Light mode color**：浅色模式下的强调色变体。具体应用方式因主题而异。
* **Dark mode color**：深色模式下的强调色变体。具体应用方式因主题而异。
* **Logo**：品牌 Logo。可上传 SVG、PNG 或 JPG 文件。你可以为浅色和深色模式分别设置不同的 Logo。
* **Logo link**：用户点击 Logo 后跳转到的位置。通常是你的主页或营销站点。
* **Background colors**：分别为浅色和深色模式设置自定义背景色。
* **Background image**：为站点添加背景图片。可上传 PNG、GIF 或 JPG 文件。
* **Background decoration**：为背景图片应用视觉样式。
* **Theme toggle**：显示或隐藏供用户切换浅色/深色模式的开关。
* **Default theme**：设置站点默认以浅色模式还是深色模式加载。

<div id="set-custom-fonts">
  ## 设置自定义字体
</div>

将默认字体替换为符合品牌风格的字体。

* **默认字体**：所有文本使用的基础字体族和字重。需提供来源 URL 和格式 (WOFF 或 WOFF2) 。
* **标题字体**：专门用于标题 (h1、h2 等) 的字体族和字重。与正文字体分开设置。
* **正文字体**：用于正文和段落的字体族和字重。

对于每种字体，请指定字体族名称、字重、来源 URL (如 Google Fonts) 和格式。

<div id="configure-header">
  ## 配置页头
</div>

在网站顶部添加导航元素。

* **导航栏按钮**：在页头中添加一个主要行动按钮。设置按钮类型、标签和目标 URL。
* **导航栏链接**：在页头中添加额外的导航链接。每个链接都包含文本和 URL。

<div id="configure-footer">
  ## 配置页脚
</div>

在网站页脚中添加链接和社交媒体账号。

* **社交链接**：添加你在 GitHub、X (Twitter) 、LinkedIn、Discord、YouTube、Slack 等平台上的个人主页链接。
* **页脚列**：使用自定义标题和链接分组，将页脚链接组织成多列。

<div id="enhance-content">
  ## 增强内容
</div>

自定义站点上的内容呈现方式。

* **缩略图背景**：为页面缩略图和社交预览设置自定义背景图。
* **缩略图外观**：控制缩略图的显示效果。
* **缩略图字体**：为缩略图中的文本设置自定义字体。
* **标题上方标签**：在页面标题上方添加小标签。
* **代码块主题**：为代码块选择语法高亮主题。
* **LaTeX 支持**：启用 LaTeX 数学公式渲染。

<div id="set-up-ai-chat-and-search">
  ## 设置 AI 聊天和搜索
</div>

自定义搜索体验。

* **搜索框占位文本**：用户输入前显示在搜索框中的提示文本。默认值为“搜索或提问...”。

<div id="configure-api-specifications">
  ## 配置 API 规范
</div>

添加 [OpenAPI](/zh/api-playground/openapi-setup) 或 [AsyncAPI](/zh/api-playground/asyncapi-setup) 规范文件，为端点编写文档。

* **OpenAPI 规范**：上传 OpenAPI 规范文件，或输入外部 OpenAPI 文件的 URL。
* **AsyncAPI 规范**：上传 AsyncAPI 规范文件，或输入外部 AsyncAPI 文件的 URL。
* **操作台显示**：选择显示[交互式 API 操作台](/zh/api-playground/overview#visibility-modes)、简易 API 操作台，或不显示 API 操作台。
* **代理服务器**：启用或禁用 API 请求的代理服务器。

<div id="add-analytics-and-integrations">
  ## 添加分析与集成
</div>

将分析工具和第三方工具接入你的文档站点。

使用以下工具跟踪访客行为：

* **Amplitude, Mixpanel, Heap**: 产品分析平台
* **Google Analytics, Google Tag Manager**: Web 分析工具
* **PostHog, Plausible, Fathom**: 注重隐私的分析工具
* **Segment, Hightouch**: 客户数据平台
* **Hotjar, LogRocket**: 会话回放和热力图工具
* **Microsoft Clarity**: 用户行为分析
* **Intercom**: 客户消息工具
* **Clearbit, Koala**: 访客身份识别

其他集成：

* **Telemetry**: 启用或禁用使用情况遥测
* **Cookies**: 设置自定义 Cookie 键值对
