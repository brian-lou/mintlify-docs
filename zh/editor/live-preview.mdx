---
title: "实时预览"
description: "在编辑时预览你的文档站点，并实时查看更改。"
keywords: ["preview"]
---

在编辑的同时预览你的文档站点。实时预览会按发布后的实际效果显示页面，并在你修改内容、导航和配置时实时更新。

<div id="open-live-preview">
  ## 打开实时预览
</div>

点击工具栏中的 <Icon icon="play" /> 按钮，即可在新标签页中打开实时预览。

<Frame>
  <img src="/images/editor/live-preview-light.png" alt="编辑器工具栏上的实时预览按钮。" className="block dark:hidden" />

  <img src="/images/editor/live-preview-dark.png" alt="编辑器工具栏上的实时预览按钮。" className="hidden dark:block" />
</Frame>

<Note>
  实时预览仅适用于公开文档。如果你的文档需要身份验证，编辑器会显示“实时预览不可用”消息。
</Note>

<div id="live-preview-versus-preview-deployments">
  ## 实时预览与预览部署
</div>

|          | 实时预览       | 预览部署      |
| -------- | ---------- | --------- |
| **速度**   | 即时         | 需要构建时间    |
| **访问方式** | 本地 URL     | 可共享的 URL  |
| **使用场景** | 编辑时查看更改    | 分享给团队审查   |
| **可用性**  | 仅在编辑器打开时可用 | 只要分支存在即可用 |

在编辑过程中，使用实时预览可立即看到反馈。需要与团队共享更改或在不同设备上测试时，请创建预览部署。
