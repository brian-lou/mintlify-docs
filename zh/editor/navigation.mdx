使用导航侧边栏整理文档。你在网页编辑器的导航树中所做的更改会显示在站点的导航侧边栏中，并同步到 `docs.json` 配置文件。

<div id="add-navigation-elements">
  ## 添加导航元素
</div>

如需添加新的导航元素，请点击导航树底部的 **Add new**。

<Frame>
  <img src="/images/editor/navigation-light.png" alt="添加新的导航元素。" className="block dark:hidden" />

  <img src="/images/editor/navigation-dark.png" alt="添加新的导航元素。" className="hidden dark:block" />
</Frame>

如需添加嵌套在其他元素中的导航元素，请点击父元素名称旁的 **+** 按钮。

创建元素后，你可以通过拖放调整顺序，或将其嵌套到其他元素中。右键点击任意元素，即可配置其属性、复制、从导航中隐藏或删除。

<Note>
  某些元素不能嵌套在其他元素中。例如，标签页不能嵌套在分组中。网页编辑器会阻止你创建无效的嵌套。
</Note>

<div id="add-existing-files">
  ### 添加现有文件
</div>

添加仓库中尚未显示在导航中的文件。

1. 在要添加文件的位置，点击加号按钮 <Icon icon="plus" />。
2. 点击 **添加现有文件**。

<div id="organize-into-sections">
  ## 划分章节
</div>

根据文档范围和目标受众，选择合适的导航结构。

<div id="when-to-use-pages">
  ### 何时使用页面
</div>

页面适用于单个文档文件。页面是导航的核心组成部分——每一项内容都承载在某个页面中。将页面添加到导航后，它们才会显示在站点侧边栏中。

页面可以位于根级，也可以放在分组、标签页、锚点、下拉菜单或菜单中。

未包含在导航中的文件会在已发布的文档中被[隐藏](/zh/organize/hidden-pages)。

<div id="when-to-use-groups">
  ### 何时使用分组
</div>

使用分组可将相关页面组织成可折叠的区块。分组通过将相似内容归类在一起，帮助用户快速浏览导航，例如将所有身份验证相关页面或所有 API 端点参考页面归为一组。

分组可以嵌套在其他分组中，以形成层级结构。分组可以位于标签页、锚点、下拉菜单中，也可以位于根级别。

<div id="when-to-use-tabs">
  ### 何时使用标签页
</div>

使用标签页，可以在站点顶部通过水平导航划分出独立的一级栏目。当你的文档包含 API Reference、Guides 和 SDKs 等不同区域，且用户需要在这些区域之间切换时，标签页就很适合。

标签页中可以包含页面、分组和菜单项。你还可以为标签页配置图标或添加外部资源链接。

<div id="when-to-use-anchors">
  ### 何时使用锚点
</div>

使用锚点可在侧边栏顶部创建固定显示的导航项。当你想将内容分区，或无需切换标签页即可快速访问外部资源时，锚点会很有帮助。

锚点可以包含页面和分组，也可以链接到外部 URL。

**全局锚点：**

创建会显示在所有页面上的全局锚点，无论用户当前正在查看哪个部分。全局锚点必须链接到外部 URL，适合用于博客、状态页或支持链接等资源。

<div id="when-to-use-dropdowns">
  ### 何时使用下拉菜单
</div>

使用下拉菜单可在侧边栏顶部创建一个可展开的菜单。如果你有多个相关部分，用户可能会想浏览，但又不需要像标签页那样始终显示，这时下拉菜单就很合适。

下拉菜单可以包含页面和分组，也可以链接到外部 URL。

<div id="when-to-use-menus">
  ### 何时使用菜单
</div>

使用菜单可在标签页内添加下拉导航项。菜单可帮助用户通过顶部导航栏直接进入特定页面。

菜单可以包含页面和分组。

<div id="when-to-use-products">
  ### 何时使用产品
</div>

如果你有多个彼此独立、且各自都需要单独文档的产品，就可以使用产品功能。产品会生成一个切换菜单，方便用户在不同产品的文档集之间切换。

每个产品都可以拥有自己的导航结构，包括标签页、页面和分组。

<div id="when-to-use-versions">
  ### 何时使用版本
</div>

当你需要同时维护多个版本的文档时，例如 API 的 v1.0、v2.0 和 v3.0，就应使用版本。版本会生成一个切换菜单，方便用户选择要查看的版本。

每个版本都可以有不同的内容和导航结构。

<div id="when-to-use-languages">
  ### 何时使用语言
</div>

如果你提供多语言文档，请使用语言配置。启用后会生成一个语言切换菜单，让用户可以按自己偏好的语言查看文档。

每种语言都会保留相同的导航结构，并提供对应的翻译内容。

<div id="customize-appearance">
  ## 自定义外观
</div>

**添加图标：**

1. 右键点击某个导航项。
2. 点击 **Configure**。
3. 点击图标字段。

**添加标签：**

1. 右键点击某个导航项。
2. 点击 **Configure**。
3. 点击标签字段。
4. 输入如 &quot;NEW&quot; 或 &quot;BETA&quot; 这样的标签，以突出重要项。

**控制可见性：**

隐藏导航元素中的内容，而无需将其从仓库中删除。

1. 右键点击任意项。
2. 点击 **Hide** 标签旁边的切换开关。
