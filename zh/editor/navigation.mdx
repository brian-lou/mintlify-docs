使用导航侧边栏来组织你的文档结构。你在 Web 编辑器的导航树中所做的更改会显示在站点的导航侧边栏中，并同步到 `docs.json` 配置文件。

<div id="add-navigation-elements">
  ## 添加导航元素
</div>

要添加新的导航元素，请点击导航树底部的 **Add new** 按钮。

<Frame>
  <img src="/images/editor/navigation-light.png" alt="添加新的导航元素。" className="block dark:hidden" />

  <img src="/images/editor/navigation-dark.png" alt="添加新的导航元素。" className="hidden dark:block" />
</Frame>

要在其他元素内添加嵌套导航元素，请点击父元素名称旁边的 **+** 按钮。

创建元素后，可以通过拖放来重新排序，或将其嵌套到其他元素中。右键单击任意元素即可配置其属性、复制、在导航中隐藏或将其删除。

<Note>
  某些元素不能嵌套在其他元素中。例如，tabs 不能嵌套在 groups 中。网页编辑器会阻止你创建无效的嵌套。
</Note>

<div id="add-existing-files">
  ### 添加现有文件
</div>

从你的仓库中添加尚未包含在导航中的文件。

1. 在你想要添加文件的位置点击加号按钮 <Icon icon="plus" />。
2. 点击 **Add existing file**。

<div id="organize-into-sections">
  ## 按章节组织内容
</div>

根据文档的范围和受众选择合适的导航结构。

<div id="when-to-use-pages">
  ### 何时使用页面
</div>

将页面用于单个文档文件。页面是导航的核心构成单元——所有内容都存在于某个页面上。将页面添加到导航中，可以让它们显示在站点的侧边栏中。

页面可以存在于根层级、分组、选项卡、锚点、下拉菜单或菜单中。

未包含在导航中的文件将在已发布文档中被[隐藏](/zh/organize/hidden-pages)。

<div id="when-to-use-groups">
  ### 何时使用分组
</div>

使用分组将相关页面组织成可折叠的部分。通过把相似内容聚在一起，分组有助于用户快速扫视导航结构，例如将所有与认证相关的页面，或所有 API 端点参考文档归为一组。

分组可以嵌套在其他分组中，从而创建层级结构。分组可以位于选项卡、锚点、下拉菜单中，或直接位于导航的根级。

<div id="when-to-use-tabs">
  ### 何时使用选项卡
</div>

使用选项卡在站点顶部创建带有水平导航的独立顶级部分。当你有 API 参考文档、指南和 SDK 等彼此独立且用户需要在其间切换的区域时，选项卡非常适用。

选项卡可以包含页面、分组和菜单项。你可以通过配置选项卡来添加图标，或链接到外部资源。

<div id="when-to-use-anchors">
  ### 何时使用锚点
</div>

使用锚点可在侧边栏顶部创建固定的导航项。当你想对内容进行分区，或在不切换标签页的情况下为外部资源提供快速访问时，锚点会很有帮助。

锚点可以包含页面和分组，或链接到外部 URL。

**全局锚点：**

创建全局锚点，使其出现在所有页面上，而不受用户当前正在查看哪个分区的影响。全局锚点必须链接到外部 URL，适用于博客、状态页或支持页面等资源。

<div id="when-to-use-dropdowns">
  ### 何时使用下拉菜单
</div>

使用下拉菜单可以在侧边栏顶部创建一个可展开的菜单。当你有多个相关部分，用户可能希望探索，但又不需要像选项卡那样始终保持可见时，下拉菜单非常适用。

下拉菜单可以包含页面和分组，或链接到外部 URL。

<div id="when-to-use-menus">
  ### 何时使用菜单
</div>

在选项卡中使用菜单以添加下拉导航项。菜单可帮助用户从顶部导航栏直接访问特定页面。

菜单可以包含页面和分组。

<div id="when-to-use-products">
  ### 何时使用产品
</div>

当你有多个彼此独立的产品，并且每个都需要各自的文档时，应使用“产品”。产品会创建一个切换菜单，让用户在不同的产品文档集之间进行切换和浏览。

每个产品都可以拥有自己包含选项卡、页面和分组的导航结构。

<div id="when-to-use-versions">
  ### 何时使用版本
</div>

当你需要同时维护文档的多个版本（例如某个 API 的 v1.0、v2.0 和 v3.0）时，请使用版本。版本会创建一个切换菜单，让用户选择想要查看的版本。

每个版本都可以有不同的内容和导航结构。

<div id="when-to-use-languages">
  ### 何时使用语言功能
</div>

当你需要以多种语言提供文档时，请使用语言功能。该功能会创建一个语言切换菜单，让用户以自己偏好的语言查看文档。

每种语言都会在保持相同导航结构的前提下，提供相应的翻译内容。

<div id="customize-appearance">
  ## 自定义外观
</div>

**添加图标：**

1. 右键点击导航条目。
2. 点击 **Configure**。
3. 点击图标字段。

**添加标签：**

1. 右键点击导航条目。
2. 点击 **Configure**。
3. 点击标签字段。
4. 输入诸如“NEW”或“BETA”等标签，用于突出显示重要条目。

**控制可见性：**

在不从存储库中删除内容的前提下，隐藏导航元素中的内容。

1. 右键点击任意条目。
2. 点击 **Hide** 标签旁的切换开关。
