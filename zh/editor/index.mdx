使用网页编辑器，直接在浏览器中创建、编辑和发布文档。你可以查看并分享更改预览；通过拖放组件管理站点的导航结构；并按团队偏好的工作流程发布更新。

<div id="key-features">
  ## 主要功能
</div>

* **可视化与 Markdown 编辑**：可在工作过程中随时切换可视化和 Markdown 编辑模式。
* **实时预览**：无需创建预览部署，即可实时查看更改。
* **可共享的预览链接**：可直接在编辑器中为团队创建预览链接。
* **拖放式导航**：无需编辑配置文件，即可通过可视化方式整理站点结构。
* **内置媒体管理器**：上传并整理图片、视频和其他资源。
* **Git 同步**：所有更改都会自动同步到你的文档仓库。
* **分支工作流**：可在功能分支上工作，并创建拉取请求供审核。
* **团队协作**：多个团队成员可借助预览部署同时协作。
