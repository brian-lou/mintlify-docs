使用 Web 编辑器，你可以在浏览器中直接创建、编辑和发布文档。可以预览并分享你的更改，通过拖放组件管理站点的导航结构，并按照团队偏好的工作流发布更新。

<div id="key-features">
  ## 关键功能
</div>

* **可视化与 Markdown 编辑**：在编辑过程中可在可视化模式和 Markdown 模式之间自由切换。
* **实时预览**：无需创建预览部署即可查看实时变更。
* **可分享的预览链接**：直接在编辑器中为团队生成预览链接。
* **拖放式导航**：通过拖放直观地组织站点结构，无需编辑配置文件。
* **内置媒体管理器**：上传并管理图片、视频和其他资源。
* **Git 同步**：所有更改会自动与文档仓库同步。
* **分支工作流**：在功能分支上工作，并通过 Pull Request 发起评审。
* **团队协作**：多名团队成员可在带有预览部署的环境中并行协作。
