<Info>
  审计日志适用于 [Enterprise 企业版计划](https://mintlify.com/pricing?ref=audit-logs)。
</Info>

使用审计日志来监控和跟踪你组织成员执行的操作。审计日志提供活动记录，用于安全、防护、合规以及故障排查。

- **监控安全性**：跟踪身份验证尝试和权限更改。
- **确保合规性**：维护所有组织活动的完整记录。
- **排查问题**：调查失败的操作及其原因。
- **跟踪变更**：查看是谁在何时进行了特定更改。

<div id="view-audit-logs">
  ## 查看审计日志
</div>

在仪表盘中前往 [Audit log](https://dashboard.mintlify.com/settings/organization/audit-logs) 页面以查看审计日志。

点击任意日志条目即可展开并查看详细信息，包括：

| 字段 | 描述 |
| ----- | ----------- |
| Timestamp | 操作发生的日期和时间 |
| Actor | 执行该操作的用户的邮箱地址 |
| Action | 用户执行的具体操作 |
| Category | 受影响的资源类型 |
| Outcome | 操作是否成功或失败 |
| Metadata | 关于该操作的更多上下文信息 |

<div id="filter-logs">
  ### 筛选日志
</div>

筛选审计日志以查找特定活动。

**日期范围**：选择预设日期范围以查看特定时间段内的日志。

**类别**：按操作类型筛选日志。

| Category         | Description                                                        |
|------------------|--------------------------------------------------------------------|
| Organization     | 组织设置更新和删除请求。                |
| Member           | 团队成员邀请、移除和角色变更。               |
| Deployment       | 部署配置更改，包括自定义域名、身份验证和 Git 源。 |
| Preview deployment | 预览部署的创建、更新和身份验证更改。 |
| API key          | API key 和 discovery API key 的创建与删除。               |
| Assistant        | 助手设置更新，例如分流邮件、网页搜索站点和预设问题。 |
| PDF export       | PDF 导出的生成和删除。                                |
| Integration      | GitHub、Slack 和 Discord 的安装与移除。             |
| Billing          | 订阅更新、附加组件购买和发票查看。          |
| Quota            | 超额策略和警报配置更改。                    |
| User             | 个人用户通知设置。                             |
| Suggestions      | 建议配置和代码仓库管理。                 |
| Audit log        | 审计日志查看和导出。                              |
| Auth             | 登录尝试、退出登录和会话创建。                     |

<div id="export-audit-logs">
  ## 导出审计日志
</div>

将审计日志导出为 CSV，以便进行分析、合规报告或长期归档。

1. 在仪表盘中进入 [Audit log](https://dashboard.mintlify.com/settings/organization/audit-logs) 页面。
1. 视需要应用筛选条件，缩小要导出的日志范围。
1. 点击 **Export CSV**。
1. 导出完成后，Mintlify 会向你发送一封包含下载链接的电子邮件。
