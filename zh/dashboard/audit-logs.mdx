<Info>
  审计日志仅适用于 [Enterprise 套餐](https://mintlify.com/pricing?ref=audit-logs)。
</Info>

使用审计日志监控和跟踪您的组织成员执行的操作。审计日志会保留活动记录，用于安全审查、合规要求和故障排查。

* **监控安全**：跟踪身份验证尝试和权限变更。
* **确保合规**：保留所有组织活动的记录。
* **排查问题**：调查失败的操作及其原因。
* **跟踪变更**：查看特定更改由谁在何时进行。

<div id="view-audit-logs">
  ## 查看审计日志
</div>

前往仪表板中的 [审计日志](https://dashboard.mintlify.com/settings/organization/audit-logs) 页面，查看审计日志。

点击任意日志条目可展开并查看详细信息，包括：

| 字段  | 描述             |
| --- | -------------- |
| 时间戳 | 操作发生的日期和时间     |
| 操作人 | 执行该操作的用户电子邮箱地址 |
| 操作  | 用户执行的操作        |
| 类别  | 受影响的资源类型       |
| 结果  | 操作成功还是失败       |
| 元数据 | 与该操作相关的附加上下文信息 |

<div id="filter-logs">
  ### 筛选日志
</div>

筛选审计日志，查找特定活动。

**日期范围**：选择预设的日期范围，查看特定时间段内的日志。

**类别**：按操作类型筛选日志。

| Category           | Description                          |
| ------------------ | ------------------------------------ |
| Organization       | 组织设置更新和删除请求。                         |
| Member             | 团队成员邀请、移除和角色变更。                      |
| Deployment         | 部署配置更改，包括自定义域名、身份验证和 Git 源。          |
| Preview deployment | 预览部署的创建、更新和身份验证更改。                   |
| API key            | API 密钥和 discovery API 密钥的创建与删除。      |
| Assistant          | Assistant 设置更新，例如转接邮箱、Web 搜索站点和起始问题。 |
| PDF export         | PDF 导出的生成与删除。                        |
| Integration        | GitHub、Slack 和 Discord 的安装与移除。       |
| Billing            | 订阅更新、附加组件购买和发票查看。                    |
| Quota              | 超额政策和警报配置更改。                         |
| User               | 个人用户通知设置。                            |
| Suggestions        | 建议配置和代码仓库管理。                         |
| Audit log          | 审计日志查看和导出。                           |
| Auth               | 登录尝试、退出登录和会话创建。                      |

<div id="export-audit-logs">
  ## 导出审计日志
</div>

将审计日志导出为 CSV，用于分析、合规报告或长期归档。

1. 前往仪表板中的 [审计日志](https://dashboard.mintlify.com/settings/organization/audit-logs) 页面。
2.  (可选) 使用筛选条件缩小要导出的日志范围。
3. 点击 **Export CSV**。
4. 导出完成后，Mintlify 会向你发送一封包含下载链接的电子邮件。
