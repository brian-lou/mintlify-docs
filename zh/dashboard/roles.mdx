<Info>
  基于角色的访问控制 (RBAC) 适用于 [Enterprise plans](https://mintlify.com/pricing?ref=rbac)。
</Info>

Mintlify 提供三种仪表板访问级别：viewer、编辑者 和 管理员。

|                    | Viewer | 编辑者 | 管理员 |
| ------------------ | :----: | :----: | :---: |
| 在编辑器中查看内容          |    ✅   |    ✅   |   ✅   |
| 查看仪表板和分析数据         |    ✅   |    ✅   |   ✅   |
| 在网页编辑器中编辑内容        |    ❌   |    ✅   |   ✅   |
| 触发部署               |    ❌   |    ✅   |   ✅   |
| 创建和删除 API 密钥       |    ❌   |    ✅   |   ✅   |
| 配置集成               |    ❌   |    ✅   |   ✅   |
| 配置助手               |    ❌   |    ✅   |   ✅   |
| 配置附加组件             |    ❌   |    ✅   |   ✅   |
| 邀请 编辑者 和 viewer |    ❌   |    ✅   |   ✅   |
| 更新用户角色             |    ❌   |    ❌   |   ✅   |
| 邀请 管理员           |    ❌   |    ❌   |   ✅   |
| 删除用户               |    ❌   |    ❌   |   ✅   |
| 管理账单               |    ❌   |    ❌   |   ✅   |
| 管理 SSO             |    ❌   |    ❌   |   ✅   |
| 更新自定义域名            |    ❌   |    ❌   |   ✅   |
| 更新 Git 来源          |    ❌   |    ❌   |   ✅   |
| 删除组织               |    ❌   |    ❌   |   ✅   |

<Tip>
  仅向需要执行管理员任务的人员授予 管理员 访问权限。
</Tip>

<div id="add-members-to-your-organization">
  ## 向你的组织添加成员
</div>

默认情况下，创建你的 Mintlify 组织的用户拥有管理员权限。你可以在仪表板的 [Members](https://dashboard.mintlify.com/settings/organization/members) 页面添加更多编辑者。

你可以根据需要向组织中添加任意数量的成员。席位可能会产生额外费用。更多详情请参阅[定价页面](https://mintlify.com/pricing)。
