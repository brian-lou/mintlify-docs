<Info>
  SSO 适用于 [Enterprise 订阅计划](https://mintlify.com/pricing?ref=sso)。
</Info>

Enterprise 管理员可以直接在 Mintlify 控制台中为 Okta 或 Microsoft Entra 配置 SAML SSO。对于其他身份提供商（如 Google Workspace 或 Okta OIDC），请[联系我们](mailto:support@mintlify.com)以设置 SSO。

<div id="set-up-sso">
  ## 配置 SSO
</div>

<div id="okta">
  ### Okta
</div>

<Steps>
  <Step title="在 Mintlify 控制台中配置 Okta SSO">
    1. 在 Mintlify 控制台中，前往 [Single Sign-On](https://dashboard.mintlify.com/settings/organization/sso) 页面。
    2. 点击 **Configure**。
    3. 选择 **Okta SAML**。
    4. 复制 **Single sign on URL** 和 **Audience URI**。
  </Step>
  <Step title="在 Okta 中创建 SAML 应用">
    1. 在 Okta 中，进入 **Applications**，使用 SAML 2.0 创建一个新的应用集成。
    2. 输入来自 Mintlify 的以下内容：
        * **Single sign on URL**：你从 Mintlify 控制台复制的 URL
        * **Audience URI**：你从 Mintlify 控制台复制的 URI
        * **Name ID Format**：`EmailAddress`

    4. 添加以下属性声明：

        | Name | Name format | Value |
        | ---- | ----------- | ----- |
        | `firstName` | Basic | `user.firstName` |
        | `lastName` | Basic | `user.lastName` |
  </Step>
  <Step title="复制 Okta metadata URL">
    在 Okta 中，进入该应用的 **Sign On** 选项卡并复制 metadata URL。
  </Step>
  <Step title="在 Mintlify 中保存">
    回到 Mintlify 控制台，粘贴 metadata URL 并点击 **Save changes**。
  </Step>
</Steps>

<div id="microsoft-entra">
  ### Microsoft Entra
</div>

<Steps>
  <Step title="在 Mintlify 控制面板中配置 Microsoft Entra SSO">
    1. 在 Mintlify 控制面板中，前往 [Single Sign-On](https://dashboard.mintlify.com/settings/organization/sso) 页面。
    2. 点击 **Configure**。
    3. 选择 **Microsoft Entra ID SAML**。
    4. 复制 **Single sign on URL** 和 **Audience URI**。
  </Step>
  <Step title="在 Microsoft Entra 中创建企业应用程序">
    1. 在 Microsoft Entra 中，前往 **Enterprise applications**。
    2. 选择 **New application**。
    3. 选择 **Create your own application**。
    4. 选择 “Integrate any other application you don't find in the gallery (Non-gallery).”
  </Step>
  <Step title="在 Microsoft Entra 中配置 SAML">
    1. 在 Microsoft Entra 中，前往 **Single Sign-On**。
    2. 选择 **SAML**。
    3. 在 **Basic SAML Configuration** 中，输入以下内容：
        * **Identifier (Entity ID)**：来自 Mintlify 的 Audience URI
        * **Reply URL (Assertion Consumer Service URL)**：来自 Mintlify 的 Single sign on URL

    将其他字段留空，然后选择 **Save**。
  </Step>
  <Step title="在 Microsoft Entra 中配置 Attributes & Claims">
    1. 在 Microsoft Entra 中，前往 **Attributes & Claims**。
    2. 在 “Required Claim” 下选择 **Unique User Identifier (Name ID)**。
    3. 将 Source attribute 更改为 `user.primaryauthoritativeemail`。
    4. 在 **Additional claims** 下，创建如下内容：
        | Name | Value |
        | ---- | ----- |
        | `firstName` | `user.givenname` |
        | `lastName` | `user.surname` |
  </Step>
  <Step title="复制 Microsoft Entra 元数据 URL">
    在 **SAML Certificates** 下，复制 **App Federation Metadata URL**。
  </Step>
  <Step title="在 Mintlify 中保存">
    回到 Mintlify 控制面板，粘贴该元数据 URL 并点击 **Save changes**。
  </Step>
  <Step title="分配用户">
    在 Microsoft Entra 中，前往 **Users and groups**。为需要访问 Mintlify 控制面板的用户分配访问权限。
  </Step>
</Steps>

<div id="jit-provisioning">
  ## JIT 即时开通
</div>

当你启用 JIT（即时）开通时，通过你的身份提供商登录的用户会被自动加入到你的 Mintlify 组织中。

要启用 JIT 即时开通，你必须先启用 SSO。前往控制面板中的 [Single Sign-On](https://dashboard.mintlify.com/settings/organization/sso) 页面，完成 SSO 设置，然后启用 JIT 即时开通。

<div id="change-or-remove-sso-provider">
  ## 更改或移除 SSO 提供商
</div>

1. 在仪表板中前往 [Single Sign-On](https://dashboard.mintlify.com/settings/organization/sso) 页面。
2. 点击 **Configure**。
3. 选择你的首选 SSO 提供商，或选择不使用 SSO。

如果你移除 SSO，用户必须改为通过密码、magic link 或 Google OAuth 进行身份验证。

<div id="other-providers">
  ## 其他提供商
</div>

如果你使用的不是 Microsoft Entra 或 Okta SAML，而是其他提供商，请[联系我们](mailto:support@mintlify.com)以配置 SSO。

<div id="google-workspace-saml">
  ### Google Workspace（SAML）
</div>

<Steps>
  <Step title="创建应用">
    1. 在 Google Workspace 中，进入 **Web and mobile apps**。
    2. 在 **Add app** 下拉菜单中选择 **Add custom SAML app**。
    <Frame>
      ![Screenshot of the Google Workspace SAML application creation page with the "Add custom SAML app" menu item highlighted](/images/gsuite-add-custom-saml-app.png)
    </Frame>
  </Step>
  <Step title="将你的 IdP 信息发送给我们">
    复制提供的 SSO URL、Entity ID 和 X.509 证书，并将其发送给 Mintlify 团队。
    <Frame>
      ![Screenshot of the Google Workspace SAML application page with the SSO URL, Entity ID, and x509 certificate highlighted. The specific values for each of these are blurred out.](/images/gsuite-saml-metadata.png)
    </Frame>
  </Step>
  <Step title="配置集成">
    在 Service provider details 页面中输入以下内容：

    * ACS URL（由 Mintlify 提供）
    * Entity ID（由 Mintlify 提供）
    * Name ID format：`EMAIL`
    * Name ID：`Basic Information > Primary email`

    <Frame>
      ![Screenshot of the Service provider details page with the ACS URL and Entity ID input fields highlighted.](/images/gsuite-sp-details.png)
    </Frame>

    在下一页中，输入以下属性声明：

    | Google Directory Attribute | App Attribute |
    | -------------------------- | ------------- |
    | `First name` | `firstName` |
    | `Last name` | `lastName` |

    完成此步骤并将用户分配给该应用后，请告知我们的团队，我们会为你的账户启用 SSO。
  </Step>
</Steps>

<div id="okta-oidc">
  ### Okta（OIDC）
</div>

<Steps>
  <Step title="Create an application">
    在 Okta 中，在 **Applications** 下使用 OIDC 创建一个新的应用集成。选择 **Web Application** 应用类型。
  </Step>
  <Step title="Configure integration">
    选择 Authorization Code（授权码）授权类型，并输入由 Mintlify 提供的重定向 URI（Redirect URI）。
  </Step>
  <Step title="Send us your IdP information">
    前往 **General** 选项卡，找到 client ID 和 client secret。请将这些信息以及你的 Okta 实例 URL（例如 `<your-tenant-name>.okta.com`）安全地提供给我们。你可以通过 1Password 或 SendSafely 等服务安全地发送这些信息。
  </Step>
</Steps>
