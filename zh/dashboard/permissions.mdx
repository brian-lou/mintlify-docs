---
title: "部署权限"
description: "了解你组织内部成员与其他贡献者在部署权限上的差异。"
keywords: ["editor access", "permissions", "team", "seats", "deployment"]
---

拥有 editor 或 admin [role](/zh/dashboard/roles) 的用户可以使用 Web 编辑器、触发部署，并在仪表板中管理集成。当 editor 或 admin 通过 Web 编辑器发布内容，或将 pull request 合并到你的文档仓库时，这些更改会自动部署到你的线上站点。

任何有权访问你文档仓库的人，都可以通过向仓库推送更改来为文档做出贡献，但在 editor 或 admin 从仪表板中手动触发部署之前，这些更改不会部署到你的线上站点。
