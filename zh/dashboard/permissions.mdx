title: "部署权限"
description: "了解组织内成员与其他贡献者在部署权限上的差异。"
keywords: ["编辑访问权限", "权限", "团队", "席位", "部署"]
---

被授予 editor 或 admin [role](/zh/dashboard/roles) 的用户可以使用网页编辑器、触发部署，并在你的仪表盘中管理集成。当 editor 或 admin 通过网页编辑器发布内容，或将拉取请求合并到你的文档仓库时，相关更改会自动部署到你的线上站点。

任何有权访问你的文档仓库的人都可以通过向仓库推送更改来为文档做出贡献，但这些更改只有在 editor 或 admin 从你的仪表盘手动触发部署后才会部署上线。
