您的 Pro 计划包含迁移服务，可将您的文档迁移至 Mintlify。本指南将介绍迁移流程、交付时间安排以及我们的质量保证做法。

<div id="what-to-expect-for-your-migration">
  ## 迁移过程中你可以预期什么
</div>

迁移是对你的文档进行的一次性转移，需要冻结代码。我们会迁移你的文档、品牌元素 (logo、颜色和字体) 、API 参考页面以及导航结构。

迁移服务包含一个用于查看进度的预发布链接，以及交付后 3 天的反馈期，用于处理任何与内容、资源或品牌相关的问题。

<Info>
  迁移服务**不**包括：

  * 文档的动态同步
  * 设计或信息架构咨询
  * 自定义组件开发 (落地页、自定义集成等) 
  * 重定向配置
  * 分析配置
</Info>

<div id="migration-process">
  ## 迁移流程
</div>

<Steps>
  <Step title="提交迁移表单">
    提交[迁移表单](https://mintlify.typeform.com/pro-migrations)。

    请提供您的文档来源、品牌资产 (徽标、颜色代码、字体) 、OpenAPI 规范、上线日期，以及您偏好的交付方式 (GitHub PR 或 zip 文件) 。
  </Step>

  <Step title="接收范围评估和时间安排（1–2 个工作日）">
    我们会审核您提交的内容，并在 24–48 小时内提供预计交付时间安排。如有任何自定义组件或迁移中的部分内容需要进一步讨论，我们也会一并说明。
  </Step>

  <Step title="在迁移过程中查看进度">
    我们会开始迁移，并分享一个预发布链接，方便您实时跟踪进度。
  </Step>

  <Step title="接收最终交付结果">
    我们会根据您的偏好，通过 GitHub PR 或 zip 文件交付迁移结果。
  </Step>

  <Step title="反馈期（3 个工作日）">
    如果您对内容、资源或品牌呈现有任何反馈，请在此期间提交。对于范围内的所有问题，我们都会在同一期限内处理完成。
  </Step>

  <Step title="上线支持">
    我们会提供相关文档和指导，帮助您连接代码仓库、设置重定向并配置自定义域名。
  </Step>
</Steps>

<div id="quality-assurance">
  ## 质量保证
</div>

我们与经过严格筛选的第三方供应商合作，并在交付前进行内部质量审核。以下是我们的检查内容：

<Card title="内容完整性" icon="file-check">
  * 你源文档中的所有内容都已完成迁移。
  * 内容已使用 Mintlify 组件正确排版。
  * 导航结构符合你的要求。
</Card>

<Card title="视觉元素" icon="palette">
  * 图片和视频均可正常显示。
  * 自定义字体已在全站正确应用。
  * 浅色和深色模式下的 logo 均已正确使用。
  * 配色方案在两种模式下都符合对比度要求。
</Card>

<Card title="功能" icon="rocket">
  * 所有链接均可正常访问 (无失效链接) 。
  * 目录可正常渲染。
  * React 组件运行符合预期。
  * 不存在性能问题。
</Card>

<div id="after-your-migration">
  ## 迁移完成后
</div>

在我们交付迁移成果后，您需要完成以下步骤才能正式发布文档：

1. [连接您的 GitHub 仓库并完成设置](https://www.mintlify.com/docs/quickstart#install-the-github-app)。
2. [如有需要，设置重定向](https://www.mintlify.com/docs/create/redirects)。
3. [配置自定义域名](https://www.mintlify.com/docs/customize/custom-domain)。
4. **正式上线前先进行测试** - 在从旧版文档切换过来之前：
   * 检查预发布链接中的所有页面。
   * 测试导航和搜索功能。
   * 确认所有图片和视频都能正常加载。
   * 检查代码块是否正常渲染。
   * 在移动端和桌面端分别进行测试。
5. **上线！** 您的文档已可正式发布！

<Note>
  **需要帮助？** 我们的支持团队可为您提供指导，协助您完成这些步骤。请通过 [support@mintlify.com](mailto:support@mintlify.com) 联系我们。
</Note>

<div id="frequently-asked-questions">
  ## 常见问题
</div>

<AccordionGroup>
  <Accordion title="迁移需要多长时间？">
    我们通常会在 10 个工作日内完成迁移，具体时长取决于复杂程度。提交迁移表单后的 24–48 小时内，你会收到明确的时间安排。
  </Accordion>

  <Accordion title="交付后可以申请修改吗？">
    可以。交付后，你有 3 天的反馈期，可申请修改内容、资源或品牌相关元素。对于范围内的所有反馈，我们都会在同一时间内处理完成。
  </Accordion>

  <Accordion title="迁移完成后我需要做什么？">
    迁移会转移你的内容，但你还需要：

    * 将你的文档仓库连接到 Mintlify 控制面板。
    * 为旧的文档 URL 设置重定向。
    * 配置你的自定义域名。

    我们会为每个步骤提供分步文档和支持。
  </Accordion>

  <Accordion title="我可以自定义导航结构吗？">
    可以。你可以在迁移表单中提供自定义的信息架构，我们会按此实现。不过，自定义组件开发 (例如自定义落地页) 不包含在迁移服务中。
  </Accordion>

  <Accordion title="如果我的文档在迁移期间发生变更，会怎样？">
    由于迁移需要冻结代码，提交后对源文档所做的任何更改都不会包含在本次迁移中。我们建议你在开始迁移前完成所有更新。
  </Accordion>
</AccordionGroup>
