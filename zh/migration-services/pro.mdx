你的 Pro 方案包含迁移服务，可将你的文档迁移到 Mintlify。本指南介绍迁移流程、交付时间安排，以及我们的质量保证机制。

<div id="what-to-expect-for-your-migration">
  ## 迁移期间可以期待什么
</div>

迁移是在某一时间点对你的文档进行的一次性转移，期间需要代码冻结。我们会迁移你的文档、品牌形象（标志、颜色和字体）、API 参考页面以及导航结构。

你的迁移将包含一个用于查看进度的预览链接，以及交付后 3 天的反馈窗口期，用于处理与内容、资源或品牌相关的任何问题。

<Info>
迁移服务**不**包括：
- 文档的动态同步
- 设计或信息架构咨询
- 自定义组件开发（落地页、自定义集成等）
- 重定向设置
- 分析工具设置
</Info>

<div id="migration-process">
  ## 迁移流程
</div>

<Steps>
  <Step title="提交迁移表单">
    提交 [迁移表单](https://mintlify.typeform.com/pro-migrations)。
    
    提供你的文档来源、品牌资产（logo、色值代码、字体）、OpenAPI 规范、上线日期，以及首选的交付方式（GitHub PR 或 zip 文件）。
  </Step>
  
  <Step title="获取范围评估与时间规划（1-2 个工作日）">
    我们会审核你的提交内容，并在 24-48 小时内提供预估交付时间表。我们会标记出需要进一步沟通的自定义组件或迁移中的特殊部分。
  </Step>
  
  <Step title="在迁移过程中查看进度">
    我们开始迁移，并提供预发布环境链接，方便你实时查看进度。
  </Step>
  
  <Step title="接收最终交付成果">
    我们会根据你的偏好，通过 GitHub PR 或 zip 文件交付迁移成果。
  </Step>
  
  <Step title="反馈窗口期（三个工作日）">
    提交你对内容、资产或品牌相关的任何反馈。我们会在该时间范围内处理所有在范围内的问题。
  </Step>
  
  <Step title="上线支持">
    我们会提供文档和指导，帮助你连接代码仓库、设置重定向并配置自定义域名。
  </Step>
</Steps>

<div id="quality-assurance">
  ## 质量保证
</div>

我们与经过筛选的第三方供应商合作，并在交付前进行内部质量审计。我们会重点检查以下内容：

<Card title="内容完整性" icon="file-check">
  - 您源站中的所有文档都已完成迁移。
  - 内容已使用 Mintlify 组件进行正确排版。
  - 导航结构与您的要求保持一致。
</Card>

<Card title="视觉元素" icon="palette">
  - 图片和视频显示正常。
  - 自定义字体已在全站范围内正确应用。
  - 浅色和深色模式下的徽标使用得当。
  - 配色方案在两种模式下均满足对比度要求。
</Card>

<Card title="功能性" icon="rocket">
  - 所有链接均可正常访问（无失效链接）。
  - 目录渲染正常。
  - React 组件按预期运行。
  - 无性能问题。
</Card>

<div id="after-your-migration">
  ## 迁移完成之后
</div>

在我们交付迁移结果后，你需要完成以下步骤来上线文档：

1. [连接你的 GitHub 仓库并完成设置](https://www.mintlify.com/docs/quickstart#install-the-github-app)。
2. [如有需要，设置重定向](https://www.mintlify.com/docs/create/redirects)。
3. [配置你的自定义域名](https://www.mintlify.com/docs/customize/custom-domain)。
4. **上线前测试** - 在从旧文档切换之前：
   - 在你的预发布链接中检查所有页面。
   - 测试导航和搜索功能。
   - 确认所有图片和视频都能正确加载。
   - 检查代码块是否正确渲染。
   - 在移动端和桌面端进行测试。
5. **上线！** 你的文档已经可以正式发布了！

<Note>
  **需要帮助？** 我们的支持团队可以为你全程提供指导。欢迎通过 [support@mintlify.com](mailto:support@mintlify.com) 与我们联系。
</Note>

<div id="frequently-asked-questions">
  ## 常见问题
</div>

<AccordionGroup>
  <Accordion title="一次迁移需要多长时间？">
    我们通常会在 10 个工作日内完成迁移，具体时间取决于复杂度。提交迁移表单后的 24–48 小时内，您会收到一份具体时间表。
  </Accordion>
  
  <Accordion title="交付之后我可以要求修改吗？">
    可以。交付后您有 3 天的反馈期，可以提出对内容、资源或品牌相关内容的修改需求。对于所有在服务范围内的反馈，我们都会在同样的时间范围内处理完成。
  </Accordion>
  
  <Accordion title="迁移完成后我需要做什么？">
    迁移会帮您完成内容转移，但您还需要：
    - 将您的文档仓库连接到 Mintlify 仪表盘。
    - 为旧文档 URL 设置重定向。
    - 配置您的自定义域名。
    
    我们会为上述每一步提供详细的操作文档和支持。
  </Accordion>
  
  <Accordion title="我可以自定义导航结构吗？">
    可以。您可以在迁移表单中提供自定义的信息架构，我们会为您实现。但自定义组件开发（例如自定义落地页）不包含在迁移服务中。
  </Accordion>
  
  <Accordion title="如果在迁移过程中我的文档发生了变更怎么办？">
    由于迁移期间需要代码冻结，在您提交之后对源文档所做的任何更改都不会被包含在内。我们建议在开始迁移之前先完成所有更新。
  </Accordion>
</AccordionGroup>
