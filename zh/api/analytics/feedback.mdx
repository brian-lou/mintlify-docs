<div id="usage">
  ## 用法
</div>

使用此 endpoint 来导出从文档中收集的用户反馈。反馈包括页面评分产生的上下文反馈以及代码片段反馈。

使用响应中返回的 `cursor` 参数对结果进行分页。当 `hasMore` 为 `true` 时继续获取。

<div id="filtering">
  ## 筛选
</div>

按以下条件筛选反馈：

- **日期范围**：使用 `dateFrom` 和 `dateTo` 将结果限定在特定时间段内
- **来源**：按 `code_snippet` 或 `contextual` 反馈类型进行筛选
- **状态**：按状态值进行筛选，例如 `pending`、`in_progress`、`resolved` 或 `dismissed`

<div id="response-types">
  ## 响应类型
</div>

响应会根据来源包含不同类型的反馈：

- **上下文反馈**：包含 `helpful` 布尔值以及可选的 `contact` 电子邮箱
- **代码片段反馈**：包含 `code`、`filename` 和 `lang` 字段
