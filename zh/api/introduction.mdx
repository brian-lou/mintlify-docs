Mintlify REST API 使你能够以编程方式操作你的文档、触发更新、嵌入 AI 驱动的对话体验，并导出分析数据。

<div id="endpoints">
  ## 端点
</div>

* [触发更新](/zh/api/update/trigger): 在需要时触发站点更新。
* [获取更新状态](/zh/api/update/status): 获取某次更新的状态以及你的文档的其他相关信息。
* [创建 agent 任务](/zh/api/agent/create-agent-job): 创建一个 agent 任务以自动编辑你的文档。
* [获取 agent 任务](/zh/api/agent/get-agent-job): 获取特定 agent 任务的详细信息和状态。
* [获取所有 agent 任务](/zh/api/agent/get-all-jobs): 获取某个域名下的所有 agent 任务。
* [生成 assistant 消息](/zh/api/assistant/create-assistant-message): 将基于你的文档训练的 assistant 嵌入到任意你选择的应用中。
* [搜索文档](/zh/api/assistant/search): 在你的文档中搜索。
* [获取用户反馈](/zh/api/analytics/feedback): 导出来自文档的用户反馈。
* [获取 assistant 会话](/zh/api/analytics/assistant-conversations): 导出 AI assistant 的会话记录。

<div id="common-use-cases">
  ### 常见用例
</div>

* **自动化部署**：使用 [Trigger update](/zh/api/update/trigger) 和 [Get update status](/zh/api/update/status)，在预设时间间隔或特定事件发生时触发网站更新。
* **CI/CD 集成**：在代码变更时，通过在部署流水线中调用 [Trigger update](/zh/api/update/trigger) 来更新文档。
* **自定义集成**：使用 [Generate assistant message](/zh/api/assistant/create-assistant-message) 和 [Search documentation](/zh/api/assistant/search)，将 AI 助手嵌入到你的产品、支持门户或内部工具中。
* **自动化编辑**：使用 agent 任务配合 [Create agent job](/zh/api/agent/create-agent-job)、[Get agent job](/zh/api/agent/get-agent-job) 和 [Get all agent jobs](/zh/api/agent/get-all-jobs)，以编程方式批量更新文档。
* **分析数据导出**：使用 [Get user feedback](/zh/api/analytics/feedback) 和 [Get assistant conversations](/zh/api/analytics/assistant-conversations) 导出反馈和助手对话，以便进行外部分析。

<div id="authentication">
  ## 身份验证
</div>

在仪表盘的 [API Keys 页面](https://dashboard.mintlify.com/settings/organization/api-keys) 中生成 API 密钥。每个 API 密钥都隶属于一个组织，你可以在同一组织内的多个部署中使用这些密钥。

每个组织每小时最多可以创建 10 个 API 密钥。

<div id="admin-api-key">
  ### Admin API key
</div>

使用 Admin API key 对以下接口请求进行认证：[Trigger update](/zh/api/update/trigger)、[Get update status](/zh/api/update/status)、[Create agent job](/zh/api/agent/create-agent-job)、[Get agent job](/zh/api/agent/get-agent-job)、[Get all agent jobs](/zh/api/agent/get-all-jobs)、[Get user feedback](/zh/api/analytics/feedback) 以及 [Get assistant conversations](/zh/api/analytics/assistant-conversations)。

Admin API key 以 `mint_` 作为前缀。

Admin API key 是服务端密钥，请不要在客户端代码中暴露它。

<div id="assistant-api-key">
  ### Assistant API 密钥
</div>

使用 Assistant API 密钥对发往 [Generate assistant message](/zh/api/assistant/create-assistant-message) 和 [Search documentation](/zh/api/assistant/search) 端点的请求进行身份验证。

Assistant API 密钥以 `mint_dsc_` 前缀开头。

Assistant API 密钥是一个公开令牌，你可以在前端代码中引用它。

<Note>
  使用 Assistant API 令牌进行的调用可能会产生费用：要么消耗你的 assistant 额度，要么产生超额费用。
</Note>
