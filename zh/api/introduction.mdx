Mintlify REST API 让你能够以编程方式与你的文档进行交互、触发更新、嵌入 AI 驱动的聊天功能，以及导出分析数据。

<div id="endpoints">
  ## 端点
</div>

* [触发更新](/zh/api/update/trigger): 按需触发站点更新。
* [获取更新状态](/zh/api/update/status): 获取更新状态及文档的其他详细信息。
* [创建代理任务](/zh/api/agent/create-agent-job): 创建代理任务，自动编辑你的文档。
* [获取代理任务](/zh/api/agent/get-agent-job): 获取特定代理任务的详细信息和状态。
* [获取所有代理任务](/zh/api/agent/get-all-jobs): 获取某个域名的所有代理任务。
* [生成助手消息](/zh/api/assistant/create-assistant-message): 将基于你的文档训练的助手嵌入到你选择的任意应用中。
* [搜索文档](/zh/api/assistant/search): 搜索你的文档。
* [获取用户反馈](/zh/api/analytics/feedback): 导出文档中的用户反馈。
* [获取助手对话](/zh/api/analytics/assistant-conversations): 导出 AI 助手的对话历史记录。

<div id="common-use-cases">
  ### 常见用例
</div>

* **自动化部署**：使用 [触发更新](/zh/api/update/trigger) 和 [获取更新状态](/zh/api/update/status)，按设定的时间间隔或在事件发生时触发站点更新。
* **CI/CD 集成**：当代码发生变更时，使用 [触发更新](/zh/api/update/trigger) 将文档更新纳入部署流水线。
* **自定义集成**：使用 [生成助手消息](/zh/api/assistant/create-assistant-message) 和 [搜索文档](/zh/api/assistant/search)，将 AI 助手嵌入你的产品、支持门户或内部工具中。
* **自动化编辑**：使用 [创建代理任务](/zh/api/agent/create-agent-job)、[获取代理任务](/zh/api/agent/get-agent-job) 和 [获取所有代理任务](/zh/api/agent/get-all-jobs)，通过代理任务以编程方式大规模更新文档。
* **分析导出**：使用 [获取用户反馈](/zh/api/analytics/feedback) 和 [获取助手对话](/zh/api/analytics/assistant-conversations) 导出反馈和助手对话，以便进行外部分析。

<div id="authentication">
  ## 身份验证
</div>

在控制面板的 [API 密钥页面](https://dashboard.mintlify.com/settings/organization/api-keys)生成 API 密钥。每个 API 密钥都归属于一个组织，你可以在同一组织内的多个部署中使用这些密钥。

每个组织每小时最多可创建 10 个 API 密钥。

<div id="admin-api-key">
  ### 管理员 API 密钥
</div>

使用管理员 API 密钥对 [触发更新](/zh/api/update/trigger)、[获取更新状态](/zh/api/update/status)、[创建代理任务](/zh/api/agent/create-agent-job)、[获取代理任务](/zh/api/agent/get-agent-job)、[获取所有代理任务](/zh/api/agent/get-all-jobs)、[获取用户反馈](/zh/api/analytics/feedback) 和 [获取助手对话](/zh/api/analytics/assistant-conversations) 的请求进行身份验证。

管理员 API 密钥以 `mint_` 为前缀。

管理员 API 密钥是服务器端密钥。不要在客户端代码中暴露它。

<div id="assistant-api-key">
  ### 助手 API 密钥
</div>

使用助手 API 密钥对调用 [生成助手消息](/zh/api/assistant/create-assistant-message) 和 [搜索文档](/zh/api/assistant/search) 端点的请求进行身份验证。

助手 API 密钥均以 `mint_dsc_` 为前缀。

助手 API 密钥是一种公开令牌，您可以在前端代码中引用它。

<Note>
  使用助手 API 令牌发起调用可能会产生费用：可能会消耗您的助手额度，或产生超额费用。
</Note>
