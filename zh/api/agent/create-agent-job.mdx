此端点会根据提供的消息和分支信息创建一个代理任务。该任务以异步方式执行，并通过流式响应返回执行详情和结果。

如果分支不存在，代理会创建一个新分支。若文件编辑成功，任务结束时会自动创建一个拉取请求（Pull Request）。

<div id="rate-limits">
  ## 调用频率限制
</div>

Agent API 具有以下限制：

- 每个 Mintlify 项目每小时最多可调用 100 次

<div id="suggested-usage">
  ## 建议用法
</div>

为了获得最佳效果，请使用 [ai-sdk 中的 useChat hook](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat#usechat) 来发送请求并处理响应。
