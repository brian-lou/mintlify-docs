keywords: [ "代理任务", "创建", "自动化", "自动执行" ]

此接口会根据提供的消息和分支信息创建一个代理任务。该任务会异步执行，并返回包含执行详情和结果的流式响应。

如果分支不存在，代理会自动创建一个分支。如果文件编辑成功，则会在任务结束时自动创建拉取请求。

<div id="rate-limits">
  ## 速率限制
</div>

代理 API 有以下限制：

* 每个 Mintlify 项目每小时最多可使用 100 次

<div id="suggested-usage">
  ## 推荐用法
</div>

为获得最佳效果，请使用 [ai-sdk 提供的 useChat hook](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat#usechat) 来发送请求并处理响应。
