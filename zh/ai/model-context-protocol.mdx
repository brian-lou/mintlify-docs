<div id="about-mcp-servers">
  ## 关于 MCP 服务器
</div>

模型上下文协议 (MCP) 是一种开放协议，用于在 AI 应用与外部服务 (如文档) 之间建立标准化连接。Mintlify 会根据你的文档生成一个 MCP 服务器，让你的内容接入更广泛的 AI 生态，使 Claude、Cursor、Goose、ChatGPT 等 MCP 客户端都能连接到你的文档。

你的 MCP 服务器会向 AI 应用提供一个搜索工具，用于查询你的文档。用户必须将你的 MCP 服务器连接到他们使用的工具。

<div id="how-mcp-servers-work">
  ### MCP 服务器如何工作
</div>

当 AI 应用连接到你的文档 MCP 服务器时，它就可以直接搜索你的文档，而不必根据用户提示去执行通用的网页搜索。你的 MCP 服务器可访问文档站点中所有已编入索引的内容。

* AI 应用可以在生成回复时主动搜索你的文档，而不只是等到被明确要求后才搜索。
* AI 应用会根据对话的上下文以及你的文档是否相关，判断何时使用搜索工具。
* 每次搜索 (工具调用) 都会发生在生成过程中，因此 AI 应用会从你的文档中检索最新信息来生成回复。

<Tip>
  某些 AI 工具 (如 Claude) 同时支持 MCP 和 Skills。MCP 让 AI 可以访问你的文档内容，而 Skills 则告诉 AI 如何高效使用这些内容。两者相辅相成：MCP 提供数据，Skills 提供指引。
</Tip>

<div id="search-filtering-parameters">
  ### 搜索筛选参数
</div>

MCP 搜索工具支持可选筛选参数，AI 应用可以使用这些参数来缩小搜索结果范围。

* **`version`**：将结果筛选到特定文档版本。例如，`'v0.7'`。仅返回带有指定版本标签的内容，或适用于所有版本的内容。
* **`language`**：将结果筛选到特定语言代码。例如，`'en'`、`'zh'` 或 `'es'`。仅返回指定语言的内容，或适用于所有语言的内容。
* **`apiReferenceOnly`**：设置为 `true` 时，仅返回 API 参考文档页面。
* **`codeOnly`**：设置为 `true` 时，仅返回代码片段和示例。

AI 应用会根据用户查询的上下文判断何时应用这些筛选条件。例如，如果用户询问特定的 API 版本或请求代码示例，AI 应用可能会自动应用相应的筛选条件，以提供更相关的结果。

<div id="mcp-compared-to-web-search">
  ### MCP 与网页搜索相比
</div>

AI 工具可以搜索网页，但对于文档来说，MCP 有明显优势。

* **直接访问源内容**：网页搜索依赖搜索引擎已收录的内容，而这些内容可能已经过时或不完整。MCP 则会直接搜索你当前已建立索引的文档。
* **集成式工作流**：MCP 允许 AI 在生成回答时直接搜索，而不需要单独进行一次网页搜索。
* **没有搜索噪声**：SEO 和排名算法会影响网页搜索结果。MCP 会直接检索你的文档内容。

<div id="access-your-mcp-server">
  ## 访问你的 MCP 服务器
</div>

<Note>
  MCP 服务器仅适用于公开文档。受终端用户身份验证保护的文档无法生成 MCP 服务器。
</Note>

Mintlify 会自动为你的文档生成一个 MCP 服务器，并将其托管在文档 URL 的 `/mcp` 路径下。例如，Mintlify 的 MCP 服务器可通过 `https://mintlify.com/docs/mcp` 访问。

你可以在控制台的 [MCP 服务器页面](https://dashboard.mintlify.com/products/mcp) 查看并复制 MCP 服务器 URL。

<div id="content-filtering-and-indexing">
  ## 内容过滤与索引
</div>

你的 MCP 服务器会搜索 Mintlify 从你的文档仓库中编入索引的内容。文件处理和搜索索引决定了哪些内容可通过你的 MCP 服务器访问。

<div id="file-processing-with-mintignore">
  ### 使用 `.mintignore` 处理文件
</div>

如果文件匹配 [.mintignore](/zh/organize/mintignore) 中的模式，Mintlify 不会处理或索引这些文件。这些文件无法通过你的 MCP 服务器访问。

<div id="search-indexing-with-docsjson">
  ### 使用 `docs.json` 配置搜索索引
</div>

默认情况下，Mintlify 仅会将 `docs.json` 导航中包含的页面编入索引，以供你的 MCP 服务器搜索。

除非你选择为所有页面编入索引，否则 Mintlify 会将[隐藏页面](/zh/organize/hidden-pages) (即未包含在导航中的页面) 排除在搜索索引之外。若要让隐藏页面出现在 MCP 服务器的搜索结果中，请在 `docs.json` 中添加 `seo.indexing` 属性。

```json
"seo": {
    "indexing": "all"
}
```

要将特定页面从搜索索引中排除，请在其前置元数据中添加 `noindex: true`。

```mdx
---
title: "隐藏页面"
description: "此页面不在导航中，也无法通过搜索访问。"
noindex: true
---
```

<div id="use-your-mcp-server">
  ## 使用你的 MCP 服务器
</div>

你的用户必须将你的 MCP 服务器连接到他们常用的 AI 工具。

1. 确保你的 MCP 服务器 URL 可公开访问。
2. 用户复制你的 MCP 服务器 URL，并将其添加到自己的工具中。
3. 用户通过这些工具访问你的文档。

以下是你可以帮助用户连接到 MCP 服务器的几种方式：

<Tabs>
  <Tab title="上下文菜单">
    在[上下文菜单](/zh/ai/contextual-menu)中添加选项，让用户可以从文档的任意页面连接到你的 MCP 服务器。

    | 选项                 | 标识符      | 说明                        |
    | :----------------- | :------- | :------------------------ |
    | **复制 MCP 服务器 URL** | `mcp`    | 将你的 MCP 服务器 URL 复制到用户剪贴板。 |
    | **连接到 Cursor**     | `cursor` | 在 Cursor 中安装你的 MCP 服务器。   |
    | **连接到 VS Code**    | `vscode` | 在 VS Code 中安装你的 MCP 服务器。  |
  </Tab>

  <Tab title="Claude">
    <Steps>
      <Step title="获取你的 MCP 服务器 URL。">
        前往你的 [控制台](https://dashboard.mintlify.com/products/mcp)，找到你的 MCP 服务器 URL。
      </Step>

      <Step title="向用户发布你的 MCP 服务器 URL。">
        为用户创建一份指南，其中包含你的 MCP 服务器 URL 以及将其连接到 Claude 的步骤。

        1. 前往 Claude 设置中的 [Connectors](https://claude.ai/settings/connectors) 页面。
        2. 选择 **Add custom connector**。
        3. 添加你的 MCP 服务器名称和 URL。
        4. 选择 **Add**。
        5. 使用 Claude 时，点击附件按钮 (加号图标) 。
        6. 选择你的 MCP 服务器。
      </Step>
    </Steps>

    更多详情，请参阅 [Model Context Protocol 文档](https://modelcontextprotocol.io/docs/tutorials/use-remote-mcp-server#connecting-to-a-remote-mcp-server)。
  </Tab>

  <Tab title="Claude Code">
    <Steps>
      <Step title="获取你的 MCP 服务器 URL。">
        前往你的 [控制台](https://dashboard.mintlify.com/products/mcp)，找到你的 MCP 服务器 URL。
      </Step>

      <Step title="向用户发布你的 MCP 服务器 URL。">
        为用户创建一份指南，其中包含你的 MCP 服务器 URL 以及将其连接到 Claude Code 的命令。

        ```bash
        claude mcp add --transport http <name> <url>
        ```
      </Step>
    </Steps>

    更多详情，请参阅 [Claude Code 文档](https://docs.anthropic.com/en/docs/claude-code/mcp#installing-mcp-servers)。
  </Tab>

  <Tab title="Cursor">
    <Steps>
      <Step title="获取你的 MCP 服务器 URL。">
        前往你的 [控制台](https://dashboard.mintlify.com/products/mcp)，找到你的 MCP 服务器 URL。
      </Step>

      <Step title="向用户发布你的 MCP 服务器 URL。">
        为用户创建一份指南，其中包含你的 MCP 服务器 URL 以及将其连接到 Cursor 的步骤。

        1. 使用 <kbd>Command</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (Windows 上为 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>) 打开命令面板。
        2. 搜索 “Open MCP settings”。
        3. 选择 **Add custom MCP**。这会打开 `mcp.json` 文件。
        4. 在 `mcp.json` 中配置你的服务器：

        ```json
        {
          "mcpServers": {
            "<your-mcp-server-name>": {
              "url": "<your-mcp-server-url>"
            }
          }
        }
        ```
      </Step>
    </Steps>

    更多详情，请参阅 [Cursor 文档](https://docs.cursor.com/en/context/mcp#installing-mcp-servers)。
  </Tab>

  <Tab title="VS Code">
    <Steps>
      <Step title="获取你的 MCP 服务器 URL。">
        前往你的 [控制台](https://dashboard.mintlify.com/products/mcp)，找到你的 MCP 服务器 URL。
      </Step>

      <Step title="向用户发布你的 MCP 服务器 URL。">
        为用户创建一份指南，其中包含你的 MCP 服务器 URL 以及将其连接到 VS Code 的步骤。

        1. 创建一个 `.vscode/mcp.json` 文件。
        2. 在 `mcp.json` 中配置你的服务器：

        ```json
        {
          "servers": {
            "<your-mcp-server-name>": {
              "type": "http",
              "url": "<your-mcp-server-url>"
            }
          }
        }
        ```
      </Step>
    </Steps>

    更多详情，请参阅 [VS Code 文档](https://code.visualstudio.com/docs/copilot/chat/mcp-servers)。
  </Tab>
</Tabs>

<div id="example-connect-to-the-mintlify-mcp-server">
  ### 示例：连接到 Mintlify MCP 服务器
</div>

连接到 Mintlify MCP 服务器，以便在你常用的 AI 工具中搜索本文档站点。这样，你就能更准确地获取有关如何在本地环境中使用 Mintlify 的答案，也能了解如何帮助你的用户连接到你的 MCP 服务器。

<Tabs>
  <Tab title="上下文菜单">
    在本页顶部，打开上下文菜单，然后选择 **Connect to Cursor** 或 **Connect to VS Code**，将 Mintlify MCP 服务器连接到你选择的 IDE。
  </Tab>

  <Tab title="Claude">
    要在 Claude 中使用 Mintlify MCP 服务器，请按以下步骤操作：

    <Steps>
      <Step title="将 Mintlify MCP 服务器添加到 Claude">
        1. 前往 Claude 设置中的 [Connectors](https://claude.ai/settings/connectors) 页面。
        2. 选择 **Add custom connector**。
        3. 添加 Mintlify MCP 服务器：

        * 名称：`Mintlify`
        * URL：`https://mintlify.com/docs/mcp`

        4. 选择 **Add**。
      </Step>

      <Step title="在聊天中访问 MCP 服务器">
        1. 使用 Claude 时，点击附件按钮 (加号图标) 。
        2. 选择 Mintlify MCP 服务器。
        3. 向 Claude 询问有关 Mintlify 的问题。
      </Step>
    </Steps>

    更多详情，请参阅 [Model Context Protocol 文档](https://modelcontextprotocol.io/docs/tutorials/use-remote-mcp-server#connecting-to-a-remote-mcp-server)。
  </Tab>

  <Tab title="Claude Code">
    要在 Claude Code 中使用 Mintlify MCP 服务器，请运行以下命令：

    ```bash
    claude mcp add --transport http Mintlify https://mintlify.com/docs/mcp
    ```

    运行以下命令测试连接：

    ```bash
    claude mcp list
    ```

    更多详情，请参阅 [Claude Code 文档](https://docs.anthropic.com/en/docs/claude-code/mcp#installing-mcp-servers)。
  </Tab>

  <Tab title="Cursor">
    <PreviewButton href="cursor://anysphere.cursor-deeplink/mcp/install?name=mintlify&config=eyJ1cmwiOiJodHRwczovL21pbnRsaWZ5LmNvbS9kb2NzL21jcCJ9">在 Cursor 中安装</PreviewButton>

    要将 Mintlify MCP 服务器连接到 Cursor，请点击 **在 Cursor 中安装** 按钮。或者，如果你想手动连接 MCP 服务器，请按以下步骤操作：

    <Steps>
      <Step title="打开 MCP 设置">
        1. 使用 <kbd>Command</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (Windows 上为 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>) 打开命令面板。
        2. 搜索 &quot;Open MCP settings&quot;。
        3. 选择 **Add custom MCP**。这会打开 `mcp.json` 文件。
      </Step>

      <Step title="配置 Mintlify MCP 服务器">
        在 `mcp.json` 中添加：

        ```json
        {
          "mcpServers": {
            "Mintlify": {
              "url": "https://mintlify.com/docs/mcp"
            }
          }
        }
        ```
      </Step>

      <Step title="测试连接">
        在 Cursor 的聊天中提问：“What tools do you have available?” Cursor 应该会将 Mintlify MCP 服务器显示为可用工具。
      </Step>
    </Steps>

    更多详情，请参阅 Cursor 文档中的 [Installing MCP servers](https://docs.cursor.com/en/context/mcp#installing-mcp-servers)。
  </Tab>

        "Mintlify": {

<div id="using-multiple-mcp-servers">
  ### 使用多个 MCP 服务器
</div>

用户可以将多个 MCP 服务器连接到其 AI 工具。已连接的 MCP 服务器在 AI 调用搜索工具之前不会占用上下文。AI 会根据 query 的相关性决定何时搜索，因此不会针对每个问题搜索所有已连接的服务器。

当 AI 执行搜索时，每个 query 都会返回多个结果，并将其加入对话上下文中。如果 AI 为同一个问题搜索多个服务器，可能会占用大量上下文。

使用多个 MCP 服务器的最佳实践：

* 只连接与当前工作相关的 MCP 服务器。
* 在提示中尽量表达明确，以便 AI 搜索最相关的服务器。
* 断开当前未使用的服务器，以减少潜在的上下文占用。
