<div id="about-mcp-servers">
  ## 关于 MCP 服务器
</div>

Model Context Protocol（MCP，模型上下文协议）是一种开放协议，用于在 AI 应用与外部服务（例如文档）之间创建标准化连接。Mintlify 会基于你的文档生成一个 MCP 服务器，将你的内容准备好接入更广泛的 AI 生态系统，在这个生态中，任何 MCP 客户端（如 Claude、Cursor、Goose、ChatGPT 等）都可以连接到你的文档。

你的 MCP 服务器会提供一个搜索工具，供 AI 应用查询你的文档。你的用户需要在他们所使用的工具中连接你的 MCP 服务器。

<div id="how-mcp-servers-work">
  ### MCP 服务器的工作原理
</div>

当 AI 应用连接到你的文档 MCP 服务器时，它可以直接检索你的文档，而不是在响应用户提问时发起普通的网页搜索。你的 MCP 服务器提供对文档网站上所有已建立索引内容的访问。

* AI 应用可以在生成响应的过程中主动搜索你的文档，而不仅仅是在被明确要求时才搜索。
* AI 应用会根据对话上下文以及你的文档的相关性来决定何时使用搜索工具。
* 每次搜索（工具调用）都发生在生成过程中，因此 AI 应用会从你的文档中检索最新信息来生成响应。

<Tip>
  一些 AI 工具（如 Claude）同时支持 MCP 和 Skills。MCP 让 AI 能访问你的文档内容，而 Skills 则指导 AI 如何高效地使用这些内容。它们相辅相成：MCP 提供数据，Skills 提供使用策略。
</Tip>

<div id="search-filtering-parameters">
  ### 搜索筛选参数
</div>

MCP 搜索工具支持可选的筛选参数，AI 应用可以利用这些参数缩小搜索结果范围。

* **`version`**：将结果限制为特定文档版本。例如，`'v0.7'`。只返回标记为指定版本的内容，或适用于所有版本的内容。
* **`language`**：将结果限制为特定语言代码。例如，`'en'`、`'zh'` 或 `'es'`。只返回指定语言的内容，或适用于所有语言的内容。
* **`apiReferenceOnly`**：当设为 `true` 时，只返回 API 参考文档页面。
* **`codeOnly`**：当设为 `true` 时，只返回代码片段和示例。

AI 应用会根据用户查询的上下文来决定何时应用这些筛选参数。例如，如果用户询问特定 API 版本或请求代码示例，AI 应用可能会自动应用相应的筛选参数，以提供更相关的结果。

<div id="mcp-compared-to-web-search">
  ### MCP 与网页搜索的对比
</div>

AI 工具可以进行网页搜索，但 MCP 在处理文档方面具有独特优势。

* **直接访问源内容**：网页搜索依赖搜索引擎已索引的内容，这些内容可能过时或不完整。MCP 会直接搜索你当前已索引的文档。
* **集成式工作流**：MCP 允许 AI 在生成回答的过程中进行搜索，而不是执行一次单独的网页搜索。
* **没有搜索噪声**：SEO 和排序算法会影响网页搜索结果。MCP 会直接访问你的文档内容。

<div id="access-your-mcp-server">
  ## 访问你的 MCP 服务器
</div>

<Note>
  MCP 服务器仅适用于公开文档。需要终端用户登录验证的文档无法生成 MCP 服务器。
</Note>

Mintlify 会为你的文档自动生成一个 MCP 服务器，并将其托管在文档 URL 下的 `/mcp` 路径。例如，Mintlify 的 MCP 服务器可通过 `https://mintlify.com/docs/mcp` 访问。

在控制台中的 [MCP 服务器页面](https://dashboard.mintlify.com/products/mcp) 查看并复制你的 MCP 服务器 URL。

<div id="content-filtering-and-indexing">
  ## 内容过滤和索引
</div>

你的 MCP 服务器会搜索 Mintlify 从你的文档仓库中建立的索引内容。文件处理和搜索索引决定了哪些内容可以通过你的 MCP 服务器访问。

<div id="file-processing-with-mintignore">
  ### 使用 `.mintignore` 处理文件
</div>

如果文件符合 [.mintignore](/zh/organize/mintignore) 中配置的模式，Mintlify 将不会处理或索引这些文件。这些文件无法通过你的 MCP 服务器访问。

<div id="search-indexing-with-docsjson">
  ### 使用 `docs.json` 进行搜索索引
</div>

默认情况下，Mintlify 只会通过 MCP 服务器为包含在 `docs.json` 导航中的页面建立搜索索引。

除非你选择为所有页面建立索引，否则 Mintlify 会将[隐藏页面](/zh/organize/hidden-pages)（未包含在导航中的页面）排除在搜索索引之外。要在 MCP 服务器的搜索结果中包含隐藏页面，请在 `docs.json` 中添加 `seo.indexing` 属性。

```json
"seo": {
    "indexing": "all"
}
```

要将某个页面从搜索索引中排除，请在其 frontmatter 中添加 `noindex: true`。

```mdx
---
title: "隐藏页面"
description: "此页面不在导航中，也无法通过搜索访问。"
noindex: true
---
```

<div id="use-your-mcp-server">
  ## 使用你的 MCP 服务器
</div>

你的用户必须将你的 MCP 服务器连接到他们首选的 AI 工具。

1. 将你的 MCP 服务器 URL 设置为公开可访问。
2. 用户复制你的 MCP 服务器 URL，并将其添加到他们的工具中。
3. 用户通过他们的工具访问你的文档。

以下是一些你可以用来帮助用户连接到你的 MCP 服务器的方式：

<Tabs>
  <Tab title="上下文菜单">
    在[上下文菜单](/zh/ai/contextual-menu)中添加选项，让用户可以在文档的任何页面连接到你的 MCP 服务器。

    | 选项 | 标识符 | 描述 |
    | :----- | :--------- | :---------- |
    | **复制 MCP 服务器 URL** | `mcp` | 将你的 MCP 服务器 URL 复制到用户的剪贴板。 |
    | **连接到 Cursor** | `cursor` | 在 Cursor 中安装你的 MCP 服务器。 |
    | **连接到 VS Code** | `vscode` | 在 VS Code 中安装你的 MCP 服务器。 |
  </Tab>

  <Tab title="Claude">
    <Steps>
      <Step title="获取你的 MCP 服务器 URL。">
        前往你的[控制台](https://dashboard.mintlify.com/products/mcp)，找到你的 MCP 服务器 URL。
      </Step>

      <Step title="为用户发布你的 MCP 服务器 URL。">
        为你的用户创建一份指南，其中包含你的 MCP 服务器 URL，以及将其连接到 Claude 的步骤。

        1. 在 Claude 设置中，前往 [Connectors](https://claude.ai/settings/connectors) 页面。
        2. 选择 **Add custom connector**。
        3. 添加你的 MCP 服务器名称和 URL。
        4. 选择 **Add**。
        5. 使用 Claude 时，选择附件按钮（加号图标）。
        6. 选择你的 MCP 服务器。
      </Step>
    </Steps>

    查看 [Model Context Protocol 文档](https://modelcontextprotocol.io/docs/tutorials/use-remote-mcp-server#connecting-to-a-remote-mcp-server)以了解更多信息。
  </Tab>

  <Tab title="Claude Code">
    <Steps>
      <Step title="获取你的 MCP 服务器 URL。">
        前往你的[控制台](https://dashboard.mintlify.com/products/mcp)，找到你的 MCP 服务器 URL。
      </Step>

      <Step title="为用户发布你的 MCP 服务器 URL。">
        为你的用户创建一份指南，其中包含你的 MCP 服务器 URL，以及将其连接到 Claude Code 的命令。

        ```bash
        claude mcp add --transport http <name> <url>
        ```
      </Step>
    </Steps>

    查看 [Claude Code 文档](https://docs.anthropic.com/en/docs/claude-code/mcp#installing-mcp-servers)以了解更多信息。
  </Tab>

  <Tab title="Cursor">
    <Steps>
      <Step title="获取你的 MCP 服务器 URL。">
        前往你的[控制台](https://dashboard.mintlify.com/products/mcp)，找到你的 MCP 服务器 URL。
      </Step>

      <Step title="为用户发布你的 MCP 服务器 URL。">
        为你的用户创建一份指南，其中包含你的 MCP 服务器 URL，以及将其连接到 Cursor 的步骤。

        1. 使用 <kbd>Command</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>（在 Windows 上为 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>）打开命令面板。
        2. 搜索 &quot;Open MCP settings&quot;。
        3. 选择 **Add custom MCP**。这会打开 `mcp.json` 文件。
        4. 在 `mcp.json` 中配置你的服务器：

        ```json
        {
          "mcpServers": {
            "<your-mcp-server-name>": {
              "url": "<your-mcp-server-url>"
            }
          }
        }
        ```
      </Step>
    </Steps>

    查看 [Cursor 文档](https://docs.cursor.com/en/context/mcp#installing-mcp-servers)以了解更多信息。
  </Tab>

  <Tab title="VS Code">
    <Steps>
      <Step title="获取你的 MCP 服务器 URL。">
        前往你的[控制台](https://dashboard.mintlify.com/products/mcp)，找到你的 MCP 服务器 URL。
      </Step>

      <Step title="为用户发布你的 MCP 服务器 URL。">
        为你的用户创建一份指南，其中包含你的 MCP 服务器 URL，以及将其连接到 VS Code 的步骤。

        1. 创建一个 `.vscode/mcp.json` 文件。
        2. 在 `mcp.json` 中配置你的服务器：

        ```json
        {
          "servers": {
            "<your-mcp-server-name>": {
              "type": "http",
              "url": "<your-mcp-server-url>"
            }
          }
        }
        ```
      </Step>
    </Steps>

    查看 [VS Code 文档](https://code.visualstudio.com/docs/copilot/chat/mcp-servers)以了解更多信息。
  </Tab>
</Tabs>

<div id="example-connect-to-the-mintlify-mcp-server">
  ### 示例：连接到 Mintlify MCP 服务器
</div>

将 Mintlify MCP 服务器连接到你常用的 AI 工具，以便在该工具中搜索本文档站点。这样可以为你在本地环境中如何使用 Mintlify 提供更准确的答案，并展示如何帮助你的用户连接到你的 MCP 服务器。

<Tabs>
  <Tab title="上下文菜单">
    在本页面顶部，打开上下文菜单，然后选择 **Connect to Cursor** 或 **Connect to VS Code**，即可将 Mintlify MCP 服务器连接到你选择的 IDE。
  </Tab>

  <Tab title="Claude">
    要在 Claude 中使用 Mintlify MCP 服务器：

    <Steps>
      <Step title="将 Mintlify MCP 服务器添加到 Claude">
        1. 在 Claude 设置中，前往 [Connectors](https://claude.ai/settings/connectors) 页面。
        2. 选择 **Add custom connector**。
        3. 添加 Mintlify MCP 服务器：

        * Name: `Mintlify`
        * URL: `https://mintlify.com/docs/mcp`

        4. 选择 **Add**。
      </Step>

      <Step title="在聊天中访问 MCP 服务器">
        1. 使用 Claude 时，选择附件按钮（加号图标）。
        2. 选择 Mintlify MCP 服务器。
        3. 向 Claude 提出关于 Mintlify 的问题。
      </Step>
    </Steps>

    更多详情请参阅 [Model Context Protocol 文档](https://modelcontextprotocol.io/docs/tutorials/use-remote-mcp-server#connecting-to-a-remote-mcp-server)。
  </Tab>

  <Tab title="Claude Code">
    要在 Claude Code 中使用 Mintlify MCP 服务器，运行以下命令：

    ```bash
    claude mcp add --transport http Mintlify https://mintlify.com/docs/mcp
    ```

    通过运行以下命令测试连接：

    ```bash
    claude mcp list
    ```

    更多详情请参阅 [Claude Code 文档](https://docs.anthropic.com/en/docs/claude-code/mcp#installing-mcp-servers)。
  </Tab>

  <Tab title="Cursor">
    <PreviewButton href="cursor://anysphere.cursor-deeplink/mcp/install?name=mintlify&config=eyJ1cmwiOiJodHRwczovL21pbnRsaWZ5LmNvbS9kb2NzL21jcCJ9">在 Cursor 中安装</PreviewButton>

    要将 Mintlify MCP 服务器连接到 Cursor，点击 **Install in Cursor** 按钮。或者要手动连接 MCP 服务器，请按以下步骤操作：

    <Steps>
      <Step title="打开 MCP 设置">
        1. 使用 <kbd>Command</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>（在 Windows 上为 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>）打开命令面板。
        2. 搜索 “Open MCP settings”。
        3. 选择 **Add custom MCP**。这会打开 `mcp.json` 文件。
      </Step>

      <Step title="配置 Mintlify MCP 服务器">
        在 `mcp.json` 中添加：

        ```json
        {
          "mcpServers": {
            "Mintlify": {
              "url": "https://mintlify.com/docs/mcp"
            }
          }
        }
        ```
      </Step>

      <Step title="测试连接">
        在 Cursor 的聊天中，询问 “What tools do you have available?”。Cursor 应该会将 Mintlify MCP 服务器显示为可用工具。
      </Step>
    </Steps>

    更多详情请参阅 Cursor 文档中的 [Installing MCP servers](https://docs.cursor.com/en/context/mcp#installing-mcp-servers)。
  </Tab>

    要将 Mintlify MCP 服务器连接到 VS Code，点击 **Install in VS Code** 按钮。或者要手动连接 MCP 服务器，创建 `.vscode/mcp.json` 文件并添加：

    ```json

      "servers": {
        "Mintlify": {
          "type": "http",
          "url": "https://mintlify.com/docs/mcp"
        }
      }
    }
    ```

    更多详情请参阅 [VS Code 文档](https://code.visualstudio.com/docs/copilot/chat/mcp-servers)。
  </Tab>

<div id="using-multiple-mcp-servers">
  ### 使用多个 MCP 服务器
</div>

用户可以将多个 MCP 服务器连接到自己的 AI 工具。已连接的 MCP 服务器在 AI 调用搜索工具之前不会占用上下文。AI 会根据查询的相关性决定何时进行搜索，因此不会为每个问题都去搜索所有已连接的服务器。

当 AI 进行搜索时，每个查询都会返回多个结果，这些结果会被加入到对话的上下文中。如果 AI 为同一个问题在多个服务器上进行搜索，就可能会占用大量上下文。

使用多个 MCP 服务器的最佳实践：

* 只连接与当前工作相关的 MCP 服务器。
* 尽量在提示中描述具体需求，以便 AI 搜索最相关的服务器。
* 断开连接当前未主动使用的服务器，以减少潜在的上下文占用。
