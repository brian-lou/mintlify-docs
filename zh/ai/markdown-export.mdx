与 HTML 相比，Markdown 能为 AI 工具提供结构化文本，使其处理更加高效，从而带来更高的回答准确性、更快的处理速度以及更低的 token 消耗。

Mintlify 会自动生成针对 AI 工具和外部集成优化的页面 Markdown 版本。


<div id="md-url-extension">
  ## .md URL 后缀
</div>

在任意页面的 URL 后添加 `.md`，即可查看该页面的 Markdown 版本。

<PreviewButton href="https://mintlify.com/docs/ai/markdown-export.md">以 Markdown 形式打开此页面</PreviewButton>

<div id="keyboard-shortcut">
  ## 键盘快捷键
</div>

按下 <kbd>Command</kbd> + <kbd>C</kbd>（在 Windows 上为 <kbd>Ctrl</kbd> + <kbd>C</kbd>），即可将当前页面以 Markdown 格式复制到剪贴板。
