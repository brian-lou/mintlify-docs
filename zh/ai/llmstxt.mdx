[llms.txt 文件](https://llmstxt.org)是一项行业标准，可帮助 LLM 更高效地索引内容，作用类似于网站地图对搜索引擎的帮助。AI 工具可以借助该文件理解你的文档结构，并找到与用户查询相关的内容。

Mintlify 会自动在项目根目录托管一个 `llms.txt` 文件，其中列出文档中的所有可用页面。该文件会始终保持最新，无需任何维护。你也可以选择在项目根目录添加自定义的 `llms.txt` 文件。

<Note>
  如果你的站点需要通过身份验证才能访问文档，那么 LLM 和 AI 工具将无法访问你的 `llms.txt` 和 `llms-full.txt` 文件。LLM 和 AI 工具只能索引可公开访问的内容。
</Note>

在文档站点的 URL 后追加 `/llms.txt`，即可查看你的 `llms.txt`。

<PreviewButton href="https://mintlify.com/docs/llms.txt">打开此站点的 llms.txt</PreviewButton>


<div id="llmstxt-structure">
  ## llms.txt 结构
</div>

`llms.txt` 文件是一个纯 Markdown 文件，包含：

* 作为 H1 标题的**站点标题**。
* **结构化的内容部分**，包含链接以及文档中每个页面的说明。

页面会从根目录开始，按照它们在仓库中出现的顺序，以字母顺序列出。

每个页面的说明都来自其前置元数据中的 `description` 字段。没有 `description` 字段的页面会出现在 `llms.txt` 文件中，但不包含说明。

```mdx Example llms.txt
# Site title

## Docs

- [API](https://example.com/docs/api): Endpoint list and usage
- [Install](https://example.com/docs/install): Setup steps
- [Getting started](https://example.com/docs/start): Intro guide
```

这种结构化方法使 LLM 能够高效地从整体层面处理文档，并根据用户查询定位相关内容，从而提升 AI 辅助文档搜索的准确性和速度。


<div id="llms-fulltxt">
  ## llms-full.txt
</div>

`llms-full.txt` 文件会将你的整个文档站点整合成一个文件，作为 AI 工具的上下文，并由 LLM 流量索引。

Mintlify 会自动在项目根目录托管一个 `llms-full.txt` 文件。要查看你的 `llms-full.txt`，只需在文档站点的 URL 后追加 `/llms-full.txt`。

<PreviewButton href="https://mintlify.com/docs/llms-full.txt">打开此站点的 llms-full.txt。</PreviewButton>

<div id="custom-files">
  ## 自定义文件
</div>

要添加自定义 `llms.txt` 或 `llms-full.txt` 文件，请在项目根目录创建一个 `llms.txt` 或 `llms-full.txt` 文件。添加自定义文件后，会覆盖自动生成的同名文件。如果删除自定义文件，则会恢复使用默认文件。

你的自定义 `llms.txt` 或 `llms-full.txt` 文件必须包含一个作为 H1 标题的站点标题。其他内容可选。有关可选部分和最佳实践的更多信息，请参阅 `llms.txt` 规范中的 [Format](https://llmstxt.org/#format)。
