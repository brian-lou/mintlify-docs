[`llms.txt` 文件](https://llmstxt.org) 是一种行业标准规范，帮助 LLM 更高效地为内容建立索引，类似于站点地图帮助搜索引擎。AI 工具可以使用该文件来理解你的文档结构，并查找与用户查询相关的内容。

Mintlify 会在你的项目根目录下自动托管一个 `llms.txt` 文件，用于列出文档中所有可用页面。该文件始终保持最新，且无需任何维护。你也可以选择在项目根目录添加自定义的 `llms.txt` 文件。

<Note>
  如果你的网站需要身份验证才能访问文档，你的 `llms.txt` 和 `llms-full.txt` 文件将无法被 LLM 和 AI 工具访问。LLM 和 AI 工具只能索引公开可访问的内容。
</Note>

在你的文档站点 URL 后添加 `/llms.txt` 即可查看 `llms.txt`。

<PreviewButton href="https://mintlify.com/docs/llms.txt">打开此站点的 llms.txt。</PreviewButton>


<div id="llmstxt-structure">
  ## llms.txt 结构
</div>

`llms.txt` 文件是一个普通的 Markdown 文件，其中包含：

* 作为 H1 标题的**站点标题**。
* **结构化内容部分**，其中包含链接以及文档中每个页面的描述。

页面会按字母顺序列出，顺序与它们在代码仓库中的位置一致，从根目录开始。

每个页面的描述来自其 frontmatter 中的 `description` 字段。没有 `description` 字段的页面将在 `llms.txt` 文件中不带描述地显示。

```mdx Example llms.txt
# Site title

## Docs

- [API](https://example.com/docs/api): Endpoint list and usage
- [Install](https://example.com/docs/install): Setup steps
- [Getting started](https://example.com/docs/start): Intro guide
```

这种结构化方法使 LLM 能够以高层视角高效处理你的文档，并为用户查询定位相关内容，从而提升 AI 辅助文档搜索的准确性和速度。


<div id="llms-fulltxt">
  ## llms-full.txt
</div>

`llms-full.txt` 文件会将整个文档站点整合为一个单一文件，作为 AI 工具的上下文，并供 LLM 流量进行索引。

Mintlify 会在你项目的根目录自动托管一个 `llms-full.txt` 文件。通过在文档站点的 URL 末尾添加 `/llms-full.txt` 来查看你的 `llms-full.txt`。

<PreviewButton href="https://mintlify.com/docs/llms-full.txt">打开此站点的 llms-full.txt。</PreviewButton>

<div id="custom-files">
  ## 自定义文件
</div>

要添加自定义的 `llms.txt` 或 `llms-full.txt` 文件，请在项目根目录创建一个 `llms.txt` 或 `llms-full.txt` 文件。添加自定义文件将覆盖同名的自动生成文件。如果你删除自定义文件，将会恢复使用默认文件。

你的自定义 `llms.txt` 或 `llms-full.txt` 文件必须包含一个网站标题，并将其设置为 H1 标题。其他内容是可选的。关于可选部分和最佳实践的更多信息，请参阅 `llms.txt` 规范中的 [Format](https://llmstxt.org/#format)。
