Mintlify 会在你项目的根目录提供一个 `skill.md` 文件，用于说明 AI 代理可以用你的产品做什么。

[skill.md specification](https://agentskills.io/specification) 是一种结构化、机器可读的格式，用来明确说明产品的能力、所需输入和约束条件，以便代理更可靠地使用这些信息。

Mintlify 会通过代理式循环分析你的文档，并自动为你的项目生成 `skill.md` 文件。随着文档更新，这个文件也会保持最新，且无需手动维护。你也可以选择在项目根目录添加自定义 `skill.md` 文件，以覆盖自动生成的版本。

要查看你的 `skill.md`，只需在文档站点的 URL 后加上 `/skill.md`。Mintlify 仅为公开的文档站点生成 `skill.md` 文件。

<PreviewButton href="https://mintlify.com/docs/skill.md">打开此站点的 skill.md。</PreviewButton>

<Tip>
  `llms.txt` 和 `skill.md` 都能帮助代理使用你的文档，但用途不同。

  * `llms.txt` 是一份目录。它会列出你的所有文档页面及其说明，让代理知道去哪里查找信息。
  * `skill.md` 是一份能力摘要。它会告诉代理能用你的产品完成什么任务、需要哪些输入，以及有哪些约束条件。
</Tip>

<div id="use-skillmd-files-with-agents">
  ## 配合代理使用 `skill.md` 文件
</div>

<Note>
  如果你使用[反向代理](/zh/deploy/reverse-proxy)，请将其配置为把 `/skill.md` 和 `/.well-known/skills/*` 路径 (关闭缓存) 转发到你的 Mintlify 子域名。
</Note>

代理可以使用 [skills CLI](https://www.npmjs.com/package/skills) 处理你的 `skill.md`。

```bash
npx skills add https://your-docs-domain.com
```

这会将你的产品能力加入代理的上下文，使其能够代表用户执行操作。

<Tip>
  指导用户如何将 `skill.md` 文件与代理配合使用，以便他们通过 AI 工具使用你的产品时获得更好的效果。
</Tip>

<div id="skillmd-structure">
  ## `skill.md` 结构
</div>

Mintlify 会根据 [agentskills.io specification](https://agentskills.io/specification) 生成一个 `skill.md` 文件。生成的文件包括：

* **元数据**：项目名称、描述和版本。
* **能力**：代理可以使用你的产品完成的任务。
* **技能**：按类别组织的具体操作。
* **工作流**：完成常见任务的分步流程。
* **集成**：支持的工具和服务。
* **上下文**：有关产品架构的背景信息。

<div id="custom-skillmd-files">
  ## 自定义 `skill.md` 文件
</div>

在项目根目录添加一个 `skill.md` 文件，即可覆盖自动生成的文件。如果删除自定义文件，Mintlify 会重新生成一个新的 `skill.md` 文件。

如果你想精确控制代理如何与你的产品交互，请编写自定义文件。请遵循 [agentskills.io specification](https://agentskills.io/specification)，以确保与代理工具兼容。

<div id="frontmatter-fields">
  ### 前置元数据字段
</div>

自定义 `skill.md` 文件必须以 YAML 前置元数据开头。

| Field           | Type   | Description                                   |
| --------------- | ------ | --------------------------------------------- |
| `name`          | string | 你的技能名称。                                       |
| `description`   | string | 对技能功能的简要说明。                                   |
| `license`       | string | 你的技能所使用的许可证 (例如 `MIT` 或 `Apache-2.0`) 。       |
| `compatibility` | string | 要求或兼容性说明 (例如运行时依赖项) 。                         |
| `metadata`      | object | 附加元数据，采用字符串键值对的形式 (例如 `author` 或 `version`) 。 |
| `allowed-tools` | string | 该技能可使用的预先批准工具列表，以空格分隔 (实验性) 。                 |

```md Example frontmatter
---
name: mintlify
description: Build and maintain documentation sites with Mintlify. Use when creating docs pages, configuring navigation, adding components, or setting up API references.
license: MIT
compatibility: Requires Node.js for CLI. Works with any Git-based workflow.
metadata:
  author: mintlify
  version: "1.0"
---
```
