Mintlify 会在你项目的根目录托管一个 `skill.md` 文件，用来描述 AI 智能体在你的产品中可以完成哪些操作。

[skill.md 规范](https://agentskills.io/specification) 是一种结构化、机器可读的格式，它将产品的能力、所需输入和约束条件显式地表达出来，从而让智能体可以更可靠地调用这些能力。

Mintlify 会通过智能体循环分析你的文档，自动为你的项目生成一个 `skill.md` 文件。这个文件会随着你更新文档而自动保持最新，且无需额外维护。你也可以选择在项目根目录添加一个自定义的 `skill.md` 文件，以覆盖自动生成的版本。

在文档站点的 URL 后追加 `/skill.md` 即可查看你的 `skill.md`。Mintlify 只会为可公开访问的文档站点生成 `skill.md` 文件。

<PreviewButton href="https://mintlify.com/docs/skill.md">打开此站点的 skill.md。</PreviewButton>

<Tip>
  `llms.txt` 和 `skill.md` 文件都能帮助智能体更好地使用你的文档，但它们的作用不同。

  * `llms.txt` 是一个目录。它列出你所有的文档页面及其描述，以便智能体知道到哪里查找信息。
  * `skill.md` 是一个能力摘要。它告知智能体在你的产品中可以实现什么、需要哪些输入，以及适用哪些约束。
</Tip>

<div id="use-skillmd-files-with-agents">
  ## 在智能体中使用 `skill.md` 文件
</div>

<Note>
  如果你使用[反向代理](/zh/deploy/reverse-proxy)，请将其配置为把 `/skill.md` 和 `/.well-known/skills/*` 路径（且禁用缓存）转发到你的 Mintlify 子域名。
</Note>

智能体可以使用 [skills CLI](https://www.npmjs.com/package/skills) 来处理你的 `skill.md`。

```bash
npx skills add https://your-docs-domain.com
```

这会将你产品的功能添加到代理的上下文中，使其能够代表用户执行操作。

<Tip>
  指导你的用户如何在代理中使用 `skill.md` 文件，这样他们在结合 AI 工具使用你的产品时就能获得更好的效果。
</Tip>

<div id="skillmd-structure">
  ## `skill.md` 结构
</div>

Mintlify 会根据 [agentskills.io 规范](https://agentskills.io/specification) 生成一个 `skill.md` 文件。生成的文件包括：

* **Metadata**：项目名称、描述和版本。
* **Capabilities**：代理使用你的产品可以完成的功能。
* **Skills**：按类别组织的具体操作。
* **Workflows**：常见任务的分步流程。
* **Integration**：支持的工具和服务。
* **Context**：关于你的产品架构的背景信息。

<div id="custom-skillmd-files">
  ## 自定义 `skill.md` 文件
</div>

在项目根目录中添加一个 `skill.md` 文件，可以覆盖自动生成的文件。如果你删除了自定义文件，Mintlify 会重新生成一个新的 `skill.md` 文件。

当你希望更精细地控制代理如何与你的产品交互时，请编写自定义文件。遵循 [agentskills.io 规范](https://agentskills.io/specification) 以确保与代理工具的兼容性。

<div id="frontmatter-fields">
  ### Frontmatter 字段
</div>

自定义 `skill.md` 文件必须以 YAML frontmatter 开头。

| 字段              | 类型     | 描述                                          |
| --------------- | ------ | ------------------------------------------- |
| `name`          | string | 你的技能名称。                                     |
| `description`   | string | 对你的技能功能的简要描述。                               |
| `license`       | string | 你的技能的许可证（例如 `MIT` 或 `Apache-2.0`）。          |
| `compatibility` | string | 要求或兼容性说明（例如运行时依赖）。                          |
| `metadata`      | object | 以字符串键值对形式提供的附加元数据（例如 `author` 或 `version`）。 |
| `allowed-tools` | string | 预先批准可供该技能使用的工具列表，以空格分隔（实验性）。                |

```md Example frontmatter
---
name: mintlify
description: Build and maintain documentation sites with Mintlify. Use when creating docs pages, configuring navigation, adding components, or setting up API references.
license: MIT
compatibility: Requires Node.js for CLI. Works with any Git-based workflow.
metadata:
  author: mintlify
  version: "1.0"
---
```
