`.mintignore` 文件允许你将文档仓库中的特定文件和目录从处理和发布中排除，从而不会出现在你的文档站点上。

使用 `.mintignore`，你可以在仓库中保留草稿、内部笔记和源文件，同时将它们排除在公共文档之外。

<div id="create-a-mintignore-file">
  ## 创建 .mintignore 文件
</div>

在文档目录的根目录下创建一个 `.mintignore` 文件。该文件使用与 `.gitignore` 相同的模式语法。

```plaintext .mintignore
# 排除草稿文档
drafts/
*.draft.mdx

# 排除内部文档
internal/

# 排除特定文件
private-notes.md
```

当 Mintlify 构建你的文档时，它会读取 `.mintignore` 文件，并在处理时排除所有匹配的文件或目录。

排除的文件：

* 不会出现在已发布的文档中。
* 不会被搜索索引收录。
* 访问者无法访问。
* 会被[失效链接检查](/zh/installation#find-broken-links)忽略。指向被忽略文件的链接会被视为失效链接。

<div id="default-ignored-patterns">
  ## 默认忽略模式
</div>

Mintlify 会自动忽略以下目录和文件，无需进行任何配置：

* `.git`
* `.github`
* `.claude`
* `.agents`
* `.idea`
* `node_modules`
* `README.md`
* `LICENSE.md`
* `CHANGELOG.md`
* `CONTRIBUTING.md`

你不必将这些内容添加到 `.mintignore` 文件中。

<Note>
  与[隐藏页面](/zh/organize/hidden-pages)不同，由 `.mintignore` 排除的文件会从你的站点中完全移除，无法通过 URL 访问。
</Note>

<div id="pattern-syntax">
  ## 模式语法
</div>

`.mintignore` 文件遵循 `.gitignore` 的语法规则。常见的模式包括：

| 模式               | 描述                                           |
| ------------------ | ---------------------------------------------- |
| `drafts/`          | 排除整个 `drafts` 目录                         |
| `*.draft.mdx`      | 排除所有以 `.draft.mdx` 结尾的文件             |
| `private-notes.md` | 排除特定文件                                   |
| `**/internal/**`   | 排除任意层级中的 `internal` 目录               |
| `!important.mdx`   | 否定前面的模式（包含该文件）                   |
