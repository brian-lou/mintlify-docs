每个页面都是一个 Markdown 文件。支持 `.mdx` 和 `.md` 两种文件类型。我们推荐使用 MDX，它将 Markdown 与 React 组件结合，可用于创建丰富的交互式文档。为便于从其他平台迁移，也支持纯 Markdown (`.md`) ，但若要使用完整功能，应将其更新为 MDX。

<div id="page-metadata">
  ## 页面元数据
</div>

每个页面都以前置元数据开头，即文件开头由 `---` 包裹的 YAML 元数据。它定义了页面的显示方式和行为。

你可以使用前置元数据来控制：

* 页面标题和描述
* 侧边栏标题、图标和标签
* 页面布局
* SEO 元标签
* 自定义元数据

<ResponseField name="title" type="string" required>
  显示在导航和浏览器标签页中的页面标题。
</ResponseField>

<ResponseField name="description" type="string">
  对本页内容的简要说明。会显示在标题下方，并有助于提升 SEO 效果。
</ResponseField>

<ResponseField name="sidebarTitle" type="string">
  显示在侧边栏导航中的简短标题。
</ResponseField>

<ResponseField name="icon" type="string">
  要显示的图标。

  可选值：

  * [Font Awesome icon](https://fontawesome.com/icons) 名称
  * [Lucide icon](https://lucide.dev/icons) 名称
  * 外部托管图标的 URL
  * 项目中图标文件的路径
</ResponseField>

<ResponseField name="iconType" type="string">
  [Font Awesome](https://fontawesome.com/icons) 图标样式。仅用于 Font Awesome 图标。

  可选值：`regular`、`solid`、`light`、`thin`、`sharp-solid`、`duotone`、`brands`。
</ResponseField>

<ResponseField name="tag" type="string">
  显示在侧边栏页面标题旁的标签。
</ResponseField>

<ResponseField name="<custom>" type="string">
  任何有效的 YAML 前置元数据。例如，`product: "API"` 或 `version: "1.0.0"`。
</ResponseField>

```yaml Example YAML frontmatter wrap
---
title: "关于前置元数据"
description: "前置元数据是控制页面外观和行为的元数据"
sidebarTitle: "前置元数据"
icon: "book"
tag: "NEW"
---
```

<div id="page-mode">
  ## 页面模式
</div>

通过 `mode` 设置控制页面的显示方式。

<div id="default">
  ### 默认
</div>

如果未定义模式，则默认使用标准布局，包含侧边栏导航和目录。

```yaml
---
title: "Default page title"
---
```

<div id="wide">
  ### 宽屏
</div>

宽屏模式会隐藏目录。对于没有任何标题的页面，或者你想利用额外横向空间时，这会很有用。所有主题都支持宽屏模式。

```yaml
---
title: "Wide page title"
mode: "wide"
---
```

<div id="custom">
  ### 自定义
</div>

自定义模式提供一种极简布局，除顶部导航栏外会移除所有元素。自定义模式就像一块空白画布，可用于创建落地页或任何其他希望仅保留最少导航元素的独特布局。自定义模式适用于所有主题。

```yaml
---
title: "Custom page title"
mode: "custom"
---
```

<Warning>
  在自定义模式页面中使用 `style` 属性，可能会导致页面加载时出现布局偏移。为避免此问题，请改用 [Tailwind CSS 或自定义 CSS](/zh/customize/custom-scripts)。
</Warning>

<div id="frame">
  ### Frame
</div>

Frame 模式提供与自定义模式类似的布局，但会保留侧边栏导航。该页面模式支持使用自定义 HTML 和组件，同时保留默认的导航体验。Frame 模式仅适用于 Aspen 和 Almond 主题。

```yaml
---
title: "Frame page title"
mode: "frame"
---
```

<div id="center">
  ### 居中
</div>

居中模式会移除侧边栏和目录，并将内容置于页面中央。这适用于更新日志或其他需要突出内容的页面。居中模式可用于 Mint 和 Linden 主题。

```yaml
---
title: "Center page title"
mode: "center"
---
```

<div id="api-pages">
  ## API 页面
</div>

在前置元数据中添加 API 规范 (`api` 或 `openapi`) ，即可创建交互式 API 操作台。

```yaml
---
openapi: "GET /endpoint"
---
```

进一步了解如何构建 [API 文档](/zh/api-playground/overview)。

<div id="external-links">
  ## 外部链接
</div>

使用 `url` 元数据，可直接在导航中链接到外部网站。

```yaml
---
title: "npm Package"
url: "https://www.npmjs.com/package/mint"
---
```

<div id="search-engine-optimization">
  ## 搜索引擎优化
</div>

大多数 SEO 元标签都会自动生成。你也可以手动设置 SEO 元标签，以提升网站的 SEO、社交分享效果和浏览器兼容性。

<Note>
  带有冒号的元标签必须用引号括起来。
</Note>

```yaml
---
"twitter:image": "/images/social-preview.jpg"
---
```

有关 SEO 元数据的完整选项，请参阅 [SEO](/zh/optimize/seo)。

<div id="internal-search-keywords">
  ## 内部搜索关键词
</div>

你可以在元数据中提供 `keywords`，以提升特定页面在内置搜索中的可发现性。这些关键词不会显示在页面内容中，也不会出现在搜索结果里，但用户搜索这些关键词时，页面仍会显示在结果中。

```yaml
---
keywords: ['configuration', 'setup', 'getting started']
---
```

<div id="last-modified-timestamp">
  ## 最后修改时间
</div>

在[全局设置](/zh/organize/settings#metadata)中启用 `metadata.timestamp`，即可为所有页面添加“最后修改于 [date]”时间。

```json docs.json
"metadata": {
  "timestamp": true
}
```

使用前置元数据中的 `timestamp` 字段覆盖单个页面的全局时间戳设置。你可以使用此字段，有选择地在特定页面上显示或隐藏时间戳。

```yaml
---
title: "Page title"
timestamp: false
---
```

设置为 `true` 时，即使全局设置为 `false`，也会显示时间戳。设置为 `false` 时，即使全局设置为 `true`，也会隐藏时间戳。
