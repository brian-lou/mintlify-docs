每个页面都是一个 Markdown 文件。支持 `.mdx` 和 `.md` 两种文件类型。我们推荐使用 MDX，它将 Markdown 与 React 组件结合起来，用于创建丰富、交互性强的文档。纯 Markdown（`.md`）也同样支持，便于从其他平台迁移，但应尽量更新为 MDX，以获得完整功能。

<div id="page-metadata">
  ## 页面元数据
</div>

每个页面都以 frontmatter 开头，即位于文件开头、由 `---` 包裹的 YAML 元数据。这些元数据定义了页面的外观和行为。

使用 frontmatter 可以控制：

* 页面标题和描述
* 侧边栏标题、图标和标签
* 页面布局
* SEO 元标签
* 自定义元数据

<ResponseField name="title" type="string" required>
  出现在导航和浏览器标签页中的页面标题。
</ResponseField>

<ResponseField name="description" type="string">
  对本页面内容的简要说明。显示在标题下方，有助于提升 SEO。
</ResponseField>

<ResponseField name="sidebarTitle" type="string">
  显示在侧边栏导航中的简短标题。
</ResponseField>

<ResponseField name="icon" type="string">
  要显示的图标。

  可选值：

  * [Font Awesome 图标](https://fontawesome.com/icons) 名称
  * [Lucide 图标](https://lucide.dev/icons) 名称
  * 外部托管图标的 URL
  * 项目中图标文件的路径
</ResponseField>

<ResponseField name="iconType" type="string">
  [Font Awesome](https://fontawesome.com/icons) 图标样式。仅在使用 Font Awesome 图标时生效。

  可选值：`regular`, `solid`, `light`, `thin`, `sharp-solid`, `duotone`, `brands`。
</ResponseField>

<ResponseField name="tag" type="string">
  显示在侧边栏中页面标题旁边的标签。
</ResponseField>

<ResponseField name="<custom>" type="string">
  任何有效的 YAML frontmatter 字段。例如，`product: "API"` 或 `version: "1.0.0"`。
</ResponseField>

```yaml Example YAML frontmatter wrap
---
title: "关于 frontmatter"
description: "Frontmatter 是控制页面外观和行为的元数据"
sidebarTitle: "Frontmatter"
icon: "book"
tag: "NEW"
---
```

<div id="page-mode">
  ## 页面模式
</div>

通过 `mode` 设置来控制页面的显示方式。

<div id="default">
  ### 默认模式
</div>

如果未指定模式，将使用带有侧边导航栏和目录的标准布局。

```yaml
---
title: "Default page title"
---
```

<div id="wide">
  ### 宽屏
</div>

宽屏模式会隐藏目录。这对没有任何标题的页面，或是你希望利用额外横向空间时非常实用。所有主题都支持宽屏模式。

```yaml
---
title: "Wide page title"
mode: "wide"
---
```

<div id="custom">
  ### 自定义
</div>

自定义模式提供极简布局，只保留顶部导航栏，其余元素全部移除。自定义模式是一块空白画布，可用于创建落地页或任何你希望仅保留最少导航元素的独特布局。自定义模式适用于所有主题。

```yaml
---
title: "Custom page title"
mode: "custom"
---
```

<Warning>
  在自定义模式页面中使用 `style` 属性可能会在页面加载时导致布局偏移。请改用 [Tailwind CSS 或自定义 CSS](/zh/customize/custom-scripts) 以避免此问题。
</Warning>

<div id="frame">
  ### Frame
</div>

Frame 模式提供了与 custom 模式类似的布局，但会保留侧边栏导航。此页面模式在保持默认导航体验的同时支持自定义 HTML 和组件。Frame 模式仅适用于 Aspen 和 Almond 主题。

```yaml
---
title: "Frame page title"
mode: "frame"
---
```

<div id="center">
  ### 居中
</div>

居中模式会移除侧边栏和目录，并将内容居中展示。对于变更日志或其他需要突出内容本身的页面，这种模式非常实用。居中模式适用于 Mint 和 Linden 主题。

```yaml
---
title: "Center page title"
mode: "center"
---
```

<div id="api-pages">
  ## API 页面
</div>

在你的 frontmatter 中添加 API 规范（`api` 或 `openapi`），即可创建交互式 API 操作环境。

```yaml
---
openapi: "GET /endpoint"
---
```

了解更多关于构建 [API 文档](/zh/api-playground/overview) 的信息。

<div id="external-links">
  ## 外部链接
</div>

在导航中使用 `url` 元数据即可直接链接到外部网站。

```yaml
---
title: "npm Package"
url: "https://www.npmjs.com/package/mint"
---
```

<div id="search-engine-optimization">
  ## 搜索引擎优化
</div>

大多数 SEO meta 标签都会自动生成。你也可以手动设置这些标签，以提升网站的 SEO 效果、社交分享表现和浏览器兼容性。

<Note>
  带有冒号的 meta 标签必须用引号括起来。
</Note>

```yaml
---
"twitter:image": "/images/social-preview.jpg"
---
```

请参阅 [SEO](/zh/optimize/seo) 了解所有 SEO 元数据选项。

<div id="internal-search-keywords">
  ## 内部搜索关键词
</div>

在元数据中添加 `keywords`，可以提高特定页面在内置搜索中的可见性。这些关键词不会出现在页面内容或搜索结果中，但当用户搜索这些关键词时，仍会在结果中显示该页面。

```yaml
---
keywords: ['configuration', 'setup', 'getting started']
---
```

<div id="last-modified-timestamp">
  ## 最后修改时间
</div>

在你的[全局设置](/zh/organize/settings#metadata)中启用 `metadata.timestamp`，即可为所有页面添加“最后修改于 [日期]”的时间戳。

```json docs.json
"metadata": {
  "timestamp": true
}
```

通过在单个页面中使用 `timestamp` frontmatter 字段来覆写全局时间戳设置。使用此字段可以选择性地在特定页面上显示或隐藏时间戳。

```yaml
---
title: "Page title"
timestamp: false
---
```

当设置为 `true` 时，即使全局设置为 `false`，仍会显示时间戳。当设置为 `false` 时，即使全局设置为 `true`，时间戳也会被隐藏。
