隐藏页面不会显示在站点导航中，但任何知道其 URL 的人仍可公开访问这些页面。

对于你希望在站点中可访问，或供 AI 工具作为上下文引用，但不想让用户通过导航发现的内容，可以使用隐藏页面。

对于需要严格访问控制的内容，你必须配置[身份验证](/zh/deploy/authentication-setup)。

如需将页面访问权限限制为仅特定用户分组可用，请配置[基于分组的访问控制](/zh/deploy/authentication-setup#control-access-with-groups)。

<div id="hiding-a-page">
  ## 隐藏页面
</div>

要隐藏某个页面，请将其从你的导航结构中移除。任何未包含在 `docs.json` 导航中的页面都会被隐藏。

隐藏页面会根据其文件路径使用与常规页面相同的 URL 结构。例如，`guides/hidden-page.mdx` 可通过 `docs.yoursite.com/guides/hidden-page` 访问。

参见[隐藏页面示例](/zh/organize/hidden-page-example)。

<Note>
  某些导航元素 (如侧边栏、下拉菜单和标签页) 在隐藏页面上可能会显示为空，或导致布局发生偏移。
</Note>

<div id="hiding-a-group-of-pages">
  ## 隐藏一组页面
</div>

如果在 `docs.json` 文件中将 `hidden` 属性设为 `true`，这组页面就会被隐藏：

```json highlight={4}
"groups": [
  {
    "group": "Getting started",
    "hidden": true,
    "pages": [
      "index",
      "quickstart"
    ]
  },
  {
    "group": "Guides",
    "pages": [
      "guides/hidden-page.mdx",
      "guides/hidden-groups.mdx"
    ]
  }
]
```

在此示例中，`Getting started` 组已隐藏，而 `Guides` 组会显示。

<div id="hiding-a-tab">
  ### 隐藏标签页
</div>

你也可以在 `docs.json` 文件中添加 `hidden` 属性，以隐藏标签页：

```json highlight={4}
"tabs": [
  {
    "tab": "Home",
    "hidden": true,
    "pages": [
      "index",
      "quickstart"
    ]
  }
]
```

<div id="search-seo-and-ai-indexing">
  ## 搜索、SEO 与 AI 索引
</div>

默认情况下，隐藏页面不会被搜索引擎收录，也不会出现在文档内搜索结果中，或作为 AI 助手的上下文。若要让隐藏页面出现在搜索结果中，并作为助手的上下文，请在 `docs.json` 中添加 `seo` 属性：

```json
"seo": {
    "indexing": "all"
}
```

要排除某个特定页面，请在其前置元数据中添加 `noindex: true`。
