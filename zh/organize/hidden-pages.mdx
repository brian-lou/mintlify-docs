隐藏页面不会出现在站点导航中，但任何知道其 URL 的人仍然可以公开访问这些页面。

可将隐藏页面用于那些你希望在站点上保持可访问、供 AI 工具作为上下文引用，但又不希望通过导航被发现的内容。

对于需要严格访问控制的内容，你必须配置[身份验证](/zh/deploy/authentication-setup)。

要将页面限制为仅特定用户组可访问，请配置[基于用户组的访问控制](/zh/deploy/authentication-setup#control-access-with-groups)。

<div id="hiding-a-page">
  ## 隐藏页面
</div>

要隐藏某个页面，请将它从导航结构中移除。任何未包含在 `docs.json` 导航中的页面都会被隐藏。

隐藏页面会根据其文件路径使用与普通页面相同的 URL 结构。比如，`guides/hidden-page.mdx` 可以通过 `docs.yoursite.com/guides/hidden-page` 访问。

请参阅[隐藏页面示例](/zh/organize/hidden-page-example)。

<Note>
  某些导航元素（如侧边栏、下拉菜单和选项卡）在隐藏页面上可能会显示为空或导致布局错位。
</Note>

<div id="hiding-a-group-of-pages">
  ## 隐藏一组页面
</div>

在 `docs.json` 文件中将 `hidden` 属性设置为 `true` 后，该组页面就会被隐藏：

```json highlight={4}
"groups": [
  {
    "group": "Getting started",
    "hidden": true,
    "pages": [
      "index",
      "quickstart"
    ]
  },
  {
    "group": "Guides",
    "pages": [
      "guides/hidden-page.mdx",
      "guides/hidden-groups.mdx"
    ]
  }
]
```

在此示例中，`Getting started` 组被隐藏，而 `Guides` 组仍然可见。

<div id="hiding-a-tab">
  ### 隐藏选项卡
</div>

你也可以通过在 `docs.json` 文件中添加 `hidden` 属性来隐藏选项卡：

```json highlight={4}
"tabs": [
  {
    "tab": "Home",
    "hidden": true,
    "pages": [
      "index",
      "quickstart"
    ]
  }
]
```

<div id="search-seo-and-ai-indexing">
  ## 搜索、SEO 和 AI 索引
</div>

默认情况下，隐藏页面不会被搜索引擎索引，也不会出现在文档内部搜索结果中或用于 AI 助手的上下文。要将隐藏页面包含在搜索结果中并用作助手的上下文，请在你的 `docs.json` 中添加 `seo` 属性：

```json
"seo": {
    "indexing": "all"
}
```

若要将某个特定页面排除在索引之外，请在其 frontmatter 中添加 `noindex: true`。
