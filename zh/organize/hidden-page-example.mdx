<div id="common-use-cases-for-hidden-pages">
  ## 隐藏页面的常见用途
</div>

<Note>
  默认情况下，隐藏页面可公开访问，但不会在导航中显示。如果你想限制对隐藏页面的访问，必须配置[身份验证](/zh/deploy/authentication-setup)。
</Note>

* **Beta 文档**：可公开，但不应在导航中显示的信息。
* **为 AI 工具提供上下文**：如果隐藏页面被索引，AI 工具就可以将其作为上下文参考。对于与用户无关、但有助于 AI 工具给出更准确回复的内容，可使用隐藏页面。
* **旧版页面**：将旧内容从导航菜单中移除的同时，仍可通过直接链接访问。
* **内部工具**：用于记录内部工具、预发布 API 或开发流程。
