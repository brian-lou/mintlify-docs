此页面是隐藏的！它未包含在 `docs.json` 导航中，因此你只能通过其 URL 直接访问。

更多信息请参阅[隐藏页面](/zh/organize/hidden-pages)。

<div id="common-use-cases-for-hidden-pages">
  ## 隐藏页面的常见用例
</div>

<Note>
  默认情况下，隐藏页面是公开可访问的，但不会出现在导航中。如果你想限制对隐藏页面的访问，必须配置[身份验证](/zh/deploy/authentication-setup)。
</Note>

* **Beta 文档**：可以公开，但不应通过导航入口被找到的信息。
* **面向 AI 工具的上下文**：如果隐藏页面被索引，AI 工具可以引用其中内容作为上下文。将对用户不相关、但能帮助 AI 工具给出更准确回答的上下文放在隐藏页面中。
* **旧版页面**：通过直接链接保留对旧内容的访问，同时将其从导航菜单中移除。
* **内部工具**：为内部工具、预发布环境的 API 或开发流程撰写文档。
