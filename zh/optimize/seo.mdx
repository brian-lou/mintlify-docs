Mintlify 会自动处理许多 SEO 最佳实践，包括：

* 生成元标签
* 生成站点地图和 `robots.txt` 文件
* 语义化 HTML 结构
* 移动端优化

你可以通过在 `docs.json` 或页面的前置元数据中添加 `metatags` 字段，完全自定义站点的元标签。

<div id="automatically-generated-meta-tags">
  ## 自动生成的元标签
</div>

Mintlify 会为每个页面自动生成以下元标签。你可以在 `docs.json` 或页面的前置元数据中显式指定这些元标签，以覆盖默认值。

**基础元数据：**

* `charset: utf-8` - 字符编码
* `og:type: website` - Open Graph 类型
* `og:site_name` - 你的文档站点名称
* `twitter:card: summary_large_image` - Twitter 卡片类型

**页面级元数据：**

* `title` - 页面标题，格式为“页面标题 - 站点名称”
* `og:title` - Open Graph 标题，与页面标题相同
* `twitter:title` - Twitter 标题，与页面标题相同
* `description` - 页面描述
* `og:description` - Open Graph 描述，与页面描述相同
* `twitter:description` - Twitter 描述，与页面描述相同

**URL 和规范链接：**

* `canonical` - 根据页面 URL 自动生成
* `og:url` - 设为规范 URL

**SEO 和索引：**

* `robots` - 根据页面元数据生成
* `noindex` - 根据页面元数据生成
* `keywords` - 根据页面元数据生成

**图片：**

* `og:image` - Open Graph 图片，`og:image:width` 设为 1200，`og:image:height` 设为 630
* `twitter:image` - Twitter 图片，`twitter:image:width` 设为 1200，`twitter:image:height` 设为 630

**浏览器和应用元数据：**

* `applicationName` - 你的文档站点名称
* `generator: Mintlify` - 标明站点生成器为 Mintlify
* `apple-mobile-web-app-title` - iOS 主屏幕应用名称
* `msapplication-TileColor` - Windows 磁贴颜色
* 来自你的配置的 favicon 和图标
* 站点地图引用链接

此外，你在 `docs.json` 的 `seo.metatags` 配置中定义的任何元标签，也会自动注入到每个页面中，例如用于 Search Console 验证的 `google-site-verification`。

<div id="global-meta-tags">
  ## 全局元标签
</div>

要为所有页面设置默认的元标签，请在 `docs.json` 中添加 `metatags` 字段。

```json
"seo": {
    "metatags": {
        "og:image": "link to your default meta tag image"
    }
}
```

<div id="set-a-canonical-url">
  ### 设置规范 URL
</div>

如果你使用自定义域名，请设置 `canonical` 元标签，确保搜索引擎将你首选的域名编入索引。规范 URL 会告知搜索引擎，你的文档以哪个版本为主。当文档可通过多个 URL 访问时，这样做有助于提升 SEO，并避免重复内容问题。

```json
"seo": {
    "metatags": {
        "canonical": "https://www.your-custom-domain-here.com"
    }
}
```

<div id="page-specific-meta-tags">
  ## 页面专用 元标签
</div>

要设置页面专用的 元标签，请将其添加到页面的前置元数据中。

以下 元标签支持在页面级别设置：

* `title` - 页面标题
* `description` - 页面描述，显示在页面标题下方，也会出现在部分搜索引擎结果中
* `keywords` - 以逗号分隔的关键词
* `og:title` - 用于社交分享的 Open Graph 标题
* `og:description` - Open Graph 描述
* `og:image` - Open Graph 图片 URL
* `og:url` - Open Graph URL
* `og:type` - Open Graph 类型，例如 &quot;article&quot; 或 &quot;website&quot;
* `og:image:width` - Open Graph 图片宽度
* `og:image:height` - Open Graph 图片高度
* `twitter:title` - Twitter 卡片标题
* `twitter:description` - Twitter 卡片描述
* `twitter:image` - Twitter 卡片图片
* `twitter:card` - Twitter 卡片类型，例如 &quot;summary&quot; 或 &quot;summary&#95;large&#95;image&quot;
* `twitter:site` - Twitter 站点账号
* `twitter:image:width` - Twitter 图片宽度
* `twitter:image:height` - Twitter 图片高度
* `noindex` - 设为 `true` 可防止被搜索引擎收录
* `robots` - Robots 元标签的值

```mdx
---
title: "Your example page title"
description: "Page-specific description"
"og:image": "link to your meta tag image"
"og:title": "Social media title"
keywords: ["keyword1", "keyword2"]
---
```

<Note>
  含有冒号的元标签必须用引号括起来。`keywords` 字段必须写成 YAML 数组格式。
</Note>

<div id="sitemaps-and-robotstxt-files">
  ## 站点地图和 robots.txt 文件
</div>

Mintlify 会自动生成 `sitemap.xml` 文件和 `robots.txt` 文件。你可以在文档站点 URL 后追加 `/sitemap.xml` 来查看站点地图。

默认只会包含 `docs.json` 中列出的页面。若要包含隐藏链接，请在 `docs.json` 中添加 `seo.indexing`：

```json
"seo": {
    "indexing": "all"
}
```

<div id="custom-sitemaps-and-robotstxt-files">
  ### 自定义 sitemap 和 robots.txt 文件
</div>

如需添加自定义 `sitemap.xml` 或 `robots.txt` 文件，请在项目根目录下创建相应的 `sitemap.xml` 或 `robots.txt` 文件。添加自定义文件后，会覆盖自动生成的同名文件。删除自定义文件后，则会恢复使用默认文件。

<div id="disabling-indexing">
  ## 禁止索引
</div>

如果你想阻止搜索引擎收录某个页面，可以在该页面的[前置元数据](/zh/organize/pages)中加入以下内容：

```
---
noindex: true
---
```

你还可以在 `docs.json` 中将 `metatags.robots` 字段设为 `"noindex"`，为文档中的所有页面设置 `noindex`：

```json
"seo": {
    "metatags": {
      "robots": "noindex"
    }
  }
```

<div id="seo-best-practices">
  ## SEO 最佳实践
</div>

<AccordionGroup>
  <Accordion title="撰写清晰的标题和描述">
    * 使用清晰、明确的页面标题 (50–60 个字符)
    * 撰写有吸引力的页面描述 (150–160 个字符)
    * 包含相关关键词
    * 确保每个页面的标题和描述都各不相同
  </Accordion>

  <Accordion title="优化内容结构">
    * 使用正确的标题层级 (H1 → H2 → H3)
    * 优先为人而写，其次才考虑搜索引擎
    * 在标题和正文中加入相关关键词
    * 保持 URL 简短、清晰，并按层级组织
    * 使用小标题和列表拆分长篇内容
  </Accordion>

  <Accordion title="内部链接策略">
    * 在文档中链接到相关页面
    * 使用描述性的锚文本，而不是“点击这里”
    * 通过链接相关概念构建主题集群
    * 使用自动交叉引用功能
  </Accordion>

  <Accordion title="图片 SEO">
    * 为图片使用清晰的文件名
    * 始终添加 alt 文本，以提升无障碍性和 SEO 效果
    * 优化图片文件大小，加快加载速度
    * 使用与内容相关且有助于说明内容的图片
  </Accordion>
</AccordionGroup>
