---
title: "Banner 横幅"
description: "添加一个横幅，用于显示全站范围内的重要公告和通知。"
keywords: ["banner", "公告", "全站"]
---

使用横幅在整个文档站点中展示重要公告、更新或通知。横幅会显示在每个页面的顶部，支持 Markdown 格式，并且可以设置为可关闭。横幅会使用 `docs.json` 中 `colors.dark` 属性所定义的颜色。

要添加横幅，请在 `docs.json` 中使用 `banner` 属性：

<CodeGroup>
  ```json Product announcements wrap
  "banner": {
    "content": "🚀 Version 2.0 is now live! See our [changelog](/changelog) for details.",
    "dismissible": true 
  }
  ```

  ```json Maintenance notices wrap
  "banner": {
    "content": "⚠️ Scheduled maintenance: API will be unavailable December 15, 2-4 AM UTC",
    "dismissible": false
  }
  ```

  ```json Required actions wrap
  "banner": {
    "content": "**Action required:** Migrate to our new version by January 1. [Migration guide](/migration)",
    "dismissible": true
  }
  ```
</CodeGroup>

<Note>
  你也可以通过在 `navigation.languages` 中设置 `banner` 来为不同语言分别配置横幅。参见[语言专属横幅](#language-specific-banners)。
</Note>

<div id="properties">
  ## 属性
</div>

<ResponseField name="content" type="string" required>
  横幅信息。支持纯文本和 Markdown 格式。
</ResponseField>

<ResponseField name="dismissible" type="boolean">
  用户是否可以关闭横幅。当为 `true` 时，用户可以关闭横幅，并且在其会话期间横幅不会再次出现。默认为 `false`。
</ResponseField>

<div id="language-specific-banners">
  ## 按语言配置横幅
</div>

在文档中为每种语言配置不同的横幅内容。在 `docs.json` 的 `navigation.languages` 数组中定义各语言对应的横幅。

```json
{
  "navigation": {
    "languages": [
      {
        "language": "en",
        "banner": {
          "content": "🚀 Version 2.0 is now live! See our [changelog](/en/changelog) for details.",
          "dismissible": true
        },
        "groups": [
          {
            "group": "Getting started",
            "pages": ["en/overview", "en/quickstart"]
          }
        ]
      },
      {
        "language": "es",
        "banner": {
          "content": "🚀 ¡La versión 2.0 ya está disponible! Consulta nuestro [registro de cambios](/es/changelog) para más detalles.",
          "dismissible": true
        },
        "groups": [
          {
            "group": "Getting started",
            "pages": ["es/overview", "es/quickstart"]
          }
        ]
      }
    ]
  },
  "banner": {
    "content": "🚀 Version 2.0 is now live!",
    "dismissible": true
  }
}
```


<div id="fallback-behavior">
  ### 回退机制
</div>

在决定展示哪种内容时，横幅会遵循以下优先级顺序：

1. **语言特定横幅**：如果当前语言配置了 `banner`，则优先生效。
2. **全局横幅**：如果没有语言特定横幅，则显示全局 `banner`。
