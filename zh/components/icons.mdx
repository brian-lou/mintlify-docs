<div id="inline-icons">
  ## 行内图标
</div>

当图标用于句子、段落或标题中时，会以行内形式显示。<Icon icon="flag" iconType="solid" /> 可使用图标进行装饰或增强视觉效果。

```markdown Inline icon example
图标在句子、段落或标题中使用时会以内联方式显示。<Icon icon="flag" iconType="solid" /> 可使用图标进行装饰或增强视觉效果。
```


<div id="properties">
  ## 属性
</div>

<IconsRequired />

<ResponseField name="color" type="string">
  图标颜色，使用十六进制代码表示 (例如 `#FF5733`) 。
</ResponseField>

<ResponseField name="size" type="number">
  图标大小，以像素为单位。
</ResponseField>

<ResponseField name="className" type="string">
  应用于图标的自定义 CSS 类名。
</ResponseField>
