`<RequestExample>` 和 `<ResponseExample>` 组件会在右侧边栏显示代码块，从而创建双列布局，在用户滚动阅读内容时始终让示例保持可见。这些组件是为 API 文档设计的，但也适用于所有页面。

常见使用场景：

* 带有请求与响应示例的 API 端点文档
* 与说明性文字并列的配置示例
* 供用户在按照说明操作时参考的代码示例
* 教程中的前后对比示例

在移动设备上，`<RequestExample>` 和 `<ResponseExample>` 组件会显示为常规代码块，用户可以正常滚动浏览。

<RequestExample>
  ```bash Request
  curl --request POST \
    --url https://dog-api.kinduff.com/api/facts
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  { "status": "success" }
  ```
</ResponseExample>

<div id="requestexample">
  ## RequestExample
</div>

使用 `<RequestExample>` 将代码示例固定在右侧边栏中。该组件的用法与 [CodeGroup](/zh/components/code-groups) 组件类似，只不过会在侧边栏中显示代码，而不是内联显示。

你可以在单个 `<RequestExample>` 中包含多个代码块。每个代码块都必须带有一个 title 属性。

````mdx RequestExample
<RequestExample>

```bash Request
curl --request POST \
  --url https://dog-api.kinduff.com/api/facts
```

</RequestExample>
````

<div id="responseexample">
  ## ResponseExample
</div>

`<ResponseExample>` 组件会将代码示例固定显示在同一页面右侧边栏中，位于所有 `<RequestExample>` 内容的下方。

````mdx ResponseExample
<ResponseExample>

```json Response
{ "status": "success" }
```

</ResponseExample>
````
