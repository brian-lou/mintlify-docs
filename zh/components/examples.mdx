`<RequestExample>` 和 `<ResponseExample>` 组件会在右侧边栏中显示代码块，形成双栏布局，让用户在滚动浏览内容时也能始终看到示例。这些组件专为 API 文档设计，但适用于所有页面。

常见用例：

* 包含请求和响应示例的 API 端点文档
* 与说明文字并排显示的配置示例
* 用户按说明操作时可随时查看的代码示例
* 教程中的前后对比示例

在移动设备上，`<RequestExample>` 和 `<ResponseExample>` 组件会显示为普通代码块，用户可以直接滚动过去。

<RequestExample>
  ```bash Request
  curl --request POST \
    --url https://dog-api.kinduff.com/api/facts
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  { "status": "success" }
  ```
</ResponseExample>

<div id="requestexample">
  ## RequestExample
</div>

使用 `<RequestExample>` 可将代码示例固定在右侧边栏。该组件的用法与 [代码分组](/zh/components/code-groups) 组件类似，但代码会显示在侧边栏中，而不是以内联形式显示。

你可以在一个 `<RequestExample>` 中包含多个代码块。每个代码块都必须包含 `title` 属性。

````mdx RequestExample
<RequestExample>

```bash Request
curl --request POST \
  --url https://dog-api.kinduff.com/api/facts
```

</RequestExample>
````

<div id="responseexample">
  ## ResponseExample
</div>

`<ResponseExample>` 组件会将代码示例固定在右侧边栏中，显示在同一页面中任意 `<RequestExample>` 内容的下方。

````mdx ResponseExample
<ResponseExample>

```json Response
{ "status": "success" }
```

</ResponseExample>
````
