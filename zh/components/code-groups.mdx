使用 `CodeGroup` 组件可在标签式界面中显示多个代码块，让用户能够对比不同编程语言的实现，或查看同一任务的其他实现方式。

<CodeGroup>
  ```javascript helloWorld.js
  console.log("Hello World");
  ```

  ```python hello_world.py
  print('Hello World!')
  ```

  ```java HelloWorld.java
  class HelloWorld {
      public static void main(String[] args) {
          System.out.println("Hello, World!");
      }
  }
  ```
</CodeGroup>

代码分组会继承 `docs.json` 文件中的全局样式。你可以使用 `styling.codeblocks` 自定义主题。配置选项请参阅[设置](/zh/organize/settings#styling)。

当标签名称一致时，代码分组会自动与同一页面上的其他代码分组和[标签页](/zh/components/tabs)同步。当你在某个代码分组中选择一种语言时，所有具有相同标签名称的标签页和代码分组都会更新为显示该语言。

<div id="create-code-groups">
  ## 创建代码分组
</div>

要创建代码分组，请用 `<CodeGroup>` 标签包裹多个代码块。每个代码块都必须包含一个标题，该标题将作为选项卡标签显示。

````mdx
<CodeGroup>

```javascript helloWorld.js
console.log("Hello World");
```

```python hello_world.py
print('Hello World!')
```

```java HelloWorld.java
class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

</CodeGroup>
````

<div id="language-dropdown">
  ## 语言下拉菜单
</div>

你可以使用 `dropdown` 属性，将代码分组中的标签页替换为下拉菜单，从而在不同语言之间切换。

<CodeGroup dropdown>
  ```javascript helloWorld.js
  console.log("Hello World");
  ```

  ```python hello_world.py
  print('Hello World!')
  ```

  ```java HelloWorld.java
  class HelloWorld {
      public static void main(String[] args) {
          System.out.println("Hello, World!");
      }
  }
  ```
</CodeGroup>
