使用 `CodeGroup` 组件在带选项卡的界面中展示多个代码块，让用户可以对比不同编程语言的实现，或查看完成同一任务的不同实现方式。

<CodeGroup>
  ```javascript helloWorld.js
  console.log("Hello World");
  ```

  ```python hello_world.py
  print('Hello World!')
  ```

  ```java HelloWorld.java
  class HelloWorld {
      public static void main(String[] args) {
          System.out.println("Hello, World!");
      }
  }
  ```
</CodeGroup>

代码组会从你的 `docs.json` 文件继承全局样式。使用 `styling.codeblocks` 来自定义你的主题。配置选项参见 [Settings](/zh/organize/settings#styling)。

当标签匹配时，代码组会自动与同一页面上的其他代码组和 [选项卡](/zh/components/tabs) 保持同步。当你在一个代码组中选择某种语言时，所有具有匹配标签的选项卡和代码组都会更新为显示相同的语言。

<div id="create-code-groups">
  ## 创建代码组
</div>

要创建代码组，请将多个代码块包裹在 `<CodeGroup>` 标签内。每个代码块都必须包含一个标题，该标题将作为选项卡标签显示。

````mdx
<CodeGroup>

```javascript helloWorld.js
console.log("Hello World");
```

```python hello_world.py
print('Hello World!')
```

```java HelloWorld.java
class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

</CodeGroup>
````

<div id="language-dropdown">
  ## 语言下拉菜单
</div>

你可以通过使用 `dropdown` 属性，将代码组中的标签页替换为下拉菜单，以在不同语言之间切换。

<CodeGroup dropdown>
  ```javascript helloWorld.js
  console.log("Hello World");
  ```

  ```python hello_world.py
  print('Hello World!')
  ```

  ```java HelloWorld.java
  class HelloWorld {
      public static void main(String[] args) {
          System.out.println("Hello, World!");
      }
  }
  ```
</CodeGroup>
