`Columns` 组件可用于将多个 `Card` 组件组合在一起。它最常见的用法是通过指定网格列数，将卡片排列成网格。`Columns` 支持响应式布局，并会自动适配较小的屏幕。

<Columns cols={2}>
  <Card title="开始使用" icon="rocket">
    使用我们的快速入门指南设置你的项目。
  </Card>

  <Card title="API 参考" icon="code">
    了解你的 API 的端点、参数和示例。
  </Card>
</Columns>

```mdx Columns example
<Columns cols={2}>
  <Card title="Get started">
    Set up your project with our quickstart guide.
  </Card>
  <Card title="API reference">
    Explore endpoints, parameters, and examples for your API.
  </Card>
</Columns>
```


<div id="properties">
  ## 属性
</div>

<ResponseField name="cols" type="number" default={2}>
  每行的列数。取值范围为 1 到 4。
</ResponseField>
