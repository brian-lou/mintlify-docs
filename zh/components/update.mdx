使用 `Update` 组件，以一致的格式展示变更日志条目、版本更新和发行说明。

<Update label="示例" description="v0.1.1">
  ## 示例更新

  你可以在这里添加任意内容，比如截图、代码片段或变更列表。

  <Frame>
    <img className="block" src="https://mintlify-assets.b-cdn.net/hero-light.png" alt="PearsDB 介绍页面的截图，作为 Update 组件中图片示例。" />
  </Frame>

  ### 功能

  * 响应式设计
  * 为每个更新提供锚点链接
  * 为每个更新生成 RSS 源条目
</Update>

<div id="how-to-use">
  ## 用法
</div>

```mdx Update example
<Update label="2024-10-11" description="v0.1.0" tags={["Mintlify"]}>
  这是一个带有标签、描述和标记的更新。
</Update>
```

使用多个 `Update` 组件来创建[更新日志](/zh/create/changelogs)。

`Update` 组件会自动生成 RSS 源条目。条目只包含纯 Markdown——组件、代码块、行内代码以及原始 HTML 元素都不会被包含在内。

如果你的更新中包含组件或 HTML，请使用 `rss` 属性为 RSS 订阅者提供替代文本。

```mdx Custom RSS content
<Update
  label="March 2025"
  description="v2.0.0"
  rss={{
    title: "2025年3月 - 重大改版",
    description: "全面的界面改版，包含全新组件"
  }}
>
```

<div id="props">
  ## 属性
</div>

<ResponseField name="label" type="string" required>
  更新的标签。显示在更新内容的左侧，并用于创建锚点链接。标签应当是唯一的。
</ResponseField>

<ResponseField name="tags" type="string[]">
  更新的标签。显示为右侧面板中的筛选器。
</ResponseField>

<ResponseField name="description" type="string">
  更新的描述。显示在标签和标签下方。
</ResponseField>

<ResponseField name="rss" type="object">
  Update 组件会自动生成 RSS 源条目。使用 `rss` 属性可为单个 RSS 源条目设置自定义标题和描述。

  如果未提供：

  * 带有 Markdown 标题的更新会为每个标题创建一个单独的 RSS 源条目。
  * 没有 Markdown 标题的更新会使用 `label` 作为标题创建一个单独的 RSS 源条目。

  <Expandable title="属性">
    <ResponseField name="title" type="string">
      RSS 源条目的自定义标题。
    </ResponseField>

    <ResponseField name="description" type="string">
      RSS 源条目的自定义描述。
    </ResponseField>
  </Expandable>
</ResponseField>
