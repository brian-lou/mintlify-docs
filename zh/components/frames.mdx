description: "为图片和其他组件添加样式化边框，增强视觉强调。"
keywords: ["图片边框", "视觉强调", "说明文字", "边框"]
---

使用边框以统一样式展示图片、图表或其他视觉内容，并可选择添加说明文字。边框会将内容居中，并在视觉上与周围文本区隔开来。

</Frame>

<div id="captions">
  ## 图注
</div>

使用可选的 `caption` prop 为图片添加补充图注。图注会显示在图片下方的边框中。

<Frame caption="优胜美地国家公园每年接待超过 350 万名游客。">
  <img src="https://mintlify-assets.b-cdn.net/yosemite.jpg" alt="优胜美地山谷的照片。" />
</Frame>

<div id="markdown-in-captions">
  ### 图注中的 Markdown
</div>

图注支持 Markdown 格式，包括链接和粗体文本。

<Frame caption="进一步了解 [优胜美地国家公园](https://www.nps.gov/yose/index.htm)，并规划您的行程。">
  <img src="https://mintlify-assets.b-cdn.net/yosemite.jpg" alt="优胜美地山谷的照片。" />
</Frame>

<Frame caption="**重要：**请查看[公园官网](https://www.nps.gov/yose/index.htm)了解当前情况。">
  <img src="https://mintlify-assets.b-cdn.net/yellowstone.jpeg" alt="黄石国家公园中一片被树木环绕、远处可见群山的湖泊照片。" />
</Frame>

<div id="hints">
  ## 提示
</div>

使用可选的 `hint` prop 添加显示在边框前面的文本。提示会显示在边框上方。

<Frame hint="如果你计划前往优胜美地国家公园，请在出发前办妥许可证。" caption="优胜美地国家公园每年接待超过 350 万名游客。">
  <img src="https://mintlify-assets.b-cdn.net/yellowstone.jpeg" alt="一张照片：黄石国家公园中，远处群山连绵，湖泊四周环绕着树木。" />
</Frame>

<div id="properties">
  ## 属性
</div>

<ResponseField name="caption" type="string">
  显示在边框中、居中位于内容下方的图注。支持 Markdown 格式，包括链接和粗体文本。
</ResponseField>

<ResponseField name="hint" type="string">
  显示在边框前面的文本。
</ResponseField>

<CodeGroup>
  ```mdx Frame
  <Frame>
    <img src="/path/image.jpg" alt="Descriptive alt text" />
  </Frame>
  ```

  ```mdx 带说明文字的 Frame
  <Frame caption="Caption text">
    <img src="/path/image.jpg" alt="Descriptive alt text" />
  </Frame>
  ```

  ```mdx 说明文字中包含 Markdown 的 Frame
  <Frame caption="Visit the [documentation](/docs) for more details">
    <img src="/path/image.jpg" alt="Descriptive alt text" />
  </Frame>
  ```

  ```mdx 说明文字中包含粗体文本和链接的 Frame
  <Frame caption="**Note:** See the [official guide](https://example.com) for setup instructions">
    <img src="/path/image.jpg" alt="Descriptive alt text" />
  </Frame>
  ```

  ```mdx 带提示文本的 Frame
  <Frame hint="Hint text">
    <img src="/path/image.jpg" alt="Descriptive alt text" />
  </Frame>
  ```

  ```mdx 同时包含提示文本和说明文字的 Frame
  <Frame hint="Hint text" caption="Caption text">
    <img src="/path/image.jpg" alt="Descriptive alt text" />
  </Frame>
  ```
</CodeGroup>
