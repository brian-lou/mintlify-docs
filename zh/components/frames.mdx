使用边框来展示图像、图表或其他视觉内容，以保持统一的样式，并可选配说明文字。边框会将内容居中显示，并与周围文本形成清晰的视觉分隔。

  <img src="https://mintlify-assets.b-cdn.net/yellowstone.jpeg" alt="黄石国家公园中，一座被树木环绕的湖泊，远处可见群山的照片。" />
</Frame>

<div id="captions">
  ## 说明文字
</div>

使用可选的 `caption` 属性为图片添加额外说明。说明文字会显示在图片下方的框架中。

<Frame caption="优胜美地国家公园每年接待超过 350 万名游客。">
  <img src="https://mintlify-assets.b-cdn.net/yosemite.jpg" alt="优胜美地山谷的照片。" />
</Frame>

<div id="markdown-in-captions">
  ### 说明文字中的 Markdown
</div>

说明文字中支持使用 Markdown 格式，包括链接和加粗文本。

<Frame caption="深入了解[优胜美地国家公园](https://www.nps.gov/yose/index.htm)，并规划你的行程。">
  <img src="https://mintlify-assets.b-cdn.net/yosemite.jpg" alt="优胜美地山谷的照片。" />
</Frame>

<Frame caption="**重要：** 请查看[公园官网](https://www.nps.gov/yose/index.htm)了解最新情况。">
  <img src="https://mintlify-assets.b-cdn.net/yellowstone.jpeg" alt="黄石国家公园中，一座被树林环绕、远处群山环抱的湖泊照片。" />
</Frame>

<div id="hints">
  ## 提示
</div>

使用可选的 `hint` 属性为框架添加前置文本。提示会显示在框架上方。

<Frame hint="如果你打算前往 Yosemite National Park，出发前务必先办好许可。" caption="优胜美地国家公园每年接待超过 350 万名游客。">
  <img src="https://mintlify-assets.b-cdn.net/yellowstone.jpeg" alt="一张在黄石国家公园拍摄的照片：远处是群山，近处是一座被树林环绕的湖泊。" />
</Frame>

<div id="properties">
  ## 属性
</div>

<ResponseField name="caption" type="string">
  作为框架的一部分展示的文本，居中显示在内容下方。支持 Markdown 格式，包括链接和加粗文本。
</ResponseField>

<ResponseField name="hint" type="string">
  显示在框架前的文本。
</ResponseField>

<CodeGroup>

```mdx Frame 示例
<Frame>
  <img src="/path/image.jpg" alt="Descriptive alt text" />
</Frame>
```

```mdx 带有说明文字的 Frame
<Frame caption="Caption text">
  <img src="/path/image.jpg" alt="Descriptive alt text" />
</Frame>
```

```mdx 在说明文字中使用 Markdown 的 Frame
<Frame caption="Visit the [documentation](/docs) for more details">
  <img src="/path/image.jpg" alt="Descriptive alt text" />
</Frame>
```

```mdx 在说明文字中包含加粗文本和链接的 Frame
<Frame caption="**Note:** See the [official guide](https://example.com) for setup instructions">
  <img src="/path/image.jpg" alt="Descriptive alt text" />
</Frame>
```

```mdx 带有提示的 Frame
<Frame hint="Hint text">
  <img src="/path/image.jpg" alt="Descriptive alt text" />
</Frame>
```

```mdx 同时带有提示和说明文字的 Frame
<Frame hint="Hint text" caption="Caption text">
  <img src="/path/image.jpg" alt="Descriptive alt text" />
</Frame>
```
</CodeGroup>
