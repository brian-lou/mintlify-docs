标注可以设置为 Note、Warning、Info、Tip、Check、Danger，或者创建你自己的标注：

<Note>这会在内容中添加一条标注</Note>

```mdx
<Note>这会在内容中添加一条注释</Note>
```

<Warning>这会触发一个需要留意的警告</Warning>

```mdx
<Warning>这是一个需要注意的警告</Warning>
```

<Info>用于突出显示重要信息</Info>

```mdx
<Info>这会引起对重要信息的注意</Info>
```

<Tip>这里提供一个实用提示</Tip>

```mdx
<Tip>这是一个有用的提示</Tip>
```

<Check>这会使其变为选中状态</Check>

```mdx
<Check>这表示已检查状态</Check>
```

<Danger>这是一个危险警告</Danger>

```mdx
<Danger>这是一个危险提示</Danger>
```

<Callout icon="key" color="#FFC107" iconType="regular"> 这是一个自定义提示</Callout>

```mdx wrap
<Callout icon="key" color="#FFC107" iconType="regular">这是一个自定义标注</Callout>
```
