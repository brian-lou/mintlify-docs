提示框可以设置为 Note、Warning、Info、Tip、Check、Danger，也可以创建你自己的提示框：

<Note>这会在内容中添加一条注释</Note>

```mdx
<Note>这会在内容中添加一条注释</Note>
```

<Warning>这会触发一条需要注意的警告</Warning>

```mdx
<Warning>这是一条需要注意的警告</Warning>
```

<Info>这用于提醒你注意重要信息</Info>

```mdx
<Info>这将引起对重要信息的关注</Info>
```

<Tip>这里提供一个实用提示</Tip>

```mdx
<Tip>这是一个实用提示</Tip>
```

<Check>这样就会变为选中状态</Check>

```mdx
<Check>这表示已选中状态</Check>
```

<Danger>这是一个危险警示</Danger>

```mdx
<Danger>这是一个危险提示</Danger>
```

<Callout icon="key" color="#FFC107" iconType="regular"> 这是一个自定义提示框</Callout>

```mdx wrap
<Callout icon="key" color="#FFC107" iconType="regular">This is a custom callout</Callout>
```
