Mintlify 为你的文档页面提供了一套内置的 MDX 组件。使用这些组件来组织内容、突出关键信息、编写 API 文档，并帮助用户进行导航。

<div id="structure-your-content">
  ## 结构化你的内容
</div>

<Card title="选项卡" icon="folder" href="/zh/components/tabs">
  将相关内容组织成可切换的选项卡视图。
</Card>

<Card title="代码组" icon="code" href="/zh/components/code-groups">
  以多种语言展示代码示例。
</Card>

<Card title="步骤" icon="list-ordered" href="/zh/components/steps">
  以编号形式展示按顺序的操作说明。
</Card>

<Card title="分栏" icon="columns-3" href="/zh/components/columns">
  在响应式布局中并排排布内容。
</Card>

<Card title="面板" icon="panel-right" href="/zh/components/panel">
  为补充内容创建侧边栏面板。
</Card>
