使用标签页将内容组织成多个面板，用户可以在这些面板之间切换。你可以添加任意数量的标签页，并在每个标签页中包含其他组件。

<Tabs>
  <Tab title="第一个标签页">
    ☝️ 欢迎查看仅在第一个标签页中显示的内容。

    你可以在标签页中添加任意数量的组件。例如，一个代码块：

    ```java HelloWorld.java
      class HelloWorld {
          public static void main(String[] args) {
              System.out.println("Hello, World!");
          }
      }
    ```
  </Tab>

  <Tab title="First tab">

  </Tab>

标题相同的标签页会在整个页面内保持同步。例如，如果你有多个标签页组都包含 `JavaScript` 标签页，那么在其中一个标签页组中选择 `JavaScript` 时，其他标签页组中的 `JavaScript` 也会自动选中。这有助于用户在选择一次语言或框架后，在所有相关位置都看到该选择。标签页还会与标题相同的 [代码组](/zh/components/code-groups) 同步。

如需禁用标签页同步，请在 `<Tabs>` 组件中添加 `sync={false}`。

```mdx Disable tab sync example
<Tabs sync={false}>
  <Tab title="First tab">
    This tab group operates independently.
  </Tab>
  <Tab title="Second tab">
    Selecting tabs here won't affect other tab groups.
  </Tab>
</Tabs>
```

<div id="properties">
  ## 属性
</div>

<ResponseField name="title" type="string" required>
  标签页的标题。标题越短，越便于浏览和切换。标题相同的标签页会同步选中状态。
</ResponseField>

<ResponseField name="icon" type="string">
  [Font Awesome](https://fontawesome.com/icons) 图标、[Lucide](https://lucide.dev/icons) 图标、图标 URL，或图标的相对路径。
</ResponseField>

<ResponseField name="iconType" type="string">
  仅适用于 Font Awesome 图标：可选值为 `regular`、`solid`、`light`、`thin`、`sharp-solid`、`duotone`、`brands`。
</ResponseField>

<ResponseField name="sync" type="boolean" default="true">
  当为 `true` 时，标签页会与页面上其他标题相同的标签页和代码组同步。设为 `false` 可使各个标签页彼此独立。
</ResponseField>

<ResponseField name="borderBottom" type="boolean">
  为标签页容器添加底部边框和内边距。适合在视觉上将标签页内容与页面其余部分区分开来，尤其是在标签页包含不同长度的内容时。
</ResponseField>
