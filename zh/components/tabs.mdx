使用选项卡将内容组织为多个可切换的面板。你可以添加任意数量的选项卡，并在每个选项卡中放入其他组件。

<Tabs>
  <Tab title="第一个选项卡">
    ☝️ 欢迎来到只能在第一个选项卡中看到的内容。

    你可以在选项卡中添加任意数量的组件。比如，一个代码块：

    ```java HelloWorld.java
      class HelloWorld {
          public static void main(String[] args) {
              System.out.println("Hello, World!");
          }
      }
    ```
  </Tab>

  <Tab title="第二个选项卡" icon="leaf">
    ✌️ 这里是仅在第二个选项卡中显示的内容。

    这个选项卡还有一个 <Icon icon="leaf" /> 图标！
  </Tab>

  <Tab title="第三个选项卡">
    💪 这里是仅在第三个选项卡中显示的内容。
  </Tab>
</Tabs>

````mdx Tabs example
<Tabs>
  <Tab title="First tab">
    ☝️ 欢迎查看仅在第一个标签页中可见的内容。

    您可以在标签页中添加任意数量的组件。例如，一个代码块：
    ```java HelloWorld.java
      class HelloWorld {
          public static void main(String[] args) {
              System.out.println("Hello, World!");
          }
      }
    ```
  </Tab>
  <Tab title="Second tab" icon="leaf">
    ✌️ 这是仅在第二个标签页中显示的内容。

    这个标签页有一个 <Icon icon="leaf" /> 图标！
  </Tab>
  <Tab title="Third tab">
    💪 这是仅在第三个标签页中显示的内容。
  </Tab>
</Tabs>
````

具有相同标题的 Tabs 会在整个页面中保持同步。例如，如果你有多个选项卡组都包含一个 `JavaScript` 选项卡标题，在其中一个选项卡组中选择 `JavaScript` 时，其他选项卡组中的 `JavaScript` 也会自动被选中。这样，用户只需选择一次语言或框架，就能在各处看到这一选择得到体现。Tabs 也会与具有相同标题的[代码组](/zh/components/code-groups)同步。

若要禁用选项卡同步，请在 `<Tabs>` 组件上添加 `sync={false}`。

```mdx Disable tab sync example
<Tabs sync={false}>
  <Tab title="First tab">
    This tab group operates independently.
  </Tab>
  <Tab title="Second tab">
    Selecting tabs here won't affect other tab groups.
  </Tab>
</Tabs>
```

<div id="properties">
  ## 属性
</div>

<ResponseField name="title" type="string" required>
  选项卡的标题。较短的标题更便于导航。具有相同标题的选项卡会同步其选中内容。
</ResponseField>

<ResponseField name="icon" type="string">
  一个 [Font Awesome](https://fontawesome.com/icons) 图标、[Lucide](https://lucide.dev/icons) 图标、图标的 URL，或图标的相对路径。
</ResponseField>

<ResponseField name="iconType" type="string">
  仅适用于 Font Awesome 图标：`regular`、`solid`、`light`、`thin`、`sharp-solid`、`duotone`、`brands` 之一。
</ResponseField>

<ResponseField name="sync" type="boolean" default="true">
  当为 `true` 时，选项卡会与页面上其他具有相同标题的选项卡和代码组同步。将其设为 `false` 可使选项卡相互独立。
</ResponseField>

<ResponseField name="borderBottom" type="boolean">
  为选项卡容器添加底部边框和内边距。用于在视觉上将选项卡内容与页面的其余部分分隔开，尤其是当选项卡中包含长短不一的内容时。
</ResponseField>
