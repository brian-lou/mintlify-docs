---
title: "Gérer la visibilité des pages"
description: "Contrôlez quels endpoints d'API apparaissent dans la navigation de votre documentation."
keywords: ["x-hidden", "x-excluded", "hide endpoints", "page visibility", "internal endpoints"]
---

Pour les endpoints internes, les opérations obsolètes, les fonctionnalités bêta ou les endpoints qui doivent être accessibles via une URL directe mais non visibles dans la navigation du site, vous pouvez contrôler quelles opérations OpenAPI sont publiées en tant que pages de documentation ainsi que leur visibilité dans la navigation.

Si vos pages sont générées automatiquement à partir d'un document OpenAPI, gérez leur visibilité avec les extensions `x-hidden` et `x-excluded`.

<div id="x-hidden">
  ## `x-hidden`
</div>

L’extension `x-hidden` crée une page pour un endpoint, mais la masque dans la navigation. La page n’est accessible qu’en accédant directement à son URL.

Les cas d’usage courants de `x-hidden` sont :

- Des endpoints que vous souhaitez documenter, mais pas mettre en avant.
- Des pages vers lesquelles vous renverrez depuis d’autres contenus.
- Des endpoints destinés à des utilisateurs spécifiques.

<div id="x-excluded">
  ## `x-excluded`
</div>

L’extension `x-excluded` exclut complètement un endpoint de votre documentation.

Les principaux cas d’utilisation de `x-excluded` sont :

- Endpoints internes uniquement.
- Endpoints obsolètes que vous ne souhaitez pas documenter.
- Fonctionnalités bêta qui ne sont pas encore prêtes pour une documentation publique.

<div id="implementation">
  ## Implémentation
</div>

Ajoutez l’extension `x-hidden` ou `x-excluded` au niveau de la méthode HTTP dans votre spécification OpenAPI.

Voici des exemples montrant comment utiliser chaque propriété dans un document de schéma OpenAPI pour un endpoint et un chemin de webhook.

```json Endpoint example {11, 19}
"paths": {
  "/plants": {
    "get": {
      "description": "Returns all plants from the store",
      "parameters": { /*...*/ },
      "responses": { /*...*/ }
    }
  },
  "/hidden_plants": {
    "get": {
      "x-hidden": true,
      "description": "Returns all somewhat secret plants from the store",
      "parameters": { /*...*/ },
      "responses": { /*...*/ }
    }
  },
  "/secret_plants": {
    "get": {
      "x-excluded": true,
      "description": "Returns all top secret plants from the store (do not publish this endpoint!)",
      "parameters": { /*...*/ },
      "responses": { /*...*/ }
    }
  }
},
```

```json Webhook example {9, 15}
"webhooks": {
  "/plants_hook": {
    "post": {
      "description": "Webhook pour les informations sur une nouvelle plante ajoutée au magasin",
    }
  },
  "/hidden_plants_hook": {
    "post": {
      "x-hidden": true,
      "description": "Webhook pour des informations quelque peu confidentielles sur une nouvelle plante ajoutée au magasin"
    }
  },
  "/secret_plants_hook": {
    "post": {
      "x-excluded": true,
      "description": "Webhook pour des informations top secrètes sur une nouvelle plante ajoutée au magasin (ne pas publier ce point de terminaison !)"
    }
  }
}
```
