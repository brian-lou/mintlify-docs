---

Pour les endpoints réservés à un usage interne, les opérations dépréciées, les fonctionnalités bêta ou les endpoints qui doivent être accessibles via une URL directe sans être visibles dans la navigation du site, vous pouvez contrôler quelles opérations OpenAPI sont publiées sous forme de pages de documentation et leur visibilité dans la navigation.

Si vos pages sont générées automatiquement à partir d&#39;un document OpenAPI, gérez leur visibilité à l&#39;aide des extensions `x-hidden` et `x-excluded`.

<div id="x-hidden">
  ## `x-hidden`
</div>

L’extension `x-hidden` crée une page pour un endpoint, mais ne l’affiche pas dans la navigation. La page n’est accessible qu’en accédant directement à son URL.

Les cas d’usage courants de `x-hidden` sont :

* Les endpoints que vous souhaitez documenter sans les mettre en avant.
* Les pages auxquelles vous renverrez depuis d’autres contenus.
* Les endpoints destinés à des utilisateurs spécifiques.

<div id="x-excluded">
  ## `x-excluded`
</div>

L’extension `x-excluded` exclut complètement un endpoint de votre documentation.

Les cas d’usage courants de `x-excluded` sont :

* Les endpoints à usage interne uniquement.
* Les endpoints obsolètes que vous ne souhaitez pas documenter.
* Les fonctionnalités bêta qui ne sont pas prêtes à être documentées publiquement.

<div id="implementation">
  ## Implémentation
</div>

Ajoutez l’extension `x-hidden` ou `x-excluded` sous la méthode HTTP dans votre spécification OpenAPI.

Voici des exemples d’utilisation de chaque propriété dans un document de schéma OpenAPI pour un endpoint et un chemin de webhook.

```json Endpoint example {11, 19}
"paths": {
  "/plants": {
    "get": {
      "description": "Returns all plants from the store",
      "parameters": { /*...*/ },
      "responses": { /*...*/ }
    }
  },
  "/hidden_plants": {
    "get": {
      "x-hidden": true,
      "description": "Returns all somewhat secret plants from the store",
      "parameters": { /*...*/ },
      "responses": { /*...*/ }
    }
  },
  "/secret_plants": {
    "get": {
      "x-excluded": true,
      "description": "Returns all top secret plants from the store (do not publish this endpoint!)",
      "parameters": { /*...*/ },
      "responses": { /*...*/ }
    }
  }
},
```

```json Webhook example {9, 15}
"webhooks": {
  "/plants_hook": {
    "post": {
      "description": "Webhook for information about a new plant added to the store",
    }
  },
  "/hidden_plants_hook": {
    "post": {
      "x-hidden": true,
      "description": "Webhook for somewhat secret information about a new plant added to the store"
    }
  },
  "/secret_plants_hook": {
    "post": {
      "x-excluded": true,
      "description": "Webhook for top secret information about a new plant added to the store (do not publish this endpoint!)"
    }
  }
}
```
