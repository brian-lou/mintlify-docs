---
title: "Ajouter des exemples de SDK"
description: "Afficher des exemples de code de SDK dans votre documentation d'API."
keywords: ["x-codeSamples", "SDK examples"]
---

Si vos utilisateurs interagissent avec votre API à l&#39;aide d&#39;un SDK plutôt que directement via une requête réseau, vous pouvez utiliser l&#39;extension `x-codeSamples` pour ajouter des exemples de code à votre document OpenAPI et les afficher dans vos pages OpenAPI.

Cette propriété peut être ajoutée à n&#39;importe quelle méthode de requête et possède le schéma suivant.

<ParamField body="lang" type="string" required>
  La langue de l&#39;exemple de code.
</ParamField>

<ParamField body="label" type="string">
  Le libellé de l&#39;exemple. C&#39;est utile lorsque vous fournissez plusieurs exemples pour un même endpoint.
</ParamField>

<ParamField body="source" type="string" required>
  Le code source de l&#39;exemple.
</ParamField>

Voici un exemple d&#39;exemples de code pour une application de suivi de plantes, qui possède à la fois un outil CLI Bash et un SDK JavaScript.

```yaml
paths:
  /plants:
    get:
      # ...
      x-codeSamples:
        - lang: bash
          label: List all unwatered plants
          source: |
            planter list -u
        - lang: javascript
          label: List all unwatered plants
          source: |
            const planter = require('planter');
            planter.list({ unwatered: true });
        - lang: bash
          label: List all potted plants
          source: |
            planter list -p
        - lang: javascript
          label: List all potted plants
          source: |
            const planter = require('planter');
            planter.list({ potted: true });
```
