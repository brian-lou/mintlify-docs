Après avoir suivi ce guide, vous aurez un site de documentation en ligne prêt à être personnalisé et mis à jour.

<div id="before-you-begin">
  ## Avant de commencer
</div>

Mintlify utilise une approche docs-as-code pour gérer votre documentation. Chaque page de votre site correspond à un fichier stocké dans le <Tooltip tip="Le code source de votre documentation, où sont stockés tous les fichiers ainsi que leur historique. L’éditeur web se connecte à votre dépôt de documentation pour accéder au contenu et le modifier, ou vous pouvez modifier les fichiers localement dans l’IDE de votre choix.">dépôt</Tooltip> de votre documentation.

Lorsque vous connectez votre dépôt de documentation à votre projet, vous pouvez travailler sur votre documentation en local ou dans l’éditeur web, puis synchroniser vos modifications avec votre dépôt distant.

<div id="deploy-your-documentation-site">
  ## Déployez votre site de documentation
</div>

Accédez à [mintlify.com/start](https://mintlify.com/start) et terminez la configuration initiale. Pendant cette étape, vous connecterez votre compte GitHub, créerez ou sélectionnerez un dépôt pour votre documentation, puis installerez la GitHub App pour activer les déploiements automatiques.

Une fois la configuration initiale terminée, votre site de documentation est déployé et accessible à l&#39;adresse de votre URL `.mintlify.app`.

<AccordionGroup>
  <Accordion title="Facultatif : ne pas connecter GitHub pendant la configuration initiale">
    Si vous souhaitez démarrer rapidement sans connecter votre propre dépôt, vous pouvez ignorer la connexion à GitHub pendant la configuration initiale. Mintlify crée un dépôt privé dans une organisation privée et configure automatiquement la GitHub App pour vous.

    Vous pouvez ainsi utiliser immédiatement l&#39;éditeur web et migrer vers votre propre dépôt plus tard.
  </Accordion>
</AccordionGroup>

<div id="view-your-deployed-site">
  ## Consultez votre site déployé
</div>

Votre site de documentation est maintenant déployé à l’adresse `https://<your-project-name>.mintlify.app`.

Retrouvez votre URL exacte sur la page **Overview** de votre [tableau de bord](https://dashboard.mintlify.com/).

</Tip>

<div id="make-your-first-change">
  ## Apportez votre première modification
</div>

<Tabs>
  <Tab title="CLI">
    <Steps>
      <Step title="Installer la CLI">
        La CLI nécessite [Node.js](https://nodejs.org/en) v20.17.0 ou une version supérieure. Utilisez une version LTS pour plus de stabilité.

        <CodeGroup>
          ```bash npm
          npm i -g mint
          ```

          ```bash pnpm
          pnpm add -g mint
          ```
        </CodeGroup>

        Consultez [Installer la CLI](/fr/installation) pour des instructions détaillées et des conseils de dépannage.
      </Step>

      <Step title="Cloner votre dépôt">
        Si vous n&#39;avez pas encore cloné votre dépôt en local, suivez les instructions de [Cloner votre dépôt](/fr/installation#clone-your-repository).
      </Step>

      <Step title="Modifier une page">
        Ouvrez `index.mdx` dans l&#39;éditeur de votre choix et mettez à jour la description dans le Frontmatter :

        ```mdx
        ---
        title: "Introduction"
        description: "Your custom description here"
        ---
        ```
      </Step>

      <Step title="Prévisualiser en local">
        Exécutez la commande suivante depuis le répertoire de votre documentation :

        ```bash
        mint dev
        ```

        Consultez l&#39;aperçu à l&#39;adresse `http://localhost:3000`.
      </Step>

      <Step title="Pousser vos modifications">
        Validez et poussez vos modifications pour déclencher un déploiement :

        ```bash
        git add .
        git commit -m "Update description"
        git push
        ```

        Mintlify déploie automatiquement vos modifications. Consultez l&#39;état du déploiement sur la page [Overview](https://dashboard.mintlify.com/) de votre tableau de bord.
      </Step>
    </Steps>
  </Tab>

  <Tab title="Éditeur web">
    <Steps>
      <Step title="Ouvrir l'éditeur web">
        Accédez à l&#39;[éditeur web](https://dashboard.mintlify.com/editor) depuis votre tableau de bord.
      </Step>

      <Step title="Modifier une page">
        Ouvrez la page **Introduction** et mettez à jour la description.

        <Frame>
          <img src="/images/quickstart/hello-world-light.png" alt="Page Introduction ouverte dans l'éditeur web, avec la description modifiée en « Hello world! »." className="block dark:hidden" />

          <img src="/images/quickstart/hello-world-dark.png" alt="Page Introduction ouverte dans l'éditeur web, avec la description modifiée en « Hello world! »." className="hidden dark:block" />
        </Frame>
      </Step>

      <Step title="Publier">
        Cliquez sur le bouton **Publish** en haut à droite de la barre d&#39;outils de l&#39;éditeur web.
      </Step>

      <Step title="Voir en ligne">
        Sur la page [Overview](https://dashboard.mintlify.com/) de votre tableau de bord, vous pouvez consulter l&#39;état du déploiement de votre site. Une fois le déploiement terminé, actualisez votre site de documentation pour voir vos modifications en ligne.
      </Step>
    </Steps>
  </Tab>
</Tabs>
