Une fois que vous aurez terminé ce guide, vous disposerez d&#39;un site de documentation en ligne, prêt à être personnalisé et mis à jour.

<div id="before-you-begin">
  ## Avant de commencer
</div>

Mintlify utilise une approche « docs-as-code » pour gérer votre documentation. Chaque page de votre site correspond à un fichier stocké dans le <Tooltip tip="Le code source de votre documentation, où tous les fichiers et leur historique sont stockés. L’éditeur web se connecte à votre dépôt de documentation pour accéder au contenu et le modifier, ou vous pouvez modifier les fichiers localement dans votre IDE préféré.">dépôt</Tooltip> de votre documentation.

Lorsque vous connectez le dépôt de votre documentation à votre projet, vous pouvez travailler sur votre documentation localement ou dans l’éditeur web et synchroniser toute modification avec votre dépôt distant.

<div id="deploy-your-documentation-site">
  ## Déployer votre site de documentation
</div>

Rendez-vous sur [mintlify.com/start](https://mintlify.com/start) et terminez le processus d&#39;onboarding. Pendant l&#39;onboarding, vous connectez votre compte GitHub, créez ou sélectionnez un dépôt pour votre documentation et installez l&#39;application GitHub afin d&#39;activer les déploiements automatiques.

Une fois l&#39;onboarding terminé, votre site de documentation est déployé et accessible via votre URL `.mintlify.app`.

<AccordionGroup>
  <Accordion title="Facultatif : passer la connexion à GitHub pendant l'onboarding">
    Si vous souhaitez commencer rapidement sans connecter votre propre dépôt, vous pouvez passer l&#39;étape de connexion à GitHub pendant l&#39;onboarding. Mintlify crée un dépôt privé dans une organisation privée et configure automatiquement l&#39;application GitHub pour vous.

    Cela vous permet d&#39;utiliser immédiatement l&#39;éditeur en ligne et de migrer vers votre propre dépôt plus tard.
  </Accordion>
</AccordionGroup>

<div id="view-your-deployed-site">
  ## Consultez votre site déployé
</div>

Votre site de documentation est maintenant déployé à l’adresse `https://<your-project-name>.mintlify.app`.

Retrouvez votre URL exacte sur la page **Overview** de votre [tableau de bord](https://dashboard.mintlify.com/).

  Votre site est prêt à être consulté immédiatement. Utilisez cette URL pour les tests et le partage avec votre équipe. Avant de le partager avec vos utilisateurs, vous voudrez peut-être ajouter un [domaine personnalisé](/fr/customize/custom-domain).
</Tip>

<div id="make-your-first-change">
  ## Effectuez votre première modification
</div>

<Tabs>
  <Tab title="CLI">
    <Steps>
      <Step title="Installer la CLI">
        La CLI nécessite [Node.js](https://nodejs.org/en) v20.17.0 ou une version ultérieure. Utilisez une version LTS pour plus de stabilité.

        <CodeGroup>
          ```bash npm
          npm i -g mint
          ```

          ```bash pnpm
          pnpm add -g mint
          ```
        </CodeGroup>

        Consultez [Installer la CLI](/fr/installation) pour plus de détails et pour le dépannage.
      </Step>

      <Step title="Cloner votre dépôt">
        Si vous n&#39;avez pas encore cloné votre dépôt en local, suivez les instructions dans [Cloner votre dépôt](/fr/installation#clone-your-repository).
      </Step>

      <Step title="Modifier une page">
        Ouvrez `index.mdx` dans votre éditeur préféré et mettez à jour la description dans le frontmatter :

        ```mdx
        ---
        title: "Introduction"
        description: "Your custom description here"
        ---
        ```
      </Step>

      <Step title="Prévisualiser en local">
        Exécutez la commande suivante depuis votre répertoire de documentation :

        ```bash
        mint dev
        ```

        Affichez la prévisualisation à l’adresse `http://localhost:3000`.
      </Step>

      <Step title="Pousser vos modifications">
        Validez et poussez vos modifications pour déclencher un déploiement :

        ```bash
        git add .
        git commit -m "Update description"
        git push
        ```

        Mintlify déploie automatiquement vos modifications. Consultez l’état de votre déploiement sur la page [Overview](https://dashboard.mintlify.com/) de votre tableau de bord.
      </Step>
    </Steps>
  </Tab>

  <Tab title="Éditeur web">
    <Steps>
      <Step title="Ouvrir l’éditeur web">
        Accédez à l’[éditeur web](https://dashboard.mintlify.com/editor) depuis votre tableau de bord.
      </Step>

      <Step title="Modifier une page">
        Ouvrez la page **Introduction** et mettez à jour la description.

        <Frame>
          <img src="/images/quickstart/hello-world-light.png" alt="Page « Introduction » ouverte dans l’éditeur web avec la description modifiée pour afficher « Hello world ! »." className="block dark:hidden" />

          <img src="/images/quickstart/hello-world-dark.png" alt="Page « Introduction » ouverte dans l’éditeur web avec la description modifiée pour afficher « Hello world ! »." className="hidden dark:block" />
        </Frame>
      </Step>

      <Step title="Publier">
        Cliquez sur le bouton **Publish** en haut à droite de la barre d’outils de l’éditeur web.
      </Step>

      <Step title="Voir en ligne">
        Sur la page [Overview](https://dashboard.mintlify.com/) de votre tableau de bord, vous pouvez voir l’état de déploiement de votre site. Lorsque le déploiement est terminé, actualisez votre site de documentation pour voir vos modifications en ligne.
      </Step>
    </Steps>
  </Tab>
</Tabs>
