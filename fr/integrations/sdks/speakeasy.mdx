Des extraits de code générés automatiquement à partir des SDK Speakeasy peuvent être intégrés directement à la documentation de référence d’API de Mintlify. Les extraits d’utilisation du SDK s’affichent dans le [Bac à sable API interactif](/fr/api-playground/overview) des sites de documentation propulsés par Mintlify.

<Frame>
  ![Un Bac à sable API Mintlify avec des extraits de code Speakeasy.](/images/speakeasy/mintlify-with-speakeasy-openapi.png)
</Frame>

<div id="prerequisites">
  ## Prérequis
</div>

Pour intégrer Mintlify à Speakeasy, vous aurez besoin des éléments suivants :

* Un [dépôt de documentation Mintlify](/fr/quickstart#creating-the-repository).
  * Un SDK généré par Speakeasy avec une [URL automatisée pour les exemples de code](https://www.speakeasy.com/docs/code-samples/automated-code-sample-urls) configurée.

<div id="setting-up-the-integration">
  ## Configurer l’intégration
</div>

Pour intégrer Speakeasy à Mintlify, vous devez récupérer l’URL publique de la spécification combinée de l’API depuis le registre, puis mettre à jour votre fichier de configuration `docs.json`.

<div id="get-the-apis-combined-spec-public-url-from-the-registry">
  ### Récupérez l&#39;URL publique de la spécification combinée de l&#39;API depuis le registre
</div>

Accédez à votre [Speakeasy Dashboard](https://app.speakeasy.com) et ouvrez l&#39;onglet **API Registry**. Ouvrez l&#39;entrée `*-with-code-samples` correspondant à l&#39;API.

<Frame>
  ![Capture d'écran de la page Speakeasy API Registry. L'onglet API Registry est mis en évidence par un carré rouge avec le numéro 1, et l'entrée de l'API par un carré rouge avec le numéro 2.](/images/speakeasy/openapi-registry-and-combined-spec.png)
</Frame>

<Note>
  Si l&#39;entrée n&#39;est pas intitulée **Combined Spec**, assurez-vous qu&#39;une [URL automatique d&#39;exemples de code](https://www.speakeasy.com/docs/code-samples/automated-code-sample-urls) est configurée pour l&#39;API.
</Note>

Depuis la page de l&#39;entrée du registre, copiez l&#39;URL publique fournie.

<Frame>
  ![Capture d'écran montrant l'entrée de registre de la spécification combinée, avec la fonction de copie de l'URL mise en évidence par un carré rouge.](/images/speakeasy/copy-combined-spec-url.png)
</Frame>

<div id="update-your-docsjson-configuration-file">
  ### Mettez à jour votre fichier de configuration `docs.json`
</div>

Ajoutez l’URL de la spécification combinée dans une section **Anchors** ou **Tabs** de votre fichier `docs.json`.

Ajoutez l’URL de la spécification combinée à une ancre en mettant à jour le champ `anchor` dans votre fichier `docs.json`, comme suit :

```json docs.json
{
  "anchors": [
    {
      "name": "API Reference",
      // !mark
      "openapi": "SPEAKEASY_COMBINED_SPEC_URL",
      "url": "api-reference",
      "icon": "square-terminal"
    }
  ]
}
```

Ajoutez l’URL de la spécification combinée à un onglet en modifiant le champ `tab` du fichier `docs.json` comme suit :

```json docs.json
{
  "tabs": [
    {
      "name": "API Reference",
      "url": "api-reference",
      // !mark
      "openapi": "SPEAKEASY_COMBINED_SPEC_URL"
    }
  ]
}
```

Les extraits de code générés par Speakeasy peuvent désormais être consultés dans votre documentation d’API et testés dans le Bac à sable API.
