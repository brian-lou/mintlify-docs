Vous devrez générer une nouvelle propriété <Tooltip tip="Google Analytics 4">GA4</Tooltip> à utiliser dans Mintlify. Les données collectées seront envoyées dans le même projet que vos autres données Google Analytics.

Si vous utilisez la version précédente de Google Analytics, Universal Analytics, vous pourrez tout de même générer une propriété <Tooltip tip="Google Analytics 4">GA4</Tooltip>. Les données <Tooltip tip="Google Analytics 4">GA4</Tooltip> sont légèrement différentes des données UA, mais elles sont tout de même rassemblées dans le même projet.

<div id="how-to-connect-ga4-to-mintlify">
  ## Comment connecter GA4 à Mintlify
</div>

<div id="create-a-web-stream">
  ### Créer un flux Web
</div>

Vous devez créer un flux Web pour obtenir l’ID de mesure à intégrer dans Mintlify.

Cliquez sur l’icône en forme de roue dentée en bas à gauche de l’écran Google Analytics, puis cliquez sur Data Streams.

<Frame>![Capture d’écran de la page Data Streams dans le tableau de bord Google Analytics.](/images/ga4-web-streams.png)</Frame>

Créez un flux Web et indiquez l’URL de votre site de documentation Mintlify comme URL du flux.

Votre ID de mesure ressemble à `G-XXXXXXX` et apparaîtra dans Stream Details immédiatement après la création du flux Web.

<div id="put-measurement-id-in-docsjson">
  ### Placez l’ID de mesure dans docs.json
</div>

Ajoutez votre ID de mesure dans votre fichier `docs.json` comme ceci :

```json docs.json
"integrations": {
    "ga4": {
        "measurementId": "G-XXXXXXX"
    }
}
```


<div id="wait">
  ### Patientez
</div>

Google Analytics met deux à trois jours à afficher vos données.

Vous pouvez utiliser le [Google Analytics Debugger](https://chrome.google.com/webstore/detail/google-analytics-debugger/jnkmfdileelhofjcijamephohjechhna?hl=en) pour vérifier que le suivi Analytics est correctement activé. L’extension consignera dans la console de votre navigateur chaque fois que GA4 envoie une requête.

<Note>

Les liens de prévisualisation ont le suivi Analytics désactivé.

</Note>
