Ajoutez ce qui suit à votre fichier `docs.json` pour envoyer des statistiques à Fathom.

Vous pouvez obtenir le `siteId` à partir des paramètres de votre script.

<CodeGroup>

```json Options d'analyse dans docs.json
"integrations": {
    "fathom": {
        "siteId": "required"
    }
}
```

```json Exemple
"integrations": {
    "fathom": {
        "siteId": "YSVMSDAY"
    }
}
```

</CodeGroup>
