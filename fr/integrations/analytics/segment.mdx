Ajoutez votre clé d’écriture Segment à votre fichier `docs.json` pour envoyer des événements d’analyse à Segment.

<CodeGroup>
  ```json Options d’analyse dans docs.json
  "integrations": {
      "segment": {
          "key": "required",
      }
  }
  ```

  ```json Exemple
  "integrations": {
      "segment": {
          "key": "nqJxiRG15Y6M594P8Sb8ESEciU3VC2"
      }
  }
  ```
</CodeGroup>
