description: "Gérez les balises et les événements d’analyse avec Google Tag Manager."
keywords: ["Intégration GTM", "gestion des balises", "ID de balise", "consentement aux cookies"]
---

Ajoutez votre ID de balise au fichier `docs.json`, et nous injecterons le script Google Tag Manager sur toutes vos pages.

Si vous en avez besoin, c’est à vous de configurer les bannières de consentement aux cookies avec Google Tag Manager.

<CodeGroup>
  ```json Options d’analyse dans docs.json
  "integrations": {
      "gtm": {
          "tagId": "required"
      }
  }
  ```

  ```json Exemple
  "integrations": {
      "gtm": {
          "tagId": "GTM-MGBL4PW"
      }
  }
  ```
</CodeGroup>
