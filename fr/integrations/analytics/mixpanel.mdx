Ajoutez ce qui suit à votre fichier `docs.json` pour envoyer vos données d’analyse à Mixpanel.

```json Analytics options in docs.json
"integrations": {
    "mixpanel": {
        "projectToken": "YOUR_MIXPANEL_PROJECT_TOKEN"
    }
}
```

Remplacez `YOUR_MIXPANEL_PROJECT_TOKEN` par le jeton de votre projet Mixpanel. Vous trouverez ce jeton dans les [paramètres de votre projet Mixpanel](https://mixpanel.com/settings/project).


<div id="tracked-events">
  ## Événements suivis
</div>

Mintlify suit automatiquement les interactions utilisateur suivantes :

* Pages vues
* Requêtes de recherche
* Envois de commentaires
* Interactions avec le menu contextuel
* Clics sur la navigation

Si vous ne voyez pas d&#39;événements dans Mixpanel, assurez-vous que le jeton de votre projet est correct et qu&#39;aucune politique de sécurité du contenu n&#39;empêche le script Mixpanel de se charger.
