Ajoutez ce qui suit à votre fichier `docs.json` pour envoyer des données d’analyse à Mixpanel.

```json Analytics options in docs.json
"integrations": {
    "mixpanel": {
        "projectToken": "YOUR_MIXPANEL_PROJECT_TOKEN"
    }
}
```

Remplacez `YOUR_MIXPANEL_PROJECT_TOKEN` par le jeton de projet Mixpanel. Vous pouvez le trouver dans les [paramètres de votre projet Mixpanel](https://mixpanel.com/settings/project).


<div id="tracked-events">
  ## Événements suivis
</div>

Mintlify suit automatiquement les interactions utilisateur suivantes :

- Pages vues
- Requêtes de recherche
- Envois de commentaires
- Interactions avec le menu contextuel
- Clics de navigation

Si vous ne voyez pas d'événements dans Mixpanel, assurez-vous que le jeton de votre projet est correct et qu’aucune stratégie de sécurité de contenu ne bloque le script Mixpanel.
