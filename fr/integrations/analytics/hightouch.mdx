Ajoutez les éléments suivants à votre fichier `docs.json` pour envoyer des données analytiques à Hightouch.

<Info>
  N’incluez pas `https://` dans `apiHost`.
</Info>

<CodeGroup>
  ```json Options d’analyse dans docs.json
  "integrations": {
      "hightouch": {
          "writeKey": "required"
          "apiHost": "optional"
      }
  }
  ```

  ```json Exemple
  "integrations": {
      "hightouch": {
          "writeKey": "9132c81do371p76sr11da0075469b54f77649c9a067dp0303p56q0q64n072336"
          "apiHost": "us-east-1.hightouch-events.com" # facultatif, valeur par défaut : `us-east-1.hightouch-events.com`
      }
  }
  ```
</CodeGroup>
