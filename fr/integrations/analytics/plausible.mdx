Ajoutez le domaine de votre site à `docs.json` pour envoyer les données d’analyse à Plausible.

<Info>
  N’incluez pas `https://` dans le domaine ou le serveur.
</Info>

<CodeGroup>
  ```json Options d’analyse dans docs.json
  "integrations": {
      "plausible": {
          "domain": "obligatoire - le domaine de votre documentation",
          "server": "facultatif - l’URL de votre serveur Plausible auto-hébergé"
      }
  }
  ```

  ```json Exemple
  "integrations": {
      "plausible": {
          "domain": "docs.domain.com"
      }
  }
  ```
</CodeGroup>
