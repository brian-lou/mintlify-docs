Ajoutez ce qui suit à votre fichier `docs.json` pour envoyer des données d’analyse à Pirsch.

Vous pouvez obtenir l’identifiant de votre site dans Settings &gt; Developer &gt; Identification Code.

<CodeGroup>
  ```json Options d’analyse dans docs.json
  "integrations": {
      "pirsch": {
          "id": "required"
      }
  }
  ```

  ```json Exemple
  "integrations": {
      "pirsch": {
          "id": "8Kw7OKxBfswOjnKGZa7P9Day8JmVYwTp"
      }
  }
  ```
</CodeGroup>
