Ajoutez ce qui suit à votre fichier `docs.json` pour envoyer des données d’analyse à PostHog.

Vous n’avez besoin d’inclure `apiHost` que si vous auto-hébergez PostHog. Nous envoyons les événements à `https://app.posthog.com` par défaut.

<CodeGroup>
  ```json Options d’analyse dans docs.json
  "integrations": {
      "posthog": {
          "apiKey": "YOUR_POSTHOG_PROJECT_API_KEY",
          "apiHost": "optional",
          "sessionRecording": true
      }
  }
  ```

  ```json Exemple
  "integrations": {
      "posthog": {
          "apiKey": "phc_TXdpocbYTeZVm5VJmMzHTMrCofBQu3e0kN7HGMNGTVW"
      }
  }
  ```
</CodeGroup>

<div id="configuration-options">
  ### Options de configuration
</div>

<ParamField path="apiKey" type="string" required>
  La clé API de votre projet PostHog. Elle doit commencer par `phc_`.
</ParamField>

<ParamField path="apiHost" type="string">
  L’URL de votre instance PostHog. Requise uniquement si vous auto-hébergez PostHog. La valeur par défaut est `https://app.posthog.com`.
</ParamField>

<ParamField path="sessionRecording" type="boolean" default="true">
  Active ou désactive l’enregistrement de session. Définissez cette option sur `false` pour désactiver les enregistrements de session tout en conservant l’analyse activée.
</ParamField>

<div id="session-recordings">
  ## Enregistrements de session
</div>

Les enregistrements de session sont activés par défaut lorsque vous configurez PostHog. Pour les désactiver tout en conservant l’analyse activée, définissez `sessionRecording` sur `false` dans votre configuration.

```json Disable session recordings
"integrations": {
    "posthog": {
        "apiKey": "phc_your-key",
        "sessionRecording": false
    }
}
```

Vous devez ajouter l’URL de votre site de documentation aux &quot;Domaines autorisés pour les enregistrements&quot; de PostHog avant de pouvoir recevoir des enregistrements de session. L’option pour ajouter votre URL se trouve dans les paramètres du projet PostHog.
