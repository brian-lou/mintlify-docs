Ajoutez ce qui suit à votre fichier `docs.json` pour envoyer des données d’analyse à PostHog.

Vous n’avez besoin d’inclure `apiHost` que si vous auto-hébergez PostHog. Par défaut, nous envoyons les événements à `https://app.posthog.com`.

<CodeGroup>

```json Options d’analyse dans docs.json
"integrations": {
    "posthog": {
        "apiKey": "YOUR_POSTHOG_PROJECT_API_KEY",
        "apiHost": "optional",
        "sessionRecording": true
    }
}
```

```json Exemple
"integrations": {
    "posthog": {
        "apiKey": "phc_TXdpocbYTeZVm5VJmMzHTMrCofBQu3e0kN7HGMNGTVW"
    }
}
```

</CodeGroup>

<div id="configuration-options">
  ### Options de configuration
</div>

<ParamField path="apiKey" type="string" required>
  La clé d’API de votre projet PostHog. Doit commencer par `phc_`.
</ParamField>

<ParamField path="apiHost" type="string">
  L’URL de votre instance PostHog. Nécessaire uniquement si vous hébergez PostHog vous‑même. La valeur par défaut est `https://app.posthog.com`.
</ParamField>

<ParamField path="sessionRecording" type="boolean" default="true">
  Active ou désactive l’enregistrement de session. Réglez ce paramètre sur `false` pour désactiver l’enregistrement de session tout en conservant l’analyse activée.
</ParamField>

<div id="session-recordings">
  ## Enregistrements de session
</div>

Les enregistrements de session sont activés par défaut lorsque vous configurez PostHog. Pour désactiver les enregistrements de session tout en gardant l’analyse de données activée, définissez `sessionRecording` sur `false` dans votre configuration.

```json Disable session recordings
"integrations": {
    "posthog": {
        "apiKey": "phc_your-key",
        "sessionRecording": false
    }
}
```

Vous devez ajouter l’URL de votre site de documentation aux « domaines autorisés pour les enregistrements » de PostHog avant de pouvoir recevoir des enregistrements de session. L’option permettant d’ajouter votre URL se trouve dans les paramètres du projet PostHog.
