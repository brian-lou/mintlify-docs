Ajoutez ce qui suit à votre fichier `docs.json` pour envoyer des données d’analyse à Amplitude.

<CodeGroup>

```json Options d’analyse dans docs.json
"integrations": {
    "amplitude": {
        "apiKey": "required"
    }
}
```

```json Exemple
"integrations": {
    "amplitude": {
        "apiKey": "76bb138bf3fbf58186XXX00000"
    }
}
```

</CodeGroup>
