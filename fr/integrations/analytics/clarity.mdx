Ajoutez ce qui suit à votre fichier `docs.json` pour envoyer des données d’analyse à Microsoft Clarity.

<CodeGroup>

```json Options d’analyse dans docs.json
"integrations": {
    "clarity": {
        "projectId": "required"
    }
}
```

```json Exemple
"integrations": {
    "clarity": {
        "projectId": "abc123xyz"
    }
}
```

</CodeGroup>

<div id="get-your-project-id">
  ## Récupérer votre ID de projet
</div>

1. Créez un [compte Clarity](https://clarity.microsoft.com/projects).
2. Cliquez sur **Get tracking code.**
3. Copiez votre ID de projet à partir du code de suivi.
