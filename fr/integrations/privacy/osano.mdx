Ajoutez la gestion du consentement aux cookies [Osano](https://www.osano.com/) à votre documentation à l&#39;aide d&#39;un [fichier JavaScript personnalisé](/fr/customize/custom-scripts#custom-javascript) dans votre dépôt.

<div id="setup">
  ## Configuration
</div>

Créez un fichier `osano.js` dans votre dépôt de documentation avec le contenu suivant :

<CodeGroup>
  ```js Format
  var script = document.createElement("script");
  script.src = "OSANO_SCRIPT_URL";
  document.head.appendChild(script);
  ```

  ```js Example
  var script = document.createElement("script");
  script.src = "https://cmp.osano.com/your-tenant-id/your-site-id/osano.js";
  document.head.appendChild(script);
  ```
</CodeGroup>

Remplacez `OSANO_SCRIPT_URL` par l’URL de votre script Osano. L’URL de votre script correspond à la valeur de l’attribut `src` dans l’extrait de code fourni par Osano. L’URL de votre script commence toujours par `https://cmp.osano.com/` et se termine par `/osano.js`.

<div id="troubleshooting">
  ## Dépannage
</div>

<Accordion title="Les pages ne se chargent pas en mode de conformité Strict">
  Si vos pages de documentation ne se chargent pas correctement lorsque vous utilisez le mode de conformité **Strict** d’Osano, vous devez ajouter le domaine de Mintlify à la liste d’autorisation afin de permettre le chargement des images et autres ressources.

  <Steps>
    <Step title="Accéder à Managed Rules">
      Dans votre tableau de bord Osano, allez dans **Scripts** → **Managed Rules**.
    </Step>

    <Step title="Ajouter le domaine Mintlify">
      Ajoutez `.mintlify.app/` en tant que règle gérée.

      <Frame>
        <img src="/images/integrations/osano-managed-rule.png" alt="Règle gérée Osano" />
      </Frame>

      <Info>
        Cela garantit que toutes les ressources servies par Mintlify (y compris les images, les feuilles de style et les autres ressources de documentation) sont considérées comme essentielles et s’affichent même lorsqu’Osano bloque du contenu tiers non catégorisé.
      </Info>
    </Step>
  </Steps>
</Accordion>
