Ajoutez l’élément suivant à votre fichier `docs.json` pour intégrer un widget [Front Chat](https://front.com).

<CodeGroup>

```json Integration options in docs.json
"integrations": {
    "frontchat": "CHAT_ID"
}
```

```json Example
"integrations": {
    "frontchat": "1365d046d7c023e9b030ce90d02d093a"
}
```

</CodeGroup>
