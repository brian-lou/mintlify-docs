Optimisez votre documentation à la fois pour les moteurs de recherche traditionnels et pour les moteurs de réponse basés sur l’IA comme ChatGPT, Perplexity et Google AI Overviews.

Le Generative Engine Optimization (GEO) consiste à faire en sorte que les systèmes d’IA citent votre contenu grâce à des contenus complets et à des informations structurées, tandis que le SEO traditionnel vise le classement dans les résultats de recherche.

<div id="geo-quickstart">
  ## Démarrage rapide de GEO
</div>

<div id="initial-setup">
  ### Configuration initiale
</div>

1. **Assurez-vous que votre documentation est bien indexée** dans les paramètres de votre `docs.json`
2. **Passez en revue les pages existantes** pour repérer les descriptions et titres manquants

<div id="content-improvements">
  ### Améliorer le contenu
</div>

1. **Ajoutez des tableaux comparatifs** aux pages pertinentes
2. **Passez en revue les titres** pour vérifier qu’ils répondent aux questions fréquentes
3. **Améliorez le maillage interne** entre les sujets connexes
4. **Testez avec des outils d’IA** pour en vérifier l’exactitude

<div id="geo-best-practices">
  ## Bonnes pratiques GEO
</div>

En général, une documentation bien rédigée et bien structurée aura de bonnes performances en GEO. Vous devez toutefois continuer à privilégier les besoins de vos utilisateurs dans votre rédaction, et si votre contenu y répond, vous serez déjà sur la bonne voie pour l’optimiser pour les outils d’IA. Créer un contenu réellement utile, plutôt que d’optimiser pour le principe d’optimiser, est valorisé à la fois par les moteurs de recherche traditionnels et par ceux fondés sur l’IA.

Concentrez-vous sur :

* Un contenu adapté aux besoins des utilisateurs plutôt qu’à la simple correspondance de mots-clés
* Des informations structurées et faciles à parcourir
* Des réponses directes aux questions

<div id="format-for-clarity">
  ### Mettez en forme pour plus de clarté
</div>

Ces pratiques de mise en forme aident les outils d’IA à analyser et à comprendre votre contenu :

* Ne sautez pas de niveaux de titre (H1 → H2 → H3)
* Utilisez des noms d’objet précis plutôt que « it » ou « this »
* Indiquez le langage de programmation de chaque bloc de code
* Donnez aux images un texte alternatif descriptif
* Ajoutez des liens vers des concepts connexes pour aider l’IA à comprendre leurs relations

<div id="answer-questions-directly">
  ### Répondez directement aux questions
</div>

Rédigez un contenu qui répond aux questions précises des utilisateurs :

* Commencez les sections par l&#39;idée essentielle à retenir
* Utilisez des titres explicites qui correspondent aux questions les plus fréquentes
* Décomposez les sujets complexes en étapes numérotées

<div id="mintlify-configuration">
  ## Configuration de Mintlify
</div>

Utilisez ces fonctionnalités pour améliorer votre GEO.

<div id="add-descriptive-page-metadata">
  ### Ajoutez des métadonnées descriptives à la page
</div>

Incluez des titres et des descriptions clairs dans votre frontmatter :

```mdx
---
title: "API authentication guide"
description: "Complete guide to implementing API authentication with code examples"
---
```


<div id="configure-global-indexing-settings">
  ### Configurez les paramètres globaux d’indexation
</div>

Ajoutez ceci à votre `docs.json` :

```json
{
  "seo": {
    "indexing": "all",
    "metatags": {
      "og:type": "website",
      "og:site_name": "Your docs"
    }
  }
}
```


<div id="llmstxt">
  ### LLMs.txt
</div>

Les fichiers LLMs.txt aident les systèmes d’IA à comprendre la structure de votre documentation, tout comme les sitemaps aident les moteurs de recherche. Mintlify génère automatiquement des fichiers LLMs.txt pour votre documentation. Aucune configuration n’est nécessaire.

<div id="testing-your-documentation">
  ## Tester votre documentation
</div>

Testez différents outils d’IA avec des questions sur votre produit et votre documentation afin de vérifier dans quelle mesure celle-ci est citée.

**Posez aux assistants IA des questions précises sur votre documentation :**

* « Comment configurer l’authentification avec cette API ? »
* « Expliquez-moi le processus d’installation étape par étape »

**Vérifiez que les outils fournissent :**

* Des exemples de code corrects
* Des instructions précises, étape par étape
