Optimisez votre documentation à la fois pour les moteurs de recherche traditionnels et pour les moteurs de réponse alimentés par l’IA comme ChatGPT, Perplexity et Google AI Overviews.

La Generative Engine Optimization (GEO) vise à obtenir des citations de la part des systèmes d’IA grâce à un contenu exhaustif et à des informations structurées, tandis que le SEO traditionnel vise le classement dans les résultats de recherche.

<div id="geo-quickstart">
  ## Démarrage rapide de GEO
</div>

<div id="initial-setup">
  ### Mise en place initiale
</div>

1. **Assurez-vous que votre documentation est indexée** dans vos paramètres `docs.json`
2. **Passez en revue les pages existantes** pour repérer les descriptions et les titres manquants

<div id="content-improvements">
  ### Améliorations de contenu
</div>

1. **Ajouter des tableaux de comparaison** aux pages pertinentes
2. **Passer les titres en revue** pour vérifier qu'ils répondent aux questions les plus fréquentes
3. **Améliorer le maillage interne** entre les sujets liés
4. **Tester avec des outils d'IA** pour vérifier la précision

<div id="geo-best-practices">
  ## Bonnes pratiques GEO
</div>

En général, une documentation bien rédigée et bien structurée présentera un GEO solide. Vous devez tout de même donner la priorité à vos utilisateurs lorsque vous rédigez : si votre contenu répond à leurs besoins, vous serez déjà bien avancé sur la voie de l’optimisation pour les outils d’IA. La création de contenu réellement utile, plutôt que la recherche d’optimisation pour elle‑même, est valorisée aussi bien par les moteurs de recherche traditionnels que par ceux basés sur l’IA.

Concentrez-vous sur :

- Un contenu aligné sur les besoins des utilisateurs plutôt que sur la simple correspondance de mots-clés
- Des informations structurées et faciles à parcourir
- Des réponses directes aux questions

<div id="format-for-clarity">
  ### Mettre en forme pour plus de clarté
</div>

Ces pratiques de mise en forme aident les outils d’IA à analyser et à comprendre votre contenu :

- Évitez de sauter des niveaux de titre (H1 → H2 → H3)
- Utilisez des noms d’objets précis au lieu de « it » ou « this »
- Indiquez le langage de programmation pour les blocs de code
- Donnez aux images un texte alternatif descriptif
- Ajoutez des liens vers des concepts connexes pour aider l’IA à comprendre les relations

<div id="answer-questions-directly">
  ### Répondre directement aux questions
</div>

Rédigez du contenu qui répond directement à des questions précises des utilisateurs :

- Commencez chaque section par l’idée principale à retenir
- Utilisez des titres explicites qui correspondent aux questions les plus fréquentes
- Divisez les sujets complexes en étapes numérotées

<div id="mintlify-configuration">
  ## Configuration de Mintlify
</div>

Utilisez ces fonctionnalités pour améliorer GEO.

<div id="add-descriptive-page-metadata">
  ### Ajouter des métadonnées descriptives de page
</div>

Ajoutez des titres et des descriptions clairs dans le frontmatter :

```mdx
---
title: "API authentication guide"
description: "Complete guide to implementing API authentication with code examples"
---
```


<div id="configure-global-indexing-settings">
  ### Configurer les paramètres globaux d’indexation
</div>

Ajoutez ceci à votre `docs.json` :

```json
{
  "seo": {
    "indexing": "all",
    "metatags": {
      "og:type": "website",
      "og:site_name": "Your docs"
    }
  }
}
```


<div id="llmstxt">
  ### LLMs.txt
</div>

Les fichiers LLMs.txt permettent aux systèmes d’IA de comprendre la structure de votre documentation, comme les sitemaps le font pour les moteurs de recherche. Mintlify génère automatiquement des fichiers LLMs.txt pour votre documentation. Aucune configuration n’est nécessaire.

<div id="testing-your-documentation">
  ## Tester votre documentation
</div>

Testez différents outils d’IA en leur posant des questions sur votre produit et votre documentation pour voir dans quelle mesure vos docs sont correctement citées.

**Posez des questions précises aux assistants IA à propos de vos docs&nbsp;:**

- «&nbsp;Comment configurer l’authentification avec cette API&nbsp;?&nbsp;»
- «&nbsp;Pouvez-vous me guider étape par étape dans le processus d’installation&nbsp;?&nbsp;»

**Vérifiez que les outils fournissent&nbsp;:**

- Des exemples de code corrects
- Des instructions détaillées, étape par étape
