<div id="what-you-will-build">
  ## Ce que vous allez créer
</div>

Un widget réutilisable qui intègre directement l’[assistant](/fr/ai/assistant) dans votre application. Le widget offre :

* Un bouton flottant qui ouvre un panneau de discussion au clic
* Des réponses diffusées en temps réel à partir des informations de votre documentation
* Un affichage des messages avec prise en charge de Markdown

Les utilisateurs peuvent utiliser le widget pour obtenir de l’aide sur votre produit sans quitter votre application.

<div id="prerequisites">
  ## Prérequis
</div>

* [Abonnement Mintlify Pro ou Enterprise](https://mintlify.com/pricing)
* Votre nom de domaine, qui apparaît à la fin de l’URL de votre tableau de bord. Par exemple, si l’URL de votre tableau de bord est `https://dashboard.mintlify.com/org-name/domain-name`, votre nom de domaine est `domain-name`
* Une [clé d’API Assistant](https://dashboard.mintlify.com/settings/organization/api-keys)
* Node.js v18 ou une version ultérieure et npm installés
* Des connaissances de base en React

<div id="get-your-assistant-api-key">
  ### Obtenir votre clé d&#39;API Assistant
</div>

1. Accédez à la page [API keys](https://dashboard.mintlify.com/settings/organization/api-keys) de votre tableau de bord.
2. Cliquez sur **Create Assistant API Key**.
3. Copiez la clé d&#39;API Assistant (elle commence par `mint_dsc_`) et conservez-la en lieu sûr.

<Note>
  La clé d&#39;API Assistant est un jeton public que vous pouvez utiliser dans du code front-end. Les appels effectués avec ce jeton sont décomptés de votre quota de messages et peuvent entraîner des dépassements.
</Note>

<div id="set-up-the-example">
  ## Configurer l&#39;exemple
</div>

Clonez le [dépôt d&#39;exemple](https://github.com/mintlify/assistant-embed-example) et personnalisez-le selon vos besoins.

<Steps>
  <Step title="Cloner le dépôt">
    ```bash
    git clone https://github.com/mintlify/assistant-embed-example.git
    cd assistant-embed-example
    ```
  </Step>

  <Step title="Choisir votre outil de développement">
    Le dépôt inclut des exemples Next.js et Vite. Choisissez l&#39;outil que vous préférez utiliser.

    <CodeGroup>
      ```bash title="Next.js"
      cd nextjs
      npm install
      ```

      ```bash title="Vite"
      cd vite
      npm install
      ```
    </CodeGroup>
  </Step>

  <Step title="Configurer votre projet">
    Ouvrez `src/config.js` et mettez-le à jour avec les informations de votre projet Mintlify.

    ```js src/config.js
    export const ASSISTANT_CONFIG = {
      domain: 'your-domain',
      docsURL: 'https://yourdocs.mintlify.app',
    };
    ```

    Remplacez :

    * `your-domain` par le domaine de votre projet Mintlify, indiqué à la fin de l&#39;URL de votre tableau de bord Mintlify.
    * `https://yourdocs.mintlify.app` par l&#39;URL réelle de votre documentation.
  </Step>

  <Step title="Ajouter votre jeton d'API">
    Créez un fichier `.env` à la racine du projet.

    ```bash .env
    VITE_MINTLIFY_TOKEN=mint_dsc_your_token_here
    ```

    Remplacez `mint_dsc_your_token_here` par votre clé d&#39;API de l&#39;assistant.
  </Step>

  <Step title="Démarrer le serveur de développement">
    ```bash
    npm run dev
    ```

    Ouvrez votre application dans un navigateur et cliquez sur le bouton **Ask** pour ouvrir le widget de l&#39;assistant.
  </Step>
</Steps>

<div id="source-citations">
  ### Citations de sources
</div>

Extraire et afficher les sources depuis les réponses de l’assistant :

```jsx
const extractSources = (parts) => {
  return parts
    ?.filter(p => p.type === 'tool-invocation' && p.toolInvocation?.toolName === 'search')
    .flatMap(p => p.toolInvocation?.result || [])
    .map(source => ({
      url: source.url || source.path,
      title: source.metadata?.title || source.path,
    })) || [];
};

// Dans le rendu de vos messages :
{messages.map((message) => {
  const sources = message.role === 'assistant' ? extractSources(message.parts) : [];
  return (
    <div key={message.id}>
      {/* contenu du message */}
      {sources.length > 0 && (
        <div className="mt-2 text-xs">
          <p className="font-semibold">Sources:</p>
          {sources.map((s, i) => (
            <a key={i} href={s.url} target="_blank" rel="noopener noreferrer" className="text-blue-600">
              {s.title}
            </a>
          ))}
        </div>
      )}
    </div>
  );
})}
```

<div id="track-conversation-thread-ids">
  ### Suivre les identifiants de fils de discussion
</div>

Enregistrez les identifiants de fil pour conserver l’historique des conversations d’une session à l’autre :

```jsx
import { useState, useEffect } from 'react';

export function AssistantWidget({ domain, docsURL }) {
  const [threadId, setThreadId] = useState(null);

  useEffect(() => {
    // Récupérer l'ID de fil sauvegardé depuis localStorage
    const saved = localStorage.getItem('assistant-thread-id');
    if (saved) {
      setThreadId(saved);
    }
  }, []);

  const { messages, input, handleInputChange, handleSubmit, isLoading } = useChat({
    api: `https://api.mintlify.com/discovery/v1/assistant/${domain}/message`,
    headers: {
      'Authorization': `Bearer ${import.meta.env.VITE_MINTLIFY_TOKEN}`,
    },
    body: {
      fp: 'anonymous',
      retrievalPageSize: 5,
      ...(threadId && { threadId }), // Inclure l'ID de fil s'il est disponible
    },
    streamProtocol: 'data',
    sendExtraMessageFields: true,
    fetch: async (url, options) => {
      const response = await fetch(url, options);
      const newThreadId = response.headers.get('x-thread-id');
      if (newThreadId) {
        setThreadId(newThreadId);
        localStorage.setItem('assistant-thread-id', newThreadId);
      }
      return response;
    },
  });

  // ... reste du composant
}
```

<div id="add-keyboard-shortcuts">
  ### Ajouter des raccourcis clavier
</div>

Autorisez les utilisateurs à ouvrir le widget et à soumettre des messages au moyen de raccourcis clavier :

```jsx
useEffect(() => {
  const handleKeyDown = (e) => {
    // Cmd/Ctrl + Shift + I pour afficher/masquer le widget
    if ((e.metaKey || e.ctrlKey) && e.shiftKey && e.key === 'I') {
      e.preventDefault();
      setIsOpen((prev) => !prev);
    }

    // Entrée (quand le widget est actif) pour envoyer
    if (e.key === 'Enter' && !e.shiftKey && document.activeElement.id === 'assistant-input') {
      e.preventDefault();
      handleSubmit();
    }
  };

  window.addEventListener('keydown', handleKeyDown);
  return () => window.removeEventListener('keydown', handleKeyDown);
}, [handleSubmit]);
```
