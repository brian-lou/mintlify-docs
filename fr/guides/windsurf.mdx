Transformez Windsurf en un expert de la documentation, capable de comprendre votre guide de style, vos composants et le contexte de votre projet, grâce aux règles de l&#39;espace de travail et aux mémoires.

<div id="use-windsurf-with-mintlify">
  ## Utiliser Windsurf avec Mintlify
</div>

L&#39;assistant IA Cascade de Windsurf peut être paramétré pour rédiger la documentation conformément à vos standards en utilisant les composants Mintlify. Les règles d&#39;espace de travail et les mémoires fournissent un contexte persistant sur votre projet, ce qui garantit des suggestions plus cohérentes de la part de Cascade.

* **Les règles d&#39;espace de travail** sont stockées dans votre dépôt de documentation et partagées avec votre équipe.
* **Les mémoires** fournissent un contexte individuel qui s&#39;enrichit au fil du temps.

Nous vous recommandons de définir des règles d&#39;espace de travail pour vos standards de documentation partagés. Vous pouvez développer des mémoires au fur et à mesure que vous travaillez, mais comme elles ne sont pas partagées, elles ne seront pas cohérentes d&#39;un membre de l&#39;équipe à l&#39;autre.

Créez des règles d&#39;espace de travail dans le répertoire `.windsurf/rules` de votre dépôt de documentation. Consultez la page [Memories &amp; Rules](https://docs.windsurf.com/windsurf/cascade/memories) dans la documentation de Windsurf pour plus d&#39;informations.

<div id="example-workspace-rule">
  ## Exemple de règle d’espace de travail
</div>

Cette règle fournit à Cascade un contexte sur les composants Mintlify et sur les bonnes pratiques générales de rédaction technique.

Vous pouvez utiliser cet exemple de règle tel quel ou le personnaliser pour votre documentation :

* **Normes rédactionnelles** : mettez à jour les directives de rédaction pour qu’elles correspondent à votre guide de style.
* **Modèles de composants** : ajoutez des composants spécifiques à votre projet ou modifiez les exemples existants.
* **Exemples de code** : remplacez les exemples génériques par de vrais appels et réponses d’API propres à votre produit.
* **Préférences de style et de ton** : ajustez la terminologie, le formatage et les autres règles.

Enregistrez votre règle dans un fichier `.md` dans le répertoire `.windsurf/rules` de votre dépôt de documentation.

````mdx
# Règle de rédaction technique Mintlify

## Contexte du projet

- Il s'agit d'un projet de documentation sur la plateforme Mintlify
- Nous utilisons des fichiers MDX avec un frontmatter YAML
- La navigation est configurée dans `docs.json`
- Nous suivons les meilleures pratiques de rédaction technique

## Normes de rédaction

- Utiliser la deuxième personne (« vous ») pour les instructions
- Écrire à la voix active et au présent
- Commencer les procédures par les prérequis
- Inclure les résultats attendus pour les étapes importantes
- Utiliser des titres descriptifs et riches en mots-clés
- Garder les phrases concises mais informatives

## Structure de page requise

Chaque page doit commencer par un frontmatter :

```yaml
---
title: "Clear, specific title"
description: "Concise description for SEO and navigation"
---
```

## Composants Mintlify

### docs.json

- Se référer au [schéma docs.json](https://mintlify.com/docs.json) lors de la construction du fichier docs.json et de la navigation du site

### Encadrés

- `<Note>` pour les informations complémentaires utiles
- `<Warning>` pour les mises en garde importantes et les changements majeurs
- `<Tip>` pour les bonnes pratiques et les conseils d'experts
- `<Info>` pour les informations contextuelles neutres
- `<Check>` pour les confirmations de succès

### Exemples de code

- Le cas échéant, inclure des exemples complets et exécutables
- Utiliser `<CodeGroup>` pour les exemples en plusieurs langages
- Spécifier les balises de langage sur tous les blocs de code
- Inclure des données réalistes, pas des espaces réservés
- Utiliser `<RequestExample>` et `<ResponseExample>` pour la documentation API

### Procédures

- Utiliser le composant `<Steps>` pour les instructions séquentielles
- Inclure des étapes de vérification avec les composants `<Check>` lorsque c'est pertinent
- Décomposer les procédures complexes en étapes plus petites

### Organisation du contenu

- Utiliser `<Tabs>` pour le contenu spécifique à une plateforme
- Utiliser `<Accordion>` pour la divulgation progressive
- Utiliser `<Card>` et `<CardGroup>` pour mettre en valeur le contenu
- Encadrer les images dans des composants `<Frame>` avec un texte alternatif descriptif

## Exigences de la documentation API

- Documenter tous les paramètres avec `<ParamField>`
- Afficher la structure de réponse avec `<ResponseField>`
- Inclure des exemples de succès et d'erreur
- Utiliser `<Expandable>` pour les propriétés d'objets imbriqués
- Toujours inclure des exemples d'authentification

## Normes de qualité

- Tester tous les exemples de code avant la publication
- Utiliser des chemins relatifs pour les liens internes
- Inclure un texte alternatif pour toutes les images
- Assurer une hiérarchie de titres correcte (commencer par h2)
- Vérifier les modèles existants pour la cohérence
````

<div id="working-with-cascade">
  ## Travailler avec Cascade
</div>

Une fois vos règles configurées, vous pouvez utiliser Cascade pour vous assister dans diverses tâches de documentation. Consultez [Cascade](https://docs.windsurf.com/windsurf/cascade) dans la documentation de Windsurf pour plus d’informations.

<div id="example-prompts">
  ### Exemples de prompts
</div>

**Rédaction de nouveaux contenus** :

```text wrap
Crée une nouvelle page expliquant comment s'authentifier avec notre API. Inclus des exemples de code en JavaScript, Python et cURL.
```

**Améliorer le contenu existant** :

```text wrap
Review this page and suggest improvements for clarity and component usage. Focus on making the steps easier to follow.
```

**Création d&#39;exemples de code** :

```text wrap
Génère un exemple de code complet illustrant la gestion des erreurs pour cet endpoint d'API. Utilise des données réalistes et inclus les réponses attendues.
```

**Assurer la cohérence** :

```text wrap
Check if this new page follows our documentation standards and suggest any needed changes.
```

<div id="enhance-with-mcp-server">
  ## Améliorer avec le serveur MCP
</div>

Connectez le serveur MCP de Mintlify à Windsurf pour permettre à Cascade de rechercher dans la documentation Mintlify tout en vous aidant à écrire. Lorsque vous connectez le serveur MCP, Cascade interroge la documentation Mintlify la plus récente pour fournir du contexte, afin que vous n&#39;ayez pas à quitter votre IDE pour la consulter.

Consultez [Model Context Protocol](/fr/ai/model-context-protocol#example%3A-connect-to-the-mintlify-mcp-server) pour les instructions complètes de configuration.
