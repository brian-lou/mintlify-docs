Transformez Windsurf en expert de la documentation capable de comprendre votre guide de style, vos composants et le contexte de votre projet grâce aux règles d’espace de travail et aux mémoires.

<div id="use-windsurf-with-mintlify">
  ## Utiliser Windsurf avec Mintlify
</div>

L’assistant IA Cascade de Windsurf peut être configuré pour rédiger de la documentation selon vos standards à l’aide des Composants Mintlify. Les règles d’espace de travail et les mémoires apportent un contexte persistant sur votre projet, ce qui garantit des suggestions plus cohérentes de la part de Cascade.

* Les **règles d’espace de travail** sont stockées dans votre dépôt de documentation et partagées avec votre équipe.
* Les **mémoires** fournissent un contexte individuel qui s’enrichit au fil du temps.

Nous vous recommandons de mettre en place des règles d’espace de travail pour définir des standards de documentation communs. Vous pouvez enrichir les mémoires au fil de votre travail, mais comme elles ne sont pas partagées, elles ne seront pas cohérentes d’un membre de l’équipe à l’autre.

Créez des règles d’espace de travail dans le répertoire `.windsurf/rules` de votre dépôt de documentation. Consultez [Memories &amp; Rules](https://docs.windsurf.com/windsurf/cascade/memories) dans la documentation Windsurf pour plus d’informations.

<div id="example-workspace-rule">
  ## Exemple de règle d’espace de travail
</div>

Cette règle fournit à Cascade des informations de contexte sur les composants Mintlify et les bonnes pratiques générales de rédaction technique.

Vous pouvez utiliser cet exemple de règle tel quel ou l’adapter à votre documentation :

* **Normes de rédaction** : mettez à jour les consignes linguistiques pour les aligner sur votre guide de style.
* **Modèles de composants** : ajoutez des composants propres au projet ou modifiez les exemples existants.
* **Exemples de code** : remplacez les exemples génériques par de vrais appels d’API et les réponses correspondantes pour votre produit.
* **Préférences de style et de ton** : ajustez la terminologie, la mise en forme et les autres règles.

Enregistrez votre règle en tant que fichier `.md` dans le répertoire `.windsurf/rules` de votre dépôt de documentation.

````mdx
# Règle de rédaction technique Mintlify

## Contexte du projet

- Il s'agit d'un projet de documentation sur la plateforme Mintlify
- Nous utilisons des fichiers MDX avec un Frontmatter YAML  
- La navigation est configurée dans `docs.json`
- Nous suivons les bonnes pratiques de rédaction technique

## Normes de rédaction

- Utilisez la deuxième personne (« vous ») pour les instructions
- Rédigez à la voix active et au présent
- Commencez les procédures par les prérequis
- Indiquez les résultats attendus pour les étapes importantes
- Utilisez des titres descriptifs et riches en mots-clés
- Rédigez des phrases concises mais informatives

## Structure de page requise

Chaque page doit commencer par un Frontmatter :

```yaml
---
title: "Titre clair et précis"
description: "Description concise pour le référencement et la navigation"
---
```

## Composants Mintlify

### docs.json

- Consultez le [schéma docs.json](https://mintlify.com/docs.json) lors de la création du fichier docs.json et de la navigation du site

### Encadrés

- `<Note>` pour les informations complémentaires utiles
- `<Warning>` pour les mises en garde importantes et les changements majeurs
- `<Tip>` pour les bonnes pratiques et les conseils d'experts  
- `<Info>` pour les informations contextuelles neutres
- `<Check>` pour les confirmations de succès

### Exemples de code

- Le cas échéant, incluez des exemples complets et exécutables
- Utilisez `<CodeGroup>` pour les exemples en plusieurs langages
- Spécifiez les balises de langage sur tous les blocs de code
- Utilisez des données réalistes plutôt que des valeurs fictives
- Utilisez `<RequestExample>` et `<ResponseExample>` pour la documentation API

### Procédures

- Utilisez le composant `<Steps>` pour les instructions séquentielles
- Ajoutez des étapes de vérification avec les composants `<Check>` lorsque c'est pertinent
- Décomposez les procédures complexes en étapes plus petites

### Organisation du contenu

- Utilisez `<Tabs>` pour le contenu spécifique à une plateforme
- Utilisez `<Accordion>` pour la divulgation progressive
- Utilisez `<Card>` et `<CardGroup>` pour mettre en valeur le contenu
- Encadrez les images dans des composants `<Frame>` avec un texte alternatif descriptif

## Exigences de la documentation API

- Documentez tous les paramètres avec `<ParamField>` 
- Affichez la structure des réponses avec `<ResponseField>`
- Incluez des exemples de succès et d'erreur
- Utilisez `<Expandable>` pour les propriétés d'objets imbriqués
- Incluez toujours des exemples d'authentification

## Normes de qualité

- Testez tous les exemples de code avant de les publier
- Utilisez des chemins relatifs pour les liens internes
- Ajoutez un texte alternatif pour toutes les images
- Respectez une hiérarchie de titres correcte (commencez par h2)
- Vérifiez les modèles existants pour garantir la cohérence
````

<div id="working-with-cascade">
  ## Utiliser Cascade
</div>

Une fois vos règles configurées, vous pouvez utiliser Cascade pour vous aider dans diverses tâches de documentation. Consultez la page [Cascade](https://docs.windsurf.com/windsurf/cascade) dans la documentation Windsurf pour en savoir plus.

<div id="example-prompts">
  ### Exemples de prompts
</div>

**Rédiger de nouveaux contenus**:

```text wrap
Create a new page explaining how to authenticate with our API. Include code examples in JavaScript, Python, and cURL.
```

**Améliorer le contenu existant** :

```text wrap
Review this page and suggest improvements for clarity and component usage. Focus on making the steps easier to follow.
```

**Créer des exemples de code** :

```text wrap
Generate a complete code example showing error handling for this API endpoint. Use realistic data and include expected responses.
```

**Maintenir la cohérence** :

```text wrap
Check if this new page follows our documentation standards and suggest any needed changes.
```

<div id="enhance-with-mcp-server">
  ## Améliorez avec le serveur MCP
</div>

Connectez le serveur MCP de Mintlify à Windsurf pour permettre à Cascade d&#39;effectuer des recherches dans la documentation Mintlify pendant qu&#39;il vous aide à rédiger. Une fois le serveur MCP connecté, Cascade recherche le contexte nécessaire dans la documentation Mintlify à jour, afin que vous n&#39;ayez pas à quitter votre IDE pour la consulter.

Consultez [Model Context Protocol](/fr/ai/model-context-protocol#example%3A-connect-to-the-mintlify-mcp-server) pour obtenir les instructions de configuration complètes.
