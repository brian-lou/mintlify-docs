title: "Guides"
description: "Apprenez à créer une documentation efficace à l’aide de bonnes pratiques et de flux de travail."
---

Les guides de cette section proposent des conseils pour créer une documentation qui aide vos utilisateurs à atteindre leurs objectifs. Que vous partiez de zéro ou cherchiez à améliorer une documentation existante, ces guides vous aident à planifier, rédiger et maintenir votre documentation.

Avant tout, tenez compte des besoins et des objectifs de vos utilisateurs. Documentez ce qui les aide à utiliser votre produit et à reprendre rapidement leurs tâches.

<div id="topics">
  ## Thèmes
</div>

<div id="ai-tools">
  ### Outils d’IA
</div>

Utilisez des outils d’IA pour accélérer votre flux de travail documentaire.

* [Automatiser les mises à jour de la documentation](/fr/guides/automate-agent) : Tutoriel expliquant comment configurer des mises à jour automatisées de la documentation à l’aide de l’agent.
* [Créer un assistant intégré à l’application](/fr/guides/assistant-embed) : Tutoriel expliquant comment ajouter un chatbot d’IA à une application React pour aider les utilisateurs à trouver des réponses dans votre documentation.
* [Claude Code](/fr/guides/claude-code), [Cursor](/fr/guides/cursor), [Windsurf](/fr/guides/windsurf) : Guides pour utiliser des assistants de programmation IA afin de maintenir votre documentation.
* [GEO](/fr/guides/geo) : Bonnes pratiques pour optimiser votre documentation pour les moteurs de recherche et les moteurs de réponse basés sur l’IA.

<div id="api-documentation">
  ### Documentation d’API
</div>

Créez une documentation d’API qui permet aux utilisateurs de tester votre API et d’apprendre à l’utiliser, tout en restant facile à maintenir.

* [Migrer de MDX vers OAS](/fr/guides/migrating-from-mdx): Faites passer votre documentation d’API de pages MDX individuelles à des pages générées automatiquement à partir d’une spécification OpenAPI.

<div id="best-practices">
  ### Bonnes pratiques
</div>

Faites de votre documentation une référence.

* [Accessibilité](/fr/guides/accessibility): Rendez votre documentation accessible au plus grand nombre.
* [Types de contenu](/fr/guides/content-types): Choisissez le bon format pour les tutoriels, les guides pratiques, les références et les explications.
* [Modèles de contenu](/fr/guides/content-templates): Copiez et adaptez des modèles pour chaque type de contenu.
* [Améliorer votre documentation](/fr/guides/improving-docs): Appuyez-vous sur les données et les retours pour améliorer continuellement votre documentation.
* [Internationalisation](/fr/guides/internationalization): Mettez en place une documentation multilingue pour toucher un public international.
* [Liens](/fr/guides/linking): Créez des liens internes, référencez des endpoints d&#39;API et préservez l&#39;intégrité des liens dans l&#39;ensemble de votre documentation.
* [Maintenance](/fr/guides/maintenance): Gardez votre documentation fiable et à jour.
* [Médias](/fr/guides/media): Ajoutez efficacement des images, des vidéos et d&#39;autres médias tout en limitant la charge de maintenance.
* [Organiser la navigation](/fr/guides/navigation): Concevez une architecture de l&#39;information adaptée à vos utilisateurs.
* [SEO](/fr/guides/seo): Optimisez votre documentation pour les moteurs de recherche.
* [Style et ton](/fr/guides/style-and-tone): Adoptez une voix cohérente.
* [Comprendre votre audience](/fr/guides/understand-your-audience): Étudiez les besoins et les objectifs de vos utilisateurs pour mieux y répondre.

<div id="git-workflows">
  ### Flux de travail Git
</div>

Comprenez Git pour tirer le meilleur parti de Mintlify et d’une approche de la documentation as code.

* [Concepts de Git](/fr/guides/git-concepts): Découvrez les bases de Git pour la documentation.
* [Branches](/fr/guides/branches): Utilisez les branches pour gérer les modifications de la documentation.

<div id="use-cases">
  ### Cas d’usage
</div>

Découvrez comment Mintlify s’adapte à différents cas d’usage et trouvez la solution qui vous convient.

* [Créer une documentation développeur](/fr/guides/developer-documentation) : Aidez vos utilisateurs à tirer le meilleur parti de votre produit ou de votre API grâce à une documentation développeur qui répond à leurs questions et leur permet de se concentrer à nouveau sur leurs tâches principales.
* [Créer une base de connaissances](/fr/guides/knowledge-base) : Mettez en place une base de connaissances interne pour centraliser les informations de votre équipe, améliorer la recherche et alléger la maintenance.
* [Créer un centre de support](/fr/guides/support-center) : Créez un centre de support en libre-service pour aider les clients à trouver des réponses, réduire le volume de tickets et améliorer leur satisfaction.
