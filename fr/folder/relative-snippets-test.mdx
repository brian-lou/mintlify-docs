<div id="relative-snippets-test-page">
  # Page de test des snippets relatifs
</div>

Il s’agit d’une page de test masquée permettant de valider la fonctionnalité d’import de snippets relatifs.

***

<div id="test-1-parent-directory-import-snippets">
  ## Test 1 : Import du répertoire parent (`../snippets/`)
</div>

Import depuis `/snippets/test-snippet-a.mdx` à l’aide de `../snippets/test-snippet-a.mdx` :

import TestSnippetA from "../snippets/test-snippet-a.mdx";

<TestSnippetA />

***


<div id="test-2-parent-directory-import-with-named-export">
  ## Test 2 : Import depuis le répertoire parent avec export nommé
</div>

Import de `testVariable` depuis `/snippets/test-snippet-b.mdx` :

import TestSnippetB from "../snippets/test-snippet-b.mdx";

<TestSnippetB />

**Valeur de la variable exportée :** {testVariable}

***


<div id="test-3-same-directory-import">
  ## Test 3 : Import depuis le même répertoire (`./`)
</div>

Import de `local-snippet.mdx` depuis le même dossier :

import LocalSnippet, { localMessage } from "./local-snippet.mdx";

<LocalSnippet />

**Valeur de la variable exportée :** {localMessage}

***


<div id="test-4-child-directory-import-nested">
  ## Test 4 : Import depuis le sous-répertoire (`./nested/`)
</div>

Import depuis `nested/deep-snippet.mdx` :

import DeepSnippet, { deepMessage } from "./nested/deep-snippet.mdx";

<DeepSnippet />

**Valeur de la variable exportée :** {deepMessage}

***


<div id="test-5-absolute-import-for-comparison">
  ## Test 5 : Import absolu (à titre de comparaison)
</div>

Import avec le chemin absolu `/snippets/icons-optional.mdx` :

import IconsOptional from "/snippets/fr/icons-optional.mdx";
