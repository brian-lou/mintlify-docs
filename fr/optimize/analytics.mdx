La page [analytics](https://dashboard.mintlify.com/products/analytics/v2/) de votre tableau de bord affiche des données sur les visiteurs de votre documentation, comment ils interagissent avec l’assistant, ce qu’ils recherchent et leurs commentaires. Utilisez ces informations pour identifier les pages les plus utiles pour vos utilisateurs et suivre l’évolution des tendances au fil du temps.

<div id="filter-by-ai-or-human-visitors">
  ## Filtrer par visiteurs IA ou humains
</div>

Filtrez vos données d’analyse par source de trafic pour analyser séparément le trafic des agents IA et celui des visiteurs humains.

<Frame>
  <img src="/images/analytics/traffic-filter-light.png" alt="Le filtre de source de trafic sur la page d’analyse." className="block dark:hidden" />

  <img src="/images/analytics/traffic-filter-dark.png" alt="Le filtre de source de trafic sur la page d’analyse." className="hidden dark:block" />
</Frame>

Lorsque vous modifiez la source de trafic, la page d’analyse n’affiche que les métriques pertinentes pour cette source de trafic. Pour le trafic IA, la page d’analyse affiche uniquement les visiteurs et les recherches MCP. Pour le trafic humain, la page d’analyse affiche les visiteurs, les informations de l’assistant, les recherches et les commentaires.

<div id="visitors">
  ## Visiteurs
</div>

L’onglet Visiteurs affiche un graphique en barres des visiteurs au fil du temps, une liste de pages populaires et les sources de trafic.

Consultez vos analyses de fréquentation pour :

* **Surveiller les tendances du trafic** : Observez les variations de trafic après des mises à jour ou l’ajout de nouveau contenu afin de comprendre l’impact de vos changements.
* **Identifier les pages populaires** : Servez-vous des pages populaires pour comprendre quels contenus sont les plus importants pour vos utilisateurs, afin de vous assurer qu’ils sont à jour et complets.
* **Suivre les sources de trafic** : Comprenez d’où viennent vos utilisateurs pour vous aider à optimiser votre contenu pour le bon public.

<div id="top-agents">
  ### Principaux agents
</div>

Lors de l’affichage du trafic IA, la section Principaux agents remplace les sites référents dans l’onglet Visiteurs. Principaux agents indique quels agents IA consultent votre documentation. Utilisez ces informations pour vous aider à déterminer :

* **Répartition des agents IA** : voyez quelles plateformes d’IA accèdent à votre documentation pour savoir quels outils vos utilisateurs privilégient.
* **Opportunités d’intégration** : identifiez les plateformes d’IA à prioriser pour l’optimisation et les tests.
* **Tendances du trafic IA** : surveillez quels agents sont les plus actifs et comment leur utilisation évolue au fil du temps.

<div id="assistant">
  ## Assistant
</div>

L’onglet Assistant affiche un histogramme de l’utilisation de l’assistant au fil du temps, une liste de catégories et l’historique des conversations.

Analysez les statistiques de votre assistant pour :

* **Surveiller l’utilisation de l’assistant** : Observez l’évolution de l’utilisation de l’assistant afin de comprendre comment vos utilisateurs interagissent avec votre contenu.
* **Identifier les catégories fréquentes** : Utilisez les catégories les plus fréquentes pour comprendre quels sujets sont les plus importants pour vos utilisateurs. Repérez les lacunes de couverture et donnez la priorité aux mises à jour de contenu.
* **Passer en revue l’historique des conversations** : Obtenez des données détaillées et fortement révélatrices de l’intention de vos utilisateurs quant à la façon dont ils perçoivent votre produit en examinant leur historique de conversations avec l’assistant. Découvrez quels termes ils utilisent, de quoi ils ont besoin et quelles tâches ils essaient d’accomplir.

<div id="categories">
  ### Catégories
</div>

L’onglet Catégories utilise des LLM pour regrouper automatiquement les conversations par sujet ou par thème.

<Frame>
  <img src="/images/analytics/categories-light.png" alt="L’onglet Catégories dans la page d’analytics de l’assistant." className="block dark:hidden" />

  <img src="/images/analytics/categories-dark.png" alt="L’onglet Catégories dans la page d’analytics de l’assistant." className="hidden dark:block" />
</Frame>

Utilisez les catégories pour identifier les sujets récurrents, les tendances dans les besoins et comportements des utilisateurs, ainsi que les domaines où la documentation pourrait devoir être étoffée ou clarifiée.

Cliquez sur une ligne de catégorie pour l’ouvrir et afficher les conversations associées regroupées sous cette catégorie.

Cliquez sur une conversation pour afficher l’intégralité du fil de discussion, y compris la question de l’utilisateur, la réponse de l’assistant et toutes les sources citées.

<div id="chat-history">
  ### Historique des conversations
</div>

L’onglet Historique des conversations affiche l’ensemble des échanges avec l’assistant par ordre chronologique.

Cliquez sur n’importe quel message pour afficher la conversation complète, y compris la question de l’utilisateur, la réponse de l’assistant et toutes les sources citées.

<div id="export-queries">
  ### Exporter des requêtes
</div>

Pour une analyse plus approfondie, exportez un fichier CSV contenant vos requêtes, réponses et sources. Utilisez vos outils préférés pour analyser les données exportées.

<Tip>
  Exemples de requêtes d&#39;analyse :

  * Dressez la liste de toutes les requêtes pour lesquelles aucune source n&#39;a été citée.
  * Repérez les tendances dans les interactions infructueuses.
</Tip>

<div id="searches">
  ## Recherches
</div>

<Note>
  La métrique « Recherches » est uniquement disponible lors de l&#39;affichage du trafic humain.
</Note>

L&#39;onglet Recherches affiche un histogramme des recherches au fil du temps ainsi que les requêtes spécifiques.

Analysez vos analyses de recherche pour :

* **Suivre les tendances de recherche** : observez l&#39;évolution des requêtes de recherche afin de comprendre comment vos utilisateurs trouvent votre contenu et sur quels sujets ils souhaitent obtenir des informations.
* **Identifier les requêtes fréquentes** : utilisez les requêtes fréquentes pour comprendre quels sujets sont les plus importants pour vos utilisateurs. Repérez les lacunes de couverture et hiérarchisez les mises à jour de contenu.
* **Identifier les faibles taux de clics** : les taux de clics (CTR) indiquent combien d&#39;utilisateurs cliquent sur un résultat de recherche après avoir saisi une requête. Un CTR faible peut indiquer que les résultats de recherche ne sont pas pertinents par rapport aux requêtes des utilisateurs. Si vous avez des termes de recherche fréquents avec un CTR faible, envisagez d&#39;améliorer la pertinence des résultats de recherche en ajoutant des mots-clés et en mettant à jour votre contenu.

<div id="mcp-searches">
  ## Recherches MCP
</div>

<Note>
  La métrique Recherches MCP est uniquement disponible lors de l’affichage du trafic lié à l’IA.
</Note>

L’onglet Recherches MCP affiche les interactions de recherche des agents IA via le Model Context Protocol (MCP). Cette métrique montre comment les agents IA interrogent et interagissent avec votre documentation.

Analysez vos statistiques de recherches MCP pour :

* **Surveiller l’activité de recherche des agents IA** : Suivez la fréquence à laquelle les agents IA recherchent dans votre documentation et identifiez les tendances des requêtes pilotées par l’IA.
* **Identifier les requêtes IA courantes** : Comprenez quelles informations les agents IA recherchent afin d’optimiser votre contenu pour les usages de l’IA.
* **Améliorer la découvrabilité pour l’IA** : Utilisez les requêtes de recherche MCP fréquentes pour repérer les lacunes de votre documentation pour lesquelles les agents IA peinent à trouver des réponses.
