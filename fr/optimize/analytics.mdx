La page [analytics](https://dashboard.mintlify.com/products/analytics/v2/) de votre tableau de bord affiche des données sur les visiteurs de votre documentation, la façon dont ils interagissent avec l’assistant, ce qu’ils recherchent et leurs retours. Utilisez ces informations pour identifier les pages les plus utiles à vos utilisateurs et suivre les tendances au fil du temps.

<div id="filter-by-ai-or-human-visitors">
  ## Filtrer par visiteurs IA ou humains
</div>

Filtrez vos données de statistique par source de trafic pour analyser séparément le trafic des agents IA et celui des visiteurs humains.

<Frame>
  <img src="/images/analytics/traffic-filter-light.png" alt="Le filtre de source de trafic sur la page de statistique." className="block dark:hidden" />

  <img src="/images/analytics/traffic-filter-dark.png" alt="Le filtre de source de trafic sur la page de statistique." className="hidden dark:block" />
</Frame>

Lorsque vous modifiez la source de trafic, la page de statistique n’affiche que les métriques pertinentes pour cette source. Pour le trafic IA, la page de statistique affiche uniquement les visiteurs et les recherches MCP. Pour le trafic humain, la page de statistique affiche les visiteurs, les insights de l’assistant, les recherches et les feedbacks.

<div id="visitors">
  ## Visiteurs
</div>

L’onglet Visiteurs affiche un histogramme de l’évolution du nombre de visiteurs, une liste des pages les plus consultées et les sources de trafic.

Consultez les statistiques de vos visiteurs pour :

* **Surveiller les tendances du trafic** : observez les variations du trafic après des mises à jour ou l’ajout de nouveau contenu afin de comprendre l’impact de vos changements.
* **Identifier les pages populaires** : utilisez les pages les plus consultées pour déterminer quel contenu est le plus important pour vos utilisateurs, afin de vous assurer qu’il est à jour et complet.
* **Suivre les sources de trafic** : identifiez la provenance de vos utilisateurs pour vous aider à optimiser votre contenu pour la bonne audience.

<div id="top-agents">
  ### Principaux agents
</div>

Lorsque vous affichez le trafic lié à l’IA, les principaux agents remplacent les référents dans l’onglet Visiteurs. Les principaux agents indiquent quels agents IA consultent votre documentation. Utilisez ces informations pour déterminer :

* **Répartition des agents IA** : voyez quelles plateformes d’IA accèdent à votre documentation afin de comprendre quels outils vos utilisateurs préfèrent.
* **Opportunités d’intégration** : identifiez les plateformes d’IA à privilégier pour l’optimisation et les tests.
* **Tendances du trafic IA** : surveillez quels agents sont les plus actifs et comment leur utilisation évolue au fil du temps.

<div id="assistant">
  ## Assistant
</div>

L’onglet Assistant affiche un graphique à barres de l’utilisation de l’assistant au fil du temps, une liste de catégories et l’historique des conversations.

Consultez les statistiques de votre assistant pour :

* **Surveiller l’utilisation de l’assistant** : observez l’évolution de son utilisation pour comprendre comment vos utilisateurs interagissent avec votre contenu.
* **Identifier les catégories fréquentes** : appuyez-vous sur les catégories les plus fréquentes pour comprendre quels sujets comptent le plus pour vos utilisateurs. Repérez les lacunes de couverture et priorisez les mises à jour de contenu.
* **Consulter l’historique des conversations** : obtenez des données détaillées sur les intentions de vos utilisateurs en consultant leur historique de conversation avec l’assistant. Voyez quels termes ils emploient, sur quoi ils ont besoin d’aide et quelles tâches ils cherchent à accomplir.

<div id="categories">
  ### Catégories
</div>

L’onglet des catégories utilise des LLM pour regrouper automatiquement les conversations par sujet ou par thème.

<Frame>
  <img src="/images/analytics/categories-light.png" alt="L’onglet des catégories sur la page de statistique de l’assistant." className="block dark:hidden" />

  <img src="/images/analytics/categories-dark.png" alt="L’onglet des catégories sur la page de statistique de l’assistant." className="hidden dark:block" />
</Frame>

Utilisez les catégories pour repérer les sujets récurrents, les tendances dans les besoins et le comportement des utilisateurs, ainsi que les domaines où la documentation pourrait devoir être enrichie ou clarifiée.

Cliquez sur une ligne de catégorie pour la déplier et afficher les conversations associées regroupées dans cette catégorie.

Cliquez sur une conversation pour afficher le fil de discussion complet, y compris la question de l’utilisateur, la réponse de l’assistant et les sources citées.

<div id="chat-history">
  ### Historique des conversations
</div>

L’onglet Historique des conversations affiche les conversations avec l’assistant dans l’ordre chronologique.

Cliquez sur n’importe quel message pour afficher l’intégralité du fil de discussion, y compris la question de l’utilisateur, la réponse de l’assistant et les sources citées.

<div id="export-queries">
  ### Exporter les requêtes
</div>

Pour une analyse plus approfondie, exportez un fichier CSV contenant vos requêtes, réponses et sources. Utilisez les outils de votre choix pour analyser les données exportées.

<Tip>
  Exemples de prompts d’analyse :

  * Répertoriez toutes les requêtes pour lesquelles aucune source n’a été citée.
  * Repérez des tendances dans les interactions infructueuses.
</Tip>

<div id="searches">
  ## Recherches
</div>

<Note>
  La métrique Recherches n’est disponible que lorsque vous affichez le trafic humain.
</Note>

L’onglet Recherches affiche un graphique en barres des recherches au fil du temps ainsi que des requêtes spécifiques.

Consultez vos statistiques de recherche pour :

* **Surveiller les tendances de recherche** : observez l’évolution des requêtes pour comprendre comment vos utilisateurs trouvent votre contenu et sur quels sujets ils recherchent des informations.
* **Identifier les requêtes fréquentes** : utilisez les requêtes fréquentes pour comprendre quels sujets importent le plus à vos utilisateurs. Repérez les lacunes dans la couverture et priorisez les mises à jour de contenu.
* **Identifier les faibles taux de clics** : les taux de clics (CTR) indiquent combien d’utilisateurs cliquent sur un résultat de recherche après avoir saisi une requête. Un faible CTR peut indiquer que les résultats de recherche ne sont pas pertinents pour les requêtes des utilisateurs. Si certains termes de recherche fréquents ont un faible CTR, envisagez d’améliorer la pertinence des résultats de recherche en ajoutant des mots-clés et en mettant votre contenu à jour.

<div id="mcp-searches">
  ## Recherches MCP
</div>

<Note>
  La métrique Recherches MCP est uniquement disponible lorsque vous consultez le trafic IA.
</Note>

L’onglet Recherches MCP affiche les interactions de recherche des agents IA via le Model Context Protocol (MCP). Cette métrique montre comment les agents IA interrogent votre documentation et interagissent avec elle.

Consultez les statistiques de vos recherches MCP pour :

* **Surveiller l’activité de recherche de l’IA** : suivez la fréquence à laquelle les agents IA effectuent des recherches dans votre documentation et repérez les tendances des requêtes générées par l’IA.
* **Identifier les requêtes IA les plus courantes** : comprenez quelles informations les agents IA recherchent afin d’optimiser votre contenu pour l’IA.
* **Améliorer la découvrabilité par l’IA** : utilisez les requêtes MCP les plus fréquentes pour repérer les lacunes de votre documentation, là où les agents IA peinent à trouver des réponses.

  ## Feedback

L’onglet Feedback affiche un graphique à barres montrant l’évolution des retours au fil du temps, ainsi que des retours spécifiques.
