  L’export au format PDF est disponible avec les [offres Enterprise](https://mintlify.com/pricing).
</Info>

Vous pouvez exporter l’ensemble de votre documentation dans un seul fichier PDF pour une consultation hors connexion. Le PDF contiendra tout le contenu de la documentation, y compris les images et les liens, ainsi qu’une table des matières interactive.


<div id="exporting-a-pdf">
  ## Exporter un PDF
</div>

1. Accédez à la page [General](https://dashboard.mintlify.com/settings/deployment/general) dans la section Project Settings de votre tableau de bord.
2. Sélectionnez le bouton **Export all content**.
3. Vous pouvez, si vous le souhaitez, personnaliser les options d’exportation :
    - **Page format** : Choisissez le format de page du PDF.
    - **Scale percentage** : Ajustez l’échelle du PDF.
    - **Include footer** : Ajoutez un pied de page indiquant le numéro de page et le nombre total de pages.
4. Sélectionnez **Export** pour lancer le processus d’exportation.
5. Une fois l’export terminé, vous recevrez un e-mail contenant un lien de téléchargement.
6. Cliquez sur le lien de téléchargement pour récupérer le fichier PDF.
