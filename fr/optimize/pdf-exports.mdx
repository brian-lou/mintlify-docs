Vous pouvez exporter votre documentation en un seul fichier PDF pour la consulter hors ligne. Le PDF contiendra l’intégralité du contenu de la documentation, y compris les images, les liens et une table des matières navigable.


<div id="exporting-a-pdf">
  ## Exporter un PDF
</div>

1. Accédez à la page [General](https://dashboard.mintlify.com/settings/deployment/general), dans la section Project Settings de votre tableau de bord.
2. Sélectionnez le bouton **Export all content**.
3. Vous pouvez également personnaliser les options d’exportation :
   * **Format de page** : choisissez le format du PDF.
   * **Pourcentage d’échelle** : ajustez l’échelle du PDF.
   * **Inclure le pied de page** : ajoutez un pied de page avec le numéro de page et le nombre total de pages.
4. Sélectionnez **Export** pour lancer l’exportation.
5. Une fois l’exportation terminée, vous recevrez un e-mail contenant un lien de téléchargement.
6. Cliquez sur le lien de téléchargement pour télécharger le fichier PDF.
