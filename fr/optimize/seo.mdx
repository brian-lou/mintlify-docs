Mintlify applique automatiquement de nombreuses bonnes pratiques SEO, notamment :

* Génération des balises méta
* Génération du plan de site et du fichier `robots.txt`
* Structure HTML sémantique
* Optimisation pour mobile

Vous pouvez personnaliser entièrement les balises méta de votre site en ajoutant le champ `metatags` à votre `docs.json` ou au frontmatter d’une page.

<div id="automatically-generated-meta-tags">
  ## Balises méta générées automatiquement
</div>

Mintlify génère les balises méta suivantes pour chaque page. Vous pouvez remplacer ces balises méta en les définissant dans votre `docs.json` ou dans le `Frontmatter` d&#39;une page.

**Métadonnées de base :**

* `charset: utf-8` - Encodage des caractères
* `og:type: website` - Type Open Graph
* `og:site_name` - Nom de votre site de documentation
* `twitter:card: summary_large_image` - Type de carte Twitter

**Métadonnées propres à la page :**

* `title` - Titre de la page, au format &quot;Titre de la page - Nom du site&quot;
* `og:title` - Titre Open Graph, identique au titre de la page
* `twitter:title` - Titre Twitter, identique au titre de la page
* `description` - Description de la page
* `og:description` - Description Open Graph, identique à la description de la page
* `twitter:description` - Description Twitter, identique à la description de la page

**URL et canonique :**

* `canonical` - Générée automatiquement à partir de l&#39;URL de la page
* `og:url` - Définie sur l&#39;URL canonique

**SEO et indexation :**

* `robots` - Générée à partir des métadonnées de la page
* `noindex` - Générée à partir des métadonnées de la page
* `keywords` - Générés à partir des métadonnées de la page

**Images :**

* `og:image` - Image Open Graph, `og:image:width` défini sur 1200 et `og:image:height` sur 630
* `twitter:image` - Image Twitter, `twitter:image:width` défini sur 1200 et `twitter:image:height` sur 630

**Métadonnées du navigateur et de l&#39;application :**

* `applicationName` - Nom de votre site de documentation
* `generator: Mintlify` - Identifie Mintlify comme générateur du site
* `apple-mobile-web-app-title` - Nom de l&#39;application sur l&#39;écran d&#39;accueil iOS
* `msapplication-TileColor` - Couleur de la tuile Windows
* Favicons et icônes issus de votre configuration
* Lien de référence vers le sitemap

Toutes les balises méta de `seo.metatags` dans votre `docs.json` sont également injectées automatiquement dans chaque page, par exemple `google-site-verification` pour la validation dans la Search Console.

<div id="global-meta-tags">
  ## Balises méta globales
</div>

Pour définir des balises méta par défaut pour toutes les pages, ajoutez le champ `metatags` à votre `docs.json`.

```json
"seo": {
    "metatags": {
        "og:image": "link to your default meta tag image"
    }
}
```

<div id="set-a-canonical-url">
  ### Définir une URL canonique
</div>

Si vous utilisez un domaine personnalisé, définissez la balise méta `canonical` pour vous assurer que les moteurs de recherche indexent le domaine de votre choix. Une URL canonique indique aux moteurs de recherche quelle version de votre documentation doit être considérée comme principale. Cela améliore le référencement lorsque votre documentation est accessible via plusieurs URL et évite les problèmes de contenu dupliqué.

```json
"seo": {
    "metatags": {
        "canonical": "https://www.your-custom-domain-here.com"
    }
}
```

<div id="page-specific-meta-tags">
  ## Balises méta spécifiques à une page
</div>

Pour définir des balises méta spécifiques à une page, ajoutez-les au Frontmatter de la page.

Les balises méta suivantes sont prises en charge au niveau de la page :

* `title` - Titre de la page
* `description` - La description de la page s’affiche sous le titre sur la page et dans certains résultats de moteurs de recherche
* `keywords` - Mots-clés séparés par des virgules
* `og:title` - Titre Open Graph pour le partage sur les réseaux sociaux
* `og:description` - Description Open Graph
* `og:image` - URL de l’image Open Graph
* `og:url` - URL Open Graph
* `og:type` - Type Open Graph, comme &quot;article&quot; ou &quot;website&quot;
* `og:image:width` - Largeur de l’image Open Graph
* `og:image:height` - Hauteur de l’image Open Graph
* `twitter:title` - Titre de la carte Twitter
* `twitter:description` - Description de la carte Twitter
* `twitter:image` - Image de la carte Twitter
* `twitter:card` - Type de carte Twitter, comme &quot;summary&quot; ou &quot;summary&#95;large&#95;image&quot;
* `twitter:site` - Identifiant du site sur Twitter
* `twitter:image:width` - Largeur de l’image Twitter
* `twitter:image:height` - Hauteur de l’image Twitter
* `noindex` - Définissez cette valeur sur `true` pour empêcher l’indexation par les moteurs de recherche
* `robots` - Valeur de la balise méta robots

```mdx
---
title: "Your example page title"
description: "Page-specific description"
"og:image": "link to your meta tag image"
"og:title": "Social media title"
keywords: ["keyword1", "keyword2"]
---
```

<Note>
  Les balises méta contenant des deux-points doivent être mises entre guillemets. Le champ `keywords` doit être formaté sous forme de tableau YAML.
</Note>

<div id="sitemaps-and-robotstxt-files">
  ## Sitemaps et fichiers robots.txt
</div>

Mintlify génère automatiquement un fichier `sitemap.xml` et un fichier `robots.txt`. Vous pouvez consulter votre sitemap en ajoutant `/sitemap.xml` à l’URL de votre site de documentation.

Par défaut, seules les pages incluses dans votre `docs.json` sont incluses. Pour inclure les liens masqués, ajoutez `seo.indexing` à votre `docs.json` :

```json
"seo": {
    "indexing": "all"
}
```

<div id="custom-sitemaps-and-robotstxt-files">
  ### Sitemaps et fichiers robots.txt personnalisés
</div>

Pour ajouter un fichier `sitemap.xml` ou `robots.txt` personnalisé, créez un fichier `sitemap.xml` ou `robots.txt` à la racine de votre projet. L’ajout d’un fichier personnalisé remplace le fichier du même nom généré automatiquement. Si vous supprimez un fichier personnalisé, le fichier par défaut sera à nouveau utilisé.

<div id="disabling-indexing">
  ## Désactiver l’indexation
</div>

Si vous souhaitez empêcher une page d’être indexée par les moteurs de recherche, vous pouvez ajouter ce qui suit dans le [frontmatter](/fr/organize/pages) de votre page :

```
---
noindex: true
---
```

Vous pouvez également appliquer `noindex` à toutes les pages de votre documentation en définissant le champ `metatags.robots` sur `"noindex"` dans votre `docs.json` :

```json
"seo": {
    "metatags": {
      "robots": "noindex"
    }
  }
```

<div id="seo-best-practices">
  ## Bonnes pratiques en matière de SEO
</div>

<AccordionGroup>
  <Accordion title="Rédiger des titres et descriptions explicites">
    * Utilisez des titres de page clairs et explicites (50-60 caractères)
    * Rédigez des descriptions convaincantes (150-160 caractères)
    * Incluez des mots-clés pertinents
    * Veillez à ce que chaque page ait un titre et une description uniques
  </Accordion>

  <Accordion title="Optimiser la structure de votre contenu">
    * Utilisez une hiérarchie de titres appropriée (H1 → H2 → H3)
    * Écrivez d&#39;abord pour les humains, puis pour les moteurs de recherche
    * Incluez des mots-clés pertinents dans les titres et le contenu
    * Gardez des URL courtes, explicites et organisées de manière hiérarchique
    * Structurez les contenus longs avec des sous-titres et des listes
  </Accordion>

  <Accordion title="Stratégie de liens internes">
    * Ajoutez des liens vers des pages connexes dans votre documentation
    * Utilisez un texte d&#39;ancrage explicite au lieu de « cliquez ici »
    * Créez des groupes thématiques en reliant des concepts connexes
    * Utilisez les fonctionnalités automatiques de référencement croisé
  </Accordion>

  <Accordion title="SEO des images">
    * Utilisez des noms de fichiers explicites pour les images
    * Incluez toujours un texte alternatif pour l&#39;accessibilité et le SEO
    * Optimisez la taille des fichiers image pour accélérer le chargement
    * Utilisez des images pertinentes qui enrichissent votre contenu
  </Accordion>
</AccordionGroup>
