<Note>
  Si le propriétaire de votre espace de travail Slack exige une approbation de l’administrateur pour installer des applications, demandez-lui d’approuver l’application Mintlify avant de la connecter.
</Note>

<div id="connect-your-slack-workspace">
  ## Connectez votre espace de travail Slack
</div>

1. Ouvrez le panneau de l’agent dans votre tableau de bord.
2. Cliquez sur le bouton **Settings**.
   <Frame>
     <img src="/images/agent/dashboard-settings-light.png" alt="Le bouton des paramètres en mode clair." className="block dark:hidden" />

     <img src="/images/agent/dashboard-settings-dark.png" alt="Le bouton des paramètres en mode sombre." className="hidden dark:block" />
   </Frame>
3. Dans la section d’intégration Slack, cliquez sur **Connect**.
4. Suivez les instructions de Slack pour ajouter l’application `mintlify` à votre espace de travail.
5. Suivez les instructions de Slack pour associer votre compte Mintlify à votre espace de travail Slack.
6. Vérifiez que l’agent fonctionne et répond lorsque vous :
   * lui envoyez un message direct.
   * le mentionnez avec `@mintlify` dans un canal.

<div id="use-the-agent-in-slack">
  ## Utiliser l’agent dans Slack
</div>

Une fois connecté, vous pouvez :

* Envoyer des messages directs à l’agent pour l’utiliser en privé afin de mettre à jour votre documentation.
* Mentionner `@mintlify` dans un canal pour l’utiliser publiquement et de manière collaborative.
* Poursuivre les conversations dans des fils de discussion pour affiner les modifications.
* Partager des liens de pull request avec l’agent pour mettre à jour la documentation associée.

<div id="update-documentation">
  ## Mettre à jour la documentation
</div>

Utilisez l’agent pour mettre à jour votre documentation dans le cadre d’une nouvelle demande ou d’un fil de discussion existant.

* **Nouvelle demande** : Envoyez un message direct à l’agent ou mentionnez `@mintlify` dans un canal avec des instructions sur ce que vous souhaitez mettre à jour.
* **Fil existant** : Répondez dans le fil de discussion et mentionnez `@mintlify` avec des instructions sur ce que vous souhaitez mettre à jour.

L’agent prend en compte le contexte de la demande ou du fil de discussion et ouvre une pull request dans votre dépôt connecté avec les modifications.

<div id="best-practices">
  ## Bonnes pratiques
</div>

* **Soyez précis** : indiquez à l’agent exactement ce que vous voulez documenter et où cela doit être ajouté.
* **Ajoutez du contexte** : si une conversation ne contient pas toutes les informations nécessaires, ajoutez des détails supplémentaires dans votre message à l’agent.
* **Vérifiez attentivement** : relisez toujours les pull requests créées par l’agent avant de les fusionner.
