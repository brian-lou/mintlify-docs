<div id="open-the-agent-panel">
  ## Ouvrir le panneau de l’agent
</div>

Sur ordinateur, le panneau de l’agent peut être redimensionné. Sur mobile, l’agent s’ouvre en plein écran.

Pour ouvrir le panneau de l’agent :

* Depuis n’importe quelle page de votre tableau de bord, utilisez le raccourci clavier <kbd>⌘</kbd>+<kbd>I</kbd> (macOS) ou <kbd>Ctrl</kbd>+<kbd>I</kbd> (Windows/Linux).
* Sur la page [Overview](https://dashboard.mintlify.com/), cliquez sur **Ask agent**.

<div id="agent-panel-views">
  ### Vues du panneau de l&#39;agent
</div>

  <img src="/images/agent/views-dark.png" alt="Vues du panneau de l'agent : nouvelle discussion, suggestions, historique et paramètres." className="hidden dark:block" />

* **Chat** : Cliquez sur l&#39;icône plus, <Icon icon="plus" />, pour démarrer une nouvelle discussion. Dans la vue de chat, envoyez des prompts à l&#39;agent pour mettre à jour votre documentation ou poser des questions à son sujet. L&#39;agent crée des pull requests à partir de vos instructions et affiche des liens pour consulter les pull requests ou ouvrir les modifications dans l&#39;éditeur web.
* **Suggestions** : Si cette option est activée, le panneau des suggestions affiche des suggestions de mise à jour de votre documentation en fonction des modifications apportées aux pull requests et des conversations des utilisateurs avec l&#39;assistant.
* **History** : Cliquez sur l&#39;icône d&#39;historique, <Icon icon="clock" />, pour parcourir les conversations précédentes et reprendre le travail sur d&#39;anciennes demandes. Cliquez sur n&#39;importe quelle conversation pour la charger dans la vue de chat.
* **Settings** : Cliquez sur l&#39;icône des paramètres, <Icon icon="settings" />, pour configurer les intégrations de l&#39;agent et l&#39;accès au dépôt.

<Tip>
  Démarrez une nouvelle conversation avec l&#39;agent pour chaque tâche. Cela permet de garder un contexte bien ciblé et de mieux associer les conversations à des projets précis.
</Tip>

<div id="connect-your-github-account">
  ## Connectez votre compte GitHub
</div>

Par défaut, l’agent ouvre des pull requests attribuées au bot Mintlify. Pour que les pull requests vous soient attribuées, connectez votre compte GitHub depuis la page [Mon profil](https://dashboard.mintlify.com/settings/account) du tableau de bord.

<div id="connect-repositories-as-context">
  ## Connecter des dépôts comme source de contexte
</div>

L’agent ne peut accéder qu’aux dépôts que vous connectez via la GitHub App Mintlify. Configurez les dépôts auxquels l’agent peut accéder dans **Settings** du panneau de l’agent ou dans les [paramètres de la GitHub App](https://github.com/apps/mintlify/installations/new).
