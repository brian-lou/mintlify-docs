<div id="open-the-agent-panel">
  ## Ouvrir le panneau de l’agent
</div>

Sur ordinateur, le panneau de l’agent est redimensionnable. Sur les appareils mobiles, l’agent s’ouvre en mode plein écran.

Pour ouvrir le panneau de l’agent :

- Depuis n’importe quelle page de votre tableau de bord, utilisez le raccourci clavier <kbd>⌘</kbd>+<kbd>I</kbd> (macOS) ou <kbd>Ctrl</kbd>+<kbd>I</kbd> (Windows/Linux).
- Sur la page [Overview](https://dashboard.mintlify.com/), cliquez sur **Ask agent**.

<div id="agent-panel-views">
  ### Vues du panneau de l’agent
</div>

<Frame>
  <img src="/images/agent/views-light.png" alt="Vues dans le panneau de l’agent : nouveau chat, suggestions, historique et paramètres." className="block dark:hidden" />
  <img src="/images/agent/views-dark.png" alt="Vues dans le panneau de l’agent : nouveau chat, suggestions, historique et paramètres." className="hidden dark:block" />
</Frame>

- **Chat** : cliquez sur l’icône plus, <Icon icon="plus" />, pour démarrer un nouveau chat. Dans la vue de chat, envoyez des requêtes à l’agent pour mettre à jour votre documentation ou poser des questions à son sujet. L’agent crée des pull requests en fonction de vos instructions et affiche des liens pour consulter les pull requests ou ouvrir les modifications dans l’éditeur web.
- **Suggestions** : si cette option est activée, le panneau Suggestions affiche des mises à jour proposées pour votre documentation, à partir des modifications des pull requests et des conversations des utilisateurs avec l’assistant.
- **Historique** : cliquez sur l’icône d’historique, <Icon icon="clock" />, pour parcourir les conversations passées et continuer à travailler sur des demandes précédentes. Cliquez sur n’importe quelle conversation pour la charger dans la vue de chat.
- **Paramètres** : cliquez sur l’icône des paramètres, <Icon icon="settings" />, pour configurer les intégrations de l’agent et l’accès au dépôt.

<Tip>
  Commencez une nouvelle conversation avec l’agent pour chaque tâche. Cela permet de conserver un contexte ciblé et vous aide à associer les conversations à des projets spécifiques.
</Tip>

<div id="connect-your-github-account">
  ## Connectez votre compte GitHub
</div>

Par défaut, l’agent ouvre des pull requests attribuées au bot Mintlify. Pour que les pull requests vous soient attribuées, connectez votre compte GitHub sur la page [My profile](https://dashboard.mintlify.com/settings/account) du tableau de bord.

<div id="connect-repositories-as-context">
  ## Connecter des dépôts en tant que contexte
</div>

L'agent ne peut accéder qu'aux dépôts que vous connectez via l'application GitHub Mintlify. Configurez les dépôts auxquels l'agent peut accéder dans le panneau **Settings** de l'agent ou dans les [paramètres de l'application GitHub](https://github.com/apps/mintlify/installations/new).
