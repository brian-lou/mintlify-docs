<Info>
  L’agent est disponible avec les [offres Pro et Enterprise](https://mintlify.com/pricing?ref=agent) pour toute personne ayant accès à votre tableau de bord.
</Info>

L’agent crée des pull requests proposant des modifications de votre documentation à partir de vos instructions. Lorsque vous envoyez une demande à l’agent, il s’appuie sur votre documentation, les dépôts connectés et les messages Slack pour créer un contenu conforme aux bonnes pratiques de rédaction technique et au schéma Mintlify.

<div id="what-you-can-do-with-the-agent">
  ## Ce que vous pouvez faire avec l’agent
</div>

Utilisez l’agent pour :

* Rédiger du nouveau contenu à partir de vos prompts, de liens vers des pull requests ou de discussions Slack.
* Mettre à jour des exemples de code obsolètes et des références d’API.
* Rechercher et mettre à jour le contenu existant.
* Répondre à des questions sur votre documentation et sur la rédaction technique.
* Préserver les informations issues de conversations Slack et de pull requests avant qu’elles ne se perdent.

<div id="where-you-can-use-the-agent">
  ## Où utiliser l’agent
</div>

* **Dashboard** : Depuis n’importe quelle page de votre tableau de bord, utilisez le raccourci clavier <kbd>⌘</kbd>+<kbd>I</kbd> (macOS) ou <kbd>Ctrl</kbd>+<kbd>I</kbd> (Windows/Linux) pour ouvrir le panneau de l’agent. Vous pouvez aussi cliquer sur **Ask agent** sur la page [Overview](https://dashboard.mintlify.com/).

  <Frame>
    <img src="/images/agent/dashboard-light.png" alt="Le panneau de l’agent ouvert dans le tableau de bord." className="block dark:hidden" />

    <img src="/images/agent/dashboard-dark.png" alt="Le panneau de l’agent ouvert dans le tableau de bord." className="hidden dark:block" />
  </Frame>
* **Slack** : Ajoutez l’agent à votre espace de travail Slack et mentionnez `@mintlify` pour lui envoyer une demande.
* **API** : Intégrez l’agent à des applications personnalisées à l’aide des [points de terminaison de l’agent](/fr/api/agent/create-agent-job).
