<Info>
  L’agent est disponible sur les [offres Pro et Enterprise](https://mintlify.com/pricing?ref=agent) pour toute personne ayant accès à votre tableau de bord.
</Info>

L’agent crée des pull requests proposant des modifications de votre documentation en fonction des instructions que vous lui donnez. Lorsque vous faites appel à l’agent, il s’appuie sur votre documentation, les dépôts connectés et les messages Slack pour créer du contenu qui suit les meilleures pratiques de rédaction technique et respecte le schéma Mintlify.

<div id="what-you-can-do-with-the-agent">
  ## Ce que vous pouvez faire avec l’agent
</div>

Utilisez l’agent pour :

* Rédiger de nouveaux contenus à partir de vos prompts, de liens vers des pull requests ou de fils de discussion Slack.
* Mettre à jour des exemples de code obsolètes et des références d’API.
* Rechercher et mettre à jour du contenu existant.
* Répondre aux questions sur votre documentation et sur des sujets de rédaction technique.
* Capturer les connaissances issues de conversations Slack et de pull requests avant qu’elles ne se perdent.

<div id="where-you-can-use-the-agent">
  ## Où vous pouvez utiliser l’agent
</div>

* **Tableau de bord** : Depuis n’importe quelle page de votre tableau de bord, utilisez le raccourci clavier <kbd>⌘</kbd>+<kbd>I</kbd> (macOS) ou <kbd>Ctrl</kbd>+<kbd>I</kbd> (Windows/Linux) pour ouvrir le panneau de l’agent. Vous pouvez aussi cliquer sur **Ask agent** sur la page [Overview](https://dashboard.mintlify.com/).
  <Frame>
    <img src="/images/agent/dashboard-light.png" alt="Le panneau de l’agent ouvert dans le tableau de bord." className="block dark:hidden" />

    <img src="/images/agent/dashboard-dark.png" alt="Le panneau de l’agent ouvert dans le tableau de bord." className="hidden dark:block" />
  </Frame>
* **Slack** : Ajoutez l’agent à votre espace de travail Slack et mentionnez `@mintlify` pour l’appeler.
* **API** : Intégrez l’agent dans vos applications personnalisées à l’aide des [endpoints de l’agent](/fr/api/agent/create-agent-job).
