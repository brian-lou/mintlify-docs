Vous pouvez autoriser l’agent à suggérer des mises à jour de la documentation à partir de deux sources.

* **Modifications des pull requests** : surveillez les dépôts Git sélectionnés pour repérer les modifications de code qui nécessitent des mises à jour de la documentation.
* **Conversations avec l’assistant** : analysez les questions que les utilisateurs posent à l’assistant sur votre site de documentation afin d’identifier les lacunes de contenu.

Lorsque l’agent identifie des mises à jour potentielles de la documentation, il crée une suggestion dans votre tableau de bord, accompagnée du contexte nécessaire à la création d’une pull request.

Utilisez les suggestions pour maintenir votre documentation à jour de manière proactive lorsque de nouvelles fonctionnalités sont mises en ligne ou pour répondre aux questions fréquentes des utilisateurs.

<div id="prerequisites">
  ## Prérequis
</div>

Avant d’utiliser les suggestions, vous devez installer l’[application GitHub de Mintlify](/fr/deploy/github) dans votre organisation. L’application doit avoir accès à votre dépôt de documentation ainsi qu’à au moins un autre dépôt dans lequel des modifications du code nécessitent des mises à jour de la documentation.

<div id="configure-suggestions">
  ## Configurer les suggestions
</div>

Configurez les dépôts que l’agent surveille et la façon dont vous recevez les notifications dans les paramètres de l’agent. La page des paramètres affiche toutes les organisations GitHub et tous les dépôts que l’agent surveille.

Pour accéder aux paramètres de l’agent :

1. Cliquez sur le bouton **Ask agent** dans votre tableau de bord pour ouvrir le panneau de l’agent.
2. Cliquez sur le bouton **Settings**.

<div id="monitor-repositories">
  ### Surveiller les dépôts
</div>

L’agent surveille toutes les pull requests fusionnées pour chaque dépôt que vous activez, quelle que soit la branche dans laquelle elles sont fusionnées. Une vérification GitHub appelée **Mintlify Autopilot** s’exécute sur les pull requests des dépôts surveillés afin de détecter d’éventuelles mises à jour de la documentation. Lorsque vous fusionnez une pull request qui nécessite des mises à jour de la documentation, l’agent crée une suggestion dans votre tableau de bord.

<Note>
  Lorsque vous activez la surveillance d’un dépôt pour la première fois, l’agent crée des suggestions pour les pull requests fusionnées au cours des sept derniers jours. Ce rattrapage n’a lieu que si aucune suggestion n’existe déjà pour ce dépôt. Il se peut que plusieurs suggestions apparaissent immédiatement après l’activation de la surveillance.
</Note>

Si vous désactivez la surveillance, l’agent cesse immédiatement de surveiller le dépôt. Toutes les suggestions existantes pour ce dépôt restent dans votre tableau de bord jusqu’à ce que vous les ignoriez.

  ### Informations issues des conversations
</div>

L&#39;agent analyse régulièrement les conversations avec l&#39;assistant et génère des suggestions lorsqu&#39;il détecte des séries de questions révélant une documentation manquante ou peu claire.

<div id="notifications">
  ### Notifications
</div>

Les suggestions de l’agent apparaissent toujours dans votre tableau de bord. Vous pouvez configurer les notifications pour recevoir des e-mails ou des messages directs sur Slack lorsque l’agent crée de nouvelles suggestions.

<Tip>
  Si vous ne recevez pas de notifications par e-mail pour les suggestions, vérifiez votre dossier de courrier indésirable et ajoutez l’adresse e-mail `notifications@mintlify.com` à votre liste d’expéditeurs autorisés.
</Tip>

<div id="review-suggestions">
  ## Examiner les suggestions
</div>

L’agent crée des suggestions dans votre tableau de bord. Chaque suggestion affiche la pull request ou le sujet de conversation avec l’assistant à l’origine de la suggestion, la date de création et les mises à jour de la documentation proposées.

Le bouton **Ask agent** dans votre tableau de bord affiche le nombre de suggestions en attente de votre examen.

<div id="create-pull-requests">
  ### Créer des pull requests
</div>

Ajoutez des suggestions au contexte afin que l’agent puisse créer des pull requests.

1. Cliquez sur le bouton **Ask agent** dans votre tableau de bord pour ouvrir le panneau de l’agent.
2. Cliquez sur **Add to chat**.
3. Envoyez le prompt à l’agent pour ouvrir une pull request.

<div id="dismiss-suggestions">
  ### Rejeter des suggestions
</div>

Si une suggestion ne nécessite pas de mise à jour de la documentation ou si vous avez déjà traité les modifications, rejetez-la pour la supprimer de votre tableau de bord.

1. Cliquez sur le bouton **Ask agent** dans votre tableau de bord pour ouvrir le panneau de l’agent.
2. Cliquez sur le bouton **Dismiss** à côté de toute suggestion que vous souhaitez rejeter.

La suggestion est immédiatement supprimée de votre tableau de bord. Vous ne pouvez pas récupérer les suggestions rejetées.
