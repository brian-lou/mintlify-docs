Vous pouvez autoriser l&#39;agent à suggérer des mises à jour de la documentation à partir de deux sources.

* **Modifications des pull requests** : Surveillez les dépôts Git sélectionnés pour les changements de code qui nécessitent des mises à jour de la documentation.
* **Conversations avec l’assistant** : Analysez les questions que les utilisateurs posent à l&#39;assistant sur votre site de documentation pour identifier les lacunes de contenu.

Lorsque l&#39;agent identifie des mises à jour potentielles de la documentation, il crée une suggestion dans votre tableau de bord avec le contexte nécessaire pour créer une pull request.

Utilisez les suggestions pour maintenir votre documentation à jour de manière proactive lors du déploiement de nouvelles fonctionnalités ou pour répondre aux questions fréquentes des utilisateurs.

<div id="prerequisites">
  ## Conditions préalables
</div>

Avant d&#39;utiliser les suggestions, vous devez installer l&#39;application [Mintlify GitHub](/fr/deploy/github) dans votre organisation. L&#39;application doit avoir accès à votre dépôt de documentation et à au moins un autre dépôt où les modifications de code nécessitent des mises à jour de la documentation.

<div id="configure-suggestions">
  ## Configurer les suggestions
</div>

Configurez les dépôts que l’agent surveille ainsi que la façon dont vous recevez les notifications dans les paramètres de l’agent. La page des paramètres affiche toutes les organisations et tous les dépôts GitHub suivis par l’agent.

Pour accéder aux paramètres de l’agent :

1. Cliquez sur le bouton **Ask agent** dans votre tableau de bord pour ouvrir le panneau de l’agent.
2. Cliquez sur le bouton **Settings**.

<div id="monitor-repositories">
  ### Surveiller les dépôts
</div>

L&#39;agent surveille toutes les pull requests fusionnées pour chaque dépôt que vous activez, quelle que soit la branche dans laquelle elles sont fusionnées. Une vérification GitHub nommée **Mintlify Autopilot** s&#39;exécute sur les pull requests dans les dépôts surveillés afin de les analyser et de détecter d&#39;éventuelles mises à jour de la documentation. Lorsque vous fusionnez une pull request qui nécessite des mises à jour de la documentation, l&#39;agent crée une suggestion dans votre tableau de bord.

<Note>
  Lorsque vous activez pour la première fois la surveillance d&#39;un dépôt, l&#39;agent crée des suggestions pour les pull requests fusionnées au cours des sept derniers jours. Ce rattrapage n&#39;a lieu que si aucune suggestion n&#39;existe déjà pour ce dépôt. Vous pouvez voir plusieurs suggestions apparaître immédiatement après avoir activé la surveillance.
</Note>

Si vous désactivez la surveillance, l&#39;agent arrête immédiatement de surveiller le dépôt. Toutes les suggestions existantes pour ce dépôt restent dans votre tableau de bord jusqu&#39;à ce que vous les rejetiez.

<div id="conversation-insights">
  ### Analyses des conversations
</div>

Si vous avez accès à l’agent et à l’assistant, l’agent crée des suggestions à partir des conversations que vos utilisateurs ont avec l’assistant.

L’agent analyse périodiquement les conversations de l’assistant et crée des suggestions lorsqu’il identifie des tendances dans les questions, indiquant que la documentation est manquante ou peu claire.

<div id="notifications">
  ### Notifications
</div>

Les suggestions de l’agent apparaissent toujours dans votre tableau de bord. Vous pouvez paramétrer les notifications pour recevoir des e-mails ou des messages privés Slack lorsque l’agent crée de nouvelles suggestions.

<Tip>
  Si vous ne recevez pas les notifications par e-mail pour les suggestions, vérifiez votre dossier de spam et ajoutez l’adresse e-mail `notifications@mintlify.com` à votre liste d’expéditeurs autorisés.
</Tip>

<div id="review-suggestions">
  ## Passer en revue les suggestions
</div>

L’agent crée des suggestions dans votre tableau de bord. Chaque suggestion affiche la pull request ou le sujet de conversation avec l’assistant qui a déclenché la suggestion, la date de création et les mises à jour de documentation proposées.

Le bouton **Ask agent** dans votre tableau de bord affiche le nombre de suggestions en attente de votre examen.

<div id="create-pull-requests">
  ### Créer des pull requests
</div>

Ajoutez des suggestions comme contexte pour permettre à l’agent de créer des pull requests.

1. Cliquez sur le bouton **Ask agent** dans votre tableau de bord pour ouvrir le panneau de l’agent.
2. Cliquez sur **Add to chat**.
3. Envoyez l’invite à l’agent pour ouvrir une pull request.

<div id="dismiss-suggestions">
  ### Ignorer des suggestions
</div>

Si une suggestion ne nécessite pas de mise à jour de la documentation ou si vous avez déjà pris en compte les modifications, ignorez-la pour la supprimer de votre tableau de bord.

1. Cliquez sur le bouton **Ask agent** dans votre tableau de bord pour ouvrir le panneau de l’agent.
2. Cliquez sur le bouton **Dismiss** à côté de toute suggestion que vous souhaitez ignorer.

La suggestion est immédiatement supprimée de votre tableau de bord. Vous ne pouvez pas récupérer les suggestions ignorées.
