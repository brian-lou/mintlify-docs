Considérez l'agent comme un assistant prêt à vous aider, qui a besoin de vos instructions pour accomplir ses tâches. Donnez-lui des consignes claires et le contexte nécessaire. Les tâches plus ciblées sont plus faciles à réaliser ; décomposez donc les projets complexes en étapes plus petites.

<div id="make-prompts-specific-and-outcome-focused">
  ## Rédigez des prompts spécifiques et orientés résultats
</div>

Des prompts génériques comme `@mintlify Improve the onboarding page` appliquent de bonnes pratiques générales, mais peuvent ne pas améliorer le contenu de la manière précise que vous aviez en tête.

Essayez plutôt des prompts basés sur les résultats que vous souhaitez que vos utilisateurs atteignent ou sur les problèmes qu’ils rencontrent.

- `@mintlify De nombreux utilisateurs ont du mal à installer le CLI. Passe en revue la page d’onboarding et mets à jour la documentation pour que les utilisateurs puissent installer le CLI facilement`
- `@mintlify Les développeurs obtiennent constamment des erreurs 401 en suivant notre guide d’authentification. Passe en revue la documentation d’authentification et ajoute des exemples plus clairs montrant comment formater correctement la clé d’API`

<div id="use-broad-prompts-for-maintenance-tasks">
  ## Utilisez des prompts généraux pour les tâches de maintenance
</div>

Utilisez des prompts généraux pour les tâches générales de maintenance de contenu, comme corriger les fautes de frappe, mettre à jour les redirections ou renommer une fonctionnalité dans l’ensemble de votre documentation.

- `@mintlify Find and fix all typos in the docs`
- `@mintlify change all unordered lists to use * instead of -`

<div id="specify-a-domain-name-for-multi-site-organizations">
  ## Spécifier un nom de domaine pour les organisations multisites
</div>

Si vous avez plusieurs sites de documentation, incluez le paramètre `subdomain` dans votre message pour indiquer sur quel ensemble de documentation l’agent doit travailler.

Pour trouver votre nom de domaine, consultez l’URL de votre tableau de bord pour l’ensemble de documentation que vous souhaitez mettre à jour. Le nom de domaine est la dernière partie après le nom de votre organisation. Par exemple, si l’URL de votre tableau de bord est `https://dashboard.mintlify.com/org-name/domain-name`, votre nom de domaine est `domain-name`.

Utilisez le format `@mintlify subdomain=<your-domain-name> <your-prompt>` pour indiquer à l’agent de travailler sur un ensemble de documentation spécifique.

- `@mintlify subdomain=public-docs Add a new section to the quickstart about inviting collaborators based on this PR` : indique à l’agent de mettre à jour le quickstart uniquement sur le site `public-docs`.
- `@mintlify subdomain=customer-docs Update the auth docs for the new authentication method` : indique à l’agent de mettre à jour la documentation d’authentification uniquement sur le site `customer-docs`.
