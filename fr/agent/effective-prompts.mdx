Considérez l’agent comme un assistant utile qui a besoin de vos consignes pour accomplir ses tâches. Donnez-lui des instructions claires et le contexte nécessaire. Les tâches bien ciblées sont plus faciles à mener à bien, alors décomposez les projets complexes en étapes plus petites.

<div id="make-prompts-specific-and-outcome-focused">
  ## Rendez les prompts précis et axés sur les résultats
</div>

Des prompts génériques comme `@mintlify Improve the onboarding page` appliquent des bonnes pratiques générales, mais n’améliorent pas forcément le contenu de la façon précise que vous aviez en tête.

Essayez des prompts basés sur les résultats que vous voulez aider vos utilisateurs à atteindre ou sur les problèmes qu’ils rencontrent.

* `@mintlify A lot of users have trouble installing the CLI. Review the onboarding page and update the docs so that users can easily install the CLI`
* `@mintlify Developers keep getting 401 errors when following our authentication guide. Review the auth docs and add clearer examples showing how to properly format the API key`

<div id="use-broad-prompts-for-maintenance-tasks">
  ## Utilisez des prompts larges pour les tâches de maintenance
</div>

Utilisez des prompts larges pour les tâches générales de maintenance du contenu, comme corriger les fautes de frappe, mettre à jour les redirections ou renommer une fonctionnalité dans toute votre documentation.

* `@mintlify Find and fix all typos in the docs`
* `@mintlify change all unordered lists to use * instead of -`

<div id="specify-a-domain-name-for-multi-site-organizations">
  ## Spécifier un nom de domaine pour les organisations multisites
</div>

Si vous avez plusieurs sites de documentation, incluez le paramètre `subdomain` dans votre message pour préciser sur quel ensemble de documentation l’agent doit intervenir.

Pour trouver votre nom de domaine, consultez l’URL du tableau de bord correspondant à l’ensemble de documentation que vous souhaitez mettre à jour. Le nom de domaine correspond à la dernière partie après le nom de votre organisation. Par exemple, si l’URL de votre tableau de bord est `https://dashboard.mintlify.com/org-name/domain-name`, votre nom de domaine est `domain-name`.

Utilisez le format `@mintlify subdomain=<your-domain-name> <your-prompt>` pour demander à l’agent d’intervenir sur un ensemble de documentation spécifique.

* `@mintlify subdomain=public-docs Add a new section to the quickstart about inviting collaborators based on this PR` : demande à l’agent de mettre à jour le quickstart uniquement sur le site `public-docs`.
* `@mintlify subdomain=customer-docs Update the auth docs for the new authentication method` : demande à l’agent de mettre à jour la documentation sur l’authentification uniquement sur le site `customer-docs`.
