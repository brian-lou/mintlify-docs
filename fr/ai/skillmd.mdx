Mintlify héberge un fichier `skill.md` à la racine de votre projet qui décrit ce que les agents IA peuvent faire avec votre produit.

La [spécification skill.md](https://agentskills.io/specification) est un format structuré, lisible par machine, qui rend explicites les capacités, les entrées requises et les contraintes des produits afin que les agents puissent les utiliser de manière plus fiable.

Mintlify génère automatiquement un fichier `skill.md` pour votre projet en analysant votre documentation avec une boucle pilotée par des agents. Ce fichier reste à jour au fur et à mesure que vous modifiez votre documentation et ne nécessite aucune maintenance. Vous pouvez également ajouter un fichier `skill.md` personnalisé à la racine de votre projet qui remplace celui généré automatiquement.

Affichez votre `skill.md` en ajoutant `/skill.md` à l&#39;URL de votre site de documentation. Mintlify ne génère des fichiers `skill.md` que pour les sites de documentation publics.

<PreviewButton href="https://mintlify.com/docs/skill.md">Ouvrir le skill.md de ce site.</PreviewButton>

<Tip>
  Les fichiers `llms.txt` et `skill.md` aident tous deux les agents à travailler avec votre documentation, mais ils remplissent des fonctions différentes.

  * `llms.txt` est un répertoire. Il répertorie toutes vos pages de documentation avec des descriptions pour que les agents sachent où trouver les informations.
  * `skill.md` est un résumé des capacités. Il indique aux agents ce qu&#39;ils peuvent accomplir avec votre produit, quelles entrées sont nécessaires et quelles contraintes s&#39;appliquent.
</Tip>

<div id="use-skillmd-files-with-agents">
  ## Utiliser les fichiers `skill.md` avec les agents
</div>

<Note>
  Si vous utilisez un [proxy inverse](/fr/deploy/reverse-proxy), configurez-le pour qu’il redirige les chemins `/skill.md` et `/.well-known/skills/*` (avec la mise en cache désactivée) vers votre sous-domaine Mintlify.
</Note>

Les agents peuvent traiter votre `skill.md` à l’aide de la [CLI Skills](https://www.npmjs.com/package/skills).

```bash
npx skills add https://your-docs-domain.com
```

Cela ajoute les capacités de votre produit au contexte de l’agent afin qu’il puisse agir au nom des utilisateurs.

<Tip>
  Expliquez à vos utilisateurs comment utiliser les fichiers `skill.md` avec des agents afin qu’ils obtiennent de meilleurs résultats avec votre produit dans leurs outils d’IA.
</Tip>

<div id="skillmd-structure">
  ## Structure de `skill.md`
</div>

Mintlify génère un fichier `skill.md` conformément à la [spécification agentskills.io](https://agentskills.io/specification). Le fichier généré contient :

* **Métadonnées** : nom du projet, description et version.
* **Capacités** : ce que les agents peuvent faire avec votre produit.
* **Compétences** : actions spécifiques classées par catégorie.
* **Workflows** : procédures étape par étape pour les tâches courantes.
* **Intégrations** : outils et services pris en charge.
* **Contexte** : informations générales sur l’architecture de votre produit.

<div id="custom-skillmd-files">
  ## Fichiers `skill.md` personnalisés
</div>

Ajoutez un fichier `skill.md` à la racine de votre projet pour remplacer le fichier généré automatiquement. Si vous supprimez un fichier personnalisé, Mintlify génère un nouveau fichier `skill.md`.

Rédigez un fichier personnalisé lorsque vous souhaitez exercer un contrôle précis sur la manière dont les agents interagissent avec votre produit. Suivez la [spécification agentskills.io](https://agentskills.io/specification) pour garantir la compatibilité avec les outils pour agents.

<div id="frontmatter-fields">
  ### Champs de frontmatter
</div>

Les fichiers `skill.md` personnalisés doivent commencer par du frontmatter YAML.

| Champ           | Type   | Description                                                                                                                                       |
| --------------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `name`          | string | Le nom de votre compétence.                                                                                                                       |
| `description`   | string | Une brève description de ce que fait votre compétence.                                                                                            |
| `license`       | string | La licence de votre compétence (par exemple, `MIT` ou `Apache-2.0`).                                                                              |
| `compatibility` | string | Exigences ou notes de compatibilité (par exemple, dépendances d’exécution).                                                                       |
| `metadata`      | object | Métadonnées supplémentaires sous forme de paires clé-valeur dont les valeurs sont des chaînes de caractères (par exemple, `author` ou `version`). |
| `allowed-tools` | string | Liste, séparée par des espaces, des outils préalablement approuvés que la compétence peut utiliser (expérimental).                                |

```md Example frontmatter
---
name: mintlify
description: Build and maintain documentation sites with Mintlify. Use when creating docs pages, configuring navigation, adding components, or setting up API references.
license: MIT
compatibility: Requires Node.js for CLI. Works with any Git-based workflow.
metadata:
  author: mintlify
  version: "1.0"
---
```
