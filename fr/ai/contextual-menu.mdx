Le menu contextuel permet d’accéder rapidement à du contenu optimisé pour l’IA ainsi qu’à des intégrations directes avec des outils d’IA populaires. Lorsque les utilisateurs ouvrent le menu contextuel sur n’importe quelle page, ils peuvent copier du contenu pour l’utiliser comme contexte dans des outils d’IA ou ouvrir des conversations dans ChatGPT, Claude, Perplexity ou l’outil personnalisé de leur choix, avec votre documentation déjà chargée comme contexte.


<div id="menu-options">
  ## Options du menu
</div>

Le menu contextuel propose plusieurs options prédéfinies que vous pouvez activer en ajoutant leur identifiant à votre configuration.

| Option                              | Identifiant  | Description                                                                                      |
| :---------------------------------- | :----------- | :----------------------------------------------------------------------------------------------- |
| **Copier la page**                  | `copy`       | Copie la page actuelle au format Markdown pour la coller comme contexte dans des outils d&#39;IA |
| **Afficher en Markdown**            | `view`       | Ouvre la page actuelle au format Markdown                                                        |
| **Ouvrir dans ChatGPT**             | `chatgpt`    | Crée une conversation dans ChatGPT avec la page actuelle comme contexte                          |
| **Ouvrir dans Claude**              | `claude`     | Crée une conversation dans Claude avec la page actuelle comme contexte                           |
| **Ouvrir dans Perplexity**          | `perplexity` | Crée une conversation dans Perplexity avec la page actuelle comme contexte                       |
| **Ouvrir dans Grok**                | `grok`       | Crée une conversation dans Grok avec la page actuelle comme contexte                             |
| **Copier l&#39;URL du serveur MCP** | `mcp`        | Copie l&#39;URL de votre serveur MCP dans le presse-papiers                                      |
| **Se connecter à Cursor**           | `cursor`     | Installe votre serveur MCP hébergé dans Cursor                                                   |
| **Se connecter à VS Code**          | `vscode`     | Installe votre serveur MCP hébergé dans VS Code                                                  |
| **Options personnalisées**          | Object       | Ajoutez des options personnalisées au menu contextuel                                            |

<div id="enabling-the-contextual-menu">
  ## Activer le menu contextuel
</div>

Ajoutez le champ `contextual` à votre fichier `docs.json`, puis précisez les options à inclure.

```json
{
 "contextual": {
   "options": [
     "copy",
     "view",
     "chatgpt",
     "claude",
     "perplexity",
     "grok",
     "mcp",
     "cursor",
     "vscode"
   ]
 }
}
```


<div id="adding-custom-options">
  ## Ajouter des options personnalisées
</div>

Créez des options personnalisées dans le menu contextuel en ajoutant un objet au tableau `options`. Chaque option personnalisée requiert les propriétés suivantes :

<ResponseField name="title" type="string" required>
  Le titre de l’option.
</ResponseField>

<ResponseField name="description" type="string" required>
  La description de l’option. Elle s’affiche sous le titre lorsque le menu contextuel est ouvert.
</ResponseField>

<IconsRequired />

<ResponseField name="href" type="string | object" required>
  Le `href` de l’option. Utilisez une chaîne pour les liens simples ou un objet pour les liens dynamiques avec des paramètres de requête.

  <Expandable title="objet href">
    <ResponseField name="base" type="string" required>
      L’URL de base de l’option.
    </ResponseField>

    <ResponseField name="query" type="object" required>
      Les paramètres de requête de l’option.

      <Expandable title="objet query">
        <ResponseField name="key" type="string" required>
          La clé du paramètre de requête.
        </ResponseField>

        <ResponseField name="value" type="string" required>
          La valeur du paramètre de requête. Les espaces réservés suivants seront remplacés par les valeurs correspondantes :

          * Utilisez `$page` pour insérer le contenu de la page actuelle au format Markdown.
          * Utilisez `$path` pour insérer le chemin de la page actuelle.
          * Utilisez `$mcp` pour insérer l’URL du serveur MCP hébergé.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

Exemple d’option personnalisée :

```json {9-14} wrap
{
    "contextual": {
        "options": [
            "copy",
            "view",
            "chatgpt",
            "claude",
            "perplexity",
            {
                "title": "Demander une fonctionnalité",
                "description": "Rejoignez la discussion sur GitHub pour demander une nouvelle fonctionnalité",
                "icon": "plus",
                "href": "https://github.com/orgs/mintlify/discussions/categories/feature-requests"
            }
        ]
    }
}
```
