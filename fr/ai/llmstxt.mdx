Le [fichier llms.txt](https://llmstxt.org) est un standard du secteur qui aide les LLM à indexer le contenu plus efficacement, de la même manière qu&#39;un sitemap aide les moteurs de recherche. Les outils d&#39;IA peuvent utiliser ce fichier pour comprendre la structure de votre documentation et trouver le contenu pertinent pour les requêtes des utilisateurs.

Mintlify héberge automatiquement un fichier `llms.txt` à la racine de votre projet qui répertorie toutes les pages disponibles dans votre documentation. Ce fichier est toujours à jour et ne nécessite aucune maintenance. Vous pouvez, si vous le souhaitez, ajouter un fichier `llms.txt` personnalisé à la racine de votre projet.

<Note>
  Si votre site nécessite une authentification pour accéder à votre documentation, vos fichiers `llms.txt` et `llms-full.txt` ne sont pas accessibles aux LLM et aux outils d&#39;IA. Les LLM et les outils d&#39;IA ne peuvent indexer que du contenu accessible publiquement.
</Note>

Consultez votre `llms.txt` en ajoutant `/llms.txt` à l&#39;URL de votre site de documentation.

<div id="llmstxt-structure">
  ## structure de llms.txt
</div>

Un fichier `llms.txt` est un simple fichier Markdown qui contient :

* **Le titre du site** comme titre H1.
* **Des sections de contenu structurées** avec des liens et une description de chaque page de votre documentation.

Les pages sont répertoriées par ordre alphabétique, dans l’ordre où elles apparaissent dans votre dépôt, en commençant par le répertoire racine.

La description de chaque page provient du champ `description` dans son frontmatter. Les pages sans champ `description` apparaissent dans le fichier `llms.txt` sans description.

```mdx Example llms.txt
# Site title

## Docs

- [API](https://example.com/docs/api): Endpoint list and usage
- [Install](https://example.com/docs/install): Setup steps
- [Getting started](https://example.com/docs/start): Intro guide
```

Cette approche structurée permet aux LLM de traiter efficacement votre documentation à un niveau global et d’identifier le contenu pertinent pour les requêtes des utilisateurs, ce qui améliore la précision et la rapidité des recherches de documentation assistées par l’IA.


<div id="llms-fulltxt">
  ## llms-full.txt
</div>

Le fichier `llms-full.txt` regroupe l’intégralité de votre site de documentation dans un seul fichier servant de contexte pour les outils d’IA, et il est indexé par le trafic LLM.

Mintlify héberge automatiquement un fichier `llms-full.txt` à la racine de votre projet. Affichez votre `llms-full.txt` en ajoutant `/llms-full.txt` à l’URL de votre site de documentation.

<div id="custom-files">
  ## Fichiers personnalisés
</div>

Pour ajouter un fichier `llms.txt` ou `llms-full.txt` personnalisé, créez un fichier `llms.txt` ou `llms-full.txt` à la racine de votre projet. L’ajout d’un fichier personnalisé remplacera le fichier généré automatiquement portant le même nom. Si vous supprimez un fichier personnalisé, le fichier par défaut sera à nouveau utilisé.

Votre fichier `llms.txt` ou `llms-full.txt` personnalisé doit contenir le titre du site sous forme de titre H1. Tout autre contenu est facultatif. Consultez la section [Format](https://llmstxt.org/#format) de la spécification `llms.txt` pour plus d’informations sur les sections optionnelles et les bonnes pratiques.
