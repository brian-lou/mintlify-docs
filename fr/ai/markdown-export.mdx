Markdown fournit un texte structuré que les outils d’IA peuvent traiter plus efficacement que le HTML, ce qui entraîne une meilleure précision des réponses, des temps de traitement plus rapides et une utilisation réduite des jetons.

Mintlify génère automatiquement des versions Markdown des pages, optimisées pour les outils d’IA et les intégrations externes.


<div id="md-url-extension">
  ## Extension d'URL .md
</div>

Ajoutez `.md` à l'URL de n'importe quelle page pour en afficher la version au format Markdown.

<PreviewButton href="https://mintlify.com/docs/ai/markdown-export.md">Ouvrir cette page au format Markdown</PreviewButton>

<div id="keyboard-shortcut">
  ## Raccourci clavier
</div>

Appuyez sur <kbd>Command</kbd> + <kbd>C</kbd> (<kbd>Ctrl</kbd> + <kbd>C</kbd> sur Windows) pour copier la page au format Markdown dans le presse-papiers.
