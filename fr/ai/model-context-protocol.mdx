<div id="about-mcp-servers">
  ## À propos des serveurs MCP
</div>

Le Model Context Protocol (MCP) est un protocole ouvert qui crée des connexions standardisées entre les applications d’IA et des services externes, comme la documentation. Mintlify génère un serveur MCP à partir de votre documentation, préparant ainsi votre contenu pour l’écosystème IA au sens large, au sein duquel n’importe quel client MCP, tel que Claude, Cursor, Goose, ChatGPT et d’autres, peut se connecter à votre documentation.

Votre serveur MCP expose un outil de recherche permettant aux applications d’IA d’interroger votre documentation. Vos utilisateurs doivent connecter votre serveur MCP à leurs outils.

<div id="how-mcp-servers-work">
  ### Fonctionnement des serveurs MCP
</div>

Lorsqu&#39;une application d&#39;IA se connecte à votre serveur MCP de documentation, elle peut rechercher directement dans votre documentation au lieu d&#39;effectuer une recherche web générique en réponse au message d&#39;un utilisateur. Votre serveur MCP donne accès à tout le contenu indexé de votre site de documentation.

* L&#39;application d&#39;IA peut rechercher de manière proactive dans votre documentation pendant qu&#39;elle génère une réponse, et pas seulement lorsqu&#39;on le lui demande explicitement.
* L&#39;application d&#39;IA décide quand utiliser l&#39;outil de recherche en fonction du contexte de la conversation et de la pertinence de votre documentation.
* Chaque recherche (appel d&#39;outil) a lieu pendant le processus de génération, de sorte que l&#39;application d&#39;IA interroge des informations à jour provenant de votre documentation pour générer sa réponse.

<Tip>
  Certains outils d&#39;IA comme Claude prennent en charge à la fois MCP et Skills. MCP donne à l&#39;IA accès au contenu de votre documentation, tandis que les Skills définissent la manière dont l&#39;IA doit utiliser ce contenu efficacement. Ils sont complémentaires : MCP fournit les données et les Skills fournissent les instructions.
</Tip>

<div id="search-filtering-parameters">
  ### Paramètres de filtrage de la recherche
</div>

L’outil de recherche MCP prend en charge des paramètres de filtrage optionnels que les applications d’IA peuvent utiliser pour affiner les résultats de recherche.

* **`version`** : filtre les résultats sur une version spécifique de la documentation. Par exemple, `'v0.7'`. Ne renvoie que le contenu marqué avec la version spécifiée ou le contenu disponible pour toutes les versions.
* **`language`** : filtre les résultats sur un code de langue spécifique. Par exemple, `'en'`, `'zh'` ou `'es'`. Ne renvoie que le contenu dans la langue spécifiée ou le contenu disponible dans toutes les langues.
* **`apiReferenceOnly`** : lorsqu’il est défini sur `true`, ne renvoie que les pages de documentation de référence d’API.
* **`codeOnly`** : lorsqu’il est défini sur `true`, ne renvoie que des extraits de code et des exemples.

Les applications d’IA déterminent quand appliquer ces filtres en fonction du contexte de la requête de l’utilisateur. Par exemple, si un utilisateur pose une question sur une version spécifique d’une API ou demande des exemples de code, l’application d’IA peut appliquer automatiquement les filtres appropriés afin de fournir des résultats plus pertinents.

<div id="mcp-compared-to-web-search">
  ### MCP comparé à la recherche sur le Web
</div>

Les outils d’IA peuvent rechercher sur le Web, mais MCP offre des avantages spécifiques pour la documentation.

* **Accès direct à la source** : La recherche sur le Web dépend de ce que les moteurs de recherche ont indexé, ce qui peut être obsolète ou incomplet. MCP recherche directement dans votre documentation indexée actuelle.
* **Flux de travail intégré** : MCP permet à l’IA d’effectuer des recherches pendant la génération de la réponse plutôt que de lancer une recherche sur le Web distincte.
* **Aucun bruit de recherche** : Le référencement (SEO) et les algorithmes de classement influencent les résultats de recherche sur le Web. MCP accède directement au contenu de votre documentation.

<div id="access-your-mcp-server">
  ## Accéder à votre serveur MCP
</div>

<Note>
  Les serveurs MCP sont uniquement disponibles pour la documentation publique. La documentation protégée par une authentification des utilisateurs finaux ne peut pas générer de serveur MCP.
</Note>

Mintlify génère automatiquement un serveur MCP pour votre documentation et l’héberge à l’URL de votre documentation avec le chemin `/mcp`. Par exemple, le serveur MCP de Mintlify est disponible à l’adresse `https://mintlify.com/docs/mcp`.

Affichez et copiez l’URL de votre serveur MCP sur la [page du serveur MCP](https://dashboard.mintlify.com/products/mcp) dans votre tableau de bord.

<div id="content-filtering-and-indexing">
  ## Filtrage et indexation du contenu
</div>

Votre serveur MCP effectue des recherches dans le contenu que Mintlify indexe à partir de votre dépôt de documentation. Le traitement des fichiers et l’indexation de la recherche déterminent le contenu accessible via votre serveur MCP.

<div id="file-processing-with-mintignore">
  ### Traitement des fichiers avec `.mintignore`
</div>

Si des fichiers correspondent aux modèles de correspondance [.mintignore](/fr/organize/mintignore), Mintlify ne les traite ni ne les indexe. Ces fichiers ne sont pas disponibles via votre serveur MCP.

<div id="search-indexing-with-docsjson">
  ### Indexation de la recherche avec `docs.json`
</div>

Par défaut, Mintlify n’indexe pour la recherche via votre serveur MCP que les pages incluses dans la navigation définie dans votre `docs.json`.

Mintlify exclut les [pages cachées](/fr/organize/hidden-pages) (pages qui ne figurent pas dans votre navigation) de l’index de recherche, sauf si vous choisissez d’indexer toutes les pages. Pour inclure les pages cachées dans les résultats de recherche de votre serveur MCP, ajoutez la propriété `seo.indexing` à votre `docs.json`.

```json
"seo": {
    "indexing": "all"
}
```

Pour exclure une page spécifique de l’indexation dans les moteurs de recherche, ajoutez `noindex: true` à son frontmatter.

```mdx
---
title: "Page masquée"
description: "Cette page ne figure pas dans la navigation et n'est pas disponible via la recherche."
noindex: true
---
```

<div id="use-your-mcp-server">
  ## Utiliser votre serveur MCP
</div>

Vos utilisateurs doivent connecter votre serveur MCP à leurs outils d’IA préférés.

1. Rendez l’URL de votre serveur MCP accessible publiquement.
2. Les utilisateurs copient l’URL de votre serveur MCP et l’ajoutent à leurs outils.
3. Les utilisateurs accèdent à votre documentation directement depuis leurs outils.

Voici quelques façons dont vous pouvez aider vos utilisateurs à se connecter à votre serveur MCP :

<Tabs>
  <Tab title="Menu contextuel">
    Ajoutez des options dans le [menu contextuel](/fr/ai/contextual-menu) pour permettre à vos utilisateurs de se connecter à votre serveur MCP depuis n’importe quelle page de votre documentation.

    | Option | Identifiant | Description |
    | :----- | :--------- | :---------- |
    | **Copier l’URL du serveur MCP** | `mcp` | Copie l’URL de votre serveur MCP dans le presse-papiers de l’utilisateur. |
    | **Se connecter à Cursor** | `cursor` | Installe votre serveur MCP dans Cursor. |
    | **Se connecter à VS Code** | `vscode` | Installe votre serveur MCP dans VS Code. |
  </Tab>

  <Tab title="Claude">
    <Steps>
      <Step title="Obtenez l’URL de votre serveur MCP.">
        Accédez à votre [tableau de bord](https://dashboard.mintlify.com/products/mcp) et récupérez l’URL de votre serveur MCP.
      </Step>

      <Step title="Mettez l’URL de votre serveur MCP à disposition de vos utilisateurs.">
        Créez un guide pour vos utilisateurs qui inclut l’URL de votre serveur MCP et les étapes pour le connecter à Claude.

        1. Accédez à la page [Connectors](https://claude.ai/settings/connectors) dans les paramètres de Claude.
        2. Sélectionnez **Add custom connector**.
        3. Ajoutez le nom et l’URL de votre serveur MCP.
        4. Sélectionnez **Add**.
        5. Lorsque vous utilisez Claude, sélectionnez le bouton des pièces jointes (l’icône Plus).
        6. Sélectionnez votre serveur MCP.
      </Step>
    </Steps>

    Consultez la [documentation Model Context Protocol](https://modelcontextprotocol.io/docs/tutorials/use-remote-mcp-server#connecting-to-a-remote-mcp-server) pour plus de détails.
  </Tab>

  <Tab title="Claude Code">
    <Steps>
      <Step title="Obtenez l’URL de votre serveur MCP.">
        Accédez à votre [tableau de bord](https://dashboard.mintlify.com/products/mcp) et récupérez l’URL de votre serveur MCP.
      </Step>

      <Step title="Mettez l’URL de votre serveur MCP à disposition de vos utilisateurs.">
        Créez un guide pour vos utilisateurs qui inclut l’URL de votre serveur MCP et la commande pour le connecter à Claude Code.

        ```bash
        claude mcp add --transport http <name> <url>
        ```
      </Step>
    </Steps>

    Consultez la [documentation Claude Code](https://docs.anthropic.com/en/docs/claude-code/mcp#installing-mcp-servers) pour plus de détails.
  </Tab>

  <Tab title="Cursor">
    <Steps>
      <Step title="Obtenez l’URL de votre serveur MCP.">
        Accédez à votre [tableau de bord](https://dashboard.mintlify.com/products/mcp) et récupérez l’URL de votre serveur MCP.
      </Step>

      <Step title="Mettez l’URL de votre serveur MCP à disposition de vos utilisateurs.">
        Créez un guide pour vos utilisateurs qui inclut l’URL de votre serveur MCP et les étapes pour le connecter à Cursor.

        1. Utilisez <kbd>Command</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> sur Windows) pour ouvrir la palette de commandes.
        2. Recherchez « Open MCP settings ».
        3. Sélectionnez **Add custom MCP**. Cela ouvre le fichier `mcp.json`.
        4. Dans `mcp.json`, configurez votre serveur :

        ```json
        {
          "mcpServers": {
            "<your-mcp-server-name>": {
              "url": "<your-mcp-server-url>"
            }
          }
        }
        ```
      </Step>
    </Steps>

    Consultez la [documentation Cursor](https://docs.cursor.com/en/context/mcp#installing-mcp-servers) pour plus de détails.
  </Tab>

  <Tab title="VS Code">
    <Steps>
      <Step title="Obtenez l’URL de votre serveur MCP.">

      </Step>

      <Step title="Mettez l’URL de votre serveur MCP à disposition de vos utilisateurs.">
        Créez un guide pour vos utilisateurs qui inclut l’URL de votre serveur MCP et les étapes pour le connecter à VS Code.

        1. Créez un fichier `.vscode/mcp.json`.
        2. Dans `mcp.json`, configurez votre serveur :

        ```json
        {
          "servers": {
            "<your-mcp-server-name>": {
              "type": "http",
              "url": "<your-mcp-server-url>"
            }
          }
        }
        ```
      </Step>
    </Steps>

    Consultez la [documentation VS Code](https://code.visualstudio.com/docs/copilot/chat/mcp-servers) pour plus de détails.
  </Tab>
</Tabs>

<div id="using-multiple-mcp-servers">
  ### Utiliser plusieurs serveurs MCP
</div>

Les utilisateurs peuvent connecter plusieurs serveurs MCP à leurs outils d’IA. Les serveurs MCP connectés ne consomment pas de contexte tant que l’IA n’appelle pas un outil de recherche. L’IA décide quand effectuer une recherche en fonction de la pertinence de la requête, elle ne lance donc pas de recherche sur chaque serveur connecté pour chaque question.

Lorsque l’IA effectue une recherche, chaque requête renvoie plusieurs résultats qui s’ajoutent au contexte de la conversation. Si l’IA interroge plusieurs serveurs pour une seule question, cela peut consommer une quantité importante de contexte.

Bonnes pratiques pour l’utilisation de plusieurs serveurs MCP :

* Connectez uniquement les serveurs MCP pertinents pour votre travail actuel.
* Soyez précis dans vos prompts afin que l’IA interroge le serveur le plus pertinent.
* Déconnectez les serveurs que vous n’utilisez pas activement pour réduire la consommation potentielle de contexte.
