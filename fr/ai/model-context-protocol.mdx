<div id="about-mcp-servers">
  ## À propos des serveurs MCP
</div>

Le Model Context Protocol (MCP) est un protocole ouvert qui établit des connexions standardisées entre les applications d’IA et des services externes, comme la documentation. Mintlify génère un serveur MCP à partir de votre documentation, afin de préparer votre contenu à l’écosystème plus large de l’IA, où n’importe quel client MCP, comme Claude, Cursor, Goose ou ChatGPT, peut se connecter à votre documentation.

Votre serveur MCP expose un outil de recherche permettant aux applications d’IA d’interroger votre documentation. Vos utilisateurs doivent connecter votre serveur MCP à leurs outils.

<div id="how-mcp-servers-work">
  ### Comment fonctionnent les serveurs MCP
</div>

Lorsqu&#39;une application d&#39;IA se connecte au serveur MCP de votre documentation, elle peut effectuer des recherches directement dans votre documentation au lieu de lancer une recherche web générique en réponse à la requête d&#39;un utilisateur. Votre serveur MCP donne accès à l&#39;ensemble du contenu indexé de votre site de documentation.

* L&#39;application d&#39;IA peut rechercher de manière proactive dans votre documentation pendant qu&#39;elle génère une réponse, et pas seulement lorsqu&#39;on le lui demande explicitement.
* L&#39;application d&#39;IA détermine quand utiliser l&#39;outil de recherche en fonction du contexte de la conversation et de la pertinence de votre documentation.
* Chaque recherche (appel d&#39;outil) a lieu pendant le processus de génération ; l&#39;application d&#39;IA interroge donc les informations à jour de votre documentation pour générer sa réponse.

<Tip>
  Certains outils d&#39;IA, comme Claude, prennent en charge à la fois MCP et Skills. MCP donne à l&#39;IA accès au contenu de votre documentation, tandis que Skills indique à l&#39;IA comment utiliser ce contenu efficacement. Les deux sont complémentaires : MCP fournit les données et Skills fournit les instructions.
</Tip>

<div id="search-filtering-parameters">
  ### Paramètres de filtrage de la recherche
</div>

L&#39;outil de recherche MCP prend en charge des paramètres de filtrage facultatifs que les applications d&#39;IA peuvent utiliser pour affiner les résultats de recherche.

* **`version`** : limite les résultats à une version spécifique de la documentation. Par exemple, `'v0.7'`. Renvoie uniquement le contenu associé à la version spécifiée ou le contenu disponible dans toutes les versions.
* **`language`** : limite les résultats à un code de langue spécifique. Par exemple, `'en'`, `'zh'` ou `'es'`. Renvoie uniquement le contenu dans la langue spécifiée ou le contenu disponible dans toutes les langues.
* **`apiReferenceOnly`** : lorsque ce paramètre est défini sur `true`, renvoie uniquement les pages de référence de l&#39;API.
* **`codeOnly`** : lorsque ce paramètre est défini sur `true`, renvoie uniquement des extraits de code et des exemples.

Les applications d&#39;IA déterminent quand appliquer ces filtres en fonction du contexte de la requête de l&#39;utilisateur. Par exemple, si un utilisateur pose une question sur une version spécifique de l&#39;API ou demande des exemples de code, l&#39;application d&#39;IA peut appliquer automatiquement les filtres appropriés pour fournir des résultats plus pertinents.

<div id="mcp-compared-to-web-search">
  ### MCP comparé à la recherche sur le Web
</div>

Les outils d’IA peuvent effectuer des recherches sur le Web, mais MCP offre des avantages distincts pour la documentation.

* **Accès direct à la source** : la recherche sur le Web dépend de ce que les moteurs de recherche ont indexé, ce qui peut être obsolète ou incomplet. MCP interroge directement la version actuelle de votre documentation indexée.
* **Flux de travail intégré** : MCP permet à l’IA d’effectuer des recherches pendant la génération de la réponse, au lieu de lancer une recherche sur le Web séparément.
* **Pas de bruit dans les résultats** : le SEO et les algorithmes de classement influencent les résultats de recherche sur le Web. MCP accède directement au contenu de votre documentation.

<div id="access-your-mcp-server">
  ## Accédez à votre serveur MCP
</div>

<Note>
  Les serveurs MCP sont disponibles uniquement pour la documentation publique. La documentation protégée par une authentification des utilisateurs finaux ne peut pas générer un serveur MCP.
</Note>

Mintlify génère automatiquement un serveur MCP pour votre documentation et l’héberge à l’URL de votre documentation, sous le chemin `/mcp`. Par exemple, le serveur MCP de Mintlify est disponible à l’adresse `https://mintlify.com/docs/mcp`.

Affichez et copiez l’URL de votre serveur MCP depuis la [page du serveur MCP](https://dashboard.mintlify.com/products/mcp) dans votre tableau de bord.

<div id="content-filtering-and-indexing">
  ## Filtrage du contenu et indexation
</div>

Votre serveur MCP effectue des recherches dans le contenu que Mintlify indexe depuis votre dépôt de documentation. Le traitement des fichiers et l’indexation pour la recherche déterminent le contenu accessible via votre serveur MCP.

<div id="file-processing-with-mintignore">
  ### Traitement des fichiers avec `.mintignore`
</div>

Si des fichiers correspondent aux motifs définis dans [.mintignore](/fr/organize/mintignore), Mintlify ne les traite pas et ne les indexe pas. Ces fichiers ne sont pas accessibles via votre serveur MCP.

<div id="search-indexing-with-docsjson">
  ### Indexation pour la recherche avec `docs.json`
</div>

Par défaut, Mintlify indexe uniquement les pages incluses dans la navigation de votre `docs.json` pour la recherche via votre serveur MCP.

Mintlify exclut les [pages masquées](/fr/organize/hidden-pages) (pages qui ne figurent pas dans votre navigation) de l’index de recherche, sauf si vous choisissez d’indexer toutes les pages. Pour inclure les pages masquées dans les résultats de recherche de votre serveur MCP, ajoutez la propriété `seo.indexing` à votre `docs.json`.

```json
"seo": {
    "indexing": "all"
}
```

Pour exclure une page spécifique de l’indexation dans la recherche, ajoutez `noindex: true` à son Frontmatter.

```mdx
---
title: "Page masquée"
description: "Cette page n'est pas dans la navigation et n'apparaît pas dans les résultats de recherche."
noindex: true
---
```

<div id="use-your-mcp-server">
  ## Utiliser votre serveur MCP
</div>

Vos utilisateurs doivent connecter votre serveur MCP à leurs outils d’IA préférés.

1. Rendez l’URL de votre serveur MCP accessible au public.
2. Les utilisateurs copient l’URL de votre serveur MCP et l’ajoutent à leurs outils.
3. Les utilisateurs accèdent à votre documentation depuis leurs outils.

Voici quelques façons d’aider vos utilisateurs à se connecter à votre serveur MCP :

<Tabs>
  <Tab title="Menu contextuel">
    Ajoutez des options au [menu contextuel](/fr/ai/contextual-menu) pour permettre à vos utilisateurs de se connecter à votre serveur MCP depuis n’importe quelle page de votre documentation.

    | Option                          | Identifiant | Description                                                               |
    | :------------------------------ | :---------- | :------------------------------------------------------------------------ |
    | **Copier l’URL du serveur MCP** | `mcp`       | Copie l’URL de votre serveur MCP dans le presse-papiers de l’utilisateur. |
    | **Se connecter à Cursor**       | `cursor`    | Installe votre serveur MCP dans Cursor.                                   |
    | **Se connecter à VS Code**      | `vscode`    | Installe votre serveur MCP dans VS Code.                                  |
  </Tab>

  <Tab title="Claude">
    <Steps>
      <Step title="Récupérez l’URL de votre serveur MCP.">
        Accédez à votre [tableau de bord](https://dashboard.mintlify.com/products/mcp) et repérez l’URL de votre serveur MCP.
      </Step>

      <Step title="Publiez l’URL de votre serveur MCP pour vos utilisateurs.">
        Créez un guide pour vos utilisateurs incluant l’URL de votre serveur MCP et les étapes pour le connecter à Claude.

        1. Accédez à la page [Connectors](https://claude.ai/settings/connectors) dans les paramètres de Claude.
        2. Sélectionnez **Add custom connector**.
        3. Ajoutez le nom et l’URL de votre serveur MCP.
        4. Sélectionnez **Add**.
        5. Lorsque vous utilisez Claude, sélectionnez le bouton des pièces jointes (l’icône plus).
        6. Sélectionnez votre serveur MCP.
      </Step>
    </Steps>

    Consultez la [documentation du Model Context Protocol](https://modelcontextprotocol.io/docs/tutorials/use-remote-mcp-server#connecting-to-a-remote-mcp-server) pour plus de détails.
  </Tab>

  <Tab title="Claude Code">
    <Steps>
      <Step title="Récupérez l’URL de votre serveur MCP.">
        Accédez à votre [tableau de bord](https://dashboard.mintlify.com/products/mcp) et repérez l’URL de votre serveur MCP.
      </Step>

      <Step title="Publiez l’URL de votre serveur MCP pour vos utilisateurs.">
        Créez un guide pour vos utilisateurs incluant l’URL de votre serveur MCP et la commande pour le connecter à Claude Code.

        ```bash
        claude mcp add --transport http <name> <url>
        ```
      </Step>
    </Steps>

    Consultez la [documentation de Claude Code](https://docs.anthropic.com/en/docs/claude-code/mcp#installing-mcp-servers) pour plus de détails.
  </Tab>

  <Tab title="Cursor">
    <Steps>
      <Step title="Récupérez l’URL de votre serveur MCP.">
        Accédez à votre [tableau de bord](https://dashboard.mintlify.com/products/mcp) et repérez l’URL de votre serveur MCP.
      </Step>

      <Step title="Publiez l’URL de votre serveur MCP pour vos utilisateurs.">
        Créez un guide pour vos utilisateurs incluant l’URL de votre serveur MCP et les étapes pour le connecter à Cursor.

        1. Utilisez <kbd>Command</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> sous Windows) pour ouvrir la palette de commandes.
        2. Recherchez « Open MCP settings ».

        ```json
            }
          }
        }
        ```
      </Step>
    </Steps>

    Consultez la [documentation de Cursor](https://docs.cursor.com/en/context/mcp#installing-mcp-servers) pour plus de détails.

<div id="using-multiple-mcp-servers">
  ### Utiliser plusieurs serveurs MCP
</div>

Les utilisateurs peuvent connecter plusieurs serveurs MCP à leurs outils d’IA. Les serveurs MCP connectés ne consomment pas de contexte tant que l’IA n’appelle pas d’outil de recherche. L’IA décide quand lancer une recherche en fonction de la pertinence de la requête, elle n’interroge donc pas tous les serveurs connectés pour chaque question.

Lorsque l’IA lance une recherche, chaque requête renvoie plusieurs résultats qui s’ajoutent au contexte de la conversation. Si l’IA interroge plusieurs serveurs pour une seule question, cela peut consommer une part importante du contexte.

Bonnes pratiques pour utiliser plusieurs serveurs MCP :

* Connectez uniquement les serveurs MCP pertinents pour votre tâche en cours.
* Soyez précis dans vos prompts afin que l’IA interroge le serveur le plus pertinent.
* Déconnectez les serveurs que vous n’utilisez pas activement afin de limiter l’utilisation potentielle du contexte.
