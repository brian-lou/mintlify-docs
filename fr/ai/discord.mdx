<Info>
  Les intégrations Discord sont disponibles sur les [offres Pro et Enterprise](https://mintlify.com/pricing?ref=discord) pour les espaces disposant de l'accès à l'assistant.
</Info>

Le bot Discord aide votre communauté en fournissant des réponses en temps réel à partir de votre documentation. Le bot utilise l'assistant Mintlify pour rechercher dans votre documentation et fournir des réponses précises et sourcées, afin d'être toujours à jour.

Le bot Discord ne fonctionne que dans les salons publics. Il répond aux mentions `@` ou à tous les messages dans un salon spécifique.

Chaque message envoyé par le bot Discord est décompté de votre quota de messages de l'assistant.

<div id="add-the-discord-bot-to-your-server">
  ## Ajouter le bot Discord à votre serveur
</div>

<Note>
  Vous devez avoir la permission « Gérer le serveur » sur Discord pour ajouter le bot.
</Note>

1. Accédez à la page [Assistant](https://dashboard.mintlify.com/products/assistant) de votre tableau de bord.
1. Sur la carte Discord, cliquez sur **Configure**. Discord s’ouvre alors.
   <Frame>
     <img src="/images/assistant/connected-apps-light.png" alt="La section des applications connectées de la page de l’assistant." className="block dark:hidden" />
     <img src="/images/assistant/connected-apps-dark.png" alt="La section des applications connectées de la page de l’assistant." className="hidden dark:block" />
   </Frame>
1. Dans Discord, sélectionnez le serveur sur lequel vous souhaitez ajouter le bot.
1. Autorisez le bot à accéder à votre serveur.
1. Mentionnez le bot pour l’ajouter à un canal. Le nom par défaut du bot est `@Mintlify Bot`.

<div id="create-an-ask-ai-channel">
  ## Créer un salon `#ask-ai`
</div>

Pour aider votre communauté à obtenir rapidement des réponses à ses questions, le bot peut répondre à chaque message publié dans un salon de votre choix. Par défaut, le bot répond à chaque message dans les salons nommés `#ask-ai`. Créez un salon `#ask-ai` et informez votre communauté que le bot répondra aux messages dans ce salon.

Si vous souhaitez que le bot réponde aux messages dans un autre salon, sélectionnez ce salon dans le [menu de configuration](https://dashboard.mintlify.com/products/assistant/settings/integrations) du bot Discord.

<Frame>
  <img src="/images/assistant/discord-configure-light.png" alt="Le panneau de configuration Discord en mode clair." className="block dark:hidden" />
  <img src="/images/assistant/discord-configure-dark.png" alt="Le panneau de configuration Discord en mode sombre." className="hidden dark:block" />

Consultez [Starting Your First Discord Server](https://discord.com/blog/starting-your-first-discord-server) sur le blog Discord pour plus d’informations sur la création d’un salon.

<div id="manage-the-discord-bot">
  ## Gérer le bot Discord
</div>

Une fois que vous avez ajouté le bot Discord à votre serveur, vous pouvez gérer ou supprimer le bot depuis l’onglet [Integrations](https://dashboard.mintlify.com/products/assistant/settings/integrations) de votre tableau de bord.

Dans le menu de configuration du bot Discord, personnalisez le bot en modifiant son avatar ou son nom, et choisissez le salon dans lequel il répond automatiquement à tous les messages.
