<Info>
  Les intégrations Discord sont disponibles avec les offres [Pro et Enterprise](https://mintlify.com/pricing?ref=discord) incluant l’accès à l’assistant.
</Info>

Le bot Discord aide votre communauté en fournissant des réponses en temps réel à partir de votre documentation. Il utilise l’assistant Mintlify pour effectuer des recherches dans votre documentation et fournir des réponses précises, avec citations, afin de rester toujours à jour.

Le bot Discord fonctionne uniquement dans les salons publics. Il répond aux mentions `@` ou à tous les messages d’un salon spécifique.

Chaque message envoyé par le bot Discord est décompté de votre quota de messages de l’assistant.

<div id="add-the-discord-bot-to-your-server">
  ## Ajoutez le bot Discord à votre serveur
</div>

<Note>
  Vous devez disposer de l’autorisation « Manage Server » dans Discord pour ajouter le bot.
</Note>

1. Accédez à la page [Assistant](https://dashboard.mintlify.com/products/assistant) dans votre tableau de bord.
2. Dans l’encadré Discord, cliquez sur **Configure**. Discord s’ouvre.
   <Frame>
     <img src="/images/assistant/connected-apps-light.png" alt="La section des applications connectées de la page Assistant." className="block dark:hidden" />

     <img src="/images/assistant/connected-apps-dark.png" alt="La section des applications connectées de la page Assistant." className="hidden dark:block" />
   </Frame>
3. Dans Discord, sélectionnez le serveur auquel vous souhaitez ajouter le bot.
4. Autorisez le bot à accéder à votre serveur.
5. Mentionnez le bot pour l’ajouter à un salon. Son nom par défaut est `@Mintlify Bot`.

<div id="create-an-ask-ai-channel">
  ## Créer un salon `#ask-ai`
</div>

Pour aider votre communauté à obtenir rapidement des réponses à ses questions, le bot peut répondre à chaque message dans le salon de votre choix. Par défaut, le bot répond à chaque message dans les salons nommés `#ask-ai`. Créez un salon `#ask-ai` et informez votre communauté que le bot répondra aux messages dans ce salon.

Si vous souhaitez que le bot réponde aux messages dans un autre salon, sélectionnez un salon dans le [menu de configuration](https://dashboard.mintlify.com/products/assistant/settings/integrations) du bot Discord.

<Frame>
  <img src="/images/assistant/discord-configure-light.png" alt="Le panneau de configuration Discord en mode clair." className="block dark:hidden" />

  <img src="/images/assistant/discord-configure-dark.png" alt="Le panneau de configuration Discord en mode sombre." className="hidden dark:block" />

Consultez [Starting Your First Discord Server](https://discord.com/blog/starting-your-first-discord-server) sur le blog de Discord pour en savoir plus sur la création d’un salon.

<div id="manage-the-discord-bot">
  ## Gérer le bot Discord
</div>

Après avoir ajouté le bot Discord à votre serveur, vous pouvez le gérer ou le supprimer depuis l’onglet [Integrations](https://dashboard.mintlify.com/products/assistant/settings/integrations) de votre tableau de bord.

Dans le menu de configuration du bot Discord, personnalisez-le en modifiant son avatar ou son nom, et choisissez le salon dans lequel il répond automatiquement à tous les messages.
