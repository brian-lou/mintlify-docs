<div id="usage">
  ## Utilisation
</div>

Utilisez cet endpoint pour exporter les commentaires d'utilisateurs recueillis à partir de votre documentation. Les commentaires incluent les retours contextuels provenant des évaluations de page et les commentaires sur les extraits de code.

Parcourez les résultats à l'aide du paramètre `cursor` renvoyé dans la réponse. Continuez à récupérer les données tant que `hasMore` est défini sur `true`.

<div id="filtering">
  ## Filtrage
</div>

Filtrez les commentaires par :

- **Plage de dates** : utilisez `dateFrom` et `dateTo` pour limiter les résultats à une période spécifique
- **Source** : filtrez par types de commentaires `code_snippet` ou `contextual`
- **Statut** : filtrez par des valeurs de statut telles que `pending`, `in_progress`, `resolved` ou `dismissed`

<div id="response-types">
  ## Types de réponse
</div>

La réponse contient différents types de retour selon la source :

- **Retour contextuel** : comprend le booléen `helpful` et éventuellement l’email de `contact`
- **Retour sur extrait de code** : comprend les champs `code`, `filename` et `lang`
