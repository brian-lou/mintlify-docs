<div id="usage">
  ## Utilisation
</div>

Utilisez cet endpoint pour exporter les retours utilisateur recueillis dans votre documentation. Ces retours comprennent les retours contextuels issus des évaluations de page ainsi que les retours sur les extraits de code.

Parcourez les résultats à l’aide de la pagination avec le paramètre `cursor` renvoyé dans la réponse. Continuez à récupérer les résultats tant que `hasMore` vaut `true`.

<div id="filtering">
  ## Filtrage
</div>

Filtrez les retours selon :

* **Plage de dates** : utilisez `dateFrom` et `dateTo` pour limiter les résultats à une période donnée
* **Source** : filtrez selon les types de retours `code_snippet` ou `contextual`
* **Statut** : filtrez selon des valeurs de statut comme `pending`, `in_progress`, `resolved` ou `dismissed`

<div id="response-types">
  ## Types de réponse
</div>

La réponse contient différents types de retour selon la source :

* **Retour contextuel** : inclut le booléen `helpful` et l’adresse e-mail `contact` facultative
* **Retour sur les extraits de code** : inclut les champs `code`, `filename` et `lang`
