L’API REST de Mintlify vous permet d’interagir avec votre documentation de manière programmatique, de déclencher des mises à jour, d’intégrer des expériences de chat propulsées par l’IA et d’exporter des données analytiques.

<div id="endpoints">
  ## Points de terminaison
</div>

* [Déclencher une mise à jour](/fr/api/update/trigger): Déclenchez une mise à jour de votre site quand vous le souhaitez.
* [Obtenir le statut d’une mise à jour](/fr/api/update/status): Obtenez le statut d’une mise à jour ainsi que d’autres informations sur votre documentation.
* [Créer une tâche d’agent](/fr/api/agent/create-agent-job): Créez une tâche d’agent pour modifier automatiquement votre documentation.
* [Obtenir une tâche d’agent](/fr/api/agent/get-agent-job): Récupérez les détails et le statut d’une tâche d’agent spécifique.
* [Obtenir toutes les tâches d’agent](/fr/api/agent/get-all-jobs): Récupérez toutes les tâches d’agent pour un domaine.
* [Générer un message de l’assistant](/fr/api/assistant/create-assistant-message): Intégrez l’assistant, entraîné sur votre documentation, dans l’application de votre choix.
* [Rechercher dans la documentation](/fr/api/assistant/search): Effectuez une recherche dans votre documentation.
* [Obtenir les retours des utilisateurs](/fr/api/analytics/feedback): Exportez les retours des utilisateurs sur votre documentation.
* [Obtenir les conversations de l’assistant](/fr/api/analytics/assistant-conversations): Exportez l’historique des conversations de l’assistant IA.

<div id="common-use-cases">
  ### Cas d&#39;utilisation courants
</div>

* **Déploiements automatisés** : Déclenchez des mises à jour du site à intervalles réguliers ou lorsqu&#39;un événement se produit avec [Déclencher une mise à jour](/fr/api/update/trigger) et [Obtenir le statut d’une mise à jour](/fr/api/update/status).
* **Intégration CI/CD** : Mettez à jour la documentation dans votre pipeline de déploiement lorsque le code change avec [Déclencher une mise à jour](/fr/api/update/trigger).
* **Intégrations personnalisées** : Intégrez l&#39;assistant IA à votre produit, à votre portail d&#39;assistance ou à vos outils internes avec [Générer un message de l&#39;assistant](/fr/api/assistant/create-assistant-message) et [Rechercher dans la documentation](/fr/api/assistant/search).
* **Modification automatisée** : Utilisez des tâches d’agent pour mettre à jour la documentation par programmation à grande échelle avec [Créer une tâche d’agent](/fr/api/agent/create-agent-job), [Obtenir une tâche d’agent](/fr/api/agent/get-agent-job) et [Obtenir toutes les tâches d’agent](/fr/api/agent/get-all-jobs).
* **Export d&#39;analyses** : Exportez les retours utilisateurs et les conversations de l&#39;assistant pour une analyse externe avec [Obtenir les retours des utilisateurs](/fr/api/analytics/feedback) et [Obtenir les conversations de l&#39;assistant](/fr/api/analytics/assistant-conversations).

<div id="authentication">
  ## Authentification
</div>

Générez des clés API sur la [page des clés API](https://dashboard.mintlify.com/settings/organization/api-keys) de votre tableau de bord. Chaque clé API appartient à une organisation--vous pouvez utiliser ces clés pour plusieurs déploiements au sein de la même organisation.

Vous pouvez créer jusqu&#39;à 10 clés API par heure et par organisation.

<div id="admin-api-key">
  ### Clé API d’administration
</div>

Utilisez la clé API d’administration pour authentifier les requêtes vers [Déclencher une mise à jour](/fr/api/update/trigger), [Obtenir le statut d’une mise à jour](/fr/api/update/status), [Créer une tâche d’agent](/fr/api/agent/create-agent-job), [Obtenir une tâche d’agent](/fr/api/agent/get-agent-job), [Obtenir toutes les tâches d’agent](/fr/api/agent/get-all-jobs), [Obtenir les retours des utilisateurs](/fr/api/analytics/feedback) et [Obtenir les conversations de l’assistant](/fr/api/analytics/assistant-conversations).

Les clés API d’administration commencent par le préfixe `mint_`.

La clé API d’administration est un secret côté serveur. Ne l’exposez pas dans le code côté client.

<div id="assistant-api-key">
  ### Clé API de l’assistant
</div>

Utilisez la clé API de l’assistant pour authentifier les requêtes adressées aux points de terminaison [Générer un message de l’assistant](/fr/api/assistant/create-assistant-message) et [Rechercher dans la documentation](/fr/api/assistant/search).

Les clés API de l’assistant commencent par le préfixe `mint_dsc_`.

La clé API de l’assistant est un jeton public que vous pouvez utiliser dans le code frontend.

<Note>
  Les appels effectués avec le jeton API de l’assistant peuvent entraîner des coûts : soit en utilisant vos crédits d’assistant, soit en générant des dépassements.
</Note>
