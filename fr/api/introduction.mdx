L&#39;API REST de Mintlify vous permet d&#39;interagir programmatiquement avec votre documentation, de déclencher des mises à jour, d&#39;intégrer des expériences de chat propulsées par l&#39;IA et d&#39;exporter des données d&#39;analyse.

<div id="endpoints">
  ## Endpoints
</div>

* [Trigger update](/fr/api/update/trigger): Déclenchez une mise à jour de votre site quand vous le souhaitez.
* [Get update status](/fr/api/update/status): Obtenez le statut d’une mise à jour et d’autres informations sur votre documentation.
* [Create agent job](/fr/api/agent/create-agent-job): Créez une tâche d’agent pour modifier automatiquement votre documentation.
* [Get agent job](/fr/api/agent/get-agent-job): Récupérez les détails et le statut d’une tâche d’agent spécifique.
* [Get all agent jobs](/fr/api/agent/get-all-jobs): Récupérez toutes les tâches d’agent pour un domaine donné.
* [Generate assistant message](/fr/api/assistant/create-assistant-message): Intégrez l’assistant, formé à partir de votre documentation, dans l’application de votre choix.
* [Search documentation](/fr/api/assistant/search): Parcourez votre documentation.
* [Get user feedback](/fr/api/analytics/feedback): Exportez les commentaires des utilisateurs relatifs à votre documentation.
* [Get assistant conversations](/fr/api/analytics/assistant-conversations): Exportez l’historique des conversations de l’assistant IA.

<div id="common-use-cases">
  ### Cas d’utilisation courants
</div>

* **Déploiements automatisés** : déclenchez les mises à jour du site à intervalles réguliers ou en réponse à certains événements avec [Trigger update](/fr/api/update/trigger) et [Get update status](/fr/api/update/status).
* **Intégration CI/CD** : mettez à jour la documentation, dans le cadre de votre pipeline de déploiement, lorsque le code change avec [Trigger update](/fr/api/update/trigger).
* **Intégrations personnalisées** : intégrez l’assistant IA à votre produit, à votre portail de support ou à vos outils internes avec [Generate assistant message](/fr/api/assistant/create-assistant-message) et [Search documentation](/fr/api/assistant/search).
* **Édition automatisée** : utilisez des jobs d’agent pour mettre à jour la documentation à grande échelle par programmation avec [Create agent job](/fr/api/agent/create-agent-job), [Get agent job](/fr/api/agent/get-agent-job) et [Get all agent jobs](/fr/api/agent/get-all-jobs).
* **Export des données d’analyse** : exportez les commentaires et les conversations avec l’assistant pour une analyse externe avec [Get user feedback](/fr/api/analytics/feedback) et [Get assistant conversations](/fr/api/analytics/assistant-conversations).

<div id="authentication">
  ## Authentification
</div>

Générez des clés API sur la [page des clés API](https://dashboard.mintlify.com/settings/organization/api-keys) de votre tableau de bord. Chaque clé API est associée à une organisation : vous pouvez utiliser des clés sur plusieurs déploiements au sein de la même organisation.

Vous pouvez créer jusqu’à 10 clés API par heure et par organisation.

<div id="admin-api-key">
  ### Clé d’API administrateur
</div>

Utilisez la clé d’API administrateur pour authentifier les requêtes vers [Trigger update](/fr/api/update/trigger), [Get update status](/fr/api/update/status), [Create agent job](/fr/api/agent/create-agent-job), [Get agent job](/fr/api/agent/get-agent-job), [Get all agent jobs](/fr/api/agent/get-all-jobs), [Get user feedback](/fr/api/analytics/feedback) et [Get assistant conversations](/fr/api/analytics/assistant-conversations).

Les clés d’API administrateur commencent par le préfixe `mint_`.

La clé d’API administrateur est un secret côté serveur. Ne l’exposez pas dans du code côté client.

<div id="assistant-api-key">
  ### Clé d’API Assistant
</div>

Utilisez la clé d’API Assistant pour authentifier les requêtes adressées aux endpoints [Generate assistant message](/fr/api/assistant/create-assistant-message) et [Search documentation](/fr/api/assistant/search).

Les clés d’API Assistant commencent par le préfixe `mint_dsc_`.

La clé d’API Assistant est un jeton public que vous pouvez utiliser dans le code frontend.

<Note>
  Les appels utilisant le jeton d’API Assistant peuvent entraîner des coûts : soit en utilisant vos crédits Assistant, soit en entraînant des dépassements de quota.
</Note>
