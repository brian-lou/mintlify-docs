<div id="usage">
  ## Utilisation
</div>

Cet endpoint récupère l’ensemble des tâches d’agent pour le domaine spécifié, offrant une vue d’ensemble de toutes les activités des agents et de leur statut actuel. Il est utile pour surveiller et gérer plusieurs tâches d’agent simultanées ou passées.

<div id="response">
  ## Réponse
</div>

Utilisez cet endpoint pour obtenir une vue d’ensemble complète de toutes les sessions précédentes de l’agent.
