<div id="usage">
  ## Utilisation
</div>

Ce point de terminaison renvoie toutes les tâches d’agent pour le domaine spécifié et offre une vue d’ensemble de toutes les activités des agents ainsi que de leur statut actuel. Cela est utile pour surveiller et gérer plusieurs tâches d’agent simultanées ou antérieures.

<div id="response">
  ## Réponse
</div>

Utilisez cet endpoint pour obtenir une vue d’ensemble complète de toutes les sessions précédentes de l’agent.
