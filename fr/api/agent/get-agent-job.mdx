<div id="usage">
  ## Utilisation
</div>

Ce point de terminaison récupère les détails et le statut d’une tâche d’agent spécifique à partir de son identifiant unique. Utilisez-le pour consulter l’avancement, le statut et les résultats d’une tâche d’agent créée précédemment.

<div id="job-details">
  ## Détails de la tâche
</div>

La réponse inclut notamment les informations suivantes :

* Le statut d’exécution de la tâche et son état d’avancement
* Les informations sur la branche et les détails de la pull request
* Les métadonnées de session et les horodatages
