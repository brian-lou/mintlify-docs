<div id="navigate-files">
  ## Naviguer dans les fichiers
</div>

Parcourez les pages de votre documentation dans l’onglet **Navigation** du volet de gauche.

* Cliquez sur les éléments de navigation pour les déployer ou les replier.
* Cliquez sur les pages pour les ouvrir dans l’éditeur.
* Cliquez sur l’icône de recherche ou appuyez sur <kbd>Cmd</kbd> + <kbd>P</kbd> (macOS) ou <kbd>Ctrl</kbd> + <kbd>P</kbd> (Windows) pour rechercher des fichiers par leur nom. La recherche doit correspondre exactement aux noms de fichiers ; utilisez donc des traits d’union entre les mots (par exemple, `get-agent-job` au lieu de `get agent job`).

<div id="create-new-pages">
  ## Créer de nouvelles pages
</div>

1. Cliquez sur le bouton **+** dans l’élément de navigation où vous souhaitez ajouter une page.
2. Cliquez sur **Ajouter une page**.
3. Saisissez un nom de fichier. L’éditeur ajoute automatiquement l’extension `.mdx`.

<div id="edit-content">
  ## Modifier le contenu
</div>

Basculez entre le mode visuel et le mode Markdown à l’aide du sélecteur dans la barre d’outils. L’éditeur web enregistre vos modifications lorsque vous changez de mode.

<div id="visual-mode">
  ### Mode visuel
</div>

Modifiez le contenu avec des aperçus en temps réel pour voir à quoi il ressemblera une fois publié.

* **Ajouter du texte** : Saisissez du texte dans l’éditeur pour voir comment il apparaîtra une fois publié.
* **Mettre le texte en forme** : Utilisez la barre d’outils pour mettre le texte en gras, en italique ou appliquer d’autres styles de mise en forme.
* **Ajouter des composants** : Appuyez sur <kbd>/</kbd> pour ouvrir le menu des composants et en sélectionner.
* **Ajouter des images** : Utilisez le composant d’image dans le menu <kbd>/</kbd>.
* **Insérer des liens** : Sélectionnez du texte et appuyez sur <kbd>Cmd</kbd> + <kbd>K</kbd>.

Consultez [Components](/fr/components) pour voir la liste complète des composants disponibles.

<div id="markdown-mode">
  ### Mode Markdown
</div>

Modifiez le code source MDX.

* **Modification directe du MDX** : Rédigez en syntaxe MDX et Markdown pour contrôler précisément le contenu.
* **Propriétés des composants** : Définissez les propriétés et la configuration des composants.
* **Frontmatter** : Modifiez les métadonnées de la page en haut du fichier.

Consultez [Mettre en forme le texte](/fr/create/text) et [Mettre en forme le code](/fr/create/code) pour en savoir plus sur la syntaxe MDX.

<div id="configure-pages">
  ## Configurer les pages
</div>

Configurez les paramètres des pages pour contrôler leur affichage dans la navigation, les résultats de recherche et la mise en page de votre site.

1. Faites un clic droit sur un fichier.
2. Cliquez sur **Configure**.

<div id="customize-navigation-appearance">
  ### Personnaliser l’apparence dans la navigation
</div>

Contrôlez la façon dont la page s’affiche dans la barre latérale de navigation de votre site.

* **Titre** : Définissez le titre principal. Il apparaît dans la navigation, les onglets du navigateur et les résultats de recherche.
* **Titre dans la barre latérale** : Affichez un texte plus court dans la navigation lorsque le titre complet est trop long pour la barre latérale.
* **Icône** : Ajoutez un repère visuel à côté de la page pour aider les utilisateurs à l’identifier rapidement.
* **URL externe** : Créez un lien vers un site externe au lieu d’une page. Utilisez cette option pour ajouter des ressources externes à votre navigation.

<div id="optimize-for-search-and-sharing">
  ### Optimiser pour la recherche et le partage
</div>

Aidez les utilisateurs à trouver votre page et améliorez son apparence lorsqu’elle est partagée.

* **Description** : Rédigez un bref résumé. Elle apparaît dans les résultats de recherche et les balises méta SEO.
* **Mots-clés** : Ajoutez des termes de recherche pertinents pour aider les utilisateurs à trouver cette page.
* **URL de l’image OG** : Définissez une image d’aperçu personnalisée pour les partages sur les réseaux sociaux et les aperçus de liens.

<div id="control-page-layout">
  ### Contrôler la mise en page
</div>

Choisissez le mode d’affichage de la page en fonction de votre contenu.

* **Mise en page standard** (`default`) : Page par défaut avec barre latérale de navigation et table des matières.
* **Mise en page pleine largeur** (`wide`) : Masque la table des matières pour offrir une mise en page plus large, adaptée aux tableaux, diagrammes et autres contenus.
* **Mise en page centrée** (`center`) : Masque la barre latérale et la table des matières pour améliorer la lisibilité des pages riches en texte, comme les journaux de modifications.
* **Largeur personnalisée** (`custom`) : Mise en page minimale avec uniquement la barre de navigation supérieure, pour les pages d’accueil ou d’autres mises en page spécifiques.

<div id="manage-pages">
  ## Gérer les pages
</div>

<div id="move-pages">
  ### Déplacer des pages
</div>

Faites glisser des pages pour les réorganiser dans la navigation ou déplacer des fichiers entre les dossiers de l’arborescence.

<div id="duplicate-pages">
  ### Dupliquer des pages
</div>

Faites un clic droit sur une page et sélectionnez **Duplicate**.

<div id="delete-pages">
  ### Supprimer des pages
</div>

Cliquez avec le bouton droit sur une page, puis sélectionnez **Delete**. La suppression d’une page la retire automatiquement de la navigation.

<div id="hide-pages">
  ### Masquer des pages
</div>

Pour masquer une page dans la navigation sans supprimer le fichier, faites un clic droit sur la page, puis cliquez sur **Masquer la page**. Le fichier reste dans votre dépôt, et vous pouvez réafficher la page en l’ajoutant à la navigation de votre `docs.json`.
