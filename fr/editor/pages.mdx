<div id="navigate-files">
  ## Parcourir les fichiers
</div>

Parcourez vos pages de documentation dans l’onglet **Navigation** du panneau de gauche.

* Cliquez sur les éléments de navigation pour les développer ou les réduire.
* Cliquez sur les pages pour les ouvrir dans l’éditeur.
* Cliquez sur l’icône de recherche ou appuyez sur <kbd>Cmd</kbd> + <kbd>P</kbd> (macOS) ou <kbd>Ctrl</kbd> + <kbd>P</kbd> (Windows) pour rechercher des fichiers par leur nom. La recherche ne renvoie que des correspondances exactes, utilisez donc des tirets entre les mots (par exemple, `get-agent-job` au lieu de `get agent job`).

<div id="create-new-pages">
  ## Créer de nouvelles pages
</div>

1. Cliquez sur le bouton **+** dans l’élément de navigation où vous souhaitez ajouter une page.
2. Cliquez sur **Add a page**.
3. Saisissez un nom de fichier. L’éditeur ajoute automatiquement l’extension `.mdx`.

<div id="edit-content">
  ## Modifier le contenu
</div>

Basculez entre le mode visuel et le mode Markdown grâce au commutateur de mode dans la barre d’outils. L’éditeur en ligne enregistre vos modifications lorsque vous changez de mode.

<div id="visual-mode">
  ### Mode visuel
</div>

Modifiez le contenu à l’aide d’aperçus en temps réel qui montrent à quoi il ressemblera une fois publié.

* **Ajouter du texte** : Saisissez du texte dans l’éditeur pour voir comment il apparaît une fois publié.
* **Mettre le texte en forme** : Utilisez la barre d’outils pour mettre du texte en gras, en italique ou lui appliquer d’autres mises en forme.
* **Ajouter des composants** : Appuyez sur <kbd>/</kbd> pour ouvrir le menu des composants et choisir des composants.
* **Ajouter des images** : Utilisez le composant d’image depuis le menu <kbd>/</kbd>.
* **Insérer des liens** : Sélectionnez du texte et appuyez sur <kbd>Cmd</kbd> + <kbd>K</kbd>.

Consultez [Composants](/fr/components) pour la liste complète des composants disponibles.

<div id="markdown-mode">
  ### Mode Markdown
</div>

Modifiez le code source MDX.

* **Modification directe de MDX** : saisissez la syntaxe MDX et Markdown pour un contrôle précis du contenu.
* **Propriétés des composants** : définissez les propriétés et configurations des composants.
* **Frontmatter** : modifiez les métadonnées de la page en haut du fichier.

Voir [Mettre en forme le texte](/fr/create/text) et [Mettre en forme le code](/fr/create/code) pour plus d&#39;informations sur la syntaxe MDX.

<div id="configure-pages">
  ## Configurer les pages
</div>

Définissez les paramètres des pages pour contrôler la façon dont elles apparaissent dans la navigation, les résultats de recherche et la mise en page de votre site.

1. Faites un clic droit sur un fichier.
2. Cliquez sur **Configurer**.

<div id="customize-navigation-appearance">
  ### Personnaliser l&#39;apparence de la navigation
</div>

Contrôlez l&#39;apparence de la page dans la barre latérale de navigation de votre site.

* **Title**: Définissez le titre principal. Il apparaît dans la navigation, les onglets du navigateur et les résultats de recherche.
* **Sidebar title**: Affichez un texte plus court dans la navigation lorsque le titre complet est trop long pour la barre latérale.
* **Icon**: Ajoutez un repère visuel à côté de la page pour aider les utilisateurs à l’identifier rapidement.
* **External URL**: Créez un lien vers un site externe plutôt que vers une page. Utilisez cette option pour ajouter des ressources externes à votre navigation.

<div id="optimize-for-search-and-sharing">
  ### Optimisez pour la recherche et le partage
</div>

Aidez les utilisateurs à trouver votre page et améliorez son apparence lorsqu’elle est partagée.

* **Description** : Rédigez un court résumé. S’affiche dans les résultats de recherche et les balises méta SEO.
* **Keywords** : Ajoutez des termes de recherche pertinents pour aider les utilisateurs à découvrir cette page.
* **OG Image URL** : Définissez une image d’aperçu personnalisée pour les partages sur les réseaux sociaux et les aperçus de liens.

<div id="control-page-layout">
  ### Contrôler la mise en page
</div>

Choisissez comment la page s’affiche pour répondre à vos besoins en contenu.

* **Mise en page standard** (`default`) : Page par défaut avec barre de navigation latérale et table des matières.
* **Mise en page pleine largeur** (`wide`) : Masque la table des matières pour permettre des mises en page plus larges pour les tableaux, diagrammes ou autres contenus.
* **Mise en page centrée** (`center`) : Masque la barre latérale et la table des matières pour une meilleure lisibilité des pages riches en texte, comme les journaux de modifications.
* **Largeur personnalisée** (`custom`) : Mise en page minimale avec uniquement la barre de navigation supérieure pour les pages de destination ou d’autres mises en page spécifiques.

<div id="manage-pages">
  ## Gérer les pages
</div>

<div id="move-pages">
  ### Déplacer des pages
</div>

Faites glisser les pages pour les réorganiser dans votre navigation ou pour déplacer des fichiers entre dossiers dans l’arborescence de fichiers.

<div id="duplicate-pages">
  ### Dupliquer des pages
</div>

Cliquez avec le bouton droit sur une page, puis sélectionnez **Duplicate**.

<div id="delete-pages">
  ### Supprimer des pages
</div>

Cliquez avec le bouton droit sur une page et sélectionnez **Supprimer**. La suppression d’une page la retire automatiquement de la navigation.

<div id="hide-pages">
  ### Masquer des pages
</div>

Pour retirer une page de la navigation sans supprimer le fichier, cliquez avec le bouton droit sur la page et sélectionnez **Hide Page**. Le fichier reste présent dans votre dépôt et vous pouvez la réafficher en l’ajoutant à la navigation définie dans votre `docs.json`.
