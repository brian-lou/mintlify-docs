<div id="supported-file-types">
  ## Formats de fichiers pris en charge
</div>

- **Images** : PNG, JPG, JPEG, SVG, GIF, WebP
- **Vidéos** : MP4, WebM
- **Polices** : TTF, WOFF, WOFF2
- **Autres fichiers** : PDF, ICO (favicons)

<div id="add-media-to-a-page">
  ## Ajouter du contenu multimédia à une page
</div>

<div id="drag-and-drop">
  ### Glisser-déposer
</div>

Faites glisser et déposez des fichiers multimédias depuis votre ordinateur ou le gestionnaire de ressources dans une page en mode visuel. Les fichiers sont enregistrés à la racine de votre dossier `images/`.

<div id="slash-command">
  ### Commande slash
</div>

Saisissez <kbd>/image</kbd> pour ouvrir le menu d’images, puis téléversez une nouvelle image ou sélectionnez-en une existante.

<div id="upload-files">
  ### Importer des fichiers
</div>

Utilisez le gestionnaire de ressources dans le panneau latéral pour importer ou rechercher des fichiers.

<Frame>
  <img src="/images/editor/assets-light.png" alt="Gestionnaire de ressources sélectionné dans le menu du panneau latéral de l'éditeur." className="block dark:hidden" />
  <img src="/images/editor/assets-dark.png" alt="Gestionnaire de ressources sélectionné dans le menu du panneau latéral de l'éditeur." className="hidden dark:block" />
</Frame>

Cliquez sur **Upload** dans le gestionnaire de ressources pour ajouter des fichiers depuis votre ordinateur.

<div id="manage-assets">
  ## Gérer les ressources
</div>

<div id="organize-with-folders">
  ### Organiser avec des dossiers
</div>

Cliquez sur le bouton **+** de l’explorateur de fichiers pour créer un nouveau dossier. Faites glisser des fichiers et des dossiers dans l’arborescence de fichiers pour les réorganiser.

<div id="rename-and-edit-assets">
  ### Renommer et modifier des ressources
</div>

Survolez une ressource et cliquez sur le bouton **...** pour renommer le fichier ou mettre à jour son texte alternatif.

<div id="delete-assets">
  ### Supprimer des ressources
</div>

Placez le pointeur sur une ressource et cliquez sur le bouton <Icon icon="trash" /> Supprimer.

<div id="best-practices">
  ## Bonnes pratiques
</div>

- **Utilisez des noms explicites** : Nommez clairement vos fichiers, par exemple `api-dashboard-light.png` plutôt que `img1.png`.
- **Ajoutez un texte alternatif (alt text)** : Fournissez un texte alternatif descriptif pour l’accessibilité et le référencement (SEO).
- **Organisez à l’aide de dossiers** : Regroupez les ressources liées, comme les variantes en mode clair et sombre ou les ressources pour une zone fonctionnelle spécifique.
- **Utilisez des formats appropriés** : PNG pour les graphiques avec transparence, JPG pour les photos, SVG pour les icônes et les logos.
