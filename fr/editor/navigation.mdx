Utilisez la barre latérale de navigation pour organiser votre documentation. Les modifications que vous apportez dans l’arborescence de navigation de l’éditeur en ligne apparaissent dans la barre latérale de navigation de votre site et sont synchronisées avec votre fichier de configuration `docs.json`.

<div id="add-navigation-elements">
  ## Ajouter des éléments de navigation
</div>

Pour ajouter un nouvel élément de navigation, cliquez sur **Add new** en bas de l’arborescence de navigation.

<Frame>
  <img src="/images/editor/navigation-light.png" alt="Ajouter un nouvel élément de navigation." className="block dark:hidden" />

  <img src="/images/editor/navigation-dark.png" alt="Ajouter un nouvel élément de navigation." className="hidden dark:block" />
</Frame>

Pour ajouter un élément de navigation imbriqué dans un autre élément, cliquez sur le bouton **+** à côté du nom de l’élément parent.

Après avoir créé un élément, faites-le glisser pour le réorganiser ou l’imbriquer dans d’autres éléments. Cliquez avec le bouton droit sur n’importe quel élément pour configurer ses propriétés, le dupliquer, le masquer dans la navigation ou le supprimer.

<Note>
  Certains éléments ne peuvent pas être imbriqués dans d’autres éléments. Par exemple, les onglets ne peuvent pas être imbriqués dans des groupes. L’éditeur en ligne vous empêche d’imbriquer des éléments non valides.
</Note>

<div id="add-existing-files">
  ### Ajouter des fichiers existants
</div>

Ajoutez des fichiers de votre dépôt qui ne figurent pas encore dans la navigation.

1. Cliquez sur le bouton plus <Icon icon="plus" /> à l’endroit où vous souhaitez ajouter le fichier.
2. Cliquez sur **Ajouter un fichier existant**.

<div id="organize-into-sections">
  ## Organiser par sections
</div>

Choisissez la structure de navigation la plus adaptée à la portée et au public de votre documentation.

<div id="when-to-use-pages">
  ### Quand utiliser des pages
</div>

Utilisez des pages pour les fichiers de documentation individuels. Les pages sont les éléments fondamentaux de votre navigation : tout contenu se trouve sur une page. Ajoutez des pages à votre navigation pour les rendre visibles dans la barre latérale de votre site.

Les pages peuvent exister à la racine, au sein de groupes, d&#39;onglets, d&#39;ancres, de menus déroulants ou de menus.

Les fichiers qui ne sont pas inclus dans votre navigation sont [cachés](/fr/organize/hidden-pages) de votre documentation publiée.

<div id="when-to-use-groups">
  ### Quand utiliser les groupes
</div>

Utilisez des groupes pour organiser des pages connexes en sections repliables. Les groupes aident les utilisateurs à parcourir la navigation en regroupant du contenu similaire, par exemple en rassemblant toutes les pages liées à l’authentification ou toutes les références de points de terminaison d’API.

Les groupes peuvent être imbriqués dans d’autres groupes pour créer une organisation hiérarchique. Les groupes peuvent exister dans des onglets, des ancres, des menus déroulants ou à la racine.

<div id="when-to-use-tabs">
  ### Quand utiliser des onglets
</div>

Utilisez des onglets pour créer des sections principales distinctes avec une navigation horizontale en haut de votre site. Les onglets sont particulièrement adaptés lorsque vous avez des rubriques distinctes comme Référence d’API, Guides et SDK, entre lesquelles les utilisateurs doivent basculer.

Les onglets peuvent contenir des pages, des groupes et des éléments de menu. Vous pouvez configurer les onglets pour ajouter des icônes ou créer des liens vers des ressources externes.

<div id="when-to-use-anchors">
  ### Quand utiliser des ancres
</div>

Utilisez des ancres pour créer des éléments de navigation persistants en haut de votre barre latérale. Les ancres sont utiles lorsque vous souhaitez structurer votre contenu en sections ou fournir un accès rapide à des ressources externes sans passer d’onglet.

Les ancres peuvent contenir des pages et des groupes, ou pointer vers des URL externes.

**Ancres globales :**

Créez des ancres globales qui apparaissent sur toutes les pages, quelle que soit la section que les utilisateurs consultent. Les ancres globales doivent pointer vers des URL externes et sont utiles pour des ressources comme des blogs, des pages de statut ou des liens d’assistance.

<div id="when-to-use-dropdowns">
  ### Quand utiliser les menus déroulants
</div>

Utilisez des menus déroulants pour créer un menu dépliable en haut de votre barre latérale. Les menus déroulants sont particulièrement adaptés lorsque vous avez plusieurs sections connexes que les utilisateurs peuvent vouloir explorer, sans pour autant devoir rester visibles en permanence comme des onglets.

Les menus déroulants peuvent contenir des pages et des groupes, ou pointer vers des URL externes.

<div id="when-to-use-menus">
  ### Quand utiliser les menus
</div>

Utilisez les menus pour ajouter, dans un onglet, des éléments de navigation sous forme de menus déroulants. Les menus permettent aux utilisateurs d’accéder directement à des pages spécifiques depuis la barre de navigation principale.

Les menus peuvent contenir des pages et des groupes.

<div id="when-to-use-products">
  ### Quand utiliser les produits
</div>

Utilisez les produits lorsque vous avez plusieurs offres de produits distinctes qui nécessitent chacune leur propre documentation. Les produits créent un sélecteur qui permet aux utilisateurs de naviguer entre différents ensembles de documentation produit.

Chaque produit peut avoir sa propre structure de navigation avec des onglets, des pages et des groupes.

<div id="when-to-use-versions">
  ### Quand utiliser les versions
</div>

Utilisez des versions lorsque vous gérez simultanément plusieurs versions de votre documentation, comme les versions v1.0, v2.0 et v3.0 d&#39;une API. Les versions ajoutent un sélecteur qui permet aux utilisateurs de choisir la version qu&#39;ils souhaitent consulter.

Chaque version peut avoir un contenu et une structure de navigation différents.

<div id="when-to-use-languages">
  ### Quand utiliser les langues
</div>

Utilisez la fonctionnalité de langues lorsque vous fournissez une documentation en plusieurs langues. Les langues ajoutent un sélecteur qui permet aux utilisateurs d’afficher la documentation dans leur langue préférée.

Chaque langue conserve la même structure de navigation, avec son contenu traduit.

<div id="customize-appearance">
  ## Personnaliser l&#39;apparence
</div>

**Ajouter des icônes :**

1. Cliquez avec le bouton droit sur un élément de navigation.
2. Cliquez sur **Configure**.
3. Cliquez sur le champ d’icône.

**Ajouter des tags :**

1. Cliquez avec le bouton droit sur un élément de navigation.
2. Cliquez sur **Configure**.
3. Cliquez sur le champ de tag.
4. Saisissez un tag comme &quot;NEW&quot; ou &quot;BETA&quot; pour mettre en avant des éléments importants.

**Contrôler la visibilité :**

Masquez le contenu au sein d’un élément de navigation sans le supprimer de votre dépôt.

1. Cliquez avec le bouton droit sur n’importe quel élément.
2. Cliquez sur le commutateur à côté du libellé **Hide**.
