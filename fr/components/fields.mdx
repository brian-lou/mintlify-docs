Utilisez des champs pour documenter les paramètres et les réponses de l’API. Il existe deux types de champs : les champs de paramètres et les champs de réponse.

<div id="parameter-field">
  ## Champ de paramètre
</div>

Le composant `<ParamField>` est utilisé pour définir les paramètres de vos API ou SDK. L’ajout d’un `ParamField` crée automatiquement un [API Playground](/fr/api-playground/overview).

<ParamField path="param" type="string" required>
  Un exemple de champ de paramètre
</ParamField>

```mdx
<ParamField path="param" type="string" required>
  Un exemple de champ de paramètre
</ParamField>
```

<div id="properties">
  ### Propriétés
</div>

<ParamField body="query, path, body, ou header" type="string">
  Indique s’il s’agit d’un paramètre de requête (query), de chemin (path), de corps (body) ou d’en-tête (header). Suivi du
  nom du paramètre.
</ParamField>

<ParamField body="type" type="string">
  Type attendu de la valeur du paramètre.

  Prend en charge `number`, `string`, `boolean`, `object`.

  Les tableaux peuvent être définis à l’aide du suffixe `[]`. Par exemple `string[]`.
</ParamField>

<ParamField body="required" type="boolean">
  Indique si le paramètre est obligatoire.
</ParamField>

<ParamField body="deprecated" type="boolean">
  Indique si le paramètre est obsolète.
</ParamField>

<ParamField body="default" type="any">
  Valeur par défaut appliquée lorsque la valeur dans la requête est vide.
</ParamField>

<ParamField body="placeholder" type="string">
  Texte indicatif affiché dans le champ de saisie du playground.
</ParamField>

<ParamField body="children" type="string">
  Description du paramètre (compatible Markdown).
</ParamField>

<div id="response-field">
  ## Champ de réponse
</div>

Le composant `<ResponseField>` définit les valeurs renvoyées par une API.

<ResponseField name="response" type="string" required>
  Un exemple de champ de réponse
</ResponseField>

```mdx
<ResponseField name="response" type="string" required>
  A response field example
</ResponseField>
```

<div id="properties">
  ### Propriétés
</div>

<ResponseField name="name" type="string" required>
  Le nom de la valeur de la réponse.
</ResponseField>

<ResponseField name="type" type="string" required>
  Type attendu de la valeur de la réponse. Il peut s’agir de n’importe quelle chaîne de caractères.
</ResponseField>

<ResponseField name="default" type="string">
  La valeur par défaut.
</ResponseField>

<ResponseField name="required" type="boolean">
  Indique si la réponse est requise.
</ResponseField>

<ResponseField name="deprecated" type="boolean">
  Indique si le champ est obsolète.
</ResponseField>

<ResponseField name="pre" type="string[]">
  Libellés affichés avant le nom du champ.
</ResponseField>

<ResponseField name="post" type="string[]">
  Libellés affichés après le nom du champ.
</ResponseField>
