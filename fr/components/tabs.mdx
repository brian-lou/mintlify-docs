Utilisez des onglets pour organiser le contenu en plusieurs panneaux entre lesquels les utilisateurs peuvent basculer. Vous pouvez ajouter autant d’onglets que vous le souhaitez et inclure d’autres composants dans chaque onglet.

<Tabs>
  <Tab title="Premier onglet">
    ☝️ Bienvenue dans le contenu visible uniquement dans le premier onglet.

    Vous pouvez ajouter autant de composants que vous le souhaitez dans les onglets. Par exemple, un bloc de code :

    ```java HelloWorld.java
      class HelloWorld {
          public static void main(String[] args) {
              System.out.println("Hello, World!");
          }
      }
    ```
  </Tab>

  <Tab title="Deuxième onglet" icon="leaf">
    ✌️ Voici le contenu affiché uniquement dans le deuxième onglet.

    Celui-ci comporte une icône <Icon icon="leaf" /> !
  </Tab>

  <Tab title="Troisième onglet">
    💪 Voici le contenu affiché uniquement dans le troisième onglet.
  </Tab>
</Tabs>

````mdx Tabs example
<Tabs>
  <Tab title="First tab">
    ☝️ Bienvenue dans le contenu visible uniquement dans le premier onglet.

    Vous pouvez ajouter autant de composants que vous le souhaitez dans les onglets. Par exemple, un bloc de code :
    ```java HelloWorld.java
      class HelloWorld {
          public static void main(String[] args) {
              System.out.println("Hello, World!");
          }
      }
    ```
  </Tab>
  <Tab title="Second tab" icon="leaf">
    ✌️ Voici le contenu visible uniquement dans le deuxième onglet.

    Celui-ci possède une icône <Icon icon="leaf" /> !
  </Tab>
  <Tab title="Third tab">
    💪 Voici le contenu visible uniquement dans le troisième onglet.
  </Tab>
</Tabs>
````

Les onglets dont les titres correspondent restent synchronisés sur toute la page. Par exemple, si vous avez plusieurs groupes d’onglets contenant un onglet intitulé `JavaScript`, sélectionner `JavaScript` dans l’un d’eux le sélectionne automatiquement dans les autres. Ainsi, lorsqu’un utilisateur choisit une langue ou un framework une fois, ce choix est répercuté partout. Les onglets se synchronisent aussi avec les [groupes de code](/fr/components/code-groups) dont les titres correspondent.

Pour désactiver la synchronisation des onglets, ajoutez `sync={false}` à un composant `<Tabs>`.

```mdx Disable tab sync example
<Tabs sync={false}>
  <Tab title="First tab">
    Ce groupe d'onglets fonctionne de manière indépendante.
  </Tab>
  <Tab title="Second tab">
    La sélection d'onglets ici n'affectera pas les autres groupes d'onglets.
  </Tab>
</Tabs>
```

<div id="properties">
  ## Propriétés
</div>

<ResponseField name="title" type="string" required>
  Le titre de l’onglet. Les titres courts sont plus faciles à parcourir. Les onglets dont les titres correspondent synchronisent leur sélection.
</ResponseField>

<ResponseField name="icon" type="string">
  Une icône [Font Awesome](https://fontawesome.com/icons), une icône [Lucide](https://lucide.dev/icons), une URL d’icône ou un chemin relatif vers une icône.
</ResponseField>

<ResponseField name="iconType" type="string">
  Uniquement pour les icônes Font Awesome : une des valeurs suivantes : `regular`, `solid`, `light`, `thin`, `sharp-solid`, `duotone`, `brands`.
</ResponseField>

<ResponseField name="sync" type="boolean" default="true">
  Lorsque `true`, les onglets se synchronisent avec les autres onglets et groupes de code de la page dont les titres correspondent. Définissez `false` pour rendre les onglets indépendants.
</ResponseField>

<ResponseField name="borderBottom" type="boolean">
  Ajoute une bordure inférieure et un espacement interne au conteneur des onglets. Utile pour séparer visuellement le contenu à onglets du reste de la page, en particulier lorsque les onglets contiennent du contenu de longueur variable.
</ResponseField>
