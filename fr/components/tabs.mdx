Utilisez des onglets pour organiser le contenu en plusieurs panneaux entre lesquels les utilisateurs peuvent basculer. Vous pouvez ajouter autant d’onglets que vous le souhaitez et inclure d’autres composants dans chaque onglet.

<Tabs>
  <Tab title="Premier onglet">
    ☝️ Bienvenue dans le contenu que vous pouvez voir uniquement dans le premier onglet.

    Vous pouvez ajouter autant de composants que vous le souhaitez dans des onglets. Par exemple, un bloc de code :

    ```java HelloWorld.java
      class HelloWorld {
          public static void main(String[] args) {
              System.out.println("Hello, World!");
          }
      }
    ```
  </Tab>

  <Tab title="Deuxième onglet" icon="leaf">
    ✌️ Voici du contenu qui se trouve uniquement dans le deuxième onglet.

    Celui-ci a une icône <Icon icon="leaf" /> !
  </Tab>

  <Tab title="Troisième onglet">
    💪 Voici du contenu qui se trouve uniquement dans le troisième onglet.
  </Tab>
</Tabs>

````mdx Tabs example
<Tabs>
  <Tab title="First tab">
    ☝️ Bienvenue dans le contenu visible uniquement dans le premier onglet.

    Vous pouvez ajouter autant de composants que vous le souhaitez dans les onglets. Par exemple, un bloc de code :
    ```java HelloWorld.java
      class HelloWorld {
          public static void main(String[] args) {
              System.out.println("Hello, World!");
          }
      }
    ```
  </Tab>
  <Tab title="Second tab" icon="leaf">
    ✌️ Voici le contenu visible uniquement dans le deuxième onglet.

    Celui-ci a une icône <Icon icon="leaf" /> !
  </Tab>
  <Tab title="Third tab">
    💪 Voici le contenu visible uniquement dans le troisième onglet.
  </Tab>
</Tabs>
````

Les onglets portant des titres identiques restent synchronisés sur toute la page. Par exemple, si vous avez plusieurs groupes d’onglets qui incluent un onglet intitulé `JavaScript`, si vous sélectionnez `JavaScript` dans un groupe d’onglets, `JavaScript` est automatiquement sélectionné dans les autres. Cela permet aux utilisateurs de choisir un langage ou un framework une seule fois et de voir ce choix reflété partout. Les onglets se synchronisent également avec les [groupes de code](/fr/components/code-groups) qui ont des titres correspondants.

Pour désactiver la synchronisation des onglets, ajoutez `sync={false}` à un composant `<Tabs>`.

```mdx Disable tab sync example
<Tabs sync={false}>
  <Tab title="First tab">
    This tab group operates independently.
  </Tab>
  <Tab title="Second tab">
    Selecting tabs here won't affect other tab groups.
  </Tab>
</Tabs>
```

<div id="properties">
  ## Propriétés
</div>

<ResponseField name="title" type="string" required>
  Le titre de l’onglet. Les titres courts sont plus faciles à parcourir. Les onglets ayant des titres identiques synchronisent leurs sélections.
</ResponseField>

<ResponseField name="icon" type="string">
  Une icône [Font Awesome](https://fontawesome.com/icons), une icône [Lucide](https://lucide.dev/icons), une URL pointant vers une icône ou un chemin relatif vers une icône.
</ResponseField>

<ResponseField name="iconType" type="string">
  Pour les icônes Font Awesome uniquement : l’une de `regular`, `solid`, `light`, `thin`, `sharp-solid`, `duotone`, `brands`.
</ResponseField>

<ResponseField name="sync" type="boolean" default="true">
  Lorsque `true`, les onglets se synchronisent avec les autres onglets et groupes de code de la page qui ont des titres identiques. Réglez sur `false` pour rendre les onglets indépendants.
</ResponseField>

<ResponseField name="borderBottom" type="boolean">
  Ajoute une bordure inférieure et un padding au conteneur des onglets. Utile pour séparer visuellement le contenu à onglets du reste de la page, en particulier lorsque les onglets contiennent des contenus de longueurs variables.
</ResponseField>
