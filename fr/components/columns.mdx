Le composant `Columns` vous permet de regrouper plusieurs composants `Card` ensemble. Il est le plus souvent utilisé pour disposer des cartes dans une grille, en spécifiant le nombre de colonnes. Les colonnes sont adaptatives et s’ajustent automatiquement aux petits écrans.

<Columns cols={2}>
  <Card title="Premiers pas" icon="rocket">
    Configurez votre projet avec notre guide de démarrage rapide.
  </Card>

  <Card title="Référence de l’API" icon="code">
    Découvrez les endpoints, les paramètres et des exemples pour votre API.
  </Card>
</Columns>

```mdx Columns example
<Columns cols={2}>
  <Card title="Get started">
    Set up your project with our quickstart guide.
  </Card>
  <Card title="API reference">
    Explore endpoints, parameters, and examples for your API.
  </Card>
</Columns>
```


<div id="properties">
  ## Propriétés
</div>

<ResponseField name="cols" type="number" default={2}>
  Le nombre de colonnes par ligne. Accepte des valeurs comprises entre 1 et 4.
</ResponseField>
