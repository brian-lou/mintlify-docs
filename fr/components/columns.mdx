Le composant `Columns` vous permet de regrouper plusieurs composants `Card`. Il sert le plus souvent à afficher des cartes dans une grille, en précisant le nombre de colonnes. Les colonnes s’adaptent automatiquement aux écrans plus petits.

<Columns cols={2}>
  <Card title="Premiers pas" icon="rocket">
    Configurez votre projet à l’aide de notre guide de démarrage rapide.
  </Card>

  <Card title="Référence API" icon="code">
    Explorez les endpoints, les paramètres et les exemples de votre API.
  </Card>
</Columns>

```mdx Columns example
<Columns cols={2}>
  <Card title="Get started">
    Set up your project with our quickstart guide.
  </Card>
  <Card title="API reference">
    Explore endpoints, parameters, and examples for your API.
  </Card>
</Columns>
```


<div id="properties">
  ## Propriétés
</div>

<ResponseField name="cols" type="number" default={2}>
  Nombre de colonnes par ligne. Valeurs acceptées : de 1 à 4.
</ResponseField>
