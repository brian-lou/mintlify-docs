<div id="inline-icons">
  ## Icônes en ligne
</div>

Les icônes sont intégrées au texte lorsqu&#39;elles sont utilisées dans une phrase, un paragraphe ou un titre. <Icon icon="flag" iconType="solid" /> Utilisez des icônes à des fins décoratives ou pour renforcer l&#39;accent visuel.

```markdown Inline icon example
Les icônes sont placées en ligne lorsqu'elles sont utilisées dans une phrase, un paragraphe ou un titre. <Icon icon="flag" iconType="solid" /> Utilisez les icônes à des fins décoratives ou pour ajouter une mise en valeur visuelle.
```


<div id="properties">
  ## Propriétés
</div>

<IconsRequired />

<ResponseField name="color" type="string">
  La couleur de l’icône sous forme de code hexadécimal (par exemple&nbsp;: `#FF5733`).
</ResponseField>

<ResponseField name="size" type="number">
  La taille de l’icône en pixels.
</ResponseField>

<ResponseField name="className" type="string">
  Le nom d’une classe CSS personnalisée à appliquer à l’icône.
</ResponseField>
