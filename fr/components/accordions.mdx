Les accordéons permettent aux utilisateurs de développer et de réduire des sections de contenu. Utilisez les accordéons pour révéler progressivement les informations et les organiser.


<div id="single-accordion">
  ## Accordéon simple
</div>

<Accordion title="Je suis un accordéon.">
  Vous pouvez mettre n’importe quel contenu ici, y compris d’autres composants, comme du code :

  ```java HelloWorld.java
   class HelloWorld {
       public static void main(String[] args) {
           System.out.println("Hello, World!");
       }
   }
  ```
</Accordion>

<div id="accordion-groups">
  ## Groupes d’accordéons
</div>

Regroupez des accordéons associés à l’aide de `<AccordionGroup>`. Cela crée une section cohérente d’accordéons qui peuvent être ouverts ou fermés individuellement.

<AccordionGroup>
  <Accordion title="Premiers pas">
    Vous pouvez placer d’autres composants dans des accordéons.

    ```java HelloWorld.java
    class HelloWorld {
        public static void main(String[] args) {
            System.out.println("Hello, World!");
        }
    }
    ```
  </Accordion>

  <Accordion title="Fonctionnalités avancées" icon="bot">
    Ajoutez des icônes pour rendre les accordéons plus faciles à distinguer et à parcourir.
  </Accordion>

  <Accordion title="Dépannage">
    Organisez le contenu connexe en groupes.
  </Accordion>
</AccordionGroup>

````mdx Accordion Group Example
<AccordionGroup>
  <Accordion title="Premiers pas">
    Vous pouvez placer d'autres composants à l'intérieur des accordéons.

    ```java HelloWorld.java

        public static void main(String[] args) {
            System.out.println("Hello, World!");
        }
    }
    ```
  </Accordion>

  <Accordion title="Fonctionnalités avancées" icon="alien-8bit">

  </Accordion>

  <Accordion title="Résolution des problèmes">
    Organisez le contenu connexe en groupes.
  </Accordion>
</AccordionGroup>
````


<div id="properties">
  ## Propriétés
</div>

<ResponseField name="title" type="string" required>
  Titre dans l’aperçu de l’accordéon.
</ResponseField>

<ResponseField name="description" type="string">
  Description affichée sous le titre dans l’aperçu de l’accordéon.
</ResponseField>

<ResponseField name="defaultOpen" type="boolean" default="false">
  Indique si l’accordéon est ouvert par défaut.
</ResponseField>
