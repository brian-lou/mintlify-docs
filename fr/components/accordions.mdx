Les accordéons permettent aux utilisateurs de développer et réduire des sections de contenu. Utilisez les accordéons pour dévoiler progressivement les informations et organiser le contenu.


<div id="single-accordion">
  ## Accordéon simple
</div>

<Accordion title="Je suis un accordéon.">
  Vous pouvez mettre tout type de contenu ici, y compris d&#39;autres composants, comme du code :

  ```java HelloWorld.java
   class HelloWorld {
       public static void main(String[] args) {
           System.out.println("Hello, World!");
       }
   }
  ```
</Accordion>

<div id="accordion-groups">
  ## Groupes d’accordéons
</div>

Regroupez les accordéons associés à l’aide de `<AccordionGroup>`. Cela crée une section cohérente d’accordéons qui peuvent être dépliés ou repliés individuellement.

<AccordionGroup>
  <Accordion title="Pour commencer">
    Vous pouvez placer d’autres composants à l’intérieur des accordéons.

    ```java HelloWorld.java
    class HelloWorld {
        public static void main(String[] args) {
            System.out.println("Hello, World!");
        }
    }
    ```
  </Accordion>

  <Accordion title="Fonctionnalités avancées" icon="bot">
    Ajoutez des icônes pour rendre les accordéons visuellement plus distincts et plus faciles à parcourir.
  </Accordion>

  <Accordion title="Dépannage">
    Conservez les contenus liés bien organisés par groupes.
  </Accordion>
</AccordionGroup>

````mdx Accordion Group Example
<AccordionGroup>
  <Accordion title="Getting started">
    You can put other components inside Accordions.

    ```java HelloWorld.java
    class HelloWorld {
        public static void main(String[] args) {
            System.out.println("Hello, World!");
        }
    }
    ```
  </Accordion>

  <Accordion title="Advanced features" icon="alien-8bit">
    Add icons to make accordions more visually distinct and scannable.
  </Accordion>

  <Accordion title="Troubleshooting">
    Keep related content organized into groups.
  </Accordion>
</AccordionGroup>
````


<div id="properties">
  ## Propriétés
</div>

<ResponseField name="title" type="string" required>
  Titre affiché dans l’aperçu de l’accordéon.
</ResponseField>

<ResponseField name="description" type="string">
  Texte affiché sous le titre dans l’aperçu de l’accordéon.
</ResponseField>

<ResponseField name="defaultOpen" type="boolean" default="false">
  Indique si l’accordéon est ouvert par défaut.
</ResponseField>
