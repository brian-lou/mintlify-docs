Utilisez le composant `Update` pour afficher les entrées du journal des modifications, les mises à jour de version et les notes de version avec une mise en forme cohérente.

<Update label="Exemple" description="v0.1.1">
  ## Exemple de mise à jour

  Vous pouvez ajouter n’importe quel contenu ici, comme une capture d’écran, un extrait de code ou une liste de modifications.

  <Frame>
    <img className="block" src="https://mintlify-assets.b-cdn.net/hero-light.png" alt="Capture d’écran de la page d’introduction de PearsDB, utilisée ici comme exemple d’image dans un composant Update." />
  </Frame>

  ### Fonctionnalités

  * Design responsive
  * Une ancre pour chaque mise à jour
  * Une entrée de flux RSS générée pour chaque mise à jour
</Update>

<div id="how-to-use">
  ## Utilisation
</div>

```mdx Update example
<Update label="2024-10-11" description="v0.1.0" tags={["Mintlify"]}>
  This is an update with a label, description, and tag.
</Update>
```

Utilisez plusieurs composants `Update` pour créer des [journaux des modifications](/fr/create/changelogs).

Les composants Update génèrent automatiquement des entrées de flux RSS. Ces entrées ne contiennent que du Markdown pur : les composants, les blocs de code, le code en ligne et les éléments HTML bruts ne sont pas inclus.

Si votre mise à jour comprend des composants ou du HTML, utilisez la prop `rss` pour fournir un texte alternatif aux abonnés RSS.

```mdx Custom RSS content
<Update
  label="March 2025"
  description="v2.0.0"
  rss={{
    title: "March 2025 - Major redesign",
    description: "Complete UI overhaul with new components"
  }}
>
  ## New dashboard

  <Frame>
    <img src="/dashboard.png" alt="New dashboard UI displaying updated components." />
  </Frame>

  Check out our redesigned dashboard with improved navigation.
</Update>
```

<div id="props">
  ## Propriétés
</div>

<ResponseField name="label" type="string" required>
  Libellé de la Update. Il apparaît à gauche de la Update et crée un lien d’ancrage. Les libellés doivent être uniques.
</ResponseField>

<ResponseField name="tags" type="string[]">
  Tags de la Update. Ils s’affichent comme filtres dans le panneau latéral droit.
</ResponseField>

<ResponseField name="description" type="string">
  Description de la Update. Elle apparaît sous le libellé et les tags.
</ResponseField>

<ResponseField name="rss" type="object">
  Les composants de Update génèrent automatiquement des entrées de flux RSS. Utilisez la propriété `rss` pour créer une seule entrée de flux RSS avec un titre et une description personnalisés.

  Si elle n’est pas fournie :

  * Les Updates avec des titres Markdown créent une entrée de flux RSS distincte pour chaque titre.
  * Les Updates sans titres Markdown créent une seule entrée de flux RSS en utilisant `label` comme titre.

  <Expandable title="propriétés">
    <ResponseField name="title" type="string">
      Titre personnalisé pour l’entrée de flux RSS.
    </ResponseField>

    <ResponseField name="description" type="string">
      Description personnalisée pour l’entrée de flux RSS.
    </ResponseField>
  </Expandable>
</ResponseField>
