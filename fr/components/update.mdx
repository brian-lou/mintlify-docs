Utilisez le composant `Update` pour afficher les entrées de journal des modifications, les mises à jour de version et les notes de version avec une mise en forme cohérente.

<Update label="Exemple" description="v0.1.1">
  ## Exemple de mise à jour

  Vous pouvez ajouter ici tout ce que vous voulez, comme une capture d’écran, un extrait de code ou une liste des modifications.

  <Frame>
    <img className="block" src="https://mintlify-assets.b-cdn.net/hero-light.png" alt="Capture d’écran de la page d’introduction de PearsDB, en exemple d’image dans un composant Update." />
  </Frame>

  ### Fonctionnalités

  * Design adaptatif (responsive)
  * Ancre pour chaque mise à jour
  * Entrée de flux RSS générée pour chaque mise à jour
</Update>

<div id="how-to-use">
  ## Utilisation
</div>

```mdx Update example
<Update label="2024-10-11" description="v0.1.0" tags={["Mintlify"]}>
  This is an update with a label, description, and tag.
</Update>
```

Utilisez plusieurs composants `Update` pour créer des [journaux de modifications](/fr/create/changelogs).

Les composants `Update` génèrent automatiquement des entrées de flux RSS. Les entrées contiennent uniquement du Markdown pur : les composants, les blocs de code, le code en ligne et les éléments HTML bruts ne sont pas inclus.

Si votre mise à jour inclut des composants ou du HTML, utilisez la prop `rss` pour fournir un texte alternatif aux abonnés RSS.

```mdx Custom RSS content
<Update
  label="March 2025"
  description="v2.0.0"
  rss={{
    title: "Mars 2025 - Refonte majeure",
    description: "Refonte complète de l'interface avec de nouveaux composants"
  }}
>
  ## Nouveau tableau de bord

  <Frame>
    <img src="/dashboard.png" alt="Nouvelle interface du tableau de bord affichant les composants mis à jour." />
  </Frame>

  Découvrez notre tableau de bord repensé avec une navigation améliorée.
</Update>
```

<div id="props">
  ## Props
</div>

<ResponseField name="label" type="string" required>
  Libellé de la mise à jour. Apparaît à gauche de la mise à jour et crée un lien d’ancrage. Les libellés doivent être uniques.
</ResponseField>

<ResponseField name="tags" type="string[]">
  Tags de la mise à jour. Affichés comme filtres dans le panneau latéral droit.
</ResponseField>

<ResponseField name="description" type="string">
  Description de la mise à jour. Apparaît sous le libellé et les tags.
</ResponseField>

<ResponseField name="rss" type="object">
  Les composants de mise à jour génèrent automatiquement des entrées dans le flux RSS. Utilisez la propriété `rss` pour créer une seule entrée de flux RSS avec un titre et une description personnalisés.

  Si elle n’est pas définie :

  * Les mises à jour avec des en-têtes Markdown créent une entrée de flux RSS distincte pour chaque en-tête.
  * Les mises à jour sans en-têtes Markdown créent une seule entrée de flux RSS en utilisant le `label` comme titre.

  <Expandable title="properties">
    <ResponseField name="title" type="string">
      Titre personnalisé pour l’entrée du flux RSS.
    </ResponseField>

    <ResponseField name="description" type="string">
      Description personnalisée pour l’entrée du flux RSS.
    </ResponseField>
  </Expandable>
</ResponseField>
