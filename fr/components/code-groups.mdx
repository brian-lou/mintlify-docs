Utilisez le composant `CodeGroup` pour afficher plusieurs blocs de code dans une interface à onglets, afin de permettre aux utilisateurs de comparer des implémentations dans différents langages de programmation ou d&#39;examiner des approches alternatives pour une même tâche.

<CodeGroup>
  ```javascript helloWorld.js
  console.log("Hello World");
  ```

  ```python hello_world.py
  print('Hello World!')
  ```

  ```java HelloWorld.java
  class HelloWorld {
      public static void main(String[] args) {
          System.out.println("Hello, World!");
      }
  }
  ```
</CodeGroup>

Les groupes de code héritent du style global de votre fichier `docs.json`. Personnalisez votre thème à l&#39;aide de `styling.codeblocks`. Consultez [Paramètres](/fr/organize/settings#styling) pour les options de configuration.

Les groupes de code se synchronisent automatiquement avec d&#39;autres groupes de code et [onglets](/fr/components/tabs) sur la même page lorsque leurs libellés correspondent. Lorsque vous sélectionnez un langage dans un groupe de code, tous les onglets et groupes de code portant des libellés correspondants sont mis à jour pour afficher le même langage.

<div id="create-code-groups">
  ## Créer des groupes de code
</div>

Pour créer un groupe de code, entourez plusieurs blocs de code avec des balises `<CodeGroup>`. Chaque bloc de code doit inclure un titre, qui devient le libellé de l’onglet.

````mdx
<CodeGroup>

```javascript helloWorld.js
console.log("Hello World");
```

```python hello_world.py
print('Hello World!')
```

```java HelloWorld.java
class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

</CodeGroup>
````

<div id="language-dropdown">
  ## Menu déroulant de langue
</div>

Vous pouvez remplacer les onglets d’un groupe de code par un menu déroulant pour basculer entre les langues en utilisant la propriété `dropdown`.

</CodeGroup>
