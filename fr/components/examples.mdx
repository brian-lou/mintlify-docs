Les composants `<RequestExample>` et `<ResponseExample>` affichent des blocs de code dans la barre latérale droite afin de créer une mise en page en deux colonnes qui garde les exemples visibles pendant que les utilisateurs font défiler votre contenu. Ces composants sont conçus pour la documentation d’API, mais ils fonctionnent sur toutes les pages.

Cas d’utilisation courants :

* Documentation d’endpoints d’API avec exemples de requête et de réponse
* Exemples de configuration à côté du texte explicatif
* Exemples de code auxquels les utilisateurs se réfèrent en suivant les instructions
* Exemples avant/après dans les tutoriels

Sur les appareils mobiles, les composants `<RequestExample>` et `<ResponseExample>` s’affichent comme des blocs de code classiques que les utilisateurs peuvent faire défiler.

<RequestExample>
  ```bash Request
  curl --request POST \
    --url https://dog-api.kinduff.com/api/facts
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  { "status": "success" }
  ```
</ResponseExample>

<div id="requestexample">
  ## RequestExample
</div>

Utilisez `<RequestExample>` pour épingler des exemples de code dans la barre latérale droite. Ce composant fonctionne de manière similaire au composant [CodeGroup](/fr/components/code-groups), mais affiche le code dans la barre latérale au lieu de l&#39;afficher en ligne.

Vous pouvez inclure plusieurs blocs de code dans un seul `<RequestExample>`. Chaque bloc de code doit avoir un attribut `title`.

````mdx RequestExample
<RequestExample>

```bash Request
curl --request POST \
  --url https://dog-api.kinduff.com/api/facts
```

</RequestExample>
````

<div id="responseexample">
  ## ResponseExample
</div>

Le composant `<ResponseExample>` fixe les exemples de code dans la barre latérale droite, sous tout contenu `<RequestExample>` présent sur la même page.

````mdx ResponseExample
<ResponseExample>

```json Response
{ "status": "success" }
```

</ResponseExample>
````
