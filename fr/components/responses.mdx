---
title: "Champs de réponse"
description: "Affiche les valeurs de réponse de l’API."
keywords: ["sortie API", "valeurs de retour", "structure de réponse"]
---

Le composant `<ResponseField>` est conçu pour définir les valeurs renvoyées par une API. Dans de nombreuses documentations, `<ResponseField>` est aussi utilisé sur certaines pages pour lister les types d’un élément.

<ResponseField name="response" type="string" required>
  Exemple de champ de réponse
</ResponseField>

```mdx
<ResponseField name="response" type="string" required>
  Un exemple de champ de réponse
</ResponseField>
```


<div id="props">
  ## Props
</div>

<ResponseField name="name" type="string" required>
  Le nom de la valeur de réponse.
</ResponseField>

<ResponseField name="type" type="string" required>
  Type attendu de la valeur de réponse : il peut s’agir de n’importe quelle chaîne.
</ResponseField>

<ResponseField name="default" type="string">
  La valeur par défaut.
</ResponseField>

<ResponseField name="required" type="boolean">
  Affiche &quot;required&quot; à côté du nom du champ.
</ResponseField>

<ResponseField name="deprecated" type="boolean">
  Indique si un champ est déprécié ou non.
</ResponseField>

<ResponseField name="pre" type="string[]">
  Libellés affichés avant le nom du champ
</ResponseField>

<ResponseField name="post" type="string[]">
  Libellés affichés après le nom du champ
</ResponseField>

  ```mdx Exemple de champ de réponse

  </ResponseField>
  ```
</RequestExample>
