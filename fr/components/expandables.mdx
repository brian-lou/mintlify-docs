Utilisez des éléments extensibles pour afficher ou masquer le contenu imbriqué à l’intérieur des champs de réponse. Ils sont particulièrement utiles pour présenter les propriétés d’objets complexes dans la documentation d’API.

<ResponseField name="user" type="User Object">
  <Expandable title="propriétés">
    <ResponseField name="full_name" type="string">
      Le nom complet de l’utilisateur
    </ResponseField>

    <ResponseField name="is_over_21" type="boolean">
      Indique si l’utilisateur a plus de 21 ans
    </ResponseField>
  </Expandable>
</ResponseField>

```mdx Expandable example
<ResponseField name="user" type="User Object">
  <Expandable title="properties">
    <ResponseField name="full_name" type="string">
      Le nom complet de l'utilisateur
    </ResponseField>

    <ResponseField name="is_over_21" type="boolean">
      Si l'utilisateur a plus de 21 ans
    </ResponseField>
  </Expandable>
</ResponseField>
```


<div id="properties">
  ## Propriétés
</div>

<ResponseField name="title" type="string">
  Le nom de l’objet que vous affichez.
</ResponseField>

<ResponseField name="defaultOpen" type="boolean" default="false">
  Définissez sur `true` pour que la zone extensible soit ouverte au chargement de la page
</ResponseField>
