---
title: "Encadrés"
description: "Utilisez des encadrés pour mettre en forme et mettre en avant des contenus importants."
keywords: ["encadrés", "notes", "avertissements", "boîtes d'information", "astuces", "mise en avant", "surlignage"]
---

Les encadrés peuvent prendre la forme d’une Note, d’un Warning, d’une Info, d’un Tip, d’un Check ou d’un Danger, ou vous pouvez créer votre propre encadré :

<Note>Cela ajoute une note au contenu</Note>

```mdx
<Note>Ceci ajoute une note dans le contenu</Note>
```

<Warning>Cela déclenche un avertissement auquel il faut faire attention</Warning>

```mdx
<Warning>Ceci affiche un avertissement à ne pas ignorer</Warning>
```

<Info>Cela met en évidence des informations importantes</Info>

```mdx
<Info>Ceci attire l'attention sur des informations importantes</Info>
```

<Tip>Voici une astuce utile</Tip>

```mdx
<Tip>Voici une astuce utile</Tip>
```

<Check>Cela nous met à l’état coché</Check>

```mdx
<Check>Ceci indique un statut validé</Check>
```

<Danger>Ceci est un encadré d’alerte</Danger>

```mdx
<Danger>Ceci est un avertissement de danger</Danger>
```

<Callout icon="key" color="#FFC107" iconType="regular"> Ceci est un encadré personnalisé</Callout>

```mdx wrap
<Callout icon="key" color="#FFC107" iconType="regular">This is a custom callout</Callout>
```
