Les encadrés peuvent être présentés sous forme de Note, Avertissement, Info, Conseil, Validation, Danger, ou vous pouvez créer votre propre encadré :

<Note>Cela ajoute une note dans le contenu</Note>

```mdx
<Note>This adds a note in the content</Note>
```

<Warning>Cela déclenche un avertissement auquel il faut faire attention</Warning>

```mdx
<Warning>Ceci est un avertissement à prendre en compte</Warning>
```

<Info>Met en évidence une information importante</Info>

```mdx
<Info>Ceci attire l'attention sur des informations importantes</Info>
```

<Tip>Cela indique un conseil utile</Tip>

```mdx
<Tip>Voici un conseil utile</Tip>
```

<Check>Cela nous donne un état coché</Check>

```mdx
<Check>This brings us a checked status</Check>
```

<Danger>Ceci est un encadré d’alerte de danger</Danger>

```mdx
<Danger>Ceci est une alerte de danger</Danger>
```

<Callout icon="key" color="#FFC107" iconType="regular"> Ceci est un encadré personnalisé</Callout>

```mdx wrap
<Callout icon="key" color="#FFC107" iconType="regular">This is a custom callout</Callout>
```
