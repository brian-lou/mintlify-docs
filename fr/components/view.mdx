Utilisez le composant `View` pour créer du contenu qui change en fonction de la vue sélectionnée dans un menu déroulant multi-vues. C&#39;est particulièrement utile pour afficher des exemples de code ou de la documentation propres à différents langages de programmation ou frameworks.

<Tip>
  Utilisez un composant View par langage et par page. Utilisez des [onglets](/fr/components/tabs) pour les procédures qui diffèrent selon le langage, et des [groupes de code](/fr/components/code-groups) pour les exemples de code qui diffèrent selon le langage.
</Tip>

<View title="JavaScript" icon="js">
  Ce contenu n&#39;est visible que lorsque JavaScript est sélectionné.

  ```javascript
  console.log("Hello from JavaScript!");
  ```
</View>

<View title="Python" icon="python">
  Ce contenu n&#39;est visible que lorsque Python est sélectionné.

  ```python
  print("Hello from Python!")
  ```
</View>

<div id="table-of-contents-behavior">
  ## Comportement de la table des matières
</div>

La table des matières se met automatiquement à jour pour n’afficher que les titres de la vue actuellement sélectionnée. Lorsque vous changez de vue à l’aide du menu déroulant multi-vues, la table des matières s’actualise pour afficher les titres pertinents pour cette vue.

Si la structure des titres diffère d’une vue à l’autre, les utilisateurs ne verront que les titres correspondant à la langue ou au framework sélectionné.

<div id="properties">
  ## Propriétés
</div>

<ResponseField name="title" type="string" required>
  Le titre qui identifie cette vue. Il doit correspondre à l’une des options du menu déroulant multi-vues.
</ResponseField>

<ResponseField name="icon" type="string">
  Une icône [Font Awesome](https://fontawesome.com/icons), une icône [Lucide](https://lucide.dev/icons), l’URL d’une icône ou le chemin relatif vers une icône.
</ResponseField>

<ResponseField name="iconType" type="string">
  Pour les icônes Font Awesome uniquement : `regular`, `solid`, `light`, `thin`, `sharp-solid`, `duotone` ou `brands`.
</ResponseField>
