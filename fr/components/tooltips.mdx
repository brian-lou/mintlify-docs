Utilisez des info-bulles pour fournir un contexte supplémentaire ou des définitions lorsqu’un utilisateur survole une partie de texte. Les info-bulles peuvent inclure des liens d’appel à l’action facultatifs.

**Exemple** : La documentation <Tooltip headline="API" tip="Application Programming Interface : un ensemble de protocoles permettant à des applications logicielles de communiquer." cta="Lire notre guide API" href="/fr/api-reference">API</Tooltip> aide les développeurs à comprendre comment s’intégrer à votre service.

```mdx Tooltip example wrap
<Tooltip headline="API" tip="Interface de programmation d'application : un ensemble de protocoles permettant aux applications logicielles de communiquer." cta="Lire notre guide API" href="/api-reference">API</Tooltip> La documentation aide les développeurs à comprendre comment s'intégrer à votre service.
```

<div id="properties">
  ## Propriétés
</div>

<ResponseField name="tip" type="string" required>
  Le texte affiché dans l’info-bulle.
</ResponseField>

<ResponseField name="headline" type="string">
  Texte affiché au-dessus du texte de `tip`.
</ResponseField>

<ResponseField name="cta" type="string">
  Le texte de l’appel à l’action pour un lien dans l’info-bulle.
</ResponseField>

<ResponseField name="href" type="string">
  URL du lien de l’appel à l’action. Obligatoire lorsque `cta` est utilisé.
</ResponseField>
