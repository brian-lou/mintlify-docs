L&#39;un des principes fondamentaux du développement logiciel est DRY (« Don&#39;t Repeat Yourself »), qui s&#39;applique aussi à la documentation. Si vous constatez que vous répétez le même contenu à plusieurs endroits, créez un snippet personnalisé pour ce contenu. Les snippets contiennent du contenu que vous pouvez importer dans d&#39;autres fichiers afin de le réutiliser. Vous choisissez où le snippet apparaît sur une page. Si vous devez mettre à jour le contenu, il vous suffit de modifier le snippet plutôt que chaque fichier dans lequel il est utilisé.

<div id="how-snippets-work">
  ## Fonctionnement des snippets
</div>

Les snippets sont des fichiers `.mdx`, `.md` ou `.jsx` importés dans un autre fichier. Vous pouvez placer les fichiers de snippet n&#39;importe où dans votre projet.

Lorsque vous importez un snippet dans un autre fichier, il n&#39;apparaît qu&#39;à l&#39;endroit où vous l&#39;importez et ne s&#39;affiche pas comme une page autonome. Tout fichier dans le dossier `/snippets/` est toujours un snippet, même s&#39;il n&#39;est pas importé dans un autre fichier.

<div id="create-snippets">
  ## Créer des snippets
</div>

Créez un fichier contenant le contenu que vous souhaitez réutiliser. Les snippets peuvent inclure tous les types de contenu pris en charge par Mintlify et peuvent importer d&#39;autres snippets.

<div id="import-snippets-into-pages">
  ## Importer des snippets dans les pages
</div>

Importez des snippets dans les pages en utilisant un chemin absolu ou un chemin relatif.

* **Imports absolus** : Commencez le chemin par `/` pour importer depuis la racine de votre projet.
* **Imports relatifs** : Utilisez `./` ou `../` pour importer des snippets par rapport à l&#39;emplacement du fichier actuel.

<Tip>
  Les imports relatifs permettent la navigation dans l&#39;IDE. Appuyez sur <kbd>CMD</kbd> et cliquez sur le nom d&#39;un snippet dans votre éditeur pour accéder directement à la définition de ce snippet.
</Tip>

<div id="import-text">
  ### Importer du texte
</div>

1. Ajoutez dans votre fichier de snippet le contenu que vous souhaitez réutiliser.

   ```mdx shared/my-snippet.mdx wrap
   Bonjour le monde ! Voici mon contenu que je souhaite réutiliser sur plusieurs pages.
   ```

2. Importez le snippet dans votre fichier de destination en utilisant un chemin absolu ou relatif.

   <CodeGroup>
     ```mdx Absolute import
     ---
     title: "Une page d’exemple"
     description: "Il s’agit d’une page d’exemple qui importe un snippet."
     ---

     import MySnippet from "/shared/my-snippet.mdx";

     Le contenu du snippet s’affiche sous cette phrase.

     <MySnippet />
     ```

     ```mdx Relative import
     ---
     title: "Une page d’exemple"
     description: "Il s’agit d’une page d’exemple qui importe un snippet."
     ---

     import MySnippet from "../shared/my-snippet.mdx";

     Le contenu du snippet s’affiche sous cette phrase.

     <MySnippet />
     ```
   </CodeGroup>

<div id="import-variables">
  ### Importer des variables
</div>

Faites référence à des variables définies dans un extrait (snippet) au sein d’une page.

1. Exportez des variables à partir d’un fichier d’extrait.

   ```mdx shared/custom-variables.mdx
   export const myName = "Ronan";

   export const myObject = { fruit: "strawberries" };

   ;
   ```

2. Importez l’extrait dans votre fichier de destination et utilisez les variables.

   ```mdx destination-file.mdx
   ---
   title: "Une page d'exemple"
   description: "Ceci est une page d'exemple qui importe un extrait (snippet) avec des variables."
   ---

   import { myName, myObject } from "/shared/custom-variables.mdx";

   Hello, my name is {myName} and I like {myObject.fruit}.
   ```

<div id="import-snippets-with-variables">
  ### Importer des snippets avec des variables
</div>

Utilisez des variables pour passer des données à un snippet lorsque vous l&#39;importez.

1. Ajoutez des variables à votre snippet et passez des propriétés (props) lorsque vous l&#39;importez. Dans cet exemple, la variable est `{word}`.

   ```mdx shared/my-snippet.mdx
   My keyword of the day is {word}.
   ```

2. Importez le snippet dans votre fichier de destination en lui passant la variable. La propriété passée remplace la variable dans la définition du snippet.

   ```mdx destination-file.mdx
   ---
   title: "An example page"
   description: "This is an example page that imports a snippet with a variable."
   ---

   import MySnippet from "/shared/my-snippet.mdx";

   <MySnippet word="bananas" />
   ```

<div id="import-react-components">
  ### Importer des composants React
</div>

1. Créez un extrait de code contenant un composant JSX. Consultez [Composants React](/fr/customize/react-components) pour plus d&#39;informations.

   ```js components/my-jsx-snippet.jsx
   export const MyJSXSnippet = () => {
     return (
       <div>
         <h1>Hello, world!</h1>
       </div>
     );
   };
   ```

<Note>
  Lors de la création d&#39;extraits JSX, utilisez la syntaxe de fonction fléchée (`=>`) plutôt que les déclarations de fonctions. Le mot-clé `function` n&#39;est pas pris en charge dans les extraits de code.
</Note>

2. Importez l&#39;extrait de code.

   ```mdx destination-file.mdx
   ---
   title: "Une page d'exemple"
   description: "Voici une page d'exemple qui importe un extrait de code contenant un composant React."
   ---

   import { MyJSXSnippet } from "/components/my-jsx-snippet.jsx";

   <MyJSXSnippet />
   ```
