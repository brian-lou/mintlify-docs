L&#39;un des principes fondamentaux du développement logiciel est le DRY (Ne vous répétez pas), qui s&#39;applique aussi à la documentation. Si vous vous retrouvez à répéter le même contenu à plusieurs endroits, créez un extrait personnalisé. Les extraits contiennent du contenu que vous pouvez importer dans d&#39;autres fichiers pour le réutiliser. Vous choisissez où l&#39;extrait apparaît sur une page. Si vous devez un jour mettre à jour ce contenu, il vous suffit de modifier l&#39;extrait plutôt que chaque fichier où il est utilisé.

<div id="how-snippets-work">
  ## Fonctionnement des extraits
</div>

Les extraits sont des fichiers `.mdx`, `.md` ou `.jsx` importés dans un autre fichier. Vous pouvez placer les fichiers d’extrait n’importe où dans votre projet.

Lorsque vous importez un extrait dans un autre fichier, il n’apparaît qu’à l’endroit où vous l’importez et ne s’affiche pas comme une page autonome. Tout fichier du dossier `/snippets/` est toujours considéré comme un extrait, même s’il n’est pas importé dans un autre fichier.

<div id="create-snippets">
  ## Créer des extraits
</div>

Créez un fichier contenant le contenu que vous souhaitez réutiliser. Les extraits peuvent contenir tous les types de contenu pris en charge par Mintlify et importer d&#39;autres extraits.

<div id="import-snippets-into-pages">
  ## Importer des extraits dans les pages
</div>

Importez des extraits dans les pages à l’aide d’un chemin absolu ou relatif.

* **Imports absolus** : commencent par `/` pour importer depuis la racine de votre projet.
* **Imports relatifs** : utilisez `./` ou `../` pour importer des extraits par rapport à l’emplacement du fichier actuel.

<Tip>
  Les imports relatifs permettent la navigation dans l’IDE. Appuyez sur <kbd>CMD</kbd> et cliquez sur le nom d’un extrait dans votre éditeur pour accéder directement à sa définition.
</Tip>

<div id="import-text">
  ### Importer du texte
</div>

1. Ajoutez au fichier d’extrait le contenu que vous souhaitez réutiliser.

   ```mdx shared/my-snippet.mdx wrap
   Bonjour le monde ! Voici le contenu que je souhaite réutiliser sur plusieurs pages.
   ```

2. Importez l’extrait dans votre fichier de destination à l’aide d’un chemin absolu ou d’un chemin relatif.

   <CodeGroup>
     ```mdx Import absolu
     ---
     title: "Une page d'exemple"
     description: "Voici une page d'exemple qui importe un extrait."
     ---

     import MySnippet from "/shared/my-snippet.mdx";

     Le contenu de l’extrait s’affiche sous cette phrase.

     <MySnippet />
     ```

     ```mdx Import relatif
     ---
     title: "Une page d'exemple"
     description: "Voici une page d'exemple qui importe un extrait."
     ---

     import MySnippet from "../shared/my-snippet.mdx";

     Le contenu de l’extrait s’affiche sous cette phrase.

     <MySnippet />
     ```
   </CodeGroup>

<div id="import-variables">
  ### Importer des variables
</div>

Utilisez des variables issues d’un extrait dans une page.

1. Exportez des variables depuis un fichier d’extrait.

   ```mdx shared/custom-variables.mdx
   export const myName = "Ronan";

   export const myObject = { fruit: "strawberries" };

   ;
   ```

2. Importez l’extrait dans votre fichier de destination et utilisez les variables.

   ```mdx destination-file.mdx
   ---
   title: "An example page"
   description: "This is an example page that imports a snippet with variables."
   ---

   import { myName, myObject } from "/shared/custom-variables.mdx";

   Hello, my name is {myName} and I like {myObject.fruit}.
   ```

<div id="import-snippets-with-variables">
  ### Importer des extraits avec des variables
</div>

Utilisez des variables pour transmettre des données à un extrait lors de son importation.

1. Ajoutez des variables à votre extrait et transmettez des propriétés lors de son importation. Dans cet exemple, la variable est `{word}`.

   ```mdx shared/my-snippet.mdx
   My keyword of the day is {word}.
   ```

2. Importez l’extrait dans votre fichier de destination avec la variable. La propriété transmise remplace la variable dans la définition de l’extrait.

   ```mdx destination-file.mdx
   ---
   title: "An example page"
   description: "This is an example page that imports a snippet with a variable."
   ---

   import MySnippet from "/shared/my-snippet.mdx";

   <MySnippet word="bananas" />
   ```

<div id="import-react-components">
  ### Importer des composants React
</div>

1. Créez un extrait contenant un composant JSX. Consultez [les composants React](/fr/customize/react-components) pour en savoir plus.

   ```js components/my-jsx-snippet.jsx
   export const MyJSXSnippet = () => {
     return (
       <div>
         <h1>Hello, world!</h1>
       </div>
     );
   };
   ```

<Note>
  Lorsque vous créez des extraits JSX, utilisez la syntaxe de fonction fléchée (`=>`) plutôt que des déclarations de fonction. Le mot-clé `function` n’est pas pris en charge dans les extraits.
</Note>

2. Importez l’extrait.

   ```mdx destination-file.mdx
   ---
   title: "Une page d’exemple"
   description: "Il s’agit d’une page d’exemple qui importe un extrait contenant un composant React."
   ---

   import { MyJSXSnippet } from "/components/my-jsx-snippet.jsx";

   <MyJSXSnippet />
   ```
