<div id="lists">
  ## Listes
</div>

Les listes suivent la [syntaxe Markdown officielle](https://www.markdownguide.org/basic-syntax/#lists-1).

<div id="ordered-list">
  ### Liste ordonnée
</div>

Pour créer une liste ordonnée, précédez chaque élément de la liste d’un nombre suivi d’un point.

1. Premier élément
2. Deuxième élément
3. Troisième élément
4. Quatrième élément

```mdx
1. First item
2. Second item
3. Third item
4. Fourth item
```


<div id="unordered-list">
  ### Liste à puces
</div>

Pour créer une liste à puces, ajoutez des tirets (`-`), des astérisques (`*`) ou des signes plus (`+`) avant chaque élément de la liste.

* Premier élément
* Deuxième élément
* Troisième élément
* Quatrième élément

```mdx
- First item
- Second item
- Third item
- Fourth item
```


<div id="nested-list">
  ### Liste imbriquée
</div>

Indentez les éléments de liste pour créer des sous-listes.

* Premier élément
* Deuxième élément
  * Élément supplémentaire
  * Élément supplémentaire
* Troisième élément

```mdx
- First item
- Second item
  - Additional item
  - Additional item
- Third item
```


<div id="tables">
  ## Tables
</div>

Les tableaux suivent la [syntaxe Markdown officielle](https://www.markdownguide.org/extended-syntax/#tables).

Pour ajouter un tableau, utilisez au moins trois tirets (`---`) pour créer l&#39;en-tête de chaque colonne, et des barres verticales (`|`) pour séparer chaque colonne. Pour des raisons de compatibilité, vous devez également ajouter une barre verticale à chaque extrémité de la ligne.

| Propriété   | Description                                          |
| ----------- | ---------------------------------------------------- |
| Nom         | Nom complet de l&#39;utilisateur                     |
| Âge         | Âge déclaré                                          |
| Inscription | Indique si l&#39;utilisateur a rejoint la communauté |

```mdx
| Property | Description                           |
| -------- | ------------------------------------- |
| Name     | Full name of user                     |
| Age      | Reported age                          |
| Joined   | Whether the user joined the community |
```


<div id="column-alignment">
  ### Alignement des colonnes
</div>

Utilisez des deux-points (:) dans la ligne de séparation pour aligner le contenu des colonnes :

| Aligné à gauche |   Centré  | Aligné à droite |
| :-------------- | :-------: | --------------: |
| À gauche        | Au centre |        À droite |
| Texte           |   Texte   |           Texte |

```mdx
| Left aligned | Center aligned | Right aligned |
| :----------- | :------------: | ------------: |
| Left         | Center         | Right         |
| Text         | Text           | Text          |
```
