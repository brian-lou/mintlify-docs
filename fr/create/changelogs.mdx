Créez un journal de modifications pour votre documentation en ajoutant des [composants Update](/fr/components/update) à une page.

Consultez le [journal de modifications Mintlify](/fr/changelog) à titre d’exemple : vous pouvez inclure des liens, des images, du texte et des démonstrations de vos nouvelles fonctionnalités dans chaque mise à jour.

<div id="setting-up-your-changelog">
  ## Configurer votre changelog
</div>

<Steps>
  <Step title="Créer une page pour votre changelog">
    1. Créez une nouvelle page dans votre documentation, par exemple `changelog.mdx` ou `updates.mdx`.
    2. Ajoutez votre page de changelog à la structure de navigation dans votre `docs.json`.
  </Step>

  <Step title="Ajouter des composants Update à votre changelog">
    Ajoutez un composant `Update` pour chaque entrée de changelog.

    Incluez des informations pertinentes comme les nouvelles fonctionnalités, les corrections de bugs ou d&#39;autres annonces.
  </Step>
</Steps>

```mdx Example changelog.mdx
---
title: "Changelog"
description: "Product updates and announcements"
---
<Update label="March 2025" description="v0.0.10">
  Added a new Wintergreen flavor.

  Released a new version of the Spearmint flavor, now with 10% more mint.
</Update>

<Update label="February 2025" description="v0.0.09">
  Released a new version of the Spearmint flavor.
</Update>
```

<div id="customizing-your-changelog">
  ## Personnaliser votre journal des modifications
</div>

Définissez comment les utilisateurs naviguent dans votre journal des modifications et restent informés des nouveautés concernant votre produit.

<div id="table-of-contents">
  ### Table des matières
</div>

Chaque propriété `label` d’une `Update` crée automatiquement une entrée dans la table des matières de la barre latérale droite. Il s’agit du mode de navigation par défaut de votre changelog.

<div id="tag-filters">
  ### Filtres de tags
</div>

Ajoutez la propriété `tags` à vos composants `Update` pour remplacer la table des matières par des filtres de tags. Les utilisateurs peuvent filtrer le changelog en sélectionnant un ou plusieurs tags :

```mdx Tag filters example wrap
<Update label="March 2025" description="v0.0.10" tags={["Wintergreen", "Spearmint"]}>
  Added a new Wintergreen flavor.

  Released a new version of the Spearmint flavor, now with 10% more mint.
</Update>

<Update label="February 2025" description="v0.0.09" tags={["Spearmint"]}>
  Released a new version of the Spearmint flavor.
</Update>

<Update label="January 2025" description="v0.0.08" tags={["Peppermint", "Spearmint"]}>
  Deprecated the Peppermint flavor.

  Released a new version of the Spearmint flavor.
</Update>
```

<Tip>
  La table des matières et les filtres du journal des modifications sont masqués lorsque vous utilisez les modes de page `custom`, `center` ou `wide`. Pour en savoir plus, consultez les [modes de page](/fr/organize/pages#page-mode).
</Tip>

<div id="subscribable-changelogs">
  ### Journaux de modifications auxquels s’abonner
</div>

<Note>Les flux RSS sont uniquement disponibles pour la documentation publique.</Note>

Utilisez des composants `Update` pour créer un flux RSS auquel s’abonner en ajoutant `/rss.xml` à l’URL de votre page. Par exemple, `mintlify.com/docs/changelog/rss.xml`.

Le flux RSS publie des entrées lorsque vous ajoutez de nouveaux composants `Update` et lorsque vous modifiez les titres à l’intérieur de composants `Update` existants.

Les entrées du flux RSS contiennent uniquement du Markdown brut. Les composants, le code et les éléments HTML sont exclus. Utilisez la propriété `rss` pour fournir des descriptions textuelles alternatives aux abonnés RSS lorsque vos mises à jour incluent du contenu exclu.

```xml Example RSS feed
<?xml version="1.0" encoding="UTF-8"?>
<rss xmlns:dc="http://purl.org/dc/elements/1.1/" xmlns:content="http://purl.org/rss/1.0/modules/content/" xmlns:atom="http://www.w3.org/2005/Atom" version="2.0">
  <channel>
    <title><![CDATA[Product updates]]></title>
    <description><![CDATA[New updates and improvements]]></description>
    <link>https://mintlify.com/docs</link>
    <generator>RSS for Node</generator>
    <lastBuildDate>Mon, 21 Jul 2025 21:21:47 GMT</lastBuildDate>
    <atom:link href="https://mintlify.com/docs/changelog/rss.xml" rel="self" type="application/rss+xml"/>
    <copyright><![CDATA[Mintlify]]></copyright>
    <docs>https://mintlify.com/docs</docs>
    <item>
      <title><![CDATA[June 2025]]></title>
      <link>https://mintlify.com/docs/changelog#june-2025</link>
      <guid isPermaLink="true">https://mintlify.com/docs/changelog#june-2025</guid>
      <pubDate>Mon, 23 Jun 2025 16:54:22 GMT</pubDate>
    </item>
  </channel>
</rss>
```

Les flux RSS peuvent s&#39;intégrer à Slack, au courrier électronique ou à d&#39;autres outils d&#39;abonnement pour notifier les utilisateurs des modifications du produit. Parmi les options possibles :

* [Slack](https://slack.com/help/articles/218688467-Add-RSS-feeds-to-Slack)
* [Email](https://zapier.com/apps/email/integrations/rss/1441/send-new-rss-feed-entries-via-email) via Zapier
* Des bots Discord tels que [Readybot](https://readybot.io) ou [RSS Feeds to Discord Bot](https://rss.app/en/bots/rssfeeds-discord-bot)

Pour rendre le flux RSS facilement repérable, vous pouvez afficher un bouton avec une icône RSS qui pointe vers le flux en haut de la page. Ajoutez `rss: true` au frontmatter de la page :

```mdx
---
rss: true
---
```
