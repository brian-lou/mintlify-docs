Lorsque vous modifiez le chemin d’accès d’un fichier dans votre dossier docs, l’URL de cette page est également modifiée. Cela peut se produire lorsque vous réorganisez votre documentation ou modifiez le titre de la barre latérale.

<div id="redirects">
  ## Redirections
</div>

<Note>
  Les redirections **ne peuvent pas** contenir d’ancres d’URL comme `path#anchor` ni de paramètres de requête comme `path?query=value`.
</Note>

Configurez des redirections 301 en ajoutant le champ `redirects` à votre fichier `docs.json`.

```json
"redirects": [
  {
    "source": "/source/path",
    "destination": "/destination/path"
  }
]
```

Cela redirige définitivement `/source/path` vers `/destination/path`, afin que vous ne perdiez pas le référencement de la page d’origine.

<div id="wildcard-redirects">
  ### Redirections avec caractère générique
</div>

Pour faire correspondre un chemin avec un caractère générique, utilisez `*` après un paramètre. Dans cet exemple, `/beta/:slug*` correspond à `/beta/introduction` et redirige ce dernier vers `/v2/introduction`.

```json
"redirects": [
  {
    "source": "/beta/:slug*",
    "destination": "/v2/:slug*"
  }
]
```

<div id="partial-wildcard-redirects">
  ### Redirections avec jokers partiels
</div>

Utilisez des jokers partiels pour faire correspondre les segments d’URL qui commencent par un préfixe donné.

```json
"redirects": [
  {
    "source": "/articles/concepts-*",
    "destination": "/collections/overview"
  }
]
```

Cette règle fait correspondre toutes les URL dont le chemin est `/articles/concepts-`, comme `/articles/concepts-getting-started` et `/articles/concepts-overview`, et les redirige toutes vers `/collections/overview`.

Vous pouvez également réutiliser la valeur du caractère générique capturée dans la destination.

```json
"redirects": [
  {
    "source": "/old/article-*",
    "destination": "/new/article-*"
  }
]
```

Cela redirige `/old/article-123` vers `/new/article-123`, tout en conservant la valeur capturée après le préfixe.

<div id="avoid-infinite-redirects">
  ### Évitez les redirections infinies
</div>

Pour éviter les boucles infinies, ne créez pas de redirections circulaires dans lesquelles les chemins se renvoient mutuellement.

```json
"redirects": [
  {
    "source": "/docs/:slug*",
    "destination": "/help/:slug*"
  },
  {
    "source": "/help/:slug*",
    "destination": "/docs/:slug*"
  }
]
```

<div id="check-for-broken-links">
  ## Vérifier les liens brisés
</div>

Détectez les liens brisés à l’aide de la [CLI](/fr/installation).

```bash
mint broken-links
```
