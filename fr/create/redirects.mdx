Lorsque vous modifiez le chemin d’un fichier dans votre dossier de documentation, l’URL de cette page change également. Cela peut se produire lorsque vous réorganisez votre documentation ou modifiez le titre dans la barre latérale.

<div id="redirects">
  ## Redirections
</div>

<Note>
  Les redirections **ne peuvent pas** inclure d’ancres d’URL comme `path#anchor` ni de paramètres de requête comme `path?query=value`.
</Note>

Configurez des redirections 301 en ajoutant le champ `redirects` dans votre fichier `docs.json`.

```json
"redirects": [
  {
    "source": "/source/path",
    "destination": "/destination/path"
  }
]
```

Cela redirige de manière permanente `/source/path` vers `/destination/path`, afin de ne pas perdre le référencement naturel déjà acquis pour la page d’origine.

<div id="wildcard-redirects">
  ### Redirections avec caractères génériques
</div>

Pour faire correspondre un chemin avec caractère générique, utilisez `*` après un paramètre. Dans cet exemple, `/beta/:slug*` correspond à `/beta/introduction` et le redirige vers `/v2/introduction`.

```json
"redirects": [
  {
    "source": "/beta/:slug*",
    "destination": "/v2/:slug*"
  }
]
```

<div id="partial-wildcard-redirects">
  ### Redirections avec caractères génériques partiels
</div>

Utilisez des caractères génériques partiels pour faire correspondre les segments d’URL qui commencent par un préfixe spécifique.

```json
"redirects": [
  {
    "source": "/articles/concepts-*",
    "destination": "/collections/overview"
  }
]
```

Ce motif correspond à toutes les URL ayant le chemin `/articles/concepts-`, comme `/articles/concepts-getting-started` et `/articles/concepts-overview`, et les redirige toutes vers `/collections/overview`.

Vous pouvez également utiliser la valeur de caractère générique capturée dans la destination.

```json
"redirects": [
  {
    "source": "/old/article-*",
    "destination": "/new/article-*"
  }
]
```

Cela redirige `/old/article-123` vers `/new/article-123`, en conservant la valeur capturée après le préfixe.

<div id="avoid-infinite-redirects">
  ### Évitez les redirections infinies
</div>

Pour éviter les boucles infinies, ne créez pas de redirections circulaires dans lesquelles les chemins se redirigent mutuellement.

```json
"redirects": [
  {
    "source": "/docs/:slug*",
    "destination": "/help/:slug*"
  },
  {
    "source": "/help/:slug*",
    "destination": "/docs/:slug*"
  }
]
```

<div id="check-for-broken-links">
  ## Vérifier les liens rompus
</div>

Recherchez les liens rompus avec le [CLI](/fr/installation).

```bash
mint broken-links
```
