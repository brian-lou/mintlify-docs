Mintlify fournit automatiquement les ressources statiques à partir de votre dépôt de documentation, au chemin approprié sur votre domaine. Par exemple, si vous avez `/images/my-logo.png` dans votre dépôt, le fichier image est disponible à l’adresse `https://docs.your-project.com/images/my-logo.png`.

Vous pouvez mettre à disposition de vos utilisateurs n’importe quel type de fichier pris en charge, y compris des spécifications OpenAPI, des images, des vidéos, et plus encore.

Les fichiers ne doivent pas dépasser 20 Mo pour les images et 100 Mo pour les autres types de fichiers.

<Note>
La mise à disposition de fichiers n’est pas prise en charge pour les sites de documentation avec authentification activée. Si votre site nécessite une authentification, les fichiers statiques ne seront pas accessibles via leurs URL directes.
</Note>

<div id="supported-file-types">
  ## Types de fichiers pris en charge
</div>

Types de fichiers pris en charge pour toutes les offres :

- **Images** : `.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`, `.svg`, `.ico`
- **Vidéos** : `.mp4`, `.webm`
- **Audio** : `.mp3`, `.wav`
- **Données** : `.json`, `.yaml`
- **Feuilles de style** : `.css`
- **Scripts** : `.js`
- **Polices** : `.woff`, `.woff2`, `.ttf`, `.eot`

Types de fichiers pris en charge pour les offres Enterprise :

- **Documents** : `.pdf`, `.txt`
- **Données** : `.xml`, `.csv`
- **Archives** : `.zip`

<div id="file-organization">
  ## Organisation des fichiers
</div>

Organisez vos fichiers en dossiers afin de garder votre dépôt facile à parcourir :

```text
/your-project
  |- docs.json
  |- images/
    |- logo.png
    |- screenshots/
      |- dashboard.png
  |- assets/
    |- whitepaper.pdf
    |- demo-video.mp4
```

Les fichiers sont servis à partir de la racine de votre domaine, ce qui fait que la structure de votre dépôt correspond directement à la structure des URL. Dans l’exemple précédent, `assets/whitepaper.pdf` serait disponible à l’adresse `https://docs.your-project.com/assets/whitepaper.pdf`.
