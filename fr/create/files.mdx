Mintlify diffuse automatiquement les ressources statiques de votre dépôt de documentation au chemin approprié sur votre domaine. Par exemple, si votre dépôt contient `/images/my-logo.png`, le fichier image sera disponible à l&#39;adresse `https://docs.your-project.com/images/my-logo.png`.

Vous pouvez mettre à la disposition de vos utilisateurs n&#39;importe quel type de fichier pris en charge, y compris des spécifications OpenAPI, des images, des vidéos, etc.

Les fichiers doivent faire moins de 20 Mo pour les images et moins de 100 Mo pour les autres types de fichiers.

<Note>
  La diffusion de fichiers n&#39;est pas prise en charge pour les sites de documentation avec authentification activée. Si votre site nécessite une authentification, les fichiers statiques ne seront pas accessibles via leurs URL directes.
</Note>

<div id="supported-file-types">
  ## Types de fichiers pris en charge
</div>

Types de fichiers pris en charge pour toutes les offres :

* **Images**: `.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`, `.svg`, `.ico`
* **Vidéo**: `.mp4`, `.webm`
* **Audio**: `.mp3`, `.wav`
* **Données**: `.json`, `.yaml`
* **Feuilles de style**: `.css`
* **Scripts**: `.js`
* **Polices**: `.woff`, `.woff2`, `.ttf`, `.eot`

Types de fichiers pris en charge pour les offres Enterprise :

* **Documents**: `.pdf`, `.txt`
* **Données**: `.xml`, `.csv`
* **Archives**: `.zip`

<div id="file-organization">
  ## Organisation des fichiers
</div>

Organisez vos fichiers dans des dossiers pour que votre dépôt reste facile à parcourir :

```text
/your-project
  |- docs.json
  |- images/
    |- logo.png
    |- screenshots/
      |- dashboard.png
  |- assets/
    |- whitepaper.pdf
    |- demo-video.mp4
```

Les fichiers sont servis à la racine de votre domaine, donc la structure de votre dépôt correspond directement à celle des URL. D’après l’exemple précédent, `assets/whitepaper.pdf` serait accessible à l’adresse `https://docs.your-project.com/assets/whitepaper.pdf`.
