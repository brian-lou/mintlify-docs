Le fichier `.mintignore` vous permet d’exclure certains fichiers et répertoires de votre dépôt de documentation afin qu’ils ne soient ni traités ni publiés sur votre site de documentation.

Utilisez `.mintignore` pour garder les brouillons, les notes internes et les fichiers source hors de votre documentation publique, tout en les conservant dans votre dépôt.

<div id="create-a-mintignore-file">
  ## Créer un fichier .mintignore
</div>

Créez un fichier `.mintignore` à la racine de votre répertoire de documentation. Ce fichier utilise la même syntaxe de motifs que le fichier `.gitignore`.

```plaintext .mintignore
# Exclure les documents brouillons
drafts/
*.draft.mdx

# Exclure la documentation interne
internal/

# Exclure des fichiers spécifiques
private-notes.md
```

Lorsque Mintlify génère votre documentation, il lit le fichier `.mintignore` et exclut du traitement tous les fichiers ou dossiers correspondants.

Fichiers exclus :

* N&#39;apparaissent pas dans votre documentation publiée.
* Ne sont pas indexés pour la recherche.
* Ne sont pas accessibles aux visiteurs.
* Sont ignorés par les [vérifications des liens cassés](/fr/installation#find-broken-links). Les liens qui pointent vers des fichiers ignorés sont cassés.

<div id="default-ignored-patterns">
  ## Motifs ignorés par défaut
</div>

Mintlify ignore automatiquement les répertoires et fichiers suivants, sans aucune configuration :

* `.git`
* `.github`
* `.claude`
* `.agents`
* `.idea`
* `node_modules`
* `README.md`
* `LICENSE.md`
* `CHANGELOG.md`
* `CONTRIBUTING.md`

Vous n&#39;avez pas besoin de les ajouter à votre fichier `.mintignore`.

<Note>
  Contrairement aux [pages masquées](/fr/organize/hidden-pages), les fichiers exclus par `.mintignore`
  sont complètement supprimés de votre site et ne sont pas accessibles via une URL.
</Note>

<div id="pattern-syntax">
  ## Syntaxe des motifs
</div>

Le fichier `.mintignore` suit la syntaxe de `.gitignore`. Voici quelques motifs courants :

| Motif              | Description                                                |
| ------------------ | ---------------------------------------------------------- |
| `drafts/`          | Exclut l’ensemble du répertoire `drafts`                   |
| `*.draft.mdx`      | Exclut tous les fichiers se terminant par `.draft.mdx`     |
| `private-notes.md` | Exclut un fichier précis                                   |
| `**/internal/**`   | Exclut tout répertoire `internal`, à n’importe quel niveau |
| `!important.mdx`   | Annule un motif précédent (inclut le fichier)              |
