La propriété [navigation](/fr/organize/settings#param-navigation) dans `docs.json` détermine la structure et la hiérarchie de l&#39;information de votre documentation.

Avec une configuration de navigation adaptée, vous pouvez organiser votre contenu afin que les utilisateurs trouvent exactement ce qu&#39;ils cherchent.

Choisissez un modèle d&#39;organisation principal à la racine de votre navigation. Une fois ce modèle défini, vous pouvez y imbriquer d&#39;autres éléments de navigation.

<div id="pages">
  ## Pages
</div>

Les pages sont l’élément de navigation le plus fondamental. Chaque page est un fichier MDX dans votre dépôt de documentation.

<img className="block dark:hidden pointer-events-none" src="/images/navigation/pages-light.png" alt="Illustration décorative de pages." />

<img className="hidden dark:block pointer-events-none" src="/images/navigation/pages-dark.png" alt="Illustration décorative de pages." />

Dans l’objet `navigation`, `pages` est un tableau dans lequel chaque entrée doit pointer vers le chemin d’accès à un [fichier de page](/fr/organize/pages).

```json
{
  "navigation": {
    "pages": [
      "settings",
      "pages",
      "navigation",
      "themes",
      "custom-domain"
    ]
  }
}
```

<div id="groups">
  ## Groupes
</div>

Utilisez les groupes pour organiser la navigation de votre barre latérale en sections. Les groupes peuvent être imbriqués, associés à des tags et personnalisés avec des icônes.

<img className="block dark:hidden pointer-events-none" src="/images/navigation/groups-light.png" alt="Illustration décorative de groupes." />

<img className="hidden dark:block pointer-events-none" src="/images/navigation/groups-dark.png" alt="Illustration décorative de groupes." />

Dans l’objet `navigation`, `groups` est un tableau dans lequel chaque entrée est un objet qui doit contenir un champ `group` et un champ `pages`. Les champs `icon`, `tag` et `expanded` sont facultatifs.

```json
{
  "navigation": {
    "groups": [
      {
        "group": "Getting started",
        "icon": "play",
        "pages": [
          "quickstart",
          {
            "group": "Editing",
            "expanded": false,
            "icon": "pencil",
            "pages": [
              "installation",
              "editor"
            ]
          }
        ]
      },
      {
        "group": "Writing content",
        "icon": "notebook-text",
        "tag": "NEW",
        "pages": [
          "writing-content/page",
          "writing-content/text"
        ]
      }
    ]
  }
}
```

<div id="default-expanded-state">
  ### État déplié par défaut
</div>

Utilisez la propriété `expanded` pour définir l’état par défaut d’un groupe imbriqué dans la barre latérale de navigation.

* `expanded: true` : le groupe est déplié par défaut.
* `expanded: false` ou omis : le groupe est replié par défaut.

<Note>
  La propriété `expanded` n’affecte que les groupes imbriqués, c’est-à-dire les groupes contenus dans d’autres groupes. Les groupes de premier niveau sont toujours dépliés et ne peuvent pas être repliés.
</Note>

```json
{
  "group": "Getting started",
  "pages": [
    "quickstart",
    {
      "group": "Advanced",
      "expanded": false,
      "pages": ["installation", "configuration"]
    }
  ]
}
```

<div id="tabs">
  ## Onglets
</div>

Les onglets créent des sections distinctes dans votre documentation, chacune avec son propre chemin d’URL. Ils ajoutent une barre de navigation horizontale en haut de votre documentation, qui permet aux utilisateurs de passer d’une section à l’autre.

<img className="block dark:hidden pointer-events-none" src="/images/navigation/tabs-light.png" alt="Illustration décorative d’une navigation par onglets." />

<img className="hidden dark:block pointer-events-none" src="/images/navigation/tabs-dark.png" alt="Illustration décorative d’une navigation par onglets." />

Dans l’objet `navigation`, `tabs` est un tableau dont chaque entrée est un objet qui doit inclure un champ `tab` et peut contenir d’autres champs de navigation, comme des groupes, des pages, des icônes ou des liens vers des pages externes.

```json
{
  "navigation": {
    "tabs": [
      {
        "tab": "API reference",
        "icon": "square-terminal",
        "pages": [
          "api-reference/get",
          "api-reference/post",
          "api-reference/delete"
        ]
      },
      {
        "tab": "SDKs",
        "icon": "code",
        "pages": [
          "sdk/fetch",
          "sdk/create",
          "sdk/delete"
        ]
      },
      {
        "tab": "Blog",
        "icon": "newspaper",
        "href": "https://external-link.com/blog"
      }
    ]
  }
}
```

<div id="menus">
  ### Menus
</div>

Les menus ajoutent des éléments de navigation déroulants à un onglet. Utilisez-les pour permettre aux utilisateurs d’accéder directement à des pages spécifiques dans un onglet.

Dans l’objet `navigation`, `menu` est un tableau dont chaque entrée est un objet qui nécessite un champ `item` et peut contenir d’autres champs de navigation, comme des groupes, des pages, des icônes ou des liens vers des pages externes.

Les éléments de menu ne peuvent contenir que des groupes, des pages et des liens externes.

```json
{
  "navigation": {
    "tabs": [
      {
        "tab": "Developer tools",
        "icon": "square-terminal",
        "menu": [
          {
            "item": "API reference",
            "icon": "rocket",
            "groups": [
              {
                "group": "Core endpoints",
                "icon": "square-terminal",
                "pages": [
                  "api-reference/get",
                  "api-reference/post",
                  "api-reference/delete"
                ]
              }
            ]
          },
          {
            "item": "SDKs",
            "icon": "code",
            "description": "Les SDK sont utilisés pour interagir avec l'API.",
            "pages": [
              "sdk/fetch",
              "sdk/create",
              "sdk/delete"
            ]
          }
        ]
      }
    ]
  }
}
```

<div id="anchors">
  ## Ancres
</div>

Les ancres ajoutent des éléments de navigation permanents en haut de votre barre latérale. Utilisez-les pour structurer votre contenu, fournir un accès rapide à des ressources externes ou créer des appels à l’action bien visibles.

<img className="block dark:hidden pointer-events-none" src="/images/navigation/anchors-light.png" alt="Illustration décorative d’une navigation par ancres." />

<img className="hidden dark:block pointer-events-none" src="/images/navigation/anchors-dark.png" alt="Illustration décorative d’une navigation par ancres." />

Dans l’objet `navigation`, `anchors` est un tableau dont chaque entrée est un objet qui doit inclure un champ `anchor` et peut contenir d’autres champs de navigation, comme des groupes, des pages, des icônes ou des liens vers des pages externes.

```json
{
  "navigation": {
    "anchors": [
      {
        "anchor": "Documentation",
        "icon": "book-open",
        "pages": [
          "quickstart",
          "development",
          "navigation"
        ]
      },
      {
        "anchor": "API reference",
        "icon": "square-terminal",
        "pages": [
          "api-reference/get",
          "api-reference/post",
          "api-reference/delete"
        ]
      },
      {
        "anchor": "Blog",
        "href": "https://external-link.com/blog"
      }
    ]
  }
}
```

<div id="global-anchors">
  ### Ancres globales
</div>

Utilisez des ancres globales pour les liens qui doivent apparaître sur toutes les pages, quelle que soit la section de navigation consultée par l’utilisateur. Les ancres globales sont particulièrement utiles pour créer des liens vers des ressources externes à votre documentation (comme un blog, un forum communautaire ou un portail d’assistance) ou pour offrir un accès constant à des pages internes importantes (comme un journal des modifications ou une page d’état).

Les ancres globales prennent en charge à la fois les URL externes et les chemins relatifs vers les pages de votre documentation.

```json
{
  "navigation": {
    "global":  {
      "anchors": [
        {
          "anchor": "Changelog",
          "icon": "list",
          "href": "/changelog"
        },
        {
          "anchor": "Blog",
          "icon": "pencil",
          "href": "https://mintlify.com/blog"
        }
      ]
    },
    "tabs": /*...*/
  }
}
```

Les menus déroulants se trouvent dans un menu extensible situé en haut de la navigation de votre barre latérale. Chaque élément d’un menu déroulant mène à une section de votre documentation.

Dans l’objet `navigation`, `dropdowns` est un tableau dont chaque entrée est un objet qui nécessite un champ `dropdown` et peut contenir d’autres champs de navigation, comme des groupes, des pages, des icônes ou des liens vers des pages externes.

        "dropdown": "Documentation",

        "pages": [

        "dropdown": "API reference",

<div id="openapi">
  ## OpenAPI
</div>

Intégrez des spécifications OpenAPI directement à votre structure de navigation pour générer automatiquement votre documentation d’API. Créez des sections d’API dédiées ou placez des pages d’endpoint dans d’autres composants de navigation.

Définissez une spécification OpenAPI par défaut à n’importe quel niveau de votre hiérarchie de navigation. Les éléments enfants en hériteront, sauf s’ils définissent leur propre spécification.

<Note>
  Lorsque vous ajoutez la propriété `openapi` à un élément de navigation (comme une ancre, un onglet ou un groupe) sans spécifier de pages, Mintlify génère automatiquement des pages pour **tous les endpoints** définis dans votre spécification OpenAPI.

  Pour contrôler les endpoints affichés, listez explicitement les endpoints souhaités dans un tableau `pages`.
</Note>

Pour en savoir plus sur la façon de référencer des endpoints OpenAPI dans votre documentation, consultez la [configuration OpenAPI](/fr/api-playground/openapi-setup).

```json
{
  "navigation": {
    "groups": [
      {
        "group": "API reference",
        "openapi": "/path/to/openapi-v1.json",
        "pages": [
          "overview",
          "authentication",
          "GET /users",
          "POST /users",
          {
            "group": "Products",
            "openapi": "/path/to/openapi-v2.json",
            "pages": [
              "GET /products",
              "POST /products"
            ]
          }
        ]
      }
    ]
  }
}
```

<div id="nesting">
  ## Imbrication
</div>

Les éléments de navigation peuvent être imbriqués les uns dans les autres pour créer des hiérarchies complexes. Vous devez avoir un élément de navigation parent au niveau racine, comme des onglets, des groupes ou un menu déroulant. Vous pouvez imbriquer d’autres types d’éléments de navigation dans votre structure de navigation principale.

Chaque élément de navigation ne peut contenir qu’un seul type d’élément enfant à chaque niveau de la hiérarchie. Par exemple, un onglet peut contenir des ancres qui contiennent des groupes, mais un onglet ne peut pas contenir à la fois des ancres et des groupes au même niveau.

<div id="breadcrumbs">
  ## Fil d’Ariane
</div>

Le fil d’Ariane affiche le chemin de navigation complet en haut des pages. Certains thèmes l’activent par défaut, d’autres non. Vous pouvez contrôler son affichage sur votre site à l’aide de la propriété `styling` dans votre `docs.json`.

<CodeGroup>
  ```json Afficher le fil d’Ariane complet
  "styling": {
    "eyebrows": "breadcrumbs"
  }
  ```

  ```json Afficher uniquement la section parente
  "styling": {
    "eyebrows": "section"
  }
  ```
</CodeGroup>

<div id="interaction-configuration">
  ## Configuration de l’interaction
</div>

Définissez la manière dont les utilisateurs interagissent avec les éléments de navigation à l’aide de la propriété `interaction` dans votre `docs.json`.

<div id="enable-auto-navigation-for-groups">
  ### Activer la navigation automatique pour les groupes
</div>

Lorsqu’un utilisateur développe un groupe de navigation, certains thèmes redirigent automatiquement vers la première page du groupe. Vous pouvez remplacer le comportement par défaut d’un thème à l’aide de l’option `drilldown`.

* Définissez cette option sur `true` pour forcer la navigation automatique vers la première page lorsqu’un groupe de navigation est sélectionné.
* Définissez cette option sur `false` pour empêcher la navigation et uniquement développer ou réduire le groupe lorsqu’il est sélectionné.
* Laissez cette option non définie pour utiliser le comportement par défaut du thème.

<CodeGroup>
  ```json Forcer la navigation
  "interaction": {
    "drilldown": true  // Forcer la navigation vers la première page lorsqu’un utilisateur développe un menu déroulant
  }
  ```

  ```json Empêcher la navigation
  "interaction": {
    "drilldown": false // Ne jamais naviguer, uniquement développer ou réduire le groupe
  }
  ```
</CodeGroup>
