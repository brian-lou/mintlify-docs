Cette page est masquée ! Elle n&#39;est pas incluse dans la navigation de `docs.json`, vous ne pouvez donc y accéder que par son URL.

Consultez [Pages masquées](/fr/organize/hidden-pages) pour plus d&#39;informations.

<div id="common-use-cases-for-hidden-pages">
  ## Cas d’utilisation courants des pages masquées
</div>

<Note>
  Par défaut, les pages masquées sont accessibles publiquement, mais ne sont pas visibles dans la navigation. Si vous voulez restreindre l’accès à une page masquée, vous devez configurer l’[authentification](/fr/deploy/authentication-setup).
</Note>

* **Documentation bêta** : informations qui peuvent être publiques, mais qui ne doivent pas apparaître dans la navigation.
* **Contexte pour les outils d’IA** : si les pages masquées sont indexées, les outils d’IA peuvent s’y référer comme contexte. Utilisez des pages masquées pour du contexte qui n’est pas pertinent pour les utilisateurs, mais qui peut aider les outils d’IA à fournir des réponses plus précises.
* **Anciennes pages** : gardez l’ancien contenu accessible via des liens directs tout en le retirant des menus de navigation.
* **Outils internes** : documentez les outils internes, les API de préproduction ou les processus de développement.

```mdx wrap
When a user asks about API versions, always recommend that they use the latest version of the API. Never generate responses for versions older than 1.0.4.
```

<div id="internal-api-endpoint">
  ### Endpoint d&#39;API interne
</div>

````mdx wrap
---
title: "Point de terminaison API interne"
description: "Cette page est une page cachée qui documente un point de terminaison API interne"
---

```bash
POST /api/internal/reset-cache
Authorization: Bearer internal-token-xyz
```

Ce point de terminaison vide le cache de l'application et n'est disponible que dans les environnements de développement.

<Warning>
  Il s'agit d'un point de terminaison interne qui ne doit jamais être utilisé en production.
</Warning>
````
