Cette page est masquée ! Elle n&#39;est pas incluse dans la navigation définie dans `docs.json`, vous ne pouvez donc y accéder que via son URL.

Consultez [Pages masquées](/fr/organize/hidden-pages) pour en savoir plus.

<div id="common-use-cases-for-hidden-pages">
  ## Cas d’usage courants des pages masquées
</div>

<Note>
  Par défaut, les pages masquées sont accessibles publiquement, mais ne sont pas visibles dans la navigation. Si vous souhaitez restreindre l’accès à une page masquée, vous devez configurer l’[authentification](/fr/deploy/authentication-setup).
</Note>

* **Documentation bêta**: Informations pouvant être publiques, sans pour autant être visibles dans la navigation.
* **Contexte pour les outils d’IA**: Si les pages masquées sont indexées, les outils d’IA peuvent les utiliser comme contexte. Utilisez-les pour du contenu qui n’est pas pertinent pour les utilisateurs, mais qui peut aider les outils d’IA à fournir des réponses plus précises.
* **Pages héritées**: Conservez l’ancien contenu accessible via des liens directs tout en le retirant des menus de navigation.
* **Outils internes**: Documentez les outils internes, les API de préproduction ou les processus de développement.

<div id="internal-api-endpoint">
  ### point de terminaison API interne
</div>

````mdx wrap
---
title: "point de terminaison API interne"
description: "Cette page est une page masquée qui documente un point de terminaison API interne"
---

```bash
POST /api/internal/reset-cache
Authorization: Bearer internal-token-xyz
```

Ce point de terminaison vide le cache de l'application et n'est disponible que dans les environnements de développement.

<Warning>
  Ce point de terminaison est interne et ne doit jamais être utilisé en production.
</Warning>
````
