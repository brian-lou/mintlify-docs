Vous pouvez faire appel à nos services de migration pour transférer votre documentation vers Mintlify. Ce guide présente le processus de migration, les délais de livraison et notre processus d’assurance qualité.

<div id="what-to-expect-for-your-migration">
  ## À quoi vous attendre lors de votre migration
</div>

Une migration est un transfert ponctuel de votre documentation qui nécessite un gel du code. Nous migrons votre documentation, vos pages de référence d’API, votre identité visuelle (logos, couleurs et polices), ainsi que votre structure de navigation. Les services de migration incluent également des conseils en design ou en architecture de l’information, ainsi que le développement de composants personnalisés, comme des pages d’accueil ou des intégrations sur mesure.

Votre migration comprend un lien de préproduction pour suivre l’avancement et un délai de 7 jours après la livraison pour nous faire part de tout problème lié au contenu, aux ressources ou à l’identité visuelle.

<div id="migration-process">
  ## Processus de migration
</div>

Le processus de migration est très collaboratif. Nous travaillons en étroite collaboration avec votre équipe pour mettre en place des solutions et des versions personnalisées adaptées à vos besoins.

<Steps>
  <Step title="Soumettre le formulaire de migration">
    Soumettez le [formulaire de migration](https://mintlify.typeform.com/pro-migrations).

    Indiquez la source de votre documentation, vos éléments de marque (logos, codes couleur, polices), vos spécifications OpenAPI, votre date de mise en ligne et le mode de livraison souhaité (PR GitHub ou fichier zip).
  </Step>

  <Step title="Appel de lancement">
    Nous examinons votre demande et organisons un appel de lancement avec notre équipe de migration pour passer en revue votre configuration actuelle, comprendre les éventuelles contraintes et répondre aux questions de votre équipe.
  </Step>

  <Step title="Réception du cadrage et du calendrier (1-2 jours ouvrés)">
    Nous analysons les éléments issus de l’appel et vous communiquons un délai de livraison estimé sous 24 à 48 heures. Nous signalons également tout composant personnalisé ou point de la migration nécessitant une discussion.
  </Step>

  <Step title="Vérifier l’avancement pendant la migration">
    Nous lançons la migration et partageons un lien de préproduction afin que vous puissiez suivre l’avancement en temps réel.
  </Step>

  <Step title="Réception de la livraison finale">
    Nous vous livrons la migration via une PR GitHub ou un fichier zip, selon votre préférence.
  </Step>

  <Step title="Fenêtre de retours (sept jours ouvrés)">
    Envoyez tout retour sur le contenu, les ressources ou l’identité visuelle. Nous traitons tous les problèmes inclus dans le périmètre dans ce même délai.
  </Step>

  <Step title="Assistance à la mise en ligne">
    Nous fournissons la documentation et les conseils nécessaires pour connecter votre dépôt, configurer les redirections et paramétrer votre domaine personnalisé.
  </Step>
</Steps>

<div id="quality-assurance">
  ## Assurance qualité
</div>

Nous travaillons avec des prestataires tiers de confiance et effectuons un audit qualité interne avant la livraison. Voici les points que nous vérifions :

<Card title="Exhaustivité du contenu" icon="file-check">
  * Toute la documentation de votre source a bien été migrée.
  * Le contenu est correctement mis en forme avec les Composants Mintlify.
  * La structure de navigation correspond à vos spécifications.
</Card>

<Card title="Éléments visuels" icon="palette">
  * Les images et les vidéos s’affichent correctement.
  * Les polices personnalisées sont appliquées sur l’ensemble du site.
  * Les logos des modes clair et sombre sont utilisés à bon escient.
  * Les palettes de couleurs respectent les exigences de contraste dans les deux modes.
</Card>

<Card title="Fonctionnement" icon="rocket">
  * Tous les liens fonctionnent correctement (aucun lien cassé).
  * La table des matières s’affiche correctement.
  * Les composants React fonctionnent comme prévu.
  * Aucun problème de performances.
</Card>

<div id="after-your-migration">
  ## Après votre migration
</div>

Une fois votre migration terminée, vous devrez suivre les étapes suivantes pour mettre votre documentation en ligne :

1. [Connectez votre dépôt GitHub et finalisez la configuration](/fr/quickstart#install-the-github-app).
2. [Configurez les redirections, si nécessaire](/fr/create/redirects).
3. [Configurez votre domaine personnalisé](/fr/customize/custom-domain).
4. **Testez avant la mise en ligne** - Avant de remplacer votre ancienne documentation :
   * Vérifiez toutes les pages sur votre lien de préproduction.
   * Testez la navigation et la recherche.
   * Vérifiez que toutes les images et vidéos se chargent correctement.
   * Vérifiez que les blocs de code s’affichent correctement.
   * Testez sur mobile et sur ordinateur.
5. **Mise en ligne !** Votre documentation est prête à être mise en ligne !

<Note>
  **Besoin d’aide ?** Notre équipe de migration est disponible pour vous guider dans ces étapes. Contactez-la via votre canal Slack dédié ou à [support@mintlify.com](mailto:support@mintlify.com).
</Note>

<div id="frequently-asked-questions">
  ## Questions fréquentes
</div>

<AccordionGroup>
  <Accordion title="Combien de temps dure une migration ?">
    Nous livrons généralement les migrations en 2 à 6 semaines, selon leur complexité. Vous recevrez un calendrier précis après l’appel de lancement.
  </Accordion>

  <Accordion title="Puis-je demander des modifications après la livraison ?">
    Oui. Vous disposez d’un délai de 7 jours après la livraison pour demander des modifications du contenu, des ressources ou de l’identité visuelle. Nous traitons tous les retours inclus dans le périmètre dans ce même délai et travaillons avec vous jusqu’à ce que vous soyez prêt à mettre votre site en ligne.
  </Accordion>

  <Accordion title="Que dois-je faire une fois la migration terminée ?">
    La migration transfère votre contenu, mais vous devrez :

    * Connecter votre dépôt de documentation à votre tableau de bord Mintlify.
    * Mettre en place des redirections depuis les URL de votre ancienne documentation.
    * Configurer votre domaine personnalisé.

    Nous fournissons une documentation étape par étape et une assistance pour chacune de ces étapes.
  </Accordion>

  <Accordion title="Puis-je personnaliser la structure de navigation ?">
    Oui. Vous pouvez fournir une architecture de l’information personnalisée, et nous l’implémenterons. Nous pouvons également vous accompagner dans le développement de composants personnalisés si nécessaire et si la plateforme le permet.
  </Accordion>

  <Accordion title="Que se passe-t-il si ma documentation change pendant la migration ?">
    Comme les migrations nécessitent un gel du code, toute modification apportée à votre documentation source après sa soumission ne sera pas incluse. Nous vous recommandons de finaliser toutes les mises à jour avant de lancer la migration.

    Si cela n’est pas possible, notre équipe travaillera avec vous pour organiser de courts sprints afin de migrer certaines sections, ou réserver du temps dédié après le premier sprint pour migrer les modifications apportées pendant la migration.
  </Accordion>
</AccordionGroup>
