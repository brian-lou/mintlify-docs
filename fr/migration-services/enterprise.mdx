Vous pouvez opter pour nos services de migration afin de transférer votre documentation vers Mintlify. Ce guide présente le processus de migration, les délais de livraison et notre approche de l’assurance qualité.

<div id="what-to-expect-for-your-migration">
  ## À quoi vous attendre lors de votre migration
</div>

Une migration est un transfert ponctuel de votre documentation qui nécessite un gel du code. Nous migrons votre documentation, les pages de référence d’API, l’image de marque (logos, couleurs et polices) et la structure de navigation. Les services de migration incluent également une consultation en matière de conception ou d’architecture de l’information, ainsi que le développement de composants personnalisés, tels que des pages d’atterrissage ou des intégrations sur mesure.

Votre migration inclut un lien vers un environnement de préproduction pour suivre l’avancement, ainsi qu’une période de 7 jours après la livraison pour signaler et résoudre tout problème lié au contenu, aux ressources ou à l’image de marque.

<div id="migration-process">
  ## Processus de migration
</div>

Le processus de migration repose sur une forte collaboration. Nous travaillons en étroite collaboration avec votre équipe pour mettre en place des solutions et des implémentations personnalisées qui vous conviennent vraiment.

<Steps>
  <Step title="Soumettre le formulaire de migration">
    Soumettez le [formulaire de migration](https://mintlify.typeform.com/pro-migrations).

    Fournissez la source de votre documentation, vos éléments de marque (logos, codes couleur, polices), les spécifications OpenAPI, la date de mise en production et votre méthode de livraison préférée (pull request GitHub ou fichier zip).
  </Step>

  <Step title="Appel de lancement">
    Nous examinons votre demande et organisons un appel de lancement avec notre équipe de migration pour passer en revue votre configuration actuelle, comprendre d’éventuelles contraintes et répondre à toutes les questions de votre équipe.
  </Step>

  <Step title="Recevoir le cadrage et le calendrier (1 à 2 jours ouvrés)">
    Nous analysons les éléments abordés lors de l’appel et vous fournissons un calendrier de livraison estimatif sous 24 à 48 heures. Nous signalerons tout composant personnalisé ou toute partie de votre migration nécessitant une discussion.
  </Step>

  <Step title="Suivre l’avancement pendant la migration">
    Nous lançons la migration et partageons un lien de préproduction afin que vous puissiez suivre l’avancement en temps réel.
  </Step>

  <Step title="Recevoir la livraison finale">
    Nous livrons votre migration via une pull request GitHub ou un fichier zip, en fonction de votre préférence.
  </Step>

  <Step title="Période de retours (sept jours ouvrés)">
    Transmettez-nous vos retours sur le contenu, les éléments graphiques ou l’image de marque. Nous traitons tous les points entrant dans le périmètre dans le même délai.
  </Step>

  <Step title="Assistance pour la mise en production">
    Nous fournissons de la documentation et des recommandations pour connecter votre dépôt, configurer les redirections et paramétrer votre domaine personnalisé.
  </Step>
</Steps>

<div id="quality-assurance">
  ## Assurance qualité
</div>

Nous travaillons avec des prestataires externes rigoureusement sélectionnés et effectuons un audit interne de la qualité avant la livraison. Voici ce que nous vérifions :

<Card title="Exhaustivité du contenu" icon="file-check">
  * Toute la documentation provenant de votre source a été migrée.
  * Le contenu est correctement mis en forme avec les composants Mintlify.
  * La structure de navigation correspond à vos spécifications.
</Card>

<Card title="Éléments visuels" icon="palette">
  * Les images et les vidéos s&#39;affichent correctement.
  * Les polices personnalisées sont appliquées de manière homogène.
  * Les logos pour les modes clair et sombre sont utilisés de manière appropriée.
  * Les jeux de couleurs respectent les exigences de contraste dans les deux modes.
</Card>

<Card title="Fonctionnalité" icon="rocket">
  * Tous les liens fonctionnent correctement (aucun lien mort).
  * La table des matières s&#39;affiche correctement.
  * Les composants React fonctionnent comme prévu.
  * Aucun problème de performances.
</Card>

<div id="after-your-migration">
  ## Après votre migration
</div>

Une fois que nous aurons livré votre migration, vous devrez effectuer les étapes suivantes pour lancer votre documentation :

1. [Connectez votre dépôt GitHub et terminez la configuration](/fr/quickstart#install-the-github-app).
2. [Configurez les redirections, si nécessaire](/fr/create/redirects).
3. [Configurez votre domaine personnalisé](/fr/customize/custom-domain).
4. **Testez avant la mise en production** - Avant de basculer depuis votre ancienne documentation :
   * Passez en revue toutes les pages sur votre lien de préproduction.
   * Testez la navigation et la fonction de recherche.
   * Vérifiez que toutes les images et vidéos se chargent correctement.
   * Vérifiez que les blocs de code s’affichent correctement.
   * Testez sur mobile et sur ordinateur.
5. **Lancez-vous !** Votre documentation est prête à être mise en ligne !

<Note>
  **Besoin d’aide ?** Notre équipe de migration est disponible pour vous accompagner dans ces étapes. Contactez-nous via votre canal Slack dédié ou [support@mintlify.com](mailto:support@mintlify.com).
</Note>

<div id="frequently-asked-questions">
  ## Foire aux questions
</div>

<AccordionGroup>
  <Accordion title="Combien de temps dure une migration ?">
    Nous réalisons généralement les migrations en 2 à 6 semaines, selon la complexité. Vous recevrez un planning précis après l&#39;appel de lancement.
  </Accordion>

  <Accordion title="Puis-je demander des modifications après la livraison ?">
    Oui. Vous disposez d&#39;un délai de 7 jours après la livraison pour nous faire part de vos retours sur le contenu, les ressources ou l&#39;identité visuelle. Nous traitons tous les retours entrant dans le périmètre prévu dans le même délai et collaborons avec vous jusqu&#39;à ce que vous soyez prêt à mettre votre documentation en ligne.
  </Accordion>

  <Accordion title="Que dois-je faire une fois la migration terminée ?">
    La migration transfère votre contenu, mais vous devrez :

    * Connecter votre dépôt de documentation à votre tableau de bord Mintlify.
    * Configurer les redirections depuis les anciennes URL de votre documentation.
    * Configurer votre domaine personnalisé.

    Nous fournissons une documentation pas à pas ainsi qu&#39;une assistance pour chacune de ces étapes.
  </Accordion>

  <Accordion title="Puis-je personnaliser la structure de navigation ?">
    Oui. Vous pouvez fournir une architecture de l’information personnalisée et nous la mettrons en place. Nous travaillons également avec vous sur le développement de composants personnalisés si nécessaire et si la plateforme le permet.
  </Accordion>

  <Accordion title="Que se passe-t-il si ma documentation change pendant la migration ?">
    Étant donné que les migrations nécessitent un gel du code, toute modification apportée à votre documentation source après la soumission ne sera pas incluse. Nous recommandons de finaliser toutes les mises à jour avant de lancer la migration.

    Si ce n&#39;est pas possible, notre équipe collaborera avec vous pour définir de courts sprints afin de migrer certaines sections ou de réserver un créneau dédié après le premier sprint pour migrer les modifications effectuées pendant la migration.
  </Accordion>
</AccordionGroup>
