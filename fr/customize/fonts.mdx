Définissez une police personnalisée pour l’ensemble de votre site, ou choisissez-en une pour les titres et une autre pour le corps du texte. Utilisez Google Fonts, des fichiers de police locaux ou des polices hébergées en externe. La police par défaut varie selon le thème.

Les polices sont configurées via la [propriété fonts](/fr/organize/settings#param-fonts) dans votre `docs.json`.

<div id="google-fonts">
  ## Google Fonts
</div>

Mintlify charge automatiquement [Google Fonts](https://fonts.google.com) lorsque vous spécifiez le nom d’une famille de polices dans votre `docs.json`.

```json docs.json
"fonts": {
  "family": "Inter"
}
```

<div id="local-fonts">
  ## Polices locales
</div>

Pour utiliser des polices locales, placez les fichiers de police dans le répertoire de votre projet et faites-y référence dans votre configuration `docs.json`.

<div id="setting-up-local-fonts">
  ### Configurer des polices locales
</div>

<Steps>
  <Step title="Ajouter les fichiers de police à votre projet">
    Par exemple, créez un dossier `fonts` et ajoutez-y vos fichiers de police :

    ```text
    your-project/
    ├── fonts/
    │   ├── InterDisplay-Regular.woff2
    │   └── InterDisplay-Bold.woff2
    ├── docs.json
    └── ...
    ```
  </Step>

  <Step title="Configurer les polices dans docs.json">
    Indiquez vos polices locales à l’aide de chemins relatifs à partir de la racine de votre projet :

    ```json docs.json
    {
      "fonts": {
        "family": "InterDisplay",
        "source": "/fonts/InterDisplay-Regular.woff2",
        "format": "woff2",
        "weight": 400
      }
    }
    ```
  </Step>
</Steps>

<div id="local-fonts-for-headings-and-body">
  ### Polices locales pour les titres et le corps de texte
</div>

Configurez des polices locales distinctes pour les titres et le corps de texte dans votre `docs.json` :

```json docs.json
{
  "fonts": {
    "heading": {
      "family": "InterDisplay",
      "source": "/fonts/InterDisplay-Bold.woff2",
      "format": "woff2",
      "weight": 700
    },
    "body": {
      "family": "InterDisplay",
      "source": "/fonts/InterDisplay-Regular.woff2",
      "format": "woff2",
      "weight": 400
    }
  }
}
```

<div id="externally-hosted-fonts">
  ## Polices hébergées en externe
</div>

Utilisez des polices hébergées en externe en indiquant l’URL source de la police dans votre `docs.json` :

```json docs.json
{
  "fonts": {
    "family": "Hubot Sans",
    "source": "https://mintlify-assets.b-cdn.net/fonts/Hubot-Sans.woff2",
    "format": "woff2",
    "weight": 400
  }
}
```

      Nom de la famille de polices, comme &quot;Inter&quot; ou &quot;Playfair Display&quot;.

    <ResponseField name="weight" type="number">
      Graisse de la police, comme 400 ou 700. Les polices variables prennent en charge des graisses précises, comme 550.
    </ResponseField>

    <ResponseField name="source" type="string (uri)">
      URL de la source de votre police, comme `https://mintlify-assets.b-cdn.net/fonts/Hubot-Sans.woff2`, ou chemin vers votre fichier de police local, comme `/assets/fonts/InterDisplay.woff2`. Les polices Google Fonts sont chargées automatiquement lorsque vous indiquez un nom de `family` Google Font ; aucune URL source n&#39;est donc nécessaire.
    </ResponseField>

      Format du fichier de police. Obligatoire lorsque vous utilisez le champ `source`.
    </ResponseField>
