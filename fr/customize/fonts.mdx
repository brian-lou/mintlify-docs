Définissez une police personnalisée pour l’ensemble de votre site, ou séparément pour les titres et le corps du texte. Utilisez Google Fonts, des fichiers de polices locaux ou des polices hébergées en externe. La police par défaut varie selon le thème.

Les polices sont définies via la [propriété fonts](/fr/organize/settings#param-fonts) dans votre `docs.json`.

<div id="google-fonts">
  ## Google Fonts
</div>

Mintlify charge automatiquement les [Google Fonts](https://fonts.google.com) lorsque vous spécifiez un nom de famille de police dans votre `docs.json`.

```json docs.json
"fonts": {
  "family": "Inter"
}
```

<div id="local-fonts">
  ## Polices locales
</div>

Pour utiliser des polices locales, placez vos fichiers de police dans le répertoire de votre projet et référencez-les dans votre configuration `docs.json`.

<div id="setting-up-local-fonts">
  ### Configurer des polices locales
</div>

<Steps>
  <Step title="Ajoutez les fichiers de police à votre projet">
    Par exemple, créez un répertoire `fonts` et ajoutez vos fichiers de police :

    ```text
    your-project/
    ├── fonts/
    │   ├── InterDisplay-Regular.woff2
    │   └── InterDisplay-Bold.woff2
    ├── docs.json
    └── ...
    ```
  </Step>

  <Step title="Configurez les polices dans docs.json">
    Déclarez vos polices locales en utilisant des chemins relatifs depuis la racine de votre projet :

    ```json docs.json
    {
      "fonts": {
        "family": "InterDisplay",
        "source": "/fonts/InterDisplay-Regular.woff2",
        "format": "woff2",
        "weight": 400
      }
    }
    ```
  </Step>
</Steps>

<div id="local-fonts-for-headings-and-body">
  ### Polices locales pour les titres et le texte principal
</div>

Définissez des polices locales distinctes pour les titres et le texte principal dans votre `docs.json` :

```json docs.json
{
  "fonts": {
    "heading": {
      "family": "InterDisplay",
      "source": "/fonts/InterDisplay-Bold.woff2",
      "format": "woff2",
      "weight": 700
    },
    "body": {
      "family": "InterDisplay",
      "source": "/fonts/InterDisplay-Regular.woff2",
      "format": "woff2",
      "weight": 400
    }
  }
}
```

<div id="externally-hosted-fonts">
  ## Polices hébergées en externe
</div>

Utilisez des polices hébergées en externe en indiquant l’URL de la source de la police dans votre fichier `docs.json` :

```json docs.json
{
  "fonts": {
    "family": "Hubot Sans",
    "source": "https://mintlify-assets.b-cdn.net/fonts/Hubot-Sans.woff2",
    "format": "woff2",
    "weight": 400
  }
}
```

<ResponseField name="fonts" type="object">
  Configuration des polices de votre documentation.

  <Expandable title="Polices">

      Nom de la famille de polices, comme &quot;Inter&quot; ou &quot;Playfair Display&quot;.
    </ResponseField>

    <ResponseField name="weight" type="number">
      Graisse de la police, par exemple 400 ou 700. Les polices variables prennent en charge des graisses précises comme 550.
    </ResponseField>

    <ResponseField name="source" type="string (uri)">
      URL de la source de la police, comme `https://mintlify-assets.b-cdn.net/fonts/Hubot-Sans.woff2`, ou chemin vers votre fichier de police local, comme `/assets/fonts/InterDisplay.woff2`. Les Google Fonts sont chargées automatiquement lorsque vous indiquez un nom de `family` de Google Font, il n’est donc pas nécessaire de fournir une URL de source.
    </ResponseField>

    <ResponseField name="format" type="'woff' | 'woff2'">
      Format du fichier de police. Obligatoire lorsque le champ `source` est utilisé.
    </ResponseField>
