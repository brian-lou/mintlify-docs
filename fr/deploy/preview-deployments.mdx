<Info>
  Les déploiements de prévisualisation sont disponibles avec les [offres Pro et Enterprise](https://mintlify.com/pricing?ref=preview-deployments).
</Info>

Les déploiements de prévisualisation vous permettent de voir à quoi ressembleront les modifications apportées à votre documentation avant leur mise en production. Chaque prévisualisation génère une URL partageable qui se met automatiquement à jour à mesure que vous envoyez de nouvelles modifications.

Les URL de prévisualisation sont accessibles publiquement par défaut. Partagez un lien de prévisualisation avec toute personne devant relire vos modifications.

<div id="create-preview-deployments">
  ## Créer des déploiements de prévisualisation
</div>

Les déploiements de prévisualisation sont créés automatiquement à partir des pull requests, ou manuellement depuis votre tableau de bord.

<div id="automatic-previews">
  ### Prévisualisations automatiques
</div>

<Note>
  Les prévisualisations automatiques sont créées uniquement pour les pull requests qui ciblent votre [branche de déploiement](/fr/guides/git-concepts#deployment-branch).
</Note>

Lorsque vous créez une pull request, le bot Mintlify ajoute automatiquement un lien pour afficher le déploiement de prévisualisation dans la pull request. La prévisualisation se met à jour chaque fois que vous envoyez de nouveaux commits vers la branche.

<div id="manual-previews">
  ### Prévisualisations manuelles
</div>

Vous pouvez créer manuellement une prévisualisation pour n’importe quelle branche.

1. Accédez à votre [tableau de bord](https://dashboard.mintlify.com/).
2. Sélectionnez **Previews**.
3. Sélectionnez **Create custom preview**.
4. Saisissez le nom de la branche à prévisualiser.
5. Sélectionnez **Create deployment**.

<div id="redeploy-a-preview">
  ## Redéployer une prévisualisation
</div>

Redéployez une prévisualisation pour actualiser le contenu ou réessayer après un échec de déploiement.

1. Sélectionnez la prévisualisation dans votre [tableau de bord](https://dashboard.mintlify.com/).
2. Sélectionnez **Redéployer**.

<div id="preview-widget">
  ## Widget de prévisualisation
</div>

Le widget de prévisualisation apparaît sur les déploiements de prévisualisation pour vous aider à naviguer et à passer en revue les pages mises à jour. Il se présente sous la forme d’un bouton flottant dans l’angle inférieur droit de votre déploiement de prévisualisation.

<Frame>
  <img src="/images/previews/widget-light.png" alt="Widget de prévisualisation déployé pour afficher la liste des fichiers modifiés." className="block dark:hidden" />

  <img src="/images/previews/widget-dark.png" alt="Widget de prévisualisation déployé pour afficher la liste des fichiers modifiés." className="hidden dark:block" />
</Frame>

1. Cliquez sur le widget pour afficher tous les fichiers ajoutés, modifiés ou supprimés dans la prévisualisation.
2. Cliquez sur un fichier pour voir les modifications sur la page correspondante.
3. Utilisez la barre de recherche pour filtrer la liste des fichiers modifiés.

Le widget apparaît uniquement sur les déploiements de prévisualisation, et non sur votre site en ligne ni dans vos prévisualisations locales.

<div id="restrict-access-to-preview-deployments">
  ## Restreindre l’accès aux déploiements de prévisualisation
</div>

Par défaut, les déploiements de prévisualisation sont accessibles à toute personne disposant de l’URL. Vous pouvez en restreindre l’accès aux membres authentifiés de votre organisation Mintlify.

1. Accédez à la section **Previews** de la page [Add-ons](https://dashboard.mintlify.com/products/addons) de votre tableau de bord.
2. Cliquez sur le bouton bascule **Preview authentication** pour activer ou désactiver l’authentification des prévisualisations.

<div id="troubleshooting-preview-deployments">
  ## Dépannage des déploiements de prévisualisation
</div>

Si votre déploiement de prévisualisation échoue, essayez les étapes de dépannage suivantes.

* **Consultez les logs de build** : dans votre [tableau de bord](https://dashboard.mintlify.com/), accédez à **Previews** et cliquez sur la prévisualisation en échec. Les logs de déploiement affichent les erreurs à l’origine de l’échec.
* **Vérifiez votre configuration** :
  * Syntaxe `docs.json` non valide
  * Chemins de fichiers manquants ou incorrects indiqués dans votre navigation
  * Frontmatter non valide dans les fichiers MDX
  * Liens d’image rompus ou fichiers image manquants
* **Validez en local** : exécutez `mint dev` en local pour repérer les erreurs de build avant de push vers le dépôt.
* **Vérifiez les modifications récentes** : examinez les commits les plus récents de votre branche pour identifier les changements à l’origine de l’échec du build.
