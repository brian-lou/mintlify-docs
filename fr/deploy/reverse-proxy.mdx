<Note>
  Les configurations de proxy inverse sont uniquement prises en charge avec les [offres Enterprise](https://mintlify.com/pricing?ref=reverse-proxy).
</Note>

Pour diffuser votre documentation via un proxy inverse personnalisé, vous devez configurer les règles de routage, les politiques de mise en cache et la transmission des en-têtes.

Lorsque vous mettez en place un proxy inverse, surveillez les problèmes potentiels liés à la vérification du domaine, au provisionnement du certificat SSL, aux flux d&#39;authentification, aux performances et au suivi analytique.

<div id="choose-your-deployment-approach">
  ## Choisissez votre méthode de déploiement
</div>

Mintlify prend en charge deux configurations de proxy inverse selon vos besoins en matière de sous-chemin.

* **Host at `/docs`**: utilisez `mintlify.dev` comme cible du proxy. Activez l’option **Host at `/docs`** sur la page [Custom domain setup](https://dashboard.mintlify.com/settings/deployment/custom-domain) de votre tableau de bord. Cette configuration est plus simple et comporte moins de routes.
* **sous-chemin personnalisé**: utilisez `mintlify.app` comme cible du proxy. Cette approche prend en charge n’importe quel sous-chemin et nécessite des règles de routage supplémentaires.

<div id="host-at-docs-subpath">
  ## Héberger sur le sous-chemin `/docs`
</div>

Utilisez cette configuration lorsque vous souhaitez héberger la documentation sur le chemin `/docs` de votre domaine.

Avant de configurer votre proxy inverse :

1. Accédez à [Custom domain setup](https://dashboard.mintlify.com/settings/deployment/custom-domain) dans votre tableau de bord.
2. Activez le bouton **Host at `/docs`**.
3. Saisissez votre domaine, puis sélectionnez **Add domain**.

<Warning>
  Lorsque vous activez **Host at `/docs`**, l’URL canonique de votre documentation devient `<your-subdomain>.mintlify.dev`. L’invalidation du cache ne fonctionne plus sur `mintlify.app`, et vous devez configurer le proxy vers `mintlify.dev` pour que les mises à jour s’affichent.
</Warning>

<div id="routing-configuration">
  ### Configuration de routage
</div>

Redirigez ces chemins via un proxy vers votre sous-domaine Mintlify :

| Chemin                               | Destination                          | Mise en cache |
| ------------------------------------ | ------------------------------------ | ------------- |
| `/docs`                              | `<your-subdomain>.mintlify.dev/docs` | Sans cache    |
| `/docs/*`                            | `<your-subdomain>.mintlify.dev/docs` | Sans cache    |
| `/.well-known/vercel/*`              | `<your-subdomain>.mintlify.dev`      | Sans cache    |
| `/.well-known/skills/*` (facultatif) | `<your-subdomain>.mintlify.dev/docs` | Sans cache    |
| `/skill.md` (facultatif)             | `<your-subdomain>.mintlify.dev/docs` | Sans cache    |

Les routes `/.well-known/skills/*` et `/skill.md` sont facultatives. Incluez-les uniquement si vous voulez servir des fichiers de compétences d’IA à la racine, comme `your-domain.com/skills.md`, plutôt que sous votre sous-chemin de documentation, comme `your-domain.com/docs/skills.md`.

<div id="required-header-configuration">
  ### Configuration requise des en-têtes
</div>

Configurez votre proxy inverse avec les en-têtes suivants :

* **Origin** : contient le sous-domaine cible `<your-subdomain>.mintlify.dev`
* **X-Forwarded-For** : préserve les informations sur l’adresse IP du client
* **X-Forwarded-Proto** : préserve le protocole d’origine (http/https)
* **X-Real-IP** : transmet l’adresse IP réelle du client
* **User-Agent** : transmet l’agent utilisateur

<Warning>
  Assurez-vous que l’en-tête `Host` n’est pas transmis.
</Warning>

<div id="example-nginx-configuration">
  ### Exemple de configuration Nginx
</div>

```nginx
server {
    listen 80;
    server_name <your-domain>.com;

    # Chemins de vérification Vercel
    location ~ ^/\.well-known/vercel/ {
        proxy_pass https://<your-subdomain>.mintlify.dev;
        proxy_set_header Origin <your-subdomain>.mintlify.dev;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }

    # Chemins des compétences IA
    location ^~ /.well-known/skills/ {
        proxy_pass https://<your-subdomain>.mintlify.dev/docs;
        proxy_set_header Origin <your-subdomain>.mintlify.dev;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }

    # Manifeste de compétence (facultatif)
    location = /skill.md {
        proxy_pass https://<your-subdomain>.mintlify.dev/docs;
        proxy_set_header Origin <your-subdomain>.mintlify.dev;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }

    # Racine de la documentation
    location = /docs {
        proxy_pass https://<your-subdomain>.mintlify.dev/docs;
        proxy_set_header Origin <your-subdomain>.mintlify.dev;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }

    # Tous les chemins de documentation
    location /docs/ {
        proxy_pass https://<your-subdomain>.mintlify.dev/docs/;
        proxy_set_header Origin <your-subdomain>.mintlify.dev;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }
}
```


<div id="custom-subpath">
  ## Sous-chemin personnalisé
</div>

Lorsque vous avez besoin d’un sous-chemin autre que `/docs` (par exemple `/help` ou `/resources`), utilisez la configuration de routage suivante.

Redirigez ces chemins vers votre sous-domaine Mintlify avec les règles de mise en cache indiquées :

| Chemin                            | Destination                     | Mise en cache |
| --------------------------------- | ------------------------------- | ------------- |
| `/.well-known/vercel/*`           | `<your-subdomain>.mintlify.app` | sans cache    |
| `/.well-known/skills/*`           | `<your-subdomain>.mintlify.app` | sans cache    |
| `/skill.md`                       | `<your-subdomain>.mintlify.app` | sans cache    |
| `/mintlify-assets/_next/static/*` | `<your-subdomain>.mintlify.app` | Activée       |
| `/_mintlify/*`                    | `<your-subdomain>.mintlify.app` | sans cache    |
| `/*`                              | `<your-subdomain>.mintlify.app` | sans cache    |
| `/`                               | `<your-subdomain>.mintlify.app` | sans cache    |

### Configuration des en-têtes requise

Configurez votre proxy inverse avec les en-têtes suivants :

* **Origin** : contient le sous-domaine cible `<your-subdomain>.mintlify.app`
* **X-Forwarded-For** : préserve les informations d’IP du client
* **X-Forwarded-Proto** : préserve le protocole d’origine (HTTP/HTTPS)
* **X-Real-IP** : transmet l’adresse IP réelle du client
* **User-Agent** : transmet l’agent utilisateur

<Warning>
  Veillez à ne pas transférer l’en-tête `Host`
</Warning>

<div id="example-nginx-configuration">
  ### Exemple de configuration Nginx
</div>

```nginx
server {
    listen 80;
    server_name <your-domain>.com;

    # Chemins de vérification Vercel
    location ~ ^/\.well-known/vercel/ {
        proxy_pass https://<your-subdomain>.mintlify.app;
        proxy_set_header Origin <your-subdomain>.mintlify.app;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        # Désactiver le cache pour les chemins de vérification
        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }

    # Chemins des compétences IA
    location ^~ /.well-known/skills/ {
        proxy_pass https://<your-subdomain>.mintlify.app;
        proxy_set_header Origin <your-subdomain>.mintlify.app;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        # Désactiver le cache pour les chemins de vérification
        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }

    # Manifeste de compétence
    location = /skill.md {
        proxy_pass https://<your-subdomain>.mintlify.app;
        proxy_set_header Origin <your-subdomain>.mintlify.app;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        # Désactiver le cache pour le manifeste de compétence
        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }

    # Ressources statiques avec mise en cache
    location ~ ^/mintlify-assets/_next/static/ {
        proxy_pass https://<your-subdomain>.mintlify.app;
        proxy_set_header Origin <your-subdomain>.mintlify.app;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        # Activer le cache pour les ressources statiques
        add_header Cache-Control "public, max-age=86400";
    }

    # Chemins spécifiques à Mintlify
    location ~ ^/_mintlify/ {
        proxy_pass https://<your-subdomain>.mintlify.app;
        proxy_set_header Origin <your-subdomain>.mintlify.app;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        # Désactiver le cache pour les chemins Mintlify
        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }

    # Chemin racine
    location = / {
        proxy_pass https://<your-subdomain>.mintlify.app;
        proxy_set_header Origin <your-subdomain>.mintlify.app;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        # Désactiver le cache pour le contenu dynamique
        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }

    # Tous les autres chemins de documentation
    location / {
        proxy_pass https://<your-subdomain>.mintlify.app;
        proxy_set_header Origin <your-subdomain>.mintlify.app;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        # Désactiver le cache pour le contenu dynamique
        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }
}
```


<div id="troubleshooting">
  ## Dépannage
</div>

<div id="changes-not-appearing">
  ### Les modifications n’apparaissent pas
</div>

**Symptômes** : vous publiez des mises à jour de la documentation, mais les modifications n’apparaissent pas sur votre site.

**Cause** : l’option **Host at `/docs`** est activée dans votre tableau de bord, mais votre proxy inverse pointe vers `mintlify.app` au lieu de `mintlify.dev`.

**Solution** : mettez à jour la configuration de votre proxy inverse afin qu’elle pointe vers `<your-subdomain>.mintlify.dev` plutôt que vers `<your-subdomain>.mintlify.app`.

<div id="404-error">
  ### Erreur 404
</div>

**Symptômes** : La documentation se charge, mais les fonctionnalités ne marchent pas. Les appels d’API échouent.

**Cause** : Le proxy inverse transmet l’en-tête `Host`, ou l’en-tête `Origin` est absent.

**Solution** :

* Désactivez le transfert de l’en-tête `Host`
* Définissez l’en-tête `Origin` sur votre sous-domaine Mintlify (`mintlify.dev` pour un sous-chemin `/docs` ou `mintlify.app` pour un autre sous-chemin)

<div id="performance-issues">
  ### Problèmes de performances
</div>

**Symptômes** : Chargement lent des pages et décalages de mise en page.

**Cause** : Configuration incorrecte de la mise en cache.

**Solution** : Pour les configurations de sous-chemin personnalisées, activez la mise en cache uniquement pour les chemins `/mintlify-assets/_next/static/*`. La configuration du sous-chemin `/docs` gère automatiquement la mise en cache.
