Configurez Mintlify pour déployer la documentation depuis un répertoire spécifique au sein d&#39;un monorepo. Cette configuration vous permet de gérer la documentation aux côtés de votre code dans des dépôts qui regroupent plusieurs projets ou services.

<div id="prerequisites">
  ## Prérequis
</div>

* Un accès administrateur à votre projet Mintlify.
* Des fichiers de documentation organisés dans un répertoire dédié de votre monorepo.
* Un fichier `docs.json` valide dans votre répertoire de documentation.

<div id="configure-monorepo-deployment">
  ## Configurer le déploiement dans un monorepo
</div>

<Steps>
  <Step title="Accéder aux paramètres Git">
    Accédez à [Git Settings](https://dashboard.mintlify.com/settings/deployment/git-settings) dans votre tableau de bord.

    <Frame>
      <img className="block dark:hidden my-0 pointer-events-none" src="/images/monorepo-light.png" alt="Le panneau des paramètres du projet dans le menu Git Settings. Le bouton bascule Set up as monorepo est activé, et un chemin vers le répertoire /docs est indiqué." />

      <img className="hidden dark:block my-0 pointer-events-none" src="/images/monorepo-dark.png" alt="Le panneau des paramètres du projet dans le menu Git Settings. Le bouton bascule Set up as monorepo est activé, et un chemin vers le répertoire /docs est indiqué." />
    </Frame>
  </Step>

  <Step title="Définir le chemin de votre documentation">
    1. Activez le bouton bascule **Set up as monorepo**.
    2. Saisissez le chemin relatif vers votre répertoire de documentation. Par exemple, si votre documentation se trouve dans le répertoire `docs`, saisissez `/docs`.

    <Note>
      N’ajoutez pas de barre oblique à la fin du chemin.
    </Note>

    3. Sélectionnez **Save changes**.
  </Step>
</Steps>
