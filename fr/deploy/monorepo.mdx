---
title: "Configuration d'un monorepo"
description: "Configurer le chemin de la documentation et le répertoire de contenu pour les projets en monorepo."
keywords: ["monorepo", "content directory", "multi-project repository"]
---

Configurez Mintlify pour déployer la documentation à partir d'un répertoire spécifique au sein d'un monorepo. Cette configuration vous permet de maintenir la documentation à côté de votre code dans des dépôts contenant plusieurs projets ou services.

<div id="prerequisites">
  ## Prérequis
</div>

* Accès administrateur à votre projet Mintlify.
* Fichiers de documentation organisés dans un répertoire dédié de votre monorepo.
* Un fichier `docs.json` valide dans votre répertoire de documentation.

<div id="configure-monorepo-deployment">
  ## Configurer le déploiement d’un monorepo
</div>

<Steps>
<Step title="Accéder aux paramètres Git">
Accédez à [Git Settings](https://dashboard.mintlify.com/settings/deployment/git-settings) dans votre tableau de bord.

<Frame>
<img
  className="block dark:hidden my-0 pointer-events-none"
  src="/images/monorepo-light.png"
  alt="Le panneau des paramètres du projet dans le menu Git Settings. L’option Set up as monorepo est activée et un chemin vers le répertoire /docs est spécifié."
/>
<img
  className="hidden dark:block my-0 pointer-events-none"
  src="/images/monorepo-dark.png"
  alt="Le panneau des paramètres du projet dans le menu Git Settings. L’option Set up as monorepo est activée et un chemin vers le répertoire /docs est spécifié."
/>
</Frame>

</Step>
<Step title="Définir le chemin de votre documentation">
1. Activez l’option **Set up as monorepo**.
2. Saisissez le chemin d’accès relatif à votre répertoire de documentation. Par exemple, si votre documentation se trouve dans le répertoire `docs`, saisissez `/docs`.
<Note>
  N’incluez pas de barre oblique à la fin du chemin.
</Note>
3. Sélectionnez **Save changes**.
</Step>
</Steps>
