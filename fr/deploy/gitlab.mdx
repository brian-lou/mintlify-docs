Nous utilisons des jetons d&#39;accès et des webhooks pour authentifier et synchroniser les modifications entre GitLab et Mintlify.

* Mintlify utilise des jetons d&#39;accès pour récupérer des informations depuis GitLab.
* GitLab utilise des webhooks pour notifier Mintlify lorsque des modifications sont effectuées, ce qui permet les déploiements de prévisualisation pour les merge requests.

<div id="set-up-the-connection">
  ## Configurer la connexion
</div>

<Note>
  **Clonage HTTPS requis** : le clonage HTTPS doit être activé pour votre projet GitLab afin que Mintlify puisse accéder à votre dépôt. Vous pouvez le vérifier dans GitLab en accédant à **Settings** &gt; **General** &gt; **Visibility and access controls**.
</Note>

<Steps>
  <Step title="Trouver l’ID de votre projet">
    Dans votre projet GitLab, accédez à **Settings** &gt; **General** et repérez votre **Project ID**.

    <Frame>
      <img src="/images/gitlab/gitlab-project-id.png" alt="La page General Settings du tableau de bord GitLab. Le Project ID est mis en évidence." />
    </Frame>
  </Step>

  <Step title="Générer un jeton d’accès">
    Accédez à **Settings** &gt; **Access Tokens**, puis sélectionnez **Add new token**.

    Configurez le jeton avec les paramètres suivants :

    * **Name** : Mintlify
    * **Role** : Maintainer (obligatoire pour les dépôts privés)
    * **Scopes** : `api` et `read_api`

    Cliquez sur **Create project access token**, puis copiez le jeton.

    <Note>
      Si les Project Access Tokens ne sont pas disponibles, vous pouvez utiliser un Personal Access Token à la place. Notez que les Personal Access Tokens expirent et doivent être mis à jour.
    </Note>

    <Frame>
      <img src="/images/gitlab/gitlab-project-access-token.png" alt="La page Access Tokens du tableau de bord GitLab. Les paramètres à configurer pour Mintlify sont mis en évidence." />
    </Frame>
  </Step>

  <Step title="Configurer la connexion">
    Dans le [tableau de bord Mintlify](https://dashboard.mintlify.com/settings/deployment/git-settings) :

    1. Saisissez l’ID de votre projet et le jeton d’accès.
    2. Effectuez toute autre configuration requise.
    3. Cliquez sur **Save Changes**.

    <Frame>
      <img src="/images/gitlab/gitlab-config-light.png" alt="Le panneau de configuration GitLab sur la page Git Settings du tableau de bord Mintlify." className="block dark:hidden" />

      <img src="/images/gitlab/gitlab-config-dark.png" alt="Le panneau de configuration GitLab sur la page Git Settings du tableau de bord Mintlify." className="hidden dark:block" />
    </Frame>
  </Step>
</Steps>

<div id="create-the-webhook">
  ## Créer le webhook
</div>

Les webhooks permettent de recevoir des événements lors de modifications afin de
déclencher automatiquement des déploiements.

<Steps>
  <Step title="Ajouter un nouveau webhook">
    1. Dans GitLab, accédez à **Settings** &gt; **Webhooks**.
    2. Cliquez sur **Add new webhook**.

    <Frame>
      <img src="/images/gitlab/gitlab-webhook.png" alt="Capture d’écran de la page Webhooks dans le tableau de bord GitLab." />
    </Frame>
  </Step>

  <Step title="Configurer l’URL et le webhook">
    Nommez le webhook **Mintlify**.

    Dans le champ **URL**, saisissez le point de terminaison `https://leaves.mintlify.com/gitlab-webhook`.
  </Step>

  <Step title="Obtenir le webtoken">
    Dans votre tableau de bord Mintlify, cliquez sur **Show Webtoken**. Copiez le webtoken.

    <Frame>
      <img src="/images/gitlab/show-webtoken-light.png" alt="Capture d’écran de la connexion GitLab dans le tableau de bord Mintlify." className="block dark:hidden" />

      <img src="/images/gitlab/show-webtoken-dark.png" alt="Capture d’écran de la connexion GitLab dans le tableau de bord Mintlify." className="hidden dark:block" />
    </Frame>
  </Step>

  <Step title="Coller le webtoken">
    Dans GitLab, collez le webtoken de votre tableau de bord Mintlify dans le champ **Secret token**.
  </Step>

  <Step title="Sélectionner les événements">
    Sélectionnez les événements suivants pour déclencher le webhook :

    * **Push events** (toutes les branches)
    * **Merge requests events**
  </Step>

  <Step title="Vérifier le webhook">
    Après avoir configuré le webhook, vous devriez voir les paramètres suivants :

    * **Name** : Mintlify
    * **URL** : `https://leaves.mintlify.com/gitlab-webhook`
    * **Secret token** : le webtoken de votre tableau de bord Mintlify
    * **Events** : **Push events** (toutes les branches) et **Merge requests events**

    Ajoutez le webhook.

    <Frame>
      <img src="/images/gitlab/gitlab-project-webtoken.png" alt="La page Webhook dans le tableau de bord GitLab. Les paramètres à configurer pour Mintlify sont mis en évidence." />
    </Frame>
  </Step>

  <Step title="Tester le webhook">
    Après avoir créé le webhook, cliquez sur le menu déroulant **Test**. Cliquez sur **Push events** pour envoyer un payload d’exemple. Si le test renvoie `Hook executed successfully: HTTP 200`, votre webhook est correctement configuré.

    <Frame>
      <img src="/images/gitlab/gitlab-project-webtoken-test.png" alt="Capture d’écran de la page GitLab Webhooks. L’élément de menu « Push events » est mis en évidence dans le menu « Test »." />
    </Frame>
  </Step>
</Steps>
