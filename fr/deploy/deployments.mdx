Votre site de documentation est automatiquement déployé lorsque vous envoyez des modifications vers votre dépôt connecté. Pour cela, l’application GitHub Mintlify doit être correctement installée et connectée.

Si vos dernières modifications n’apparaissent pas sur votre site en production, vérifiez d’abord que le compte ou l’organisation GitHub qui possède votre dépôt de documentation a bien l’application GitHub installée. Consultez la page [Dépannage GitHub](/fr/deploy/github#troubleshooting) pour plus d’informations.

Si l’application GitHub est bien installée mais que les modifications ne se déploient toujours pas, déclenchez manuellement un déploiement depuis votre tableau de bord.

<div id="manually-trigger-a-deployment">
  ## Déclencher manuellement un déploiement
</div>

<Steps>
  <Step title="Vérifier que votre dernier commit s’est bien déroulé.">
    Vérifiez que votre dernier commit apparaît dans votre dépôt de documentation et qu’il ne comporte aucune erreur.
  </Step>

  <Step title="Déclencher manuellement un déploiement.">
    Accédez à votre [tableau de bord](https://dashboard.mintlify.com) et cliquez sur le bouton de déploiement.

  </Step>
</Steps>

<div id="delete-a-deployment">
  ## Supprimer un déploiement
</div>

Vous pouvez supprimer définitivement un déploiement à partir de la [Danger zone](https://dashboard.mintlify.com/settings/organization/danger-zone) dans les paramètres de votre tableau de bord. Cette action est irréversible et supprime toutes les données du déploiement, y compris les déploiements de prévisualisation associés.

<Steps>
  <Step title="Accédez à la Danger zone.">
    Accédez à la [Danger zone](https://dashboard.mintlify.com/settings/organization/danger-zone) sur la page des paramètres de votre tableau de bord.
  </Step>

  <Step title="Supprimez le déploiement.">
    1. Dans la section **Delete my deployment**, indiquez un motif de suppression.
    2. Cliquez sur le bouton de suppression et confirmez que vous souhaitez supprimer le déploiement.
  </Step>
</Steps>

<Warning>
  La suppression d&#39;un déploiement est définitive et ne peut pas être annulée. Si vous avez un abonnement actif, vous recevrez un avoir calculé au prorata pour le temps non utilisé restant dans votre période de facturation.
</Warning>

Si vous avez plusieurs déploiements, vous serez redirigé vers un autre déploiement après la suppression. Si vous supprimez votre seul déploiement, vous serez redirigé vers la page d&#39;accueil de Mintlify. Lorsque vous supprimez un déploiement, l&#39;administrateur de l&#39;organisation reçoit un e-mail de notification confirmant la suppression.
