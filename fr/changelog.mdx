  ## Configuration du SSO en libre-service

  Les clients Enterprise peuvent désormais configurer le SSO SAML (Okta ou Microsoft Entra) directement depuis le tableau de bord, y compris le provisionnement juste-à-temps (JIT), le changement de fournisseur et la suppression de connexion.

  ## Rôle lecteur

  Nouveau rôle lecteur avec accès en lecture seule à votre tableau de bord. Les lecteurs peuvent voir le contenu dans l’éditeur, mais ils ne peuvent ni le modifier, ni inviter des membres, ni changer la configuration.

  ## Bascule trafic humain/IA

  La page d’analyse affiche désormais des onglets distincts pour le trafic humain et le trafic IA.

  ## Refonte du menu de commandes slash

  Le menu slash de l’éditeur propose désormais la recherche à la saisie, une navigation au clavier améliorée et d’autres améliorations UX.

  ## Correctifs

  * Correction du débordement des cellules dans les tableaux du tableau de bord.
  * Le renommage de fichiers via le panneau de configuration dans l’éditeur enregistre désormais correctement les modifications.
  * Les erreurs d’analyse MDX, comme une balise `<Card>` non fermée, se mettent désormais à jour dynamiquement à mesure que vous les corrigez, au lieu de persister à tort après rechargement.
  * Les poignées de glisser-déposer dans l’éditeur s’alignent désormais correctement avec différents types de contenu, comme les titres ou les paragraphes, avec une taille cohérente et de meilleures zones de clic.
</Update>

<Update label="23 janvier 2026" tags={["Nouveautés", "Améliorations"]} rss={{ title: "skills.md, journaux d’audit et export Markdown" }}>
  ## Génération automatique de `skill.md`

  Les sites de documentation génèrent désormais automatiquement un fichier `skill.md` à partir de vos références d’API, guides et fonctionnalités, afin de fournir aux agents IA un fichier de compétences complet avec le contexte nécessaire pour aider les utilisateurs à exploiter votre produit. `skill.md` remplace l’approche `install.md` avec des capacités plus structurées et une adoption plus large. Si vous avez un fichier `skills.md` personnalisé à la racine de votre dépôt de documentation, il remplace la version générée automatiquement. Consultez [skill.md](/fr/ai/skillmd) pour plus d’informations.

  ## Journaux d’audit pour les événements d’authentification

  Les événements sont désormais consignés dans les [journaux d’audit](/fr/dashboard/audit-logs) pour améliorer la visibilité et la conformité.

  ## Export Markdown pour les agents

  Les pages de documentation renvoient désormais le Markdown brut lorsque l’en-tête `Accept: text/markdown` est envoyé, ce qui permet aux agents IA de mieux exploiter le contenu.

  ## Améliorations

  * L’authentification combinée, l’authentification partielle et la personnalisation ont été réunies dans une seule expérience d’authentification. Consultez [Configuration de l’authentification](/fr/deploy/authentication-setup) pour plus d’informations.
  * Les pages masquées reçoivent désormais automatiquement des balises méta `noindex` pour un meilleur contrôle du SEO.
  * Ajout de la prise en charge du Markdown pour les légendes d’image.
</Update>

<Update label="9 janvier 2026" tags={["Nouveautés", "Améliorations"]} rss={{ title: "Extraits implicites et analyses des conversations de l’assistant pour tous" }}>
  ## Extraits implicites

  Les extraits fonctionnent désormais sans configuration explicite. Auparavant, vous deviez définir les extraits dans un répertoire `/snippets` spécifique. Désormais, vous pouvez importer n’importe quel fichier comme extrait depuis n’importe quel emplacement de votre documentation pour réutiliser le contenu plus facilement. Consultez [Extraits réutilisables](/fr/create/reusable-snippets) pour plus d’informations.

  ## Suggestions de l’assistant pour tous les utilisateurs

  Les [analyses des conversations](/fr/agent/suggestions#conversation-insights) sont désormais disponibles pour tous les sites de documentation sur lesquels l’agent et l’assistant sont activés. L’agent analyse les tendances dans les conversations avec l’assistant afin d’identifier les lacunes de la documentation et de suggérer des améliorations, ce qui vous aide à traiter de manière proactive les questions fréquentes des utilisateurs.

  ## Synchronisation des onglets et des groupes de code

  Les onglets et les groupes de code synchronisent désormais leur sélection sur toute la page. Lorsque vous sélectionnez un onglet dans un composant, tous les autres composants d’onglets avec des libellés correspondants se mettent à jour pour afficher la même sélection. Cela permet de conserver des choix de langage ou de framework cohérents sur l’ensemble d’une page.

  ## Améliorations

  * **Bordure inférieure des onglets** : ajout d’un style de bordure inférieure facultatif pour les onglets.
  * **Contrôles Mermaid** : contrôles interactifs pour les [diagrammes Mermaid](/fr/components/mermaid-diagrams) afin de naviguer dans les grands diagrammes.
  * **Paramètres d’URL pour la recherche et l’assistant** : ouvrez des pages avec la fenêtre modale de recherche préremplie avec `?search=` ou l’assistant avec `?assistant=`. Utilisez les paramètres de requête pour le lien direct et le partage de connaissances.
  * **Modification du nom de profil** : les utilisateurs peuvent désormais modifier leur prénom et leur nom dans les paramètres du profil.
</Update>

  ## Suggestions de l’agent

  L’agent peut désormais surveiller des dépôts Git et [suggérer](/fr/agent/suggestions) des mises à jour de la documentation. Lorsque des modifications de code visibles par les utilisateurs sont détectées, des suggestions apparaissent dans le panneau de l’agent. Ces suggestions incluent la pull request correspondante ainsi qu’une liste des mises à jour de documentation proposées. Ajoutez-les comme contexte pour que l’agent crée des pull requests, ou ignorez-les.

  ## Bots de questions-réponses dans Slack et Discord

  Ajoutez des bots alimentés par l’assistant à vos [espaces de travail Slack](/fr/ai/slack-bot) et [serveurs Discord](/fr/ai/discord). Les bots répondent aux questions en temps réel à partir de votre documentation, afin de fournir à vos communautés des réponses précises et à jour.

  Les bots répondent aux mentions `@` et à tous les messages dans les canaux nommés `#ask-ai`.

  ## Extraits prennent désormais en charge les imports relatifs

  Vous pouvez désormais utiliser des chemins relatifs lors de l’import d’extraits dans vos fichiers MDX. Auparavant, les imports nécessitaient des chemins absolus commençant par `/snippets/`. Vous pouvez maintenant utiliser des chemins relatifs comme `../snippets/example.mdx` pour organiser vos fichiers plus librement.

  ## Améliorations

  * **Insights** a été renommé **Analytics** dans le tableau de bord.
  * Ajout de la possibilité de supprimer un déploiement depuis le tableau de bord.
  * Le composant `Tooltip` a été repensé avec un style amélioré et prend désormais en charge une prop `headline` facultative pour ajouter un titre à vos infobulles.
  * La commande `mint a11y` prend désormais en charge les flags `--skip-contrast` et `--skip-alt-text`, ce qui vous permet d’exécuter des vérifications d’accessibilité spécifiques dans votre pipeline CI/CD. Utilisez `--skip-contrast` pour vérifier uniquement l’absence de texte alternatif, ou `--skip-alt-text` pour vérifier uniquement les ratios de contraste des couleurs.

  ## Corrections de bugs

  * Correction des liens à l’intérieur des onglets qui ne fonctionnaient pas correctement.
  * Correction du rendu des niveaux de titre 5 et 6 dans l’éditeur web.
  * Correction de l’affichage des exemples sur les pages de schéma dans la référence API.
  * Correction des chemins de téléversement d’images dans les configurations monorepo.
  * Correction d’un problème où la mauvaise valeur de charge utile de requête était sélectionnée en premier dans le Bac à sable API.
  * Suppression des extensions de fichier des titres d’image par défaut lors du téléversement.
  * Correction du style de double soulignement sur les liens de bannière.
  * Correction des états de chargement et des valeurs de plage de dates sur la page d’analyse.
  * Les dossiers dans l’éditeur web conservent désormais correctement leur état ouvert/fermé lorsque d’autres dossiers sont ouverts ou fermés.
  * Correction des titres longs de pages API qui débordaient au lieu de revenir à la ligne.

  Les déploiements d’aperçu incluent désormais un widget interactif qui affiche tous les fichiers modifiés dans le déploiement. Le widget apparaît sous la forme d’un bouton flottant dans le coin inférieur droit et fournit :
