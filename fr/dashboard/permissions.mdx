Les personnes ayant le [rôle](/fr/dashboard/roles) d’éditeur ou d’administrateur peuvent utiliser l’éditeur web, déclencher des déploiements et gérer les intégrations depuis votre tableau de bord. Lorsqu’un éditeur ou un administrateur publie via l’éditeur web ou fusionne une pull request dans votre dépôt de documentation, les modifications sont automatiquement déployées sur votre site public.

Toute personne ayant accès à votre dépôt de documentation peut contribuer à votre documentation en y apportant des modifications, mais celles-ci ne sont pas déployées tant qu’un éditeur ou un administrateur ne déclenche pas manuellement un déploiement depuis votre tableau de bord.
