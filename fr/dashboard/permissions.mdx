---
title: "Autorisations de déploiement"
description: "Comprendre les différences de déploiement entre les personnes de votre organisation et les autres contributeurs."
keywords: ["editor access", "permissions", "team", "seats", "deployment"]
---

Les personnes ayant le rôle d’[editor ou d’admin](/fr/dashboard/roles) peuvent utiliser l’éditeur web, déclencher des déploiements et gérer les intégrations depuis votre tableau de bord. Lorsqu’un editor ou un admin publie via l’éditeur web ou fusionne une pull request dans votre dépôt de documentation, les modifications sont automatiquement déployées sur votre site en production.

Toute personne ayant accès à votre dépôt de documentation peut contribuer à votre documentation en poussant des modifications vers le dépôt, mais leurs modifications ne sont pas déployées tant qu’un editor ou un admin n’a pas déclenché manuellement un déploiement depuis votre tableau de bord.
