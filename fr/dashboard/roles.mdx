<Info>
  Le contrôle d’accès basé sur les rôles (RBAC) est disponible avec les [offres Enterprise](https://mintlify.com/pricing?ref=rbac).
</Info>

Mintlify propose trois niveaux d’accès au tableau de bord : lecteur, éditeur et admin.

|                                | Lecteur | Éditeur | Admin |
| ------------------------------ | :-----: | :-----: | :---: |
| View content in the editor     |   ✅    |   ✅    |  ✅   |
| View dashboard and analytics   |   ✅    |   ✅    |  ✅   |
| Edit content in the web editor |   ❌    |   ✅    |  ✅   |
| Trigger deployments            |   ❌    |   ✅    |  ✅   |
| Create and delete API keys     |   ❌    |   ✅    |  ✅   |
| Configure integrations         |   ❌    |   ✅    |  ✅   |
| Configure assistant            |   ❌    |   ✅    |  ✅   |
| Configure add-ons              |   ❌    |   ✅    |  ✅   |
| Invite editors and viewers     |   ❌    |   ✅    |  ✅   |
| Update user roles              |   ❌    |   ❌    |  ✅   |
| Invite admins                  |   ❌    |   ❌    |  ✅   |
| Delete users                   |   ❌    |   ❌    |  ✅   |
| Manage billing                 |   ❌    |   ❌    |  ✅   |
| Manage SSO                     |   ❌    |   ❌    |  ✅   |
| Update custom domain           |   ❌    |   ❌    |  ✅   |
| Update Git source              |   ❌    |   ❌    |  ✅   |
| Delete organization            |   ❌    |   ❌    |  ✅   |

<Tip>
  Limitez l’accès admin uniquement aux personnes qui doivent effectuer des tâches d’administration.
</Tip>

<div id="add-members-to-your-organization">
  ## Ajouter des membres à votre organisation
</div>

Par défaut, la personne qui crée votre organisation Mintlify dispose de droits d’administrateur. Ajoutez des éditeurs supplémentaires sur la page [Members](https://dashboard.mintlify.com/settings/organization/members) de votre tableau de bord.

Vous pouvez avoir autant de membres que nécessaire dans votre organisation. Les places peuvent entraîner des frais supplémentaires. Consultez la [page de tarification](https://mintlify.com/pricing) pour plus de détails.
