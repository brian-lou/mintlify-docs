<Info>
  Les journaux d’audit sont disponibles avec les [formules Enterprise](https://mintlify.com/pricing?ref=audit-logs).
</Info>

Utilisez les journaux d’audit pour surveiller et suivre les actions effectuées par les membres de votre organisation. Les journaux d’audit fournissent un historique des activités à des fins de sécurité, de conformité et de résolution des problèmes.

- **Surveiller la sécurité** : Suivre les tentatives d’authentification et les modifications d’autorisations.
- **Garantir la conformité** : Conserver une trace de toutes les activités de l’organisation.
- **Résoudre les problèmes** : Enquêter sur les actions échouées et leurs causes.
- **Suivre les modifications** : Vérifier qui a effectué quelles modifications et à quel moment.

<div id="view-audit-logs">
  ## Afficher les journaux d’audit
</div>

Accédez à la page [Audit log](https://dashboard.mintlify.com/settings/organization/audit-logs) de votre tableau de bord pour consulter les journaux d’audit.

Cliquez sur n’importe quelle entrée de journal pour la développer et afficher des informations détaillées, notamment :

| Field | Description |
| ----- | ----------- |
| Timestamp | Date et heure de l’action |
| Actor | Adresse e-mail de l’utilisateur qui a effectué l’action |
| Action | Action effectuée par l’utilisateur |
| Category | Type de ressource concernée |
| Outcome | Indique si l’action a réussi ou échoué |
| Metadata | Informations contextuelles supplémentaires sur l’action |

<div id="filter-logs">
  ### Filtrer les journaux
</div>

Filtrez les journaux d’audit pour trouver des activités spécifiques.

**Plage de dates** : Sélectionnez une plage de dates prédéfinie pour afficher les journaux sur une période spécifique.

**Catégorie** : Filtrez les journaux par type d’action.

| Category         | Description                                                        |
|------------------|--------------------------------------------------------------------|
| Organization     | Mises à jour des paramètres d’organisation et demandes de suppression.                |
| Member           | Invitations, suppressions et changements de rôle des membres de l’équipe.               |
| Deployment       | Modifications de configuration de déploiement, y compris les domaines personnalisés, l’authentification et les sources Git. |
| Preview deployment | Création, mises à jour et modifications d’authentification des déploiements de prévisualisation. |
| API key          | Création et suppression de clés API et de clés API de découverte.               |
| Assistant        | Mises à jour des paramètres d’Assistant, comme l’e-mail de redirection, les sites de recherche web et les questions de départ. |
| PDF export       | Génération et suppression d’exportations PDF.                                |
| Integration      | Installations et désinstallations de GitHub, Slack et Discord.             |
| Billing          | Mises à jour d’abonnement, achats de modules complémentaires et consultation de factures.          |
| Quota            | Modifications des règles de dépassement de quota et de la configuration des alertes.                    |
| User             | Paramètres de notification des utilisateurs individuels.                             |
| Suggestions      | Configurations de suggestions et gestion des dépôts.                 |
| Audit log        | Consultations et exportations du journal d’audit.                              |
| Auth             | Tentatives de connexion, déconnexions et créations de sessions.                     |

<div id="export-audit-logs">
  ## Exporter les journaux d’audit
</div>

Exportez les journaux d’audit au format CSV pour analyse, rapports de conformité ou archivage à long terme.

1. Accédez à la page [Audit log](https://dashboard.mintlify.com/settings/organization/audit-logs) de votre tableau de bord.
1. Si nécessaire, appliquez des filtres pour affiner les journaux que vous souhaitez exporter.
1. Cliquez sur **Export CSV**.
1. Mintlify vous envoie un e-mail avec un lien de téléchargement lorsque l’exportation est prête.
