<ResponseField name="icon" type="string">
  要显示的图标。

  选项：

  * 如果你在 `docs.json` 中将 `icons.library` [属性](/zh/organize/settings#param-icons) 设为 `fontawesome`，则填写 [Font Awesome](https://fontawesome.com/icons) 图标名称
  * 如果你在 `docs.json` 中将 `icons.library` [属性](/zh/organize/settings#param-icons) 设为 `lucide`，则填写 [Lucide](https://lucide.dev/icons) 图标名称
  * 外部托管图标的 URL
  * 项目中图标文件的路径
  * 用花括号括起来的 SVG 代码

  对于自定义 SVG 图标：

  1. 使用 [SVGR converter](https://react-svgr.com/playground/) 转换 SVG。
  2. 将 SVG 代码粘贴到 SVG 输入框中。
  3. 从 JSX 输出框中复制完整的 `<svg>...</svg>` 元素。
  4. 将兼容 JSX 的 SVG 代码用花括号括起来：`icon={<svg ...> ... </svg>}`。
  5. 根据需要调整 `height` 和 `width`。
</ResponseField>

<ResponseField name="iconType" type="string">
  [Font Awesome](https://fontawesome.com/icons) 图标样式。仅适用于 Font Awesome 图标。

  选项：`regular`、`solid`、`light`、`thin`、`sharp-solid`、`duotone`、`brands`。
</ResponseField>
