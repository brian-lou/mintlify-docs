<ResponseField name="icon" type="string">
  L’icône à afficher.

  Options :

  * Nom d’icône [Font Awesome](https://fontawesome.com/icons), si la [propriété](/fr/organize/settings#param-icons) `icons.library` est définie sur `fontawesome` dans votre `docs.json`
  * Nom d’icône [Lucide](https://lucide.dev/icons), si la [propriété](/fr/organize/settings#param-icons) `icons.library` est définie sur `lucide` dans votre `docs.json`
  * URL d’une icône hébergée en externe
  * Chemin vers un fichier d’icône dans votre projet
  * Code SVG entouré d’accolades

  Pour les icônes SVG personnalisées :

  1. Convertissez votre SVG à l’aide du [convertisseur SVGR](https://react-svgr.com/playground/).
  2. Collez votre code SVG dans le champ d’entrée SVG.
  3. Copiez l’élément `<svg>...</svg>` complet depuis le champ de sortie JSX.
  4. Entourez le code SVG compatible JSX d’accolades : `icon={<svg ...> ... </svg>}`.
  5. Ajustez `height` et `width` selon vos besoins.
</ResponseField>

<ResponseField name="iconType" type="string">
  Le style de l’icône [Font Awesome](https://fontawesome.com/icons). Utilisé uniquement avec les icônes Font Awesome.

  Options : `regular`, `solid`, `light`, `thin`, `sharp-solid`, `duotone`, `brands`.
</ResponseField>
