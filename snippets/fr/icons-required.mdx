<ResponseField name="icon" type="string" required>
  L’icône à afficher.

  Options :

  * Nom de l’icône [Font Awesome](https://fontawesome.com/icons), si vous avez défini la [propriété](/fr/organize/settings#param-icons) `icons.library` sur `fontawesome` dans votre fichier `docs.json`
  * Nom de l’icône [Lucide](https://lucide.dev/icons), si vous avez défini la [propriété](/fr/organize/settings#param-icons) `icons.library` sur `lucide` dans votre fichier `docs.json`
  * URL pointant vers une icône hébergée en externe
  * Chemin d’accès vers un fichier d’icône dans votre projet
</ResponseField>

<ResponseField name="iconType" type="string">
  Le style d’icône [Font Awesome](https://fontawesome.com/icons). Utilisé uniquement avec les icônes Font Awesome.

  Options : `regular`, `solid`, `light`, `thin`, `sharp-solid`, `duotone`, `brands`.
</ResponseField>
