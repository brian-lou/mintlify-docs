<div id="cookie-consent-and-disabling-telemetry">
  ## Consentimiento de cookies y desactivación de la telemetría
</div>

Si necesitas comprobar si un usuario ya ha dado su consentimiento para las cookies a efectos de cumplimiento del RGPD, puedes especificar una clave y un valor de almacenamiento local en `cookies`:

```json
  "integrations": {
    "cookies": {
      "key": "LOCAL STORAGE KEY",
      "value": "LOCAL STORAGE VALUE"
    }
  }
```

Si se establecen estos valores, tu sitio comprueba el almacenamiento local del navegador para la clave y el valor especificados y así determinar si un usuario ha dado su consentimiento para el uso de cookies. Si un usuario no ha dado su consentimiento para las cookies, tu sitio desactiva la telemetría para ese usuario.

Si deseas desactivar la telemetría para todos los usuarios, agrega lo siguiente a tu archivo `docs.json`:

```json
  "integrations": {
    "telemetry": {
      "enabled": false
    }
  }
```

<Note>
  Si desactivas la telemetría, no podrás recopilar comentarios sobre tus páginas de documentación, aunque habilites la opción de comentarios en tu panel de control.
</Note>
