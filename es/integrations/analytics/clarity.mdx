Añade lo siguiente a tu archivo `docs.json` para enviar datos de analítica a Microsoft Clarity.

<CodeGroup>

```json Opciones de analítica en docs.json
"integrations": {
    "clarity": {
        "projectId": "required"
    }
}
```

```json Ejemplo
"integrations": {
    "clarity": {
        "projectId": "abc123xyz"
    }
}
```

</CodeGroup>

<div id="get-your-project-id">
  ## Obtén el ID de tu proyecto
</div>

1. Crea una [cuenta de Clarity](https://clarity.microsoft.com/projects).
2. Haz clic en **Get tracking code.**
3. Copia el ID de tu proyecto del código de seguimiento.
