description: "Realiza un seguimiento de analíticas sencillas y respetuosas con la privacidad con Plausible."
keywords: ["Plausible Analytics", "analíticas respetuosas con la privacidad", "analíticas autoalojadas", "configuración de dominio"]
---

Añade el dominio de tu sitio a `docs.json` para enviar analíticas a Plausible.

<Info>
  No incluyas `https://` en el dominio ni en el servidor.
</Info>

<CodeGroup>

```json Opciones de analíticas en docs.json
"integrations": {
    "plausible": {
        "domain": "obligatorio: el dominio de tu documentación",
        "server": "opcional: la URL de tu servidor Plausible autoalojado"
    }
}
```

```json Ejemplo
"integrations": {
    "plausible": {
        "domain": "docs.domain.com"
    }
}
```

</CodeGroup>
