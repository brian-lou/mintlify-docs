Agrega lo siguiente a tu archivo `docs.json` para enviar datos de analítica a PostHog.

Solo necesitas incluir `apiHost` si utilizas PostHog en modo autoalojado. Enviamos los eventos a `https://app.posthog.com` de forma predeterminada.

<CodeGroup>

```json Opciones de analítica en docs.json
"integrations": {
    "posthog": {
        "apiKey": "YOUR_POSTHOG_PROJECT_API_KEY",
        "apiHost": "optional",
        "sessionRecording": true
    }
}
```

```json Ejemplo
"integrations": {
    "posthog": {
        "apiKey": "phc_TXdpocbYTeZVm5VJmMzHTMrCofBQu3e0kN7HGMNGTVW"
    }
}
```

</CodeGroup>

<div id="configuration-options">
  ### Opciones de configuración
</div>

<ParamField path="apiKey" type="string" required>
  La clave de API de tu proyecto de PostHog. Debe comenzar con `phc_`.
</ParamField>

<ParamField path="apiHost" type="string">
  La URL de tu instancia de PostHog. Solo es necesaria si alojas PostHog tú mismo. Por defecto es `https://app.posthog.com`.
</ParamField>

<ParamField path="sessionRecording" type="boolean" default="true">
  Activa o desactiva la grabación de sesiones. Configúralo en `false` para desactivar la grabación de sesiones manteniendo la analítica activada.
</ParamField>

<div id="session-recordings">
  ## Grabaciones de sesión
</div>

Las grabaciones de sesión están habilitadas de forma predeterminada cuando configuras PostHog. Para desactivar las grabaciones de sesión y mantener la analítica activada, establece `sessionRecording` en `false` en tu configuración.

```json Disable session recordings
"integrations": {
    "posthog": {
        "apiKey": "phc_your-key",
        "sessionRecording": false
    }
}
```

Debes añadir la URL de tu sitio de documentación a los &quot;dominios autorizados para grabaciones&quot; de PostHog antes de poder recibir grabaciones de sesiones. La opción para añadir tu URL se encuentra en la configuración del proyecto de PostHog.
