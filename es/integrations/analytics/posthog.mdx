Agrega lo siguiente a tu archivo `docs.json` para enviar datos de analítica a PostHog.

Solo necesitas incluir `apiHost` si alojas PostHog por tu cuenta. Enviamos eventos a `https://app.posthog.com` de forma predeterminada.

<CodeGroup>
  ```json Opciones de analítica en docs.json
  "integrations": {
      "posthog": {
          "apiKey": "YOUR_POSTHOG_PROJECT_API_KEY",
          "apiHost": "optional",
          "sessionRecording": true
      }
  }
  ```

  ```json Ejemplo
  "integrations": {
      "posthog": {
          "apiKey": "phc_TXdpocbYTeZVm5VJmMzHTMrCofBQu3e0kN7HGMNGTVW"
      }
  }
  ```
</CodeGroup>

<div id="configuration-options">
  ### Opciones de configuración
</div>

<ParamField path="apiKey" type="string" required>
  La clave de API de tu proyecto de PostHog. Debe comenzar con `phc_`.
</ParamField>

<ParamField path="apiHost" type="string">
  La URL de tu instancia de PostHog. Solo es necesaria si alojas PostHog por tu cuenta. El valor predeterminado es `https://app.posthog.com`.
</ParamField>

<ParamField path="sessionRecording" type="boolean" default="true">
  Activa o desactiva la grabación de sesión. Establece `false` para desactivar las grabaciones de sesión sin desactivar analytics.
</ParamField>

<div id="session-recordings">
  ## Grabaciones de sesiones
</div>

Las grabaciones de sesión se habilitan de forma predeterminada cuando configuras PostHog. Para deshabilitarlas y mantener habilitada la analítica, establece `sessionRecording` en `false` en tu configuración.

```json Disable session recordings
"integrations": {
    "posthog": {
        "apiKey": "phc_your-key",
        "sessionRecording": false
    }
}
```

Debes añadir la URL de tu sitio web de documentación a los &quot;Dominios autorizados para grabaciones&quot; de PostHog antes de poder recibir grabaciones de sesión. La opción para añadir tu URL está en la configuración del proyecto de PostHog.
