Añade lo siguiente a tu archivo `docs.json` para enviar los datos de analítica a Pirsch.

Puedes obtener el ID de tu sitio en Settings &gt; Developer &gt; Identification Code.

<CodeGroup>
  ```json Opciones de analítica en docs.json
  "integrations": {
      "pirsch": {
          "id": "required"
      }
  }
  ```

  ```json Ejemplo
  "integrations": {
      "pirsch": {
          "id": "8Kw7OKxBfswOjnKGZa7P9Day8JmVYwTp"
      }
  }
  ```
</CodeGroup>
