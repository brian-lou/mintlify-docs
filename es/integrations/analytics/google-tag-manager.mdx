---
title: "Google Tag Manager"
description: "Administra etiquetas y eventos de analítica con Google Tag Manager."
keywords: ["GTM integration", "tag management", "tag ID", "cookie consent"]
---

Añade tu ID de etiqueta (`tagId`) al archivo `docs.json` y insertaremos el script de Google Tag Manager en todas tus páginas.

Eres responsable de configurar los banners de consentimiento de cookies con Google Tag Manager si los necesitas.

<CodeGroup>

```json Opciones de analítica en docs.json
"integrations": {
    "gtm": {
        "tagId": "required"
    }
}
```

```json Ejemplo
"integrations": {
    "gtm": {
        "tagId": "GTM-MGBL4PW"
    }
}
```

</CodeGroup>
