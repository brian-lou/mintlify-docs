Añade lo siguiente a tu archivo `docs.json` para enviar datos de analítica a Hightouch.

<Info>

  No incluyas `https://` en el `apiHost`.

</Info>

<CodeGroup>

```json Analytics options in docs.json
"integrations": {
    "hightouch": {
        "writeKey": "required"
        "apiHost": "optional"
    }
}
```

```json Example
"integrations": {
    "hightouch": {
        "writeKey": "9132c81do371p76sr11da0075469b54f77649c9a067dp0303p56q0q64n072336"
        "apiHost": "us-east-1.hightouch-events.com" # opcional, de forma predeterminada es `us-east-1.hightouch-events.com`
    }
}
```

</CodeGroup>
