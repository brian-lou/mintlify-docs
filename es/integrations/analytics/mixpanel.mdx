Agrega lo siguiente a tu archivo `docs.json` para enviar datos de analítica a Mixpanel.

```json Analytics options in docs.json
"integrations": {
    "mixpanel": {
        "projectToken": "YOUR_MIXPANEL_PROJECT_TOKEN"
    }
}
```

Reemplaza `YOUR_MIXPANEL_PROJECT_TOKEN` por el token del proyecto de Mixpanel. Puedes encontrarlo en la [configuración del proyecto de Mixpanel](https://mixpanel.com/settings/project).


<div id="tracked-events">
  ## Eventos rastreados
</div>

Mintlify rastrea automáticamente las siguientes interacciones de los usuarios:

* Vistas de página
* Consultas de búsqueda
* Envíos de comentarios
* Interacciones con el menú contextual
* Clics de navegación

Si no ves eventos en Mixpanel, asegúrate de que el token del proyecto sea correcto y de que ninguna política de seguridad de contenido esté bloqueando el script de Mixpanel.
