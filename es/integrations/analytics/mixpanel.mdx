Agrega lo siguiente a tu archivo `docs.json` para enviar analíticas a Mixpanel.

```json Analytics options in docs.json
"integrations": {
    "mixpanel": {
        "projectToken": "YOUR_MIXPANEL_PROJECT_TOKEN"
    }
}
```

Sustituye `YOUR_MIXPANEL_PROJECT_TOKEN` por el token de tu proyecto de Mixpanel. Puedes encontrarlo en la [configuración de tu proyecto en Mixpanel](https://mixpanel.com/settings/project).


<div id="tracked-events">
  ## Eventos registrados
</div>

Mintlify registra automáticamente las siguientes interacciones de los usuarios:

- Vistas de página
- Consultas de búsqueda
- Envío de comentarios
- Interacciones con el menú contextual
- Clics de navegación

Si no ves eventos en Mixpanel, asegúrate de que el token de tu proyecto sea correcto y de que no haya políticas de seguridad de contenido que estén bloqueando el script de Mixpanel.
