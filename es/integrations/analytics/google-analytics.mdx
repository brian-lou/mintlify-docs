Tendrás que generar una nueva propiedad de <Tooltip tip="Google Analytics 4">GA4</Tooltip> para usarla con Mintlify. Los datos recopilados se enviarán al mismo proyecto que tus otros datos de Google Analytics.

Si usas la versión anterior de Google Analytics, Universal Analytics, igualmente podrás generar una propiedad de <Tooltip tip="Google Analytics 4">GA4</Tooltip>. Los datos de <Tooltip tip="Google Analytics 4">GA4</Tooltip> son ligeramente distintos de los datos de UA, pero aun así se recopilan en el mismo proyecto.

<div id="how-to-connect-ga4-to-mintlify">
  ## Cómo conectar GA4 con Mintlify
</div>

<div id="create-a-web-stream">
  ### Crear un flujo de datos web
</div>

Deberás crear un flujo de datos web para obtener el ID de medición que debes introducir en Mintlify.

Haz clic en el icono de engranaje de la esquina inferior izquierda de la pantalla de Google Analytics. Después, haz clic en Data Streams.

<Frame>![Captura de pantalla de la página Data Streams en el panel de Google Analytics.](/images/ga4-web-streams.png)</Frame>

Crea un flujo de datos web e introduce la URL de tu sitio de documentación de Mintlify como la URL del flujo.

Tu ID de medición tendrá un formato similar a `G-XXXXXXX` y aparecerá en Stream Details inmediatamente después de crear el flujo de datos web.

<div id="put-measurement-id-in-docsjson">
  ### Añade el ID de medición a docs.json
</div>

Agrega tu ID de medición a tu archivo `docs.json` de la siguiente manera:

```json docs.json
"integrations": {
    "ga4": {
        "measurementId": "G-XXXXXXX"
    }
}
```


<div id="wait">
  ### Espera
</div>

Google Analytics tarda entre dos y tres días en mostrar tus datos.

Puedes usar [Google Analytics Debugger](https://chrome.google.com/webstore/detail/google-analytics-debugger/jnkmfdileelhofjcijamephohjechhna?hl=en) para comprobar que la analítica esté habilitada correctamente. La extensión registrará en la consola de tu navegador cada vez que GA4 haga una solicitud.

<Note>
  Los enlaces de vista previa tienen la analítica desactivada.
</Note>
