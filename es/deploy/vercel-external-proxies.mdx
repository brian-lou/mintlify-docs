Si tienes un proxy externo, como Cloudflare o AWS CloudFront, delante de tu despliegue de Vercel, debes configurarlo correctamente para evitar conflictos con la verificación de dominios y el aprovisionamiento de certificados SSL de Vercel.

Una configuración incorrecta del proxy puede impedir que Vercel aprovisione certificados SSL de Let&#39;s Encrypt y provocar errores en la verificación del dominio.

Consulta los [proveedores compatibles](https://vercel.com/guides/how-to-setup-verified-proxy#supported-providers-verified-proxy-lite) en la documentación de Vercel.

<div id="required-path-allowlist">
  ## Lista obligatoria de rutas permitidas
</div>

Tu proxy externo debe permitir el tráfico hacia estas rutas específicas sin bloquearlo, redirigirlo ni aplicarle una caché agresiva:

* `/.well-known/acme-challenge/*` - Obligatorio para la verificación de certificados de Let&#39;s Encrypt
* `/.well-known/vercel/*` - Obligatorio para la verificación de dominios de Vercel
* `/mintlify-assets/_next/static/*` - Obligatorio para los recursos estáticos

Estas rutas deben pasar directamente a tu despliegue de Vercel sin modificaciones.

<div id="header-forwarding-requirements">
  ## Requisitos para el reenvío de encabezados
</div>

Asegúrate de que tu proxy reenvíe correctamente el encabezado `HOST`. Si los encabezados no se reenvían correctamente, las solicitudes de verificación fallarán.

<div id="testing-your-proxy-setup">
  ## Probar la configuración del proxy
</div>

Para verificar que el proxy esté configurado correctamente:

1. Comprueba que `https://[yourdomain].com/.well-known/vercel/` responda.
2. Asegúrate de que los certificados SSL se estén generando correctamente en el panel de Vercel.
3. Verifica que la verificación de dominio se complete correctamente.
