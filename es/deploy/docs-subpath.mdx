Publica tu documentación en una subruta como `your-domain.com/docs` para mantenerla en tu dominio principal, lo que facilita encontrarla y mantiene una experiencia de marca coherente para tus usuarios.

<div id="set-up-by-hosting-provider">
  ## Configuración según el proveedor de alojamiento
</div>

La configuración de una subruta `/docs` depende de tu proveedor de alojamiento. Elige tu proveedor y sigue las instrucciones de configuración.

* [Cloudflare](/es/deploy/cloudflare): Configura Cloudflare Workers en tu dominio para servir tu documentación en la subruta `/docs`.
* [AWS Route 53 y CloudFront](/es/deploy/route53-cloudfront): Despliega tu documentación en la subruta `/docs` usando AWS con Route 53 (DNS) y CloudFront (CDN).
* [Vercel](/es/deploy/vercel#host-from-docs) - Usa reglas de reescritura (rewrites) para desplegar tu documentación en la subruta `/docs`.
* [Proxy inverso personalizado](/es/deploy/reverse-proxy) - Para otras plataformas de alojamiento, configura un proxy inverso para desplegar tu documentación en la subruta `/docs`.

<div id="additional-configuration-for-strict-security-policies">
  ### Configuración adicional para políticas de seguridad estrictas
</div>

Si canalizas todo el tráfico de tu dominio personalizado a través de un proxy, es posible que tengas que configurar tu proxy o las reglas de tu firewall para añadir los [encabezados](/es/deploy/csp-configuration) correctos y que tu documentación se muestre correctamente.
