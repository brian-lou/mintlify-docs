Esta guía te explica paso a paso cómo configurar la aplicación de GitHub de Mintlify en tu instalación de GitHub Enterprise Server (GHES). Para conectar una instancia de GHES a Mintlify, debes crear una versión local de nuestra aplicación dentro de tu entorno autoalojado que se comunique con nuestro servidor remoto.

Si usas una instancia de GitHub alojada en la nube, consulta la página de [GitHub](/es/deploy/github) para obtener instrucciones de configuración.

<div id="prerequisites">
  ## Requisitos previos
</div>

* Privilegios de administrador en tu organización de GitHub Enterprise Server donde deseas instalar la aplicación
* Acceso a los repositorios de tu organización donde deseas instalar la aplicación
* Conectividad de red para comunicarte con nuestros servicios externos (consulta la sección [Requisitos de red](#network-requirements) a continuación)

<div id="network-requirements">
  ### Requisitos de red
</div>

<div id="outbound-connectivity">
  #### Conectividad de salida
</div>

Tu GitHub Enterprise Server debe poder establecer conexión con:

* Endpoints de la API de Mintlify (https://leaves.mintlify.com)
* Destinos de los webhooks (puerto 443)

<div id="firewall-configuration">
  #### Configuración del firewall
</div>

Se deben permitir las siguientes conexiones salientes:

* Conexiones salientes desde la IP estática de Mintlify: `54.242.90.151`
* HTTPS (puerto 443) hacia los dominios de servicio de Mintlify
* Resolución de DNS para los dominios de servicio de Mintlify

<div id="step-1-register-the-github-app">
  ## Paso 1: Registrar la GitHub App
</div>

Consulta [Registering a GitHub App](https://docs.github.com/en/enterprise-server@3.18/apps/creating-github-apps/registering-a-github-app/registering-a-github-app) en la documentación de GitHub para obtener instrucciones detalladas.

<Steps>
  <Step title="Ve a la configuración de tu organización">
    1. En la esquina superior derecha de cualquier página de GitHub, haz clic en tu foto de perfil.
    2. Haz clic en **Your organizations**.
    3. Haz clic en **Settings** junto a la organización para la que quieres crear la app.
  </Step>

  <Step title="Crea una nueva GitHub App">
    1. En la barra lateral izquierda, haz clic en **Developer settings**.
    2. Haz clic en **GitHub Apps**.
    3. Haz clic en **New GitHub App**.
  </Step>

  <Step title="Configura la información básica de la app">
    Configura lo siguiente:

    * **GitHub App name:** `Mintlify`
    * **Description:** `Integration with Mintlify services`
    * **Homepage URL:** `https://mintlify.com`
    * **User authorization callback URL:** `https://your-github-server.com/` (reemplázalo por tu dominio real de GHES)
  </Step>
</Steps>

<div id="step-2-configure-app-permissions">
  ## Paso 2: Configurar los permisos de la aplicación
</div>

<Steps>
  <Step title="Configurar permisos del repositorio">
    Configura los siguientes permisos para la aplicación. No se requieren permisos de organización, cuenta o empresa:

    * **Checks:** lectura y escritura
    * **Contents:** lectura y escritura
    * **Deployments:** lectura y escritura
    * **Metadata:** solo lectura
    * **Pull Requests:** lectura y escritura
  </Step>

  <Step title="Suscribirse a eventos">
    Selecciona los siguientes eventos de webhook:

    * Installation
    * Installation Target
    * Create
    * Delete
    * Public
    * Pull Request
    * Push
    * Repository
  </Step>
</Steps>

<div id="step-3-generate-and-secure-credentials">
  ## Paso 3: Generar y asegurar las credenciales
</div>

<Steps>
  <Step title="Crear la app">
    Haz clic en **Create GitHub App**.

    Serás redirigido a la página de configuración de la app.
  </Step>

  <Step title="Generar clave privada">
    1. Desplázate hasta la sección **Private keys**.
    2. Haz clic en **Generate a private key**.
    3. Descarga el archivo `.pem` y guárdalo de forma segura.
  </Step>

  <Step title="Registrar credenciales de la app">
    Toma nota de lo siguiente:

    * **App ID** (visible en la parte superior de la página de configuración)
    * **Client ID** (en la sección &quot;About&quot;)
    * **Client Secret** (genéralo y guárdalo de forma segura)
  </Step>
</Steps>

<div id="step-4-install-the-app">
  ## Paso 4: Instalar la aplicación
</div>

<Steps>
  <Step title="Ir a la instalación de la aplicación">
    1. En la página de configuración de la aplicación, haz clic en **Install App** en la barra lateral izquierda.
    2. Selecciona tu organización en la lista.
  </Step>

  <Step title="Elegir el alcance de la instalación">
    Selecciona una de las siguientes opciones:

    * **All repositories** (para acceso a todos los repositorios de la organización)
    * **Only select repositories** (para elegir repositorios específicos)

    <Tip>
      Recomendamos seleccionar &quot;Only select repositories&quot; y limitar la aplicación solo a los repositorios donde está tu documentación.
    </Tip>
  </Step>

  <Step title="Completar la instalación">
    1. Haz clic en **Install**.
    2. Anota el ID de instalación de la URL. Por ejemplo, en `https://your-github-server.com/settings/installations/12345`, la cadena `12345` es el ID de instalación.
  </Step>
</Steps>

<div id="step-5-configure-webhook-url">
  ## Paso 5: Configurar la URL del webhook
</div>

<Steps>
  <Step title="Volver a la configuración de la app">
    1. Vuelve a la página de configuración de tu app.
    2. Desplázate hasta la sección **Webhook**.
  </Step>

  <Step title="Configurar la URL del webhook">
    Configura lo siguiente:

    * **Webhook URL:** `https://leaves.mintlify.com/github-enterprise/:subdomain` (reemplaza `:subdomain` por la URL que te proporcionemos)
    * **Webhook secret:** Genera una cadena aleatoria (de 32 o más caracteres) y guárdala de forma segura. Mintlify también puede generarla y proporcionártela.
  </Step>
</Steps>

<div id="share-credentials-with-us">
  ## Comparte tus credenciales con nosotros
</div>

Comparte la siguiente información con nuestro equipo mediante el método seguro de transferencia de información que prefieras.

<div id="required-credentials">
  ### Credenciales obligatorias
</div>

* URL base de GitHub Enterprise Server: https://your-github-server.com
* ID de la aplicación: (del paso 3)
* ID de cliente de la aplicación: (del paso 3)
* Secreto de cliente de la aplicación: (del paso 3)
* ID de la instalación: (del paso 4)
* Clave privada: Todo el contenido del archivo `.pem` (debe compartirse mediante una transferencia segura de archivos)
* Secreto del webhook: (del paso 5)

<div id="optional-credentials-for-troubleshooting">
  ### Credenciales opcionales para solucionar problemas
</div>

* Nombre de la organización: El nombre de tu organización de GitHub
* Nombres de los repositorios: Repositorios específicos en los que la aplicación está instalada
* Versión de GitHub Enterprise Server: Se encuentra en el panel de administración de tu sitio

<div id="mintlify-connection">
  ## Conexión con Mintlify
</div>

Tomamos las credenciales que nos proporcionas y las almacenamos cifradas en una ubicación segura. Luego trabajamos contigo para:

* Integrar tu entorno GHES con una implementación existente de Mintlify.
* Integrar tu entorno GHES con una nueva implementación de Mintlify que aprovisionamos para ti.

Una vez que tu entorno GHES esté integrado con una implementación de Mintlify, ya podrás habilitar los webhooks de tu GitHub App.

<Note>
  La URL del webhook puede cambiar según nuestra configuración. Probamos la integración y te proporcionamos la nueva URL.
</Note>

<div id="test-the-integration">
  ## Prueba la integración
</div>

<Steps>
  <Step title="Verificar la entrega del webhook">
    1. Ve a la configuración de tu GitHub App.
    2. Haz clic en la pestaña **Advanced**.
    3. Revisa &quot;Recent Deliveries&quot; para comprobar que las entregas del webhook se han realizado correctamente.
    4. Busca respuestas HTTP 200.
  </Step>

  <Step title="Probar el acceso al repositorio">
    1. Crea un issue o pull request de prueba en un repositorio donde esté instalada la app.
    2. Verifica que Mintlify responda de forma adecuada.
  </Step>
</Steps>

<div id="faq-and-troubleshooting">
  ## Preguntas frecuentes y resolución de problemas
</div>

<AccordionGroup>
  <Accordion title="La instalación de la aplicación falla con errores de permisos.">
    Asegúrate de que tengas:

    * Privilegios de administrador del sitio para crear aplicaciones.
    * Permisos de propietario o administrador de la organización para instalar aplicaciones.
    * Permisos adecuados en los repositorios si estás instalando en repositorios específicos.
  </Accordion>

  <Accordion title="Los webhooks no se están entregando">
    * Verifica que la URL del webhook sea correcta y accesible.
    * Asegúrate de que tu firewall permita conexiones HTTPS salientes.
    * Comprueba que el secreto del webhook coincida con el que se configuró.
    * Revisa los registros de entrega de webhooks en la pestaña &quot;Advanced&quot; de la configuración de tu GitHub App.
  </Accordion>

  <Accordion title="Estoy recibiendo errores de certificados SSL/TLS">
    Tu GHES podría usar certificados autofirmados. Nuestros servicios no pueden verificar el certificado de tu servidor.

    **Solución:** Asegúrate de que tu GHES tenga un certificado SSL válido.
  </Accordion>

  <Accordion title="La aplicación se instala, pero no responde a los eventos.">
    * Asegúrate de que los webhooks se estén entregando y que nuestro servidor los confirme con el código de respuesta 200.
    * Verifica que se hayan concedido los permisos necesarios durante la instalación.
  </Accordion>

  <Accordion title="¿Puedo limitar a qué repositorios accede la aplicación?">
    Sí, durante la instalación puedes seleccionar &quot;Only select repositories&quot; y elegir repositorios específicos. Puedes modificar esto más adelante en la configuración de aplicaciones instaladas de tu organización. Esta es la forma de instalación recomendada.
  </Accordion>

  <Accordion title="¿Cómo actualizo los permisos de la aplicación más adelante?">
    * Ve a la configuración de la aplicación como administrador del sitio.
    * Modifica los permisos según sea necesario.
    * La aplicación deberá ser aprobada nuevamente por los propietarios de la organización.
    * Avísanos de cualquier cambio en los permisos, ya que puede afectar la funcionalidad.
  </Accordion>

  <Accordion title="Nuestro GHES está detrás de un firewall corporativo, proxy nginx o una configuración similar.">
    Debes:

    * Incluir nuestros dominios de servicio en la lista de permitidos de tu firewall.
    * Asegurar la conectividad HTTPS saliente (puerto 443).
    * Si no se permite el acceso directo a Internet, configura un proxy.
  </Accordion>

  <Accordion title="¿Esto puede funcionar con GHES en entornos aislados (air-gapped)?">
    No, tu GHES debe poder comunicarse con nuestro servidor alojado en la nube.
  </Accordion>

  <Accordion title="¿Con quién debo ponerme en contacto si necesito ayuda?">
    Ponte en contacto con tu representante de éxito del cliente (customer success) con quien hayas hablado en Mintlify, o con nuestro equipo de soporte en <a href="mailto:support@mintlify.com">support@mintlify.com</a> con:

    * Tu versión de GitHub Enterprise Server.
    * Mensajes de error específicos.
    * Capturas de pantalla de cualquier problema.
    * Detalles de la configuración de red/firewall (si corresponde).
  </Accordion>
</AccordionGroup>
