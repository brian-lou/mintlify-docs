Configura una fuente personalizada para todo tu sitio o por separado para los encabezados y el texto principal. Usa Google Fonts, archivos de fuentes locales o fuentes alojadas externamente. La fuente predeterminada varía según el tema.

Las fuentes se controlan mediante la [propiedad `fonts`](/es/organize/settings#param-fonts) en tu `docs.json`.

<div id="google-fonts">
  ## Google Fonts
</div>

Mintlify carga automáticamente [Google Fonts](https://fonts.google.com) cuando especificas un nombre de familia de fuentes en tu `docs.json`.

```json docs.json
"fonts": {
  "family": "Inter"
}
```

<div id="local-fonts">
  ## Fuentes locales
</div>

Para utilizar fuentes locales, coloca los archivos de fuente en el directorio de tu proyecto y haz referencia a ellos en la configuración de `docs.json`.

<div id="setting-up-local-fonts">
  ### Configuración de fuentes locales
</div>

<Steps>
  <Step title="Agregar archivos de fuentes a tu proyecto">
    Por ejemplo, crea un directorio `fonts` y agrega tus archivos de fuentes:

    ```text
    your-project/
    ├── fonts/
    │   ├── InterDisplay-Regular.woff2
    │   └── InterDisplay-Bold.woff2
    ├── docs.json
    └── ...
    ```
  </Step>

  <Step title="Configurar fuentes en docs.json">
    Haz referencia a tus fuentes locales utilizando rutas relativas desde la raíz de tu proyecto:

    ```json docs.json
    {
      "fonts": {
        "family": "InterDisplay",
        "source": "/fonts/InterDisplay-Regular.woff2",
        "format": "woff2",
        "weight": 400
      }
    }
    ```
  </Step>
</Steps>

<div id="local-fonts-for-headings-and-body">
  ### Fuentes locales para títulos y cuerpo de texto
</div>

Configura fuentes locales distintas para los títulos y el cuerpo del texto en tu `docs.json`:

```json docs.json
{
  "fonts": {
    "heading": {
      "family": "InterDisplay",
      "source": "/fonts/InterDisplay-Bold.woff2",
      "format": "woff2",
      "weight": 700
    },
    "body": {
      "family": "InterDisplay",
      "source": "/fonts/InterDisplay-Regular.woff2",
      "format": "woff2",
      "weight": 400
    }
  }
}
```

<div id="externally-hosted-fonts">
  ## Fuentes externas alojadas
</div>

Usa fuentes externas haciendo referencia a una URL de origen de fuente en tu `docs.json`:

```json docs.json
{
  "fonts": {
    "family": "Hubot Sans",
    "source": "https://mintlify-assets.b-cdn.net/fonts/Hubot-Sans.woff2",
    "format": "woff2",
    "weight": 400
  }
}
```

</div>

<ResponseField name="fonts" type="object">
  Configuración de fuentes para tu documentación.

  <Expandable title="Fuentes">
    <ResponseField name="family" type="string" required>
      Nombre de la familia tipográfica, como &quot;Inter&quot; o &quot;Playfair Display&quot;.

    <ResponseField name="weight" type="number">
      Peso de la fuente, como 400 o 700. Las fuentes variables admiten pesos precisos como 550.
    </ResponseField>

    <ResponseField name="source" type="string (uri)">
      URL de tu fuente, como `https://mintlify-assets.b-cdn.net/fonts/Hubot-Sans.woff2`, o ruta a tu archivo de fuente local, como `/assets/fonts/InterDisplay.woff2`. Google Fonts se cargan automáticamente cuando especificas un nombre de `family` de Google Font, por lo que no se necesita una URL de origen.
    </ResponseField>

    <ResponseField name="format" type="'woff' | 'woff2'">
      Formato del archivo de fuente. Obligatorio cuando se usa el campo `source`.
    </ResponseField>
