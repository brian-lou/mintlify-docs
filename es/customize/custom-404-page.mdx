---
title: "Página 404 personalizada"
description: "Personaliza el título y la descripción de tu página de error 404."
keywords: ["página de error 404", "páginas de error personalizadas"]
---

Todas las páginas 404 sugieren automáticamente páginas relevantes en función de la URL solicitada. Si los usuarios llegan a una página 404, un agente analiza la ruta y obtiene páginas relacionadas semánticamente de tu documentación para ayudarles a encontrar lo que buscan.

Puedes personalizar el título y la descripción de la página de error 404. Usa la descripción para añadir enlaces útiles o instrucciones.

<div id="configuration">
  ## Configuración
</div>

Configura tu página 404 en la sección `errors.404` del archivo `docs.json`:

```json
"errors": {
  "404": {
    "redirect": false,
    "title": "I can't be found",
    "description": "What ever **happened** to this _page_?"
  }
}
```


<div id="parameters">
  ## Parámetros
</div>

<ResponseField name="redirect" type="boolean">
  Si se debe redirigir automáticamente a la página de inicio cuando no se encuentre una página.

  Establece `true` para redirigir a la página de inicio.

  Establece `false` para mostrar la página 404 personalizada.
</ResponseField>

<ResponseField name="title" type="string">
  Título personalizado para la página de error 404. Sustituye el encabezado predeterminado &quot;Página no encontrada&quot;.
</ResponseField>

<ResponseField name="description" type="string">
  Descripción personalizada para la página de error 404. Admite formato Markdown.
</ResponseField>
