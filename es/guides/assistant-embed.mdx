<div id="what-you-will-build">
  ## Lo que vas a crear
</div>

Un widget reutilizable que integra el [asistente](/es/ai/assistant) directamente en tu aplicación. El widget ofrece:

* Un botón flotante que abre un panel de chat al hacer clic
* Respuestas transmitidas en tiempo real basadas en la información de tu documentación
* Visualización de mensajes con compatibilidad con Markdown

Los usuarios pueden usar el widget para obtener ayuda con tu producto sin salir de tu aplicación.

<div id="prerequisites">
  ## Requisitos previos
</div>

* [Plan Pro o Enterprise de Mintlify](https://mintlify.com/pricing)
* Tu nombre de dominio, que aparece al final de la URL de tu panel de control. Por ejemplo, si la URL de tu panel de control es `https://dashboard.mintlify.com/org-name/domain-name`, tu nombre de dominio es `domain-name`
* Una [clave API del asistente](https://dashboard.mintlify.com/settings/organization/api-keys)
* Tener instalados Node.js v18 o superior y npm
* Conocimientos básicos de React

<div id="get-your-assistant-api-key">
  ### Obtén la clave API de tu asistente
</div>

1. Ve a la página de [claves API](https://dashboard.mintlify.com/settings/organization/api-keys) en tu panel de control.
2. Haz clic en **Create Assistant API Key**.
3. Copia la clave API del asistente (empieza por `mint_dsc_`) y guárdala en un lugar seguro.

<Note>
  La clave API del asistente es un token público que puedes usar en código de frontend. Las llamadas que usan este token cuentan para el límite de mensajes de tu plan y pueden generar cargos por excedente.
</Note>

<div id="set-up-the-example">
  ## Configura el ejemplo
</div>

Clona el [repositorio de ejemplo](https://github.com/mintlify/assistant-embed-example) y adáptalo a tus necesidades.

<Steps>
  <Step title="Clona el repositorio">
    ```bash
    git clone https://github.com/mintlify/assistant-embed-example.git
    cd assistant-embed-example
    ```
  </Step>

  <Step title="Elige tu herramienta de desarrollo">
    El repositorio incluye ejemplos con Next.js y Vite. Elige la herramienta que prefieras.

    <CodeGroup>
      ```bash title="Next.js"
      cd nextjs
      npm install
      ```

      ```bash title="Vite"
      cd vite
      npm install
      ```
    </CodeGroup>
  </Step>

  <Step title="Configura tu proyecto">
    Abre `src/config.js` y actualízalo con los datos de tu proyecto de Mintlify.

    ```js src/config.js
    export const ASSISTANT_CONFIG = {
      domain: 'your-domain',
      docsURL: 'https://yourdocs.mintlify.app',
    };
    ```

    Reemplaza:

    * `your-domain` por el dominio de tu proyecto de Mintlify, que encontrarás al final de la URL de tu panel de control.
    * `https://yourdocs.mintlify.app` por la URL real de tu documentación.
  </Step>

  <Step title="Añade tu token de la API">
    Crea un archivo `.env` en la raíz del proyecto.

    ```bash .env
    VITE_MINTLIFY_TOKEN=mint_dsc_your_token_here
    ```

    Reemplaza `mint_dsc_your_token_here` por la clave de la API de tu asistente.
  </Step>

  <Step title="Inicia el servidor de desarrollo">
    ```bash
    npm run dev
    ```

    Abre tu aplicación en el navegador y haz clic en el botón **Ask** para abrir el widget del asistente.
  </Step>
</Steps>

<div id="source-citations">
  ### Fuentes citadas
</div>

Extrae y muestra las fuentes de las respuestas del asistente:

```jsx
const extractSources = (parts) => {
  return parts
    ?.filter(p => p.type === 'tool-invocation' && p.toolInvocation?.toolName === 'search')
    .flatMap(p => p.toolInvocation?.result || [])
    .map(source => ({
      url: source.url || source.path,
      title: source.metadata?.title || source.path,
    })) || [];
};

// En el renderizado de tus mensajes:
{messages.map((message) => {
  const sources = message.role === 'assistant' ? extractSources(message.parts) : [];
  return (
    <div key={message.id}>
      {/* contenido del mensaje */}
      {sources.length > 0 && (
        <div className="mt-2 text-xs">
          <p className="font-semibold">Sources:</p>
          {sources.map((s, i) => (
            <a key={i} href={s.url} target="_blank" rel="noopener noreferrer" className="text-blue-600">
              {s.title}
            </a>
          ))}
        </div>
      )}
    </div>
  );
})}
```

<div id="track-conversation-thread-ids">
  ### Seguimiento de los ID de los hilos de conversación
</div>

Almacena los ID de los hilos para mantener el historial de conversación en distintas sesiones:

```jsx
import { useState, useEffect } from 'react';

export function AssistantWidget({ domain, docsURL }) {
  const [threadId, setThreadId] = useState(null);

  useEffect(() => {
    // Recuperar el ID de hilo guardado desde localStorage
    const saved = localStorage.getItem('assistant-thread-id');
    if (saved) {
      setThreadId(saved);
    }
  }, []);

  const { messages, input, handleInputChange, handleSubmit, isLoading } = useChat({
    api: `https://api.mintlify.com/discovery/v1/assistant/${domain}/message`,
    headers: {
      'Authorization': `Bearer ${import.meta.env.VITE_MINTLIFY_TOKEN}`,
    },
    body: {
      fp: 'anonymous',
      retrievalPageSize: 5,
      ...(threadId && { threadId }), // Incluir el ID de hilo si está disponible
    },
    streamProtocol: 'data',
    sendExtraMessageFields: true,
    fetch: async (url, options) => {
      const response = await fetch(url, options);
      const newThreadId = response.headers.get('x-thread-id');
      if (newThreadId) {
        setThreadId(newThreadId);
        localStorage.setItem('assistant-thread-id', newThreadId);
      }
      return response;
    },
  });

  // ... resto del componente
}
```

<div id="add-keyboard-shortcuts">
  ### Añade atajos de teclado
</div>

Permite que los usuarios abran el widget y envíen mensajes mediante atajos de teclado:

```jsx
useEffect(() => {
  const handleKeyDown = (e) => {
    // Cmd/Ctrl + Shift + I para alternar el widget
    if ((e.metaKey || e.ctrlKey) && e.shiftKey && e.key === 'I') {
      e.preventDefault();
      setIsOpen((prev) => !prev);
    }

    // Enter (cuando el widget está enfocado) para enviar
    if (e.key === 'Enter' && !e.shiftKey && document.activeElement.id === 'assistant-input') {
      e.preventDefault();
      handleSubmit();
    }
  };

  window.addEventListener('keydown', handleKeyDown);
  return () => window.removeEventListener('keydown', handleKeyDown);
}, [handleSubmit]);
```
