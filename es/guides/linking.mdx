Un enlazado eficaz crea una experiencia de documentación conectada que ayuda a los usuarios a descubrir contenido relacionado y navegar con eficiencia. Demasiados enlaces o enlaces rotos pueden confundir a los usuarios y hacer que tu documentación sea menos eficaz. Esta guía explica cómo crear y mantener enlaces en toda tu documentación.

<div id="internal-links">
  ## Enlaces internos
</div>

Enlaza con otras páginas de tu documentación mediante rutas relativas a la raíz. Las rutas relativas a la raíz parten de la raíz del directorio de tu documentación y funcionan de forma coherente independientemente de dónde esté la página que contiene el enlace.

```mdx
* [Quickstart guide](/quickstart)
* [API overview](/api-playground/overview)
* [Custom components](/customize/react-components)
```

* [Guía de inicio rápido](/es/quickstart)
* [Resumen de la API](/es/api-playground/overview)
* [Componentes personalizados](/es/customize/react-components)

<div id="anchor-links">
  ## Enlaces de ancla
</div>

Los enlaces de ancla te permiten enlazar directamente a secciones específicas de una página. Cada encabezado genera automáticamente un enlace de ancla en función de su texto.

<div id="link-to-headers-on-the-same-page">
  ### Enlace a encabezados de la misma página
</div>

Haz referencia a los encabezados de la página actual con el símbolo de almohadilla:

```mdx
[Jump to best practices](#best-practices)
```

[Ir a las prácticas recomendadas](#best-practices)

<div id="link-to-headers-on-other-pages">
  ### Enlazar a encabezados de otras páginas
</div>

Combina las rutas de las páginas con enlaces de ancla.

```mdx
* [Customize your playground](/api-playground/overview#customize-your-playground)
* [Cards properties](/components/cards#properties)
```

* [Personaliza tu playground](/es/api-playground/overview#customize-your-playground)
* [Propiedades de Cards](/es/components/cards#properties)

<div id="how-anchor-links-are-generated">
  ### Cómo se generan los enlaces de ancla
</div>

Los enlaces de ancla se crean automáticamente a partir del texto del encabezado.

* Convertir a minúsculas
* Reemplazar los espacios por guiones
* Eliminar los caracteres especiales
* Conservar números y letras

| Texto del encabezado     | Enlace de ancla       |
| ------------------------ | --------------------- |
| `## Getting Started`     | `#getting-started`    |
| `### API Authentication` | `#api-authentication` |
| `#### Step 1: Install`   | `#step-1-install`     |

<Note>
  Los encabezados con la propiedad `noAnchor` no generan enlaces de ancla. Consulta [Formato de texto](/es/create/text#disabling-anchor-links) para obtener más información.
</Note>

<div id="link-to-api-endpoints">
  ## Enlazar con endpoints de la API
</div>

Al documentar APIs, puedes enlazar con endpoints específicos desde cualquier parte de tu documentación.

Enlaza con las páginas de endpoints de la API mediante su ruta en la navegación.

<div id="link-to-external-pages">
  ## Enlaces a páginas externas
</div>

Cuando enlaces a recursos externos, deja claro que el enlace dirige fuera de tu documentación.

```mdx
Obtén más información sobre la [sintaxis de Markdown](https://www.markdownguide.org/) (enlace externo).

Consulta la [especificación OpenAPI](https://swagger.io/specification/) en la documentación de Swagger para más detalles.
```

<div id="best-practices">
  ## Buenas prácticas
</div>

<div id="write-descriptive-link-text">
  ### Escribe un texto de enlace descriptivo
</div>

Usa un texto claro y descriptivo que indique lo que encontrarán los usuarios al hacer clic.

<CodeGroup>
  ```mdx Good examples
  Consulta [Páginas ocultas](/organize/hidden-pages) para obtener más información.
  [Configurar dominios personalizados](/customize/custom-domain)
  ```

  ```mdx Avoid
  [Haz clic aquí](/api-playground/overview)
  [Más información](/deploy/deployments)
  [Consulta esta página](/customize/custom-domain)
  ```
</CodeGroup>

<div id="create-topic-clusters">
  ### Crear grupos temáticos
</div>

Enlaza contenido relacionado para ayudar a los usuarios a descubrir información relevante.

```mdx
## Temas relacionados

- [Autenticación de API](/api-playground/overview#authentication)
- [Agregar ejemplos de SDK](/api-playground/adding-sdk-examples)
- [Gestionar la visibilidad de páginas](/api-playground/managing-page-visibility)
```

<div id="use-contextual-links">
  ### Usa enlaces contextuales
</div>

Añade enlaces de forma natural en el contenido cuando aporten valor.

```mdx
To customize your documentation appearance, configure [themes](/customize/themes) 
and [fonts](/customize/fonts) in your settings. You can also add 
[custom scripts](/customize/custom-scripts) for advanced functionality.
```

<div id="link-to-prerequisites">
  ### Enlace al contenido previo necesario
</div>

Ayuda a los usuarios a prepararse enlazando al contenido previo necesario:

```mdx
## Requisitos previos

Antes de desplegar tu documentación, asegúrate de haber:

- Completado la [guía de inicio rápido](/quickstart)
- Configurado tu [dominio personalizado](/customize/custom-domain)
- Configurado la [autenticación](/deploy/authentication-setup) si es necesario
```

<div id="avoid-circular-links">
  ### Evita los enlaces circulares
</div>

No crees enlaces que hagan que los usuarios vayan de una página a otra entre las mismas páginas.

<div id="check-for-broken-links">
  ### Comprueba si hay enlaces rotos
</div>

Usa la CLI de Mintlify para detectar enlaces rotos en tu documentación.

```bash
mint broken-links
```

<div id="update-links-when-reorganizing">
  ### Actualiza los enlaces al reorganizar
</div>

Al mover o cambiar de nombre páginas:

1. Actualiza la ruta de la página en la configuración de navegación.
2. Configura redirecciones desde la ruta anterior a la nueva.
3. Busca en la documentación referencias a la ruta anterior.
4. Actualiza todos los enlaces internos para que usen la nueva ruta.
5. Ejecuta `mint broken-links` para verificar que todos los enlaces funcionen.

<div id="use-redirects-for-moved-content">
  ### Usa redirecciones para el contenido movido
</div>

Cuando muevas contenido de forma permanente, agrega redirecciones para evitar enlaces rotos.

```json
{
  "redirects": [
    {
      "source": "/old-path",
      "destination": "/new-path"
    }
  ]
}
```

Consulta [Redirecciones](/es/create/redirects) para obtener más información.
