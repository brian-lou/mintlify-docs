<div id="content-basics">
  ## Conceptos básicos del contenido
</div>

Haz que tu redacción y estructura sean fáciles de analizar para los motores de búsqueda.

* **Títulos y subtítulos:** Usa encabezados secuenciales y descriptivos para estructurar tu contenido. Cada página tiene un H1 creado a partir de la propiedad `title:` del Frontmatter.
* **Párrafos cortos y viñetas:** Divide los bloques grandes de texto en secciones fáciles de leer. Usa viñetas y listas numeradas cuando corresponda.
* **Enlaces internos:** Enlaza contenido relacionado usando texto de anclaje descriptivo. Por ejemplo, &quot;Obtén más información sobre la limitación de velocidad&quot; en lugar de &quot;Haz clic aquí&quot;.

<div id="technical-seo-basics">
  ## Aspectos básicos del SEO técnico
</div>

Una vez que tu contenido esté optimizado, asegúrate de que tu documentación tenga un buen rendimiento a nivel técnico.

Estas prácticas básicas de SEO técnico ayudan a que tu documentación sea más fácil de encontrar:

* **Meta tags y descripciones:** Crea títulos optimizados para SEO (50-60 caracteres) y descripciones (150-160 caracteres) para cada página. La mayoría de las [meta tags](/es/optimize/seo) se generan automáticamente.
* **Texto alternativo para imágenes:** Proporciona texto alternativo descriptivo para las imágenes con palabras clave relevantes. Por ejemplo, &quot;flujo de autenticación de API con OAuth 2.0&quot; en lugar de solo &quot;diagrama&quot;. Esto mejora el SEO y la accesibilidad.
* **Sitemaps:** Asegúrate de que tu sitemap esté actualizado. Mintlify genera automáticamente un sitemap. Sin embargo, puedes crear uno manualmente si prefieres un formato personalizado. Una vez creado, los motores de búsqueda indexan los mapas del sitio con el tiempo, pero puedes enviar tu sitemap directamente a Google Search Console para acelerar el proceso.

<div id="page-performance">
  ## Rendimiento de la página
</div>

Usa herramientas como [Google PageSpeed Insights](https://pagespeed.web.dev) para identificar oportunidades de mejora del SEO técnico.

Ejemplos de optimizaciones más avanzadas:

* **Optimiza el contenido multimedia para mejorar la velocidad:** Comprime imágenes con formatos como WebP o AVIF y asegúrate de que tus páginas carguen rápido (idealmente en menos de 3 segundos).
* **Datos estructurados (marcado de esquema):** Añade marcado de esquema (como HowTo, FAQ) a tus páginas para ayudar a los motores de búsqueda a comprender y posicionar mejor tu contenido.

<div id="keyword-research">
  ## Investigación de palabras clave
</div>

Para aumentar el tráfico orgánico, dedica tiempo a entender qué palabras clave ayudan a los usuarios a llegar a tu documentación.

* **Investigación de palabras clave:** Usa herramientas gratuitas como [Google Keyword Planner](https://ads.google.com/intl/en_us/home/tools/keyword-planner/) o [Keywords Everywhere](https://keywordseverywhere.com) para identificar frases habituales o palabras clave de cola larga.
* **Integra las palabras clave de forma natural:** Incorpora las palabras clave de forma natural en los encabezados, subencabezados y el cuerpo del texto. No abuses de las palabras clave. Tu documentación debe estar escrita para tus usuarios, no para los motores de búsqueda.
