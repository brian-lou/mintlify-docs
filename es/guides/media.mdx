<Tip>
  Esta página explica las mejores prácticas para usar capturas de pantalla, GIFs y vídeos en tu documentación.
</Tip>

Las capturas de pantalla, los GIFs y los vídeos pueden mejorar la documentación, pero requieren mantenimiento continuo a medida que cambian los elementos de la interfaz. Úsalos de forma selectiva para evitar trabajo de mantenimiento innecesario.

Pautas clave:

- **El contenido multimedia debe ser complementario.** Si un flujo de trabajo se entiende claramente solo con texto, evita añadir elementos visuales.
- **Garantiza la accesibilidad.** Agrega texto alternativo para las imágenes, subtítulos para los vídeos y transcripciones para el contenido de audio. Muchas personas usan tecnología de asistencia y el contenido accesible beneficia a todas las personas usuarias.
- **Equilibra claridad y facilidad de mantenimiento.** Los cambios frecuentes en la interfaz pueden hacer que las capturas de pantalla y los vídeos queden obsoletos rápidamente. Considera si el esfuerzo de actualizarlos compensa el valor que aportan.

<div id="when-to-use-media">
  ## Cuándo usar contenido multimedia
</div>

* **Capturas de pantalla** para tareas difíciles de explicar solo con palabras.
* **GIFs** para fines promocionales y flujos de trabajo breves pero complejos.
* **Vídeos** para conceptos abstractos y flujos de trabajo extensos.

Usa el contenido multimedia con moderación y de manera deliberada para evitar generar deuda de documentación innecesaria. Cuando se utiliza adecuadamente, mejora la comprensión sin añadir cargas de mantenimiento ni barreras de accesibilidad.
