La internacionalización (i18n) es el proceso de diseñar software o contenido para que funcione en distintos idiomas y configuraciones regionales. Esta guía explica cómo estructurar archivos, configurar la navegación y mantener las traducciones de forma eficaz para ayudar a los usuarios a acceder a tu documentación en su idioma preferido y mejorar tu alcance global.

<div id="file-structure">
  ## Estructura de archivos
</div>

Organiza el contenido traducido en directorios específicos de cada idioma para que tu documentación sea fácil de mantener y estructurar la navegación por idioma.

Crea un directorio independiente para cada idioma con los [códigos de idioma ISO 639-1](https://en.wikipedia.org/wiki/List_of_ISO_639-1_codes). Coloca los archivos traducidos en esos directorios con la misma estructura que la de tu idioma predeterminado.

<Expandable title="códigos de idioma admitidos">
  * `ar` - Árabe
  * `cs` - Checo
  * `cn` o `zh-Hans` - Chino (simplificado)
  * `zh-Hant` - Chino (tradicional)
  * `de` - Alemán
  * `en` - Inglés
  * `es` - Español
  * `fr` - Francés
  * `he` - Hebreo
  * `hi` - Hindi
  * `id` - Indonesio
  * `it` - Italiano
  * `jp` - Japonés
  * `ko` - Coreano
  * `lv` - Letón
  * `nl` - Neerlandés
  * `no` - Noruego
  * `pl` - Polaco
  * `pt` o `pt-BR` - Portugués
  * `ro` - Rumano
  * `ru` - Ruso
  * `sv` - Sueco
  * `tr` - Turco
  * `ua` - Ucraniano
  * `uz` - Uzbeko
  * `vi` - Vietnamita
</Expandable>

```text Example file structure
docs/
├── index.mdx                    # Inglés (predeterminado)
├── quickstart.mdx
├── fr/
│   ├── index.mdx               # Francés
│   ├── quickstart.mdx
├── es/
│   ├── index.mdx               # Español
│   ├── quickstart.mdx
└── zh/
    ├── index.mdx               # Chino
    └── quickstart.mdx
```

<Tip>
  Mantén los mismos nombres de archivo y la misma estructura de directorios en todos los idiomas. Esto facilita el mantenimiento de las traducciones y la identificación del contenido que falta.
</Tip>


<div id="configure-the-language-switcher">
  ## Configura el selector de idioma
</div>

Para añadir un selector de idioma a tu documentación, configura la matriz `languages` en la navegación de tu `docs.json`.

```json docs.json
{
  "navigation": {
    "languages": [
      {
        "language": "en",
        "groups": [
          {
            "group": "Getting started",
            "pages": ["index", "quickstart"]
          }
        ]
      },
      {
        "language": "es",
        "groups": [
          {
            "group": "Comenzando",
            "pages": ["es/index", "es/quickstart"]
          }
        ]
      }
    ]
  }
}
```

Cada entrada de idioma en el array `languages` requiere:

* `language`: código de idioma ISO 639-1
* Estructura de navegación completa
* Rutas a los archivos traducidos

La estructura de navegación puede variar entre idiomas para adaptarse a las necesidades de contenido específicas de cada uno.


<div id="set-default-language">
  ### Configurar el idioma predeterminado
</div>

El primer idioma de la matriz `languages` se usa automáticamente como predeterminado. Para usar otro idioma como predeterminado, reordena la matriz o añade la propiedad `default`:

```json docs.json
{
  "navigation": {
    "languages": [
      {
        "language": "es",
        "groups": [...]
      },
      {
        "language": "en",
        "groups": [...]
      }
    ]
  }
}
```

Como alternativa, usa la propiedad `default` para cambiar el orden:

```json docs.json
{
  "navigation": {
    "languages": [
      {
        "language": "en",
        "groups": [...]
      },
      {
        "language": "es",
        "default": true,
        "groups": [...]
      }
    ]
  }
}
```


<div id="single-language-documentation">
  ### Documentación en un solo idioma
</div>

Si solo quieres tener un idioma disponible sin un selector de idioma, elimina el campo `languages` de la configuración de navegación. En su lugar, define directamente la estructura de navegación:

```json docs.json
{
  "navigation": {
    "tabs": [
      {
        "tab": "Documentation",
        "groups": [
          {
            "group": "Getting started",
            "pages": ["index", "quickstart"]
          }
        ]
      }
    ]
  }
}
```

Esto muestra tu documentación en un solo idioma, sin la interfaz del selector de idioma.

<Tip>
  Traduce las etiquetas de navegación, como los nombres de grupos o pestañas, para que coincidan con el idioma del contenido. Así crearás una experiencia totalmente localizada para tus usuarios.
</Tip>


<div id="global-navigation">
  ### Navegación global
</div>

Para añadir elementos de navegación global que aparezcan en todos los idiomas, configura el objeto `global` dentro de la navegación de tu `docs.json`.

```json docs.json
{
  "navigation": {
    "global": {
      "anchors": [
        {
          "anchor": "Documentation",
          "href": "https://example.com/docs"
        },
        {
          "anchor": "Blog",
          "href": "https://example.com/blog"
        }
      ]
    },
    "languages": [
      // Navegación específica por idioma
    ]
  }
}
```


<div id="maintain-translations">
  ## Mantén actualizadas las traducciones
</div>

Mantén las traducciones precisas y sincronizadas con tu contenido original.

<div id="translation-workflow">
  ### Flujo de trabajo de traducción
</div>

1. Actualiza el contenido original en tu idioma principal.
2. Identifica el contenido modificado.
3. Traduce el contenido modificado.
4. Revisa las traducciones para comprobar su precisión.
5. Actualiza los archivos traducidos.
6. Verifica que la navegación y los enlaces funcionen.

<div id="images-and-media">
  ### Imágenes y contenido multimedia
</div>

Guarda las imágenes traducidas en directorios específicos para cada idioma.

```
images/
├── dashboard.png          # Versión en inglés
├── fr/
│   └── dashboard.png     # Versión en francés
└── es/
    └── dashboard.png     # Versión en español
```

Usa rutas relativas para las imágenes en tu contenido traducido.

```mdx es/index.mdx
![Captura de pantalla del panel de control](/images/es/dashboard.png)
```

  ### Metadatos de la página
</div>

Incluye metadatos traducidos en el frontmatter de cada archivo:

```mdx fr/index.mdx
title: "Commencer"

```


<div id="best-practices">
  ## Buenas prácticas
</div>

<div id="date-and-number-formats">
  ### Formatos de fecha y número
</div>

Ten en cuenta los formatos específicos de cada región para las fechas y los números.

* Formatos de fecha: MM/DD/YYYY vs DD/MM/YYYY
* Formatos de número: 1,000.00 vs 1.000,00
* Símbolos de moneda: $100.00 vs 100,00€

Incluye ejemplos con el formato adecuado para cada idioma o usa formatos universalmente comprendidos.

<div id="maintain-consistency">
  ### Mantén la coherencia
</div>

* Mantén la paridad del contenido en todos los idiomas para garantizar que cada usuario reciba información de la misma calidad.
* Crea un glosario de traducción para los términos técnicos.
* Mantén la misma estructura de contenido en todos los idiomas.
* Mantén el tono y el estilo de tu contenido original.
* Usa ramas de Git para gestionar el trabajo de traducción por separado de las actualizaciones del contenido principal.

<div id="layout-differences">
  ### Diferencias de diseño
</div>

Algunos idiomas requieren más o menos espacio que el inglés. Prueba tu contenido traducido en distintos tamaños de pantalla para comprobar que:

* La navegación se ajuste correctamente.
* Los bloques de código no se desborden.
* Las tablas y otros textos con formato sigan siendo legibles.
* Las imágenes se escalen correctamente.

<div id="character-encoding">
  ### Codificación de caracteres
</div>

Asegúrate de que tu entorno de desarrollo y tu proceso de despliegue admitan la codificación UTF-8 para mostrar correctamente todos los caracteres en idiomas con alfabetos distintos y caracteres especiales.
