La internacionalización (i18n) es el proceso de diseñar software o contenido para que sea compatible con diferentes idiomas y configuraciones regionales. Esta guía explica cómo estructurar archivos, configurar la navegación y mantener las traducciones de forma efectiva, para que puedas ayudar a los usuarios a acceder a tu documentación en su idioma preferido y mejorar tu alcance global.

<div id="file-structure">
  ## Estructura de archivos
</div>

Organiza el contenido traducido en directorios específicos por idioma para mantener tu documentación fácil de mantener y estructurar la navegación por idioma.

Crea un directorio independiente para cada idioma usando los [códigos de idioma ISO 639-1](https://en.wikipedia.org/wiki/List_of_ISO_639-1_codes). Coloca los archivos traducidos en estos directorios con la misma estructura que en tu idioma predeterminado.

<Expandable title="códigos de idioma admitidos">
  * `ar` - árabe
  * `cs` - checo
  * `cn` o `zh-Hans` - chino (simplificado)
  * `zh-Hant` - chino (tradicional)
  * `de` - alemán
  * `en` - inglés
  * `es` - español
  * `fr` - francés
  * `he` - hebreo
  * `hi` - hindi
  * `id` - indonesio
  * `it` - italiano
  * `jp` - japonés
  * `ko` - coreano
  * `lv` - letón
  * `nl` - neerlandés
  * `no` - noruego
  * `pl` - polaco
  * `pt` o `pt-BR` - portugués
  * `ro` - rumano
  * `ru` - ruso
  * `sv` - sueco
  * `tr` - turco
  * `ua` - ucraniano
  * `uz` - uzbeko
  * `vi` - vietnamita
</Expandable>

```text Example file structure
docs/
├── index.mdx                    # Inglés (predeterminado)
├── quickstart.mdx
├── fr/
│   ├── index.mdx               # Francés
│   ├── quickstart.mdx
├── es/
│   ├── index.mdx               # Español
│   ├── quickstart.mdx
└── zh/
    ├── index.mdx               # Chino
    └── quickstart.mdx
```

<Tip>
  Mantén los mismos nombres de archivo y la misma estructura de directorios en todos los idiomas. Esto facilita mantener las traducciones y detectar contenido faltante.
</Tip>


<div id="configure-the-language-switcher">
  ## Configurar el selector de idioma
</div>

Para agregar un selector de idioma a tu documentación, configura el array `languages` en la navegación de tu `docs.json`.

```json docs.json
{
  "navigation": {
    "languages": [
      {
        "language": "en",
        "groups": [
          {
            "group": "Getting started",
            "pages": ["index", "quickstart"]
          }
        ]
      },
      {
        "language": "es",
        "groups": [
          {
            "group": "Comenzando",
            "pages": ["es/index", "es/quickstart"]
          }
        ]
      }
    ]
  }
}
```

Cada entrada de idioma en la matriz `languages` requiere:

* `language`: código de idioma ISO 639-1
* Estructura de navegación completa
* Rutas de los archivos traducidos

La estructura de navegación puede variar entre idiomas para adaptarse a las necesidades de contenido específicas de cada uno.


<div id="set-default-language">
  ### Establecer el idioma predeterminado
</div>

El primer idioma en el array `languages` se usa automáticamente como idioma predeterminado. Para usar un idioma diferente como predeterminado, reordena el array o agrega la propiedad `default`:

```json docs.json
{
  "navigation": {
    "languages": [
      {
        "language": "es",
        "groups": [...]
      },
      {
        "language": "en",
        "groups": [...]
      }
    ]
  }
}
```

Como alternativa, usa la propiedad `default` para sobrescribir el orden:

```json docs.json
{
  "navigation": {
    "languages": [
      {
        "language": "en",
        "groups": [...]
      },
      {
        "language": "es",
        "default": true,
        "groups": [...]
      }
    ]
  }
}
```


<div id="single-language-documentation">
  ### Documentación en un solo idioma
</div>

Si solo quieres tener un idioma disponible y no necesitas un selector de idioma, elimina el campo `languages` de tu configuración de navegación. Luego define directamente tu estructura de navegación:

```json docs.json
{
  "navigation": {
    "tabs": [
      {
        "tab": "Documentation",
        "groups": [
          {
            "group": "Getting started",
            "pages": ["index", "quickstart"]
          }
        ]
      }
    ]
  }
}
```

Esto muestra la documentación en un solo idioma, sin el conmutador de idioma en la interfaz.

<Tip>
  Traduce las etiquetas de navegación, como los nombres de grupos o pestañas, para que estén en el mismo idioma que el contenido. Esto crea una experiencia completamente localizada para tus usuarios.
</Tip>


<div id="global-navigation">
  ### Navegación global
</div>

Para añadir elementos de navegación global que sean visibles en todos los idiomas, configura el objeto `global` en la navegación de `docs.json`.

```json docs.json
{
  "navigation": {
    "global": {
      "anchors": [
        {
          "anchor": "Documentation",
          "href": "https://example.com/docs"
        },
        {
          "anchor": "Blog",
          "href": "https://example.com/blog"
        }
      ]
    },
    "languages": [
      // Navegación específica por idioma
    ]
  }
}
```


<div id="maintain-translations">
  ## Mantén actualizadas las traducciones
</div>

Mantén tus traducciones precisas y sincronizadas con tu contenido fuente.

<div id="translation-workflow">
  ### Flujo de trabajo de traducción
</div>

1. Actualiza el contenido fuente en tu idioma principal.
2. Identifica el contenido que haya cambiado.
3. Traduce el contenido cambiado.
4. Revisa las traducciones para comprobar su precisión.
5. Actualiza los archivos traducidos.
6. Verifica que la navegación y los enlaces funcionen correctamente.

<div id="images-and-media">
  ### Imágenes y medios
</div>

Almacena las imágenes traducidas en directorios específicos para cada idioma.

```
images/
├── dashboard.png          # Versión en inglés
├── fr/
│   └── dashboard.png     # Versión en francés
└── es/
    └── dashboard.png     # Versión en español
```

Utiliza rutas relativas para las imágenes en tu contenido traducido.

```mdx es/index.mdx
![Captura de pantalla del panel de control](/images/es/dashboard.png)
```


<div id="seo-for-multi-language-sites">
  ## SEO para sitios multilingües
</div>

Optimiza cada versión en cada idioma para los motores de búsqueda.

<div id="page-metadata">
  ### Metadatos de página
</div>

Incluye los metadatos traducidos en el frontmatter de cada archivo:

```mdx fr/index.mdx
---
title: "Commencer"
description: "Apprenez à commencer avec notre produit."
keywords: ["démarrage", "tutoriel", "guide"]
---
```


<div id="best-practices">
  ## Buenas prácticas
</div>

<div id="date-and-number-formats">
  ### Formatos de fecha y número
</div>

Ten en cuenta los formatos específicos de cada región para fechas y números.

- Formatos de fecha: MM/DD/YYYY vs DD/MM/YYYY
- Formatos numéricos: 1,000.00 vs 1.000,00
- Símbolos de moneda: $100.00 vs 100,00€

Incluye ejemplos en el formato adecuado para cada idioma o utiliza formatos universalmente entendidos.

<div id="maintain-consistency">
  ### Mantén la coherencia
</div>

- Mantén la equivalencia del contenido en todos los idiomas para asegurarte de que cada usuario reciba la misma calidad de información.
- Crea un glosario de términos técnicos para la traducción.
- Conserva la misma estructura de contenido en todos los idiomas.
- Alinea el tono y el estilo con tu contenido original.
- Usa ramas de Git para gestionar el trabajo de traducción por separado de las actualizaciones del contenido principal.

<div id="layout-differences">
  ### Diferencias de diseño
</div>

Algunos idiomas requieren más o menos espacio que el inglés. Prueba tu contenido traducido en distintos tamaños de pantalla para comprobar que:

- La navegación se ajuste correctamente.
- Los bloques de código no se desborden.
- Las tablas y otros textos con formato sigan siendo legibles.
- Las imágenes se redimensionen de forma adecuada.

<div id="character-encoding">
  ### Codificación de caracteres
</div>

Asegúrate de que tu entorno de desarrollo y tu canal de despliegue sean compatibles con la codificación UTF-8 para mostrar correctamente todos los caracteres en idiomas que usan alfabetos distintos y caracteres especiales.
