Las guías de esta sección contienen recomendaciones para crear documentación que ayude a tus usuarios a tener éxito. Ya sea que empieces desde cero o que mejores la documentación existente, estas guías te ayudan a planificar, redactar y mantener tu documentación.

Ante todo, ten en cuenta las necesidades y los objetivos de tus usuarios. Documenta aquello que les ayude a usar tu producto y a volver a sus tareas.

<div id="topics">
  ## Temas
</div>

<div id="ai-tools">
  ### Herramientas de IA
</div>

Usa herramientas con tecnología de IA para acelerar tu flujo de trabajo de documentación.

* [Automatizar actualizaciones de documentación](/es/guides/automate-agent): Tutorial que explica cómo configurar actualizaciones automatizadas de la documentación usando el agente.
* [Crear un asistente dentro de la app](/es/guides/assistant-embed): Tutorial que explica cómo añadir un chatbot de IA en una app de React para ayudar a los usuarios a encontrar respuestas en tu documentación.
* [Claude Code](/es/guides/claude-code), [Cursor](/es/guides/cursor), [Windsurf](/es/guides/windsurf): Guías para usar asistentes de programación con IA para mantener la documentación.
* [GEO](/es/guides/geo): Mejores prácticas para optimizar tu documentación para motores de búsqueda y de respuesta basados en IA.

<div id="api-documentation">
  ### Documentación de la API
</div>

Crea documentación de la API para que los usuarios puedan probar y aprender a usar tu API, y que a la vez sea fácil de mantener.

* [Migrar de MDX a OAS](/es/guides/migrating-from-mdx): Migra tu documentación de la API de páginas individuales en MDX a páginas autogeneradas a partir de una especificación de OpenAPI.

<div id="best-practices">
  ### Mejores prácticas
</div>

Haz que tu documentación sea de primer nivel.

* [Accesibilidad](/es/guides/accessibility): Haz que tu documentación sea accesible para el mayor número posible de usuarios.
* [Tipos de contenido](/es/guides/content-types): Elige el formato adecuado para tutoriales, guías prácticas, referencias y explicaciones.
* [Plantillas de contenido](/es/guides/content-templates): Copia y modifica plantillas para cada tipo de contenido.
* [Mejora tu documentación](/es/guides/improving-docs): Usa datos y comentarios para mejorar continuamente tu documentación.
* [Internacionalización](/es/guides/internationalization): Configura documentación multilingüe para llegar a una audiencia global.
* [Enlaces](/es/guides/linking): Crea enlaces internos, referencia endpoints de API y mantén la integridad de los enlaces en toda tu documentación.
* [Mantenimiento](/es/guides/maintenance): Mantén tu documentación precisa y actualizada.
* [Contenido multimedia](/es/guides/media): Añade imágenes, videos y otros medios de forma eficaz mientras gestionas la carga de mantenimiento.
* [Organizar la navegación](/es/guides/navigation): Diseña una arquitectura de información que funcione para tus usuarios.
* [SEO](/es/guides/seo): Optimiza tu documentación para motores de búsqueda.
* [Estilo y tono](/es/guides/style-and-tone): Escribe con una voz consistente.
* [Conoce a tu audiencia](/es/guides/understand-your-audience): Investiga y atiende las necesidades y objetivos de tus usuarios.

<div id="git-workflows">
  ### Flujos de trabajo con Git
</div>

Entiende Git para aprovechar al máximo Mintlify y un enfoque de documentación como código.

* [Conceptos de Git](/es/guides/git-concepts): Aprende los fundamentos de Git para la documentación.
* [Ramas](/es/guides/branches): Usa ramas para gestionar los cambios en la documentación.

<div id="use-cases">
  ### Casos de uso
</div>

Descubre cómo Mintlify se adapta a distintos casos de uso y encuentra una solución que funcione para ti.

* [Crear documentación para desarrolladores](/es/guides/developer-documentation): Ayuda a tus usuarios a sacar el máximo partido de tu producto o API con documentación para desarrolladores que responda a sus preguntas y les permita retomar cuanto antes sus tareas principales.
* [Crear una base de conocimientos](/es/guides/knowledge-base): Crea una base de conocimientos interna para consolidar la información de tu equipo, mejorar la búsqueda y reducir la carga de mantenimiento.
* [Crear un centro de soporte](/es/guides/support-center): Crea un centro de soporte de autoservicio que ayude a los clientes a encontrar respuestas, reduzca el volumen de tickets y mejore la satisfacción del cliente.
