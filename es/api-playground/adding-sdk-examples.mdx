---
title: "Agregar ejemplos de SDK"
description: "Muestra ejemplos de código de SDK en tu documentación de API."
keywords: ["x-codeSamples", "Ejemplos de SDK"]
---

Si tus usuarios interactúan con tu API mediante un SDK en lugar de hacerlo directamente a través de una solicitud de red, puedes usar la extensión `x-codeSamples` para añadir ejemplos de código a tu documento OpenAPI y mostrarlos en tus páginas de OpenAPI.

Esta propiedad se puede añadir a cualquier método de solicitud y tiene el siguiente esquema.

<ParamField body="lang" type="string" required>
  El idioma del ejemplo de código.
</ParamField>

<ParamField body="label" type="string">
  La etiqueta del ejemplo. Esto resulta útil cuando proporcionas varios ejemplos para un mismo endpoint.
</ParamField>

<ParamField body="source" type="string" required>
  El código fuente del ejemplo.
</ParamField>

Aquí tienes un ejemplo de muestras de código para una aplicación de seguimiento de plantas, que cuenta tanto con una herramienta de línea de comandos de Bash como con un SDK de JavaScript.

```yaml
paths:
  /plants:
    get:
      # ...
      x-codeSamples:
        - lang: bash
          label: List all unwatered plants
          source: |
            planter list -u
        - lang: javascript
          label: List all unwatered plants
          source: |
            const planter = require('planter');
            planter.list({ unwatered: true });
        - lang: bash
          label: List all potted plants
          source: |
            planter list -p
        - lang: javascript
          label: List all potted plants
          source: |
            const planter = require('planter');
            planter.list({ potted: true });
```
