---
title: "Agregar ejemplos de SDK"
description: "Muestra ejemplos de código de SDK en tu documentación de API."
keywords: ["x-codeSamples", "SDK examples"]
---

Si tus usuarios interactúan con tu API usando un SDK en lugar de hacerlo directamente mediante una solicitud de red, puedes usar la extensión `x-codeSamples` para agregar ejemplos de código a tu documento OpenAPI y mostrarlos en tus páginas de OpenAPI.

Esta propiedad se puede agregar a cualquier método de solicitud y tiene el siguiente esquema.

<ParamField body="lang" type="string" required>
  El idioma del ejemplo de código.
</ParamField>

<ParamField body="label" type="string">
  La etiqueta para el ejemplo. Esto es útil cuando proporcionas varios ejemplos para un solo endpoint.
</ParamField>

<ParamField body="source" type="string" required>
  El código fuente del ejemplo.
</ParamField>

A continuación, se muestra un conjunto de ejemplos de código para una aplicación de seguimiento de plantas, que cuenta tanto con una herramienta de línea de comandos (CLI) en Bash como con un SDK de JavaScript.

```yaml
paths:
  /plants:
    get:
      # ...
      x-codeSamples:
        - lang: bash
          label: List all unwatered plants
          source: |
            planter list -u
        - lang: javascript
          label: List all unwatered plants
          source: |
            const planter = require('planter');
            planter.list({ unwatered: true });
        - lang: bash
          label: List all potted plants
          source: |
            planter list -p
        - lang: javascript
          label: List all potted plants
          source: |
            const planter = require('planter');
            planter.list({ potted: true });
```
