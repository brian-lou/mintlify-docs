<div id="add-an-asyncapi-specification-file">
  ## Añadir un archivo de especificación AsyncAPI
</div>

Para crear páginas para tus websockets, debes tener un documento de esquema de AsyncAPI válido en formato JSON o YAML que siga la [especificación AsyncAPI 3.0](https://www.asyncapi.com/docs/reference/specification/v3.0.0).

<Tip>
  Usa [AsyncAPI Studio](https://studio.asyncapi.com/) para validar tu esquema de AsyncAPI.
</Tip>

```json {3}
/your-project
  |- docs.json
  |- asyncapi.json
```

<div id="auto-populate-websockets-pages">
  ## Generar automáticamente páginas de websockets
</div>

Para generar automáticamente páginas para todos los canales de tu esquema AsyncAPI, agrega una propiedad `asyncapi` a cualquier elemento de navegación. La propiedad `asyncapi` acepta una ruta a un documento de esquema AsyncAPI en tu repositorio de documentación, una URL a un documento AsyncAPI alojado o una lista de enlaces a documentos de esquema AsyncAPI.

<div id="examples-with-tabs">
  ### Ejemplos con pestañas
</div>

<CodeGroup>
  ```json Archivo local
  "navigation": {
    "tabs": [
      {
          "tab": "API Reference",
          "asyncapi": "/path/to/asyncapi.json"
      }
    ]
  }

  ```

  ```json URL remota
  "navigation": {
    "tabs": [
      {
          "tab": "API Reference",
          "asyncapi": "https://github.com/asyncapi/spec/blob/master/examples/simple-asyncapi.yml"
      }
    ]
  }
  ```

  ```json Varios archivos
  "navigation": {
    "tabs": [
      {
        "tab": "API Reference",
        "asyncapi": [
          "/path/to/events.json",
          "/path/to/webhooks.json"
        ]
      }
    ]
  }
  ```
</CodeGroup>

<Note>
  Cuando especificas varios archivos AsyncAPI, cada archivo genera su propio conjunto de páginas de canales.
</Note>

<div id="examples-with-groups">
  ### Ejemplos de grupos
</div>

```json
"navigation": {
  "tabs": [
    {
      "tab": "AsyncAPI",
      "groups": [
        {
          "group": "Websockets",
          "asyncapi": {
            "source": "/path/to/asyncapi.json",
            "directory": "websockets"
          }
        }
      ]
    }
  ]
}
```

<Note>
  El campo `directory` es opcional. Si no se especifica, los archivos se guardarán en la carpeta **api-reference** del repositorio de documentación.
</Note>

<div id="channel-page">
  ## Página del canal
</div>

Si quieres tener un mayor control sobre el orden de tus canales o quieres hacer referencia únicamente a canales específicos, crea un archivo MDX con la propiedad `asyncapi` en el frontmatter.

```mdx
---
title: "Websocket Channel"
asyncapi: "/path/to/asyncapi.json channelName"
---
```
