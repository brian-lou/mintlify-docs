description: "Controla qué endpoints de API aparecen en la navegación de tu documentación."

Para endpoints de uso interno, operaciones obsoletas, funciones beta o endpoints a los que se deba acceder mediante URL directa pero que no deban descubrirse a través de la navegación del sitio, puedes controlar qué operaciones de OpenAPI se publican como páginas de documentación y su visibilidad en la navegación.

Si tus páginas se autogeneran a partir de un documento OpenAPI, gestiona la visibilidad de las páginas con las extensiones `x-hidden` y `x-excluded`.

<div id="x-hidden">
  ## `x-hidden`
</div>

La extensión `x-hidden` crea una página para un endpoint, pero la oculta en la navegación. Solo se puede acceder a ella directamente mediante su URL.

Los casos de uso habituales de `x-hidden` son:

* Endpoints que quieres documentar, pero no destacar.
* Páginas a las que enlazarás desde otro contenido.
* Endpoints para usuarios específicos.

<div id="x-excluded">
  ## `x-excluded`
</div>

La extensión `x-excluded` excluye por completo un endpoint de tu documentación.

Los casos de uso más comunes de `x-excluded` son:

* Endpoints de uso interno.
* Endpoints obsoletos que no quieres documentar.
* Funcionalidades beta que no están listas para la documentación pública.

<div id="implementation">
  ## Implementación
</div>

Agrega la extensión `x-hidden` o `x-excluded` debajo del método HTTP en tu especificación de OpenAPI.

Aquí tienes ejemplos de cómo usar cada propiedad en un documento de esquema de OpenAPI para un endpoint y una ruta de webhook.

```json Endpoint example {11, 19}
"paths": {
  "/plants": {
    "get": {
      "description": "Returns all plants from the store",
      "parameters": { /*...*/ },
      "responses": { /*...*/ }
    }
  },
  "/hidden_plants": {
    "get": {
      "x-hidden": true,
      "description": "Returns all somewhat secret plants from the store",
      "parameters": { /*...*/ },
      "responses": { /*...*/ }
    }
  },
  "/secret_plants": {
    "get": {
      "x-excluded": true,
      "description": "Returns all top secret plants from the store (do not publish this endpoint!)",
      "parameters": { /*...*/ },
      "responses": { /*...*/ }
    }
  }
},
```

```json Webhook example {9, 15}
"webhooks": {
  "/plants_hook": {
    "post": {
      "description": "Webhook con información sobre una nueva planta añadida a la tienda",
    }
  },
  "/hidden_plants_hook": {
    "post": {
      "x-hidden": true,
      "description": "Webhook con información algo secreta sobre una nueva planta añadida a la tienda"
    }
  },
  "/secret_plants_hook": {
    "post": {
      "x-excluded": true,
      "description": "Webhook con información ultrasecreta sobre una nueva planta añadida a la tienda (¡no publiques este endpoint!)"
    }
  }
}
```
