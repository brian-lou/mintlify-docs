<Info>
  Los registros de auditoría están disponibles en los [planes Enterprise](https://mintlify.com/pricing?ref=audit-logs).
</Info>

Utilice los registros de auditoría para supervisar y hacer seguimiento de las acciones realizadas por los miembros de su organización. Los registros de auditoría proporcionan un historial de actividades para fines de seguridad, cumplimiento y resolución de problemas.

- **Supervisar la seguridad**: Haga seguimiento de los intentos de autenticación y los cambios de permisos.
- **Garantizar el cumplimiento**: Mantenga registros de todas las actividades de la organización.
- **Solucionar problemas**: Investigue las acciones fallidas y sus causas.
- **Hacer seguimiento de los cambios**: Revise quién realizó cambios específicos y cuándo.

<div id="view-audit-logs">
  ## Ver registros de auditoría
</div>

Ve a la página de [Audit log](https://dashboard.mintlify.com/settings/organization/audit-logs) de tu panel para ver los registros de auditoría.

Haz clic en cualquier entrada del registro para expandirla y ver información detallada, incluida:

| Campo | Descripción |
| ----- | ----------- |
| Timestamp | Fecha y hora en que ocurrió la acción |
| Actor | Dirección de correo electrónico del usuario que realizó la acción |
| Action | Acción que realizó el usuario |
| Category | Tipo de recurso afectado |
| Outcome | Si la acción se realizó correctamente o falló |
| Metadata | Contexto adicional sobre la acción |

<div id="filter-logs">
  ### Filtrar registros
</div>

Filtra los registros de auditoría para encontrar actividades específicas.

**Intervalo de fechas**: Selecciona un intervalo de fechas preestablecido para ver registros durante un período específico.

**Categoría**: Filtra los registros por tipo de acción.

| Categoría        | Descripción                                                        |
|------------------|--------------------------------------------------------------------|
| Organization     | Actualizaciones de la configuración de la organización y solicitudes de eliminación. |
| Member           | Invitaciones, retiradas y cambios de rol de miembros del equipo.  |
| Deployment       | Cambios en la configuración de despliegues, incluidos dominios personalizados, autenticación y orígenes de Git. |
| Preview deployment | Creación, actualizaciones y cambios de autenticación de despliegues de vista previa. |
| API key          | Creación y eliminación de claves de API y claves de API de descubrimiento. |
| Assistant        | Actualizaciones de la configuración de Assistant, como correo de desvío, sitios de búsqueda web y preguntas iniciales. |
| PDF export       | Generación y eliminación de exportaciones en PDF.                 |
| Integration      | Instalaciones y desinstalaciones de GitHub, Slack y Discord.      |
| Billing          | Actualizaciones de suscripciones, compras de complementos y visualización de facturas. |
| Quota            | Cambios en la política de excedentes y en la configuración de alertas. |
| User             | Configuración de notificaciones para usuarios individuales.        |
| Suggestions      | Configuraciones de sugerencias y gestión de repositorios.         |
| Audit log        | Visualización y exportación del registro de auditoría.            |
| Auth             | Intentos de inicio de sesión, cierres de sesión y creación de sesiones. |

<div id="export-audit-logs">
  ## Exportar registros de auditoría
</div>

Exporta los registros de auditoría en formato CSV para análisis, elaboración de informes de cumplimiento o archivo a largo plazo.

1. Navega a la página [Audit log](https://dashboard.mintlify.com/settings/organization/audit-logs) de tu panel de control.
1. Opcionalmente, aplica filtros para acotar los registros que quieres exportar.
1. Haz clic en **Export CSV**.
1. Mintlify te enviará un correo electrónico con un enlace de descarga cuando la exportación esté lista.
