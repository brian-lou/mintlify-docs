<Info>
  Los registros de auditoría están disponibles en los [planes Enterprise](https://mintlify.com/pricing?ref=audit-logs).
</Info>

Usa los registros de auditoría para supervisar y seguir las acciones realizadas por los miembros de tu organización. Los registros de auditoría ofrecen un registro de actividades con fines de seguridad, cumplimiento y resolución de problemas.

* **Supervisar la seguridad**: Haz un seguimiento de los intentos de autenticación y los cambios de permisos.
* **Garantizar el cumplimiento**: Mantén un registro de todas las actividades de la organización.
* **Resolver problemas**: Investiga las acciones fallidas y sus causas.
* **Seguir los cambios**: Revisa quién hizo cambios específicos y cuándo.

<div id="view-audit-logs">
  ## Ver los registros de auditoría
</div>

Ve a la página [Registro de auditoría](https://dashboard.mintlify.com/settings/organization/audit-logs) de tu panel para ver los registros de auditoría.

Haz clic en cualquier entrada del registro para expandirla y ver información detallada, como:

| Campo          | Descripción                                                       |
| -------------- | ----------------------------------------------------------------- |
| Marca temporal | Fecha y hora en que se produjo la acción                          |
| Actor          | Dirección de correo electrónico del usuario que realizó la acción |
| Acción         | Acción realizada por el usuario                                   |
| Categoría      | Tipo de recurso afectado                                          |
| Resultado      | Indica si la acción se completó correctamente o falló             |
| Metadatos      | Contexto adicional sobre la acción                                |

<div id="filter-logs">
  ### Filtrar registros
</div>

Filtra los registros de auditoría para encontrar actividades específicas.

**Rango de fechas**: Selecciona un rango de fechas predefinido para ver los registros de un período específico.

**Categoría**: Filtra los registros por tipo de acción.

| Categoría                  | Descripción                                                                                                                       |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Organización               | Actualizaciones de la configuración de la organización y solicitudes de eliminación.                                              |
| Miembro                    | Invitaciones, eliminaciones y cambios de rol de miembros del equipo.                                                              |
| Despliegue                 | Cambios en la configuración del despliegue, incluidos dominios personalizados, autenticación y orígenes de Git.                   |
| Despliegue de vista previa | Creación de despliegues de vista previa, actualizaciones y cambios de autenticación.                                              |
| Clave de API               | Creación y eliminación de claves de API y claves de API de descubrimiento.                                                        |
| Assistant                  | Actualizaciones de la configuración de Assistant, como el correo de desvío, los sitios de búsqueda web y las preguntas iniciales. |
| Exportación en PDF         | Generación y eliminación de exportaciones en PDF.                                                                                 |
| Integración                | Instalaciones y eliminaciones de GitHub, Slack y Discord.                                                                         |
| Facturación                | Actualizaciones de la suscripción, compras de complementos y consultas de facturas.                                               |
| Cuota                      | Cambios en la política de excedentes y en la configuración de alertas.                                                            |
| Usuario                    | Configuración de notificaciones de usuarios individuales.                                                                         |
| Sugerencias                | Configuración de sugerencias y gestión de repositorios.                                                                           |
| Registro de auditoría      | Consultas y exportaciones de registros de auditoría.                                                                              |
| Autenticación              | Intentos de inicio de sesión, cierres de sesión y creación de sesiones.                                                           |

<div id="export-audit-logs">
  ## Exportar registros de auditoría
</div>

Exporta los registros de auditoría a un archivo CSV para analizarlos, generar informes de cumplimiento o archivarlos a largo plazo.

1. Ve a la página [Registro de auditoría](https://dashboard.mintlify.com/settings/organization/audit-logs) de tu panel.
2. Si lo deseas, aplica filtros para acotar los registros que quieres exportar.
3. Haz clic en **Export CSV**.
4. Mintlify te envía un correo electrónico con un enlace de descarga cuando la exportación está lista.
