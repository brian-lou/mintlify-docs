<Info>
  El control de acceso basado en roles (RBAC) está disponible en los [planes Enterprise](https://mintlify.com/pricing?ref=rbac).
</Info>

Mintlify ofrece tres niveles de acceso al panel de control: lector, editor y administrador.

|                                        | Lector | Editor | Administrador |
| -------------------------------------- | :----: | :----: | :-----------: |
| Ver contenido en el editor             |    ✅   |    ✅   |       ✅       |
| Ver el panel de control y la analítica |    ✅   |    ✅   |       ✅       |
| Editar contenido en el editor web      |    ❌   |    ✅   |       ✅       |
| Iniciar despliegues                    |    ❌   |    ✅   |       ✅       |
| Crear y eliminar claves de API         |    ❌   |    ✅   |       ✅       |
| Configurar integraciones               |    ❌   |    ✅   |       ✅       |
| Configurar el asistente                |    ❌   |    ✅   |       ✅       |
| Configurar complementos                |    ❌   |    ✅   |       ✅       |
| Invitar a editores y lectores          |    ❌   |    ✅   |       ✅       |
| Actualizar roles de usuario            |    ❌   |    ❌   |       ✅       |
| Invitar a administradores              |    ❌   |    ❌   |       ✅       |
| Eliminar usuarios                      |    ❌   |    ❌   |       ✅       |
| Gestionar la facturación               |    ❌   |    ❌   |       ✅       |
| Gestionar SSO                          |    ❌   |    ❌   |       ✅       |
| Actualizar el dominio personalizado    |    ❌   |    ❌   |       ✅       |
| Actualizar el origen de Git            |    ❌   |    ❌   |       ✅       |
| Eliminar la organización               |    ❌   |    ❌   |       ✅       |

<Tip>
  Limita el acceso de administrador únicamente a quienes necesiten realizar tareas administrativas.
</Tip>

<div id="add-members-to-your-organization">
  ## Agrega miembros a tu organización
</div>

De forma predeterminada, la persona que crea tu organización de Mintlify tiene acceso de administrador. Agrega editores adicionales en la página [Miembros](https://dashboard.mintlify.com/settings/organization/members) de tu panel de control.

Puedes tener tantos miembros como necesites en tu organización. Las licencias pueden generar costos adicionales. Consulta la [página de precios](https://mintlify.com/pricing) para obtener más información.
