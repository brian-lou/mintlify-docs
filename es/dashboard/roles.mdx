<Info>
  El control de acceso basado en roles (RBAC) está disponible en los [planes Enterprise](https://mintlify.com/pricing?ref=rbac).
</Info>

Mintlify ofrece tres niveles de acceso al panel: lector, editor y administrador.

|                                           | Lector | Editor | Admin |
| ----------------------------------------- | :----: | :----: | :---: |
| Ver contenido en el editor                |   ✅   |   ✅   |  ✅   |
| Ver el panel y las analíticas             |   ✅   |   ✅   |  ✅   |
| Editar contenido en el editor web         |   ❌   |   ✅   |  ✅   |
| Lanzar despliegues                        |   ❌   |   ✅   |  ✅   |
| Crear y eliminar claves de API            |   ❌   |   ✅   |  ✅   |
| Configurar integraciones                  |   ❌   |   ✅   |  ✅   |
| Configurar el asistente                   |   ❌   |   ✅   |  ✅   |
| Configurar complementos                   |   ❌   |   ✅   |  ✅   |
| Invitar editores y lectores               |   ❌   |   ✅   |  ✅   |
| Actualizar roles de usuario               |   ❌   |   ❌   |  ✅   |
| Invitar administradores                   |   ❌   |   ❌   |  ✅   |
| Eliminar usuarios                         |   ❌   |   ❌   |  ✅   |
| Gestionar la facturación                  |   ❌   |   ❌   |  ✅   |
| Gestionar el SSO                          |   ❌   |   ❌   |  ✅   |
| Actualizar el dominio personalizado       |   ❌   |   ❌   |  ✅   |
| Actualizar el origen en Git               |   ❌   |   ❌   |  ✅   |
| Eliminar la organización                  |   ❌   |   ❌   |  ✅   |

<Tip>
  Limita el acceso de administrador únicamente a las personas que necesiten realizar tareas administrativas.
</Tip>

<div id="add-members-to-your-organization">
  ## Agrega miembros a tu organización
</div>

De forma predeterminada, la persona que crea tu organización de Mintlify tiene acceso de administrador. Agrega editores adicionales en la página [Members](https://dashboard.mintlify.com/settings/organization/members) de tu panel.

Puedes tener tantos miembros como necesites en tu organización. Los asientos pueden generar costos adicionales. Consulta la [página de precios](https://mintlify.com/pricing) para obtener más detalles.
