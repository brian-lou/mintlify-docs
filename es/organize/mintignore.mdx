El archivo `.mintignore` te permite excluir archivos y directorios específicos de tu repositorio de documentación para evitar que se procesen y publiquen en tu sitio de documentación.

Usa `.mintignore` para mantener borradores, notas internas y archivos fuente fuera de tu documentación pública, sin dejar de conservarlos en tu repositorio.

<div id="create-a-mintignore-file">
  ## Crea un archivo `.mintignore`
</div>

Crea un archivo `.mintignore` en la raíz de tu directorio de documentación. Este archivo utiliza la misma sintaxis de patrones que `.gitignore`.

```plaintext .mintignore
# Excluir documentos en borrador
drafts/
*.draft.mdx

# Excluir documentación interna
internal/

# Excluir archivos específicos
private-notes.md
```

Cuando Mintlify genera tu documentación, lee el archivo `.mintignore` y excluye del procesamiento cualquier archivo o directorio que coincida.

Archivos excluidos:

* No aparecen en tu documentación publicada.
* No se indexan para las búsquedas.
* Los visitantes no pueden acceder a ellos.
* No se tienen en cuenta en las [comprobaciones de enlaces rotos](/es/installation#find-broken-links). Los enlaces que apuntan a archivos ignorados se consideran rotos.

<div id="default-ignored-patterns">
  ## Patrones ignorados por defecto
</div>

Mintlify ignora automáticamente los siguientes directorios y archivos sin necesidad de configuración:

* `.git`
* `.github`
* `.claude`
* `.agents`
* `.idea`
* `node_modules`
* `README.md`
* `LICENSE.md`
* `CHANGELOG.md`
* `CONTRIBUTING.md`

No necesitas añadirlos a tu archivo `.mintignore`.

<Note>
  A diferencia de las [páginas ocultas](/es/organize/hidden-pages), los archivos excluidos por `.mintignore`
  se eliminan por completo de tu sitio y no se puede acceder a ellos mediante una URL.
</Note>

<div id="pattern-syntax">
  ## Sintaxis de patrones
</div>

El archivo `.mintignore` sigue la sintaxis de `.gitignore`. Algunos patrones comunes son:

| Patrón             | Descripción                                                |
| ------------------ | ---------------------------------------------------------- |
| `drafts/`          | Excluye todo el directorio `drafts`                        |
| `*.draft.mdx`      | Excluye todos los archivos que terminan en `.draft.mdx`    |
| `private-notes.md` | Excluye un archivo específico                              |
| `**/internal/**`   | Excluye cualquier directorio `internal` en cualquier nivel |
| `!important.mdx`   | Anula un patrón anterior (incluye el archivo)              |
