La propiedad [navigation](/es/organize/settings#param-navigation) en `docs.json` controla la estructura y la jerarquía de la información de tu documentación.

Con una configuración de navegación adecuada, puedes organizar tu contenido para que los usuarios encuentren exactamente lo que están buscando.

Elige un único patrón de organización principal en el nivel raíz de tu navegación. Una vez que hayas elegido tu patrón principal, puedes anidar otros elementos de navegación dentro de él.

<div id="pages">
  ## Páginas
</div>

Las páginas son el elemento de navegación más básico. Cada página es un archivo MDX en tu repositorio de documentación.

<img className="block dark:hidden pointer-events-none" src="/images/navigation/pages-light.png" alt="Gráfico decorativo de páginas." />

<img className="hidden dark:block pointer-events-none" src="/images/navigation/pages-dark.png" alt="Gráfico decorativo de páginas." />

En el objeto `navigation`, `pages` es un array donde cada entrada debe hacer referencia a la ruta a un [archivo de página](/es/organize/pages).

```json
{
  "navigation": {
    "pages": [
      "settings",
      "pages",
      "navigation",
      "themes",
      "custom-domain"
    ]
  }
}
```

<div id="groups">
  ## Grupos
</div>

Usa grupos para organizar la navegación de tu barra lateral en secciones. Los grupos se pueden anidar entre sí, etiquetar con etiquetas y personalizar con íconos.

<img className="block dark:hidden pointer-events-none" src="/images/navigation/groups-light.png" alt="Gráfico decorativo de grupos." />

<img className="hidden dark:block pointer-events-none" src="/images/navigation/groups-dark.png" alt="Gráfico decorativo de grupos." />

En el objeto `navigation`, `groups` es un array donde cada entrada es un objeto que requiere un campo `group` y un campo `pages`. Los campos `icon`, `tag` y `expanded` son opcionales.

```json
{
  "navigation": {
    "groups": [
      {
        "group": "Getting started",
        "icon": "play",
        "pages": [
          "quickstart",
          {
            "group": "Editing",
            "expanded": false,
            "icon": "pencil",
            "pages": [
              "installation",
              "editor"
            ]
          }
        ]
      },
      {
        "group": "Writing content",
        "icon": "notebook-text",
        "tag": "NEW",
        "pages": [
          "writing-content/page",
          "writing-content/text"
        ]
      }
    ]
  }
}
```

<div id="default-expanded-state">
  ### Estado expandido predeterminado
</div>

Usa la propiedad `expanded` para controlar el estado predeterminado de un grupo anidado en la barra lateral de navegación.

* `expanded: true`: el grupo se muestra expandido de forma predeterminada.
* `expanded: false` o cuando se omite: el grupo se muestra contraído de forma predeterminada.

<Note>
  La propiedad `expanded` solo afecta a los grupos anidados --grupos dentro de grupos. Los grupos de nivel superior siempre están expandidos y no se pueden contraer.
</Note>

```json
{
  "group": "Getting started",
  "pages": [
    "quickstart",
    {
      "group": "Advanced",
      "expanded": false,
      "pages": ["installation", "configuration"]
    }
  ]
}
```

<div id="tabs">
  ## Pestañas
</div>

Las pestañas crean secciones diferenciadas en tu documentación con rutas URL independientes. También añaden una barra de navegación horizontal en la parte superior de tu documentación que permite a los usuarios cambiar entre secciones.

<img className="block dark:hidden pointer-events-none" src="/images/navigation/tabs-light.png" alt="Gráfico decorativo de una navegación con pestañas." />

<img className="hidden dark:block pointer-events-none" src="/images/navigation/tabs-dark.png" alt="Gráfico decorativo de una navegación con pestañas." />

En el objeto `navigation`, `tabs` es un array donde cada entrada es un objeto que requiere un campo `tab` y puede contener otros campos de navegación como grupos, páginas, iconos o enlaces a páginas externas.

```json
{
  "navigation": {
    "tabs": [
      {
        "tab": "API reference",
        "icon": "square-terminal",
        "pages": [
          "api-reference/get",
          "api-reference/post",
          "api-reference/delete"
        ]
      },
      {
        "tab": "SDKs",
        "icon": "code",
        "pages": [
          "sdk/fetch",
          "sdk/create",
          "sdk/delete"
        ]
      },
      {
        "tab": "Blog",
        "icon": "newspaper",
        "href": "https://external-link.com/blog"
      }
    ]
  }
}
```

<div id="menus">
  ### Menús
</div>

Los menús añaden elementos de navegación desplegables a una pestaña. Utiliza los menús para ayudar a los usuarios a ir directamente a páginas específicas dentro de una pestaña.

En el objeto `navigation`, `menu` es un arreglo en el que cada elemento es un objeto que requiere un campo `item` y puede contener otros campos de navegación, como grupos, páginas, iconos o enlaces a páginas externas.

Los elementos de menú solo pueden contener grupos, páginas y enlaces externos.

```json
{
  "navigation": {
    "tabs": [
      {
        "tab": "Developer tools",
        "icon": "square-terminal",
        "menu": [
          {
            "item": "API reference",
            "icon": "rocket",
            "groups": [
              {
                "group": "Core endpoints",
                "icon": "square-terminal",
                "pages": [
                  "api-reference/get",
                  "api-reference/post",
                  "api-reference/delete"
                ]
              }
            ]
          },
          {
            "item": "SDKs",
            "icon": "code",
            "description": "SDKs are used to interact with the API.",
            "pages": [
              "sdk/fetch",
              "sdk/create",
              "sdk/delete"
            ]
          }
        ]
      }
    ]
  }
}
```

<div id="anchors">
  ## Anclas
</div>

Las anclas agregan elementos de navegación fijos en la parte superior de tu barra lateral. Usa anclas para estructurar tu contenido, proporcionar acceso rápido a recursos externos o crear llamadas a la acción destacadas.

<img className="block dark:hidden pointer-events-none" src="/images/navigation/anchors-light.png" alt="Gráfico decorativo de una navegación con anclas." />

<img className="hidden dark:block pointer-events-none" src="/images/navigation/anchors-dark.png" alt="Gráfico decorativo de una navegación con anclas." />

En el objeto `navigation`, `anchors` es un array donde cada elemento es un objeto que debe incluir un campo `anchor` y puede contener otros campos de navegación como grupos, páginas, iconos o enlaces a páginas externas.

```json
{
  "navigation": {
    "anchors": [
      {
        "anchor": "Documentation",
        "icon": "book-open",
        "pages": [
          "quickstart",
          "development",
          "navigation"
        ]
      },
      {
        "anchor": "API reference",
        "icon": "square-terminal",
        "pages": [
          "api-reference/get",
          "api-reference/post",
          "api-reference/delete"
        ]
      },
      {
        "anchor": "Blog",
        "href": "https://external-link.com/blog"
      }
    ]
  }
}
```

<div id="global-anchors">
  ### Anclas globales
</div>

Usa anclas globales para enlaces que deban aparecer en todas las páginas, independientemente de qué sección de tu navegación esté viendo el usuario. Las anclas globales son especialmente útiles para enlazar con recursos fuera de tu documentación (como un blog, un foro de la comunidad o un portal de soporte) o para proporcionar acceso constante a páginas internas importantes (como un registro de cambios o una página de estado).

Las anclas globales admiten tanto URL externas como rutas relativas a páginas dentro de tu documentación.

```json
{
  "navigation": {
    "global":  {
      "anchors": [
        {
          "anchor": "Changelog",
          "icon": "list",
          "href": "/changelog"
        },
        {
          "anchor": "Blog",
          "icon": "pencil",
          "href": "https://mintlify.com/blog"
        }
      ]
    },
    "tabs": /*...*/
  }
}
```

<div id="openapi">
  ## OpenAPI
</div>

Integra especificaciones de OpenAPI directamente en tu estructura de navegación para generar automáticamente la documentación de tu API. Crea secciones de API dedicadas o coloca páginas de endpoints dentro de otros componentes de navegación.

Establece una especificación de OpenAPI predeterminada en cualquier nivel de tu jerarquía de navegación. Los elementos secundarios heredarán esta especificación, a menos que definan una propia.

<Note>
  Cuando agregas la propiedad `openapi` a un elemento de navegación (como un enlace, pestaña o grupo) sin especificar ninguna página, Mintlify genera automáticamente páginas para **todos los endpoints** definidos en tu especificación de OpenAPI.

  Para controlar qué endpoints aparecen, enumera explícitamente los endpoints deseados en un array `pages`.
</Note>

Para obtener más información sobre cómo hacer referencia a endpoints de OpenAPI en tu documentación, consulta la [configuración de OpenAPI](/es/api-playground/openapi-setup).

```json
{
  "navigation": {
    "groups": [
      {
        "group": "API reference",
        "openapi": "/path/to/openapi-v1.json",
        "pages": [
          "overview",
          "authentication",
          "GET /users",
          "POST /users",
          {
            "group": "Products",
            "openapi": "/path/to/openapi-v2.json",
            "pages": [
              "GET /products",
              "POST /products"
            ]
          }
        ]
      }
    ]
  }
}
```

<div id="nesting">

</div>

Cada elemento de navegación puede contener un único tipo de elemento hijo en cada nivel de tu jerarquía de navegación. Por ejemplo, una pestaña puede contener enlaces que a su vez contengan grupos, pero una pestaña no puede contener enlaces y grupos al mismo nivel.

<div id="breadcrumbs">
  ## Breadcrumbs
</div>

Los breadcrumbs muestran la ruta completa de navegación en la parte superior de las páginas. Algunos temas tienen los breadcrumbs activados de forma predeterminada y otros no. Puedes controlar si los breadcrumbs están activados en tu sitio mediante la propiedad `styling` en tu `docs.json`.

<CodeGroup>
  ```json Mostrar breadcrumbs completos
  "styling": {
    "eyebrows": "breadcrumbs"
  }
  ```

  ```json Mostrar solo la sección principal
  "styling": {
    "eyebrows": "section"
  }
  ```
</CodeGroup>

<div id="enable-auto-navigation-for-groups">
  ### Habilitar la navegación automática para grupos
</div>

Cuando un usuario expande un grupo de navegación, algunos temas navegarán automáticamente a la primera página del grupo. Puedes anular el comportamiento predeterminado de un tema usando la opción `drilldown`.

* Establécelo en `true` para forzar la navegación automática a la primera página al seleccionar un grupo de navegación.
* Establécelo en `false` para evitar la navegación y solo expandir o contraer el grupo cuando se seleccione.
* Déjalo sin configurar para usar el comportamiento predeterminado del tema.

<CodeGroup>
  ```json Force navigation
  "interaction": {
    "drilldown": true  // Forzar la navegación a la primera página cuando un usuario expande un menú desplegable
  }
  ```

  ```json Prevent navigation
  "interaction": {
    "drilldown": false // No navegar nunca, solo expandir o contraer el grupo
  }
  ```
</CodeGroup>
