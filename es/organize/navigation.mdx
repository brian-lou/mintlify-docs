La propiedad [navigation](/es/organize/settings#param-navigation) de `docs.json` controla la estructura y la jerarquía de la información de tu documentación.

Con una configuración de navegación adecuada, puedes organizar tu contenido para que los usuarios encuentren exactamente lo que buscan.

Elige un patrón de organización principal en el nivel raíz de la navegación. Una vez que lo hayas elegido, puedes anidar otros elementos de navegación dentro de él.

<div id="pages">
  ## Páginas
</div>

Las páginas son el componente de navegación más básico. Cada página es un archivo MDX de tu repositorio de documentación.

<img className="block dark:hidden pointer-events-none" src="/images/navigation/pages-light.png" alt="Gráfico decorativo de páginas." />

<img className="hidden dark:block pointer-events-none" src="/images/navigation/pages-dark.png" alt="Gráfico decorativo de páginas." />

En el objeto `navigation`, `pages` es un array en el que cada elemento debe hacer referencia a la ruta de un [archivo de página](/es/organize/pages).

```json
{
  "navigation": {
    "pages": [
      "settings",
      "pages",
      "navigation",
      "themes",
      "custom-domain"
    ]
  }
}
```

<div id="groups">
  ## Grupos
</div>

Usa grupos para organizar la navegación de la barra lateral en secciones. Los grupos pueden anidarse entre sí, etiquetarse con etiquetas y mostrarse con iconos.

<img className="block dark:hidden pointer-events-none" src="/images/navigation/groups-light.png" alt="Gráfico decorativo de grupos." />

<img className="hidden dark:block pointer-events-none" src="/images/navigation/groups-dark.png" alt="Gráfico decorativo de grupos." />

En el objeto `navigation`, `groups` es un array en el que cada entrada es un objeto que requiere un campo `group` y un campo `pages`. Los campos `icon`, `tag` y `expanded` son opcionales.

```json
{
  "navigation": {
    "groups": [
      {
        "group": "Getting started",
        "icon": "play",
        "pages": [
          "quickstart",
          {
            "group": "Editing",
            "expanded": false,
            "icon": "pencil",
            "pages": [
              "installation",
              "editor"
            ]
          }
        ]
      },
      {
        "group": "Writing content",
        "icon": "notebook-text",
        "tag": "NEW",
        "pages": [
          "writing-content/page",
          "writing-content/text"
        ]
      }
    ]
  }
}
```

<div id="default-expanded-state">
  ### Estado expandido predeterminado
</div>

Usa la propiedad `expanded` para controlar el estado predeterminado de un grupo anidado en la barra lateral de navegación.

* `expanded: true`: El grupo aparece expandido de forma predeterminada.
* `expanded: false` o se omite: El grupo aparece contraído de forma predeterminada.

<Note>
  La propiedad `expanded` solo afecta a los grupos anidados, es decir, grupos dentro de otros grupos. Los grupos de nivel superior siempre aparecen expandidos y no se pueden contraer.
</Note>

```json
{
  "group": "Getting started",
  "pages": [
    "quickstart",
    {
      "group": "Advanced",
      "expanded": false,
      "pages": ["installation", "configuration"]
    }
  ]
}
```

<div id="tabs">
  ## Pestañas
</div>

Las pestañas crean secciones diferenciadas en tu documentación con rutas URL independientes. También añaden una barra de navegación horizontal en la parte superior de la documentación para que los usuarios puedan cambiar entre secciones.

<img className="block dark:hidden pointer-events-none" src="/images/navigation/tabs-light.png" alt="Gráfico decorativo de una navegación por pestañas." />

<img className="hidden dark:block pointer-events-none" src="/images/navigation/tabs-dark.png" alt="Gráfico decorativo de una navegación por pestañas." />

En el objeto `navigation`, `tabs` es un array en el que cada elemento es un objeto que requiere un campo `tab` y puede incluir otros campos de navegación, como grupos, páginas, iconos o enlaces a páginas externas.

```json
{
  "navigation": {
    "tabs": [
      {
        "tab": "API reference",
        "icon": "square-terminal",
        "pages": [
          "api-reference/get",
          "api-reference/post",
          "api-reference/delete"
        ]
      },
      {
        "tab": "SDKs",
        "icon": "code",
        "pages": [
          "sdk/fetch",
          "sdk/create",
          "sdk/delete"
        ]
      },
      {
        "tab": "Blog",
        "icon": "newspaper",
        "href": "https://external-link.com/blog"
      }
    ]
  }
}
```

<div id="menus">
  ### Menús
</div>

Los menús añaden elementos desplegables de navegación a una pestaña. Úsalos para ayudar a los usuarios a ir directamente a páginas específicas dentro de una pestaña.

En el objeto `navigation`, `menu` es un array en el que cada elemento es un objeto que requiere un campo `item` y puede contener otros campos de navegación, como grupos, páginas, iconos o enlaces a páginas externas.

Los elementos del menú solo pueden contener grupos, páginas y enlaces externos.

```json
{
  "navigation": {
    "tabs": [
      {
        "tab": "Developer tools",
        "icon": "square-terminal",
        "menu": [
          {
            "item": "API reference",
            "icon": "rocket",
            "groups": [
              {
                "group": "Core endpoints",
                "icon": "square-terminal",
                "pages": [
                  "api-reference/get",
                  "api-reference/post",
                  "api-reference/delete"
                ]
              }
            ]
          },
          {
            "item": "SDKs",
            "icon": "code",
            "description": "Los SDKs se utilizan para interactuar con la API.",
            "pages": [
              "sdk/fetch",
              "sdk/create",
              "sdk/delete"
            ]
          }
        ]
      }
    ]
  }
}
```

<div id="anchors">
  ## Anclas
</div>

Las anclas añaden elementos de navegación persistentes en la parte superior de tu barra lateral. Usa anclas para organizar tu contenido por secciones, ofrecer acceso rápido a recursos externos o crear llamadas a la acción destacadas.

<img className="block dark:hidden pointer-events-none" src="/images/navigation/anchors-light.png" alt="Gráfico decorativo de una navegación con anclas." />

<img className="hidden dark:block pointer-events-none" src="/images/navigation/anchors-dark.png" alt="Gráfico decorativo de una navegación con anclas." />

En el objeto `navigation`, `anchors` es un array en el que cada entrada es un objeto que requiere un campo `anchor` y puede incluir otros campos de navegación, como grupos, páginas, iconos o enlaces a páginas externas.

```json
{
  "navigation": {
    "anchors": [
      {
        "anchor": "Documentation",
        "icon": "book-open",
        "pages": [
          "quickstart",
          "development",
          "navigation"
        ]
      },
      {
        "anchor": "API reference",
        "icon": "square-terminal",
        "pages": [
          "api-reference/get",
          "api-reference/post",
          "api-reference/delete"
        ]
      },
      {
        "anchor": "Blog",
        "href": "https://external-link.com/blog"
      }
    ]
  }
}
```

<div id="global-anchors">
  ### Anclas globales
</div>

Usa anclas globales para los enlaces que deben aparecer en todas las páginas, independientemente de la sección de navegación que esté viendo el usuario. Las anclas globales son especialmente útiles para enlazar a recursos externos a tu documentación (como un blog, un foro de la comunidad o un portal de soporte) o para ofrecer acceso uniforme a páginas internas importantes (como un registro de cambios o una página de estado).

Las anclas globales admiten tanto URL externas como rutas relativas a páginas dentro de tu documentación.

```json
{
  "navigation": {
    "global":  {
      "anchors": [
        {
          "anchor": "Changelog",
          "icon": "list",
          "href": "/changelog"
        },
        {
          "anchor": "Blog",
          "icon": "pencil",
          "href": "https://mintlify.com/blog"
        }
      ]
    },
    "tabs": /*...*/
  }
}
```

<div id="openapi">
  ## OpenAPI
</div>

Integra las especificaciones de OpenAPI directamente en tu estructura de navegación para generar automáticamente la documentación de la API. Crea secciones de API específicas o coloca páginas de endpoints dentro de otros componentes de navegación.

Define una especificación de OpenAPI predeterminada en cualquier nivel de tu jerarquía de navegación. Los elementos secundarios heredarán esta especificación, a menos que definan la suya propia.

<Note>
  Cuando añades la propiedad `openapi` a un elemento de navegación (como un ancla, una pestaña o un grupo) sin especificar ninguna página, Mintlify genera automáticamente páginas para **todos los endpoints** definidos en tu especificación de OpenAPI.

  Para controlar qué endpoints aparecen, enumera explícitamente los endpoints que quieras en un array `pages`.
</Note>

Para obtener más información sobre cómo hacer referencia a endpoints de OpenAPI en tu documentación, consulta la [configuración de OpenAPI](/es/api-playground/openapi-setup).

```json
{
  "navigation": {
    "groups": [
      {
        "group": "API reference",
        "openapi": "/path/to/openapi-v1.json",
        "pages": [
          "overview",
          "authentication",
          "GET /users",
          "POST /users",
          {
            "group": "Products",
            "openapi": "/path/to/openapi-v2.json",
            "pages": [
              "GET /products",
              "POST /products"
            ]
          }
        ]
      }
    ]
  }
}
```

<div id="nesting">

</div>

Cada elemento de navegación puede contener un único tipo de elemento secundario en cada nivel de la jerarquía. Por ejemplo, una pestaña puede contener anclas que, a su vez, contienen grupos, pero una pestaña no puede contener tanto anclas como grupos en el mismo nivel.

<div id="breadcrumbs">
  ## Migas de pan
</div>

Las migas de pan muestran la ruta de navegación completa en la parte superior de las páginas. Algunos temas las tienen habilitadas de forma predeterminada y otros no. Puedes controlar si están habilitadas en tu sitio mediante la propiedad `styling` de tu `docs.json`.

<CodeGroup>
  ```json Mostrar todas las migas de pan
  "styling": {
    "eyebrows": "breadcrumbs"
  }
  ```

  ```json Mostrar solo la sección padre
  "styling": {
    "eyebrows": "section"
  }
  ```
</CodeGroup>

Controla cómo interactúan los usuarios con los elementos de navegación mediante la propiedad `interaction` de tu `docs.json`.

<div id="enable-auto-navigation-for-groups">
  ### Habilitar la navegación automática para grupos
</div>

Cuando un usuario expande un grupo de navegación, algunos temas navegan automáticamente a la primera página del grupo. Puedes anular el comportamiento predeterminado del tema con la opción `drilldown`.

* Establece `true` para forzar la navegación automática a la primera página cuando se seleccione un grupo de navegación.
* Establece `false` para evitar la navegación y solo expandir o contraer el grupo al seleccionarlo.
* Déjalo sin definir para usar el comportamiento predeterminado del tema.

<CodeGroup>
  ```json Forzar navegación
  "interaction": {
    "drilldown": true  // Forzar la navegación a la primera página cuando un usuario expanda un menú desplegable
  }
  ```

  ```json Evitar navegación
  "interaction": {
    "drilldown": false // No navegar nunca; solo expandir o contraer el grupo
  }
  ```
</CodeGroup>
