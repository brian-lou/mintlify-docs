Cada página es un archivo de Markdown. Se admiten archivos `.mdx` y `.md`. Recomendamos usar MDX, que combina Markdown con componentes de React para crear documentación completa e interactiva. También se admite Markdown simple (`.md`) para facilitar la migración desde otras plataformas, pero conviene actualizarlo a MDX para aprovechar todas sus funciones.

<div id="page-metadata">
  ## Metadatos de la página
</div>

Cada página comienza con Frontmatter, los metadatos YAML delimitados por `---` al principio de un archivo. Estos metadatos definen cómo se muestra y se comporta tu página.

Usa Frontmatter para controlar:

* Títulos y descripciones de las páginas
* Títulos, iconos y etiquetas de la barra lateral
* Diseños de página
* Metaetiquetas de SEO
* Metadatos personalizados

<ResponseField name="title" type="string" required>
  El título de tu página que aparece en la navegación y en las pestañas del navegador.
</ResponseField>

<ResponseField name="description" type="string">
  Una breve descripción del contenido de esta página. Aparece debajo del título y mejora el SEO.
</ResponseField>

<ResponseField name="sidebarTitle" type="string">
  Un título breve que se muestra en la navegación de la barra lateral.
</ResponseField>

<ResponseField name="icon" type="string">
  El icono que se mostrará.

  Opciones:

  * Nombre de un [icono de Font Awesome](https://fontawesome.com/icons)
  * Nombre de un [icono de Lucide](https://lucide.dev/icons)
  * URL de un icono alojado externamente
  * Ruta a un archivo de icono en tu proyecto
</ResponseField>

<ResponseField name="iconType" type="string">
  El estilo del icono de [Font Awesome](https://fontawesome.com/icons). Solo se usa con iconos de Font Awesome.

  Opciones: `regular`, `solid`, `light`, `thin`, `sharp-solid`, `duotone`, `brands`.
</ResponseField>

<ResponseField name="tag" type="string">
  Una etiqueta que aparece junto al título de tu página en la barra lateral.
</ResponseField>

<ResponseField name="<custom>" type="string">
  Cualquier Frontmatter válido en YAML. Por ejemplo, `product: "API"` o `version: "1.0.0"`.
</ResponseField>

```yaml Example YAML frontmatter wrap
---
title: "Acerca del frontmatter"
description: "El frontmatter es el metadato que controla cómo aparece y se comporta tu página"
sidebarTitle: "Frontmatter"
icon: "book"
tag: "NEW"
---
```

<div id="page-mode">
  ## Modo de la página
</div>

Controla cómo se muestra tu página con la opción `mode`.

<div id="default">
  ### Por defecto
</div>

Si no se define ningún modo, se utiliza un diseño estándar con navegación en la barra lateral y tabla de contenidos.

```yaml
---
title: "Default page title"
---
```

<div id="wide">
  ### Ancho
</div>

El modo ancho oculta la tabla de contenidos. Resulta útil en páginas sin encabezados o si prefieres aprovechar el espacio horizontal adicional. Está disponible en todos los temas.

```yaml
---
title: "Wide page title"
mode: "wide"
---
```

<div id="custom">
  ### Personalizado
</div>

El modo personalizado ofrece un diseño minimalista que elimina todos los elementos excepto la barra de navegación superior. Es un lienzo en blanco para crear páginas de inicio o cualquier otro diseño único en el que quieras mantener al mínimo los elementos de navegación. El modo personalizado está disponible para todos los temas.

```yaml
---
title: "Custom page title"
mode: "custom"
---
```

<Warning>
  Usar la propiedad `style` en páginas de modo personalizado puede provocar un cambio en el diseño al cargar la página. Para evitar este problema, usa [Tailwind CSS o CSS personalizado](/es/customize/custom-scripts).
</Warning>

<div id="frame">
  ### Frame
</div>

El modo Frame ofrece un diseño similar al modo personalizado, pero conserva la navegación de la barra lateral. Este modo de página permite usar HTML y componentes personalizados mientras mantiene la experiencia de navegación predeterminada. El modo Frame solo está disponible para los temas Aspen y Almond.

```yaml
---
title: "Frame page title"
mode: "frame"
---
```

<div id="center">
  ### Centrado
</div>

El modo centrado elimina la barra lateral y la tabla de contenidos para centrar el contenido. Esto resulta útil para registros de cambios u otras páginas en las que quieras destacar el contenido. El modo centrado está disponible en los temas Mint y Linden.

```yaml
---
title: "Center page title"
mode: "center"
---
```

<div id="api-pages">
  ## Páginas de API
</div>

Crea áreas de pruebas de API interactivas añadiendo una especificación de API en tu Frontmatter, `api` u `openapi`.

```yaml
---
openapi: "GET /endpoint"
---
```

Obtén más información sobre cómo crear [documentación de API](/es/api-playground/overview).

<div id="external-links">
  ## Enlaces externos
</div>

Enlaza directamente a sitios externos desde tu navegación con los metadatos `url`.

```yaml
---
title: "npm Package"
url: "https://www.npmjs.com/package/mint"
---
```

<div id="search-engine-optimization">
  ## Optimización para motores de búsqueda
</div>

La mayoría de las metaetiquetas SEO se generan automáticamente. Puedes definirlas manualmente para mejorar el SEO de tu sitio, cómo se comparte en redes sociales y la compatibilidad con los navegadores.

<Note>
  Las metaetiquetas con dos puntos deben ir entre comillas.
</Note>

```yaml
---
"twitter:image": "/images/social-preview.jpg"
---
```

Consulta [SEO](/es/optimize/seo) para ver todas las opciones de metadatos de SEO.

<div id="internal-search-keywords">
  ## Palabras clave de búsqueda internas
</div>

Mejora la visibilidad de una página específica en la búsqueda integrada añadiendo `keywords` en tus metadatos. Estas palabras clave no aparecerán como parte del contenido de la página ni en los resultados de búsqueda, pero los usuarios que las busquen verán la página entre los resultados.

```yaml
---
keywords: ['configuration', 'setup', 'getting started']
---
```

<div id="last-modified-timestamp">
  ## Marca temporal de última modificación
</div>

Añade una marca temporal de &quot;Última modificación el [date]&quot; a todas las páginas habilitando `metadata.timestamp` en tu [configuración global](/es/organize/settings#metadata).

```json docs.json
"metadata": {
  "timestamp": true
}
```

Sobrescribe la configuración global de la marca temporal en páginas individuales con el campo `timestamp` del Frontmatter. Usa este campo para mostrar u ocultar selectivamente las marcas temporales en páginas específicas.

```yaml
---
title: "Page title"
timestamp: false
---
```

Cuando se establece en `true`, la marca temporal se muestra incluso si la configuración global es `false`. Cuando se establece en `false`, la marca temporal se oculta incluso si la configuración global es `true`.
