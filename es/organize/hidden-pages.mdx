---
title: "Páginas ocultas"
description: "Oculta páginas de la navegación mientras las mantienes accesibles."
keywords: ["ocultar de la navegación", "páginas no listadas", "visibilidad de la página"]
---

Las páginas ocultas no se incluyen en la navegación de tu sitio, pero siguen siendo accesibles públicamente para cualquiera que conozca su URL.

Usa páginas ocultas para contenido que quieras que esté accesible en tu sitio o que sirva como contexto para herramientas de IA, pero que no pueda descubrirse a través de la navegación.

Para el contenido que requiere un control de acceso estricto, debes configurar la [autenticación](/es/deploy/authentication-setup).

Para restringir páginas a grupos específicos de usuarios, configura el [control de acceso basado en grupos](/es/deploy/authentication-setup#control-access-with-groups).

<div id="hiding-a-page">
  ## Ocultar una página
</div>

Para ocultar una página, elimínala de tu estructura de navegación. Todas las páginas que no estén incluidas en la navegación de tu `docs.json` quedarán ocultas.

Las páginas ocultas usan la misma estructura de URL que las páginas normales, según la ruta del archivo. Por ejemplo, `guides/hidden-page.mdx` sería accesible en `docs.yoursite.com/guides/hidden-page`.

Consulta un [ejemplo de página oculta](/es/organize/hidden-page-example).

<Note>
  Algunos elementos de navegación, como barras laterales, menús desplegables y pestañas, pueden aparecer vacíos o alterar el diseño en las páginas ocultas.
</Note>

<div id="hiding-a-group-of-pages">
  ## Ocultar un grupo de páginas
</div>

Un grupo de páginas se oculta cuando la propiedad `hidden` se establece en `true` en tu archivo `docs.json`:

```json highlight={4}
"groups": [
  {
    "group": "Getting started",
    "hidden": true,
    "pages": [
      "index",
      "quickstart"
    ]
  },
  {
    "group": "Guides",
    "pages": [
      "guides/hidden-page.mdx",
      "guides/hidden-groups.mdx"
    ]
  }
]
```

En este ejemplo, el grupo `Getting started` está oculto, pero el grupo `Guides` se muestra.

<div id="hiding-a-tab">
  ### Ocultar una pestaña
</div>

También puedes ocultar una pestaña añadiendo la propiedad `hidden` a tu archivo `docs.json`:

```json highlight={4}
"tabs": [
  {
    "tab": "Home",
    "hidden": true,
    "pages": [
      "index",
      "quickstart"
    ]
  }
]
```

<div id="search-seo-and-ai-indexing">
  ## Búsqueda, SEO e indexación con IA
</div>

De forma predeterminada, las páginas ocultas se excluyen de la indexación en los motores de búsqueda, de la búsqueda interna de tu documentación y del contexto del asistente de IA. Para incluir páginas ocultas en los resultados de búsqueda y como contexto para el asistente, agrega la propiedad `seo` a tu `docs.json`:

```json
"seo": {
    "indexing": "all"
}
```

Para excluir una página específica, añade `noindex: true` a su frontmatter.
