---
title: "Páginas ocultas"
description: "Oculta páginas de la navegación manteniéndolas accesibles."
keywords: ["ocultar de la navegación", "no listada", "visibilidad de la página"]
---

Las páginas ocultas no se incluyen en la navegación de tu sitio, pero siguen siendo públicamente accesibles para cualquiera que conozca su URL.

Usa páginas ocultas para contenido que quieras que sea accesible en tu sitio o que se utilice como contexto para herramientas de IA, pero que no sea localizable a través de la navegación.

Para contenido que requiera un control de acceso estricto, debes configurar la [autenticación](/es/deploy/authentication-setup).

Para restringir páginas a grupos específicos de usuarios, configura el [control de acceso basado en grupos](/es/deploy/authentication-setup#control-access-with-groups).

<div id="hiding-a-page">
  ## Ocultar una página
</div>

Para ocultar una página, elimínala de tu estructura de navegación. Cualquier página que no esté incluida en la navegación de tu `docs.json` quedará oculta.

Las páginas ocultas usan la misma estructura de URL que las páginas normales, a partir de su ruta de archivo. Por ejemplo, `guides/hidden-page.mdx` sería accesible en `docs.yoursite.com/guides/hidden-page`.

Consulta un [ejemplo de página oculta](/es/organize/hidden-page-example).

<Note>
  Algunos elementos de navegación como barras laterales, menús desplegables y pestañas pueden aparecer vacíos o modificar su distribución en las páginas ocultas.
</Note>

<div id="hiding-a-group-of-pages">
  ## Ocultar un grupo de páginas
</div>

Un grupo de páginas queda oculto si la propiedad `hidden` se establece en `true` en tu archivo `docs.json`:

```json highlight={4}
"groups": [
  {
    "group": "Getting started",
    "hidden": true,
    "pages": [
      "index",
      "quickstart"
    ]
  },
  {
    "group": "Guides",
    "pages": [
      "guides/hidden-page.mdx",
      "guides/hidden-groups.mdx"
    ]
  }
]
```

En este ejemplo, el grupo `Getting started` está oculto, pero el grupo `Guides` está visible.

<div id="hiding-a-tab">
  ### Ocultar una pestaña
</div>

También puedes ocultar una pestaña añadiendo la propiedad `hidden` al archivo `docs.json`:

```json highlight={4}
"tabs": [
  {
    "tab": "Home",
    "hidden": true,
    "pages": [
      "index",
      "quickstart"
    ]
  }
]
```

<div id="search-seo-and-ai-indexing">
  ## Búsqueda, SEO e indexación con IA
</div>

De forma predeterminada, las páginas ocultas se excluyen de la indexación para los motores de búsqueda, la búsqueda interna de tu documentación y como contexto para el asistente de IA. Para incluir páginas ocultas en los resultados de búsqueda y como contexto para el asistente, agrega la propiedad `seo` a tu `docs.json`:

```json
"seo": {
    "indexing": "all"
}
```

Para excluir una página específica, añade `noindex: true` al frontmatter de esa página.
