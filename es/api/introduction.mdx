La API REST de Mintlify te permite interactuar mediante programación con tu documentación, lanzar actualizaciones, integrar experiencias de chat impulsadas por IA y exportar datos de analítica.

<div id="endpoints">
  ## Endpoints
</div>

* [Trigger update](/es/api/update/trigger): Activa una actualización de tu sitio cuando lo desees.
* [Get update status](/es/api/update/status): Consulta el estado de una actualización y otros detalles sobre tu documentación.
* [Create agent job](/es/api/agent/create-agent-job): Crea una tarea de agente para editar tu documentación automáticamente.
* [Get agent job](/es/api/agent/get-agent-job): Obtén los detalles y el estado de una tarea de agente específica.
* [Get all agent jobs](/es/api/agent/get-all-jobs): Obtén todas las tareas de agente de un dominio.
* [Generate assistant message](/es/api/assistant/create-assistant-message): Integra el asistente, entrenado a partir de tu documentación, en cualquier aplicación que elijas.
* [Search documentation](/es/api/assistant/search): Busca en tu documentación.
* [Get user feedback](/es/api/analytics/feedback): Exporta los comentarios de los usuarios sobre tu documentación.
* [Get assistant conversations](/es/api/analytics/assistant-conversations): Exporta el historial de conversaciones del asistente de IA.

<div id="common-use-cases">
  ### Casos de uso comunes
</div>

* **Implementaciones automatizadas**: Activa actualizaciones del sitio a intervalos definidos o cuando se produzcan eventos con [Trigger update](/es/api/update/trigger) y [Get update status](/es/api/update/status).
* **Integración CI/CD**: Actualiza la documentación como parte de tu pipeline de despliegue cuando haya cambios en el código con [Trigger update](/es/api/update/trigger).
* **Integraciones personalizadas**: Integra el asistente de IA en tu producto, portal de soporte o herramientas internas con [Generate assistant message](/es/api/assistant/create-assistant-message) y [Search documentation](/es/api/assistant/search).
* **Edición automatizada**: Usa trabajos de agente para actualizar la documentación de forma programática y a gran escala con [Create agent job](/es/api/agent/create-agent-job), [Get agent job](/es/api/agent/get-agent-job) y [Get all agent jobs](/es/api/agent/get-all-jobs).
* **Exportación de analíticas**: Exporta comentarios y conversaciones del asistente para su análisis externo con [Get user feedback](/es/api/analytics/feedback) y [Get assistant conversations](/es/api/analytics/assistant-conversations).

<div id="authentication">
  ## Autenticación
</div>

Genera claves de API en la [página de claves de API](https://dashboard.mintlify.com/settings/organization/api-keys) de tu panel de control. Cada clave de API pertenece a una organización; puedes usar claves en múltiples despliegues dentro de esa misma organización.

Puedes crear hasta 10 claves de API por hora y por organización.

<div id="admin-api-key">
  ### Clave de API de administrador
</div>

Usa la clave de API de administrador para autenticar las solicitudes a [Trigger update](/es/api/update/trigger), [Get update status](/es/api/update/status), [Create agent job](/es/api/agent/create-agent-job), [Get agent job](/es/api/agent/get-agent-job), [Get all agent jobs](/es/api/agent/get-all-jobs), [Get user feedback](/es/api/analytics/feedback) y [Get assistant conversations](/es/api/analytics/assistant-conversations).

Las claves de API de administrador comienzan con el prefijo `mint_`.

La clave de API de administrador es un secreto del lado del servidor. No la expongas en el código del lado del cliente.

<div id="assistant-api-key">
  ### Clave de API del asistente
</div>

Usa la clave de API del asistente para autenticar solicitudes a los endpoints [Generate assistant message](/es/api/assistant/create-assistant-message) y [Search documentation](/es/api/assistant/search).

Las claves de API del asistente comienzan con el prefijo `mint_dsc_`.

La clave de API del asistente es un token público que puedes utilizar en el código de frontend.

<Note>
  Las llamadas que usan el token de API del asistente pueden generar costos: ya sea consumiendo tus créditos de asistente o generando cargos adicionales.
</Note>
