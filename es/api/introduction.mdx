La API REST de Mintlify te permite interactuar con tu documentación de forma programática, iniciar actualizaciones, integrar experiencias de chat con IA y exportar datos analíticos.

<div id="endpoints">
  ## Endpoints
</div>

* [Iniciar actualización](/es/api/update/trigger): Inicia una actualización de tu sitio cuando lo desees.
* [Obtener el estado de la actualización](/es/api/update/status): Obtén el estado de una actualización y otros detalles sobre tu documentación.
* [Crear agent job](/es/api/agent/create-agent-job): Crea un agent job para editar automáticamente tu documentación.
* [Obtener agent job](/es/api/agent/get-agent-job): Obtén los detalles y el estado de un agent job específico.
* [Obtener todos los agent jobs](/es/api/agent/get-all-jobs): Obtén todos los agent jobs de un dominio.
* [Generar mensaje del asistente](/es/api/assistant/create-assistant-message): Integra el asistente, entrenado con tu documentación, en cualquier aplicación que elijas.
* [Buscar en la documentación](/es/api/assistant/search): Busca en tu documentación.
* [Obtener comentarios de los usuarios](/es/api/analytics/feedback): Exporta los comentarios de los usuarios sobre tu documentación.
* [Obtener conversaciones del asistente](/es/api/analytics/assistant-conversations): Exporta el historial de conversaciones del asistente de IA.

<div id="common-use-cases">
  ### Casos de uso comunes
</div>

* **Despliegues automatizados**: Inicia actualizaciones del sitio a intervalos definidos o cuando se produzcan eventos con [Iniciar actualización](/es/api/update/trigger) y [Obtener el estado de la actualización](/es/api/update/status).
* **Integración de CI/CD**: Actualiza la documentación como parte de tu pipeline de despliegue cuando cambie el código con [Iniciar actualización](/es/api/update/trigger).
* **Integraciones personalizadas**: Integra el asistente de IA en tu producto, portal de soporte o herramientas internas con [Generar mensaje del asistente](/es/api/assistant/create-assistant-message) y [Buscar en la documentación](/es/api/assistant/search).
* **Edición automatizada**: Usa agent jobs para actualizar la documentación mediante programación y a gran escala con [Crear agent job](/es/api/agent/create-agent-job), [Obtener agent job](/es/api/agent/get-agent-job) y [Obtener todos los agent jobs](/es/api/agent/get-all-jobs).
* **Exportación de análisis**: Exporta comentarios de usuarios y conversaciones del asistente para realizar análisis externos con [Obtener comentario de los usuarios](/es/api/analytics/feedback) y [Obtener conversaciones del asistente](/es/api/analytics/assistant-conversations).

<div id="authentication">
  ## Autenticación
</div>

Genera claves de API en la [página de claves de API](https://dashboard.mintlify.com/settings/organization/api-keys) de tu panel de control. Cada clave de API pertenece a una organización; puedes usar claves en varios despliegues dentro de la misma organización.

Puedes crear hasta 10 claves de API por hora y por organización.

<div id="admin-api-key">
  ### Clave de API de administrador
</div>

Usa la clave de API de administrador para autenticar las solicitudes a [Iniciar actualización](/es/api/update/trigger), [Obtener el estado de la actualización](/es/api/update/status), [Crear un agent job](/es/api/agent/create-agent-job), [Obtener un agent job](/es/api/agent/get-agent-job), [Obtener todos los agent jobs](/es/api/agent/get-all-jobs), [Obtener comentarios de los usuarios](/es/api/analytics/feedback) y [Obtener conversaciones del asistente](/es/api/analytics/assistant-conversations).

Las claves de API de administrador comienzan con el prefijo `mint_`.

La clave de API de administrador es un secreto del servidor. No la expongas en el código del cliente.

<div id="assistant-api-key">
  ### Clave de API del asistente
</div>

Usa la clave de API del asistente para autenticar las solicitudes a los endpoints [Generar mensaje del asistente](/es/api/assistant/create-assistant-message) y [Buscar en la documentación](/es/api/assistant/search).

Las claves de API del asistente comienzan con el prefijo `mint_dsc_`.

La clave de API del asistente es un token público que puedes usar en el código del frontend.

<Note>
  Las llamadas que usan el token de API del asistente pueden generar costos, ya sea consumiendo tus créditos del asistente o generando cargos por excedente.
</Note>
