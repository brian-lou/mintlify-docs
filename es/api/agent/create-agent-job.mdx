Este endpoint crea una tarea de agente a partir de los mensajes proporcionados y la información de la rama. La tarea se ejecuta de forma asíncrona y devuelve una respuesta en streaming con los detalles de la ejecución y los resultados.

Si una rama no existe, el agente crea una. Si los archivos se editan correctamente, se crea automáticamente una pull request al final de la tarea.

<div id="rate-limits">
  ## Límites de uso
</div>

La API de agentes tiene los siguientes límites:

- Hasta 100 solicitudes por proyecto de Mintlify por hora

<div id="suggested-usage">
  ## Uso recomendado
</div>

Para obtener los mejores resultados, utiliza el [hook useChat de ai-sdk](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat#usechat) para enviar peticiones y gestionar las respuestas.
