<div id="usage">
  ## Uso
</div>

Este endpoint recupera todos los trabajos del agente del dominio especificado y ofrece una visión general de todas las actividades del agente y de su estado actual. Resulta útil para supervisar y gestionar varios trabajos del agente, tanto simultáneos como históricos.

<div id="response">
  ## Respuesta
</div>

Usa este endpoint para obtener una visión completa de todas las sesiones anteriores del agente.
