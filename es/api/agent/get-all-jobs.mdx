<div id="usage">
  ## Uso
</div>

Este endpoint recupera todos los trabajos de agente del dominio especificado y ofrece una vista general de todas las actividades de los agentes y su estado actual. Esto es útil para supervisar y gestionar múltiples trabajos de agente, ya sean concurrentes o históricos.

<div id="response">
  ## Respuesta
</div>

Utilice este endpoint para obtener una visión completa de todas las sesiones anteriores del agente.
