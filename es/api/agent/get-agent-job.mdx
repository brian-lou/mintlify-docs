<div id="usage">
  ## Uso
</div>

Este endpoint obtiene los detalles y el estado de un trabajo de agente específico por su identificador único. Úsalo para verificar el progreso, el estado y los resultados de un trabajo de agente creado anteriormente.

<div id="job-details">
  ## Detalles del trabajo
</div>

La respuesta incluye información como:

- Estado de ejecución y de finalización del trabajo
- Información de la rama y detalles del pull request
- Metadatos de la sesión y marcas de tiempo
