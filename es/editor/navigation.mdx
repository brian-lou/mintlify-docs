Usa la barra lateral de navegación para organizar tu documentación. Los cambios que hagas en el árbol de navegación del editor web aparecerán en la barra lateral de navegación de tu sitio y se sincronizarán con tu archivo de configuración `docs.json`.

<div id="add-navigation-elements">
  ## Agregar elementos de navegación
</div>

Para agregar un nuevo elemento de navegación, haz clic en **Add new** en la parte inferior del árbol de navegación.

<Frame>
  <img src="/images/editor/navigation-light.png" alt="Agregar un nuevo elemento de navegación." className="block dark:hidden" />

  <img src="/images/editor/navigation-dark.png" alt="Agregar un nuevo elemento de navegación." className="hidden dark:block" />
</Frame>

Para agregar un elemento de navegación anidado dentro de otro elemento, haz clic en el botón **+** junto al nombre del elemento principal.

Después de crear un elemento, arrástralo y suéltalo para reordenarlo o anidarlo dentro de otros elementos. Haz clic con el botón derecho en cualquier elemento para configurar sus propiedades, duplicarlo, ocultarlo de la navegación o eliminarlo.

<Note>
  Algunos elementos no se pueden anidar dentro de otros elementos. Por ejemplo, las pestañas no se pueden anidar dentro de grupos. El editor web impide que anides elementos no válidos.
</Note>

<div id="add-existing-files">
  ### Agregar archivos existentes
</div>

Agrega archivos de tu repositorio que aún no están en la navegación.

1. Haz clic en el botón con el signo más, <Icon icon="plus" />, donde quieras agregar el archivo.
2. Haz clic en **Agregar archivo existente**.

<div id="organize-into-sections">
  ## Organiza en secciones
</div>

Elige la estructura de navegación adecuada al alcance y al público de tu documentación.

<div id="when-to-use-pages">
  ### Cuándo usar páginas
</div>

Usa páginas para archivos de documentación individuales. Las páginas son los elementos básicos de tu navegación: todo el contenido vive en una página. Agrega páginas a tu navegación para que sean visibles en la barra lateral de tu sitio.

Las páginas pueden existir en el nivel principal, dentro de grupos, pestañas, anclas, menús desplegables o menús.

Los archivos que no se incluyen en tu navegación quedan [ocultos](/es/organize/hidden-pages) en tu documentación publicada.

<div id="when-to-use-groups">
  ### Cuándo usar grupos
</div>

Usa grupos para organizar páginas relacionadas en secciones plegables. Los grupos ayudan a los usuarios a explorar la navegación al agrupar contenido similar, como reunir todas las páginas relacionadas con la autenticación o todas las referencias de endpoints de la API.

Los grupos se pueden anidar dentro de otros grupos para crear una organización jerárquica. Los grupos pueden existir dentro de pestañas, anclas, menús desplegables o en el nivel raíz.

<div id="when-to-use-tabs">
  ### Cuándo usar pestañas
</div>

Usa pestañas para crear secciones de primer nivel separadas con navegación horizontal en la parte superior de tu sitio. Las pestañas funcionan bien cuando tienes áreas diferenciadas como API Reference, Guides y SDKs entre las que los usuarios necesitan alternar.

Las pestañas pueden contener páginas, grupos y elementos de menú. Configura las pestañas para añadir iconos o enlazarlas a recursos externos.

<div id="when-to-use-anchors">
  ### Cuándo usar anclas
</div>

Usa anclas para crear elementos de navegación persistentes en la parte superior de la barra lateral. Las anclas son útiles cuando quieres dividir tu contenido en secciones o proporcionar acceso rápido a recursos externos sin cambiar de pestaña.

Las anclas pueden contener páginas y grupos, o enlazar a URL externas.

**Anclas globales:**

Crea anclas globales que aparezcan en todas las páginas, sin importar qué sección estén viendo los usuarios. Las anclas globales deben enlazar a URL externas y son útiles para recursos como blogs, páginas de estado o enlaces de soporte.

<div id="when-to-use-dropdowns">
  ### Cuándo usar menús desplegables
</div>

Usa menús desplegables para crear un menú desplegable en la parte superior de tu barra lateral. Los menús desplegables funcionan bien cuando tienes múltiples secciones relacionadas que los usuarios quizá quieran explorar, pero que no necesitan estar siempre visibles como las pestañas.

Los menús desplegables pueden contener páginas y grupos, o enlazar a URL externas.

<div id="when-to-use-menus">
  ### Cuándo usar los menús
</div>

Usa menús para agregar opciones de navegación desplegables dentro de una pestaña. Los menús ayudan a los usuarios a ir directamente a páginas específicas desde la barra de navegación superior.

Los menús pueden contener páginas y grupos.

<div id="when-to-use-products">
  ### Cuándo usar productos
</div>

Usa productos cuando cuentes con varias ofertas de productos diferenciadas, cada una de las cuales necesite su propia documentación. Los productos crean un menú de selección que permite a los usuarios navegar entre diferentes conjuntos de documentación de productos.

Cada producto puede tener su propia estructura de navegación con pestañas, páginas y grupos.

<div id="when-to-use-versions">
  ### Cuándo usar versiones
</div>

Usa versiones cuando mantienes varias versiones de tu documentación al mismo tiempo, como v1.0, v2.0 y v3.0 de una API. Las versiones crean un menú desplegable que permite a los usuarios seleccionar qué versión quieren ver.

Cada versión puede tener contenido y una estructura de navegación diferentes.

<div id="when-to-use-languages">
  ### Cuándo usar idiomas
</div>

Usa idiomas cuando ofrezcas documentación en varios idiomas. Los idiomas crean un menú de selección que permite a los usuarios ver la documentación en su idioma preferido.

Cada idioma mantiene la misma estructura de navegación con el contenido traducido.

<div id="customize-appearance">
  ## Personalizar la apariencia
</div>

**Agregar iconos:**

1. Haz clic con el botón derecho en un elemento de navegación.
2. Haz clic en **Configurar**.
3. Haz clic en el campo de icono.

**Agregar etiquetas:**

1. Haz clic con el botón derecho en un elemento de navegación.
2. Haz clic en **Configurar**.
3. Haz clic en el campo de etiqueta.
4. Escribe una etiqueta como &quot;NEW&quot; o &quot;BETA&quot; para resaltar elementos importantes.

**Controlar la visibilidad:**

Oculta el contenido de un elemento de navegación sin eliminarlo de tu repositorio.

1. Haz clic con el botón derecho en cualquier elemento.
2. Haz clic en el interruptor junto a la opción **Ocultar**.
