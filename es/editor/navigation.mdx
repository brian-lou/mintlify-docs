Usa la barra lateral de navegación para organizar tu documentación. Los cambios que hagas en el árbol de navegación del editor web se reflejarán en la barra lateral de navegación de tu sitio y se sincronizarán con tu archivo de configuración `docs.json`.

<div id="add-navigation-elements">
  ## Agregar elementos de navegación
</div>

Para agregar un nuevo elemento de navegación, haz clic en **Add new** al final del árbol de navegación.

<Frame>
  <img src="/images/editor/navigation-light.png" alt="Agregar un nuevo elemento de navegación." className="block dark:hidden" />

  <img src="/images/editor/navigation-dark.png" alt="Agregar un nuevo elemento de navegación." className="hidden dark:block" />
</Frame>

Para agregar un elemento de navegación dentro de otro, haz clic en el botón **+** junto al nombre del elemento principal.

Después de crear un elemento, arrástralo y suéltalo para reordenarlo o colocarlo dentro de otros elementos. Haz clic con el botón derecho en cualquier elemento para configurar sus propiedades, duplicarlo, ocultarlo de la navegación o eliminarlo.

<Note>
  Algunos elementos no pueden colocarse dentro de otros. Por ejemplo, las pestañas no pueden colocarse dentro de grupos. El editor web evita que coloques elementos no válidos.
</Note>

<div id="add-existing-files">
  ### Agregar archivos existentes
</div>

Agrega archivos de tu repositorio que todavía no aparezcan en la navegación.

1. Haz clic en el botón con el signo más, <Icon icon="plus" />, donde quieras agregar el archivo.
2. Haz clic en **Agregar archivo existente**.

<div id="organize-into-sections">
  ## Organiza por secciones
</div>

Elige la estructura de navegación adecuada según el alcance y la audiencia de tu documentación.

<div id="when-to-use-pages">
  ### Cuándo usar páginas
</div>

Usa páginas para archivos de documentación individuales. Las páginas son los elementos básicos de tu navegación: todo el contenido está en una página. Agrega páginas a tu navegación para que se muestren en la barra lateral de tu sitio.

Las páginas pueden existir en el nivel raíz, dentro de grupos, pestañas, anclas, menús desplegables o menús.

Los archivos que no se incluyan en tu navegación estarán [ocultos](/es/organize/hidden-pages) en tu documentación publicada.

<div id="when-to-use-groups">
  ### Cuándo usar grupos
</div>

Usa grupos para organizar páginas relacionadas en secciones plegables. Los grupos ayudan a los usuarios a explorar la navegación al agrupar contenido similar, como todas las páginas relacionadas con la autenticación o todas las referencias de endpoints de la API.

Los grupos pueden anidarse dentro de otros grupos para crear una organización jerárquica. Los grupos pueden estar dentro de pestañas, anclas, menús desplegables o en el nivel raíz.

<div id="when-to-use-tabs">
  ### Cuándo usar pestañas
</div>

Usa pestañas para crear secciones principales independientes con navegación horizontal en la parte superior de tu sitio. Las pestañas funcionan bien cuando tienes áreas diferenciadas, como Referencia de la API, Guías y SDK, entre las que los usuarios necesitan cambiar.

Las pestañas pueden contener páginas, grupos y elementos de menú. Configúralas para añadir iconos o enlazar recursos externos.

<div id="when-to-use-anchors">
  ### Cuándo usar anclas
</div>

Usa anclas para crear elementos de navegación permanentes en la parte superior de tu barra lateral. Las anclas son útiles cuando quieres organizar tu contenido en secciones o proporcionar acceso rápido a recursos externos sin cambiar de pestaña.

Las anclas pueden contener páginas y grupos, o enlazar a URL externas.

**Anclas globales:**

Crea anclas globales que aparezcan en todas las páginas, independientemente de la sección que estén viendo los usuarios. Las anclas globales deben enlazar a URL externas y resultan útiles para recursos como blogs, páginas de estado o enlaces de soporte.

<div id="when-to-use-dropdowns">
  ### Cuándo usar menús desplegables
</div>

Usa menús desplegables para crear un menú expandible en la parte superior de la barra lateral. Funcionan bien cuando tienes varias secciones relacionadas que los usuarios pueden querer explorar, pero que no necesitan estar siempre visibles como las pestañas.

Los menús desplegables pueden contener páginas y grupos, o enlazar a URL externas.

<div id="when-to-use-menus">
  ### Cuándo usar menús
</div>

Usa menús para añadir elementos desplegables de navegación dentro de una pestaña. Los menús ayudan a los usuarios a ir directamente a páginas específicas desde la barra de navegación superior.

Los menús pueden contener páginas y grupos.

<div id="when-to-use-products">
  ### Cuándo usar productos
</div>

Usa productos cuando tengas varias ofertas de producto diferenciadas y cada una necesite su propia documentación. Los productos crean un menú selector que permite a los usuarios navegar entre distintos conjuntos de documentación.

Cada producto puede tener su propia estructura de navegación con pestañas, páginas y grupos.

<div id="when-to-use-versions">
  ### Cuándo usar versiones
</div>

Usa versiones cuando mantienes varias versiones de tu documentación al mismo tiempo, como la v1.0, la v2.0 y la v3.0 de una API. Las versiones crean un menú selector que permite a los usuarios elegir qué versión quieren consultar.

Cada versión puede tener contenido y una estructura de navegación diferentes.

<div id="when-to-use-languages">
  ### Cuándo usar idiomas
</div>

Usa idiomas cuando ofrezcas documentación en varios idiomas. Esto crea un menú selector que permite a los usuarios ver la documentación en el idioma de su preferencia.

Cada idioma mantiene la misma estructura de navegación con el contenido traducido.

<div id="customize-appearance">
  ## Personaliza la apariencia
</div>

**Añade iconos:**

1. Haz clic derecho en un elemento de navegación.
2. Haz clic en **Configure**.
3. Haz clic en el campo del icono.

**Añade etiquetas:**

1. Haz clic derecho en un elemento de navegación.
2. Haz clic en **Configure**.
3. Haz clic en el campo de la etiqueta.
4. Introduce una etiqueta como &quot;NEW&quot; o &quot;BETA&quot; para destacar elementos importantes.

**Controla la visibilidad:**

Oculta el contenido de un elemento de navegación sin eliminarlo de tu repositorio.

1. Haz clic derecho en cualquier elemento.
2. Haz clic en el interruptor junto a la etiqueta **Hide**.
