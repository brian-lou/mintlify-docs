<div id="open-the-agent-panel">
  ## Abrir el panel del agente
</div>

En computadoras de escritorio, puedes cambiar el tamaño del panel del agente. En dispositivos móviles, el agente se abre en pantalla completa.

Para abrir el panel del agente:

- Desde cualquier página del panel de control, usa la combinación de teclas <kbd>⌘</kbd>+<kbd>I</kbd> (macOS) o <kbd>Ctrl</kbd>+<kbd>I</kbd> (Windows/Linux).
- En la página [Overview](https://dashboard.mintlify.com/), haz clic en **Ask agent**.

  ### Vistas del panel del agente

- **Chat**: Haz clic en el ícono de más, <Icon icon="plus" />, para iniciar un nuevo chat. En la vista de chat, envía instrucciones al agente para actualizar tu documentación o hacer preguntas sobre ella. El agente crea pull requests según tus instrucciones y muestra enlaces para ver los pull requests o abrir los cambios en el editor web.
- **Suggestions**: Si está habilitado, el panel de sugerencias muestra actualizaciones sugeridas para tu documentación a partir de los cambios en los pull requests y de las conversaciones de los usuarios con el asistente.
- **History**: Haz clic en el ícono de historial, <Icon icon="clock" />, para explorar conversaciones anteriores y continuar trabajando en solicitudes previas. Haz clic en cualquier conversación para cargarla en la vista de chat.
- **Settings**: Haz clic en el ícono de configuración, <Icon icon="settings" />, para configurar las integraciones del agente y el acceso al repositorio.

<Tip>
  Inicia una nueva conversación con el agente para cada tarea. Esto mantiene centrado el contexto del agente y te ayuda a asociar las conversaciones con proyectos específicos.
</Tip>

<div id="connect-your-github-account">
  ## Conecta tu cuenta de GitHub
</div>

Por defecto, el agente abre pull requests atribuidos al bot de Mintlify. Para que los pull requests aparezcan a tu nombre, conecta tu cuenta de GitHub en la página de [Mi perfil](https://dashboard.mintlify.com/settings/account) del panel de control.

<div id="connect-repositories-as-context">
  ## Conecta repositorios como contexto
</div>

El agente solo puede acceder a los repositorios que conectes mediante la aplicación de GitHub de Mintlify. Configura a qué repositorios puede acceder el agente en **Settings** del panel del agente o en la [configuración de la aplicación de GitHub](https://github.com/apps/mintlify/installations/new).
