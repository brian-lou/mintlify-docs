<div id="open-the-agent-panel">
  ## Abre el panel del agente
</div>

En computadoras de escritorio, el panel del agente puede redimensionarse. En dispositivos móviles, el agente se abre en pantalla completa.

Para abrir el panel del agente:

* Desde cualquier página de tu panel de control, usa el atajo de teclado <kbd>⌘</kbd>+<kbd>I</kbd> (macOS) o <kbd>Ctrl</kbd>+<kbd>I</kbd> (Windows/Linux).
* En la página [Overview](https://dashboard.mintlify.com/), haz clic en **Ask agent**.

* **Chat**: Haz clic en el icono de más, <Icon icon="plus" />, para iniciar un nuevo chat. En la vista de chat, envía prompts al agente para actualizar tu documentación o hacer preguntas sobre ella. El agente crea pull requests según tus instrucciones y muestra enlaces para verlos o abrir los cambios en el editor web.
* **Suggestions**: Si está habilitado, el panel de sugerencias muestra actualizaciones sugeridas para tu documentación en función de los cambios en los pull requests y de las conversaciones de los usuarios con el asistente.
* **History**: Haz clic en el icono del historial, <Icon icon="clock" />, para explorar conversaciones anteriores y seguir trabajando en peticiones previas. Haz clic en cualquier conversación para cargarla en la vista de chat.
* **Settings**: Haz clic en el icono de configuración, <Icon icon="settings" />, para configurar las integraciones del agente y el acceso al repositorio.

<Tip>
  Inicia una nueva conversación con el agente para cada tarea. Esto mantiene el contexto del agente enfocado y te ayuda a asociar las conversaciones con proyectos específicos.
</Tip>

<div id="connect-your-github-account">
  ## Conecta tu cuenta de GitHub
</div>

Por defecto, el agente crea pull requests atribuidos al bot de Mintlify. Para que los pull requests se te atribuyan a ti, conecta tu cuenta de GitHub en la página [Mi perfil](https://dashboard.mintlify.com/settings/account) del panel de control.

<div id="connect-repositories-as-context">
  ## Conecta repositorios para usarlos como contexto
</div>

El agente solo puede acceder a los repositorios que conectes mediante la GitHub App de Mintlify. Configura a qué repositorios puede acceder el agente en **Settings** del panel del agente o en la [configuración de la GitHub App](https://github.com/apps/mintlify/installations/new).
