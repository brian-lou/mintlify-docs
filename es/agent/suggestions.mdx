Puedes permitir que el agente sugiera actualizaciones de la documentación a partir de dos fuentes.

* **Cambios en pull requests**: Supervisa los repositorios de Git seleccionados para detectar cambios en el código que requieran actualizaciones en la documentación.
* **Conversaciones con el asistente**: Analiza las preguntas que los usuarios hacen al asistente en tu sitio de documentación para identificar lagunas de contenido.

Cuando el agente identifica posibles actualizaciones de la documentación, crea una sugerencia en tu panel con el contexto necesario para crear un pull request.

Usa las sugerencias para mantener tu documentación actualizada de forma proactiva cuando se lancen nuevas funciones o para abordar preguntas habituales de los usuarios.

<div id="prerequisites">
  ## Requisitos previos
</div>

Antes de usar las sugerencias, debes instalar la [Mintlify GitHub App](/es/deploy/github) en tu organización. La aplicación debe tener acceso a tu repositorio de documentación y, como mínimo, a otro repositorio donde los cambios en el código requieran actualizar la documentación.

<div id="configure-suggestions">
  ## Configurar sugerencias
</div>

Configura qué repositorios supervisa el agente y cómo quieres recibir las notificaciones en la configuración del agente. La página de configuración muestra todas las organizaciones y los repositorios de GitHub que el agente supervisa.

Para acceder a la configuración del agente:

1. Haz clic en el botón **Ask agent** de tu panel para abrir el panel del agente.
2. Haz clic en el botón **Settings**.

<div id="monitor-repositories">
  ### Monitorizar repositorios
</div>

El agente supervisa todas las pull requests fusionadas de cada repositorio que habilites, independientemente de la rama en la que se fusionen. Una comprobación de GitHub llamada **Mintlify Autopilot** se ejecuta en las pull requests de los repositorios supervisados para analizarlas en busca de posibles actualizaciones de la documentación. Cuando fusionas una pull request que requiere actualizaciones de la documentación, el agente crea una sugerencia en tu panel.

<Note>
  Cuando habilitas la supervisión de un repositorio por primera vez, el agente crea sugerencias para las pull requests fusionadas en los últimos siete días. Este proceso retroactivo solo se produce si aún no existen sugerencias para ese repositorio. Es posible que veas varias sugerencias inmediatamente después de habilitar la supervisión.
</Note>

Si deshabilitas la supervisión, el agente deja de supervisar el repositorio de inmediato. Las sugerencias existentes para ese repositorio permanecen en tu panel hasta que las descartes.

<div id="conversation-insights">
  ### Análisis de conversaciones
</div>

Si tienes acceso al agente y al asistente, el agente crea sugerencias a partir de las conversaciones que tus usuarios mantienen con el asistente.

El agente analiza periódicamente las conversaciones con el asistente y crea sugerencias cuando identifica patrones de preguntas que indican que la documentación falta o no es lo suficientemente clara.

<div id="notifications">
  ### Notificaciones
</div>

Las sugerencias del agente siempre aparecen en tu panel. Puedes configurar las notificaciones para recibir correos electrónicos o mensajes directos de Slack cuando el agente cree nuevas sugerencias.

<Tip>
  Si no recibes notificaciones por correo electrónico sobre las sugerencias, revisa tu carpeta de spam y añade la dirección de correo `notifications@mintlify.com` a tu lista de remitentes seguros.
</Tip>

<div id="review-suggestions">
  ## Revisa las sugerencias
</div>

El agente crea sugerencias en tu panel. Cada sugerencia muestra la pull request o el tema de la conversación con el asistente que la originó, la fecha de creación y las actualizaciones de documentación propuestas.

El botón **Ask agent** de tu panel muestra cuántas sugerencias están pendientes de tu revisión.

<div id="create-pull-requests">
  ### Crear pull requests
</div>

Agrega sugerencias como contexto para que el agente cree pull requests.

1. Haz clic en el botón **Ask agent** de tu panel para abrir el panel del agente.
2. Haz clic en **Add to chat**.
3. Envía la solicitud al agente para que abra un pull request.

<div id="dismiss-suggestions">
  ### Descartar sugerencias
</div>

Si una sugerencia no requiere actualizaciones en la documentación o ya has aplicado los cambios, descártala para eliminarla de tu panel.

1. Haz clic en el botón **Ask agent** de tu panel para abrir el panel del agente.
2. Haz clic en el botón **Descartar** junto a cualquier sugerencia que quieras descartar.

La sugerencia se elimina de inmediato de tu panel. No puedes recuperar las sugerencias descartadas.
