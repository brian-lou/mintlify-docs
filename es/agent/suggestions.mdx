Puedes permitir que el agente sugiera actualizaciones de documentación a partir de dos fuentes.

* **Cambios en pull requests**: Supervisa repositorios de Git seleccionados en busca de cambios en el código que requieran actualizaciones de la documentación.
* **Conversaciones con el asistente**: Analiza las preguntas que los usuarios le hacen al asistente en tu sitio de documentación para identificar lagunas de contenido.

Cuando el agente identifica posibles actualizaciones de documentación, crea una sugerencia en tu panel con el contexto necesario para crear una pull request.

Usa las sugerencias para mantener tu documentación actualizada de forma proactiva cuando se lancen nuevas funciones o para abordar preguntas frecuentes de los usuarios.

<div id="prerequisites">
  ## Requisitos previos
</div>

Antes de usar las sugerencias, debes instalar la [aplicación de GitHub de Mintlify](/es/deploy/github) en tu organización. La aplicación debe tener acceso a tu repositorio de documentación y al menos a otro repositorio donde los cambios de código requieran actualizaciones en la documentación.

<div id="configure-suggestions">
  ## Configurar sugerencias
</div>

Configura qué repositorios supervisa el agente y cómo recibes las notificaciones en la configuración del agente. La página de configuración muestra todas las organizaciones y repositorios de GitHub que el agente supervisa.

Para acceder a la configuración del agente:

1. Haz clic en el botón **Ask agent** en tu panel para abrir el panel del agente.
2. Haz clic en el botón **Settings**.

<div id="monitor-repositories">
  ### Supervisar repositorios
</div>

El agente supervisa todas las pull requests fusionadas de cada repositorio que habilites, sin importar en qué rama se fusionen. Una verificación de GitHub llamada **Mintlify Autopilot** se ejecuta en las pull requests de los repositorios supervisados para analizarlas en busca de posibles actualizaciones de la documentación. Cuando fusionas una pull request que requiere actualizaciones de documentación, el agente crea una sugerencia en tu panel de control.

<Note>
  Cuando habilitas por primera vez la supervisión de un repositorio, el agente crea sugerencias para las pull requests fusionadas en los últimos siete días. Este procesamiento retrospectivo solo se realiza si aún no existen sugerencias para ese repositorio. Es posible que veas varias sugerencias aparecer inmediatamente después de habilitar la supervisión.
</Note>

Si deshabilitas la supervisión, el agente deja de supervisar el repositorio de inmediato. Cualquier sugerencia existente para ese repositorio permanece en tu panel de control hasta que la descartes.

<div id="conversation-insights">
  ### Información sobre conversaciones
</div>

Si tienes acceso al agente y al asistente, el agente crea sugerencias a partir de las conversaciones que tus usuarios tienen con el asistente.

El agente analiza periódicamente las conversaciones del asistente y crea sugerencias cuando identifica patrones de preguntas que indican que falta documentación o que esta no es clara.

<div id="notifications">
  ### Notificaciones
</div>

Las sugerencias del agente siempre aparecen en tu panel. Puedes configurar las notificaciones para recibir correos electrónicos o mensajes directos en Slack cuando el agente cree nuevas sugerencias.

<Tip>
  Si no recibes notificaciones por correo electrónico sobre las sugerencias, revisa la carpeta de spam y agrega la dirección `notifications@mintlify.com` a tu lista de remitentes seguros.
</Tip>

<div id="review-suggestions">
  ## Revisar sugerencias
</div>

El agente crea sugerencias en tu panel de control. Cada sugerencia muestra la pull request o el tema de conversación con el asistente que activó la sugerencia, la fecha de creación y las actualizaciones de documentación propuestas.

El botón **Ask agent** en tu panel de control muestra el número de sugerencias que están pendientes de tu revisión.

<div id="create-pull-requests">
  ### Crear pull requests
</div>

Añade sugerencias como contexto para que el agente cree pull requests.

1. Haz clic en el botón **Ask agent** en tu panel para abrir el panel del agente.
2. Haz clic en **Add to chat**.
3. Envía el prompt al agente para abrir un pull request.

<div id="dismiss-suggestions">
  ### Descartar sugerencias
</div>

Si una sugerencia no requiere actualizar la documentación o ya has realizado los cambios, descártala para eliminarla de tu panel.

1. Haz clic en el botón **Ask agent** en tu panel para abrir el panel del agente.
2. Haz clic en el botón **Dismiss** junto a cualquier sugerencia que quieras descartar.

La sugerencia se elimina inmediatamente de tu panel. No es posible recuperar las sugerencias descartadas.
