El agente ayuda con muchas tareas de documentación. Estos flujos de trabajo muestran algunas formas de integrar el agente en tu proceso de documentación. Prueba un enfoque que se ajuste a la forma en que trabaja actualmente tu equipo y adáptalo a tus necesidades específicas.

<div id="iterate-on-a-prompt-in-a-slack-thread">
  ## Itera sobre un prompt en un hilo de Slack
</div>

Envía un prompt al agente y luego sigue mencionándolo con `@mintlify` en el mismo hilo para refinar y seguir iterando en la pull request que crea.

Por ejemplo: `@mintlify Nuestra página de inicio rápido necesita una nueva sección sobre cómo invitar a colaboradores`. Luego, `@mintlify La nueva sección debe llamarse "Invitar a colaboradores"`. Y después, cualquier otra iteración.

<div id="start-with-the-agent-finish-manually">
  ## Empieza con el agente y termina manualmente
</div>

Pídele al agente que inicie un proyecto y, después, pásate a la rama que cree para terminar la tarea en tu entorno local o en el editor web. El agente puede ayudarte a dar el primer paso y luego puedes encargarte de completar la tarea.

Por ejemplo: `@mintlify Update the quickstart page to include information about inviting collaborators` y luego pásate a la rama para hacer cualquier cambio adicional con el método que prefieras.

<div id="update-docs-when-merging-feature-changes">
  ## Actualiza la documentación al fusionar cambios de una funcionalidad
</div>

Cuando fusiones un pull request de una funcionalidad, comparte el enlace de la PR con el agente para actualizar la documentación correspondiente.

Por ejemplo: `@mintlify This PR adds a new authentication method. Update the docs to include the new auth flow: [PR link]`.

<div id="generate-release-notes-from-a-pull-request">
  ## Generar notas de la versión desde un pull request
</div>

Indica al agente un pull request específico para que genere notas de la versión o actualizaciones del registro de cambios en función del historial de commits.

Por ejemplo: `@mintlify Genera las notas de la versión para este PR: [enlace del PR]`.

<div id="generate-code-examples">
  ## Generar ejemplos de código
</div>

Pídele al agente que genere ejemplos de código para distintas funcionalidades de tu documentación o para páginas específicas.

Por ejemplo: `@mintlify Genera un ejemplo de código para que el método de autenticación sea más fácil de entender`.

<div id="review-existing-content">
  ## Revisa el contenido existente
</div>

Pídele al agente que revise el contenido existente para detectar problemas de precisión técnica, estilo, gramática u otros aspectos.

Por ejemplo: `@mintlify Review the API rate limiting section. We changed limits last month`.

<div id="respond-to-user-feedback">
  ## Responde a los comentarios de los usuarios
</div>

Dale al agente comentarios de tus usuarios para hacer actualizaciones específicas en tu documentación.

Por ejemplo: `@mintlify Users are getting confused by step 3 in the setup guide. What might be making it unclear?`.

<div id="automate-with-the-api">
  ## Automatiza con la API
</div>

Integra el agente en tus herramientas de automatización existentes para actualizar automáticamente la documentación cuando haya cambios en el código, activar revisiones de contenido o sincronizar actualizaciones de la documentación en varios repositorios.

Usa los endpoints del agente para [crear trabajos](/es/api-reference/agent/create-agent-job), [obtener un trabajo específico](/es/api-reference/agent/get-agent-job) y [obtener todos los trabajos](/es/api-reference/agent/get-all-jobs).

Al crear trabajos mediante la API, puedes controlar si las pull requests se abren en modo borrador con el parámetro `asDraft` (el valor predeterminado es `true`). Establece `asDraft: false` para crear pull requests que no estén en borrador y queden listas para revisión y fusión inmediatas en flujos de trabajo automatizados.

Aprende a configurar la automatización con la API en el tutorial [Actualiza automáticamente la documentación cuando se fusiona código](/es/guides/automate-agent).
