<Update label="6 de febrero de 2026" tags={["Nuevas versiones", "Mejoras"]} rss={{ title: "SSO de autoservicio, rol de solo lectura, selector de tráfico humano/IA y rediseño de los comandos con /" }}>
  ## Configuración de SSO de autoservicio

  Los clientes Enterprise ahora pueden configurar SSO con SAML (Okta o Microsoft Entra) directamente desde el panel de control, incluido el aprovisionamiento just-in-time (JIT), el cambio de proveedor y la eliminación de la conexión.

  ## Rol de solo lectura

  Nuevo rol de solo lectura con acceso a tu panel de control. Los usuarios con este rol pueden ver contenido en el editor, pero no pueden editarlo, invitar a miembros ni modificar configuraciones.

  ## Selector de tráfico humano/IA

  La página de Analytics ahora muestra pestañas separadas para el tráfico humano y el tráfico de IA.

  ## Rediseño del menú de comandos con /

  El menú de comandos con / del editor ahora incluye búsqueda al escribir, mejor navegación con teclado y otras mejoras de UX.

  ## Correcciones de errores

  * Se corrigió el desbordamiento de celdas en las tablas del panel de control.
  * Ahora, al renombrar archivos desde la hoja de configuración en el editor, los cambios se guardan correctamente.
  * Los errores de análisis de MDX, como una etiqueta `<Card>` sin cerrar, ahora se actualizan dinámicamente a medida que los corriges, en lugar de persistir incorrectamente entre recargas.
  * Los controles de arrastrar y soltar del editor ahora se alinean correctamente con distintos tipos de contenido, como encabezados o párrafos, con un tamaño uniforme y mejores áreas de interacción.
</Update>

<Update label="23 de enero de 2026" tags={["Novedades", "Mejoras"]} rss={{ title: "skill.md, registros de auditoría y exportación en Markdown" }}>
  ## Generación automática de `skill.md`

  Los sitios de documentación ahora generan automáticamente un archivo `skill.md` a partir de tus referencias de la API, guías y funcionalidades para ofrecer a los agentes de IA un archivo de habilidades completo con contexto sobre cómo ayudar a las personas a usar tu producto. `skill.md` sustituye el enfoque de `install.md` por capacidades más estructuradas y una adopción más amplia. Si tienes un archivo `skills.md` personalizado en la raíz de tu repositorio de documentación, este sustituye la versión generada automáticamente. Consulta [skill.md](/es/ai/skillmd) para obtener más información.

  ## Registros de auditoría para eventos de autenticación

  Ahora se registran los eventos en los [registros de auditoría](/es/dashboard/audit-logs) para mejorar la visibilidad y el cumplimiento.

  ## Exportación en Markdown para agentes

  Las páginas de documentación ahora sirven Markdown sin procesar cuando se envía el encabezado `Accept: text/markdown`, lo que permite que los agentes de IA consuman mejor el contenido.

  ## Mejoras

  * Se unificaron la autenticación, la autenticación parcial y la personalización en una sola experiencia de autenticación. Consulta [Configuración de autenticación](/es/deploy/authentication-setup) para obtener más información.
  * Las páginas ocultas ahora reciben automáticamente meta tags `noindex` para un mejor control del SEO.
  * Se añadió compatibilidad con Markdown para los pies de imagen.
</Update>

<Update label="9 de enero de 2026" tags={["Novedades", "Mejoras"]} rss={{ title: "Snippets implícitos e información sobre conversaciones con el asistente para todos" }}>
  ## Snippets implícitos

  Los Snippets ahora funcionan sin configuración explícita. Antes, tenías que definir Snippets en un directorio `/snippets` específico. Ahora puedes importar cualquier archivo como un Snippet desde cualquier lugar de tu documentación para reutilizar contenido con mayor flexibilidad. Consulta [Snippets reutilizables](/es/create/reusable-snippets) para obtener más información.

  ## Sugerencias del asistente para todos los usuarios

  Los [análisis de conversaciones](/es/agent/suggestions#conversation-insights) ya están disponibles para todos los sitios de documentación que tengan tanto el agente como el asistente habilitados. El agente analiza patrones en las conversaciones con el asistente para identificar lagunas en la documentación y sugerir mejoras, lo que te ayuda a abordar de forma proactiva las preguntas habituales de los usuarios.

  ## Sincronización de pestañas y grupos de código

  Las pestañas y los grupos de código ahora sincronizan su selección en toda la página. Cuando seleccionas una pestaña en un componente, todos los demás componentes de pestañas con la misma etiqueta se actualizan para mostrar la misma selección. Esto mantiene consistentes las opciones de lenguaje o framework en toda la página.

  ## Mejoras

  * **Borde inferior de las pestañas**: Se añadió un estilo opcional de borde inferior para las pestañas.
  * **Controles de Mermaid**: Controles interactivos para [diagramas de Mermaid](/es/components/mermaid-diagrams) que permiten navegar por diagramas grandes.
  * **Parámetros de URL para búsqueda y asistente**: Abre páginas con el modal de búsqueda precompletado con `?search=` o el asistente con `?assistant=`. Parámetros de consulta para enlaces directos y para compartir conocimiento.
  * **Edición del nombre del perfil**: Ahora los usuarios pueden editar su nombre y apellido en la configuración del perfil.
</Update>

  El agente ahora puede supervisar repositorios de Git y [sugerir](/es/agent/suggestions) actualizaciones de la documentación.   * Se corrigieron las rutas de carga de imágenes en configuraciones de monorepo.
  * Se corrigió un problema por el que primero se seleccionaba un valor incorrecto de la carga útil de la solicitud en el Área de pruebas de API.
  * Se eliminaron las extensiones de archivo de los títulos predeterminados de las imágenes al subirlas.
  * Se corrigió el estilo de doble subrayado en los enlaces del banner.
  * Se corrigieron los estados de carga y los valores de intervalo de fechas en la página de Analytics.

  * Se corrigió el desbordamiento de los títulos largos de páginas de API en lugar de ajustarse a la línea.

  * Se mejoró el espaciado y relleno de las descripciones en toda el Área de pruebas de API para mejorar la legibilidad y la consistencia visual.

  ## Mejoras de localización
