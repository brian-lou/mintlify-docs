<Update label="6 de febrero de 2026" tags={["Nuevos lanzamientos", "Mejoras"]} rss={{ title: "Configuración de SSO de autoservicio, rol de lector, conmutador de tráfico humano/IA y rediseño del menú de comandos slash" }}>
  ## Configuración de SSO de autoservicio

  Los clientes Enterprise ahora pueden configurar SAML SSO (Okta o Microsoft Entra) directamente desde el panel de control, incluyendo aprovisionamiento justo a tiempo (JIT), cambio de proveedor y eliminación de conexiones.

  ## Rol de lector

  Nuevo rol de lector con acceso de solo lectura a tu panel de control. Los lectores pueden ver contenido en el editor, pero no pueden editar contenido, invitar miembros ni modificar configuraciones.

  ## Conmutador de tráfico humano/IA

  La página de analíticas ahora muestra pestañas separadas para tráfico humano y de IA.

  ## Rediseño del menú de comandos slash

  El menú slash del editor ahora incluye búsqueda mientras escribes, mejor navegación con el teclado y otras mejoras de UX.

  ## Correcciones de errores

  * Se corrigió el desbordamiento de celdas en las tablas del panel de control.
  * Al cambiar el nombre de archivos mediante la hoja de configuración en el editor, ahora los cambios se guardan correctamente.
  * Los errores de análisis de MDX, como una etiqueta `<Card>` sin cerrar, ahora se actualizan dinámicamente a medida que los corriges en lugar de mantenerse incorrectamente entre recargas.
  * Los controles de arrastrar y soltar en el editor ahora se alinean correctamente con diferentes tipos de contenido como encabezados o párrafos, con tamaños consistentes y mejores áreas de interacción.
</Update>

  Instala [archivos skill.md](/es/ai/skillmd) usando solo una URL de documentación. No se necesita la ruta al archivo `skill.md`.

  ```bash
  npx skills add mintlify.com/docs
  ```

  Navegación mejorada entre las pestañas de [analíticas](optimize/analytics). Información más útil para la toma de decisiones y mejor visualización de datos.

  * Iconos editables
  * Edición de título y descripción de tipo &quot;lo que ves es lo que obtienes&quot; para los componentes Cards, Accordions y Steps
  * Ocultar y mostrar páginas en tu navegación

  * Activación de bloques de código con <code>```</code>

  Administra todas las [funciones del asistente](/es/ai/assistant) en una sola página con un diseño más limpio y mejor UX.

  ## Otros

  * Compatibilidad con la subida de archivos ZIP en el [proceso de incorporación](deploy/github#alternative%3A-download-and-create-your-own-repository)

  * Se corrigieron conflictos cuando aparecían varios diagramas Mermaid en la misma página.
  * Se corrigió un bucle de renderizado que podía causar problemas de rendimiento con el componente Tabs.
  * Se corrigió el botón de restablecimiento de contraseña que no funcionaba.

  * Se corrigió un problema por el que las fechas de &quot;última modificación&quot; de las páginas se actualizaban incorrectamente durante cambios globales de configuración.

<Update label="23 de enero de 2026" tags={["Nuevos lanzamientos", "Mejoras"]} rss={{ title: "skills.md, registros de auditoría y exportación en Markdown" }}>
  ## Generación automática de `skill.md`

  Los sitios de documentación ahora generan automáticamente un archivo `skill.md` basado en tus referencias de API, guías y funcionalidades para proporcionar a los agentes de IA un archivo de habilidades completo con contexto sobre cómo ayudar a las personas a usar tu producto. `skill.md` reemplaza el enfoque de `install.md` con capacidades más estructuradas y una adopción más amplia. Si tienes un archivo `skills.md` personalizado en la raíz de tu repositorio de documentación, este reemplaza la versión generada automáticamente. Consulta [skill.md](/es/ai/skillmd) para obtener más información.

  ## Registros de auditoría para eventos de autenticación

  Ahora se registran los eventos en los [registros de auditoría](/es/dashboard/audit-logs) para mayor visibilidad y cumplimiento.

  ## Exportación en Markdown para agentes

  Las páginas de documentación ahora sirven Markdown en bruto cuando se envía el encabezado `Accept: text/markdown`, lo que permite un mejor consumo de contenido por parte de los agentes de IA.

  ## Mejoras

  * Se combinaron la autenticación, la autenticación parcial y la personalización en una única experiencia de autenticación. Consulta [Configuración de autenticación](/es/deploy/authentication-setup) para obtener más información.
  * Las páginas ocultas ahora reciben automáticamente metaetiquetas `noindex` para un mejor control de SEO.
  * Se agregó compatibilidad con Markdown para pies de foto de imágenes.
</Update>

  ## Generación automática de `install.md`

  Los sitios de documentación ahora generan automáticamente un archivo `install.md` que agrupa las páginas relacionadas con la instalación, como inicios rápidos, primeros pasos, instalación y guías de configuración para agentes de IA. Si tienes un archivo `install.md` personalizado en tu repositorio de documentación, este tiene prioridad sobre la versión generada automáticamente.

  ## Mejoras del editor web

  * **Vista previa en vivo**: Ve los cambios en tiempo real mientras editas tu documentación en el editor web. Las vistas previas en vivo muestran tu sitio exactamente como aparece cuando se publica, sin crear un despliegue de vista previa.
  * **Sección de archivos sin usar**: El editor ahora muestra las páginas sin usar que no están en tu navegación, con compatibilidad de arrastrar y soltar para agregarlas.

  ## Búsqueda de ramas para integraciones con Git

  Se agregó funcionalidad de búsqueda de ramas para las integraciones con GitHub y GitLab, de modo que sea más fácil encontrar y cambiar entre ramas de despliegue en la configuración de Git de tu panel.

  ## Comando de CLI `mintlify validate`

  Nuevo comando de CLI para validar tus compilaciones de documentación localmente antes de desplegar. Ejecuta `mint validate` para detectar errores de configuración y de compilación con anticipación.

  ## Niveles de mensajes del asistente

  Los usuarios ahora pueden seleccionar niveles de cupos de mensajes del asistente por mes desde el panel.

  ## Correcciones de errores

  * Se corrigieron problemas con las rutas base de las referencias de API.
  * Se actualizaron los colores de los avisos con un esquema de colores renovado.
  * Se corrigió que las imágenes no se mostraran en la carga inicial después de subirlas en el editor.
  * Se corrigió el estilo del código dentro de enlaces de tarjetas.
  * Se corrigió que los archivos `.md` sobrescribieran incorrectamente los archivos `.mdx`.
</Update>

<Update label="9 de enero de 2026" tags={["Nuevos lanzamientos", "Mejoras"]} rss={{ title: "Fragmentos implícitos e información de conversaciones del asistente para todos" }}>
  ## Fragmentos implícitos

  Los fragmentos ahora funcionan sin configuración explícita. Antes, necesitabas definir fragmentos en un directorio `/snippets` específico. Ahora puedes importar cualquier archivo como fragmento desde cualquier lugar de tu documentación para una reutilización de contenido más flexible. Consulta [Fragmentos reutilizables](/es/create/reusable-snippets) para obtener más información.

  ## Sugerencias del asistente para todos los usuarios

  [Conversation insights](/es/agent/suggestions#conversation-insights) ahora está disponible para todos los sitios de documentación que tengan tanto el agente como el asistente habilitados. El agente analiza patrones en las conversaciones del asistente para identificar brechas en la documentación y sugerir mejoras, ayudándote a abordar de forma proactiva las preguntas comunes de los usuarios.

  ## Sincronización de pestañas y grupos de código

  Las pestañas y los grupos de código ahora sincronizan su selección en toda la página. Cuando seleccionas una pestaña en un componente, todos los demás componentes de pestañas con etiquetas coincidentes se actualizan para mostrar la misma selección. Esto mantiene las elecciones de lenguaje o framework coherentes en toda la página.

  ## Mejoras

  * **Borde inferior de pestañas**: Se agregó un estilo opcional de borde inferior para las pestañas.
  * **Controles de Mermaid**: Controles interactivos para [diagramas Mermaid](/es/components/mermaid-diagrams) que permiten navegar por diagramas grandes.
  * **Parámetros de URL para búsqueda y asistente**: Abre páginas con el cuadro de búsqueda precargado con `?search=` o el asistente con `?assistant=`. Parámetros de consulta de usuario para enlaces directos y para compartir conocimiento.
  * **Edición del nombre de perfil**: Los usuarios ahora pueden editar su nombre y apellido en la configuración de perfil.
</Update>

  * **Arrastrar y soltar recursos**: Arrastra imágenes y archivos directamente desde tu computadora al árbol de archivos para subirlos.

  * Se añadió un selector de tema a la navegación móvil para facilitar el cambio entre los modos claro y oscuro.

  * Se corrigieron ejemplos de solicitudes que faltaban en el área de pruebas de la API para ciertos endpoints.
  * Se corrigió que los ejemplos MDX no se mostraran correctamente al usar ejemplos predefinidos en el área de pruebas de la API.
  * Se corrigieron enlaces en el asistente que se abrían en ventanas nuevas en lugar de en la misma ventana.
  * Se corrigió el renderizado de enlaces Markdown en las respuestas del asistente.
  * Se corrigió el manejo de caracteres especiales en los *slugs* de encabezados.

<Update label="12 de diciembre de 2025" tags={["Nuevos lanzamientos", "Mejoras"]} rss={{  title: "Sugerencias del agente y bots de preguntas y respuestas" }}>
  ## Sugerencias del agente

  El agente ahora puede supervisar repositorios Git y [sugerir](/es/agent/suggestions) actualizaciones de documentación. Cuando se detectan cambios en el código orientado al usuario, las sugerencias aparecen en el panel del agente. Las sugerencias incluyen la pull request correspondiente y una lista de actualizaciones de documentación propuestas. Añade las sugerencias como contexto para que el agente cree pull requests o descártalas.

  ## Bots de preguntas y respuestas en Slack y Discord

  Añade bots impulsados por el asistente a tus [espacios de trabajo de Slack](/es/ai/slack-bot) y [servidores de Discord](/es/ai/discord). Los bots responden preguntas en tiempo real basándose en tu documentación, de modo que proporcionan respuestas precisas y actualizadas a tus comunidades.

  Los bots responden a menciones con `@` y a todos los mensajes en canales llamados `#ask-ai`.

  ## Los snippets ahora admiten importaciones relativas

  Ahora puedes usar rutas relativas al importar snippets en tus archivos MDX. Antes, las importaciones requerían rutas absolutas que empezaran con `/snippets/`. Ahora puedes usar rutas relativas como `../snippets/example.mdx` para una organización de archivos más flexible.

  ## Mejoras

  * **Insights** pasó a llamarse **Analytics** en el panel.
  * Se añadió la posibilidad de eliminar un despliegue desde el panel.
  * El componente `Tooltip` ha sido rediseñado con un estilo mejorado y ahora admite una prop opcional `headline` para añadir un título a tus tooltips.
  * El comando `mint a11y` ahora admite las opciones `--skip-contrast` y `--skip-alt-text`, lo que te permite ejecutar comprobaciones de accesibilidad específicas en tu pipeline de CI/CD. Usa `--skip-contrast` para comprobar solo si falta texto alternativo, o `--skip-alt-text` para comprobar solo las relaciones de contraste de color.

  ## Correcciones de errores

  * Se corrigió un problema por el que los enlaces dentro de pestañas no funcionaban correctamente.
  * Se corrigió el renderizado de los encabezados de nivel 5 y 6 en el editor web.
  * Se corrigió la visualización de ejemplos de páginas de esquema en las páginas de referencia de API.
  * Se corrigieron las rutas de carga de imágenes en configuraciones de monorepo.
  * Se corrigió un problema en el que se seleccionaba primero un valor incorrecto de payload de solicitud en el playground de la API.
  * Se eliminaron las extensiones de archivo de los títulos de imagen predeterminados al subirlas.
  * Se corrigió el estilo de subrayado doble en los enlaces de banners.
  * Se corrigieron los estados de carga y los valores de rango de fechas de la página de Analytics.
  * Las carpetas en el editor web ahora mantienen correctamente su estado abierto/cerrado cuando se abren o cierran otras carpetas.
  * Se corrigió que los títulos largos de páginas de API se desbordaran en lugar de ajustarse.
</Update>

  ## Mejoras en el API playground

  * Se corrigió un problema por el que la sección de respuesta desaparecía al cambiar entre endpoints con diferentes códigos de respuesta. Ahora el playground se restablece correctamente al primer código de respuesta disponible al navegar a un nuevo endpoint.

  * Se mejoró el manejo de esquemas `oneOf` en objetos y arrays anidados. Los esquemas de API complejos con múltiples opciones de tipo ahora se representan correctamente como menús desplegables en lugar de pestañas en los contextos apropiados.
  * Se corrigieron parámetros de ruta faltantes que estaban definidos a nivel de endpoint en especificaciones OpenAPI. Los parámetros especificados por encima de las operaciones individuales ahora se incluyen correctamente tanto en la página principal como en el playground.
  * Se mejoró la generación de ejemplos de respuesta para incluir todas las propiedades requeridas, incluso cuando los ejemplos solo especifican algunos campos. Esto asegura que los ejemplos de respuesta sean completos y precisos.
  * Se corrigieron ejemplos de autocompletado faltantes en arrays de objetos. Los elementos de arrays con datos de ejemplo ahora se completan correctamente en el playground con el índice adecuado.
  * Se mejoró el espaciado y el padding de las descripciones en todo el API playground para una mejor legibilidad y consistencia visual.

  ## Mejoras de localización

  * Se mejoraron las traducciones en las opciones del menú contextual y en los mensajes de estado de Assistant para todos los idiomas admitidos.

  ## Mejoras de la CLI

  Hemos introducido un nuevo esquema `docs.json` como reemplazo de `mint.json`, para admitir un mejor versionado multinivel, una comprensión visual más sencilla y una terminología más coherente. Para obtener más información sobre lo que ha cambiado, [consulta nuestro blog](https://mintlify.com/blog/refactoring-mint-json-into-docs-json).

  Actualiza de `mint.json` a `docs.json` con los siguientes pasos:

  1. Asegúrate de que tu CLI esté en la última versión

  ```bash
  npm i mint@latest -g
  ```

  1. En tu repositorio de documentación, ejecuta

  ```bash
  mint upgrade
  ```

  1. Elimina tu antiguo archivo `mint.json` y haz push de tus cambios
