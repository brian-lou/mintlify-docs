Después de completar esta guía, tendrás un sitio de documentación en línea listo para personalizar y actualizar.

<div id="before-you-begin">
  ## Antes de empezar
</div>

Mintlify utiliza un enfoque de documentación como código para gestionar tu documentación. Cada página de tu sitio tiene un archivo correspondiente almacenado en el <Tooltip tip="El código fuente de tu documentación, donde se guardan todos los archivos y su historial. El editor web se conecta al repositorio de tu documentación para acceder al contenido y modificarlo, o puedes editar los archivos localmente en tu IDE preferido.">repositorio</Tooltip> de tu documentación.

Cuando conectas el repositorio de tu documentación a tu proyecto, puedes trabajar en ella localmente o en el editor web y sincronizar cualquier cambio con tu repositorio remoto.

<div id="deploy-your-documentation-site">
  ## Despliega tu sitio de documentación
</div>

Ve a [mintlify.com/start](https://mintlify.com/start) y completa el proceso de configuración inicial. Durante este proceso, conectarás tu cuenta de GitHub, crearás o seleccionarás un repositorio para tu documentación e instalarás la GitHub App para habilitar los despliegues automáticos.

Después de la configuración inicial, tu sitio de documentación quedará desplegado y accesible en tu URL de `.mintlify.app`.

<AccordionGroup>
  <Accordion title="Opcional: omite la conexión con GitHub durante la configuración inicial">
    Si quieres empezar rápidamente sin conectar tu propio repositorio, puedes omitir la conexión con GitHub durante la configuración inicial. Mintlify crea un repositorio privado en una organización privada y configura automáticamente la GitHub App por ti.

    Esto te permite usar el editor web de inmediato y migrar a tu propio repositorio más adelante.
  </Accordion>
</AccordionGroup>

<div id="view-your-deployed-site">
  ## Ver tu sitio desplegado
</div>

Tu sitio de documentación ya está desplegado en `https://<your-project-name>.mintlify.app`.

Encuentra la URL exacta en la página **Overview** de tu [panel](https://dashboard.mintlify.com/).

</Tip>

<div id="make-your-first-change">
  ## Haz tu primer cambio
</div>

<Tabs>
  <Tab title="CLI">
    <Steps>
      <Step title="Instala la CLI">
        La CLI requiere [Node.js](https://nodejs.org/en) v20.17.0 o superior. Usa una versión LTS para mayor estabilidad.

        <CodeGroup>
          ```bash npm
          npm i -g mint
          ```

          ```bash pnpm
          pnpm add -g mint
          ```
        </CodeGroup>

        Consulta [Instalar la CLI](/es/installation) para ver todos los detalles y solucionar problemas.
      </Step>

      <Step title="Clona tu repositorio">
        Si aún no has clonado tu repositorio en local, sigue las instrucciones de [Clona tu repositorio](/es/installation#clone-your-repository).
      </Step>

      <Step title="Edita una página">
        Abre `index.mdx` en tu editor preferido y actualiza la descripción en el Frontmatter:

        ```mdx
        ---
        title: "Introduction"
        description: "Your custom description here"
        ---
        ```
      </Step>

      <Step title="Vista previa local">
        Ejecuta el siguiente comando desde tu directorio de documentación:

        ```bash
        mint dev
        ```

        Consulta la vista previa en `http://localhost:3000`.
      </Step>

      <Step title="Sube tus cambios">
        Haz commit y sube tus cambios para activar un despliegue:

        ```bash
        git add .
        git commit -m "Update description"
        git push
        ```

        Mintlify despliega tus cambios automáticamente. Consulta el estado del despliegue en la página [Overview](https://dashboard.mintlify.com/) de tu panel.
      </Step>
    </Steps>
  </Tab>

  <Tab title="Editor web">
    <Steps>
      <Step title="Abre el editor web">
        Ve al [editor web](https://dashboard.mintlify.com/editor) en tu panel.
      </Step>

      <Step title="Edita una página">
        Abre la página **Introduction** y actualiza la descripción.

        <Frame>
          <img src="/images/quickstart/hello-world-light.png" alt="Página Introduction abierta en el editor web con la descripción editada para mostrar «Hello world!». " className="block dark:hidden" />

          <img src="/images/quickstart/hello-world-dark.png" alt="Página Introduction abierta en el editor web con la descripción editada para mostrar «Hello world!». " className="hidden dark:block" />
        </Frame>
      </Step>

      <Step title="Publica">
        Haz clic en el botón **Publish** en la esquina superior derecha de la barra de herramientas del editor web.
      </Step>

      <Step title="Ver en vivo">
        En la página [Overview](https://dashboard.mintlify.com/) de tu panel, puedes ver el estado del despliegue de tu sitio. Cuando termine de desplegarse, actualiza tu sitio de documentación para ver los cambios en vivo.
      </Step>
    </Steps>
  </Tab>
</Tabs>
