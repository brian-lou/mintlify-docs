Los acordeones permiten a los usuarios expandir y contraer secciones de contenido. Usa acordeones para mostrar información de forma progresiva y para organizarla.


<div id="single-accordion">
  ## Acordeón individual
</div>

<Accordion title="Soy un acordeón.">
  Puedes poner cualquier tipo de contenido aquí, incluidos otros componentes, como código:

  ```java HelloWorld.java
   class HelloWorld {
       public static void main(String[] args) {
           System.out.println("Hello, World!");
       }
   }
  ```
</Accordion>

<div id="accordion-groups">
  ## Grupos de acordeones
</div>

Agrupa los acordeones relacionados usando `<AccordionGroup>`. Esto crea una sección coherente de acordeones que se pueden expandir o contraer individualmente.

<AccordionGroup>
  <Accordion title="Primeros pasos">
    Puedes colocar otros componentes dentro de los acordeones.

    ```java HelloWorld.java
    class HelloWorld {
        public static void main(String[] args) {
            System.out.println("Hello, World!");
        }
    }
    ```
  </Accordion>

  <Accordion title="Funciones avanzadas" icon="bot">
    Agrega iconos para hacer que los acordeones sean más distintivos visualmente y fáciles de recorrer con la vista.
  </Accordion>

  <Accordion title="Solución de problemas">
    Mantén el contenido relacionado organizado en grupos.
  </Accordion>
</AccordionGroup>

````mdx Accordion Group Example
<AccordionGroup>
  <Accordion title="Getting started">
    You can put other components inside Accordions.

    ```java HelloWorld.java
    class HelloWorld {

            System.out.println("Hello, World!");
        }
    }
    ```
  </Accordion>

  <Accordion title="Advanced features" icon="alien-8bit">
    Add icons to make accordions more visually distinct and scannable.
  </Accordion>

  <Accordion title="Troubleshooting">
    Keep related content organized into groups.
  </Accordion>
</AccordionGroup>
````


<div id="properties">
  ## Propiedades
</div>

<ResponseField name="title" type="string" required>
  Título en la vista previa del Accordion.
</ResponseField>

<ResponseField name="description" type="string">
  Detalle que aparece debajo del título en la vista previa del Accordion.
</ResponseField>

<ResponseField name="defaultOpen" type="boolean" default="false">
  Indica si el Accordion está abierto de forma predeterminada.
</ResponseField>
