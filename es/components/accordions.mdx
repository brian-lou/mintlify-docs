Los acordeones permiten a los usuarios expandir y contraer secciones de contenido. Usa acordeones para mostrar la información de forma progresiva y organizarla.


<div id="single-accordion">
  ## Acordeón individual
</div>

<Accordion title="Soy un acordeón.">
  Puedes poner aquí cualquier contenido, incluidos otros componentes, como código:

  ```java HelloWorld.java
   class HelloWorld {
       public static void main(String[] args) {
           System.out.println("Hello, World!");
       }
   }
  ```
</Accordion>

<div id="accordion-groups">
  ## Grupos de acordeones
</div>

Agrupa acordeones relacionados con `<AccordionGroup>`. Esto crea una sección unificada de acordeones que puedes expandir o contraer por separado.

<AccordionGroup>
  <Accordion title="Primeros pasos">
    Puedes colocar otros componentes dentro de los acordeones.

    ```java HelloWorld.java
    class HelloWorld {
        public static void main(String[] args) {
            System.out.println("Hello, World!");
        }
    }
    ```
  </Accordion>

  <Accordion title="Funciones avanzadas" icon="bot">
    Agrega iconos para que los acordeones se distingan visualmente y sean más fáciles de identificar de un vistazo.
  </Accordion>

  <Accordion title="Solución de problemas">
    Organiza el contenido relacionado en grupos.
  </Accordion>
</AccordionGroup>

<div id="properties">
  ## Propiedades
</div>

<ResponseField name="title" type="string" required>
  Título en la vista previa del acordeón.
</ResponseField>

<ResponseField name="description" type="string">
  Descripción debajo del título en la vista previa del acordeón.
</ResponseField>

<ResponseField name="defaultOpen" type="boolean" default="false">
  Indica si el acordeón está abierto de forma predeterminada.
</ResponseField>
