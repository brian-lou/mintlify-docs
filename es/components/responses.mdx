El componente `<ResponseField>` está diseñado para definir los valores de retorno de una API. Gran parte de la documentación también utiliza `<ResponseField>` en páginas donde se necesita enumerar los tipos de algo.

<ResponseField name="response" type="string" required>
  Un ejemplo de campo de respuesta
</ResponseField>

```mdx
<ResponseField name="response" type="string" required>
  Un ejemplo de campo de respuesta
</ResponseField>
```


<div id="props">
  ## Props
</div>

<ResponseField name="name" type="string" required>
  El nombre del valor de la respuesta.
</ResponseField>

<ResponseField name="type" type="string" required>
  Tipo esperado del valor de la respuesta; puede ser cualquier cadena de texto arbitraria.
</ResponseField>

<ResponseField name="default" type="string">
  El valor predeterminado.
</ResponseField>

<ResponseField name="required" type="boolean">
  Muestra "required" junto al nombre del campo.
</ResponseField>

<ResponseField name="deprecated" type="boolean">
  Indica si un campo está obsoleto o no.
</ResponseField>

<ResponseField name="pre" type="string[]">
  Etiquetas que se muestran antes del nombre del campo.
</ResponseField>

<ResponseField name="post" type="string[]">
  Etiquetas que se muestran después del nombre del campo.
</ResponseField>
