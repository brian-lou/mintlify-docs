---
title: "Callouts"
description: "Usa callouts para dar estilo y resaltar contenido importante."
keywords: ["callouts", "notes", "warnings", "info boxes", "tips", "emphasis", "highlight"]
---

Los callouts pueden mostrarse como Nota, Advertencia, Información, Consejo, Confirmación o Peligro, o puedes crear tu propio callout:

<Note>Esto añade una nota al contenido</Note>

```mdx
<Note>Esto añade una nota en el contenido</Note>
```

<Warning>Esto muestra una advertencia a la que debes prestar atención</Warning>

```mdx
<Warning>Esto genera una advertencia a tener en cuenta</Warning>
```

<Info>Esto destaca información importante</Info>

```mdx
<Info>Esto llama la atención sobre información importante</Info>
```

<Tip>Esto ofrece un consejo útil</Tip>

```mdx
<Tip>Esto sugiere un consejo útil</Tip>
```

<Check>Esto nos deja con un estado marcado</Check>

```mdx
<Check>This brings us a checked status</Check>
```

<Danger>Este es un recuadro de peligro</Danger>

```mdx
<Danger>Este es un aviso de peligro</Danger>
```

<Callout icon="key" color="#FFC107" iconType="regular"> Este es un callout personalizado</Callout>

```mdx wrap
<Callout icon="key" color="#FFC107" iconType="regular">This is a custom callout</Callout>
```
