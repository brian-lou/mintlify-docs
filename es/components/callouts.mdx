Los avisos se pueden mostrar como Note, Warning, Info, Tip, Check, Danger, o puedes crear tu propio aviso:

<Note>Esto añade una nota al contenido</Note>

```mdx
<Note>This adds a note in the content</Note>
```

<Warning>Esto genera una advertencia que hay que tener en cuenta</Warning>

```mdx
<Warning>Esto genera una advertencia a tener en cuenta</Warning>
```

<Info>Esto destaca información importante</Info>

```mdx
<Info>Esto llama la atención sobre información importante</Info>
```

<Tip>Esto indica un consejo útil</Tip>

```mdx
<Tip>Esto sugiere un consejo útil</Tip>
```

<Check>Esto nos da un estado seleccionado</Check>

```mdx
<Check>This brings us a checked status</Check>
```

<Danger>Este es un aviso de peligro</Danger>

```mdx
<Danger>Este es un aviso de peligro</Danger>
```

<Callout icon="key" color="#FFC107" iconType="regular"> Este es un aviso personalizado</Callout>

```mdx wrap
<Callout icon="key" color="#FFC107" iconType="regular">Este es un callout personalizado</Callout>
```
