Los componentes `<RequestExample>` y `<ResponseExample>` muestran bloques de código en la barra lateral derecha para crear un diseño de dos columnas que mantiene los ejemplos visibles mientras los usuarios se desplazan por el contenido. Estos componentes están diseñados para la documentación de API, pero funcionan en cualquier página.

Casos de uso habituales:

* Documentación de endpoints de API con ejemplos de solicitud y respuesta
* Ejemplos de configuración junto a texto explicativo
* Fragmentos de código que los usuarios consultan mientras siguen instrucciones
* Ejemplos de antes y después en tutoriales

En dispositivos móviles, los componentes `<RequestExample>` y `<ResponseExample>` se muestran como bloques de código normales y los usuarios pueden seguir desplazándose más allá de ellos.

<RequestExample>
  ```bash Request
  curl --request POST \
    --url https://dog-api.kinduff.com/api/facts
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  { "status": "success" }
  ```
</ResponseExample>

<div id="requestexample">
  ## RequestExample
</div>

Usa `<RequestExample>` para fijar ejemplos de código en la barra lateral derecha. Este componente funciona de forma similar al componente [CodeGroup](/es/components/code-groups), pero muestra el código en la barra lateral en lugar de integrarlo en el contenido.

Puedes incluir varios bloques de código dentro de un solo `<RequestExample>`. Cada bloque de código debe tener un atributo `title`.

````mdx RequestExample
<RequestExample>

```bash Request
curl --request POST \
  --url https://dog-api.kinduff.com/api/facts
```

</RequestExample>
````

<div id="responseexample">
  ## ResponseExample
</div>

El componente `<ResponseExample>` fija ejemplos de código en la barra lateral derecha, debajo de cualquier contenido de `<RequestExample>` en la misma página.

````mdx ResponseExample
<ResponseExample>

```json Response
{ "status": "success" }
```

</ResponseExample>
````
