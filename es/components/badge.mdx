Usa insignias para mostrar indicadores de estado, etiquetas o metadatos. Las insignias pueden usarse integradas en el texto o como elementos independientes.

</div>

```mdx

```

<div id="inline-usage">
  ## Uso en línea
</div>

Las insignias funcionan de forma natural en el texto. Por ejemplo, esta función requiere una suscripción <Badge color="orange" size="sm">Premium</Badge> o este endpoint de la API devuelve contenido en formato <Badge color="green" size="sm">JSON</Badge>.

```mdx
This feature requires a <Badge color="orange" size="sm">Premium</Badge> subscription.
```

<div id="properties">
  ## Propiedades
</div>

<ResponseField name="color" type="string" default="gray">
  Variante de color del badge.

  Opciones: `gray`, `blue`, `green`, `yellow`, `orange`, `red`,
  `purple`, `white`, `surface`, `white-destructive`, `surface-destructive`.
</ResponseField>

<ResponseField name="size" type="string" default="md">
  Tamaño del badge.

  Opciones: `xs`, `sm`, `md`, `lg`.
</ResponseField>

<ResponseField name="shape" type="string" default="rounded">
  Forma del badge.

  Opciones: `rounded`, `pill`.
</ResponseField>

<IconsOptional />

<ResponseField name="stroke" type="boolean" default="false">
  Muestra el badge con un contorno en lugar de un fondo sólido.
</ResponseField>

<ResponseField name="disabled" type="boolean" default="false">
  Muestra el badge en estado deshabilitado con opacidad reducida.
</ResponseField>

<ResponseField name="className" type="string">
  Clases CSS adicionales para aplicar al badge.
</ResponseField>
