Usa mosaicos para crear elementos visuales de presentación con un fondo con patrón, título y descripción. Los mosaicos son ideales para mostrar vistas previas de componentes, destacar funciones o elementos de navegación en una cuadrícula.

<div id="properties">
  ## Propiedades
</div>

<ResponseField name="href" type="string" required>
  URL a la que se navega cuando se hace clic en la tarjeta.
</ResponseField>

<ResponseField name="title" type="string">
  El título que se muestra debajo de la vista previa de la tarjeta.
</ResponseField>

<ResponseField name="description" type="string">
  Una breve descripción que se muestra debajo del título.
</ResponseField>

<ResponseField name="children" type="React.ReactNode" required>
  Contenido que se muestra dentro del área de vista previa de la tarjeta, generalmente imágenes o SVG.
</ResponseField>
