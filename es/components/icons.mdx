<div id="inline-icons">
  ## Iconos en línea
</div>

Los iconos se muestran en línea cuando se usan dentro de una oración, un párrafo o un encabezado. <Icon icon="flag" iconType="solid" /> Usa iconos como elemento decorativo o para añadir énfasis visual.

<div id="properties">
  ## Propiedades

<IconsRequired />

<ResponseField name="color" type="string">
  El color del icono como código hexadecimal (por ejemplo, `#FF5733`).
</ResponseField>

<ResponseField name="size" type="number">
  El tamaño del icono en píxeles.
</ResponseField>

<ResponseField name="className" type="string">
  Nombre de clase CSS personalizado que se aplica al icono.
</ResponseField>
