El componente `Columns` te permite agrupar varios componentes `Card`. Se usa principalmente para mostrar tarjetas en una cuadrícula al especificar el número de columnas. Las columnas son responsivas y se ajustan automáticamente en pantallas más pequeñas.

<Columns cols={2}>
  <Card title="Comenzar" icon="rocket">
    Configura tu proyecto con nuestra guía de inicio rápido.
  </Card>

  <Card title="Referencia de API" icon="code">
    Explora endpoints, parámetros y ejemplos de tu API.
  </Card>
</Columns>

```mdx Columns example
<Columns cols={2}>
  <Card title="Get started">
    Set up your project with our quickstart guide.
  </Card>
  <Card title="API reference">
    Explore endpoints, parameters, and examples for your API.
  </Card>
</Columns>
```


<div id="properties">
  ## Propiedades
</div>

<ResponseField name="cols" type="number" default={2}>
  La cantidad de columnas por fila. Acepta valores del 1 al 4.
</ResponseField>
