El componente `Columns` te permite agrupar varios componentes `Card`. Se usa con mayor frecuencia para colocar tarjetas en una cuadrícula, indicando el número de columnas. Las columnas son adaptables y se ajustan automáticamente a las pantallas más pequeñas.

<Columns cols={2}>
  <Card title="Primeros pasos" icon="rocket">
    Configura tu proyecto con nuestra guía de inicio rápido.
  </Card>

  <Card title="Referencia de la API" icon="code">
    Explora endpoints, parámetros y ejemplos para tu API.
  </Card>
</Columns>

```mdx Columns example
<Columns cols={2}>
  <Card title="Get started">
    Set up your project with our quickstart guide.
  </Card>
  <Card title="API reference">
    Explore endpoints, parameters, and examples for your API.
  </Card>
</Columns>
```


<div id="properties">
  ## Propiedades
</div>

<ResponseField name="cols" type="number" default={2}>
  El número de columnas por fila. Acepta valores de 1 a 4.
</ResponseField>
