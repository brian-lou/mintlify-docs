Usa tooltips para proporcionar contexto adicional o definiciones cuando un usuario pase el cursor sobre un fragmento de texto. Los tooltips pueden incluir enlaces opcionales de llamada a la acción.

**Ejemplo**: la documentación de <Tooltip headline="API" tip="Interfaz de Programación de Aplicaciones: un conjunto de protocolos que permite que las aplicaciones de software se comuniquen." cta="Lee nuestra guía sobre API" href="/es/api-reference">API</Tooltip> ayuda a los desarrolladores a entender cómo integrarse con tu servicio.

```mdx Tooltip example wrap
<Tooltip headline="API" tip="Application Programming Interface: un conjunto de protocolos para que las aplicaciones de software se comuniquen." cta="Lee nuestra guía de API" href="/api-reference">API</Tooltip> documentation helps developers understand how to integrate with your service.
```

<div id="properties">
  ## Propiedades
</div>

<ResponseField name="tip" type="string" required>
  El texto que se muestra en el tooltip.
</ResponseField>

<ResponseField name="headline" type="string">
  Texto que se muestra encima del texto de `tip`.
</ResponseField>

<ResponseField name="cta" type="string">
  El texto de llamada a la acción de un enlace dentro del tooltip.
</ResponseField>

<ResponseField name="href" type="string">
  URL del enlace de llamada a la acción. Obligatorio al usar `cta`.
</ResponseField>
