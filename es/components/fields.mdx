Usa campos para documentar los parámetros y las respuestas de la API. Hay dos tipos de campos: campos de parámetros y campos de respuesta.

<div id="parameter-field">
  ## Campo de parámetro
</div>

El componente `<ParamField>` se usa para definir parámetros para tus API o SDK. Al añadir un `ParamField`, se agrega automáticamente un [Área de pruebas de API](/es/api-playground/overview).

<ParamField path="param" type="string" required>
  Un ejemplo de campo de parámetro
</ParamField>

```mdx
<ParamField path="param" type="string" required>
  An example of a parameter field
</ParamField>
```

<div id="properties">
  ### Propiedades
</div>

<ParamField body="query, path, body, or header" type="string">
  Indica si el parámetro es de tipo query, path, body o header, seguido del
  nombre del parámetro.
</ParamField>

<ParamField body="type" type="string">
  Tipo esperado del valor del parámetro.

  Admite `number`, `string`, `boolean`, `object`.

  Los arrays se pueden definir con el sufijo `[]`. Por ejemplo, `string[]`.
</ParamField>

<ParamField body="required" type="boolean">
  Indica si el parámetro es obligatorio.
</ParamField>

<ParamField body="deprecated" type="boolean">
  Indica si el parámetro está en desuso.
</ParamField>

<ParamField body="default" type="any">
  Valor predeterminado que se rellena cuando el valor de la solicitud está vacío
</ParamField>

<ParamField body="placeholder" type="string">
  Texto del marcador de posición para el campo en el playground.
</ParamField>

<ParamField body="children" type="string">
  Descripción del parámetro (compatible con Markdown).
</ParamField>

<div id="response-field">
  ## Campo de respuesta
</div>

El componente `<ResponseField>` define los valores que devuelve una API.

<ResponseField name="response" type="string" required>
  Un ejemplo de campo de respuesta
</ResponseField>

```mdx
<ResponseField name="response" type="string" required>
  A response field example
</ResponseField>
```

<div id="properties">
  ### Propiedades
</div>

<ResponseField name="name" type="string" required>
  El nombre del valor de respuesta.
</ResponseField>

<ResponseField name="type" type="string" required>
  El tipo esperado del valor de respuesta. Puede ser cualquier cadena.
</ResponseField>

<ResponseField name="default" type="string">
  El valor predeterminado.
</ResponseField>

<ResponseField name="required" type="boolean">
  Indica si la respuesta es obligatoria.
</ResponseField>

<ResponseField name="deprecated" type="boolean">
  Indica si un campo está en desuso.
</ResponseField>

<ResponseField name="pre" type="string[]">
  Etiquetas que se muestran antes del nombre del campo.
</ResponseField>

<ResponseField name="post" type="string[]">
  Etiquetas que se muestran después del nombre del campo.
</ResponseField>
