Mintlify gestiona automáticamente muchas de las mejores prácticas de SEO, entre ellas:

* Generación de meta tags
* Generación de archivos sitemap y `robots.txt`
* Estructura HTML semántica
* Optimización para dispositivos móviles

Puedes personalizar por completo las meta tags de tu sitio añadiendo el campo `metatags` a tu `docs.json` o al frontmatter de una página.

<div id="automatically-generated-meta-tags">
  ## Metaetiquetas generadas automáticamente
</div>

Mintlify genera las siguientes metaetiquetas para cada página. Puedes sobrescribir estas metaetiquetas especificándolas en tu `docs.json` o en el frontmatter de una página.

**Metadatos básicos:**

* `charset: utf-8` - Codificación de caracteres
* `og:type: website` - Tipo de Open Graph
* `og:site_name` - Nombre de tu sitio de documentación
* `twitter:card: summary_large_image` - Tipo de tarjeta de Twitter

**Metadatos específicos de la página:**

* `title` - Título de la página, con el formato &quot;Título de la página - Nombre del sitio&quot;
* `og:title` - Título de Open Graph, igual que el título de la página
* `twitter:title` - Título de Twitter, igual que el título de la página
* `description` - Descripción de la página
* `og:description` - Descripción de Open Graph, igual que la descripción de la página
* `twitter:description` - Descripción de Twitter, igual que la descripción de la página

**URL y canonical:**

* `canonical` - Se genera automáticamente a partir de la URL de la página
* `og:url` - Se configura con la URL canonical

**SEO e indexación:**

* `robots` - Se genera a partir de los metadatos de la página
* `noindex` - Se genera a partir de los metadatos de la página
* `keywords` - Se generan a partir de los metadatos de la página

**Imágenes:**

* `og:image` - Imagen de Open Graph, `og:image:width` se establece en 1200 y `og:image:height` en 630
* `twitter:image` - Imagen de Twitter, `twitter:image:width` se establece en 1200 y `twitter:image:height` en 630

**Metadatos del navegador y la aplicación:**

* `applicationName` - Nombre de tu sitio de documentación
* `generator: Mintlify` - Identifica el generador del sitio como Mintlify
* `apple-mobile-web-app-title` - Nombre de la aplicación en la pantalla de inicio de iOS
* `msapplication-TileColor` - Color del mosaico de Windows
* Favicons e iconos desde tu configuración
* Enlace de referencia al sitemap

Cualquier metaetiqueta en la configuración `seo.metatags` de tu `docs.json` también se inyecta automáticamente en cada página, como `google-site-verification` para la validación en Search Console.

<div id="global-meta-tags">
  ## Metaetiquetas globales
</div>

Para definir metaetiquetas predeterminadas para todas las páginas, agrega el campo `metatags` al archivo `docs.json`.

```json
"seo": {
    "metatags": {
        "og:image": "link to your default meta tag image"
    }
}
```

<div id="set-a-canonical-url">
  ### Establecer una URL canónica
</div>

Si estás usando un dominio personalizado, configura la etiqueta meta `canonical` para asegurarte de que los motores de búsqueda indexen tu dominio preferido. Una URL canónica indica a los motores de búsqueda qué versión de tu documentación es la principal. Esto mejora el SEO cuando tu documentación es accesible desde varias URLs y evita problemas de contenido duplicado.

```json
"seo": {
    "metatags": {
        "canonical": "https://www.your-custom-domain-here.com"
    }
}
```

<div id="page-specific-meta-tags">
  ## Meta tags específicos de la página
</div>

Para definir meta tags específicos de la página, se añaden al frontmatter de la página.

Los siguientes meta tags se admiten a nivel de página:

* `title` - Título de la página
* `description` - La descripción de la página aparece debajo del título en la página y en algunos resultados de motores de búsqueda
* `keywords` - Palabras clave separadas por comas
* `og:title` - Título Open Graph para compartir en redes sociales
* `og:description` - Descripción Open Graph
* `og:image` - URL de la imagen Open Graph
* `og:url` - URL Open Graph
* `og:type` - Tipo de Open Graph, como &quot;article&quot; o &quot;website&quot;
* `og:image:width` - Ancho de la imagen Open Graph
* `og:image:height` - Altura de la imagen Open Graph
* `twitter:title` - Título de la tarjeta de Twitter
* `twitter:description` - Descripción de la tarjeta de Twitter
* `twitter:image` - Imagen de la tarjeta de Twitter
* `twitter:card` - Tipo de tarjeta de Twitter, como &quot;summary&quot; o &quot;summary&#95;large&#95;image&quot;
* `twitter:site` - Nombre de usuario del sitio en Twitter
* `twitter:image:width` - Ancho de la imagen de Twitter
* `twitter:image:height` - Altura de la imagen de Twitter
* `noindex` - Establecer en `true` para evitar la indexación por motores de búsqueda
* `robots` - Valor de la meta tag robots

```mdx
---
title: "Your example page title"
description: "Page-specific description"
"og:image": "link to your meta tag image"
"og:title": "Social media title"
keywords: ["keyword1", "keyword2"]
---
```

<Note>
  Las metaetiquetas con dos puntos deben estar entre comillas. El campo `keywords` debe estar formateado como una lista YAML.
</Note>

<div id="sitemaps-and-robotstxt-files">
  ## Sitemaps y archivos robots.txt
</div>

Mintlify genera automáticamente un archivo `sitemap.xml` y un archivo `robots.txt`. Puedes ver tu sitemap añadiendo `/sitemap.xml` a la URL de tu sitio de documentación.

Por defecto, solo se incluyen las páginas que aparecen en tu `docs.json`. Para incluir enlaces ocultos, añade `seo.indexing` a tu `docs.json`:

```json
"seo": {
    "indexing": "all"
}
```

<div id="custom-sitemaps-and-robotstxt-files">
  ### Sitemaps personalizados y archivos robots.txt
</div>

Para añadir un `sitemap.xml` o un archivo `robots.txt` personalizado, crea un archivo `sitemap.xml` o `robots.txt` en la raíz de tu proyecto. Al añadir un archivo personalizado, se reemplazará el archivo generado automáticamente con el mismo nombre. Si eliminas un archivo personalizado, se volverá a utilizar el archivo predeterminado.

<div id="disabling-indexing">
  ## Desactivar la indexación
</div>

Si quieres impedir que los motores de búsqueda indexen una página, puedes incluir lo siguiente en el [frontmatter](/es/organize/pages) de tu página:

```
---
noindex: true
---
```

También puedes especificar `noindex` para todas las páginas de tu documentación configurando el campo `metatags.robots` en `"noindex"` en tu `docs.json`:

```json
"seo": {
    "metatags": {
      "robots": "noindex"
    }
  }
```

<div id="seo-best-practices">
  ## Mejores prácticas de SEO
</div>

<AccordionGroup>
  <Accordion title="Escribe títulos y descripciones claros y descriptivos">
    * Usa títulos de página claros y descriptivos (50-60 caracteres)
    * Escribe descripciones atractivas (150-160 caracteres)
    * Incluye palabras clave relevantes
    * Haz que cada título y descripción de página sean únicos
  </Accordion>

  <Accordion title="Optimiza la estructura de tu contenido">
    * Usa una jerarquía de encabezados adecuada (H1 → H2 → H3)
    * Escribe primero para humanos, después para motores de búsqueda
    * Incluye palabras clave relevantes en encabezados y contenido
    * Mantén las URL cortas, descriptivas y organizadas jerárquicamente
    * Divide el contenido extenso con subtítulos y listas
  </Accordion>

  <Accordion title="Estrategia de enlaces internos">
    * Enlaza a páginas relacionadas dentro de tu documentación
    * Usa texto ancla descriptivo en lugar de &quot;haz clic aquí&quot;
    * Crea grupos temáticos enlazando conceptos relacionados
    * Usa las funciones automáticas de referencia cruzada
  </Accordion>

  <Accordion title="SEO para imágenes">
    * Usa nombres de archivo descriptivos para las imágenes
    * Incluye siempre texto alternativo para accesibilidad y SEO
    * Optimiza el tamaño de los archivos de imagen para una carga más rápida
    * Usa imágenes relevantes que respalden tu contenido
  </Accordion>
</AccordionGroup>
