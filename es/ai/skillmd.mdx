Mintlify aloja un archivo `skill.md` en la raíz de tu proyecto que describe lo que los agentes de IA pueden hacer con tu producto.

La [especificación de skill.md](https://agentskills.io/specification) es un formato estructurado y legible por máquinas que deja explícitas las capacidades, los datos de entrada necesarios y las restricciones de los productos para que los agentes puedan usarlos de forma más fiable.

Mintlify genera automáticamente un archivo `skill.md` para tu proyecto analizando tu documentación mediante un ciclo con agentes. Este archivo se mantiene actualizado a medida que haces cambios en tu documentación y no requiere mantenimiento. También puedes añadir opcionalmente un archivo `skill.md` personalizado en la raíz de tu proyecto para reemplazar el generado automáticamente.

Puedes ver tu `skill.md` añadiendo `/skill.md` a la URL de tu sitio de documentación. Mintlify solo genera archivos `skill.md` para sitios de documentación públicos.

<PreviewButton href="https://mintlify.com/docs/skill.md">Abre el archivo skill.md de este sitio.</PreviewButton>

<Tip>
  Tanto los archivos `llms.txt` como `skill.md` ayudan a los agentes a trabajar con tu documentación, pero cumplen funciones distintas.

  * `llms.txt` es un directorio. Enumera todas las páginas de tu documentación con descripciones para que los agentes sepan dónde encontrar la información.
  * `skill.md` es un resumen de capacidades. Les indica a los agentes qué pueden hacer con tu producto, qué datos de entrada necesitan y qué restricciones se aplican.
</Tip>

<div id="use-skillmd-files-with-agents">
  ## Usa archivos `skill.md` con agentes
</div>

<Note>
  Si usas un [proxy inverso](/es/deploy/reverse-proxy), configúralo para que reenvíe las rutas `/skill.md` y `/.well-known/skills/*` (con la caché desactivada) a tu subdominio de Mintlify.
</Note>

Los agentes pueden procesar tu `skill.md` con la [CLI de skills](https://www.npmjs.com/package/skills).

```bash
npx skills add https://your-docs-domain.com
```

Esto incorpora las capacidades de tu producto al contexto del agente para que pueda realizar acciones en nombre de los usuarios.

<Tip>
  Enseña a tus usuarios a usar archivos `skill.md` con agentes para obtener mejores resultados al usar tu producto con sus herramientas de IA.
</Tip>

<div id="skillmd-structure">
  ## Estructura de `skill.md`
</div>

Mintlify genera un archivo `skill.md` siguiendo la [especificación de agentskills.io](https://agentskills.io/specification). El archivo generado incluye:

* **Metadatos**: Nombre, descripción y versión del proyecto.
* **Capacidades**: Lo que los agentes pueden hacer con tu producto.
* **Habilidades**: Acciones específicas organizadas por categoría.
* **Flujos de trabajo**: Procedimientos paso a paso para tareas habituales.
* **Integración**: Herramientas y servicios compatibles.
* **Contexto**: Información sobre la arquitectura de tu producto.

<div id="custom-skillmd-files">
  ## Archivos `skill.md` personalizados
</div>

Agrega un archivo `skill.md` en la raíz de tu proyecto para reemplazar el archivo generado automáticamente. Si eliminas un archivo personalizado, Mintlify genera un nuevo archivo `skill.md`.

Escribe un archivo personalizado cuando quieras tener un control preciso sobre cómo los agentes interactúan con tu producto. Sigue la [especificación de agentskills.io](https://agentskills.io/specification) para garantizar la compatibilidad con las herramientas de agentes.

<div id="frontmatter-fields">
  ### Campos de Frontmatter
</div>

Los archivos `skill.md` personalizados deben comenzar con un Frontmatter YAML.

| Campo           | Tipo   | Descripción                                                                                             |
| --------------- | ------ | ------------------------------------------------------------------------------------------------------- |
| `name`          | string | El nombre de tu habilidad.                                                                              |
| `description`   | string | Una breve descripción de lo que hace tu habilidad.                                                      |
| `license`       | string | La licencia de tu habilidad (por ejemplo, `MIT` o `Apache-2.0`).                                        |
| `compatibility` | string | Requisitos o notas de compatibilidad (por ejemplo, dependencias del entorno de ejecución).              |
| `metadata`      | object | Metadatos adicionales como pares clave-valor de cadenas de texto (por ejemplo, `author` o `version`).   |
| `allowed-tools` | string | Lista de herramientas preaprobadas, separadas por espacios, que la habilidad puede usar (experimental). |

```md Example frontmatter
---
name: mintlify
description: Build and maintain documentation sites with Mintlify. Use when creating docs pages, configuring navigation, adding components, or setting up API references.
license: MIT
compatibility: Requires Node.js for CLI. Works with any Git-based workflow.
metadata:
  author: mintlify
  version: "1.0"
---
```
