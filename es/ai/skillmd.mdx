Mintlify aloja un archivo `skill.md` en la raíz de tu proyecto que describe qué pueden hacer los agentes de IA con tu producto.

La [especificación de skill.md](https://agentskills.io/specification) es un formato estructurado y legible por máquinas que hace explícitas las capacidades, los inputs requeridos y las restricciones de los productos, de modo que los agentes puedan utilizarlos de forma más fiable.

Mintlify genera automáticamente un archivo `skill.md` para tu proyecto analizando tu documentación con un bucle basado en agentes. Este archivo se mantiene actualizado a medida que realizas cambios en tu documentación y no requiere mantenimiento. Opcionalmente, puedes añadir un archivo `skill.md` personalizado en la raíz de tu proyecto que reemplace al generado automáticamente.

Visualiza tu `skill.md` añadiendo `/skill.md` a la URL del sitio de tu documentación. Mintlify solo genera archivos `skill.md` para sitios de documentación públicos.

<PreviewButton href="https://mintlify.com/docs/skill.md">Abrir el skill.md de este sitio.</PreviewButton>

<Tip>
  Los archivos `llms.txt` y `skill.md` ayudan a los agentes a trabajar con tu documentación, pero cumplen funciones diferentes.

  * `llms.txt` es un directorio. Enumera todas las páginas de tu documentación con descripciones para que los agentes sepan dónde encontrar información.
  * `skill.md` es un resumen de capacidades. Indica a los agentes qué pueden lograr con tu producto, qué inputs necesitan y qué restricciones se aplican.
</Tip>

<div id="use-skillmd-files-with-agents">
  ## Utiliza archivos `skill.md` con agentes
</div>

<Note>
  Si utilizas un [proxy inverso](/es/deploy/reverse-proxy), configúralo para reenviar las rutas `/skill.md` y `/.well-known/skills/*` (con la caché desactivada) a tu subdominio de Mintlify.
</Note>

Los agentes pueden procesar tu `skill.md` con la [CLI de skills](https://www.npmjs.com/package/skills).

```bash
npx skills add https://your-docs-domain.com
```

Esto agrega las capacidades de tu producto al contexto del agente para que pueda realizar acciones en nombre de los usuarios.

<Tip>
  Enseña a tus usuarios a usar archivos `skill.md` con agentes, para que obtengan mejores resultados al utilizar tu producto con sus herramientas de IA.
</Tip>

<div id="skillmd-structure">
  ## Estructura de `skill.md`
</div>

Mintlify genera un archivo `skill.md` siguiendo la [especificación de agentskills.io](https://agentskills.io/specification). El archivo generado incluye:

* **Metadata**: Nombre del proyecto, descripción y versión.
* **Capabilities**: Qué pueden hacer los agentes con tu producto.
* **Skills**: Acciones específicas organizadas por categoría.
* **Workflows**: Procedimientos paso a paso para tareas habituales.
* **Integration**: Herramientas y servicios compatibles.
* **Context**: Contexto sobre la arquitectura de tu producto.

<div id="custom-skillmd-files">
  ## Archivos personalizados `skill.md`
</div>

Añade un archivo `skill.md` a la raíz de tu proyecto para reemplazar el archivo generado automáticamente. Si eliminas un archivo personalizado, Mintlify genera un nuevo archivo `skill.md`.

Crea un archivo personalizado cuando quieras tener un control preciso sobre cómo los agentes interactúan con tu producto. Sigue la [especificación de agentskills.io](https://agentskills.io/specification) para garantizar la compatibilidad con las herramientas para agentes.

<div id="frontmatter-fields">
  ### Campos de frontmatter
</div>

Los archivos personalizados `skill.md` deben comenzar con frontmatter YAML.

| Campo           | Tipo   | Descripción                                                                                           |
| --------------- | ------ | ----------------------------------------------------------------------------------------------------- |
| `name`          | string | El nombre de tu skill.                                                                                |
| `description`   | string | Una breve descripción de lo que hace tu skill.                                                        |
| `license`       | string | La licencia de tu skill (por ejemplo, `MIT` o `Apache-2.0`).                                          |
| `compatibility` | string | Requisitos o notas de compatibilidad (por ejemplo, dependencias en tiempo de ejecución).              |
| `metadata`      | object | Metadatos adicionales como pares clave-valor de cadenas de texto (por ejemplo, `author` o `version`). |
| `allowed-tools` | string | Lista delimitada por espacios de herramientas preaprobadas que la skill puede usar (experimental).    |

```md Example frontmatter
---
name: mintlify
description: Build and maintain documentation sites with Mintlify. Use when creating docs pages, configuring navigation, adding components, or setting up API references.
license: MIT
compatibility: Requires Node.js for CLI. Works with any Git-based workflow.
metadata:
  author: mintlify
  version: "1.0"
---
```
