<div id="about-mcp-servers">
  ## Sobre los servidores MCP
</div>

El Model Context Protocol (MCP) es un protocolo abierto que crea conexiones estandarizadas entre aplicaciones de IA y servicios externos, como la documentación. Mintlify genera un servidor MCP a partir de tu documentación, preparando tu contenido para el ecosistema de IA en general, donde cualquier cliente MCP, como Claude, Cursor, Goose, ChatGPT y otros, puede conectarse a tu documentación.

Tu servidor MCP expone una herramienta de búsqueda para que las aplicaciones de IA puedan consultar tu documentación. Tus usuarios deben conectar tu servidor MCP a sus herramientas.

<div id="how-mcp-servers-work">
  ### Cómo funcionan los servidores MCP
</div>

Cuando una aplicación de IA se conecta a tu servidor MCP de documentación, puede buscar directamente en tu documentación en lugar de hacer una búsqueda web genérica como respuesta a la consulta de un usuario. Tu servidor MCP proporciona acceso a todo el contenido indexado de tu sitio de documentación.

* La aplicación de IA puede buscar proactivamente en tu documentación mientras genera una respuesta, no solo cuando se le pide explícitamente.
* La aplicación de IA determina cuándo usar la herramienta de búsqueda según el contexto de la conversación y la relevancia de tu documentación.
* Cada búsqueda (llamada a herramienta) se realiza durante el proceso de generación, de modo que la aplicación de IA consulta información actualizada de tu documentación para generar su respuesta.

<Tip>
  Algunas herramientas de IA como Claude son compatibles tanto con MCP como con Skills. MCP da a la IA acceso al contenido de tu documentación, mientras que Skills indican a la IA cómo usar ese contenido de forma eficaz. Son complementarias: MCP proporciona los datos y Skills proporcionan las instrucciones.
</Tip>

<div id="search-filtering-parameters">
  ### Parámetros de filtrado de búsqueda
</div>

La herramienta de búsqueda MCP admite parámetros de filtrado opcionales que las aplicaciones de IA pueden usar para acotar los resultados de la búsqueda.

* **`version`**: Filtra los resultados para una versión específica de la documentación. Por ejemplo, `'v0.7'`. Solo devuelve contenido etiquetado con la versión especificada o contenido disponible en todas las versiones.
* **`language`**: Filtra los resultados para un código de idioma específico. Por ejemplo, `'en'`, `'zh'` o `'es'`. Solo devuelve contenido en el idioma especificado o contenido disponible en todos los idiomas.
* **`apiReferenceOnly`**: Cuando está establecido en `true`, solo devuelve páginas de documentación de referencia de la API.
* **`codeOnly`**: Cuando está establecido en `true`, solo devuelve fragmentos de código y ejemplos.

Las aplicaciones de IA determinan cuándo aplicar estos filtros según el contexto de la consulta del usuario. Por ejemplo, si un usuario pregunta por una versión específica de la API o solicita ejemplos de código, la aplicación de IA puede aplicar automáticamente los filtros apropiados para ofrecer resultados más relevantes.

<div id="mcp-compared-to-web-search">
  ### MCP comparado con la búsqueda en la web
</div>

Las herramientas de IA pueden buscar en la web, pero MCP ofrece ventajas claras para la documentación.

* **Acceso directo a la fuente**: La búsqueda en la web depende de lo que los motores de búsqueda han indexado, lo cual puede estar obsoleto o incompleto. MCP busca directamente en tu documentación indexada actual.
* **Flujo de trabajo integrado**: MCP permite que la IA busque mientras genera la respuesta, en lugar de tener que realizar una búsqueda en la web por separado.
* **Sin ruido de búsqueda**: El SEO y los algoritmos de clasificación influyen en los resultados de la búsqueda en la web. MCP va directamente al contenido de tu documentación.

<div id="access-your-mcp-server">
  ## Accede a tu servidor MCP
</div>

<Note>
  Los servidores MCP solo están disponibles para documentación pública. La documentación protegida mediante autenticación de usuario final no puede generar un servidor MCP.
</Note>

Mintlify genera automáticamente un servidor MCP para tu documentación y lo aloja en la URL de tu documentación con la ruta `/mcp`. Por ejemplo, el servidor MCP de Mintlify está disponible en `https://mintlify.com/docs/mcp`.

Consulta y copia la URL de tu servidor MCP en la [página del servidor MCP](https://dashboard.mintlify.com/products/mcp) de tu panel de control.

</Note>

<div id="content-filtering-and-indexing">
  ## Filtrado e indexación de contenido
</div>

Tu servidor MCP busca el contenido que Mintlify indexa en tu repositorio de documentación. El procesamiento de archivos y la indexación de búsqueda determinan qué contenido está disponible a través de tu servidor MCP.

<div id="file-processing-with-mintignore">
  ### Procesamiento de archivos con `.mintignore`
</div>

Si los archivos coinciden con los patrones de [.mintignore](/es/organize/mintignore), Mintlify no los procesa ni los indexa. Estos archivos no están disponibles mediante tu servidor MCP.

<div id="search-indexing-with-docsjson">
  ### Indexación de búsqueda con `docs.json`
</div>

De forma predeterminada, Mintlify solo indexa para las búsquedas a través de tu servidor MCP las páginas incluidas en la navegación de tu `docs.json`.

Mintlify excluye [páginas ocultas](/es/organize/hidden-pages) (páginas que no están en tu navegación) del índice de búsqueda, a menos que elijas indexar todas las páginas. Para incluir páginas ocultas en los resultados de búsqueda de tu servidor MCP, agrega la propiedad `seo.indexing` a tu `docs.json`.

```json
"seo": {
    "indexing": "all"
}
```

Para excluir una página específica de la indexación en buscadores, agrega `noindex: true` al frontmatter de la página.

```mdx
---
title: "Página oculta"
description: "Esta página no está en la navegación y no está disponible a través de la búsqueda."
noindex: true
---
```

<div id="use-your-mcp-server">
  ## Usa tu servidor MCP
</div>

Tus usuarios deben conectar tu servidor MCP con sus herramientas de IA preferidas.

1. Haz pública la URL de tu servidor MCP.
2. Los usuarios copian la URL de tu servidor MCP y la añaden a sus herramientas.
3. Los usuarios acceden a tu documentación a través de sus herramientas.

Estas son algunas de las formas en que puedes ayudar a tus usuarios a conectarse a tu servidor MCP:

<Tabs>
  <Tab title="Menú contextual">
    Añade opciones en el [menú contextual](/es/ai/contextual-menu) para que tus usuarios se conecten a tu servidor MCP desde cualquier página de tu documentación.

    | Opción | Identificador | Descripción |
    | :----- | :------------ | :---------- |
    | **Copy MCP server URL** | `mcp` | Copia la URL de tu servidor MCP en el portapapeles del usuario. |
    | **Connect to Cursor** | `cursor` | Instala tu servidor MCP en Cursor. |
    | **Connect to VS Code** | `vscode` | Instala tu servidor MCP en VS Code. |
  </Tab>

  <Tab title="Claude">
    <Steps>
      <Step title="Obtén la URL de tu servidor MCP.">
        Ve a tu [dashboard](https://dashboard.mintlify.com/products/mcp) y encuentra la URL de tu servidor MCP.
      </Step>

      <Step title="Publica la URL de tu servidor MCP para tus usuarios.">
        Crea una guía para tus usuarios que incluya la URL de tu servidor MCP y los pasos para conectarlo a Claude.

        1. Ve a la página [Connectors](https://claude.ai/settings/connectors) en la configuración de Claude.
        2. Selecciona **Add custom connector**.
        3. Añade el nombre y la URL de tu servidor MCP.
        4. Selecciona **Add**.
        5. Al usar Claude, selecciona el botón de adjuntos (el icono de sumar).
        6. Selecciona tu servidor MCP.
      </Step>
    </Steps>

    Consulta la [documentación de Model Context Protocol](https://modelcontextprotocol.io/docs/tutorials/use-remote-mcp-server#connecting-to-a-remote-mcp-server) para obtener más información.
  </Tab>

  <Tab title="Claude Code">
    <Steps>
      <Step title="Obtén la URL de tu servidor MCP.">
        Ve a tu [dashboard](https://dashboard.mintlify.com/products/mcp) y encuentra la URL de tu servidor MCP.
      </Step>

      <Step title="Publica la URL de tu servidor MCP para tus usuarios.">
        Crea una guía para tus usuarios que incluya la URL de tu servidor MCP y el comando para conectarlo a Claude Code.

        ```bash
        claude mcp add --transport http <name> <url>
        ```
      </Step>
    </Steps>

    Consulta la [documentación de Claude Code](https://docs.anthropic.com/en/docs/claude-code/mcp#installing-mcp-servers) para obtener más información.
  </Tab>

  <Tab title="Cursor">
    <Steps>
      <Step title="Obtén la URL de tu servidor MCP.">
        Ve a tu [dashboard](https://dashboard.mintlify.com/products/mcp) y encuentra la URL de tu servidor MCP.
      </Step>

      <Step title="Publica la URL de tu servidor MCP para tus usuarios.">
        Crea una guía para tus usuarios que incluya la URL de tu servidor MCP y los pasos para conectarlo a Cursor.

        1. Usa <kbd>Command</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> en Windows) para abrir la paleta de comandos.
        2. Busca &quot;Open MCP settings&quot;.
        3. Selecciona **Add custom MCP**. Esto abrirá el archivo `mcp.json`.
        4. En `mcp.json`, configura tu servidor:

        ```json
        {
          "mcpServers": {
            "<your-mcp-server-name>": {
              "url": "<your-mcp-server-url>"
            }
          }
        }
        ```
      </Step>
    </Steps>

    Consulta la [documentación de Cursor](https://docs.cursor.com/en/context/mcp#installing-mcp-servers) para obtener más información.
  </Tab>

  <Tab title="VS Code">
    <Steps>
      <Step title="Obtén la URL de tu servidor MCP.">
        Ve a tu [dashboard](https://dashboard.mintlify.com/products/mcp) y encuentra la URL de tu servidor MCP.
      </Step>

      <Step title="Publica la URL de tu servidor MCP para tus usuarios.">
        Crea una guía para tus usuarios que incluya la URL de tu servidor MCP y los pasos para conectarlo a VS Code.

        1. Crea un archivo `.vscode/mcp.json`.
        2. En `mcp.json`, configura tu servidor:

        ```json
        {
          "servers": {
            "<your-mcp-server-name>": {
              "type": "http",
              "url": "<your-mcp-server-url>"
            }
          }
        }
        ```
      </Step>
    </Steps>

    Consulta la [documentación de VS Code](https://code.visualstudio.com/docs/copilot/chat/mcp-servers) para obtener más información.
  </Tab>
</Tabs>

<div id="using-multiple-mcp-servers">
  ### Uso de múltiples servidores MCP
</div>

Los usuarios pueden conectar varios servidores MCP a sus herramientas de IA. Los servidores MCP conectados no consumen contexto hasta que la IA utiliza una herramienta de búsqueda. La IA decide cuándo buscar según la relevancia de la consulta, por lo que no busca en cada servidor conectado para cada pregunta.

Cuando la IA realiza una búsqueda, cada consulta devuelve varios resultados que se añaden al contexto de la conversación. Si la IA busca en varios servidores para una sola pregunta, esto puede consumir una cantidad significativa de contexto.

Mejores prácticas para usar múltiples servidores MCP:

* Conecta solo los servidores MCP relevantes para tu trabajo actual.
* Sé específico en tus instrucciones para que la IA busque en el servidor más relevante.
* Desconecta los servidores que no estés utilizando activamente para reducir el posible uso de contexto.
