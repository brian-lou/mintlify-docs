<div id="about-mcp-servers">
  ## Sobre los servidores MCP
</div>

El Model Context Protocol (MCP) es un protocolo abierto que crea conexiones estandarizadas entre aplicaciones de IA y servicios externos, como la documentación. Mintlify genera un servidor MCP a partir de tu documentación y prepara tu contenido para el ecosistema más amplio de la IA, donde cualquier cliente MCP, como Claude, Cursor, Goose, ChatGPT y otros, puede conectarse a tu documentación.

Tu servidor MCP expone una herramienta de búsqueda para que las aplicaciones de IA consulten tu documentación. Tus usuarios deben conectar tu servidor MCP a sus herramientas.

<div id="how-mcp-servers-work">
  ### Cómo funcionan los servidores MCP
</div>

Cuando una aplicación de IA se conecta a tu servidor MCP de documentación, puede buscar directamente en tu documentación en lugar de hacer una búsqueda web genérica en respuesta al `prompt` de un usuario. Tu servidor MCP proporciona acceso a todo el contenido indexado de tu sitio de documentación.

* La aplicación de IA puede buscar de forma proactiva en tu documentación mientras genera una respuesta, no solo cuando se le pide explícitamente.
* La aplicación de IA determina cuándo usar la herramienta de búsqueda en función del contexto de la conversación y de la relevancia de tu documentación.
* Cada búsqueda (llamada a la herramienta) se realiza durante el proceso de generación, por lo que la aplicación de IA consulta información actualizada de tu documentación para generar su respuesta.

<Tip>
  Algunas herramientas de IA, como Claude, son compatibles tanto con MCP como con Skills. MCP le da a la IA acceso al contenido de tu documentación, mientras que Skills le indican a la IA cómo usar ese contenido de forma eficaz. Son complementarios. MCP proporciona los datos y Skills proporcionan las instrucciones.
</Tip>

<div id="search-filtering-parameters">
  ### Parámetros de filtrado de búsqueda
</div>

La herramienta de búsqueda de MCP admite parámetros de filtrado opcionales que las aplicaciones de IA pueden usar para acotar los resultados de búsqueda.

* **`version`**: Limita los resultados a una versión específica de la documentación. Por ejemplo, `'v0.7'`. Solo devuelve contenido etiquetado con la versión especificada o contenido disponible en todas las versiones.
* **`language`**: Limita los resultados a un código de idioma específico. Por ejemplo, `'en'`, `'zh'` o `'es'`. Solo devuelve contenido en el idioma especificado o contenido disponible en todos los idiomas.
* **`apiReferenceOnly`**: Cuando se establece en `true`, solo devuelve páginas de referencia de la API.
* **`codeOnly`**: Cuando se establece en `true`, solo devuelve fragmentos de código y ejemplos.

Las aplicaciones de IA determinan cuándo aplicar estos filtros según el contexto de la consulta del usuario. Por ejemplo, si un usuario pregunta por una versión específica de la API o solicita ejemplos de código, la aplicación de IA puede aplicar automáticamente los filtros adecuados para ofrecer resultados más relevantes.

<div id="mcp-compared-to-web-search">
  ### MCP frente a la búsqueda web
</div>

Las herramientas de IA pueden buscar en la web, pero MCP ofrece ventajas específicas para la documentación.

* **Acceso directo a la fuente**: La búsqueda web depende de lo que los motores de búsqueda hayan indexado, que puede estar desactualizado o incompleto. MCP busca directamente en la versión actual indexada de tu documentación.
* **Flujo de trabajo integrado**: MCP permite que la IA busque mientras genera la respuesta, en lugar de hacer una búsqueda web por separado.
* **Sin ruido en la búsqueda**: El SEO y los algoritmos de clasificación influyen en los resultados de búsqueda web. MCP va directo al contenido de tu documentación.

<div id="access-your-mcp-server">
  ## Accede a tu servidor MCP
</div>

<Note>
  Los servidores MCP solo están disponibles para documentación pública. La documentación protegida con autenticación de usuario final no puede generar un servidor MCP.
</Note>

Mintlify genera automáticamente un servidor MCP para tu documentación y lo aloja en la URL de tu documentación con la ruta `/mcp`. Por ejemplo, el servidor MCP de Mintlify está disponible en `https://mintlify.com/docs/mcp`.

Consulta y copia la URL de tu servidor MCP en la [página del servidor MCP](https://dashboard.mintlify.com/products/mcp) de tu panel de control.

</Frame>

<Note>
  Los servidores MCP alojados usan la ruta `/mcp` en sus URL. Ningún otro elemento de navegación puede usar la ruta `/mcp`.
</Note>

<div id="content-filtering-and-indexing">
  ## Filtrado e indexación del contenido
</div>

Tu servidor MCP busca en el contenido que Mintlify indexa desde tu repositorio de documentación. El procesamiento de archivos y la indexación de búsquedas determinan qué contenido está disponible a través de tu servidor MCP.

<div id="file-processing-with-mintignore">
  ### Procesamiento de archivos con `.mintignore`
</div>

Si los archivos coinciden con los patrones de [.mintignore](/es/organize/mintignore), Mintlify no los procesa ni los indexa. Estos archivos no estarán disponibles a través de tu servidor MCP.

<div id="search-indexing-with-docsjson">
  ### Indexación de búsquedas con `docs.json`
</div>

De forma predeterminada, Mintlify solo indexa las páginas incluidas en la navegación de tu `docs.json` para las búsquedas a través de tu servidor MCP.

Mintlify excluye las [páginas ocultas](/es/organize/hidden-pages) (las páginas que no están en tu navegación) del índice de búsqueda, a menos que decidas indexar todas las páginas. Para incluir páginas ocultas en los resultados de búsqueda de tu servidor MCP, añade la propiedad `seo.indexing` a tu `docs.json`.

```json
"seo": {
    "indexing": "all"
}
```

Para excluir una página específica de la indexación de búsqueda, agrega `noindex: true` en su Frontmatter.

```mdx
---
title: "Página oculta"
description: "Esta página no está en la navegación y no está disponible en la búsqueda."
noindex: true
---
```

<div id="use-your-mcp-server">
  ## Usa tu servidor MCP
</div>

Tus usuarios deben conectar tu servidor MCP a las herramientas de IA que prefieran.

1. Haz pública la URL de tu servidor MCP.
2. Los usuarios copian la URL de tu servidor MCP y la agregan a sus herramientas.
3. Los usuarios acceden a tu documentación desde sus herramientas.

Estas son algunas formas de ayudar a tus usuarios a conectarse a tu servidor MCP:

<Tabs>
  <Tab title="Menú contextual">
    Agrega opciones en el [menú contextual](/es/ai/contextual-menu) para que tus usuarios puedan conectarse a tu servidor MCP desde cualquier página de tu documentación.

    | Opción                          | Identificador | Descripción                                                     |
    | :------------------------------ | :------------ | :-------------------------------------------------------------- |
    | **Copiar URL del servidor MCP** | `mcp`         | Copia la URL de tu servidor MCP en el portapapeles del usuario. |
    | **Conectar a Cursor**           | `cursor`      | Instala tu servidor MCP en Cursor.                              |
    | **Conectar a VS Code**          | `vscode`      | Instala tu servidor MCP en VS Code.                             |
  </Tab>

  <Tab title="Claude">
    <Steps>
      <Step title="Obtén la URL de tu servidor MCP.">
        Ve a tu [panel de control](https://dashboard.mintlify.com/products/mcp) y busca la URL de tu servidor MCP.
      </Step>

      <Step title="Publica la URL de tu servidor MCP para tus usuarios.">
        Crea una guía para tus usuarios que incluya la URL de tu servidor MCP y los pasos para conectarlo a Claude.

        1. Ve a la página [Connectors](https://claude.ai/settings/connectors) en la configuración de Claude.
        2. Selecciona **Add custom connector**.
        3. Agrega el nombre y la URL de tu servidor MCP.
        4. Selecciona **Add**.
        5. Al usar Claude, selecciona el botón de archivos adjuntos (el icono de más).
        6. Selecciona tu servidor MCP.
      </Step>
    </Steps>

    Consulta la [documentación de Model Context Protocol](https://modelcontextprotocol.io/docs/tutorials/use-remote-mcp-server#connecting-to-a-remote-mcp-server) para obtener más información.
  </Tab>

  <Tab title="Claude Code">
    <Steps>
      <Step title="Obtén la URL de tu servidor MCP.">
        Ve a tu [panel de control](https://dashboard.mintlify.com/products/mcp) y busca la URL de tu servidor MCP.
      </Step>

      <Step title="Publica la URL de tu servidor MCP para tus usuarios.">
        Crea una guía para tus usuarios que incluya la URL de tu servidor MCP y el comando para conectarlo a Claude Code.

        ```bash
        claude mcp add --transport http <name> <url>
        ```
      </Step>
    </Steps>

    Consulta la [documentación de Claude Code](https://docs.anthropic.com/en/docs/claude-code/mcp#installing-mcp-servers) para obtener más información.
  </Tab>

  <Tab title="Cursor">
    <Steps>
      <Step title="Obtén la URL de tu servidor MCP.">
        Ve a tu [panel de control](https://dashboard.mintlify.com/products/mcp) y busca la URL de tu servidor MCP.
      </Step>

      <Step title="Publica la URL de tu servidor MCP para tus usuarios.">
        Crea una guía para tus usuarios que incluya la URL de tu servidor MCP y los pasos para conectarlo a Cursor.

        1. Usa <kbd>Command</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> en Windows) para abrir la paleta de comandos.
        2. Busca &quot;Open MCP settings&quot;.
        3. Selecciona **Add custom MCP**. Se abrirá el archivo `mcp.json`.
        4. En `mcp.json`, configura tu servidor:

        ```json
        {
          "mcpServers": {
            "<your-mcp-server-name>": {
              "url": "<your-mcp-server-url>"
            }
          }
        }
        ```
      </Step>
    </Steps>

    Consulta la [documentación de Cursor](https://docs.cursor.com/en/context/mcp#installing-mcp-servers) para obtener más información.
  </Tab>

  <Tab title="VS Code">
    <Steps>
      <Step title="Obtén la URL de tu servidor MCP.">
        Ve a tu [panel de control](https://dashboard.mintlify.com/products/mcp) y busca la URL de tu servidor MCP.
      </Step>

      <Step title="Publica la URL de tu servidor MCP para tus usuarios.">
        Crea una guía para tus usuarios que incluya la URL de tu servidor MCP y los pasos para conectarlo a VS Code.

        1. Crea un archivo `.vscode/mcp.json`.
        2. En `mcp.json`, configura tu servidor:

        ```json
        {
          "servers": {
            "<your-mcp-server-name>": {
              "type": "http",
              "url": "<your-mcp-server-url>"
            }
          }
        }
        ```
      </Step>
    </Steps>

    Consulta la [documentación de VS Code](https://code.visualstudio.com/docs/copilot/chat/mcp-servers) para obtener más información.
  </Tab>
</Tabs>

<div id="using-multiple-mcp-servers">
  ### Usar varios servidores MCP
</div>

Los usuarios pueden conectar varios servidores MCP a sus herramientas de IA. Los servidores MCP conectados no consumen contexto hasta que la IA llama a una herramienta de búsqueda. La IA decide cuándo buscar en función de la relevancia de la consulta, por lo que no busca en todos los servidores conectados para cada pregunta.

Cuando la IA realiza una búsqueda, cada consulta devuelve varios resultados que se añaden al contexto de la conversación. Si la IA busca en varios servidores para una sola pregunta, esto puede consumir una cantidad considerable de contexto.

Prácticas recomendadas para usar varios servidores MCP:

* Conecta solo los servidores MCP relevantes para la tarea en la que estés trabajando.
* Sé específico en tus prompts para que la IA busque en el servidor más relevante.
* Desconecta los servidores que no estés usando activamente para reducir el posible consumo de contexto.
