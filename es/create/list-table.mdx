<div id="lists">
  ## Listas
</div>

Las listas siguen la [sintaxis oficial de Markdown](https://www.markdownguide.org/basic-syntax/#lists-1).

<div id="ordered-list">
  ### Lista ordenada
</div>

Para crear una lista ordenada, añade números seguidos de un punto antes de los elementos de la lista.

1. Primer elemento
2. Segundo elemento
3. Tercer elemento
4. Cuarto elemento

```mdx
1. First item
2. Second item
3. Third item
4. Fourth item
```


<div id="unordered-list">
  ### Lista no ordenada
</div>

Para crear una lista no ordenada, añade guiones (`-`), asteriscos (`*`) o el signo más (`+`) antes de los elementos de la lista.

* Primer elemento
* Segundo elemento
* Tercer elemento
* Cuarto elemento

```mdx
- First item
- Second item
- Third item
- Fourth item
```


<div id="nested-list">
  ### Lista anidada
</div>

Indenta los elementos de la lista para anidarlos.

* Primer elemento
* Segundo elemento
  * Elemento adicional
  * Elemento adicional
* Tercer elemento

```mdx
- First item
- Second item
  - Additional item
  - Additional item
- Third item
```


<div id="tables">
  ## Tablas
</div>

Las tablas siguen la [sintaxis oficial de Markdown](https://www.markdownguide.org/extended-syntax/#tables).

Para añadir una tabla, usa tres o más guiones (`---`) para crear la cabecera de cada columna y usa barras verticales (`|`) para separar cada columna. Para mayor compatibilidad, también debes añadir una barra vertical al principio y al final de la fila.

| Property | Description                                 |
| -------- | ------------------------------------------- |
| Name     | Nombre completo del usuario                 |
| Age      | Edad indicada                               |
| Joined   | Indica si el usuario se unió a la comunidad |

```mdx
| Property | Description                           |
| -------- | ------------------------------------- |
| Name     | Full name of user                     |
| Age      | Reported age                          |
| Joined   | Whether the user joined the community |
```


<div id="column-alignment">
  ### Alineación de columnas
</div>

Usa dos puntos en la fila de separación para alinear el contenido de las columnas:

| Alineado a la izquierda | Centrado | Alineado a la derecha |
| :---------------------- | :------: | --------------------: |
| Izquierda               |  Centro  |               Derecha |
| Texto                   |   Texto  |                 Texto |

```mdx
| Left aligned | Center aligned | Right aligned |
| :----------- | :------------: | ------------: |
| Left         | Center         | Right         |
| Text         | Text           | Text          |
```
