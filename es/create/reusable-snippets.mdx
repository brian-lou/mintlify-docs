Uno de los principios fundamentales del desarrollo de software es DRY (No te repitas), y también se aplica a la documentación. Si ves que repites el mismo contenido en varios lugares, crea un snippet personalizado para ese contenido. Los snippets contienen contenido que puedes importar en otros archivos para reutilizarlo. Tú decides dónde aparece el snippet en una página. Si alguna vez necesitas actualizar ese contenido, solo tienes que editar el snippet en lugar de hacerlo en cada archivo donde se usa.

<div id="how-snippets-work">
  ## Cómo funcionan los snippets
</div>

Los snippets son archivos `.mdx`, `.md` o `.jsx` que se importan en otro archivo. Puedes colocar los archivos de snippet en cualquier parte de tu proyecto.

Cuando importas un snippet en otro archivo, solo aparece donde lo importas y no se muestra como una página independiente. Cualquier archivo de la carpeta `/snippets/` siempre es un snippet, aunque no se importe en otro archivo.

<div id="create-snippets">
  ## Crear snippets
</div>

Crea un archivo con el contenido que quieras reutilizar. Los snippets pueden incluir todos los tipos de contenido compatibles con Mintlify y pueden importar otros snippets.

<div id="import-snippets-into-pages">
  ## Importa Snippets en páginas
</div>

Importa Snippets en páginas con una ruta absoluta o relativa.

* **Importaciones absolutas**: Comienzan con `/` para importar desde la raíz de tu proyecto.
* **Importaciones relativas**: Usa `./` o `../` para importar Snippets en relación con la ubicación del archivo actual.

<Tip>
  Las importaciones relativas permiten la navegación del IDE. Presiona <kbd>CMD</kbd> y haz clic en el nombre de un Snippet en tu editor para ir directamente a la definición del Snippet.
</Tip>

<div id="import-text">
  ### Importar texto
</div>

1. Agrega al archivo del snippet el contenido que quieras reutilizar.

   ```mdx shared/my-snippet.mdx wrap
   ¡Hola, mundo! Este es el contenido que quiero reutilizar en varias páginas.
   ```

2. Importa el snippet en el archivo de destino con una ruta absoluta o relativa.

   <CodeGroup>
     ```mdx Importación absoluta
     ---
     title: "Una página de ejemplo"
     description: "Esta es una página de ejemplo que importa un snippet."
     ---

     import MySnippet from "/shared/my-snippet.mdx";

     El contenido del snippet se muestra debajo de esta frase.

     <MySnippet />
     ```

     ```mdx Importación relativa
     ---
     title: "Una página de ejemplo"
     description: "Esta es una página de ejemplo que importa un snippet."
     ---

     import MySnippet from "../shared/my-snippet.mdx";

     El contenido del snippet se muestra debajo de esta frase.

     <MySnippet />
     ```
   </CodeGroup>

<div id="import-variables">
  ### Importar variables
</div>

Haz referencia a variables de un snippet en una página.

1. Exporta variables desde un archivo de snippet.

   ```mdx shared/custom-variables.mdx
   export const myName = "Ronan";

   export const myObject = { fruit: "strawberries" };

   ;
   ```

2. Importa el snippet en tu archivo de destino y usa la variable.

   ```mdx destination-file.mdx
   ---
   title: "An example page"
   description: "This is an example page that imports a snippet with variables."
   ---

   import { myName, myObject } from "/shared/custom-variables.mdx";

   Hello, my name is {myName} and I like {myObject.fruit}.
   ```

<div id="import-snippets-with-variables">
  ### Importa snippets con variables
</div>

Usa variables para pasar datos a un snippet al importarlo.

1. Agrega variables a tu snippet y pasa propiedades al importarlo. En este ejemplo, la variable es `{word}`.

   ```mdx shared/my-snippet.mdx
   My keyword of the day is {word}.
   ```

2. Importa el snippet en tu archivo de destino con la variable. La propiedad que pases reemplaza la variable en la definición del snippet.

   ```mdx destination-file.mdx
   ---
   title: "An example page"
   description: "This is an example page that imports a snippet with a variable."
   ---

   import MySnippet from "/shared/my-snippet.mdx";

   <MySnippet word="bananas" />
   ```

<div id="import-react-components">
  ### Importar componentes de React
</div>

1. Crea un snippet con un componente JSX. Consulta [componentes de React](/es/customize/react-components) para más información.

   ```js components/my-jsx-snippet.jsx
   export const MyJSXSnippet = () => {
     return (
       <div>
         <h1>Hello, world!</h1>
       </div>
     );
   };
   ```

<Note>
  Al crear snippets de JSX, usa la sintaxis de función flecha (`=>`) en lugar de declaraciones de función. La palabra clave `function` no se admite en los snippets.
</Note>

2. Importa el snippet.

   ```mdx destination-file.mdx
   ---
   title: "Una página de ejemplo"
   description: "Esta es una página de ejemplo que importa un snippet con un componente de React."
   ---

   import { MyJSXSnippet } from "/components/my-jsx-snippet.jsx";

   <MyJSXSnippet />
   ```
