Uno de los principios fundamentales del desarrollo de software es DRY (Don&#39;t Repeat Yourself), que también se aplica a la documentación. Si te encuentras repitiendo el mismo contenido en varios lugares, crea un fragmento personalizado para ese contenido. Los fragmentos incluyen contenido que puedes importar en otros archivos para reutilizarlo. Tú controlas dónde aparece el fragmento en una página. Si alguna vez necesitas actualizar el contenido, solo tendrás que editar el fragmento en lugar de cada archivo donde se use.

<div id="how-snippets-work">
  ## Cómo funcionan los snippets
</div>

Los snippets son archivos `.mdx`, `.md` o `.jsx` que se importan en otro archivo. Puedes colocar los archivos de snippets en cualquier parte de tu proyecto.

Cuando importas un snippet en otro archivo, este solo aparece en el lugar donde lo importas y no se renderiza como una página independiente. Cualquier archivo dentro de la carpeta `/snippets/` siempre es un snippet, incluso si no se importa desde otro archivo.

<div id="create-snippets">
  ## Crear fragmentos
</div>

Crea un archivo con el contenido que desees reutilizar. Los fragmentos pueden contener todos los tipos de contenido que admite Mintlify y pueden importar otros fragmentos.

<div id="import-snippets-into-pages">
  ## Importar fragmentos en páginas
</div>

Importa fragmentos en las páginas usando una ruta absoluta o relativa.

* **Importaciones absolutas**: Empiezan con `/` para importar desde la raíz de tu proyecto.
* **Importaciones relativas**: Usa `./` o `../` para importar fragmentos en relación con la ubicación del archivo actual.

<Tip>
  Las importaciones relativas permiten la navegación en tu IDE. Pulsa <kbd>CMD</kbd> y haz clic en un nombre de fragmento en tu editor para ir directamente a la definición del fragmento.
</Tip>

<div id="import-text">
  ### Importar texto
</div>

1. Añade contenido al archivo de fragmento (snippet) que quieras reutilizar.

   ```mdx shared/my-snippet.mdx wrap
   ¡Hola, mundo! Este es el contenido que quiero reutilizar en varias páginas.
   ```

2. Importa el fragmento (snippet) en tu archivo de destino usando una ruta absoluta o relativa.

   <CodeGroup>
     ```mdx Absolute import
     ---
     title: "Una página de ejemplo"
     description: "Esta es una página de ejemplo que importa un fragmento (snippet)."
     ---

     import MySnippet from "/shared/my-snippet.mdx";

     El contenido del fragmento se muestra debajo de esta frase.

     <MySnippet />
     ```

     ```mdx Relative import
     ---
     title: "Una página de ejemplo"
     description: "Esta es una página de ejemplo que importa un fragmento (snippet)."
     ---

     import MySnippet from "../shared/my-snippet.mdx";

     El contenido del fragmento se muestra debajo de esta frase.

     <MySnippet />
     ```
   </CodeGroup>

<div id="import-variables">
  ### Importar variables
</div>

Haz referencia a variables definidas en un snippet dentro de una página.

1. Exporta variables desde un archivo de snippet.

   ```mdx shared/custom-variables.mdx
   export const myName = "Ronan";

   export const myObject = { fruit: "strawberries" };

   ;
   ```

2. Importa el snippet desde tu archivo de destino y usa la variable.

   ```mdx destination-file.mdx
   ---
   title: "An example page"
   description: "This is an example page that imports a snippet with variables."
   ---

   import { myName, myObject } from "/shared/custom-variables.mdx";

   Hello, my name is {myName} and I like {myObject.fruit}.
   ```

<div id="import-snippets-with-variables">
  ### Importar fragmentos con variables
</div>

Usa variables para pasar datos a un fragmento al importarlo.

1. Agrega variables a tu fragmento y pasa propiedades al importarlo. En este ejemplo, la variable es `{word}`.

   ```mdx shared/my-snippet.mdx
   My keyword of the day is {word}.
   ```

2. Importa el fragmento en tu archivo de destino con la variable. La propiedad que pases reemplaza la variable en la definición del fragmento.

   ```mdx destination-file.mdx
   ---
   title: "An example page"
   description: "This is an example page that imports a snippet with a variable."
   ---

   import MySnippet from "/shared/my-snippet.mdx";

   <MySnippet word="bananas" />
   ```

<div id="import-react-components">
  ### Importar componentes de React
</div>

1. Crea un snippet con un componente JSX. Consulta [Componentes de React](/es/customize/react-components) para obtener más información.

   ```js components/my-jsx-snippet.jsx
   export const MyJSXSnippet = () => {
     return (
       <div>
         <h1>Hello, world!</h1>
       </div>
     );
   };
   ```

<Note>
  Al crear snippets de JSX, utiliza la sintaxis de función flecha (`=>`) en lugar de declaraciones de función. La palabra clave `function` no es compatible en los snippets.
</Note>

2. Importa el snippet.

   ```mdx destination-file.mdx
   ---
   title: "Una página de ejemplo"
   description: "Esta es una página de ejemplo que importa un snippet con un componente de React."
   ---

   import { MyJSXSnippet } from "/components/my-jsx-snippet.jsx";

   <MyJSXSnippet />
   ```
