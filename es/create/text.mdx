<div id="headers">
  ## Encabezados
</div>

Los encabezados organizan tu contenido y crean anclas de navegación. Aparecen en la tabla de contenido y ayudan a los usuarios a examinar rápidamente tu documentación.

<div id="creating-headers">
  ### Crear encabezados
</div>

Usa el símbolo `#` para crear encabezados de distintos niveles:

```mdx
## Main section header
### Subsection header
#### Sub-subsection header
```

<Tip>
  Usa encabezados descriptivos y con palabras clave relevantes que indiquen claramente el contenido que sigue. Esto mejora tanto la navegación como la optimización para motores de búsqueda.
</Tip>

<div id="disabling-anchor-links">
  ### Desactivar enlaces de ancla
</div>

De forma predeterminada, los encabezados incluyen enlaces de ancla clicables que permiten a los usuarios enlazar directamente a secciones específicas. Puedes desactivar estos enlaces de ancla con la prop `noAnchor` en encabezados HTML o React.

<CodeGroup>
  ```mdx HTML header example
  <h2 noAnchor>
  Header without anchor link
  </h2>
  ```

  ```mdx React header example
  <Heading level={2} noAnchor>
  Header without anchor link
  </Heading>
  ```
</CodeGroup>

Cuando se usa `noAnchor`, el encabezado no mostrará el chip de ancla, y al hacer clic en el texto del encabezado no se copiará el enlace de ancla al portapapeles.

## Formato de texto

Admitimos la mayoría de los formatos de Markdown para resaltar y dar estilo al texto.

<div id="basic-formatting">
  ### Formato básico
</div>

Aplica estos estilos de formato al texto:

| Estilo      | Sintaxis    | Ejemplo               | Resultado            |
| ----------- | ----------- | --------------------- | -------------------- |
| **Negrita** | `**texto**` | `**nota importante**` | **nota importante**  |
| *Cursiva*   | `_texto_`   | `_énfasis_`           | *énfasis*            |
| ~~Tachado~~ | `~texto~`   | `~función obsoleta~`  | ~~función obsoleta~~ |

<div id="combining-formats">
  ### Combinación de formatos
</div>

Puedes combinar estilos de formato:

```mdx
**_bold and italic_**
**~~bold and strikethrough~~**
*~~italic and strikethrough~~*
```

***negrita y cursiva***<br />
**~~negrita y tachado~~**<br />
*~~cursiva y tachado~~*

<div id="superscript-and-subscript">
  ### Superíndice y subíndice
</div>

Para expresiones matemáticas o notas al pie, usa etiquetas HTML:

| Tipo        | Sintaxis          | Ejemplo               | Resultado           |
| ----------- | ----------------- | --------------------- | ------------------- |
| Superíndice | `<sup>text</sup>` | `example<sup>2</sup>` | example<sup>2</sup> |
| Subíndice   | `<sub>text</sub>` | `example<sub>n</sub>` | example<sub>n</sub> |

## Enlaces

Los enlaces ayudan a los usuarios a navegar entre páginas y a acceder a recursos externos. Usa un texto de enlace descriptivo para mejorar la accesibilidad y la experiencia del usuario.

<div id="internal-links">
  ### Enlaces internos
</div>

Enlaza a otras páginas de tu documentación mediante rutas relativas a la raíz:

```mdx
[Quickstart](/quickstart)
[Steps](/components/steps)
```

[Primeros pasos](/es/quickstart)<br />
[Pasos](/es/components/steps)

<div id="external-links">
  ### Enlaces externos
</div>

Para los recursos externos, incluye la URL completa:

```mdx
[Markdown Guide](https://www.markdownguide.org/)
```

[Guía de Markdown](https://www.markdownguide.org/)

<div id="broken-links">
  ### Enlaces rotos
</div>

Puedes comprobar si hay enlaces rotos en tu documentación con la [CLI](/es/installation):

```bash
mint broken-links
```

<div id="blockquotes">
  ## Citas en bloque
</div>

Las citas en bloque permiten destacar información importante, citas o ejemplos en tu contenido.

<div id="single-line-blockquotes">
  ### Citas en bloque de una sola línea
</div>

Añade `>` antes del texto para crear una cita en bloque:

```mdx
> This is a quote that stands out from the main content.
```

> Esta es una cita que destaca dentro del contenido principal.

<div id="multi-line-blockquotes">
  ### Citas en bloque de varias líneas
</div>

Para citas más largas o de varios párrafos:

```mdx
> Este es el primer párrafo de una cita en bloque multilínea.
>
> Este es el segundo párrafo, separado por una línea vacía con `>`.
```

> Este es el primer párrafo de una cita en bloque de varias líneas.
>
> Este es el segundo párrafo, separado por una línea en blanco con `>`.

<Tip>
  Usa las citas en bloque con moderación para mantener su impacto visual y significado. Considera usar [callouts](/es/components/callouts) para notas, advertencias y otros tipos de información.
</Tip>

<div id="mathematical-expressions">
  ## Expresiones matemáticas
</div>

Admitimos LaTeX para mostrar expresiones y ecuaciones matemáticas. Puedes anular la detección automática configurando `styles.latex` en tu `docs.json` [configuración](/es/organize/settings#param-latex).

<div id="inline-math">
  ### Matemáticas en línea
</div>

Usa un solo signo de dólar, `$`, para las expresiones matemáticas en línea:

```mdx
The Pythagorean theorem states that $(a^2 + b^2 = c^2)$ in a right triangle.
```

El teorema de Pitágoras establece que $(a^2 + b^2 = c^2)$ en un triángulo rectángulo.

<div id="block-equations">
  ### Ecuaciones en bloque
</div>

Usa dos signos de dólar, `$$`, para ecuaciones independientes:

```mdx
$$
E = mc^2
$$
```

$$
E = mc^2
$$

<Info>
  La compatibilidad con LaTeX requiere una sintaxis matemática correcta. Consulta la [documentación de LaTeX](https://www.latex-project.org/help/documentation/) para ver una guía completa sobre la sintaxis.
</Info>

<div id="line-breaks-and-spacing">
  ## Saltos de línea y espaciado
</div>

Controla el espaciado y los saltos de línea para mejorar la legibilidad del contenido.

<div id="paragraph-breaks">
  ### Saltos de párrafo
</div>

Separa los párrafos con líneas en blanco:

```mdx
This is the first paragraph.

This is the second paragraph, separated by a blank line.
```

Este es el primer párrafo.

Este es el segundo párrafo, separado por una línea en blanco.

<div id="manual-line-breaks">
  ### Saltos de línea manuales
</div>

Usa etiquetas HTML `<br />` para insertar saltos de línea forzados dentro de los párrafos:

```mdx
This line ends here.<br />
This line starts on a new line.
```

Esta línea termina aquí.<br />
Esta línea empieza en una línea nueva.

<Tip>
  En la mayoría de los casos, los saltos de párrafo con líneas en blanco ofrecen una mejor legibilidad que los saltos de línea manuales.
</Tip>

<div id="best-practices">
  ## Buenas prácticas
</div>

<div id="content-organization">
  ### Organización del contenido
</div>

* Usa encabezados para crear una jerarquía de contenido clara
* Sigue una jerarquía correcta de encabezados (no pases de H2 a H4)
* Escribe encabezados descriptivos y con palabras clave relevantes

<div id="text-formatting">
  ### Formato del texto
</div>

* Usa la negrita para dar énfasis, no para párrafos enteros
* Reserva la cursiva para términos, títulos o un énfasis sutil
* Evita el exceso de formato que distraiga del contenido

<div id="links">
  ### Enlaces
</div>

* Usa un texto de enlace descriptivo en lugar de &quot;haz clic aquí&quot; o &quot;leer más&quot;
* Usa rutas relativas a la raíz para los enlaces internos
* Comprueba los enlaces con regularidad para evitar referencias rotas
