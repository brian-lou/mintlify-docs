<div id="headers">
  ## Encabezados
</div>

Los encabezados organizan tu contenido y crean anclas de navegación. Aparecen en la tabla de contenidos y ayudan a los usuarios a recorrer rápidamente tu documentación.

<div id="creating-headers">
  ### Creación de encabezados
</div>

Usa el símbolo `#` para crear encabezados de distintos niveles:

```mdx
## Main section header
### Subsection header
#### Sub-subsection header
```

<Tip>
  Utiliza encabezados descriptivos, con palabras clave, que indiquen claramente el contenido que viene a continuación. Esto mejora tanto la navegación de los usuarios como el posicionamiento en motores de búsqueda.
</Tip>

<div id="disabling-anchor-links">
  ### Desactivar enlaces de ancla
</div>

De forma predeterminada, los encabezados incluyen enlaces de ancla en los que se puede hacer clic y que permiten a los usuarios enlazar directamente a secciones específicas. Puedes desactivar estos enlaces de ancla usando la prop `noAnchor` en encabezados HTML o de React.

<CodeGroup>
  ```mdx HTML header example
  <h2 noAnchor>
  Header without anchor link
  </h2>
  ```

  ```mdx React header example
  <Heading level={2} noAnchor>
  Header without anchor link
  </Heading>
  ```
</CodeGroup>

Cuando se usa `noAnchor`, el encabezado no mostrará la ficha de ancla y, al hacer clic en el texto del encabezado, no se copiará el enlace de ancla al portapapeles.

## Formato de texto

Admitimos la mayoría de las opciones de formato de Markdown para resaltar y dar estilo al texto.

<div id="basic-formatting">
  ### Formato básico
</div>

Aplica estos estilos de formato a tu texto:

| Estilo | Sintaxis | Ejemplo | Resultado |
|-------|--------|---------|--------|
| **Negrita** | `**text**` | `**nota importante**` | **nota importante** |
| *Cursiva* | `_text_` | `_énfasis_` | *énfasis* |
| ~~Tachado~~ | `~text~` | `~función obsoleta~` | ~~función obsoleta~~ |

<div id="combining-formats">
  ### Combinar formatos
</div>

Puedes combinar distintos estilos de formato:

```mdx
**_bold and italic_**
**~~bold and strikethrough~~**
*~~italic and strikethrough~~*
```

***negrita y cursiva***<br />
**~~negrita y tachado~~**<br />
*~~cursiva y tachado~~*

<div id="superscript-and-subscript">
  ### Superíndice y subíndice
</div>

Para expresiones matemáticas o notas al pie, utiliza etiquetas HTML:

| Tipo | Sintaxis | Ejemplo | Resultado |
|------|--------|---------|--------|
| Superíndice | `<sup>text</sup>` | `example<sup>2</sup>` | example<sup>2</sup> |
| Subíndice | `<sub>text</sub>` | `example<sub>n</sub>` | example<sub>n</sub> |

## Enlaces

Los enlaces ayudan a los usuarios a navegar entre páginas y acceder a recursos externos. Utiliza textos de enlace descriptivos para mejorar la accesibilidad y la experiencia del usuario.

<div id="internal-links">
  ### Enlaces internos
</div>

Enlaza a otras páginas de tu documentación mediante rutas relativas a la raíz:

```mdx
[Quickstart](/quickstart)
[Steps](/components/steps)
```

[Guía rápida](/es/quickstart)<br />
[Pasos](/es/components/steps)

<div id="external-links">
  ### Enlaces externos
</div>

Para los recursos externos, incluye la URL completa:

```mdx
[Markdown Guide](https://www.markdownguide.org/)
```

[Guía de Markdown](https://www.markdownguide.org/)

<div id="broken-links">
  ### Enlaces rotos
</div>

Puedes comprobar si hay enlaces rotos en tu documentación mediante la [CLI](/es/installation):

```bash
mint broken-links
```

<div id="blockquotes">
  ## Citas en bloque
</div>

Las citas en bloque sirven para resaltar información importante, citas o ejemplos dentro de tu contenido.

<div id="single-line-blockquotes">
  ### Citas de una sola línea
</div>

Añade `>` antes del texto para crear una cita de bloque:

```mdx
> This is a quote that stands out from the main content.
```

> Esta es una cita que resalta frente al contenido principal.

<div id="multi-line-blockquotes">
  ### Citas en bloque de varias líneas
</div>

Para citas más largas o con varios párrafos:

```mdx
> Este es el primer párrafo de una cita de bloque multilínea.
>
> Este es el segundo párrafo, separado por una línea vacía con `>`.
```

> Este es el primer párrafo de una cita en bloque de varias líneas.
>
> Este es el segundo párrafo, separado por una línea en blanco con `>`.

<Tip>
  Usa las citas en bloque con moderación para mantener su impacto visual y significado. Considera usar [callouts](/es/components/callouts) para notas, advertencias y otros tipos de información.
</Tip>

<div id="mathematical-expressions">
  ## Expresiones matemáticas
</div>

Usamos LaTeX para mostrar expresiones y ecuaciones matemáticas. Puedes anular la detección automática configurando `styles.latex` en tu archivo `docs.json` en [configuración](/es/organize/settings#param-latex).

<div id="inline-math">
  ### Matemáticas en línea
</div>

Utiliza un solo signo de dólar, `$`, para las expresiones matemáticas en línea:

```mdx
The Pythagorean theorem states that $(a^2 + b^2 = c^2)$ in a right triangle.
```

El teorema de Pitágoras establece que $(a^2 + b^2 = c^2)$ en un triángulo rectángulo.

<div id="block-equations">
  ### Ecuaciones en bloque
</div>

Usa dos signos de dólar, `$$`, para ecuaciones en bloque:

```mdx
$$
E = mc^2
$$
```

$$
E = mc^2
$$

<Info>
  El soporte de LaTeX requiere una sintaxis matemática correcta. Consulta la [documentación de LaTeX](https://www.latex-project.org/help/documentation/) para obtener directrices detalladas sobre la sintaxis.
</Info>

<div id="line-breaks-and-spacing">
  ## Saltos de línea y espaciado
</div>

Controla los saltos de línea y el espaciado para mejorar la legibilidad del contenido.

<div id="paragraph-breaks">
  ### Saltos de párrafo
</div>

Separe los párrafos con una línea en blanco:

```mdx
This is the first paragraph.

This is the second paragraph, separated by a blank line.
```

Este es el primer párrafo.

Este es el segundo párrafo, separado por una línea en blanco.

<div id="manual-line-breaks">
  ### Saltos de línea manuales
</div>

Utiliza etiquetas HTML `<br />` para insertar saltos de línea forzados dentro de los párrafos:

```mdx
This line ends here.<br />
This line starts on a new line.
```

Esta línea termina aquí.<br />
Esta línea comienza en una nueva línea.

<Tip>
  En la mayoría de los casos, los saltos de párrafo con líneas en blanco mejoran la legibilidad frente a los saltos de línea manuales.
</Tip>

<div id="best-practices">
  ## Mejores prácticas
</div>

<div id="content-organization">
  ### Organización del contenido
</div>

* Usa encabezados para crear una jerarquía de contenido clara
* Sigue una jerarquía correcta de encabezados (no pases de H2 a H4)
* Escribe encabezados descriptivos y con abundantes palabras clave

<div id="text-formatting">
  ### Formato de texto
</div>

* Usa negrita para resaltar, no para párrafos completos
* Reserva la cursiva para términos, títulos o énfasis sutil
* Evita el exceso de formato que distraiga del contenido

<div id="links">
  ### Enlaces
</div>

* Escribe texto descriptivo para los enlaces en lugar de &quot;haz clic aquí&quot; o &quot;leer más&quot;
* Usa rutas relativas a la raíz para los enlaces internos
* Comprueba los enlaces con regularidad para evitar enlaces rotos
