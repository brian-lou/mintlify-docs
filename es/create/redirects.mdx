Cuando cambias la ruta de acceso de un archivo en la carpeta docs de tu documentación, también cambia la ruta de la URL de esa página. Esto puede ocurrir al reestructurar la documentación o al cambiar el título de la barra lateral.

<div id="redirects">
  ## Redirecciones
</div>

<Note>
  Las redirecciones **no pueden** incluir fragmentos de URL como `path#anchor` ni parámetros de consulta como `path?query=value`.
</Note>

Configura redirecciones 301 agregando el campo `redirects` a tu archivo `docs.json`.

```json
"redirects": [
  {
    "source": "/source/path",
    "destination": "/destination/path"
  }
]
```

Esto redirige permanentemente `/source/path` a `/destination/path` para que no pierdas el posicionamiento SEO previo de la página original.

<div id="wildcard-redirects">
  ### Redirecciones con comodín
</div>

Para hacer coincidir una ruta comodín, usa `*` después de un parámetro. En este ejemplo, `/beta/:slug*` coincide con `/beta/introduction` y la redirige a `/v2/introduction`.

```json
"redirects": [
  {
    "source": "/beta/:slug*",
    "destination": "/v2/:slug*"
  }
]
```

<div id="partial-wildcard-redirects">
  ### Redirecciones con comodines parciales
</div>

Utiliza comodines parciales para coincidir con segmentos de URL que empiezan con un prefijo determinado.

```json
"redirects": [
  {
    "source": "/articles/concepts-*",
    "destination": "/collections/overview"
  }
]
```

Esto hace coincidir cualquier URL con la ruta `/articles/concepts-`, como `/articles/concepts-getting-started` y `/articles/concepts-overview`, y las redirige todas a `/collections/overview`.

También puedes sustituir el valor del comodín capturado en el destino.

```json
"redirects": [
  {
    "source": "/old/article-*",
    "destination": "/new/article-*"
  }
]
```

Esto redirige `/old/article-123` a `/new/article-123`, manteniendo el valor capturado tras el prefijo.

<div id="avoid-infinite-redirects">
  ### Evitar redirecciones infinitas
</div>

Para evitar bucles infinitos, no crees redirecciones circulares en las que unas rutas redirijan a otras y viceversa.

```json
"redirects": [
  {
    "source": "/docs/:slug*",
    "destination": "/help/:slug*"
  },
  {
    "source": "/help/:slug*",
    "destination": "/docs/:slug*"
  }
]
```

<div id="check-for-broken-links">
  ## Comprobar enlaces rotos
</div>

Comprueba si hay enlaces rotos con la [CLI](/es/installation).

```bash
mint broken-links
```
